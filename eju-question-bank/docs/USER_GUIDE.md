# 本地题库使用说明

本说明覆盖已实现且经过测试的功能。完整后续范围见 [实施台账](IMPLEMENTATION_STATUS.md)，未完成项目仍在推进。

对照原规格的完成范围与明确限制见 [本轮交付记录](IMPLEMENTATION_DELIVERY_2026-09-08.md)。

### 新增操作提示

- 复核区域支持拖动位置及右下角缩放，精确数值输入仍可使用；改动后先保存再签署。撤回签署需填写原因，保留原签署记录和撤回事件。
- 学习恢复使用该会话固定版本的 outline 和题目分页；新版发布不会替换旧会话题目。停用收藏仍显示个人记录和原因，但不能进入组题预览。
- “学习安排”分别显示首答、重练、提示后作答的分母；来源待复核/停用的作答有质量提示。前台心跳计时有上限，不把多个会话同时打开计为多倍学习时长。
- 管理中的个人数据清空先预览、备份，再事务删除；渲染缓存清理是另一独立操作，不清理源 PDF、审核内容、媒体和历史。
- 数据升级前选择 FULL 备份并校验。恢复至新目录，旧程序回退应使用迁移前快照，不能直接打开更高版本数据库。

## 安装与启动

```bash
cd /workspace/Develop/eju-question-bank
python -m pip install -e '.[pdf,dev,browser]'
python -m playwright install chromium
python -m eju_bank serve --database library/eju.db
```

打开 `http://127.0.0.1:8765`。学习页面的数学公式已随项目本地提供，无须访问CDN。启动会执行事务迁移，拒绝比本程序更新的数据库。

## 三个工作区

界面按角色分成三个独立工作区，入口页 `/` 只做选择：

| 地址 | 工作区 | 内容 |
|---|---|---|
| `/practice` | 開始練習 | 选科目 → 选练法（整卷模考 / 单科精练 / 专项组题）→ 选卷 → 确认选科 → 作答 → 复盘 |
| `/me` | 我的学习中心 | 错题集、收藏笔记、练习记录、学习分析 |
| `/studio` | 题库制作台 | 导入、逐页复核、签署、发布与运维 |

每一层都有自己的地址，刷新停在原处，后退键在应用内导航，链接可以收藏也可以互相跳转。
常用深链：

```
/practice#/subject/SCIENCE/papers   理科的整卷列表
/practice#/collect                  跨卷检索组题
/practice#/session/<会话ID>          继续某次作答
/practice#/result/<会话ID>           某次作答的复盘
/me#/mistakes/SCIENCE               理科错题
/studio#/source/<来源ID>/stage/4     某套来源的逐页复核阶段
```

本机访问三个工作区都不需要口令：能连上 `127.0.0.1` 的就是本机用户本人。旧地址 `/index.html` 会自动跳到 `/practice`，已有书签不会失效。

从其他目录启动时，使用数据库的绝对路径；媒体默认读取该数据库旁的 `media/`。如果制作目录不同，使用 `--workspace-root` 明确指定包含 `sources/`、`work/`、`content/` 的项目目录。

## 这份卷是怎么过审的

卷卡片与选卷页会标明把关程度，开始作答之前就能看到：

- 没有徽标 = **人工复核**：每一页都由复核人对照原卷签署。
- `⚙ 机器校验` = 题干与选项是原卷的逐字 OCR，答案取自官方正解表并核对过确实在读到的选项里；
  但**未经人工逐页比对**，页面区域位置也未核实。选卷页还会列出这份卷缺了什么
  （例如「正解表列出 38 个解答欄，本次发布收录 22 个」）。

机器校验的卷一律是 `部分练习卷`，不开放全真模考。详见 `docs/CONTENT_RELEASE_2026-09-11.md`。

2026-09-10 退役的 217 套卷（答案为占位值或未签署）仍为暂停状态，不会出现在可练列表里；
它们对应的历史学习记录和复盘完整保留。

## 作答、暂停与恢复

- 试卷卡片显示完整度、可用模式及内容状态，未开放的模式不能创建会话。
- 作答会自动保存；“已保存”表示收到服务器确认，待发送内容同时保留本机草稿。
- 保存失败时点击保存状态重试。主动交卷必须先保存成功。
- 刷新页面会恢复上次会话，也可以从练习记录继续未完成会话。暂停时题目不可修改。
- 模考截止后以服务器截止前接受的答案为准；未能及时提交的本机草稿保留供核对，不计入截止后的答卷。
- 本次“存疑”标记与长期收藏分别保存。已提交会话只读，重新练习会生成新的记录。

多个页面同时编辑同一会话时，过期版本会被拒绝，避免静默覆盖。此时保留草稿并核对服务器最新会话；完整的冲突合并界面仍在完善。

## 答案复盘与历史

交卷后显示完整题面、材料、选项、本人作答和正确答案；数字格逐格显示错误或漏填。作文显示“待评阅”，不纳入客观题正确率。已复核解析存在时展示，缺少时明确标注。

汇总正确率按所选客观题总数计算，包括未答题。历史旧结果使用新版统计口径展示并注明，原始存储结果保留。历史详情从当时版本加载，之后发布新题卷不会改变旧答卷的题文和答案。

“打印/导出”打开浏览器打印功能，可选择保存为PDF。

## 找题、收藏、笔记与错题

跨卷检索组题是練習工作区的第三种练法（`/practice#/collect`），可按科目、关键词、知识点标签及全部/未做/收藏/错题/笔记/到期复习范围搜索。选择题目后可开专项练习，支持跨卷；共享材料题会一并加入，并保持题组内部顺序。开始前会先显示预览，说明实际题量。

收藏、笔记、错题和练习记录属于个人资产，都在 `/me`。题目和复盘页可展开个人笔记，笔记自动保存，保存失败保留本机草稿；关键词搜索同时检索题干、标签和个人笔记。

错题集按科目分段，各科独立取数、独立复习，不把不同科目的掌握度混成一个数字。每条错题可直接重练、保存错因、标记已掌握、安排今天/明天/3天后/一周后的复习。「去重练」会跳回練習工作区并自动组题。重练成功会进入“复习中”；再次做错会重新进入新错题。未作答和作文不作为客观答错题自动混入。

## 对照来源复核与发布

来源通过现有 `source-init/probe/render/extract` 命令准备。来源清单位于 `work/<目录>/source-manifest.json`；维护页会列出这些来源。

制作台按 `PIPELINE.md` 的状态流分成八个阶段，来源列表每一行显示这套卷卡在哪一步、下一个动作是什么。未满足前置条件的阶段点不动，并写明差哪一步。「探测与渲染」是可选加速，跳过也能逐页复核。

1. 从 `/studio` 的来源列表点进一套来源，进入阶段 ④「提取与逐页复核」，点「打开复核工作台」，选择题册/答案册和PDF物理页码。
2. 左侧显示真实原页与bbox标记；右侧编辑题文、选项、公式和顺序。裁图、完整JSON与前后差异收在「进阶」折叠区里，日常复核用不到。
3. 必要图形按明确的归一化区域裁剪，保存实际资产。选项专属图形应在JSON中放入对应选项的 `contentAst`，不能放错所属位置。
4. 空白或非题目页也需填写说明并登记，不能直接省略。
5. 保存为新草稿，修正所有合同问题和 `issues`。复核人实际对照完成后勾选确认并签署。系统不会替人自动签名。
6. 回到流水线，在阶段 ⑤ 对照原卷独立填写并签署来源结构（复核人姓名填在阶段列表顶部的「签署身份」里，签署结构与签署整卷共用）。
7. 阶段 ⑥ 组装并核对整卷题号、题量、分科、来源页和独立答案。其他科目的答案排除清单会单独列出；预检报告的问题显示在该阶段内，不会把入口关掉。
8. 阶段 ⑦ 签署整卷，阶段 ⑧ 发布到私人题库。发布检查内容摘要、复核证书、媒体文件与渠道约束；成功后更新内容清单。

导入、后台任务、内容问题、解析与翻译、评阅标准、备份与恢复都在制作台里：导入是来源的诞生方式，来源列表和阶段 ② 都链到同一个导入视图；其余跨来源的操作在「运维」组。听力音频在阶段 ⑤ 验证并试听，素材 ID 会自动填入，不需要手工粘贴 64 位十六进制。

修改已签署页面或撤回签署会生成新的草稿，撤销依赖它的整卷复核，使相应旧发布版本停止新交付。旧内容与作答历史仍保留。

命令行也可以组装签署页面，默认不会改写旧JSON：

```bash
python scripts/build_2023_science.py --out work/reviewed-candidate.json
python scripts/build_2023_science.py --review-id rev_实际签署编号
```

原先硬编码题文并删除页面目录的脚本已替换。批量裁图脚本只处理合同明确标记的figure，并要求写入新的草稿目录，不自动签署或发布。

## 备份、恢复与测试

```bash
python -m eju_bank backup create --database library/eju.db
python -m eju_bank backup verify --backup library/backups/实际备份文件.zip
python -m eju_bank backup restore --backup library/backups/实际备份文件.zip --target work/restored-library
pytest
```

新备份包含SQLite快照、内容清单和媒体文件，逐文件校验哈希，同时检查数据库完整性、外键和引用图片。恢复先在临时目录校验并迁移，成功后交付到目标目录；使用强制恢复时，原目标仍保存在相邻的 `.previous-*` 目录。

这类学习库备份不包含原始 `sources/` 和制作过程 `work/`，内容制作资料应另外保留。开始本次改造前的代码和数据库快照位于项目同级目录。

浏览器测试使用临时数据库和合成来源，不往正式库写模拟作答记录。

## 局域网访问

默认只允许本机，本机不需要令牌。确需局域网时，令牌就变成唯一的身份凭证，必须设置至少16字符的令牌、Host与Origin白名单，例如：

```bash
EJU_ADMIN_TOKEN='替换成自己的长随机令牌' python -m eju_bank serve \
  --database library/eju.db --host 0.0.0.0 --allow-remote \
  --allow-host 192.168.1.10 --allow-origin http://192.168.1.10:8765
```

页面上没有令牌输入框（它只服务过本机，已经删掉）。远程访问先换一次会话 cookie，之后浏览器即可正常使用：

```bash
curl -c cookies.txt -X POST http://192.168.1.10:8765/api/v1/auth \
  -H 'Origin: http://192.168.1.10:8765' \
  -d '{"token":"替换成自己的长随机令牌"}'
```

或者每次请求都带 `Authorization: Bearer <令牌>`。白名单应与实际访问地址一致；该功能仍是单用户题库的访问方式，不是多账户系统。

- 管理页面导入工作区内的文件，先题册，再答案/音频。成功导入只代表文件经探测和校验，不能代表题目已审核。选定来源后创建 PROBE、RENDER 或 EXTRACT 任务；OCR 使用工作区 `config/providers.json` 中预先配置的名称。

- 学习包保留运行数据与媒体；完整制作包还包含来源、草稿和配置。恢复到工作区内的新目录，检查完成后再选择是否切换服务。

### 只发布已复核部分

先核对完整来源的 `forms` 和物理页数 `pages`，再在独立结构中加入 `reviewedScope`，指定本次纳入的题目、题册页、答案页及缺失原因。例如：

```json
{
  "forms": {"PHYSICS_JA": ["PHYSICS:1", "PHYSICS:2"]},
  "pages": {"QUESTION_BOOKLET": 2, "ANSWER_KEY": 1},
  "reviewedScope": {
    "forms": {"PHYSICS_JA": ["PHYSICS:1"]},
    "pages": {"QUESTION_BOOKLET": [1], "ANSWER_KEY": [1]},
    "missingReasons": ["第 2 题尚未完成录入复核"]
  }
}
```

这是格式示例，需替换为实际核对结果。签署结构及范围内页面后，在复核台选择“仅已签署的明确范围”，生成候选、审批并发布。范围内题目及顺序必须与所选签署页完全一致。发布结果标为 PARTIAL，只开放练习和符合范围的分区；缺失部分不能计入整卷完整度，也不能开启完整模拟考试。
