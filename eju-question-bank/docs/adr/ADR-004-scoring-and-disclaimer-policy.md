# ADR-004: 练习评分统计与官方尺度分声明

- 状态：Accepted
- 日期：2026-09-03
- 决策人：EJU题库架构组

## 背景
EJU（日本留学考试）官方采用基于项目反应理论的“尺度等化计分体系”（Equating），其分值（0–200 或 0–400）并非卷面原始题数的简单加权，且官方并不公开项目参数。部分第三方产品将题目做简单比例折算冒充官方分数，严重误导考生。

## 决策
1. 明确标识：所有界面、API 返回与报告中，显式声明“原始练习统计，非官方等化尺度分”。
2. 客观题统计：仅返回“客观题正确数”、“做答总数”、“原始正确率”以及各科目明细。
3. 日本语记述题：不采用伪造评分，提供官方评分准则（Rubric），支持考生自评及人工批改录入。
4. 禁止在系统内使用“预测官方分”等具有误导性的字段命名。
