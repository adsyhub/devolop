# ADR-001: 本地单用户优先与远程暴露安全边界

- 状态：Accepted
- 日期：2026-09-03
- 决策人：EJU题库架构组

## 背景
EJU题库包含从扫描件识别的试题、图形与音频。对于多数学习者，属于个人本地私有学习副本（`PRIVATE_STUDY`）。若服务直接监听在公网或未经防护的局域网，会导致版权试题泄漏、未授权数据篡改及跨站请求伪造攻击。

## 决策
1. 默认网络绑定：HTTP服务默认仅绑定到 `127.0.0.1`（Loopback），禁止默认监听 `0.0.0.0`。
2. 远程访问开启条件：若用户显式传递 `--allow-remote`，必须同时指定 `--token` 或配置环境变量 `EJU_ADMIN_TOKEN`，并且必须验证请求头中的 `Host` 和 `Origin`。
3. 权限隔离：
   - Learner API：仅提供做题所需内容，永不返回正确答案密钥、原始PDF文件路径或版权内部审核备注。
   - Admin API：包括人工复核、签署、重新组卷和发布，必须具备管理员授权。
4. 防路径穿越：静态文件与媒体请求严格限制在对应根目录下，杜绝 `..` 及绝对路径访问。

## 2026-09-08 实施补充

本机单用户模式也默认生成管理凭证；维护 API、未发布媒体、源 PDF、签署和数据删除需要该凭证。
学习接口采用场景白名单 DTO。`EJU_TRUST_LOCAL=1` 是显式开发选择，不是默认模式；合成内容还要求
独立 `EJU_ALLOW_SYNTHETIC=1` 示例开关。

## 2026-09-10 修订：撤销本机访问令牌

上面这条"本机单用户模式也默认生成管理凭证"作废。回环绑定不再签发令牌，`EJU_TRUST_LOCAL`
开关一并删除（它唯一的作用就是关掉这个令牌）。

理由：令牌在本机模式下挡不住任何人。能连上 `127.0.0.1:8765` 的进程就是本机用户自己跑的
进程，它同样能直接打开 `library/eju.db`——令牌只是让题库的主人每次开工先对自己报一次口令。
真正在挡跨站点浏览器请求的是 `validate_host` / `validate_origin`：非回环 Host 和非同源
Origin 一律拒绝，这两道校验保持不变。

决策 2（`--allow-remote` 必须同时具备令牌、Host 白名单与 Origin 白名单）不受影响，且是
令牌现在唯一的存在理由：一旦服务对网络开放，令牌就是唯一的身份凭证，`create_server` 在
绑定端口之前就强制检查。制作台页面上的令牌输入框已删除，远程客户端改用
`POST /api/v1/auth` 换取会话 cookie 或直接携带 `Authorization: Bearer`。

内容待复核或停用时保留历史复盘；`RIGHTS_WITHDRAWN` 阻断原文与媒体交付，仅保留历史摘要。
生产服务启动独立 worker 进程，测试嵌入服务可以使用线程 worker。

配置顺序为显式参数、配置文件、默认工作区路径。发布、媒体与备份共用数据根，安装目录不保存个人数据。
备份恢复默认写入新目录，先校验再切换。
