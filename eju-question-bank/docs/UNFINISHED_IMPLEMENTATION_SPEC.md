## 3. 统一设计约束

### 3.1 数据与状态

1. **原文、答案、解析、个人数据分层**：原文与答案随题卷发布不可变；解析/翻译独立版本；笔记、错因、自评属于个人数据。
2. **签署绑定内容摘要**：来源文件哈希、结构基线 revision、页面 revision、媒体引用、规则 revision 共同进入审批摘要。修改任一依赖都需重新确认。
3. **真实与合成分离**：`contentKind=SYNTHETIC` 不能由普通导入 JSON 自行声明后免审进入正式题库。测试库明确启用 fixture 通道，正常工作区拒绝该通道或显示隔离的示例内容。
4. **发布状态与交付状态分离**：历史 `PUBLISHED` 不被覆盖；停用通过 `paper_delivery_state` 记录。重新开放必须验证有效证书和依赖，不能仅把状态字符串改成 `REVIEWED`。
5. **模式能力由服务端派生**：`availableModes` 是经审计的结果；`SECTION` 必须有实际可用分区，`MOCK` 必须具备完整结构和已核实规则。
6. **旧会话版本固定**：跨卷练习持久化所选题版本、材料与顺序；后续更新不得改变原答卷。修正统计口径保留原始结果及版本。
7. **新数据严格、旧数据显式兼容**：旧 v1 内容可以只读展示或迁移为待复核草稿，不能自动补签署、猜区域或把旧内容改为完整卷。

### 3.2 错误、幂等和分页

现有 `/api/v1` 保留。新增接口统一响应错误：

```json
{
  "error": {
    "code": "ANSWER_VERSION_CONFLICT",
    "message": "答案已在其他页面更新，请处理冲突后保存。",
    "requestId": "request-identifier",
    "details": {"currentVersion": 8, "recoverable": true}
  }
}
```

稳定错误码至少区分输入错误、版本冲突、内容不可用、资料缺失、媒体损坏和任务取消；details 只返回允许公开的定位信息。HTTP 请求 ID 与作答保存的幂等 requestId 分开命名，避免混淆。

JSON 字段按类型检验，不把 `false`、`0`、空对象静默变成默认数组；整数使用严格类型，拒绝布尔值。列表默认 limit=20 或 50，上限 200。新列表使用稳定排序键和 opaque cursor；兼容旧 offset 入口时明确迁移期，不将两种 cursor 混用。

批量写入先整批验证，再单事务提交；同一幂等键同一 payload 返回原结果，不同 payload 返回 409。长制作任务返回 202 和 jobId，通过查询获得进度，不能持有 HTTP 请求直到 OCR 完成。

### IMP-02：来源结构、完整度、syllabus 与 inventory 一致性

2. 建立独立 `source_structure_revisions`：记录每个 form 的顺序、题号/答案引用集合、section、材料组、题册及答案册全部物理页处置、排除项及原因。结构由原卷目录/题号核对建立，经签署后冻结，不能用候选题目反推期望值。

8. 审批后再次检查所有依赖。发布的证书验证、版本号分配、幂等判断与写入放进一致的事务边界；防止审批撤回和并发发布竞态。

验收：基准报告包含 p50/p95、payload 大小和峰值内存；键盘/焦点/缩放清单通过；优化后慢保存、刷新恢复和版本固定仍通过回归。

### IMP-20：结构化日志、诊断与数据保留

**优先级 P2；依赖 IMP-06/13/16。** 对应 R15、EJU-201/EJU-206。

1. 在现有 request ID/errorType 日志上补 timestamp、level、action、requestId/jobId、允许记录的 targetId、durationMs、result/errorCode。成功/失败均可关联，来源页任务能定位阶段和 attempt。
2. 不记录完整请求体、作文、标准答案、token、cookie、provider 密钥或本地敏感绝对路径。诊断导出只带配置键、版本、错误码和计数，私有内容必须显式选择。
3. 对日志、OCR 原始输出、渲染缓存、失败任务临时文件分别配置保留期/字节上限；默认清理可再生成数据，先 dry-run，再按已审核策略执行。已签署内容、历史、源文件不能被一般日志清理删除。
4. 个人数据删除/清空范围在数据管理页面明确预览，执行事务和备份策略；不是“顺便清缓存”。备份保留独立配置，失败或未经验证的最近包不替代最后一个有效恢复点。
5. `doctor` 检查 schema 资源、数据库、媒体 hash、磁盘、任务 lease、音频依赖与配置一致性；诊断不自动修复正式内容。错误码链接到操作手册中的恢复步骤。

验收：注入特殊笔记/作文/密钥标记后日志和诊断包中无这些正文；一个失败 OCR 可经 jobId 定位；保留策略不会删历史引用媒体；最后有效备份可恢复。
