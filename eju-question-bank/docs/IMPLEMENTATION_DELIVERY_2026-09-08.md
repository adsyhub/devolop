## 2. 核心代码入口

- `review.py`、`page_contract.py`、`schema_validation.py`：来源 baseline、页合同、签署/撤回、候选和证书。

- `sessions.py`、`learning.py`、`workflows.py`：保存事务、版本冻结、检索、统计、解析/翻译、听力、评阅。

- `ops.py`、`maintenance.py`、`workspace.py`：备份恢复、数据维护和配置根目录。
- `web/app.js`、`learning.js`、`review.js`、`workflows.js`：对应界面。

## 4. 自动验证与性能

本轮最终验证结果为 **105 passed in 64.72s (0:01:04)**，包含 Chromium；wheel 安装与异目录启动通过，校验结束后再次确认源码摘要一致。

最终测试数、安装检查和参与验证的文件摘要以 [release 记录](evidence/release-2026-09-08.json) 为准，JUnit 在同目录。统一命令：

```bash
python scripts/verify_release.py
```

此命令检查 Schema 同步、Python/JavaScript 语法、完整 pytest（含 Chromium）、wheel 构建、另一个 venv 的 wheel 安装和异目录工作区启动。若源码在过程中改变会失败，避免旧测试结果为新文件背书。`--skip-browser` 仅用于局部开发检查，不等价于完整 release 验收。

[性能报告](evidence/learning-benchmark-2026-09-08.json) 使用隔离的合成数据库：10,000 题、100 个卷版本、1,001 条会话及 200 题练习。本机热缓存数据库调用 p95：检索 40.005ms、历史 7.042ms、批量保存 5.476ms；记录了 payload 与 RSS。它不证明 HTTP/浏览器交互 p95，也不是跨硬件性能承诺。
