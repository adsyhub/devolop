## 問1：3本の糸による質点のつり合いと直角三角形の幾何的性質

**【考査考点】**：質点の静止条件（力のつり合い）, 直角三角形の辺の比と幾何学的相似, 力の分解・三角比

**【題目大意】**
天井の2点から伸びる長さ $3L$ の糸 $a$ と長さ $4L$ の糸 $b$ を結び合わせ、その結び目から糸 $c$ で質量 $M$ の小物体をつるして静止させた。
糸 $a$ と糸 $b$ のなす角は $90^\circ$ である。糸 $a$ の張力を $T$ とするとき、比 $\frac{T}{Mg}$ はいくらか。

**【公式正解】**：$\textcircled{3}$（$\frac{4}{5}$）

**【詳細推導・解答プロセス】**
1. **幾何配置の分析**：
   糸 $a$（長さ $3L$）と糸 $b$（長さ $4L$）が結び目において $90^\circ$ で直交している。
   天井は水平であり、天井上の2つの固定点と結び目がつくる三角形は、直角を挟む2辺が $3L$ と $4L$ の直角三角形である。
   三平方の定理より、天井の2点間の距離（斜辺）は $\sqrt{(3L)^2 + (4L)^2} = 5L$ である。
   したがって、この三角形の辺の比は $3 : 4 : 5$ である。
2. **力のつり合いとベクトル三角形**：
   結び目には以下の3つの力がはたらいて静止している：
   - 糸 $a$ の張力 $\vec{T}_a$（大きさ $T$、糸 $a$ の向き）
   - 糸 $b$ の張力 $\vec{T}_b$（大きさ $T_b$、糸 $b$ の向き）
   - 糸 $c$ の張力（小物体を鉛直下向きに引く重力 $Mg$ に等しい）
   $\vec{T}_a \perp \vec{T}_b$ であるため、これら3力のつり合いが作る閉じたベクトル三角形（力の三角形）も斜辺が $Mg$ の直角三角形となる。
3. **相似比による張力の計算**：
   糸 $a$ が鉛直線（重力の向き）となす角を $\theta$ とすると、幾何学的関係より：
   $$\cos\theta = \frac{4L}{5L} = \frac{4}{5}$$
   力の三角形において、鉛直成分のつり合いから糸 $a$ の張力は：
   $$T = Mg \cos\theta = Mg \times \frac{4}{5}$$
   したがって：
   $$\frac{T}{Mg} = \frac{4}{5}$$
   よって、正解は **$\textcircled{3}$** である。

## 問2：斜方投射における外力・加速度・速さの比較

**【考査考点】**：斜方投射の運動方程式, 重力加速度の不変性, 力学的エネルギー保存則と高さによる速さの変化

**【題目大意】**
地表から小物体を斜めに投げ上げ、放物線軌道を描いて地表に落下させた。軌道上の3点 $A, B, C$（$B$ は最高点、$A$ は上昇途中、$C$ は下降途中、$A$ の高さ $> C$ の高さ）における力・加速度・速さに関する文の正誤を判定する。

**【公式正解】**：$\textcircled{5}$（(a) 誤、(b) 正、(c) 正）

**【詳細推導・解答プロセス】**
1. **文(a)の検討**：
   空気抵抗は無視できるため、飛行中の小物体に作用する外力は常に「鉛直下向きの重力 $mg$」のみである。
   点 $A$ においても点 $B$ においても外力の大きさは等しく $mg$ である。
   したがって、「$A$ の力のほうが小さい」とする文(a)は **誤** である。
2. **文(b)の検討**：
   運動方程式 $m\vec{a} = m\vec{g}$ より、小物体の加速度は軌道上のどの点でも常に一定で、大きさは $g$（重力加速度）、向きは鉛直下向きである。
   したがって、点 $B$ と点 $C$ の加速度の大きさは等しい。文(b)は **正** である。
3. **文(c)の検討**：
   外力は保存力である重力のみであるから、力学的エネルギー保存則が成り立つ：
   $$\frac{1}{2}mv^2 + mgy = \text{一定}$$
   高さ $y$ が高い点ほど運動エネルギーが小さく、速さ $v$ は小さくなる。
   図より点 $A$ の位置は点 $C$ より高い位置にあるため、速さは $v_A < v_C$ となる。
   したがって、文(c)は **正** である。

以上より、(a) 誤、(b) 正、(c) 正 の組み合わせである **$\textcircled{5}$** が正しい。

## 問3：動摩擦力のある水平面上での物体の重なりと加速度の計算

**【考査考点】**：運動方程式 $ma = F - f$, 動摩擦力 $f = \mu' N$, 質量の変化と外力の変化による加速度の比例・加算関係

**【題目大意】**
床の上に質量 $m$ の小物体を置き、水平方向に力 $T$ を加えたときの加速度が $a$ であった。
次に、同じ床の上で質量 $m$ の小物体を2つ重ねて固定し（合計質量 $2m$）、水平方向に力 $3T$ を加えたときの加速度 $A$ を $a, m, T$ で表す。

**【公式正解】**：$\textcircled{5}$（$a + \frac{T}{2m}$）

**【詳細推導・解答プロセス】**
1. **図1（1個の物体）の運動方程式**：
   垂直抗力は $N_1 = mg$、動摩擦力は $f_1 = \mu' mg$ である。
   水平方向の運動方程式は：
   $$ma = T - \mu' mg \implies \mu' g = \frac{T - ma}{m} = \frac{T}{m} - a$$
2. **図2（2個重ねた物体）の運動方程式**：
   合計質量は $2m$、垂直抗力は $N_2 = (2m)g$、動摩擦力は $f_2 = \mu' (2m)g = 2\mu' mg$ である。
   水平方向の外力は $3T$ であるから、運動方程式は：
   $$(2m)A = 3T - \mu' (2m)g = 3T - 2m(\mu' g)$$
3. **$\mu' g$ を消去して $A$ を導出**：
   先に求めた $\mu' g = \frac{T}{m} - a$ を代入すると：
   $$2mA = 3T - 2m\left(\frac{T}{m} - a\right) = 3T - 2T + 2ma = T + 2ma$$
   両辺を $2m$ で割ると：
   $$A = \frac{T + 2ma}{2m} = a + \frac{T}{2m}$$
したがって、正解は **$\textcircled{5}$** である。

## 問4：鉛直ばね振り子の単振動の最大速さと自由落下の速さの比

**【考査考点】**：ばね振り子のつり合い位置 $kL = mg$, 単振動の力学的エネルギー保存則, 自由落下の等加速度運動の公式

**【題目大意】**
質量 $m$ の小物体をつるすと自然長から $L$ 伸びて静止するばねがある。自然長の位置から静かに手を放したときの単振動の最大速さを $v_1$ とする。
また、この物体をばねから外し、初速度 0 で自由落下させて距離 $L$ 落下した瞬間の速さを $v_2$ とする。比 $\frac{v_2}{v_1}$ を求める。

**【公式正解】**：$\textcircled{4}$（$\sqrt{2}$）

**【詳細推導・解答プロセス】**
1. **ばね定数 $k$ の決定**：
   伸び $L$ でつり合って静止したことから：
   $$kL = mg \implies k = \frac{mg}{L}$$
2. **単振動における最大速さ $v_1$**：
   自然長から静かに手を放すと、つり合いの位置（中心、伸び $L$）を中心として振幅 $A = L$ の単振動を行う。
   単振動において速さが最大となるのは、加速度が 0 となる「つり合いの位置（中心）」を通過するときである。
   力学的エネルギー保存則（または単振動の速度振幅公式 $v_{\text{max}} = A\omega$）：
   $$\omega = \sqrt{\frac{k}{m}} = \sqrt{\frac{mg/L}{m}} = \sqrt{\frac{g}{L}}$$
   $$v_1 = A\omega = L \sqrt{\frac{g}{L}} = \sqrt{gL}$$
3. **自由落下における速さ $v_2$**：
   初速 0 で重力加速度 $g$ のもと距離 $L$ 自由落下したときの速さは、公式 $v^2 - 0 = 2gL$ より：
   $$v_2 = \sqrt{2gL}$$
4. **速さの比**：
   $$\frac{v_2}{v_1} = \frac{\sqrt{2gL}}{\sqrt{gL}} = \sqrt{2}$$
したがって、正解は **$\textcircled{4}$** である。

## 問5：物体の完全非弾性衝突と動摩擦による制動停止距離

**【考査考点】**：運動量保存則（完全非弾性衝突）, 動摩擦力のする仕事と運動エネルギーの減少（機能関係）, 停止距離の導出

**【題目大意】**
質量 $m$ の小物体 A が速さ $v_0$ で、静止している質量 $2m$ の小物体 B に衝突して一体となった。
その後、一体となった物体が動摩擦係数 $\mu'$ の水平面上を距離 $d$ 進んで停止した。$d$ を求める。

**【公式正解】**：$\textcircled{1}$（$\frac{v_0^2}{18\mu'g}$）

**【詳細推導・解答プロセス】**
1. **衝突直後の速度 $V$ の決定（運動量保存則）**：
   衝突の瞬間に水平方向の外力積は無視できるため、運動量保存則が成り立つ：
   $$m v_0 + 2m \times 0 = (m + 2m) V$$
   $$3m V = m v_0 \implies V = \frac{1}{3}v_0$$
2. **衝突後の運動と摩擦による仕事**：
   一体となった物体の全質量は $M = 3m$ である。
   水平面から受ける垂直抗力は $N = (3m)g$、動摩擦力は $f = \mu' N = 3\mu' mg$ である。
   距離 $d$ 滑って静止するまでの仕事と運動エネルギーの関係より：
   $$0 - \frac{1}{2}(3m)V^2 = -f \cdot d$$
   $$\frac{1}{2}(3m)\left(\frac{1}{3}v_0\right)^2 = (3\mu' mg) \cdot d$$
   $$\frac{3m}{2} \times \frac{v_0^2}{9} = 3\mu' mg d \implies \frac{1}{6}m v_0^2 = 3\mu' mg d$$
3. **停止距離 $d$ の算出**：
   両辺を $3\mu' mg$ で割ると：
   $$d = \frac{\frac{1}{6}mv_0^2}{3\mu' mg} = \frac{v_0^2}{18\mu'g}$$
したがって、正解は **$\textcircled{1}$** である。

## 問6：単振り子の最下点における糸の張力の最大値

**【考査考点】**：力学的エネルギー保存則, 円運動の向心力方程式 $F - mg = m\frac{v^2}{L}$, 最下点での張力の極大値

**【題目大意】**
長さ $L$ の糸におもり（質量 $m$）をつけ、鉛直線から角度 $\theta_0$ 持ち上げて静かに放した。
鉛直面内での振動中に糸の張力が最大となる値 $F$ を求める。

**【公式正解】**：$\textcircled{5}$（$mg(3 - 2\cos\theta_0)$）

**【詳細推導・解答プロセス】**
1. **最下点での速さ $v$（力学的エネルギー保存則）**：
   最下点を重力による位置エネルギーの基準面にとる。
   角度 $\theta_0$ の位置の高さは $h = L(1 - \cos\theta_0)$ である。
   最下点に達した瞬間の速さを $v$ とすると：
   $$mgh = \frac{1}{2}mv^2 \implies mgL(1 - \cos\theta_0) = \frac{1}{2}mv^2$$
   $$\frac{mv^2}{L} = 2mg(1 - \cos\theta_0)$$
2. **最下点での円運動の運動方程式**：
   最下点において、おもりには上向きの張力 $F$ と下向きの重力 $mg$ が作用する。
   向心加速度は上向きに $\frac{v^2}{L}$ であるから：
   $$m\frac{v^2}{L} = F - mg \implies F = mg + m\frac{v^2}{L}$$
3. **張力の最大値 $F$ の計算**：
   向心力の式を代入すると：
   $$F = mg + 2mg(1 - \cos\theta_0) = mg(1 + 2 - 2\cos\theta_0) = mg(3 - 2\cos\theta_0)$$
したがって、正解は **$\textcircled{5}$** である。

## 問7：熱量保存の法則と金属球・水の比熱の比

**【考査考点】**：熱量保存則 $Q_{\text{放}} = Q_{\text{吸}}$, 熱容量・比熱の公式 $Q = mc\Delta T$, 比熱の比の計算

**【題目大意】**
質量 $100\text{ g}$、温度 $95^\circ\text{C}$ の金属球を、質量 $100\text{ g}$、温度 $5^\circ\text{C}$ の水に入れたところ、熱平衡に達して温度が $13^\circ\text{C}$ になった。
この金属の比熱は水の比熱の何倍か。

**【公式正解】**：$\textcircled{1}$（$0.1$ 倍）

**【詳細推導・解答プロセス】**
1. **熱量の移動の定式化**：
   金属の比熱を $c_m$、水の比熱を $c_w$ とする。
   - 金属球が放出した熱量：
     $$Q_1 = m_m c_m (95 - 13) = 100 \times c_m \times 82 = 8200 c_m$$
   - 水が吸収した熱量：
     $$Q_2 = m_w c_w (13 - 5) = 100 \times c_w \times 8 = 800 c_w$$
2. **熱量保存の法則**：
   外部との熱の出入りはないため $Q_1 = Q_2$ が成り立つ：
   $$8200 c_m = 800 c_w$$
3. **比の計算**：
   $$\frac{c_m}{c_w} = \frac{800}{8200} = \frac{8}{82} \approx 0.0976$$
   最も近い適当な値は **$0.1$** である。
したがって、正解は **$\textcircled{1}$** である。

## 問8：等温変化におけるコックの開放とピストンの移動量の比

**【考査考点】**：ボイルの法則（等温変化 $pV = \text{一定}$）, ピストンによる大気圧つり合い, 物質量保存と体積変化の計算

**【題目大意】**
断面積 $S$ のシリンダーが固定壁で領域 A と B に分かれている。B には可動ピストンがある。
初期状態：A 内は圧力 $\frac{5}{3}p_0$、長さ $h_0$。B 内は大気圧 $p_0$、長さ $h_1$。温度はともに一定の $T_0$。
コックを開けて充分時間が経ち平衡に達したとき、ピストンが移動して B の気体部分の長さが $h_2$ になった。
比 $\frac{h_2 - h_1}{h_0}$ を求める。

**【公式正解】**：$\textcircled{5}$（$\frac{2}{3}$）

**【詳細推導・解答プロセス】**
1. **平衡後の終状態の圧力**：
   B のピストンはなめらかに動くため、静止した最終状態では内部の全気体の圧力は大気圧 $p_0$ とつり合い、全体で圧力は $p_0$ となる。
2. **物質量保存（ボイルの法則の拡張）**：
   温度は終始 $T_0$ で一定であるため、全物質量に対応する $pV$ の和は保存される：
   $$\sum (pV)_{\text{初}} = \sum (pV)_{\text{終}}$$
   - 初状態：
     $$p_A V_A + p_B V_B = \left(\frac{5}{3}p_0\right)(S h_0) + p_0(S h_1)$$
   - 終状態：
     A の領域の体積は固定壁のため $S h_0$ のまま、B の領域の体積は $S h_2$ となる。
     全圧力が $p_0$ に均一化されるため：
     $$p_{\text{終}} (V_A + V_B') = p_0 (S h_0 + S h_2)$$
3. **等式の整理と移動量の導出**：
   $$\frac{5}{3}p_0 S h_0 + p_0 S h_1 = p_0 S h_0 + p_0 S h_2$$
   両辺を $p_0 S$ で割ると：
   $$\frac{5}{3}h_0 + h_1 = h_0 + h_2$$
   $$h_2 - h_1 = \frac{5}{3}h_0 - h_0 = \frac{2}{3}h_0$$
   したがって：
   $$\frac{h_2 - h_1}{h_0} = \frac{2}{3}$$
よって、正解は **$\textcircled{5}$** である。

## 問9：定積・定圧変化からなる矩形サイクルの熱効率

**【考査考点】**：$p-V$ グラフの正味の仕事 $W = \Delta p \Delta V$, 定積吸熱 $Q = n C_V \Delta T$ と定圧吸熱 $Q = n C_P \Delta T$, 熱効率 $e = \frac{W}{Q_{\text{in}}}$ の公式

**【題目大意】**
理想気体 $n$ [mol] に対し、状態 A$(p_0, V_0, T_0)$ $\to$ B$(2p_0, V_0)$ $\to$ C$(2p_0, 2V_0)$ $\to$ D$(p_0, 2V_0)$ $\to$ A のサイクルを考える。
定積モル比熱を $C_V$、気体定数を $R$ とするとき、熱効率 $e$ を求める。

**【公式正解】**：$\textcircled{2}$（$\frac{R}{3C_V + 2R}$）

**【詳細推導・解答プロセス】**
1. **各状態の温度**：
   状態方程式 $pV = nRT$ より：
   - $T_A = T_0$
   - $T_B = \frac{(2p_0)V_0}{nR} = 2T_0$
   - $T_C = \frac{(2p_0)(2V_0)}{nR} = 4T_0$
   - $T_D = \frac{p_0(2V_0)}{nR} = 2T_0$
2. **サイクルが外部にした正味の仕事 $W$**：
   $p-V$ 図で囲まれた長方形の面積が正味の仕事である：
   $$W = (2p_0 - p_0)(2V_0 - V_0) = p_0 V_0 = nRT_0$$
3. **吸収した熱量 $Q_{\text{in}}$ の算出**：
   熱を吸収する過程は、温度と圧力が上昇する A $\to$ B と B $\to$ C である：
   - **A $\to$ B（定積変化）**：
     $$Q_{AB} = n C_V (T_B - T_A) = n C_V (2T_0 - T_0) = n C_V T_0$$
   - **B $\to$ C（定圧変化）**：
     定圧モル比熱はマイヤーの関係式より $C_P = C_V + R$ であるから：
     $$Q_{BC} = n C_P (T_C - T_B) = n (C_V + R)(4T_0 - 2T_0) = 2n(C_V + R)T_0$$
   全吸収熱量は：
   $$Q_{\text{in}} = Q_{AB} + Q_{BC} = n C_V T_0 + 2n(C_V + R)T_0 = n(3C_V + 2R)T_0$$
4. **熱効率 $e$ の計算**：
   $$e = \frac{W}{Q_{\text{in}}} = \frac{nRT_0}{n(3C_V + 2R)T_0} = \frac{R}{3C_V + 2R}$$
したがって、正解は **$\textcircled{2}$** である。

## 問10：正弦波の $y-t$ グラフから特定時刻の $y-x$ 波形グラフへの変換

$x$ 軸の正の向きに速さ $v = 5.0\text{ m/s}$ で進む正弦波がある。

1. **$y-t$ グラフからの周期 $T$ と波長 $\lambda$ の読み取り**：
   $x = 0$ における振動のグラフから、1周期は $T = 4.0\text{ s}$ である。

3. **波形（$y-x$ グラフ）の判定**：

## 問11：遠ざかる反射板による音波の反射とドップラー効果によるうなり

**【考査考点】**：動く反射面によるドップラー効果（2段階の周波数変換）, うなりの振動数公式 $f_{\text{beat}} = |f_1 - f_2|$, 相対速度と音速の関係

**【題目大意】**
静止した観測者と音源（$f_0 = 682\text{ Hz}$、音速 $V = 340\text{ m/s}$）に対し、反射板が速さ $v = 1\text{ m/s}$ で遠ざかっている。
直接音と反射音の干渉によって生じる毎秒のうなりの回数 $n$ を求める。

**【公式正解】**：$\textcircled{4}$（$4$ 回）

**【詳細推導・解答プロセス】**
1. **反射板が受ける周波数 $f'$**：
   音源は静止、反射板は速さ $v = 1\text{ m/s}$ で遠ざかる観測者とみなせるので：
   $$f' = f_0 \frac{V - v}{V}$$
2. **反射板から静止観測者に届く周波数 $f''$**：
   反射板を周波数 $f'$ の音を出しながら遠ざかる音源とみなせるので：
   $$f'' = f' \frac{V}{V + v} = f_0 \left(\frac{V - v}{V}\right) \left(\frac{V}{V + v}\right) = f_0 \frac{V - v}{V + v}$$
3. **うなりの回数 $n$ の算出**：
   観測者は静止音源からの直接音 $f_0$ と反射音 $f''$ を同時に聞くため、うなりの回数は：
   $$n = |f_0 - f''| = f_0 \left(1 - \frac{V - v}{V + v}\right) = f_0 \frac{(V + v) - (V - v)}{V + v} = f_0 \frac{2v}{V + v}$$
4. **数値を代入**：
   $$n = 682 \times \frac{2 \times 1}{340 + 1} = 682 \times \frac{2}{341} = 2 \times 2 = 4\text{ 回/秒}$$
したがって、正解は **$\textcircled{4}$** である。

## 問12：凸レンズの焦点内側に置いた物体の結像（虚像・正立・倍率）

**【考査考点】**：凸レンズの写像公式 $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$, 焦点の内側に物体を置いた場合の虚像の形成, 横倍率公式 $m = |\frac{b}{a}|$

焦点距離 $f$ の凸レンズの中心 $O$ と焦点 $F$ の中点 $A$ に物体を置いた。

3. **倍率の計算**：

## 問13：点電荷のクーロン力に抗して移動させる外力の仕事

**【考査考点】**：点電荷のつくる電位 $V(r) = k_0 \frac{Q}{r}$, 静電気力による位置エネルギー $U = qV$, 外力の仕事と位置エネルギーの変化量 $W = \Delta U$

**【題目大意】**
原点に固定された点電荷 $Q$ による電場中で、電荷 $q$ の点電荷を静電気力とつりあう外力を加えて $x = r$ から $x = R$（$R > r$）までゆっくり移動させた。外力のした仕事 $W$ を求める。

**【公式正解】**：$\textcircled{3}$（$-\frac{k_0 Q q}{r} + \frac{k_0 Q q}{R}$）

**【詳細推導・解答プロセス】**
1. **電位と位置エネルギー**：
   原点の点電荷 $Q$ から距離 $x$ の点における電位は：
   $$V(x) = k_0 \frac{Q}{x}$$
   電荷 $q$ がもつ静電エネルギー（位置エネルギー）は：
   $$U(x) = q V(x) = k_0 \frac{Qq}{x}$$
2. **外力の仕事とエネルギー変化**：

   $$W = U(R) - U(r) = k_0 \frac{Qq}{R} - k_0 \frac{Qq}{r} = -\frac{k_0 Q q}{r} + \frac{k_0 Q q}{R}$$
したがって、正解は **$\textcircled{3}$** である。

## 問14：直列・並列コンデンサー回路のスイッチ切り替えと電荷の再分配

**【考査考点】**：直列コンデンサーの充電と電荷量 $Q = C_{\text{eq}} E$, スイッチ切り替え後の孤立導線部の電荷保存則, 並列接続時の端子電圧と電荷再分配

**【題目大意】**
起電力 $6.0\text{ V}$ の電池、$C_1 = 2.0\ \mu\text{F}$, $C_2 = 4.0\ \mu\text{F}$, $C_3 = 6.0\ \mu\text{F}$ のコンデンサーを接続した回路がある。
$S_1$ を閉じて充分時間が経過した後に開き、続いて $S_2$ を閉じて充分時間が経過した後に開いた。このとき $C_2$ に蓄えられている電気量 $Q_2$ を求める。

**【公式正解】**：$\textcircled{2}$（$3.2\ \mu\text{C}$）

**【詳細推導・解答プロセス】**
1. **$S_1$ を閉じたときの充電（ステップ1）**：
   $S_1$ を閉じると、電池と $C_1, C_2$ が直列に接続された閉回路が形成される。
   $C_1$ と $C_2$ の直列合成容量 $C_{12}$ は：
   $$C_{12} = \frac{C_1 C_2}{C_1 + C_2} = \frac{2.0 \times 4.0}{2.0 + 4.0} = \frac{8.0}{6.0} = \frac{4}{3}\ \mu\text{F}$$
   電池の起電力は $E = 6.0\text{ V}$ であるから、回路に流れて各コンデンサーに蓄えられる電気量は：
   $$Q_0 = C_{12} E = \frac{4}{3}\ \mu\text{F} \times 6.0\text{ V} = 8.0\ \mu\text{C}$$
   このとき $C_2$ の上側極板には $+8.0\ \mu\text{C}$ の電荷が蓄えられている。
2. **$S_1$ を開いて $S_2$ を閉じたときの電荷再分配（ステップ2）**：
   $S_2$ を閉じると、電荷を持っていた $C_2$ に対し、電荷を持たなかった $C_3$ が並列に接続される。
   $C_2$ と $C_3$ の上側極板がつながる導線部分は孤立しており、電荷の総量 $+8.0\ \mu\text{C}$ が保存される。
   並列接続全体の合成容量は：
   $$C_{23} = C_2 + C_3 = 4.0\ \mu\text{F} + 6.0\ \mu\text{F} = 10.0\ \mu\text{F}$$
   平衡時の共通電位差 $V'$ は：
   $$V' = \frac{Q_0}{C_{23}} = \frac{8.0\ \mu\text{C}}{10.0\ \mu\text{F}} = 0.80\text{ V}$$
3. **$C_2$ の最終電気量 $Q_2$**：
   $$Q_2 = C_2 V' = 4.0\ \mu\text{F} \times 0.80\text{ V} = 3.2\ \mu\text{C}$$
したがって、正解は **$\textcircled{2}$** である。

**【公式正解】**：$\textcircled{3}$（$\frac{3\mu I i}{4\pi}$）

**【詳細推導・解答プロセス】**
1. **辺 $AD$ 上の磁場が 0 となる電流 $I'$ の決定**：
   辺 $AD$ は導線 $XX'$ から距離 $a$、導線 $YY'$ から距離 $2a$ の位置にある。
   両導線の電流による磁場が打ち消し合うため：
   $$\frac{\mu I}{2\pi a} = \frac{\mu I'}{2\pi (2a)} \implies I' = 2I$$

   - 辺 $AD$：磁場が 0 の場所にあるため、受ける力は $0$ である。

     合成磁場は紙面の裏向きに：
     $$B = B_2 - B_1 = \frac{\mu I}{\pi a} - \frac{\mu I}{4\pi a} = \frac{3\mu I}{4\pi a}$$

   $$F = i a B = i a \left(\frac{3\mu I}{4\pi a}\right) = \frac{3\mu I i}{4\pi}$$
したがって、正解は **$\textcircled{3}$** である。

## 問17：一様磁場中の荷電粒子の半円軌道・ローレンツ力と比電荷の決定

**【考査考点】**：ローレンツ力 $\vec{F} = q(\vec{v} \times \vec{B})$ とフレミングの左手の法則, サイクロトロン運動の周期と半径 $r = \frac{mv}{qB}$, 通過時間 $t$ による比電荷 $\frac{q}{m}$ の表現

$y > 0$ の領域に磁束密度 $B$ の一様磁場がある。正の電荷 $q$（質量 $m$）が点 $(-r, 0)$ から $+y$ 向きに速さ $v$ で入射し、時間 $t$ 後に点 $(r, 0)$ から $-y$ 向きに出ていった。
磁場の向きおよび比電荷 $\frac{q}{m}$ を求める。

**【公式正解】**：$\textcircled{2}$（表$\to$裏、$\frac{\pi}{Bt}$）

**【詳細推導・解答プロセス】**
1. **磁場の向きの決定**：
   粒子は $(-r, 0)$ から入射して右向き（$+x$ 側）に偏向し、半円を描いて $(r, 0)$ から出ている。

   人差し指（磁場）は紙面に垂直で「表から裏の向き（表 $\to$ 裏）」でなければならない。

   粒子が描く軌道は半径 $r$ の半円であり、移動した弧長は $\pi r$ である。

   $$t = \frac{\pi r}{v}$$

   $$\frac{r}{v} = \frac{m}{qB}$$

   $$t = \pi \left(\frac{m}{qB}\right) = \frac{\pi m}{qB}$$

   $$\frac{q}{m} = \frac{\pi}{Bt}$$
したがって、正しい組み合わせは **$\textcircled{2}$** である。

## 問18：磁場領域を通過する長方形コイルの誘導電流の時間変化グラフ

**【考査考点】**：ファラデーの電磁誘導の法則 $V = -\frac{\Delta \Phi}{\Delta t}$, レンツの法則による誘導電流の向きの決定, コイル長 $L > d$（磁場幅）における3段階の電流波形

**【題目大意】**
幅 $d$ の領域に裏から表向きの磁場がある。長さ $L$（$L > d$）の長方形コイルが一定の速さ $v$ でこの領域を通過するとき、コイルに流れる誘導電流 $I$ の時間変化グラフを選択する。

**【公式正解】**：$\textcircled{6}$

**【詳細推導・解答プロセス】**
1. **第1段階（コイルの前辺が進入中：$0 \le t < \frac{d}{v}$）**：
   コイルを貫く表向きの磁束が増加する。
   レンツの法則により、これを妨げる向き（裏向き）の磁場を作ろうとして、時計回りの誘導起電力・電流が生じる。
   問題文では反時計回りを正としているため、電流は **負の一定値** となる。
2. **第2段階（磁場領域が完全にコイルの内部にある期間：$\frac{d}{v} \le t < \frac{L}{v}$）**：
   $L > d$ であるため、磁場領域全体がコイルの内側に入り込む期間が存在する。
   このとき、コイルを貫く全磁束は $\Phi = B \times (d \times \text{幅})$ で一定であり、時間変化しない（$\frac{d\Phi}{dt} = 0$）。
   したがって、誘導電流は **$0$** となる。
3. **第3段階（コイルの後辺が脱出中：$\frac{L}{v} \le t < \frac{L+d}{v}$）**：
   コイルを貫く表向きの磁束が減少する。
   これを補う向き（表向き）の磁場を作ろうとして、反時計回りの誘導電流が生じる。
   したがって、電流は **正の一定値** となる。

「負の一定値 $\to$ 0 $\to$ 正の一定値」と推移するグラフは **$\textcircled{6}$** である。

## 問19：X線管の連続X線における最短波長（デュアン・ハントの法則）

**【考査考点】**：電子の運動エネルギー $E_k = eV$, 光子のエネルギー $E = h\nu = \frac{hc}{\lambda}$, 最短波長（Duane-Hunt limit）の導出

**【題目大意】**
加速電圧 $V$ の X 線管から放出される連続 X 線の最短波長 $\lambda_0$ を、$e, h, c, V$ を用いて表す。

**【公式正解】**：$\textcircled{6}$（$\frac{hc}{eV}$）

**【詳細推導・解答プロセス】**
1. **電子の最大運動エネルギー**：
   加速電圧 $V$ で加速された電子が陽極ターゲットに衝突する直前の運動エネルギーは：
   $$E_k = eV$$
2. **最短波長光子の放出（デュアン・ハントの法則）**：
   衝突の際、1個の電子がもつ全運動エネルギー $eV$ が一度の制動放射によってすべて1個の光子に変換されたとき、光子のエネルギーは最大となり、波長は最短 $\lambda_0$ となる。
   光子のエネルギー式 $E = h\nu = \frac{hc}{\lambda_0}$ より：
   $$eV = \frac{hc}{\lambda_0}$$
3. **最短波長 $\lambda_0$ の式**：
   $$\lambda_0 = \frac{hc}{eV}$$
したがって、正解は **$\textcircled{6}$** である。
