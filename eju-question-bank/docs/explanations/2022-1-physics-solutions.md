## 問1：2本の軽い糸による小物体のつり合い・張力比の導出

**【考査考点】**：共点力のつり合い, 力の直交分解（水平・鉛直成分）, 三角比を用いた張力比の計算

**【題目大意】**
天井から2本の軽い糸A、糸Bで小物体をつり下げたところ、Aは水平方向となす角が $60^\circ$、Bは水平方向となす角が $45^\circ$ になってつりあった。
このときのAの張力を $T_A$、Bの張力を $T_B$ とするとき、比 $\frac{T_A}{T_B}$ の値を求めよ。

**【公式正解】**：$\textcircled{2}$（$\sqrt{2}$）

**【詳細推導・解答プロセス】**
小物体は静止してつり合っているため、水平方向および鉛直方向の合力はともに 0 である。
1. **水平方向の力のつり合い**：
   糸Aの張力 $T_A$ の水平成分（左向き）と、糸Bの張力 $T_B$ の水平成分（右向き）がつり合うため：
   $$T_A \cos 60^\circ = T_B \cos 45^\circ$$
2. **三角比の代入**：
   $$\cos 60^\circ = \frac{1}{2}, \quad \cos 45^\circ = \frac{\sqrt{2}}{2}$$
   代入すると：
   $$T_A \cdot \frac{1}{2} = T_B \cdot \frac{\sqrt{2}}{2} \implies T_A = \sqrt{2} T_B$$
3. **張力比の計算**：
   $$\frac{T_A}{T_B} = \sqrt{2}$$
したがって、選択肢 $\textcircled{2}$ が正しい。

## 問2：直角三角形断面の台上の連結物体・運動方程式と加速度

**【考査考点】**：直角三角形の幾何学的辺比と斜面傾斜角の三角比, 連結物体の運動方程式, 滑車を介した糸の張力消去法

**【題目大意】**
各辺の長さが $3L, 4L, 5L$ の直角三角形の断面をもつ台が、長さ $5L$ の辺を下にして水平床上に固定されている。
台の最高点（直角の頂点）の滑車を介して、斜面 $4L$ 上の質量 $m$ の物体Aと、斜面 $3L$ 上の質量 $m$ の物体Bを軽い糸でつなぎ静かに手をはなした。
物体の加速度の大きさ $a$ を求めよ。摩擦は無視できる。

**【公式正解】**：$\textcircled{7}$（$\frac{g}{10}$）

**【詳細推導・解答プロセス】**
1. **各斜面の傾斜角の三角比**：
   底辺 $5L$ に対し、斜面 $4L$ と斜面 $3L$ のなす角は $90^\circ$ である。
   - 斜面 $4L$ の水平面に対する傾斜角を $\theta_A$ とすると、$\cos\theta_A = \frac{4L}{5L} = \frac{4}{5}$、$\sin\theta_A = \frac{3L}{5L} = \frac{3}{5}$ である。
   - 斜面 $3L$ の水平面に対する傾斜角を $\theta_B$ とすると、$\cos\theta_B = \frac{3L}{5L} = \frac{3}{5}$、$\sin\theta_B = \frac{4L}{5L} = \frac{4}{5}$ である。
2. **斜面方向の重力成分**：
   - 物体Aを斜面下向きに引く重力成分：$F_A = mg \sin\theta_A = \frac{3}{5}mg$
   - 物体Bを斜面下向きに引く重力成分：$F_B = mg \sin\theta_B = \frac{4}{5}mg$
   $F_B > F_A$ であるため、物体Bが斜面 $3L$ を滑り降り、物体Aが斜面 $4L$ を引き上げられる向きに運動する。
3. **系全体の運動方程式**：
   糸の張力を $T$ とすると：
   - 物体B：$ma = mg \sin\theta_B - T = \frac{4}{5}mg - T$
   - 物体A：$ma = T - mg \sin\theta_A = T - \frac{3}{5}mg$
   2式を加えると張力 $T$ が相殺され：
   $$2ma = \left(\frac{4}{5} - \frac{3}{5}\right)mg = \frac{1}{5}mg \implies a = \frac{g}{10}$$
したがって、選択肢 $\textcircled{7}$ が正しい。

## 問3：粗い斜面上の等加速度運動・$v-t$ グラフからの動摩擦力決定

**【考査考点】**：$v-t$ グラフの傾きと加速度の関係, 斜面上の運動方程式 $ma = mg\sin\theta - F_{\text{動}}$, 重力加速度 $g = 9.8\text{ m/s}^2$ の数値代入

**【題目大意】**
水平面と $30^\circ$ の角をなす粗い斜面上を質量 $2.0\text{ kg}$ の小物体が滑り降りている。
グラフより、時刻 $t = 0$ で $v = 0$、$t = 2\text{ s}$ で $v = 6\text{ m/s}$ であった。動摩擦力の大きさを求めよ（$g = 9.8\text{ m/s}^2$）。

**【公式正解】**：$\textcircled{2}$（$3.8\text{ N}$）

**【詳細推導・解答プロセス】**
1. **加速度 $a$ の算出**：
   $v-t$ グラフは直線であり、等加速度直線運動を表す。傾きより加速度は：
   $$a = \frac{\Delta v}{\Delta t} = \frac{6.0 - 0}{2.0 - 0} = 3.0\text{ m/s}^2$$
2. **斜面方向の運動方程式**：
   斜面下向きを正にとると、重力の斜面平行成分は $mg\sin 30^\circ$、動摩擦力 $F_{\text{動}}$ は運動を妨げる斜面上向きにはたらく。
   $$ma = mg \sin 30^\circ - F_{\text{動}}$$
3. **数値を代入して動摩擦力を計算**：
   $$2.0 \times 3.0 = 2.0 \times 9.8 \times \frac{1}{2} - F_{\text{動}}$$
   $$6.0 = 9.8 - F_{\text{動}} \implies F_{\text{動}} = 9.8 - 6.0 = 3.8\text{ N}$$
したがって、動摩擦力の大きさは $3.8\text{ N}$（選択肢 $\textcircled{2}$）である。

## 問4：直線上の2物体の正面衝突・運動量保存則と反発係数

**【考査考点】**：運動量保存則のベクトル（符号付き）立式, 反発係数（はねかえり係数）の定義式 $e = -\frac{v_B' - v_A'}{v_B - v_A}$, 衝突後の相対速度の計算

**【題目大意】**
質量 $m$ の物体Aが右向きに速さ $v$、質量 $\frac{3m}{2}$ の物体Bが左向きに速さ $\frac{v}{3}$ で向かい合って衝突した。
衝突直後にAが静止したとき、衝突の反発係数 $e$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$\frac{1}{4}$）

**【詳細推導・解答プロセス】**
右向きを正の向きとする。
- 衝突前：$v_A = v$、$v_B = -\frac{v}{3}$
- 衝突後：$v_A' = 0$、物体Bの速度を $v_B'$ とする。
1. **運動量保存則**：
   $$m v_A + \left(\frac{3m}{2}\right) v_B = m v_A' + \left(\frac{3m}{2}\right) v_B'$$
   $$mv + \frac{3m}{2}\left(-\frac{v}{3}\right) = 0 + \frac{3m}{2} v_B'$$
   $$mv - \frac{1}{2}mv = \frac{1}{2}mv = \frac{3}{2}m v_B' \implies v_B' = \frac{1}{3}v$$
2. **反発係数 $e$ の定義**：
   $$e = -\frac{v_B' - v_A'}{v_B - v_A} = -\frac{\frac{v}{3} - 0}{-\frac{v}{3} - v} = -\frac{\frac{1}{3}v}{-\frac{4}{3}v} = \frac{1}{4}$$
したがって、選択肢 $\textcircled{4}$ が正しい。

## 問5：円すい振子状の円すい面内等速円運動・向心力と垂直抗力

**【考査考点】**：円運動の運動方程式 $m\frac{v^2}{r} = F_{\text{向心}}$, 鉛直方向のつり合い, 円すい面傾斜角 $\theta$ と垂直抗力の成分分解

**【題目大意】**
頂点を下にした円すい面の内側で、小物体が中心軸となす角 $\theta$ を保ちながら半径 $r$、速さ $v$ の等速円運動をしている。
$r, v, \theta$ の関係式を求めよ。

**【公式正解】**：$\textcircled{3}$（$\tan\theta = \frac{gr}{v^2}$）

**【詳細推導・解答プロセス】**
中心軸（鉛直軸）と円すい面の母線のなす角が $\theta$ である。
小物体が面から受ける垂直抗力を $N$ とすると、垂直抗力は母線に垂直であるため：
- 面が鉛直となす角が $\theta$ なので、面は水平面となす角が $90^\circ - \theta$ である。
- したがって、垂直抗力 $N$ は水平面となす角が $\theta$（鉛直上向きとなす角が $90^\circ - \theta$）となる。
1. **鉛直方向の力のつり合い**：
   $$N \sin\theta = mg$$
2. **水平方向の運動方程式（向心力）**：
   $$N \cos\theta = m \frac{v^2}{r}$$
3. **2式の比をとる**：
   $$\frac{N \sin\theta}{N \cos\theta} = \frac{mg}{m \frac{v^2}{r}} \implies \tan\theta = \frac{gr}{v^2}$$
したがって、選択肢 $\textcircled{3}$ が正しい。

## 問6：人工衛星の円軌道運動・万有引力と地表の重力加速度

**【考査考点】**：地表における重力と万有引力 $mg = \frac{GMm}{R^2} \iff GM = gR^2$, 軌道半径 $r = 3R$ における等速円運動, 軌道速度 $v$ の導出

**【題目大意】**
地球を半径 $R$ の球、地表での重力加速度を $g$ とする。地球中心から半径 $3R$ の円軌道を速さ $v$ で等速円運動する人工衛星の速さ $v$ を求めよ。

**【公式正解】**：$\textcircled{2}$（$\sqrt{\frac{gR}{3}}$）

**【詳細推導・解答プロセス】**
1. **万有引力定数と地表重力加速度の関係**：
   地球の質量を $M$ とすると、地表において：
   $$mg = G \frac{Mm}{R^2} \implies GM = gR^2$$
2. **人工衛星の運動方程式**：
   軌道半径は $r = 3R$ である。万有引力が向心力となるので：
   $$m \frac{v^2}{3R} = G \frac{Mm}{(3R)^2}$$
   整理すると：
   $$v^2 = \frac{GM}{3R}$$
3. **$GM = gR^2$ を代入**：
   $$v^2 = \frac{gR^2}{3R} = \frac{gR}{3} \implies v = \sqrt{\frac{gR}{3}}$$
したがって、選択肢 $\textcircled{2}$ が正しい。

## 問7：氷の融解・水の昇温・蒸発の熱量計算と所要時間

**【考査考点】**：状態変化に伴う潜熱（融解熱・蒸発熱）の計算 $Q = m L$, 昇温に必要な熱量 $Q = m c \Delta T$, 熱量保存と一定入力熱流率 $P = 300\text{ J/s}$

**【題目大意】**
$0^\circ\text{C}$ の氷 $10\text{ g}$ に毎秒 $300\text{ J}$ の熱を与え、$100^\circ\text{C}$ の水蒸気にするまでの時間を求めよ。
融解熱 $3.4 \times 10^2\text{ J/g}$、比熱 $4.2\text{ J/(g}\cdot\text{K)}$、蒸発熱 $2.3 \times 10^3\text{ J/g}$。

**【公式正解】**：$\textcircled{5}$（$1.0 \times 10^2\text{ s}$）

**【詳細推導・解答プロセス】**
質量 $m = 10\text{ g}$ に対し、3段階の熱量を合計する：
1. **$0^\circ\text{C}$ の氷から $0^\circ\text{C}$ の水への融解熱 $Q_1$**：
   $$Q_1 = m L_f = 10\text{ g} \times 3.4 \times 10^2\text{ J/g} = 3400\text{ J}$$
2. **$0^\circ\text{C}$ の水から $100^\circ\text{C}$ の水への昇温熱 $Q_2$**：
   $$Q_2 = m c \Delta T = 10\text{ g} \times 4.2\text{ J/(g}\cdot\text{K)} \times 100\text{ K} = 4200\text{ J}$$
3. **$100^\circ\text{C}$ の水から $100^\circ\text{C}$ の水蒸気への蒸発熱 $Q_3$**：
   $$Q_3 = m L_v = 10\text{ g} \times 2.3 \times 10^3\text{ J/g} = 23000\text{ J}$$
全熱量は：
$$Q = Q_1 + Q_2 + Q_3 = 3400 + 4200 + 23000 = 30600\text{ J}$$
毎秒 $300\text{ J}$ の熱を与えるので、所要時間 $t$ は：
$$t = \frac{Q}{P} = \frac{30600\text{ J}}{300\text{ J/s}} = 102\text{ s} \approx 1.0 \times 10^2\text{ s}$$
したがって、選択肢 $\textcircled{5}$ が正しい。

## 問8：定圧加熱から定積加熱への遷移・$T-t$ グラフの傾き変化

**【考査考点】**：定圧モル比熱 $C_p = \frac{5}{2}R$ と定積モル比熱 $C_v = \frac{3}{2}R$, 温度上昇率 $\frac{dT}{dt} = \frac{q}{n C}$ の比較, ストッパー到達後の傾きの急峻化

**【題目大意】**
断熱シリンダー内の単原子気体に一定出力ヒーターで熱を与え続ける。
時刻 $t = 0$ から $t_A$ まではピストンが自由に動き定圧膨張し、$t_A$ で位置 A に到達して静止（定積加熱に移行）。
温度 $T$ と時刻 $t$ の関係を示すグラフを選べ。

**【公式正解】**：$\textcircled{3}$（$t_A$ 以降の傾きが急になるグラフ）

**【詳細推導・解答プロセス】**
熱供給率を $q$（一定）とする。
1. **$0 \le t \le t_A$（定圧過程）**：
   大気圧一定でピストンがゆっくり動くため、圧力は一定である。
   単原子分子理想気体の定圧モル比熱は $C_p = \frac{5}{2}R$ である。
   $$q \, dt = n C_p \, dT \implies \frac{dT}{dt} = \frac{q}{n C_p} = \frac{2q}{5nR} \quad (\text{正の一定の傾き})$$
2. **$t > t_A$（定積過程）**：
   ピストンがストッパー A で固定されるため、体積が一定となる。
   定積モル比熱は $C_v = \frac{3}{2}R$ である。
   $$q \, dt = n C_v \, dT \implies \frac{dT}{dt} = \frac{q}{n C_v} = \frac{2q}{3nR}$$
3. **傾きの比較**：
   $$C_v < C_p \implies \frac{2q}{3nR} > \frac{2q}{5nR}$$
   したがって、$t_A$ を境にして $T-t$ 直線の傾きは **より急になる（折れ線状に傾きが増大する）**。
この特徴を正しく表したグラフは選択肢 $\textcircled{3}$ である。

## 問9：断熱圧縮と等温圧縮の比較・熱力学第一法則と $p-V$ 曲線

**【考査考点】**：熱力学第一法則 $\Delta U = Q + W$, 等温変化（$\Delta U = 0$）と熱量放出 $Q < 0$, 断熱変化（$Q = 0$）と温度上昇、断熱線の傾きと圧力高低

**【題目大意】**
同量の理想気体を体積 $V_1$ から $V_2$（$< V_1$）まで圧縮する。
シリンダーAは断熱圧縮、Bは等温圧縮である。表中の a, b, c の正負、および $V_2$ で圧力の低い曲線 $C_2$ に対応するシリンダー d を選べ。

**【公式正解】**：$\textcircled{6}$（a: 負, b: 正, c: 正, d: B）

**【詳細推導・解答プロセス】**
気体が外部からされた仕事を $W > 0$ とする。
1. **等温圧縮（シリンダーB）**：
   温度一定であるから内部エネルギー変化 $\Delta U = 0$。
   熱力学第一法則 $\Delta U = Q + W$ より：
   $$0 = Q + W \implies Q = -W < 0$$
   気体は外部へ放熱するため、$Q$（外部から受け取った熱量）は **負** である。$\implies \mathbf{a = \text{負}}$。
2. **断熱圧縮（シリンダーA）**：
   断熱であるから $Q = 0$。
   $$\Delta U = 0 + W = W > 0$$
   したがって内部エネルギーは増加する。$\implies \mathbf{b = \text{正}}$。
   単原子分子理想気体では $\Delta U = n C_v \Delta T$ であるから、$\Delta T > 0$（温度上昇）。$\implies \mathbf{c = \text{正}}$。
3. **$p-V$ 曲線と圧力の比較**：
   同一状態 $(V_1, p_1)$ から圧縮したとき、断熱圧縮では温度が上昇するため、等温圧縮よりも常に圧力が急激に高くなる（断熱線 $C_1$ の方が上）。
   したがって、体積 $V_2$ で圧力が低い曲線 $C_2$ は等温圧縮の **シリンダーB** に対応する。$\implies \mathbf{d = \text{B}}$。
以上より、(負, 正, 正, B) の組み合わせは選択肢 $\textcircled{6}$ である。

## 問10：進行波の波形グラフから特定位置の媒質の単振動式の導出

**【考査考点】**：波の波長 $\lambda$ と速さ $v$ から角周波数 $\omega$ の決定, 波の進行に伴う媒質の変位の時間変化の向き, 三角関数による単振動の表現 $y(t) = -A\sin(\omega t)$

**【題目大意】**

   $$f = \frac{v}{\lambda} = \frac{8\text{ m/s}}{2\text{ m}} = 4\text{ Hz}$$

3. **変位関数の立式**：
   $t = 0$ で $y = 0$ かつ初速度が負の単振動であるから：
   $$y(t) = -A \sin(\omega t) = -A \sin 8\pi t$$

BがAから受ける力を $F_0$、CがAとBから受ける合力の大きさを $F_1$ とするとき、比 $\frac{F_1}{F_0}$ を求めよ。

各電荷の電気量を $q$ とする。

     $$F_{CB} = k \frac{q^2}{(\sqrt{3}L)^2} = \frac{kq^2}{3L^2} = \frac{4}{3}F_0$$

したがって：
$$\frac{F_1}{F_0} = \frac{4\sqrt{10}}{3}$$
選択肢 $\textcircled{8}$ が正しい。

## 問15：抵抗網の分圧と節点電位の計算

**【考査考点】**：直並列合成抵抗の計算, オームの法則と分圧の法則, 基準電位（接地）からの節点電位の導出

## 問16：平行直線電流間に働くアンペール力の重ね合わせと方向決定

**【考査考点】**：同方向電流の吸引力と逆方向電流の反発力, 直線電流間のアンペール力 $F = \frac{\mu_0 I_1 I_2}{2\pi r}$, 直角二等辺三角形の幾何学的力ベクトル合成

**【題目大意】**
直角二等辺三角形 OPQ（$\angle O = 90^\circ, OP = OQ = d$）の頂点に3本の長い直線導線がある。
Oには表向き（手前向き）に $I$、Pには裏向き（奥向き）に $I$、Qには裏向き（奥向き）に $2I$ の電流が流れている。
導線 Q が受ける力の合力の向きを図2の矢印 (a)～(h) から選べ。

**【公式正解】**：$\textcircled{8}$（(h)）

**【詳細推導・解答プロセス】**
平行電流間に働く力の原則：
- 電流の向きが **同じ** $\implies$ **引き合う引力**
- 電流の向きが **逆** $\implies$ **退け合う斥力**
1. **導線 O の電流（表向き $I$）が導線 Q の電流（裏向き $2I$）に及ぼす力**：
   向きが逆であるため **斥力（遠ざかる向き）** となる。
   OからQへの向きは上向き（$+y$ 方向）であるため、斥力 $\vec{F}_{QO}$ は **真上向き（方向 (g)）** である。
   大きさは距離 $d$ より：$F_{QO} = \frac{\mu_0 (2I)(I)}{2\pi d} = \frac{\mu_0 I^2}{\pi d}$。
2. **導線 P の電流（裏向き $I$）が導線 Q の電流（裏向き $2I$）に及ぼす力**：
   向きが同じであるため **引力（近づく向き）** となる。
   QからPへの向きは右下 $45^\circ$ 方向（方向 (b)）であるため、引力 $\vec{F}_{QP}$ は **方向 (b)** を向く。
   QとPの距離は斜辺 $\sqrt{2}d$ であるから、大きさは：
   $$F_{QP} = \frac{\mu_0 (2I)(I)}{2\pi (\sqrt{2}d)} = \frac{1}{\sqrt{2}} \frac{\mu_0 I^2}{\pi d} = \frac{1}{\sqrt{2}} F_{QO}$$
3. **合力ベクトルの直交成分合成**：
   右向きを $x$ 軸（方向(a)）、上向きを $y$ 軸（方向(g)）とする：
   - $\vec{F}_{QO} = (0, F_{QO})$
   - $\vec{F}_{QP} = (F_{QP} \cos 45^\circ, -F_{QP} \sin 45^\circ) = \left(\frac{1}{\sqrt{2}}F_{QO} \cdot \frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}}F_{QO} \cdot \frac{1}{\sqrt{2}}\right) = \left(\frac{1}{2}F_{QO}, -\frac{1}{2}F_{QO}\right)$
   合力 $\vec{F} = \vec{F}_{QO} + \vec{F}_{QP}$ の成分は：
   $$F_x = \frac{1}{2}F_{QO} > 0, \quad F_y = F_{QO} - \frac{1}{2}F_{QO} = \frac{1}{2}F_{QO} > 0$$
   $F_x = F_y > 0$ であるため、合力の向きは右上 $45^\circ$、すなわち **矢印 (h)** である。
したがって、選択肢 $\textcircled{8}$ が正しい。

   $$2d \sin\theta = n \lambda \quad (n = 1, 2, 3, \dots)$$
2. **次数 $n$ の同定**：
   - $\theta$ を $0^\circ$ から大きくしていき「初めて」極大となった $\sin\theta_1 = 0.25$ は $n = 1$（1次回折）に対応する：
     $$2d \sin\theta_1 = 1 \cdot \lambda$$
   - 次に極大となった $\sin\theta_2 = 0.50$ は $n = 2$（2次回折）に対応する：
     $$2d \sin\theta_2 = 2 \cdot \lambda$$
   （実際、$\frac{\sin\theta_2}{\sin\theta_1} = \frac{0.50}{0.25} = 2$ であり、条件式と完全に整合する）
3. **格子面間隔 $d$ の計算**：
   $n = 1$ の式に数値を代入すると：
   $$2d \times 0.25 = 1.5 \times 10^{-10}\text{ m}$$
   $$0.50 \, d = 1.5 \times 10^{-10}\text{ m} \implies d = \frac{1.5 \times 10^{-10}}{0.50} = 3.0 \times 10^{-10}\text{ m}$$
したがって、格子面間隔は $3.0 \times 10^{-10}\text{ m}$（選択肢 $\textcircled{5}$）である。
