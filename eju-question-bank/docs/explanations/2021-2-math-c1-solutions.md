## 第I問 問1：2次関数の頂点・軸の場合分けと閉区間における最大値条件

**【考査考点】**：2次関数の平方完成 $f(x) = a(x-p)^2 + q$ と頂点の導出, 定義域 $1 \le x \le 4$ に対する対称軸 $x = a+1$ の位置による場合分け, 区間の端点および頂点における最大値方程式の解法

### 【第I問 問1】詳細解答と解説

#### 1. 平方完成と頂点座標の決定
与えられた2次関数は：
$$f(x) = -2x^2 + 4(a+1)x - a^2 - 5a$$
平方完成を行う：
$$f(x) = -2\left[x^2 - 2(a+1)x\right] - a^2 - 5a$$
$$= -2\left[(x - (a+1))^2 - (a+1)^2\right] - a^2 - 5a$$
$$= -2(x - (a+1))^2 + 2(a^2 + 2a + 1) - a^2 - 5a$$
$$= -2(x - (a+1))^2 + a^2 - a + 2$$
したがって、放物線 $y = f(x)$ の頂点の座標は：
$$\left(a + 1,\, a^2 - a + 2\right)$$
となり、$\mathbf{A = 1},\, \mathbf{B = 2}$ である。
また、対称軸の方程式は $x = a + 1$ である。

#### 2. 軸の位置による場合分けと最大値条件
放物線は上に凸（$x^2$ の係数が $-2 < 0$）であるから、閉区間 $1 \le x \le 4$ における最大値は軸の位置によって次のように場合分けされる。

**(i) 軸が定義域の左外側にある場合（$a+1 \le 1 \iff a \le 0$）：**
このとき $\mathbf{C = 0}$ である。
関数は区間 $1 \le x \le 4$ で単調減少するため、最大値は左端 $x = 1$ でとる。
$$f(1) = -2(1)^2 + 4(a+1)(1) - a^2 - 5a = -2 + 4a + 4 - a^2 - 5a = -a^2 - a + 2$$
条件より最大値が 2 であるから：
$$-a^2 - a + 2 = 2 \implies a^2 + a = 0 \implies a(a+1) = 0$$
よって $a = 0$ または $a = -1$。いずれも $a \le 0$ を満たす。
- $a = 0$ のとき：
  $$f(x) = -2x^2 + 4(0+1)x - 0 = -2x^2 + 4x$$
  よって $\mathbf{D = 4}$ である。
- $a = -1$ のとき：
  $$f(x) = -2x^2 + 4(0)x - (1 - 5) = -2x^2 + 4$$
  よって $\mathbf{E = 4}$ である。

**(ii) 軸が定義域の内部にある場合（$1 < a+1 \le 4 \iff 0 < a \le 3$）：**
このとき $\mathbf{F = 3}$ である。
最大値は頂点でとり、その値は頂点の $y$ 座標 $a^2 - a + 2$ である。
$$a^2 - a + 2 = 2 \implies a^2 - a = 0 \implies a(a-1) = 0$$
$0 < a \le 3$ より $a = 1$ である。
$a = 1$ を代入すると：
$$f(x) = -2x^2 + 4(2)x - (1 + 5) = -2x^2 + 8x - 6$$
よって、$\mathbf{G = 8},\, \mathbf{H = 6}$（解答番号 $\mathbf{GH = 86}$）である。

**(iii) 軸が定義域の右外側にある場合（$a+1 > 4 \iff a > 3$）：**
関数は区間 $1 \le x \le 4$ で単調増加するため、最大値は右端 $x = 4$ でとる。
$$f(4) = -2(4)^2 + 4(a+1)(4) - a^2 - 5a = -32 + 16a + 16 - a^2 - 5a = -a^2 + 11a - 16$$
条件より最大値が 2 であるから：
$$-a^2 + 11a - 16 = 2 \implies a^2 - 11a + 18 = 0$$
$$(a - 2)(a - 9) = 0$$
$a > 3$ であるから $a = 9$ と定まる。
$a = 9$ を代入すると：
$$4(a+1) = 4(10) = 40$$
$$-a^2 - 5a = -81 - 45 = -126$$
したがって、求める関数は：
$$f(x) = -2x^2 + 40x - 126$$
よって、$\mathbf{IJ = 40},\, \mathbf{KLM = 126}$（解答番号 $\mathbf{IJKLM = 40126}$）である。

## 第I問 問2：球と箱の順列・重複度と条件付き配置の場合の数

**【考査考点】**：異なる球の異なる箱への順列 $P(n, r)$, 同一箱に入る球の選択と箱の割当て, 奇数・偶数番号の箱への条件付き配置と積の法則

### 【第I問 問2】詳細解答と解説

赤・黄・緑・青の異なる4個の球と、1から7までの番号がついた7個の異なる箱がある。

#### (1) 4個の球を7個の箱に1個ずつ入れる入れ方
7個の異なる箱から4個を選び、4個の異なる球を順序をつけて対応させる順列である：
$$P(7, 4) = 7 \times 6 \times 5 \times 4 = 840$$
よって、$\mathbf{NOP = 840}$ 通りである。

#### (2) 4個のうち3個の球を同じ1つの箱に入れ、残りの1個を他の箱に入れる入れ方
1. 同じ箱に入る3個の球の選び方：$\binom{4}{3} = 4$ 通り。
2. その3個の球を入れる箱の選び方：7通り。
3. 残った1個の球を入れる箱の選び方：残りの6個の箱から1個選ぶので 6通り。
積の法則より：
$$4 \times 7 \times 6 = 168$$
よって、$\mathbf{QRS = 168}$ 通りである。

#### (3) 奇数番号箱と偶数番号箱への条件付き配置
1から7までの番号のうち：
- 奇数番号の箱：1, 3, 5, 7 の計4個。
- 偶数番号の箱：2, 4, 6 の計3個。

1. **赤色と黄色の球の入れ方**：
   赤と黄の2個の球を4個の奇数番号の箱に入れる。各球について4つの箱のいずれを選んでもよいため：
   $$4 \times 4 = 16$$
   よって、$\mathbf{TU = 16}$ 通り。
2. **緑色と青色の球の入れ方**：
   緑と青の2個の球を3個の偶数番号の箱に入れる。各球について3つの箱のいずれを選んでもよいため：
   $$3 \times 3 = 9$$
   よって、$\mathbf{V = 9}$ 通り。
3. **全体の入れ方**：
   積の法則により：
   $$16 \times 9 = 144$$
   よって、$\mathbf{WXY = 144}$ 通りである。

## 第II問 問1：分母の有理化・対称式の計算および高次多項式の値

**【考査考点】**：無理数の有理化と基本対称式 $x + \frac{1}{x}$ の計算, 分数式の相反的変形と対称式の応用, 2次関係式 $x^2 - 5x + 1 = 0$ を用いた高次式の因数分解と値の導出

### 【第II問 問1】詳細解答と解説

#### (1) 分母の有理化
$$x = \frac{2}{5 - \sqrt{21}}$$
分子・分母に共役な数 $5 + \sqrt{21}$ を掛ける：
$$x = \frac{2(5 + \sqrt{21})}{(5 - \sqrt{21})(5 + \sqrt{21})} = \frac{2(5 + \sqrt{21})}{25 - 21} = \frac{2(5 + \sqrt{21})}{4} = \frac{5 + \sqrt{21}}{2}$$
よって、$\mathbf{A = 5},\, \mathbf{B = 2}$（解答番号 $\mathbf{AB = 52}$）である。

#### (2) 基本対称式と分数式の値
$x$ の逆数 $\frac{1}{x}$ は：
$$\frac{1}{x} = \frac{5 - \sqrt{21}}{2}$$
したがって：
$$x + \frac{1}{x} = \frac{5 + \sqrt{21}}{2} + \frac{5 - \sqrt{21}}{2} = \frac{10}{2} = 5$$
よって、$\mathbf{C = 5}$ である。

また、平方の関係から：
$$x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2 = 5^2 - 2 = 23$$
与えられた分数式の分子・分母をともに $x^2$ で割る：
$$\frac{1 - x + x^2 - x^3 + x^4}{1 + x + x^2 + x^3 + x^4} = \frac{\left(x^2 + \frac{1}{x^2}\right) - \left(x + \frac{1}{x}\right) + 1}{\left(x^2 + \frac{1}{x^2}\right) + \left(x + \frac{1}{x}\right) + 1}$$
数値を代入すると：
$$= \frac{23 - 5 + 1}{23 + 5 + 1} = \frac{19}{29}$$
よって、$\mathbf{DE = 19},\, \mathbf{FG = 29}$（解答番号 $\mathbf{DEFG = 1929}$）である。

#### (3) 2次関係式と多項式の値
$x = \frac{5 + \sqrt{21}}{2} \implies 2x - 5 = \sqrt{21}$。
両辺を2乗すると：
$$4x^2 - 20x + 25 = 21 \implies 4x^2 - 20x + 4 = 0 \implies x^2 - 5x + 1 = 0$$
したがって：
$$x^2 - 5x = -1$$
よって、$\mathbf{HI = -1}$ である。

次に、与えられた6次多項式を因数分解して $x^2 - 5x$ を含むペアに組み替える：
$$P = (x^2 - 1)(x^2 - 7x + 12)(x^2 - 8x + 12)$$
各2次式を1次式に因数分解すると：
$$x^2 - 1 = (x - 1)(x + 1)$$
$$x^2 - 7x + 12 = (x - 3)(x - 4)$$
$$x^2 - 8x + 12 = (x - 2)(x - 6)$$
和が 5 になるように組み合わせる：
- $(x - 1)(x - 4) = x^2 - 5x + 4$
- $(x - 2)(x - 3) = x^2 - 5x + 6$
- $(x + 1)(x - 6) = x^2 - 5x - 6$
したがって：
$$P = (x^2 - 5x + 4)(x^2 - 5x + 6)(x^2 - 5x - 6)$$
$x^2 - 5x = -1$ を代入すると：
$$P = (-1 + 4)(-1 + 6)(-1 - 6) = 3 \times 5 \times (-7) = -105$$
題意は $-JKL$ であるから、$\mathbf{JKL = 105}$ である。

## 第II問 問2：パラメータを含む連立2次不等式の解と共通解の存在条件

**【考査考点】**：2次不等式の因数分解と解の表現, パラメータ $a$ の値による根の大小関係の分類, 連立不等式が共通解をもつための区間交差条件

### 【第II問 問2】詳細解答と解説

2つの関数：
$$f(x) = 2x^2 + (1 - 2a^2)x - a^2$$
$$g(x) = x^2 + (a + 1)x - 2a^2 + 5a - 2$$
に関する連立不等式 $f(x) < 0$ かつ $g(x) < 0$ を考える。

#### (1) 不等式 $f(x) < 0$ の解
$f(x)$ を因数分解する：
$$f(x) = 2x^2 - 2a^2 x + x - a^2 = 2x(x - a^2) + 1(x - a^2) = (2x + 1)(x - a^2)$$
方程式 $f(x) = 0$ の2根は $x = -\frac{1}{2}$ と $x = a^2$ である。
実数 $a$ に対し $a^2 \ge 0 > -\frac{1}{2}$ であるから、不等式 $f(x) < 0$ の解は常に：
$$-\frac{1}{2} < x < a^2$$
よって、$\mathbf{MNO = -12}$（$\frac{-1}{2} < x < a^2$）である。

#### (2) 不等式 $g(x) < 0$ の解と $a$ による場合分け
$g(x)$ の定数項を整理する：
$$-2a^2 + 5a - 2 = -(2a^2 - 5a + 2) = -(2a - 1)(a - 2) = (1 - 2a)(a - 2)$$
また、$(a - 2) + (1 - 2a) = -a - 1$ となり、$x$ の係数 $a+1$ と符号が逆転する。
したがって、$g(x)$ は次のように因数分解できる：
$$g(x) = (x - (a - 2))(x - (1 - 2a))$$
2根は $x_1 = a - 2$ と $x_2 = 1 - 2a$ である。
これらの大小を比較する：
$$(a - 2) - (1 - 2a) = 3a - 3 = 3(a - 1)$$
したがって、分岐点となる値は $a = 1$ であり、$\mathbf{P = 1}$ である。

- **$a < 1$ のとき**：$a - 2 < 1 - 2a$ であるから：
  $$a - 2 < x < -2a + 1$$
  これは選択肢 $\textcircled{6}$ に対応する。よって $\mathbf{Q = 6}$。
- **$a = 1$ のとき**：2根が一致し、$g(x) = (x + 1)^2$ となる。
  実数 $x$ に対し $(x+1)^2 < 0$ を満たす解は存在しない（解はない）。
  これは選択肢 $\textcircled{9}$ に対応する。よって $\mathbf{R = 9}$。
- **$a > 1$ のとき**：$1 - 2a < a - 2$ であるから：
  $$-2a + 1 < x < a - 2$$
  これは選択肢 $\textcircled{0}$ に対応する。よって $\mathbf{S = 0}$。

#### (3) 連立不等式が解をもつ $a$ の範囲
連立不等式が解をもつためには、区間 $\left(-\frac{1}{2}, a^2\right)$ と $g(x) < 0$ の解の区間が共通部分をもつ必要がある。

1. **$a < 1$ のとき**：
   $g(x) < 0$ の解は $a - 2 < x < -2a + 1$。
   共通部分をもつ条件は、左側の区間の下限が右側の区間の上限より小さく、かつ左側の区間の上限が右側の区間の下限より大きいことである。
   - 下限条件：$a - 2 < a^2 \iff a^2 - a + 2 > 0$（判別式 $D = 1 - 8 < 0$ より全ての実数 $a$ で常に成立）。
   - 上限条件：$-2a + 1 > -\frac{1}{2} \iff 2a < \frac{3}{2} \iff a < \frac{3}{4}$。
   $a < 1$ との共通範囲は $a < \frac{3}{4}$ である。
   よって、$\mathbf{TU = 34}$。

2. **$a > 1$ のとき**：
   $g(x) < 0$ の解は $-2a + 1 < x < a - 2$。
   共通部分をもつ条件は：
   - $a - 2 > -\frac{1}{2} \iff a > \frac{3}{2}$。
   - また、$-2a + 1 < a^2 \iff a^2 + 2a - 1 > 0$ であるが、$a > \frac{3}{2}$ では明らかに成立する。
   $a > 1$ との共通範囲は $a > \frac{3}{2}$ である。
   よって、$\mathbf{VW = 32}$。

以上より、求める範囲は $a < \frac{3}{4},\, a > \frac{3}{2}$ である。

## 第III問（前半）：素因数分解と最大公約数・最小公倍数による自然数の構造決定

**【考査考点】**：自然数 2520 の素因数分解, 2数ずつの最大公約数条件から各数の因数倍数条件の導出, 互いに素の条件に基づくパラメータ表示

### 【第III問 前半】詳細解答と解説

3つの自然数 $a, b, c$ の最小公倍数は 2520 であり、次の条件を満たす：
- (i) $\gcd(a, b) = 18 = 2 \times 3^2$
- (ii) $\gcd(b, c) = 30 = 2 \times 3 \times 5$
- (iii) $\gcd(c, a) = 24 = 2^3 \times 3$

#### 1. 2520 の素因数分解
$$2520 = 2^3 \times 3^2 \times 5 \times 7$$
問題文の形式 $2^A \cdot B^C \cdot 5 \cdot D$ に照らすと：
$$2^3 \cdot 3^2 \cdot 5 \cdot 7$$
よって、$\mathbf{A = 3},\, \mathbf{B = 3},\, \mathbf{C = 2},\, \mathbf{D = 7}$（解答番号 $\mathbf{ABCD = 3327}$）である。

#### 2. $a$ の因数構造の決定
条件 (i) より $a$ は 18 の倍数、条件 (iii) より $a$ は 24 の倍数である。
したがって、$a$ は $\operatorname{lcm}(18, 24) = 72 = 2^3 \times 3^2$ の倍数である。
よって、$\mathbf{EF = 72}$ である。

一方、$\gcd(b, c) = 30$ は素因数 5 を含むが、$\gcd(a, b) = 18$ および $\gcd(c, a) = 24$ はともに 5 を含まない。
よって、$a$ は 5 を素因数にもたず、$a$ と 5 は互いに素である。したがって $\mathbf{G = 5}$。
2520 の残る素因数は 7 であり、$a$ は 7 を因数にもつかもたないかのいずれかである：
$$a = 72m \quad (m = 1 \text{ または } m = 7)$$
よって、$\mathbf{H = 7}$ である。

#### 3. $b$ および $c$ の因数構造の決定
1. **$b$ について**：
   条件 (i) より $b$ は 18 の倍数、条件 (ii) より $b$ は 30 の倍数である。
   したがって、$b$ は $\operatorname{lcm}(18, 30) = 90 = 2 \times 3^2 \times 5$ の倍数である。
   よって、$\mathbf{IJ = 90}$ である。
   $b$ の素因数 2 の指数は $\gcd(a, b)=18$ より 1 で確定しており、$b$ がとりうる残りの素因数は 7 のみである：
   $$b = 90n \quad (n = 1 \text{ または } n = 7)$$
   よって、$\mathbf{K = 7}$ である。

2. **$c$ について**：
   条件 (ii) より $c$ は 30 の倍数、条件 (iii) より $c$ は 24 の倍数である。
   したがって、$c$ は $\operatorname{lcm}(30, 24) = 120 = 2^3 \times 3 \times 5$ の倍数である。
   よって、$\mathbf{LMN = 120}$ である。
   同様に $c$ がとりうる残りの素因数は 7 のみである：
   $$c = 120\ell \quad (\ell = 1 \text{ または } \ell = 7)$$
   よって、$\mathbf{O = 7}$ である。

## 第III問（後半）：組の総数の決定と大小関係を満たす自然数組の特定

**【考査考点】**：最小公倍数の素因数 7 の分配と組の総数, 大小関係 $a < b < c$ に基づく解の組の一意決定

### 【第III問 後半】詳細解答と解説

#### 1. 条件を満たす組 $(a, b, c)$ の総数
前半で得られた表現は：
$$a = 72m,\quad b = 90n,\quad c = 120\ell \quad (m, n, \ell \in \{1, 7\})$$
3数の最小公倍数が 2520 であるためには、素因数 7 が $a, b, c$ の少なくとも1つに含まれなければならない。
一方で、条件 (i) $\gcd(a, b) = 18$、(ii) $\gcd(b, c) = 30$、(iii) $\gcd(c, a) = 24$ はいずれも 7 で割り切れない。
したがって、2数以上が同時に 7 を因数にもつことはできない。
ゆえに、$m, n, \ell$ のうち**ちょうど1つだけが 7 で、残り2つは 1** でなければならない。
この組み合わせは：
$$(m, n, \ell) \in \{(7, 1, 1), (1, 7, 1), (1, 1, 7)\}$$
の全部で **3組** である。
よって、$\mathbf{P = 3}$ である。

#### 2. 大小関係 $a < b < c$ を満たす組の決定
各場合における $(a, b, c)$ の値を計算する：
1. $(m, n, \ell) = (7, 1, 1)$ のとき：
   $$a = 72 \times 7 = 504,\quad b = 90,\quad c = 120$$
   $a > b$ となり不適。
2. $(m, n, \ell) = (1, 7, 1)$ のとき：
   $$a = 72,\quad b = 90 \times 7 = 630,\quad c = 120$$
   $b > c$ となり不適。
3. $(m, n, \ell) = (1, 1, 7)$ のとき：
   $$a = 72 \times 1 = 72$$
   $$b = 90 \times 1 = 90$$
   $$c = 120 \times 7 = 840$$
   このとき $72 < 90 < 840$ であり、$a < b < c$ を満たす。

したがって、求める組は：
$$(a, b, c) = (72, 90, 840)$$
よって、$\mathbf{QR = 72},\, \mathbf{ST = 90},\, \mathbf{UVW = 840}$ である。

## 第IV問（前半）：三角形の面積・余弦定理と外接円の半径

**【考査考点】**：三角形の面積公式 $S = \frac{1}{2}ab\sin C$, 余弦定理による対辺長の算出, 正弦定理による外接円の半径の導出

### 【第IV問 前半】詳細解答と解説

$\triangle \text{ABC}$ において、$\text{AB} = 2,\, \text{AC} = \sqrt{2},\, \angle \text{BAC} = 135^\circ$ である。

#### 1. 三角形 ABC の面積
三角形の面積公式より：
$$S = \frac{1}{2} \times \text{AB} \times \text{AC} \times \sin 135^\circ = \frac{1}{2} \times 2 \times \sqrt{2} \times \frac{\sqrt{2}}{2} = 1$$
よって、三角形 ABC の面積は $\mathbf{A = 1}$ である。

#### 2. 辺 BC の長さと外接円の半径
余弦定理より：
$$\text{BC}^2 = \text{AB}^2 + \text{AC}^2 - 2 \times \text{AB} \times \text{AC} \times \cos 135^\circ$$
$$= 2^2 + (\sqrt{2})^2 - 2 \times 2 \times \sqrt{2} \times \left(-\frac{\sqrt{2}}{2}\right)$$
$$= 4 + 2 + 4 = 10$$
したがって、$\text{BC} = \sqrt{10}$ である。
よって、$\mathbf{BC = 10}$ である。

外接円の半径を $R$ とすると、正弦定理より：
$$\frac{\text{BC}}{\sin 135^\circ} = 2R \implies 2R = \frac{\sqrt{10}}{\frac{\sqrt{2}}{2}} = 2\sqrt{5} \implies R = \sqrt{5}$$
よって、外接円の半径は $\sqrt{D}$ より $\mathbf{D = 5}$ である。

## 第IV問（後半）：角の3等分線・三角比と分割された各三角形の面積

**【考査考点】**：正弦定理による $\sin\theta, \tan\theta$ の導出, 直角三角形における線分比の決定, 角の二等分線定理と高さ共通の三角形の面積比

### 【第IV問 後半】詳細解答と解説

#### 1. $\angle ABC = \theta$ の三角比と線分 AE の長さ
$\angle \text{BAC} = 135^\circ$ の3等分線を引くと：
$$\angle \text{BAD} = \angle \text{DAE} = \angle \text{EAC} = 45^\circ$$
したがって：
$$\angle \text{BAE} = \angle \text{BAD} + \angle \text{DAE} = 45^\circ + 45^\circ = 90^\circ$$
すなわち $\triangle \text{ABE}$ は $\angle \text{BAE} = 90^\circ$ の直角三角形である。

$\triangle \text{ABC}$ において正弦定理を適用すると：
$$\frac{\text{AC}}{\sin\theta} = 2R = 2\sqrt{5} \implies \sin\theta = \frac{\sqrt{2}}{2\sqrt{5}} = \frac{1}{\sqrt{10}} = \frac{\sqrt{10}}{10}$$
よって、$\mathbf{FG = 10},\, \mathbf{HI = 10}$（解答番号 $\mathbf{FGHI = 1010}$）である。

$\theta$ は鋭角であるから：
$$\cos\theta = \sqrt{1 - \sin^2\theta} = \sqrt{1 - \frac{1}{10}} = \frac{3}{\sqrt{10}}$$
したがって：
$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{1/\sqrt{10}}{3/\sqrt{10}} = \frac{1}{3}$$
よって、$\mathbf{JK = 13}$（$\frac{1}{3}$）である。

直角三角形 ABE において、$\text{AE} = \text{AB} \tan\theta = 2 \tan\theta$ であるから（$\mathbf{E = 2}$）：
$$\text{AE} = 2 \times \frac{1}{3} = \frac{2}{3}$$
よって、$\mathbf{LM = 23}$（$\frac{2}{3}$）である。

#### 2. 各三角形の面積比と面積の決定
直角三角形 ABE の面積は：
$$\triangle \text{ABE} = \frac{1}{2} \times \text{AB} \times \text{AE} = \frac{1}{2} \times 2 \times \frac{2}{3} = \frac{2}{3}$$
よって、$\mathbf{PQ = 23}$（$\frac{2}{3}$）である。

線分 AD は $\angle \text{BAE} = 90^\circ$ の二等分線（$\angle \text{BAD} = \angle \text{DAE} = 45^\circ$）であるから、角の二等分線定理より：
$$\text{BD} : \text{DE} = \text{AB} : \text{AE} = 2 : \frac{2}{3} = 3 : 1$$
$\triangle \text{ABD}$ と $\triangle \text{ADE}$ は頂点 A を共有し底辺が直線 BE 上にあるため、面積比は底辺の比に等しい：
$$\frac{\triangle \text{ADE}}{\triangle \text{ABD}} = \frac{\text{DE}}{\text{BD}} = \frac{1}{3}$$
よって、$\mathbf{NO = 13}$（$\frac{1}{3}$）である。

したがって：
$$\triangle \text{ABD} = \frac{3}{3 + 1} \triangle \text{ABE} = \frac{3}{4} \times \frac{2}{3} = \frac{1}{2}$$
よって、$\mathbf{RS = 12}$（$\frac{1}{2}$）である。

$$\triangle \text{ADE} = \frac{1}{3 + 1} \triangle \text{ABE} = \frac{1}{4} \times \frac{2}{3} = \frac{1}{6}$$
よって、$\mathbf{TU = 16}$（$\frac{1}{6}$）である。

最後に、全体の面積 $\triangle \text{ABC} = 1$ より：
$$\triangle \text{AEC} = \triangle \text{ABC} - \triangle \text{ABE} = 1 - \frac{2}{3} = \frac{1}{3}$$
よって、$\mathbf{VW = 13}$（$\frac{1}{3}$）である。
