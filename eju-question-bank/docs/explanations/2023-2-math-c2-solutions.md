## 第I問 問1：2次関数の平行移動と定義域における最大値

**【考查考点】**：2次関数の頂点・平方完成, グラフの平行移動, 動く軸と固定された定義域における最大値の分類討議

### 【第I問 問1】詳細解答と解説

#### (1) 放物線の頂点座標
与えられた2次関数は $f(x) = -x^2 + 4x + 5$。
平方完成を行うと：
$$f(x) = -(x^2 - 4x) + 5 = -((x - 2)^2 - 4) + 5 = -(x - 2)^2 + 9$$
したがって、放物線 $y = f(x)$ の頂点の座標は **$(2, 9)$** である。
よって、$\mathbf{A = 2, B = 9}$（解答番号 $\mathbf{AB = 29}$）。

#### (2) 平行移動後の放物線
放物線 $y = f(x)$ を $x$ 軸方向に $k$、$y$ 軸方向に $-4$ だけ平行移動した放物線を $y = g(x)$ とする。
頂点の移動に着目すると、元の頂点 $(2, 9)$ は $(2 + k, 9 - 4) = (k + 2, 5)$ に移る。
2次の係数は変わらず $-1$ のままであるから：
$$g(x) = -(x - (2 + k))^2 + 5 = -(x - 2 - k)^2 + 5$$
問題文の形式 $g(x) = -(x - \text{C} - k)^2 + \text{D}$ と比較して：
$$\mathbf{C = 2, D = 5}$$（解答番号 $\mathbf{CD = 25}$）。

#### (3) 定義域 $-1 \le x \le 4$ における最大値が 3 となる $k$ の条件
放物線 $y = g(x)$ は上に凸で、頂点の $y$ 座標は $5$、軸の方程式は $x = k + 2$ である。
もし軸 $x = k + 2$ が定義域 $[-1, 4]$ の内部（$-1 \le k + 2 \le 4 \iff -3 \le k \le 2$）にあれば、最大値は頂点の $y$ 座標 $5$ となり、条件「最大値が 3」を満たさない。
したがって、最大値が 3 となるためには、軸が定義域の外側になければならず、端点で最大値 3 をとる。

**Case 1: 軸が定義域の左側にある場合（$k + 2 < -1 \iff k < -3$）**
このとき、$-1 \le x \le 4$ において $g(x)$ は単調減少するので、最大値は左端 $x = -1$ でとる。
$$g(-1) = -(-1 - 2 - k)^2 + 5 = -(k + 3)^2 + 5 = 3$$
$$-(k + 3)^2 = -2 \implies (k + 3)^2 = 2 \implies k^2 + 6k + 9 = 2 \implies k^2 + 6k + 7 = 0$$
二次方程式を解くと $k = -3 \pm \sqrt{2}$。
$k < -3$ より、適するのは $k = -3 - \sqrt{2}$ である。
この条件は選択肢 $\textcircled{3}$「$k < -3$ かつ $k^2 + 6k + 7 = 0$」に一致する。
よって、$\mathbf{E = 3}$。
また、$k = -\text{G} - \sqrt{\text{H}}$ より $\mathbf{G = 3, H = 2}$（解答番号 $\mathbf{GH = 32}$）。

**Case 2: 軸が定義域の右側にある場合（$k + 2 > 4 \iff k > 2$）**
このとき、$-1 \le x \le 4$ において $g(x)$ は単調増加するので、最大値は右端 $x = 4$ でとる。
$$g(4) = -(4 - 2 - k)^2 + 5 = -(2 - k)^2 + 5 = -(k - 2)^2 + 5 = 3$$
$$-(k - 2)^2 = -2 \implies (k - 2)^2 = 2 \implies k^2 - 4k + 4 = 2 \implies k^2 - 4k + 2 = 0$$
二次方程式を解くと $k = 2 \pm \sqrt{2}$。
$k > 2$ より、適するのは $k = 2 + \sqrt{2}$ である。
この条件は選択肢 $\textcircled{7}$「$k > 2$ かつ $k^2 - 4k + 2 = 0$」に一致する。
よって、$\mathbf{F = 7}$。
また、$k = \text{I} + \sqrt{\text{J}}$ より $\mathbf{I = 2, J = 2}$（解答番号 $\mathbf{IJ = 22}$）。

**【解法テクニック・易錯点】**
- 放物線の軸の位置（$k+2$）が定義域の内側にあるか外側にあるかを即座に見抜くことがポイントです。頂点最大値が 5 であるため、3 に下がるには必ず軸が区間外に外れなければなりません。

## 第I問 問2：正多面体（正四面体・立方体）の面の塗り分けと対称性

**【考查考点】**：組み合わせ（Combination）, 円順列・空間回転群（3次元回転対称性）, 二面体群による面の同値類

### 【第I問 問2】詳細解答と解説

#### (1) 正四面体の各面の塗り分け（6色から4色）
相異なる 6 色から使用する 4 色を選ぶ組み合わせの数は：
$$\binom{6}{4} = \binom{6}{2} = \frac{6 \times 5}{2 \times 1} = 15 \text{ 通り}$$
よって、$\mathbf{KL = 15}$。

選ばれた 4 色（例えば赤、青、黄、緑）を用いて正四面体の 4 面を塗る場合：
回転させて重なるものを同一視するため、まず「赤」で塗る面を底面に固定して空間の向きを固定する。
残りの 3 面（側面 3 つ）は、底面の上から見て円周上に並ぶため、残りの 3 色による円順列の数となる：
$$(3 - 1)! = 2! = 2 \text{ 通り}$$
よって、$\mathbf{M = 2}$。

したがって、6 色から 4 面を塗るすべての方法は：
$$15 \times 2 = 30 \text{ 通り}$$
よって、$\mathbf{NO = 30}$。

#### (2) 立方体の各面の塗り分け
**(i) 6 色すべてを使って塗る方法**
立方体には 6 つの面がある。
回転による同値性を除くため、基準となる 1 色（例えば色 1）をある面（上面）に固定する。
次に、その対面（底面）に塗る色を残り 5 色から選ぶため、$5$ 通りある。
残った 4 つの側面を残り 4 色で塗るが、上面・底面を結ぶ軸のまわりの回転（4 回回転対称）により同値となるため、4 色の円順列となる：
$$(4 - 1)! = 3! = 6 \text{ 通り}$$
したがって、求める塗り方の総数は：
$$5 \times 6 = 30 \text{ 通り}$$
よって、$\mathbf{PQ = 30}$。

**(ii) 紫を除いた 5 色をすべて使って塗る方法（隣接面は異色）**
立方体の 6 面を 5 色で塗るため、鳩の巣原理より必ず 1 色が 2 面に塗られる。
「隣り合った面の色が異なる」という制約から、同一色で塗られる 2 つの面は必ず「向かい合う面（対面）」でなければならない。
立方体には向かい合う面のペアが 3 組ある。
1. まず、5 色の中から対面に塗る「重複する 1 色」を選ぶ：$\binom{5}{1} = 5$ 通り。
2. その色を塗る対面（上面・底面）に固定する。
3. 残りの 4 面（側面環）を、残り 4 色で 1 面ずつ塗る。
ここで、空間の回転対称性を慎重に考える：
- 上面・底面を結ぶ軸まわりの回転により 4 つの側面は円順列となり、$(4 - 1)! = 6$ 通りある。
- さらに、上面と底面は「同じ色」で塗られているため、側面の中央を通る水平軸まわりの 180° 反転（立方体の空間回転）によって上面と底面が入れ替わっても同じ塗り方とみなされる。
- 側面環の順序を反転させる対称変換（裏返し）が空間の剛体回転として存在するため、対面が同色の場合は円順列 6 通りのうち鏡映反転ペア同士が同一視され、実質的な配置数は：
$$\frac{(4 - 1)!}{2} = \frac{6}{2} = 3 \text{ 通り}$$
したがって、求める総数は：
$$5 \times 3 = 15 \text{ 通り}$$
よって、$\mathbf{RS = 15}$。

**【解法テクニック・易錯点】**
- (ii) では上面と底面が同色であるため、立方体の「裏返し回転（180° flip）」が作用することを見落として $5 \times 6 = 30$ としてしまう受験生が非常に多い典型的な罠問題です。必ず面が同色であることによる付加的な対称性を除算してください。

## 第II問 問1：長方形内のベクトル演算・直交条件と内積・余弦の決定

**【考查考点】**：平面ベクトルの線分比と内分点公式, 直交条件（内積＝0）による未知数の決定, ベクトルの内積と成す角の余弦（cos θ）

### 【第II問 問1】詳細解答と解説

#### (1) 線分比 $AG : GC$ とベクトル $\overrightarrow{BG}$ の表現
長方形 $ABCD$ において、$\overrightarrow{AB} = \vec{a}, \overrightarrow{AD} = \vec{b}$ とする。
長方形であるから $\vec{a} \perp \vec{b}$、すなわち $\vec{a} \cdot \vec{b} = 0$ である。
また、$BC = |\vec{b}| = \sqrt{3}$ である。
点 $E$ は辺 $AB$ を $1:5$ に内分するので：
$$\overrightarrow{AE} = \frac{1}{6}\vec{a}$$
点 $F$ は辺 $CD$ を $1:2$ に内分する。
$C$ の位置ベクトルは $\vec{a} + \vec{b}$、$D$ の位置ベクトルは $\vec{b}$ であるから：
$$\overrightarrow{AF} = \overrightarrow{AC} + \frac{1}{3}(\overrightarrow{AD} - \overrightarrow{AC}) = (\vec{a} + \vec{b}) + \frac{1}{3}(\vec{b} - (\vec{a} + \vec{b})) = \frac{2}{3}\vec{a} + \vec{b}$$

点 $G$ は対角線 $AC$ と線分 $EF$ の交点である。
$G$ は $AC$ 上にあるので、実数 $k$ を用いて $\overrightarrow{AG} = k\overrightarrow{AC} = k(\vec{a} + \vec{b})$ と表せる。
また、$G$ は線分 $EF$ 上にあるので、実数 $s$ を用いて：
$$\overrightarrow{AG} = (1 - s)\overrightarrow{AE} + s\overrightarrow{AF} = (1 - s)\left(\frac{1}{6}\vec{a}\right) + s\left(\frac{2}{3}\vec{a} + \vec{b}\right) = \left(\frac{1}{6} + \frac{1}{2}s\right)\vec{a} + s\vec{b}$$
$\vec{a}$ と $\vec{b}$ は 1 次独立であるから、各成分を比較して：
$$s = k, \quad k = \frac{1}{6} + \frac{1}{2}k \implies \frac{1}{2}k = \frac{1}{6} \implies k = \frac{1}{3}$$
したがって、$\overrightarrow{AG} = \frac{1}{3}\overrightarrow{AC}$ であるから：
$$AG : GC = 1 : 2$$
よって、$\mathbf{A = 1, B = 2}$（解答番号 $\mathbf{AB = 12}$）。

これより、$\overrightarrow{BG}$ を $\vec{a}, \vec{b}$ で表すと：
$$\overrightarrow{BG} = \overrightarrow{AG} - \overrightarrow{AB} = \frac{1}{3}(\vec{a} + \vec{b}) - \vec{a} = \frac{1}{3}(-2\vec{a} + \vec{b})$$
選択肢の形式と比較すると、$\textcircled{1}$「$\frac{1}{3}(-2\vec{a} + \vec{b})$」に一致する。
よって、$\mathbf{C = 1}$。

#### (2) 直交条件と辺 $AB$ の長さ
線分 $BG$ と $AC$ は直交しているため：
$$\overrightarrow{BG} \cdot \overrightarrow{AC} = 0$$
よって、$\mathbf{D = 0}$。

この内積を計算すると：
$$\overrightarrow{BG} \cdot \overrightarrow{AC} = \frac{1}{3}(-2\vec{a} + \vec{b}) \cdot (\vec{a} + \vec{b}) = \frac{1}{3}\left(-2|\vec{a}|^2 + |\vec{b}|^2 - \vec{a} \cdot \vec{b}\right)$$
$\vec{a} \cdot \vec{b} = 0$ かつ $|\vec{b}| = \sqrt{3} \implies |\vec{b}|^2 = 3$ であるから：
$$\frac{1}{3}\left(-2|\vec{a}|^2 + 3\right) = 0 \implies 2|\vec{a}|^2 = 3 \implies |\vec{a}|^2 = \frac{3}{2}$$
したがって、$AB = |\vec{a}| = \sqrt{\frac{3}{2}} = \frac{\sqrt{6}}{2}$ である。
問題文の形式 $AB = \frac{\sqrt{\text{E}}}{\text{F}}$ より：
$$\mathbf{E = 6, F = 2} \implies \mathbf{EF = 62}$$

#### (3) $\overrightarrow{GC}, \overrightarrow{GF}$ の表示と $\cos \angle CGF$ の決定
点 $G$ は $AC$ を $1:2$ に内分するので：
$$\overrightarrow{GC} = \frac{2}{3}\overrightarrow{AC} = \frac{2}{3}(\vec{a} + \vec{b})$$
選択肢 $\textcircled{9}$「$\frac{2}{3}(\vec{a} + \vec{b})$」より、$\mathbf{G = 9}$。

また、$\overrightarrow{GF} = \overrightarrow{AF} - \overrightarrow{AG}$ より：
$$\overrightarrow{GF} = \left(\frac{2}{3}\vec{a} + \vec{b}\right) - \frac{1}{3}(\vec{a} + \vec{b}) = \frac{1}{3}\vec{a} + \frac{2}{3}\vec{b} = \frac{1}{3}(\vec{a} + 2\vec{b})$$
選択肢 $\textcircled{0}$「$\frac{1}{3}(\vec{a} + 2\vec{b})$」より、$\mathbf{H = 0}$。

内積 $\overrightarrow{GC} \cdot \overrightarrow{GF}$ を計算する：
$$\overrightarrow{GC} \cdot \overrightarrow{GF} = \frac{2}{3}(\vec{a} + \vec{b}) \cdot \frac{1}{3}(\vec{a} + 2\vec{b}) = \frac{2}{9}\left(|\vec{a}|^2 + 2|\vec{b}|^2 + 3\vec{a} \cdot \vec{b}\right)$$
$|\vec{a}|^2 = \frac{3}{2}, |\vec{b}|^2 = 3, \vec{a} \cdot \vec{b} = 0$ を代入すると：
$$\overrightarrow{GC} \cdot \overrightarrow{GF} = \frac{2}{9}\left(\frac{3}{2} + 6\right) = \frac{2}{9} \times \frac{15}{2} = \frac{5}{3}$$
問題文の形式 $\frac{\text{I}}{\text{J}}$ より：
$$\mathbf{I = 5, J = 3} \implies \mathbf{IJ = 53}$$

各ベクトルの大きさを計算する：
$$|\overrightarrow{GC}|^2 = \frac{4}{9}(|\vec{a}|^2 + |\vec{b}|^2) = \frac{4}{9}\left(\frac{3}{2} + 3\right) = \frac{4}{9} \times \frac{9}{2} = 2 \implies |\overrightarrow{GC}| = \sqrt{2}$$
$$|\overrightarrow{GF}|^2 = \frac{1}{9}(|\vec{a}|^2 + 4|\vec{b}|^2) = \frac{1}{9}\left(\frac{3}{2} + 12\right) = \frac{1}{9} \times \frac{27}{2} = \frac{3}{2} \implies |\overrightarrow{GF}| = \sqrt{\frac{3}{2}}$$
したがって：
$$\cos \theta = \frac{\overrightarrow{GC} \cdot \overrightarrow{GF}}{|\overrightarrow{GC}| |\overrightarrow{GF}|} = \frac{\frac{5}{3}}{\sqrt{2} \times \sqrt{\frac{3}{2}}} = \frac{\frac{5}{3}}{\sqrt{3}} = \frac{5}{3\sqrt{3}} = \frac{5\sqrt{3}}{9}$$
問題文の形式 $\frac{\text{K}\sqrt{\text{L}}}{\text{M}}$ より：
$$\mathbf{K = 5, L = 3, M = 9} \implies \mathbf{KLM = 539}$$

## 第II問 問2：円の方程式・直線に関する線対称変換・点と直線の距離と接線

**【考查考点】**：円の標準形と中心・半径, 直線に関する点の対称移動（垂直条件と中点条件）, 点と直線の距離公式による円の接する条件

### 【第II問 問2】詳細解答と解説

#### (1) 円 $C$ の中心と半径
与えられた円の方程式は：
$$C: x^2 + y^2 - 4x - 2y + 5 - r^2 = 0$$
平方完成を行うと：
$$(x^2 - 4x + 4) + (y^2 - 2y + 1) - 4 - 1 + 5 - r^2 = 0$$
$$(x - 2)^2 + (y - 1)^2 = r^2$$
したがって、円 $C$ の中心は **$(2, 1)$**、半径は $r$ である。
よって、$\mathbf{N = 2, O = 1} \implies \mathbf{NO = 21}$。

#### (2) 直線 $\ell$ に関して対称な円 $C'$ の中心座標
円 $C'$ は円 $C$ を直線 $\ell: y = 2x - 1 \iff 2x - y - 1 = 0$ に関して対称移動した円である。
円 $C$ の中心 $(2, 1)$ の直線 $\ell$ に関する対称点を $(a, b)$ とする。
1. **垂直条件**：中心を結ぶ直線の傾きは $\ell$ の傾き $2$ と直交するため $-\frac{1}{2}$ である：
   $$\frac{b - 1}{a - 2} = -\frac{1}{2} \implies 2(b - 1) = -(a - 2) \implies a + 2b - 4 = 0$$
2. **中点条件**：線分の中点 $\left(\frac{a + 2}{2}, \frac{b + 1}{2}\right)$ が直線 $\ell$ 上にある：
   $$2\left(\frac{a + 2}{2}\right) - \left(\frac{b + 1}{2}\right) - 1 = 0$$
   $$2(a + 2) - (b + 1) - 2 = 0 \implies 2a - b + 1 = 0 \implies b = 2a + 1$$
垂直条件の式に代入すると：
$$a + 2(2a + 1) - 4 = 0 \implies 5a - 2 = 0 \implies a = \frac{2}{5}$$
$$b = 2\left(\frac{2}{5}\right) + 1 = \frac{9}{5}$$
したがって、対称円 $C'$ の中心は $\left(\frac{2}{5}, \frac{9}{5}\right)$ である。
問題文の形式 $a = \frac{\text{P}}{\text{Q}}, b = \frac{\text{R}}{\text{S}}$ より：
$$\mathbf{P = 2, Q = 5, R = 9, S = 5} \implies \mathbf{PQ = 25, RS = 95}$$

#### (3) 円 $C'$ が直線 $m$ に接する条件と半径 $r$
直線 $m$ の方程式は $y = \frac{3}{4}x - 1 \iff 3x - 4y - 4 = 0$ である。
対称移動しても円の半径は不変であるから、$C'$ の半径も $r$ である。
円 $C'$ が直線 $m$ に接するとき、中心 $(a, b)$ と直線 $m$ との距離が半径 $r$ に等しい：
$$r = \frac{|3a - 4b - 4|}{\sqrt{3^2 + (-4)^2}} = \frac{|3a - 4b - 4|}{\sqrt{25}} = \frac{|3a - 4b - 4|}{5}$$
問題文の形式 $\frac{|\text{T}a - \text{U}b - \text{V}|}{\text{W}}$ と比較して：
$$\mathbf{T = 3, U = 4, V = 4, W = 5} \implies \mathbf{TUVW = 3445}$$

求めた $a = \frac{2}{5}, b = \frac{9}{5}$ を代入すると：
$$3a - 4b - 4 = 3\left(\frac{2}{5}\right) - 4\left(\frac{9}{5}\right) - 4 = \frac{6 - 36 - 20}{5} = \frac{-50}{5} = -10$$
したがって：
$$r = \frac{|-10|}{5} = \frac{10}{5} = 2$$
よって、$\mathbf{X = 2}$。

## 第III問：3次関数の接線の方程式・共有点・平行接線・面積

**【考查考点】**：3次関数の微分係数と接線の方程式, 3次方程式の重解と因数定理（共有点の決定）, 放物線・3次曲線と接線が囲む面積公式（1/12公式）

### 【第III問】詳細解答と解説

#### (1) 任意の点における接線と点 $A$ における接線 $l$
関数 $f(x) = x^3 - 4x^2 + 1$ に対し、導関数は：
$$f'(x) = 3x^2 - 8x$$
点 $(t, f(t))$ における接線の傾きは $f'(t) = 3t^2 - 8t$ である。
問題文の形式 $Ct^2 - Dt$ より：
$$\mathbf{C = 3, D = 8} \implies \mathbf{CD = 38}$$

接線の方程式は：
$$y - f(t) = f'(t)(x - t) \implies y = (3t^2 - 8t)x - t(3t^2 - 8t) + (t^3 - 4t^2 + 1)$$
$$y = (3t^2 - 8t)x - 2t^3 + 4t^2 + 1$$
したがって、$y$ 切片は $-2t^3 + 4t^2 + 1$ である。
問題文の形式 $-Et^3 + Ft^2 + G$ より：
$$\mathbf{E = 2, F = 4, G = 1} \implies \mathbf{EFG = 241}$$

点 $A(1, a)$ は $C$ 上の点であるから、$a = f(1) = 1 - 4 + 1 = -2$ である。
接線 $l$ は $t = 1$ における接線であるから：
傾き: $3(1)^2 - 8(1) = -5$
$y$ 切片: $-2(1)^3 + 4(1)^2 + 1 = 3$
したがって、接線 $l$ の方程式は：
$$y = -5x + 3$$
問題文の形式 $y = HI x + J$ より：
$$\mathbf{HI = -5, J = 3} \implies \mathbf{HIJ = -53}$$

#### (2) $C$ と $l$ の共有点 $B$
曲線 $C$ と直線 $l$ の共有点の $x$ 座標は連立方程式を満たす：
$$x^3 - 4x^2 + 1 = -5x + 3 \iff x^3 - 4x^2 + 5x - 2 = 0$$
$x = 1$ で接することから、左辺は必ず $(x - 1)^2$ を因数にもつ：
$$x^3 - 4x^2 + 5x - 2 = (x - 1)^2 (x - 2) = 0$$
したがって、$A$ と異なる共有点 $B$ の $x$ 座標は $x = 2$ である。
$y$ 座標は $l$ に代入して $y = -5(2) + 3 = -7$。
よって、点 $B$ の座標は **$(2, -7)$** である。
問題文の形式 $\boxed{K, LM}$ より：
$$\mathbf{K = 2, LM = -7} \implies \mathbf{KLM = 2-7}$$

#### (3) $l$ に平行な接線 $m$
直線 $m$ は $l$ と平行であるから、傾きが $-5$ で接点の $x$ 座標を $t$ とすると：
$$3t^2 - 8t = -5 \iff 3t^2 - 8t + 5 = 0 \iff (t - 1)(3t - 5) = 0$$
$l$ とは異なる接線であるから $t \neq 1$ より：
$$t = \frac{5}{3}$$
問題文の形式 $\frac{\text{N}}{\text{O}}$ より：
$$\mathbf{N = 5, O = 3} \implies \mathbf{NO = 53}$$

$m$ の $y$ 切片は、$t = \frac{5}{3}$ を切片の式 $-2t^3 + 4t^2 + 1$ に代入して：
$$-2\left(\frac{5}{3}\right)^3 + 4\left(\frac{5}{3}\right)^2 + 1 = -2\left(\frac{125}{27}\right) + 4\left(\frac{25}{9}\right) + 1 = -\frac{250}{27} + \frac{300}{27} + \frac{27}{27} = \frac{77}{27}$$
したがって、直線 $m$ の方程式は $y = -5x + \frac{77}{27}$ である。
問題文の形式 $y = HI x + \frac{\text{PQ}}{\text{RS}}$ より：
$$\mathbf{PQ = 77, RS = 27} \implies \mathbf{PQRS = 7727}$$

#### (4) $y$ 切片が $l$ と同じ（切片が 3）である他の 2 本の接線
接線の $y$ 切片が 3 となる接点の $x$ 座標 $t$ の方程式は：
$$-2t^3 + 4t^2 + 1 = 3 \iff 2t^3 - 4t^2 + 2 = 0 \iff t^3 - 2t^2 + 1 = 0$$
$l$ の接点 $t = 1$ が解であるから $(t - 1)$ で因数分解できる：
$$(t - 1)(t^2 - t - 1) = 0$$
他の 2 接点は $t^2 - t - 1 = 0$ の 2 根である：
$$t = \frac{1 \pm \sqrt{1^2 - 4(1)(-1)}}{2} = \frac{1 \pm \sqrt{5}}{2}$$
問題文の形式 $\frac{\text{T} - \sqrt{\text{U}}}{\text{V}}$ と $\frac{\text{T} + \sqrt{\text{U}}}{\text{V}}$ より：
$$\mathbf{T = 1, U = 5, V = 2} \implies \mathbf{TUV = 152}$$

#### (5) $C$ と $l$ で囲まれた部分の面積
区間 $[1, 2]$ において、直線 $l$ は曲線 $C$ の上側にある。
囲まれた部分の面積 $S$ は：
$$S = \int_1^2 \left[(-5x + 3) - (x^3 - 4x^2 + 1)\right] dx = \int_1^2 -(x - 1)^2 (x - 2) \, dx$$
ここで $x - 1 = u$ と置換すると、$dx = du$、積分区間は $0 \le u \le 1$ となり：
$$S = \int_0^1 -u^2 (u - 1) \, du = \int_0^1 (u^2 - u^3) \, du = \left[\frac{u^3}{3} - \frac{u^4}{4}\right]_0^1 = \frac{1}{3} - \frac{1}{4} = \frac{1}{12}$$
問題文の形式 $\frac{\text{W}}{\text{XY}}$ より：
$$\mathbf{W = 1, XY = 12} \implies \mathbf{WXY = 112}$$

**【解法テクニック・面積の 1/12 公式】**
- 3次曲線と接線が囲む面積は、接点 $\alpha$、交点 $\beta$ と最高次の係数 $a$ を用いて $S = \frac{|a|}{12}(\beta - \alpha)^4$ で瞬時に計算可能です。本問では $a = 1, \alpha = 1, \beta = 2$ であるから $S = \frac{1}{12}(2 - 1)^4 = \frac{1}{12}$ と一瞬で検算できます。

## 第IV問：絶対値付き指数関数の定積分・微分と増減表・最小値の決定

**【考查考点】**：絶対値を含む関数の場合分け, 積分区間と折れ曲がり点の相対位置による関数の区分, 微分積分の基本定理による導関数の計算と増減・極小値

### 【第IV問】詳細解答と解説

#### (1) 絶対値の解除と場合分けの基準
被積分関数は $|e^x - 2|$ である。
$e^x - 2 = 0 \iff e^x = 2 \iff x = \log 2$ であるから：
$$|e^x - 2| = \begin{cases} e^x - 2 & (x \ge \log 2) \\ 2 - e^x & (x \le \log 2) \end{cases}$$
問題文の形式より、$\mathbf{A = 2}$。

積分区間は $[a, a + 1]$ であり、その区間幅は 1 である。
折れ曲がり点 $x = \log 2$ と区間 $[a, a + 1]$ の位置関係により、以下の 3 つの場合に分けられる：
- (i) $a + 1 \le \log 2 \iff a \le \log 2 - 1$（区間全体が $\log 2$ の左側）
- (ii) $a \le \log 2 \le a + 1 \iff \log 2 - 1 \le a \le \log 2$（区間内に $\log 2$ を含む）
- (iii) $a \ge \log 2$（区間全体が $\log 2$ の右側）

#### (2) 各区間における関数の表示と導関数

**(i) $a < \log 2 - 1$ のとき**
区間内のすべての $x$ で $e^x - 2 \le 0$ であるから、被積分関数は $2 - e^x$ である。
問題文の形式 $\log \text{B} - \text{C}$ より：$\mathbf{B = 2, C = 1} \implies \mathbf{BC = 21}$。

$$f(a) = \int_a^{a+1} (2 - e^x) \, dx = \left[2x - e^x\right]_a^{a+1} = \{2(a + 1) - e^{a+1}\} - (2a - e^a) = 2 - e^a(e - 1) = 2 + e^a(1 - e)$$
問題文の形式 $D + e^a(E - e)$ より：$\mathbf{D = 2, E = 1} \implies \mathbf{DE = 21}$。

$a$ で微分すると：
$$f'(a) = e^a(1 - e)$$
問題文の形式 $e^a(F - e)$ より：$\mathbf{F = 1}$。
$e \approx 2.718 > 1$ より $1 - e < 0$、かつ $e^a > 0$ であるから、$f'(a) < 0$ が恒等的に成り立つ。
したがって、$f(a)$ は **単調減少** である。
選択肢 $\textcircled{1}$「減少」より、$\mathbf{G = 1}$。

**(ii) $\log 2 - 1 \le a < \log 2$ のとき**
区間内に折れ曲がり点 $x = \log 2$ を含むため、積分を 2 つに分割する：
$$f(a) = \int_a^{\log 2} (2 - e^x) \, dx + \int_{\log 2}^{a+1} (e^x - 2) \, dx$$
各部分を計算すると：
$$\int_a^{\log 2} (2 - e^x) \, dx = \left[2x - e^x\right]_a^{\log 2} = (2\log 2 - 2) - (2a - e^a) = 2\log 2 - 2 - 2a + e^a$$
$$\int_{\log 2}^{a+1} (e^x - 2) \, dx = \left[e^x - 2x\right]_{\log 2}^{a+1} = \{e^{a+1} - 2(a + 1)\} - (2 - 2\log 2) = e \cdot e^a - 2a - 4 + 2\log 2$$
両者を足し合わせると：
$$f(a) = 4\log 2 - 6 - 4a + e^a(e + 1)$$
問題文の形式 $H\log 2 - I - Ja + e^a(e + K)$ と比較して：
$$\mathbf{H = 4, I = 6, J = 4, K = 1} \implies \mathbf{HIJK = 4641}$$

$a$ で微分すると：
$$f'(a) = -4 + e^a(e + 1)$$
問題文の形式 $-L + e^a(e + M)$ より：$\mathbf{L = 4, M = 1} \implies \mathbf{LM = 41}$。

$f'(a) = 0$ となる $a$ を求めると：
$$e^a(e + 1) = 4 \iff e^a = \frac{4}{e + 1} \iff a = \log \frac{4}{e + 1}$$
問題文の形式 $\log \frac{\text{N}}{e + \text{O}}$ より：$\mathbf{N = 4, O = 1} \implies \mathbf{NO = 41}$。

ここで $\frac{4}{e + 1}$ の値の範囲を確認すると、$2 < e < 3$ より $3 < e + 1 < 4$ であるから：
$$1 < \frac{4}{e + 1} < \frac{4}{3} < 2$$
よって $0 < \log \frac{4}{e + 1} < \log 2$ であり、区間 $[\log 2 - 1, \log 2]$ に確かに属する。
増減を調べると：
- $\log 2 - 1 \le a < \log \frac{4}{e + 1}$ においては $e^a(e + 1) < 4$ より $f'(a) < 0$ となり、$f(a)$ は **減少**（選択肢 $\textcircled{1}$、$\mathbf{P = 1}$）。
- $\log \frac{4}{e + 1} < a < \log 2$ においては $e^a(e + 1) > 4$ より $f'(a) > 0$ となり、$f(a)$ は **増加**（選択肢 $\textcircled{0}$、$\mathbf{Q = 0}$）。

**(iii) $a \ge \log 2$ のとき**
区間内のすべての $x$ で $e^x - 2 \ge 0$ であるから、被積分関数は $e^x - 2$ である。
$$f(a) = \int_a^{a+1} (e^x - 2) \, dx = \left[e^x - 2x\right]_a^{a+1} = \{e^{a+1} - 2(a + 1)\} - (e^a - 2a) = e^a(e - 1) - 2$$
問題文の形式 $e^a(e - R) - S$ より：$\mathbf{R = 1, S = 2} \implies \mathbf{RS = 12}$。

$a$ で微分すると：
$$f'(a) = e^a(e - 1)$$
問題文の形式 $e^a(e - T)$ より：$\mathbf{T = 1}$。
$e - 1 > 0$ かつ $e^a > 0$ であるから、$f'(a) > 0$ が恒等的に成り立つ。
したがって、$f(a)$ は **単調増加** である。
選択肢 $\textcircled{0}$「増加」より、$\mathbf{U = 0}$。

#### (3) 最小値をとる $a$ の決定
以上の (i), (ii), (iii) の増減を統合すると：
- $a < \log \frac{4}{e + 1}$ では $f(a)$ は単調減少。
- $a > \log \frac{4}{e + 1}$ では $f(a)$ は単調増加。
したがって、$f(a)$ は $a = \log \frac{4}{e + 1}$ において全体で最小値をとる。
問題文の形式 $\log \frac{\text{V}}{e + \text{W}}$ より：
$$\mathbf{V = 4, W = 1} \implies \mathbf{VW = 41}$$

**【解法テクニック・易錯点】**
- 区間が動く積分関数では、折れ曲がり点 $x_0 = \log 2$ が積分の「左端の左側」「区間の内部」「右端の右側」のどこにあるかを境界値 $a = \log 2 - 1, \log 2$ で几帳面に分類するのが基本です。導関数の符号変化から極値が区間 (ii) の内部に存在することが鮮やかに導かれます。
