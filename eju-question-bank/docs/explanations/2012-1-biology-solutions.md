## 生物 問3：植物細胞の浸透圧と吸水

これらの条件に合致する組み合わせは $\textcircled{1}$。

## 生物 問12(1)：光発芽種子（レタス）のフィトクロム反応

**【題目大意】**
レタスの種子に赤色光（R）と遠赤色光（FR）を交互に照射した結果から，発芽の制御機構を分析する。

**【公式正解】**
正解：$\textcircled{7}$

**【詳細推導・解答プロセス】**
フィトクロムには Pr 型と Pfr 型がある。赤色光（R）で Pr → Pfr に変換され，Pfr が発芽を促進する。遠赤色光（FR）で Pfr → Pr に変換され，発芽が抑制される。最後に照射した光が赤色光なら発芽し，遠赤色光なら発芽しない。

実験結果をこの理論に基づいて分析すると $\textcircled{7}$ が正解。

**【考査考点】**
フィトクロム，光発芽種子，赤色光と遠赤色光の可逆反応。

## 生物 問14：筋収縮とATP・クレアチンリン酸

**【題目大意】**
骨格筋の長時間収縮時にATPの量は変化しないがクレアチンリン酸は減少する。ATP とクレアチンリン酸の使われ方を説明する。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
筋収縮のエネルギーは ATP の加水分解（ATP → ADP + Pi）により供給される。
クレアチンリン酸は ADP を ATP に再生する（クレアチンリン酸 + ADP → クレアチン + ATP）。
このため ATP 量は一定に保たれるが，クレアチンリン酸は消費されて減少する。
この説明に合致するのは $\textcircled{3}$。

**【考査考点】**
筋収縮のエネルギー代謝，ATP，クレアチンリン酸。
