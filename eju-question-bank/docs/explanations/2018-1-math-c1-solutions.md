## 第1問 [1]：2次関数の頂点・判別式・解の存在範囲

**【考査考点】**：平方完成による2次関数の頂点座標の決定, 判別式 $D > 0$ による $x$ 軸との交点条件, 区間 $[0, 6]$ 内に2解をもつ条件（端点値・軸・判別式）

**【題目大意】**
$a$ を実数とし、2次関数 $f(x) = \frac{1}{4} x^2 - (2a - 1)x + a$ について考える。
(1) $y = f(x)$ のグラフの頂点の座標を求めよ。
(2) グラフと $x$ 軸が異なる 2 点 A, B で交わるような $a$ の値の範囲を求めよ。
(3) 2 点 A, B の $x$ 座標がともに $0 \le x \le 6$ となる $a$ の値の範囲を求めよ。

**【公式正解】**
- $\text{AB} = 42$（頂点 $x$ 座標：$4a - 2$）
- $\text{CDE} = 451$（頂点 $y$ 座標：$-4a^2 + 5a - 1$）
- $\text{FG} = 14$, $\text{H} = 1$（$a < \frac{1}{4}, 1 < a$）
- $\text{I} = 1$, $\text{JKLM} = 1511$（$1 < a \le \frac{15}{11}$）

**【詳細推導・解答プロセス】**
1. **(1) 頂点座標の算出（平方完成）**：
   $$f(x) = \frac{1}{4}\left[ x^2 - 4(2a - 1)x \right] + a$$
   $$f(x) = \frac{1}{4}\left[ x - 2(2a - 1) \right]^2 - \frac{1}{4}\left[ 2(2a - 1) \right]^2 + a$$
   $$f(x) = \frac{1}{4}\left[ x - (4a - 2) \right]^2 - (4a^2 - 4a + 1) + a$$
   $$f(x) = \frac{1}{4}\left[ x - (4a - 2) \right]^2 - 4a^2 + 5a - 1$$
   したがって、頂点の座標は：
   $$(4a - 2, -4a^2 + 5a - 1)$$
   よって、$\text{AB} = 42$, $\text{CDE} = 451$ である。

2. **(2) $x$ 軸と異なる 2 点で交わる条件**：
   頂点の $y$ 座標が負（下に凸の放物線）：
   $$-4a^2 + 5a - 1 < 0 \iff 4a^2 - 5a + 1 > 0$$
   因数分解すると：
   $$(4a - 1)(a - 1) > 0$$
   したがって、求める $a$ の範囲は：
   $$a < \frac{1}{4}, \quad 1 < a$$
   よって、$\text{FG} = 14$, $\text{H} = 1$ である。

3. **(3) 2 解がともに $0 \le x \le 6$ に存在する条件**：
   $f(x) = 0$ の 2 解が $0 \le x \le 6$ にあるための条件は次の 4 点である：
   - **判別式**：$D > 0 \implies a < \frac{1}{4}$ または $a > 1$
   - **軸の位置**：$0 \le 4a - 2 \le 6 \implies 2 \le 4a \le 8 \implies \frac{1}{2} \le a \le 2$
   - **端点 $x = 0$ での値**：$f(0) \ge 0 \implies a \ge 0$
   - **端点 $x = 6$ での値**：
     $$f(6) = \frac{1}{4}(36) - 6(2a - 1) + a = 9 - 12a + 6 + a = 15 - 11a \ge 0 \implies a \le \frac{15}{11}$$
   これらの共通範囲を求めると：
   $$\left(a < \frac{1}{4} \text{ または } a > 1\right) \land \left(\frac{1}{2} \le a \le 2\right) \land (a \ge 0) \land \left(a \le \frac{15}{11}\right)$$
   $\frac{1}{2} \le a$ と $a < \frac{1}{4}$ に共通部分はないため、$a > 1$ の側を採用する：
   $$1 < a \le \frac{15}{11}$$
   よって、$\text{I} = 1$, $\text{JKLM} = 1511$ である。

## 第1問 [2]：重複順列・色の塗り分けの場合の数

**【考査考点】**：重複順列 $4^4$, 全単射（順列）$4!$, 同じものを含む順列と包除原理

**【題目大意】**
大きさの異なる 4 枚のカードに赤、黒、青、黄の 4 色を塗る。
(1) 全部の塗り方の総数を求めよ。
(2) 4 色すべてを使う塗り方の数を求めよ。
(3) 2 枚が赤、1 枚が黒、1 枚が青となる塗り方の数を求めよ。
(4) ちょうど 3 色を使う塗り方の数を求めよ。
(5) ちょうど 2 色を使う塗り方の数を求めよ。

**【公式正解】**
- $\text{NOP} = 256$
- $\text{QR} = 24$
- $\text{ST} = 12$
- $\text{UVW} = 144$
- $\text{XY} = 84$

**【詳細推導・解答プロセス】**
4 枚のカードは区別できる（大きさが異なる）。
1. **(1) 全部の塗り方**：
   各カードにつき 4 通りの色の選び方がある：
   $$4^4 = 256$$
   よって、$\text{NOP} = 256$ である。

2. **(2) 全部の色を使う塗り方**：
   4 枚の異なるカードに異なる 4 色を 1 枚ずつ割り当てる：
   $$4! = 4 \times 3 \times 2 \times 1 = 24$$
   よって、$\text{QR} = 24$ である。

3. **(3) 赤 2 枚、黒 1 枚、青 1 枚**：
   同じものを含む順列：
   $$\frac{4!}{2! 1! 1!} = \frac{24}{2} = 12$$
   よって、$\text{ST} = 12$ である。

4. **(4) ちょうど 3 色を使う塗り方**：
   - 4 色から使用する 3 色を選ぶ組み合わせ：$\binom{4}{3} = 4$ 通り。
   - 選んだ 3 色で 4 枚のカードを塗る際、枚数の内訳は必ず「2枚、1枚、1枚」となる。
   - 2 枚塗る色の選び方：$\binom{3}{1} = 3$ 通り。
   - 4 枚のカードへの塗り分け：$\frac{4!}{2! 1! 1!} = 12$ 通り。
   したがって：
   $$4 \times (3 \times 12) = 4 \times 36 = 144$$
   よって、$\text{UVW} = 144$ である。

5. **(5) ちょうど 2 色を使う塗り方**：
   - 4 色から使用する 2 色を選ぶ組み合わせ：$\binom{4}{2} = 6$ 通り。
   - 2 色だけで塗る総数は $2^4 = 16$ 通りであるが、1 色のみを使う 2 通りを除外する：
     $$2^4 - 2 = 14$$
   - したがって：
     $$6 \times 14 = 84$$
   よって、$\text{XY} = 84$ である。

## 第2問 [1]：3次方程式と対称式を用いた実数の導出

**【考査考点】**：対称式の変形 $a^3 + b^3 = (a+b)^3 - 3ab(a+b)$, 3次方程式 $x^3 - 3x - 18 = 0$ の因数分解, 2次方程式の解の公式による $a$ の決定

**【題目大意】**
$a^3 = 9 + \sqrt{80}$ を満たす正の数 $a$ を求めるため、$b^3 = 9 - \sqrt{80}$ を追加して考える。
$a^3 + b^3 = \text{AB}$, $ab = \text{C}$ から $a+b = x$ とおき、3次方程式を解いて $a$ の値を求めよ。

**【公式正解】**
- $\text{AB} = 18$
- $\text{C} = 1$
- $\text{D} = 3$, $\text{E} = 3$
- $\text{FGH} = 336$（$(x - 3)(x^2 + 3x + 6) = 0$）
- $\text{I} = 3$
- $\text{JKL} = 352$（$a = \frac{3 + \sqrt{5}}{2}$）

**【詳細推導・解答プロセス】**
1. **基本対称式の計算**：
   - 和：$a^3 + b^3 = (9 + \sqrt{80}) + (9 - \sqrt{80}) = 18$
   - 積：$a^3 b^3 = (9 + \sqrt{80})(9 - \sqrt{80}) = 81 - 80 = 1$
     $a, b > 0$ であるから、$ab = 1$
   よって、$\text{AB} = 18$, $\text{C} = 1$ である。

2. **$a+b = x$ による変形**：
   $$a^3 + b^3 = (a+b)^3 - 3ab(a+b) = 18$$
   $ab = 1$ より：
   $$(a+b)^3 - 3(a+b) = 18 \implies x^3 - 3x = 18$$
   よって、$D = 3$ である。
   この式を変形すると：
   $$x^3 - 27 = 3(x - 3)$$
   よって、$E = 3$ である。

3. **因数分解と実数解の決定**：
   $$x^3 - 27 - 3(x - 3) = 0$$
   $$(x - 3)(x^2 + 3x + 9) - 3(x - 3) = 0$$
   $$(x - 3)(x^2 + 3x + 6) = 0$$
   よって、$\text{F} = 3$, $\text{G} = 3$, $\text{H} = 6$ である。
   ここで $x^2 + 3x + 6 = \left(x + \frac{3}{2}\right)^2 + \frac{15}{4} > 0$ であるため実数解をもたない。
   したがって、実数解は $x = 3$ のみである：
   $$a + b = 3$$
   よって、$\text{I} = 3$ である。

4. **$a$ の値の決定**：
   $a+b = 3$ かつ $ab = 1$ より、$a, b$ は 2 次方程式 $t^2 - 3t + 1 = 0$ の 2 解である。
   解の公式より：
   $$t = \frac{3 \pm \sqrt{9 - 4}}{2} = \frac{3 \pm \sqrt{5}}{2}$$
   $a > b$ であるから：
   $$a = \frac{3 + \sqrt{5}}{2}$$
   よって、$\text{JKL} = 352$ である。

## 第2問 [2]：共通解・重解・2次不等式が常に成り立つ条件

**【考査考点】**：係数比較による方程式の解の一致条件, 2次方程式の重解条件（判別式 $D = 0$）, すべての実数 $x$ で $f(x) < g(x)$ が成り立つ条件（最高次係数と判別式）

**【題目大意】**
$a \neq 0$ とし、$f(x) = x^2 + 2ax - 4a - 12$、$g(x) = ax^2 + 2x - 4a + 4$ とする。
(1) $f(x) = 0$ と $g(x) = 0$ の解が一致するときの $a$ とその解を求めよ。
(2) $g(x) = 0$ が重解をもつときの $a$ とその解を求めよ。
(3) すべての実数 $x$ に対して $f(x) < g(x)$ が成り立つ $a$ の範囲を求めよ。

**【公式正解】**
- $\text{MN} = -1$
- $\text{OP} = -2$, $\text{Q} = 4$
- $\text{RS} = 12$（$a = \frac{1}{2}$）
- $\text{TU} = -2$（重解 $x = -2$）
- $\text{V} = 1$, $\text{WX} = 17$（$1 \le a < 17$ または $1 < a < 17$）

**【詳細推導・解答プロセス】**
1. **(1) 解が一致する条件**：
   $f(x) = 0$ と $g(x) = 0$ の解が一致するとき、係数の比が等しい：
   $$\frac{a}{1} = \frac{2}{2a} = \frac{-4a + 4}{-4a - 12}$$
   まず第1・第2項より：
   $$a = \frac{1}{a} \implies a^2 = 1 \implies a = \pm 1$$
   - $a = 1$ のとき：第3項は $\frac{0}{-16} = 0 \neq 1$（不適）。
   - $a = -1$ のとき：第3項は $\frac{8}{-8} = -1$（適する）。
   したがって、$a = -1$ である（$\text{MN} = -1$）。
   このときの方程式は $x^2 - 2x - 8 = 0 \implies (x + 2)(x - 4) = 0$
   解は $x = -2, 4$ である（$\text{OP} = -2$, $\text{Q} = 4$）。

2. **(2) $g(x) = 0$ が重解をもつ条件**：
   $g(x) = ax^2 + 2x - 4a + 4 = 0$（$a \neq 0$）の判別式：
   $$D/4 = 1^2 - a(-4a + 4) = 4a^2 - 4a + 1 = (2a - 1)^2$$
   重解をもつ条件は $D/4 = 0 \implies 2a - 1 = 0 \implies a = \frac{1}{2}$（$\text{RS} = 12$）。
   このときの重解は：
   $$x = -\frac{b'}{a} = -\frac{1}{1/2} = -2$$
   よって、$\text{TU} = -2$ である。

3. **(3) すべての $x$ に対して $f(x) < g(x)$ が成り立つ条件**：
   $$g(x) - f(x) > 0 \iff (a - 1)x^2 + 2(1 - a)x + 16 > 0$$
   これがすべての実数 $x$ で成り立つためには：
   - $x^2$ の係数が正：$a - 1 > 0 \implies a > 1$
   - 2次方程式 $(a - 1)x^2 + 2(1 - a)x + 16 = 0$ の判別式が負：
     $$D'/4 = (1 - a)^2 - 16(a - 1) = (a - 1)^2 - 16(a - 1) = (a - 1)(a - 1 - 16) = (a - 1)(a - 17) < 0$$
     $a > 1$ より $a - 1 > 0$ であるから、両辺を $a - 1$ で割ると：
     $$a - 17 < 0 \implies a < 17$$
   したがって、$1 < a < 17$ である。
   よって、$\text{V} = 1$, $\text{WX} = 17$ である。

## 第3問 [1]：整数の合同式・余りと倍数の個数

**【考査考点】**：連続3整数の積 $n(n-1)(n+1)$ の倍数性, 2と3の倍数による6の倍数の証明, 素因数11の倍数の個数カウント

**【題目大意】**
$n$ は 2 桁の自然数（$10 \le n \le 99$）で、$n^3$ を 66 で割った余りが $n$ である。
商を $p$ として $n^3 = \text{AB}p + n$ より $n(n-1)(n+1) = \text{AB}p$ を得る。
$n(n-1)(n+1)$ が $G$ の倍数であることを示し、$HI = 11$ の倍数となる個数を分類せよ。

**【公式正解】**
- $\text{AB} = 66$
- $\text{CD} = 65$
- $\text{E} = 2$, $\text{F} = 3$, $\text{G} = 6$
- $\text{HI} = 11$
- $\text{J} = 5$, $\text{K} = 5$, $\text{L} = 6$

**【詳細推導・解答プロセス】**
1. **条件の立式**：
   $n^3$ を 66 で割った余りが $n$ であるから：
   $$n^3 = 66p + n \iff n^3 - n = 66p \iff n(n-1)(n+1) = 66p$$
   割る数が 66 であるため、余り $n$ の満たすべき条件は $0 < n \le 65$（$\text{CD} = 65$）である。
   よって、$\text{AB} = 66$, $\text{CD} = 65$ である。

2. **連続整数の倍数性**：
   - 連続する 2 整数 $n-1, n$ の一方は必ず 2 の倍数である（$E = 2$）。
   - 連続する 3 整数 $n-1, n, n+1$ のうち 1 つは必ず 3 の倍数である（$F = 3$）。
   - 2 と 3 は互いに素であるから、$n(n-1)(n+1)$ は常に $2 \times 3 = 6$ の倍数である（$G = 6$）。
   したがって、$66 = 6 \times 11$ より、$n(n-1)(n+1)$ が 66 の倍数となるためには、$n-1, n, n+1$ のいずれか 1 つが **11 の倍数** であればよい（$\text{HI} = 11$）。

3. **各因数が 11 の倍数となる $n$ の個数（$10 \le n \le 65$）**：
   - **$n-1$ が 11 の倍数のとき**：
     $n-1 = 11, 22, 33, 44, 55 \implies n = 12, 23, 34, 45, 56$（計 **5 個**、$\text{J} = 5$）。
   - **$n$ が 11 の倍数のとき**：
     $n = 11, 22, 33, 44, 55$（計 **5 個**、$\text{K} = 5$）。
   - **$n+1$ が 11 の倍数のとき**：
     $n+1 = 11, 22, 33, 44, 55, 66 \implies n = 10, 21, 32, 43, 54, 65$（計 **6 個**、$\text{L} = 6$）。
   よって、$\text{J} = 5, \text{K} = 5, \text{L} = 6$ である。

## 第3問 [2]：条件を満たす自然数と素数の決定

**【考査考点】**：倍数の個数の集計, 求めた解の集合から素数の抽出（11, 23, 43）

**【題目大意】**
前問で求めた条件を満たす 2 桁の自然数 $n$ の総数 $MN$ と、そのうち素数であるものを小さい順に求めよ。

**【公式正解】**
- $\text{MN} = 16$
- $\text{OP} = 11$
- $\text{QR} = 23$
- $\text{ST} = 43$

**【詳細推導・解答プロセス】**
1. **$n$ の総数の集計**：
   3 つのグループの $n$ をすべて列挙する：
   - $n-1$ が 11 の倍数：$12, 23, 34, 45, 56$（5 個）
   - $n$ が 11 の倍数：$11, 22, 33, 44, 55$（5 個）
   - $n+1$ が 11 の倍数：$10, 21, 32, 43, 54, 65$（6 個）
   これら 3 群の元は互いに重複しない（差が 1 または 2 であるため）。
   したがって、求める $n$ の総数は：
   $$5 + 5 + 6 = 16$$
   よって、$\text{MN} = 16$ である。

2. **素数である $n$ の選定**：
   該当する 16 個の数を小さい順に並べると：
   $$10, \mathbf{11}, 12, 21, 22, \mathbf{23}, 32, 33, 34, \mathbf{43}, 44, 45, 54, 55, 56, 65$$
   このうち素数であるものを判定する：
   - $10$：合成数
   - **$11$**：**素数**（$\text{OP} = 11$）
   - $12$：合成数
   - $21 = 3 \times 7$：合成数
   - $22$：合成数
   - **$23$**：**素数**（$\text{QR} = 23$）
   - $32, 33, 34$：合成数
   - **$43$**：**素数**（$\text{ST} = 43$）
   - $44, 45, 54, 55, 56, 65$：合成数
   したがって、素数である $n$ は小さい順に **11, 23, 43** である。
よって、$\text{OP} = 11$, $\text{QR} = 23$, $\text{ST} = 43$ である。

## 第4問 [1]：三角形の正弦定理と外接円の半径

**【考査考点】**：正弦定理 $\frac{b}{\sin B} = \frac{c}{\sin C} = 2R$, 外接円の半径公式

**【題目大意】**
$\triangle\text{ABC}$ において $AB = 4, AC = 3, \angle B = 30^\circ$ である。
辺 BC 上に $AC = AD$ となる点 D をとり、$\triangle\text{ACD}$ の外接円 O を考える。
(1) $\sin B, \sin C$ を求め、円 O の半径を求めよ。

**【公式正解】**
- $\text{AB} = 12$（$\sin B = \frac{1}{2}$）
- $\text{CD} = 23$（$\sin C = \frac{2}{3}$）
- $\text{EF} = 94$（外接円の半径 $R = \frac{9}{4}$）

**【詳細推導・解答プロセス】**
1. **$\sin B$ と $\sin C$ の算出**：
   $\angle B = 30^\circ$ であるから：
   $$\sin B = \sin 30^\circ = \frac{1}{2}$$
   よって、$\text{AB} = 12$ である。
   $\triangle\text{ABC}$ において正弦定理を適用する：
   $$\frac{AC}{\sin B} = \frac{AB}{\sin C}$$
   各値を代入すると：
   $$\frac{3}{1/2} = \frac{4}{\sin C} \implies 6 = \frac{4}{\sin C} \implies \sin C = \frac{4}{6} = \frac{2}{3}$$
   よって、$\text{CD} = 23$ である。

2. **外接円 O の半径の算出**：
   点 D は辺 BC 上にあり、$AC = AD$ であるから、$\triangle\text{ACD}$ は $AC = AD = 3$ の二等辺三角形である。
   $\triangle\text{ACD}$ の外接円 O の半径を $R$ とすると、正弦定理より：
   $$2R = \frac{AD}{\sin C} = \frac{3}{2/3} = \frac{9}{2} \implies R = \frac{9}{4}$$
   よって、$\text{EF} = 94$ である。

## 第4問 [2]：余弦定理・方べきの定理と面積比の計算

**【考査考点】**：余弦定理による辺長 $BC, BD$ の導出, 方べきの定理による $BE$ の決定, 高さ共通の三角形の面積比と三角比による面積比

**【題目大意】**
辺 BC, BD の長さを求めよ。
辺 AB と円 O の交点を E とするとき、BE の長さを求め、面積比 $\triangle\text{BDE} : \triangle\text{ADE}$ および $\triangle\text{BDE} : \triangle\text{ACD}$ を求めよ。

**【公式正解】**
- $\text{GHI} = 235$（$BC = 2\sqrt{3} + \sqrt{5}$）
- $\text{JKL} = 235$（$BD = 2\sqrt{3} - \sqrt{5}$）
- $\text{MN} = 74$（$BE = \frac{7}{4}$）
- $\text{OP} = 79$（$\triangle\text{BDE} : \triangle\text{ADE} = 7 : 9$）
- $\text{QRST} = 7325$（$\triangle\text{BDE} : \triangle\text{ACD} = 7(2\sqrt{3} - \sqrt{5}) : 32\sqrt{5}$）

**【詳細推導・解答プロセス】**
1. **辺 BC の長さの算出**：
   $\triangle\text{ABC}$ において余弦定理を適用する。$BC = x$ とおくと：
   $$AC^2 = AB^2 + BC^2 - 2 AB \cdot BC \cos 30^\circ$$
   $$3^2 = 4^2 + x^2 - 2 \times 4 \times x \times \frac{\sqrt{3}}{2}$$
   $$9 = 16 + x^2 - 4\sqrt{3} x \implies x^2 - 4\sqrt{3} x + 7 = 0$$
   2次方程式の解の公式より：
   $$x = 2\sqrt{3} \pm \sqrt{12 - 7} = 2\sqrt{3} \pm \sqrt{5}$$
   図より $\angle C$ は鋭角であり、点 D が線分 BC 上にあるため、$BC > BD$ より：
   $$BC = 2\sqrt{3} + \sqrt{5}, \quad BD = 2\sqrt{3} - \sqrt{5}$$
   （$CD = BC - BD = 2\sqrt{5}$）。
   よって、$\text{GHI} = 235$, $\text{JKL} = 235$ である。

2. **線分 BE の長さ（方べきの定理）**：
   点 B から円 O を通る 2 直線 B-E-A と B-D-C について、方べきの定理が成り立つ：
   $$BE \cdot BA = BD \cdot BC$$
   $BA = 4$, $BD \cdot BC = (2\sqrt{3} - \sqrt{5})(2\sqrt{3} + \sqrt{5}) = 12 - 5 = 7$ であるから：
   $$BE \times 4 = 7 \implies BE = \frac{7}{4}$$
   よって、$\text{MN} = 74$ である。
   また、$AE = AB - BE = 4 - \frac{7}{4} = \frac{9}{4}$ である。

3. **面積比 $\triangle\text{BDE} : \triangle\text{ADE}$ の計算**：
   2つの三角形は線分 AB 上に底辺をもち、頂点 D を共有するため、面積比は底辺の比に等しい：
   $$\triangle\text{BDE} : \triangle\text{ADE} = BE : AE = \frac{7}{4} : \frac{9}{4} = 7 : 9$$
   よって、$\text{OP} = 79$ である。

4. **面積比 $\triangle\text{BDE} : \triangle\text{ACD}$ の計算**：
   - $\triangle\text{BDE} = \frac{1}{2} BE \cdot BD \sin 30^\circ = \frac{1}{2} \times \frac{7}{4} \times (2\sqrt{3} - \sqrt{5}) \times \frac{1}{2} = \frac{7}{16}(2\sqrt{3} - \sqrt{5})$
   - $\triangle\text{ACD}$ は二等辺三角形で、底辺 $CD = 2\sqrt{5}$、等辺 $3$ より、高さ $h = \sqrt{3^2 - (\sqrt{5})^2} = \sqrt{9 - 5} = 2$。
     $$\triangle\text{ACD} = \frac{1}{2} \times 2\sqrt{5} \times 2 = 2\sqrt{5}$$
   - したがって比は：
     $$\frac{\triangle\text{BDE}}{\triangle\text{ACD}} = \frac{\frac{7}{16}(2\sqrt{3} - \sqrt{5})}{2\sqrt{5}} = \frac{7(2\sqrt{3} - \sqrt{5})}{32\sqrt{5}}$$
   よって、$\text{QRST} = 7325$ である。
