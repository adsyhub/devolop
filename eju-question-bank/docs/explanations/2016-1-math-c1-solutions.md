## 大問I 問1：2次関数の頂点軌跡・最大値および接線条件による値域

**問題コード**: `math-q-I_1` | **正解参照**: `MATH_C1:I_1`

### 出題のポイント
- 2次関数の平方完成と頂点 $(p, q)$ の導出
- 頂点の直線上の運動によるパラメータ消去と2次関数の最大値
- $x$ 軸との接点条件（判別式 $D = 0$ または頂点 $q = 0$）による不等式の導出

### 詳細解説
**【題目大意】**
2次関数 $y = -\frac{1}{8}x^2 + ax + b$ $\textcircled{1}$ の頂点を $(p, q)$ とし、(1) 頂点が直線 $x + y = 1$ 上を動くときの $8a + b$ の最大値、および (2) グラフが $x$ 軸に接するときの $a + b$ のとり得る値の範囲を求める。

**【公式正解】**
- $\text{A} = 4, \text{B} = 2$ ($p = 4a, q = 2a^2 + b$)
- $\text{CDEF} = -241$ ($b = -2a^2 - 4a + 1$)
- $\text{G} = 1, \text{H} = 3$ ($a = 1$ で最大値 3)
- $\text{IJ} = 18$ ($a + b \leq \frac{1}{8}$)

**【詳細推導・解答プロセス】**
**(1) 頂点の座標の算出**
関数 $\textcircled{1}$ を平方完成する：
$$y = -\frac{1}{8}(x^2 - 8ax) + b = -\frac{1}{8}(x - 4a)^2 + 2a^2 + b$$
したがって、頂点の座標 $(p, q)$ は：
$$p = 4a, \quad q = 2a^2 + b$$
よって、$\text{A} = 4, \text{B} = 2$ である。

**(2) 頂点が直線 $x + y = 1$ 上にある条件と最大値**
点 $(p, q)$ を直線の方程式 $x + y = 1$ に代入すると：
$$4a + (2a^2 + b) = 1 \implies b = -2a^2 - 4a + 1$$
したがって、$\text{CD} = -2, \text{E} = 4, \text{F} = 1$ (CDEF = -241) である。
このとき、$8a + b$ を $a$ の関数として表すと：
$$8a + b = 8a + (-2a^2 - 4a + 1) = -2a^2 + 4a + 1$$
これを平方完成すると：
$$-2(a^2 - 2a) + 1 = -2(a - 1)^2 + 2 + 1 = -2(a - 1)^2 + 3$$
したがって、$a = 1$ のとき最大値 3 をとる。
よって、$\text{G} = 1, \text{H} = 3$ である。

**(3) グラフが $x$ 軸に接する条件**
放物線 $\textcircled{1}$ が $x$ 軸に接するとき、頂点の $y$ 座標 $q$ は 0 であるから：
$$2a^2 + b = 0 \implies b = -2a^2$$
このとき、$a + b$ は：
$$a + b = a - 2a^2 = -2\left(a^2 - \frac{1}{2}a\right) = -2\left(a - \frac{1}{4}\right)^2 + \frac{1}{8}$$
したがって、$a + b$ は $a = \frac{1}{4}$ で最大値 $\frac{1}{8}$ をとる。
すなわち、そのとり得る値の範囲は：
$$a + b \leq \frac{1}{8}$$
よって、$\text{I} = 1, \text{J} = 8$ (IJ = 18) である。

**【考査考点】**
1. 2次関数の標準形への変形と頂点座標の特定。
2. 条件付き2次式の最大値問題（1文字消去法と平方完成）。
3. 接線条件（$D = 0$ または頂点 $y = 0$）と2次不等式の値域解析。

## 大問I 問2：格子点から選ぶ三角形の総数（共線点の除外と組合せ）

**問題コード**: `math-q-I_2` | **正解参照**: `MATH_C1:I_2`

### 出題のポイント
- 12点から3点を選ぶ全組合せ数の計算
- 3点以上が一直線上に並ぶ同一直線上の組（退化三角形）の分類・減算
- 特定線分上に底辺をもつ三角形の個数計算

### 詳細解説
**【題目大意】**
平面上の $4 \times 3$ の格子点（計 12 点）から 3 点を選んで三角形を作る。作ることができる三角形の総数、および線分 AB 上に 2 頂点をもつ三角形の個数を求める。

**【公式正解】**
- $\text{KLM} = 220$ (全組合せ 220 通り)
- $\text{N} = 3, \text{O} = 8$ (4点直線 3本、3点直線 8本)
- $\text{PQ} = 12, \text{R} = 8$ (除外する組 12 通り、8 通り)
- $\text{STU} = 200$ (三角形の総数 200 個)
- $\text{VW} = 48$ (線分 AB 上に 2 頂点をもつ三角形 48 個)

**【詳細推導・解答プロセス】**
**(1) 12点から3点を選ぶ全組合せ**
12 個の点から 3 個を選ぶ組合せの総数は：
$$\binom{12}{3} = \frac{12 \times 11 \times 10}{3 \times 2 \times 1} = 220$$
したがって、$\text{KLM} = 220$ である。

**(2) 3点以上が一直線上に並ぶ直線の数**
(i) **4点を通る直線**：
各行（水平線 $y = 1, 2, 3$）には 4 点ずつ並んでいる。この直線は計 3 本ある。
よって、$\text{N} = 3$ である。
4 点から 3 点を選ぶ組合せは 1 本あたり $\binom{4}{3} = 4$ 通りあるので：
$$3 \times 4 = 12\text{ 通り}$$
よって、$\text{PQ} = 12$ である。

(ii) **3点を通る直線**：
- 各列（垂直線 $x = 1, 2, 3, 4$）：各 3 点並ぶ直線が 4 本。
- 傾き $+1$ の対角線：$(1,1)-(2,2)-(3,3)$ および $(2,1)-(3,2)-(4,3)$ の 2 本。
- 傾き $-1$ の対角線：$(1,3)-(2,2)-(3,1)$ および $(2,3)-(3,2)-(4,1)$ の 2 本。
合計で $4 + 2 + 2 = 8$ 本ある。
よって、$\text{O} = 8$ である。
3 点から 3 点を選ぶ組合せは 1 本あたり $\binom{3}{3} = 1$ 通りであるから：
$$8 \times 1 = 8\text{ 通り}$$
よって、$\text{R} = 8$ である。

**(3) できる三角形の総数**
全組合せから共線 3 点の組を引くと：
$$220 - (12 + 8) = 220 - 20 = 200$$
したがって、求める三角形は 200 個である。
よって、$\text{STU} = 200$ である。

**(4) 線分 AB 上に 2 頂点をもつ三角形の個数**
線分 AB（直線 $y = 1$ 上）には 4 つの格子点が存在する。
線分 AB 上から 2 頂点を選ぶ組合せは：
$$\binom{4}{2} = \frac{4 \times 3}{2} = 6\text{ 通り}$$
第 3 の頂点は直線 AB 外の $12 - 4 = 8$ 点から選べば、どの点を選んでも一直線上に並ぶことはなく三角形を形成する。
したがって、三角形の個数は：
$$6 \times 8 = 48\text{ 個}$$
よって、$\text{VW} = 48$ である。

**【考査考点】**
1. 格子点配置における組合せの計算。
2. 水平・垂直・斜め方向の共線条件（退化三角形）の網羅的分類と除外算。

## 大問II 問1：2変数2次式の1次式の積への因数分解（未定係数法）

**問題コード**: `math-q-II_1` | **正解参照**: `MATH_C1:II_1`

### 出題のポイント
- 2次の斉次項のたすき掛けによる因数分解
- 未定係数法による1次式の積の展開と係数比較
- 連立1次方程式による定数項 $a$ の決定

### 詳細解説
**【題目大意】**
多項式 $15x^2 - 2xy - 8y^2 - 11x + 22y + a$ が $x, y$ の 1 次式の積に因数分解できるときの定数 $a$ の値を求める。

**【公式正解】**
- $\text{ABCD} = 5432$ ($(5x - 4y)(3x + 2y)$)
- $\text{EFGH} = 3524$ ($(3b + 5c)x + (2b - 4c)y$)
- $\text{I} = 3, \text{J} = 4$ ($b = 3, c = -4$)
- $\text{KL} = 12$ ($a = -12$)

**【詳細推導・解答プロセス】**
**(1) 2次斉次項の因数分解**
2次の項 $15x^2 - 2xy - 8y^2$ をたすき掛けにより因数分解する：
$$15x^2 - 2xy - 8y^2 = (5x - 4y)(3x + 2y)$$
したがって、$\text{A} = 5, \text{B} = 4, \text{C} = 3, \text{D} = 2$ (ABCD = 5432) である。

**(2) 1次式の積の展開と係数比較**
与式を $(5x - 4y + b)(3x + 2y + c)$ $\textcircled{1}$ とおく。
これを展開すると：
$$(5x - 4y)(3x + 2y) + c(5x - 4y) + b(3x + 2y) + bc$$
$$= 15x^2 - 2xy - 8y^2 + (3b + 5c)x + (2b - 4c)y + bc$$
したがって、$\text{E} = 3, \text{F} = 5, \text{G} = 2, \text{H} = 4$ (EFGH = 3524) である。
与えられた式の 1 次の項の係数と比較すると：
$$\begin{cases} 3b + 5c = -11 & \textcircled{2} \\ 2b - 4c = 22 & \textcircled{3} \end{cases}$$
$\textcircled{3}$ の両辺を 2 で割ると：
$$b - 2c = 11 \implies b = 2c + 11$$
これを $\textcircled{2}$ に代入すると：
$$3(2c + 11) + 5c = -11 \implies 6c + 33 + 5c = -11$$
$$11c = -44 \implies c = -4$$
したがって：
$$b = 2(-4) + 11 = 3$$
これより、$b = 3$、および $c = -4$ である。
よって、$\text{I} = 3, \text{J} = 4$ である。

**(3) 定数項 $a$ の算出**
定数項は $a = bc$ であるから：
$$a = 3 \times (-4) = -12$$
したがって、$\text{KL} = 12$ ($a = -12$) である。

**【考査考点】**
1. 2変数2次式の因数分解の定石（最高次項の分解から定数項の決定）。
2. 恒等式の係数比較法による連立方程式の解法。

## 大問II 問2：一次不定方程式（ベズー等式）と2桁自然数の決定

**問題コード**: `math-q-II_2` | **正解参照**: `MATH_C1:II_2`

### 出題のポイント
- 剰余条件の倍数関係式化による1次不定方程式の立式
- ユークリッドの互除法または特殊解による一般解の導出
- 2桁の自然数条件を満たす解の特定

### 詳細解説
**【題目大意】**
$a + 9$ が 7 の倍数、$a + 8$ が 13 の倍数となる 2 桁の自然数 $a$ を、1次不定方程式を解くことにより求める。

**【公式正解】**
- $\text{M} = 7, \text{NO} = 13$ ($a + 9 = 7m, a + 8 = 13n$)
- $\text{P} = 1$ ($7m - 13n = 1$)
- $\text{Q} = 2, \text{R} = 1$ (特殊解 $m = 2, n = 1$)
- $\text{ST} = 71$ ($n = 7k + 1$)
- $\text{UVW} = 915$ ($a = 91k + 5$)
- $\text{XY} = 96$ ($a = 96$)

**【詳細推導・解答プロセス】**
**(1) 不定方程式の立式**
自然数 $m, n$ を用いて：
$$a + 9 = 7m, \quad a + 8 = 13n$$
よって、$\text{M} = 7, \text{NO} = 13$ である。
第 1 式から第 2 式を引くと：
$$(a + 9) - (a + 8) = 7m - 13n \implies 7m - 13n = 1 \quad \textcircled{1}$$
したがって、$\text{P} = 1$ である。

**(2) 整数解の導出**
$7 \times 2 - 13 \times 1 = 14 - 13 = 1$ であるから、$m = 2, n = 1$ は $\textcircled{1}$ の 1 組の整数解である。
よって、$\text{Q} = 2, \text{R} = 1$ である。
これより：
$$7(m - 2) - 13(n - 1) = 0 \implies 7(m - 2) = 13(n - 1) \quad \textcircled{2}$$
7 と 13 は互いに素であるから、$n - 1$ は 7 の倍数でなければならない。
したがって、整数 $k$ を用いて：
$$n - 1 = 7k \implies n = 7k + 1$$
よって、$\text{S} = 7, \text{T} = 1$ (ST = 71) である。

**(3) $a$ の決定**
$a + 8 = 13n$ より：
$$a = 13n - 8 = 13(7k + 1) - 8 = 91k + 13 - 8 = 91k + 5$$
したがって、$\text{UV} = 91, \text{W} = 5$ (UVW = 915) である。
$a$ は 2 桁の自然数（$10 \leq a \leq 99$）であるから、$k = 1$ のとき：
$$a = 91 \times 1 + 5 = 96$$
（$k = 0$ では $a = 5$（1桁）、$k = 2$ では $a = 187$（3桁）となる）
よって、求める自然数は $a = 96$ である。
これより、$\text{XY} = 96$ である。

**【考査考点】**
1. 剰余問題の一次不定方程式（ベズー方程式）への定式化。
2. 互いに素な整数の性質を利用した一般解の表現と桁数条件による解の絞り込み。

## 大問III 問1：2次不等式が常に成り立つ条件（判別式による係数決定）

**問題コード**: `math-q-III_1` | **正解参照**: `MATH_C1:III_1`

### 出題のポイント
- 差の関数 $f(x) - g(x) \geq 0$ の標準形への整理
- すべての実数に対して不等式が成り立つ判別式条件 $D \leq 0$ の適用
- 2次不等式の解によるパラメータ $a$ の範囲決定

### 詳細解説
**【題目大意】**
2つの関数 $f(x) = x^2 + 2ax + 4a - 3$ と $g(x) = 2x + 1$ について、すべての実数 $x$ に対し $f(x) \geq g(x)$ が成り立つための $a$ の条件を求める。

**【公式正解】**
- $\text{ABCD} = 2144$ ($x^2 + 2(a - 1)x + 4a - 4 \geq 0$)
- $\text{E} = 3$ ($a^2 - 6a + 5 \leq 0$、選択肢 $\textcircled{3}$)
- $\text{F} = 5$ ($1 \leq a \leq 5$、選択肢 $\textcircled{5}$)

**【詳細推導・解答プロセス】**
すべての $x$ に対して $f(x) \geq g(x)$ が成り立つ条件を考える：
$$x^2 + 2ax + 4a - 3 \geq 2x + 1$$
移項して整理すると：
$$x^2 + (2a - 2)x + 4a - 4 \geq 0 \implies x^2 + 2(a - 1)x + 4a - 4 \geq 0$$
したがって、$\text{A} = 2, \text{B} = 1, \text{C} = 4, \text{D} = 4$ (ABCD = 2144) である。

2次関数の $x^2$ の係数は $1 > 0$（下に凸）であるから、すべての実数 $x$ に対してこの不等式が成り立つための条件は、2次方程式 $x^2 + 2(a - 1)x + 4a - 4 = 0$ の判別式 $D/4 \leq 0$ である：
$$\frac{D}{4} = (a - 1)^2 - (4a - 4) \leq 0$$
$$a^2 - 2a + 1 - 4a + 4 \leq 0 \implies a^2 - 6a + 5 \leq 0$$
したがって、条件の2次不等式は $a^2 - 6a + 5 \leq 0$ である。
選択肢より $\text{E} = 3$ ($\textcircled{3}$) である。

この2次不等式を解くと：
$$(a - 1)(a - 5) \leq 0 \implies 1 \leq a \leq 5$$
選択肢より $\text{F} = 5$ ($\textcircled{5}$) である。

**【考査考点】**
1. 不等式の恒等成立条件（下に凸な2次関数において $D \leq 0$）。
2. 判別式の展開・整理と2次不等式の解法。

## 大問III 問2：2次関数の最小値の関数解析と定義域における値域決定

**問題コード**: `math-q-III_2` | **正解参照**: `MATH_C1:III_2`

### 出題のポイント
- 平方完成による $f(x)$ の最小値 $m(a)$ の導出
- 閉区間 $1 \leq a \leq 5$ における 2次関数 $m(a)$ の頂点・端点の値の比較による値域決定

### 詳細解説
**【題目大意】**
$f(x)$ の最小値を $m$ とするとき、$m$ を $a$ で表し、前問で求めた $1 \leq a \leq 5$ の範囲における $m$ のとり得る値の範囲を求める。

**【公式正解】**
- $\text{G} = 2$ ($m = -a^2 + 4a - 3$、選択肢 $\textcircled{2}$)
- $\text{H} = 5$ ($-8 \leq m \leq 1$、選択肢 $\textcircled{5}$)

**【詳細推導・解答プロセス】**
**(1) 最小値 $m$ の式**
$f(x) = x^2 + 2ax + 4a - 3$ を平方完成すると：
$$f(x) = (x + a)^2 - a^2 + 4a - 3$$
下に凸な放物線であるから、最小値 $m$ は頂点の $y$ 座標であり：
$$m = -a^2 + 4a - 3$$
選択肢より、$\text{G} = 2$ ($\textcircled{2}$) である。

**(2) $m$ のとり得る値の範囲**
$m(a) = -a^2 + 4a - 3$ を $a$ について平方完成する：
$$m(a) = -(a^2 - 4a) - 3 = -(a - 2)^2 + 4 - 3 = -(a - 2)^2 + 1$$
これは上に凸な放物線であり、頂点は $(2, 1)$ である。
定義域は問 1 で求めた $1 \leq a \leq 5$ である。
- 頂点 $a = 2$ は区間内にあり、最大値は：
  $$m(2) = 1$$
- 区間の端点における値：
  $$m(1) = -(1 - 2)^2 + 1 = 0$$
  $$m(5) = -(5 - 2)^2 + 1 = -9 + 1 = -8$$
したがって、$m$ の最小値は $-8$、最大値は $1$ である。
よって、$m$ のとり得る値の範囲は：
$$-8 \leq m \leq 1$$
選択肢より、$\text{H} = 5$ ($\textcircled{5}$) である。

**【考査考点】**
1. 2次関数の頂点による最小値の導出。
2. パラメータの制限区間内における2次関数の最大・最小解析（端点と頂点の比較）。

## 大問IV 問1：展開図をもつ四面体の面素面積と垂線の長さ

**問題コード**: `math-q-IV_1` | **正解参照**: `MATH_C1:IV_1`

### 出題のポイント
- 三角形の面積公式 $S = \frac{1}{2} ab \sin C$ による面積計算
- 底辺と面積の関係を用いた垂線の長さの導出

### 詳細解説
**【題目大意】**
四面体 OABC において $BC = 10, AC = 8, \sin \angle ACB = \frac{3}{4}$ であるとき、(1) $\triangle \text{ABC}$ の面積、および (2) 点 A から辺 BC に下ろした垂線 AH の長さを求める。

**【公式正解】**
- $\text{AB} = 30$ (面積 30)
- $\text{C} = 6$ (垂線 $AH = 6$)

**【詳細推導・解答プロセス】**
**(1) $\triangle \text{ABC}$ の面積の計算**
三角形の面積の公式より：
$$\triangle \text{ABC} = \frac{1}{2} \cdot \text{BC} \cdot \text{AC} \cdot \sin \angle \text{ACB}$$
与えられた値を代入すると：
$$\triangle \text{ABC} = \frac{1}{2} \times 10 \times 8 \times \frac{3}{4} = 40 \times \frac{3}{4} = 30$$
したがって、$\text{AB} = 30$ である。

**(2) 垂線 AH の長さの計算**
点 A から辺 BC に下ろした垂線を AH とすると、辺 BC を底辺としたときの高さが AH である。
$$\triangle \text{ABC} = \frac{1}{2} \cdot \text{BC} \cdot \text{AH}$$
$$30 = \frac{1}{2} \times 10 \times \text{AH} = 5 \cdot \text{AH} \implies \text{AH} = 6$$
（別解：直角三角形 ACH において、$\text{AH} = \text{AC} \sin \angle \text{ACB} = 8 \times \frac{3}{4} = 6$）
したがって、$\text{C} = 6$ である。

**【考査考点】**
1. 2辺とその夾角の正弦による三角形の面積公式。
2. 底辺と高さによる面積の表現と垂線長の算出。

## 大問IV 問2：二面角の余弦・正弦と四面体の体積の計算

**問題コード**: `math-q-IV_2` | **正解参照**: `MATH_C1:IV_2`

### 出題のポイント
- 展開図の合同条件 $\triangle ABC \equiv \triangle OBC$ からの線分長の同定
- 余弦定理による二面角 $\theta$ の $\cos \theta$ および $\sin \theta$ の導出
- 四面体の高さと体積 $V = \frac{1}{3} S h$ の算出

### 詳細解説
**【題目大意】**
四面体 OABC において $OA = 4, \triangle ABC \equiv \triangle OBC$ であるとき、平面 ABC と平面 OBC のなす角 $\theta$ の $\cos \theta, \sin \theta$、および四面体の体積を求める。

**【公式正解】**
- $\text{DE} = 79$ ($\cos \theta = \frac{7}{9}$)
- $\text{FGH} = 429$ ($\sin \theta = \frac{4\sqrt{2}}{9}$)
- $\text{IJKL} = 8023$ (体積 $V = \frac{80\sqrt{2}}{3}$)

**【詳細推導・解答プロセス】**
**(1) $\triangle \text{OAH}$ における二面角 $\theta$ の決定**
$\triangle \text{ABC} \equiv \triangle \text{OBC}$ であるから、点 O から辺 BC に下ろした垂線の足も点 H に一致し、$\text{OH} = \text{AH} = 6$ である。
したがって、$\text{AH} \perp \text{BC}$ かつ $\text{OH} \perp \text{BC}$ であるため、平面 ABC と平面 OBC のなす二面角は $\angle \text{AHO} = \theta$ である。
$\triangle \text{OAH}$ において、$\text{OA} = 4, \text{AH} = 6, \text{OH} = 6$ である。
余弦定理より：
$$\cos \theta = \frac{\text{AH}^2 + \text{OH}^2 - \text{OA}^2}{2 \cdot \text{AH} \cdot \text{OH}} = \frac{6^2 + 6^2 - 4^2}{2 \times 6 \times 6} = \frac{36 + 36 - 16}{72} = \frac{56}{72} = \frac{7}{9}$$
したがって、$\text{D} = 7, \text{E} = 9$ (DE = 79) である。

$\sin \theta > 0$ であるから、相互関係 $\sin^2 \theta + \cos^2 \theta = 1$ より：
$$\sin \theta = \sqrt{1 - \left(\frac{7}{9}\right)^2} = \sqrt{1 - \frac{49}{81}} = \sqrt{\frac{32}{81}} = \frac{4\sqrt{2}}{9}$$
したがって、$\text{F} = 4, \text{G} = 2, \text{H} = 9$ (FGH = 429) である。

**(2) 四面体 OABC の体積の計算**
底面を $\triangle \text{ABC}$（面積 $S = 30$）とする。
点 O から平面 ABC に下ろした垂線の長さ（四面体の高さ）$h$ は：
$$h = \text{OH} \sin \theta = 6 \times \frac{4\sqrt{2}}{9} = \frac{8\sqrt{2}}{3}$$
四面体の体積 $V$ は：
$$V = \frac{1}{3} \times \triangle \text{ABC} \times h = \frac{1}{3} \times 30 \times \frac{8\sqrt{2}}{3} = 10 \times \frac{8\sqrt{2}}{3} = \frac{80\sqrt{2}}{3}$$
したがって、$\text{I} = 8, \text{J} = 0, \text{K} = 2, \text{L} = 3$ (IJKL = 8023) である。

**【考査考点】**
1. 空間図形における二面角の定義（交線に垂直な2本の垂線のなす角）。
2. 余弦定理を用いた二面角の余弦・正弦の算出。
3. 四面体の体積公式（底面積 $\times$ 高さ $\div 3$）の適用。
