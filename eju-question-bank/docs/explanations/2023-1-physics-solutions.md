## 問1：3本の糸で吊るされた一様円板の力のつり合い

**【考査考点】**：空間対称性による張力の等価性, 鉛直方向の力のつり合い, 三角比による分力計算

**【題目大意】**
質量 $m$、半径 $\ell$ の一様な薄い円板の円周上に、3点 A, B, C が等間隔（中心角 $120^\circ$ ずつ）で並んでいる。
A, B, C のそれぞれに長さ $2\ell$ の伸び縮みしない軽い糸をつけ、天井の1点から吊るしたところ、円板は水平に静止した。
このとき、各糸と鉛直方向のなす角は $30^\circ$ であり、各糸の張力の大きさは等しく $T$ であった。張力 $T$ を求めよ。

**【公式正解】**：$\textcircled{2}$（$\frac{2\sqrt{3}}{9}mg$）

**【詳細推導・解答プロセス】**
1. **空間対称性と力の鉛直成分**：
   3本の糸は円周上に等間隔に配置され、天井の同一点に固定されているため、円板の水平面内での水平成分の合力は対称性により完全に相殺して 0 となる。
   したがって、円板全体のつり合いは鉛直方向の力のつり合いのみを考えればよい。
2. **鉛直方向のつり合いの立式**：
   1本の糸の張力を $T$ とすると、糸と鉛直方向のなす角が $30^\circ$ であるから、上向きの鉛直分力は：
   $$T_z = T \cos 30^\circ = T \cdot \frac{\sqrt{3}}{2}$$
   3本の糸による上向きの鉛直分力の合計は $3 T_z = 3 \cdot T \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{2}T$ である。
   円板にはたらく下向きの重力は $mg$ であるから：
   $$\frac{3\sqrt{3}}{2}T = mg$$
3. **張力 $T$ の導出**：
   $$T = \frac{2mg}{3\sqrt{3}} = \frac{2\sqrt{3}}{9}mg$$
したがって、正しい選択肢は **$\textcircled{2}$** である。

## 問2：連結物体の運動方程式と張力の比

**【考査考点】**：静止時の糸の張力（つり合い条件）, 滑車を介した2物体の運動方程式, 内力としての糸の張力の決定

**【題目大意】**
滑らかな水平台の上に質量 $m$ の物体を置き、軽い糸で滑車を介して質量 $M$ のおもりをつるした。
手で固定しているときの張力を $T_0$、手を静かにはなして物体が加速運動しているときの張力を $T_1$ とするとき、比 $\frac{T_1}{T_0}$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{m}{m + M}$）

**【詳細推導・解答プロセス】**
1. **静止時（手で固定しているとき）の張力 $T_0$**：
   質量 $M$ のおもりは静止しているため、鉛直方向の力のつり合いより：
   $$T_0 = Mg$$
2. **手をはなした後の加速運動時の張力 $T_1$**：
   系全体の加速度を $a$ とする。糸は伸び縮みしないため、台上の物体（水平右向き）とおもり（鉛直下向き）の加速度の大きさは等しい。
   - 台上の物体（質量 $m$）の運動方程式：
     $$m a = T_1$$
   - おもり（質量 $M$）の運動方程式：
     $$M a = Mg - T_1$$
   2式を足し合わせると：
     $$(m + M)a = Mg \implies a = \frac{M}{m + M}g$$
   これを第1式に代入して張力 $T_1$ を求める：
     $$T_1 = m a = \frac{mM}{m + M}g$$
3. **張力の比 $\frac{T_1}{T_0}$ の計算**：
   $$\frac{T_1}{T_0} = \frac{\frac{mM}{m + M}g}{Mg} = \frac{m}{m + M}$$
したがって、正しい選択肢は **$\textcircled{5}$** である。

## 問3：斜め上方に引く力と動摩擦力のなす仕事

**【考査考点】**：斜め方向の外力の分解（垂直抗力の減少）, 動摩擦力の公式 $F_k = \mu' N$, 摩擦力のなす負の仕事 $W = -F_k \ell$

**【題目大意】**
粗い水平床上の質量 $m$ の小物体に糸をつけ、水平面から $30^\circ$ の角度で外力 $F$ を加えて引いたところ、床から離れずに距離 $\ell$ だけ等速移動した。
動摩擦係数を $\mu'$ とするとき、動摩擦力が小物体にした仕事 $W$ を求めよ。

**【公式正解】**：$\textcircled{3}$（$-\mu' \ell \left( mg - \frac{1}{2} F \right)$）

**【詳細推導・解答プロセス】**
1. **鉛直方向の力のつり合いと垂直抗力 $N$**：
   外力 $F$ の鉛直上向き成分は $F \sin 30^\circ = \frac{1}{2}F$ である。
   床からの垂直抗力を $N$、下向きの重力を $mg$ とすると、床から離れないため鉛直方向につり合っている：
   $$N + F \sin 30^\circ = mg \implies N = mg - \frac{1}{2}F$$
2. **動摩擦力の大きさ $F_k$**：
   $$F_k = \mu' N = \mu'\left(mg - \frac{1}{2}F\right)$$
3. **動摩擦力がした仕事 $W$**：
   小物体は進行方向（前向き）に距離 $\ell$ 移動し、動摩擦力は常に進行方向と逆向き（後向き）にはたらく。
   したがって、仕事は負となり：
   $$W = -F_k \ell = -\mu' \ell \left(mg - \frac{1}{2}F\right)$$
したがって、正しい選択肢は **$\textcircled{3}$** である。

## 問4：振り子の弾性衝突と水平投射の力学的エネルギー保存則

**【考査考点】**：振り子の力学的エネルギー保存則, 等質量物体の正面弾性衝突における速度交換, 重力場における力学的エネルギー保存則による落下速度

**【題目大意】**
台の高さは床から $\frac{3}{2}l$、台の上面に静止した小物体 A（質量 $m$）がある。
長さ $l$ の糸につるされた小物体 B（質量 $m$）を鉛直から $60^\circ$ 持ち上げて放すと、最下点で A と弾性衝突した。
A は台から水平に飛び出して床に落下した。A が床に達する直前の速さ $v$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$2\sqrt{gl}$）

**【詳細推導・解答プロセス】**
1. **小物体 B の衝突直前の速さ $v_B$**：
   B は最下点に対して高さ $h_B = l(1 - \cos 60^\circ) = l\left(1 - \frac{1}{2}\right) = \frac{1}{2}l$ だけ高い位置から静かに放される。
   力学的エネルギー保存則より：
   $$\frac{1}{2}mv_B^2 = mg \cdot \frac{1}{2}l \implies v_B = \sqrt{gl}$$
2. **A と B の弾性衝突後の速さ**：
   A と B はともに質量 $m$ で等しく、反発係数 $e = 1$（完全弾性衝突）である。
   等質量の 1 次元弾性衝突では速度が交換されるため、静止していた A の衝突直後の水平初速度は：
   $$v_A = v_B = \sqrt{gl}$$
3. **A が床に達する直前の速さ $v$**：
   A は台の上面（床からの高さ $H = \frac{3}{2}l$）から水平投射される。
   空中運動において力学的エネルギーが保存されるため：
   $$\frac{1}{2}mv^2 = \frac{1}{2}mv_A^2 + mgH$$
   $$v^2 = v_A^2 + 2gH = gl + 2g\left(\frac{3}{2}l\right) = gl + 3gl = 4gl$$
   $$v = \sqrt{4gl} = 2\sqrt{gl}$$
したがって、正しい選択肢は **$\textcircled{4}$** である。

## 問5：円錐振り子の等速円運動の周期

**【考査考点】**：円錐振り子の力のつり合い（張力と重力）, 水平向心力と向心加速度, 円運動の周期公式 $T = \frac{2\pi}{\omega}$

**【題目大意】**
長さ $5L$ の軽い糸の一端を天井の点 C に固定し、他端のおもりに半径 $3L$ の水平等速円運動をさせた。
円運動の中心 O は C の真下にある。この円運動の周期 $T$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$4\pi \sqrt{\frac{L}{g}}$）

**【詳細推導・解答プロセス】**
1. **幾何学的関係**：
   糸の長さは $5L$、円運動の半径は $r = 3L$ である。
   糸と鉛直方向のなす角を $\theta$ とすると：
   $$\sin\theta = \frac{3L}{5L} = \frac{3}{5}, \quad \cos\theta = \frac{4}{5}$$
   懸垂点 C から回転中心 O までの鉛直距離は $h = 5L \cos\theta = 4L$ である。
2. **運動方程式と角速度 $\omega$**：
   糸の張力を $S$、おもりの質量を $m$、角速度を $\omega$ とする。
   - 鉛直方向のつり合い：$S \cos\theta = mg \implies S = \frac{mg}{\cos\theta}$
   - 水平方向の運動方程式：$m r \omega^2 = S \sin\theta$
   $S$ を代入すると：
   $$m r \omega^2 = mg \frac{\sin\theta}{\cos\theta} = mg \tan\theta$$
   ここで $r = 3L, \tan\theta = \frac{3}{4}$ であるから：
   $$3L \omega^2 = g \cdot \frac{3}{4} \implies \omega^2 = \frac{g}{4L} \implies \omega = \frac{1}{2}\sqrt{\frac{g}{L}}$$
3. **周期 $T$ の導出**：
   $$T = \frac{2\pi}{\omega} = \frac{2\pi}{\frac{1}{2}\sqrt{\frac{g}{L}}} = 4\pi \sqrt{\frac{L}{g}}$$
したがって、正しい選択肢は **$\textcircled{4}$** である。

## 問6：鉛直単振動における垂直抗力の最小時刻と重力と等しい時刻

**【考査考点】**：鉛直単振動の運動方程式 $ma = N - mg$, 加速度の向きと垂直抗力 $N$ の増減関係, グラフからの極値時刻・中心通過時刻の読み取り

**【題目大意】**
水平な板の上で小物体が鉛直方向に単振動している。高さ $h$ と時刻 $t$ のグラフが与えられている。
$0.1\text{ s} \le t \le 1.1\text{ s}$ の範囲で、垂直抗力 $N$ が最小となる時刻 $t_1$ と、$N$ が重力と等しくなる時刻 $t_2$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$t_1 = 0.3\text{ s}, t_2 = 0.6\text{ s}$）

**【詳細推導・解答プロセス】**
1. **小物体の運動方程式と垂直抗力 $N$**：
   鉛直上向きを正にとると、小物体の加速度は $a = -\omega^2 h$ である。
   運動方程式：$m a = N - mg \implies N = m(g + a) = m(g - \omega^2 h)$
2. **垂直抗力 $N$ が最小となる時刻 $t_1$**：
   $N = m(g - \omega^2 h)$ より、$h$ が最大のとき（最上点）に $N$ は最小値をとる。
   グラフより、高さ $h$ が極大（最大値 $h_0$）に達する時刻は $t = 0.3\text{ s}$ である。
   したがって、$t_1 = 0.3\text{ s}$。
3. **$N = mg$ となる時刻 $t_2$**：
   $N = mg \iff m(g - \omega^2 h) = mg \iff \omega^2 h = 0 \iff h = 0$。
   すなわち、振動中心（$h = 0$）を通過する時刻である。
   グラフにおいて、$0.1\text{ s} \le t \le 1.1\text{ s}$ で $h = 0$ となる時刻を読み取ると、$t = 0.6\text{ s}$ である。
   したがって、$t_2 = 0.6\text{ s}$。
よって、最も適当な組み合わせは **$\textcircled{1}$**（$t_1 = 0.3, t_2 = 0.6$）である。

## 問7：容器・温水と氷の熱平衡・融解熱の計算

**【考査考点】**：熱容量 $C$ と比熱 $c$ の熱量計算 $Q = C\Delta T$, 氷の融解に伴う潜熱の吸収, 熱量保存則（放出熱量＝吸収熱量）

**【題目大意】**
熱容量 $160\text{ J/K}$ の容器に $200\text{ g}$ の水が入り、$80^\circ\text{C}$ で平衡にある。
ここに $0^\circ\text{C}$ の氷 $100\text{ g}$ を投入した。水の融解熱を $330\text{ J/g}$、水の比熱を $4.2\text{ J/(g}\cdot\text{K)}$ とするとき、熱平衡後の温度 $T$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$33^\circ\text{C}$）

**【詳細推導・解答プロセス】**
1. **容器と温水が放出する熱量 $Q_1$**：
   容器の熱容量は $C = 160\text{ J/K}$、温水の熱容量は $m_1 c = 200 \times 4.2 = 840\text{ J/K}$。
   全体の熱容量は $C_{\text{tot}} = 160 + 840 = 1000\text{ J/K}$ である。
   温度が $80^\circ\text{C}$ から $T$ に下がるときに放出する熱量は：
   $$Q_1 = 1000 \times (80 - T)$$
2. **氷が融解し昇温する際に吸収する熱量 $Q_2$**：
   - $0^\circ\text{C}$ の氷 $100\text{ g}$ がすべて融解して $0^\circ\text{C}$ の水になる熱量：
     $$Q_{\text{融解}} = 100\text{ g} \times 330\text{ J/g} = 33000\text{ J}$$
   - 融解後の水（$100\text{ g}$）が $0^\circ\text{C}$ から $T$ まで昇温する熱量：
     $$Q_{\text{昇温}} = 100 \times 4.2 \times (T - 0) = 420 T$$
   吸収熱量の合計は：
     $$Q_2 = 33000 + 420 T$$
3. **熱量保存則による立式と解法**：
   $$Q_1 = Q_2 \implies 1000(80 - T) = 33000 + 420 T$$
   $$80000 - 1000 T = 33000 + 420 T$$
   $$1420 T = 47000 \implies T = \frac{47000}{1420} \approx 33.098^\circ\text{C} \approx 33^\circ\text{C}$$
したがって、最も適当な値は **$33^\circ\text{C}$**（選択肢 **$\textcircled{4}$**）である。

## 問8：シリンダーの姿勢変化とピストンによる気体の等温変化

**【考査考点】**：ボイルの法則 $pV = \text{一定}$, ピストンの重力による追加圧力の符号判定, 水平・鉛直上向き・鉛直下向きでの気体圧力の立式

**【題目大意】**
一定温度で断面積 $S$ のシリンダー内にピストン（質量 $M$）で空気を閉じ込めた。
水平時（図1）の気柱長は $L_1 = 15\text{ cm}$、底を下にして立てた時（図2）は $L_2 = 10\text{ cm}$ であった。
底を上にして立てた時（図3）の気柱長 $L_3$ を求めよ。

**【公式正解】**：$\textcircled{3}$（$30\text{ cm}$）

**【詳細推導・解答プロセス】**
大気圧を $p_0$ とする。温度は一定であるためボイルの法則 $p L = \text{一定}$ が成り立つ。
1. **図1（水平時）**：ピストンの重力はシリンダー壁面で支えられ、気体の圧力は $p_1 = p_0$ である。
2. **図2（底が下）**：ピストンは気体を圧縮する向きに重力 $Mg$ を及ぼすため：
   $$p_2 = p_0 + \frac{Mg}{S}$$
   ボイルの法則より：
   $$p_1 L_1 = p_2 L_2 \implies p_0 \times 15 = \left(p_0 + \frac{Mg}{S}\right) \times 10$$
   $$15 p_0 = 10 p_0 + 10 \frac{Mg}{S} \implies 10 \frac{Mg}{S} = 5 p_0 \implies \frac{Mg}{S} = 0.5 p_0$$
3. **図3（底が上）**：ピストンの重力は気体を広げる（下向きに引っ張る）向きに働くため：
   $$p_3 = p_0 - \frac{Mg}{S} = p_0 - 0.5 p_0 = 0.5 p_0$$
   ボイルの法則より：
   $$p_3 L_3 = p_1 L_1 \implies 0.5 p_0 \times L_3 = p_0 \times 15 \implies L_3 = \frac{15}{0.5} = 30\text{ cm}$$
したがって、最も適当な値は **$30\text{ cm}$**（選択肢 **$\textcircled{3}$**）である。

## 問9：気体の状態変化における外部からの仕事の大小比較

**【考査考点】**：$p-V$ グラフにおける仕事と面積の対応 $W = -\int p dV$, 断熱圧縮・等温圧縮・定圧圧縮の曲線勾配, 体積半減時の仕事の最大・最小の判定

**【題目大意】**
初期状態 $(p_0, V_0)$ の理想気体を、次の3通りの方法で体積 $\frac{V_0}{2}$ まで圧縮したとき、外部から気体にする仕事 $W$ の最大・最小を判定せよ。
(a) 断熱圧縮、(b) 等温圧縮、(c) 定圧圧縮。

**【公式正解】**：$\textcircled{2}$（最大：(a)、最小：(c)）

**【詳細推導・解答プロセス】**
1. **仕事と $p-V$ グラフの関係**：
   外部から気体にする仕事は $W = \int_{V_0/2}^{V_0} p(V) \, dV$ であり、$p-V$ グラフにおいて状態変化の曲線と $V$ 軸で囲まれる面積に等しい。
2. **3 つの過程の圧力の比較**：
   - **(a) 断熱圧縮**：熱の出入りがなく仕事によって内部エネルギーが増加するため、温度が上昇する。ポアソンの法則 $p V^\gamma = \text{一定}$（$\gamma > 1$）に従い、等温線よりも急激に圧力が上昇する。
   - **(b) 等温圧縮**：$p V = \text{一定}$ に従って双曲線を描いて圧力が上昇する。
   - **(c) 定圧圧縮**：圧力は $p = p_0$ の一定値のままである。
   体積が $V_0 \to \frac{V_0}{2}$ へ減少する過程において、常に各体積 $V$ での圧力は：
   $$p_{(a)} > p_{(b)} > p_{(c)} = p_0$$
3. **仕事 $W$ の大小関係**：
   曲線の高さの順序により、囲まれる面積は明らかに：
   $$W_{(a)} > W_{(b)} > W_{(c)}$$
   したがって、仕事が最大となるのは **(a)**、最小となるのは **(c)** である。
よって、正しい組み合わせは **$\textcircled{2}$** である。

したがって、最も高いのは **C, G**、最も低いのは **A, E** である。
正しい選択肢は **$\textcircled{4}$** である。

## 問12：回転鏡法（フーコー・マイケルソン法）による光速測定

**【考査考点】**：光の往復時間 $\Delta t = \frac{2D}{c}$, 回転鏡の回転角と反射光の振れ角の関係（倍角効果 $\Delta\phi = \frac{\theta}{2}$）, 角速度による回転角 $\Delta\phi = \omega \Delta t$

**【題目大意】**
光源 L、回転鏡 R、固定鏡 M（RM 間の距離 $D$）を用いた光速測定実験。
R を角速度 $\omega$ で回転させたところ、反射光の向きが $\theta$ だけ回転した。
往復時間 $\frac{2D}{c}$ の間に R が $\frac{\theta}{2}$ 回転したとき、光速 $c$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{4D\omega}{\theta}$）

**【詳細推導・解答プロセス】**
1. **光の往復時間 $\Delta t$**：
   RM 間の距離が $D$ であるため、光が R から M へ進み、再び R に戻るまでの往復距離は $2D$ である。
   光速を $c$ とすると、所要時間は：
   $$\Delta t = \frac{2D}{c}$$
2. **回転鏡の回転角と角速度の関係**：
   鏡が角度 $\Delta\phi$ だけ回転すると、反射の法則により反射光線の進路は $2\Delta\phi = \theta$ だけ回転する。
   問題文にも示されている通り、この間の鏡の回転角は $\Delta\phi = \frac{\theta}{2}$ である。
   角速度 $\omega$ の定義より：
   $$\Delta\phi = \omega \Delta t \implies \frac{\theta}{2} = \omega \cdot \frac{2D}{c}$$
3. **光速 $c$ の導出**：
   $$\frac{\theta}{2} = \frac{2D\omega}{c} \implies c = \frac{4D\omega}{\theta}$$
したがって、正しい選択肢は **$\textcircled{5}$** である。

## 問13：2つの点電荷が原点の電荷に及ぼす静電気力の合力の向き

**【考査考点】**：クーロンの法則 $F = k \frac{|q_1 q_2|}{r^2}$, 引力と斥力のベクトルの向きの同定, 直角座標系における合力の方向正接 $|\tan\theta| = |F_y / F_x|$

**【題目大意】**
$xy$ 平面上の点 $(a, 0)$ に点電荷 A（$-3q$）、点 $(0, -2a)$ に点電荷 B（$q$）が固定されている。
原点 O に点電荷 C（$q$）を置いたとき、C が受ける静電気力の合力と $x$ 軸正の向きとのなす角 $\theta$ について、$|\tan\theta|$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$\frac{1}{12}$）

**【詳細推導・解答プロセス】**
クーロンの法則の比例定数を $k$ とする。
1. **電荷 A（$-3q$）が原点の電荷 C（$q$）に及ぼす静電気力 $\vec{F}_A$**：
   A は $(a, 0)$ にあり異符号であるため、引力となる。
   したがって、向きは $+x$ 軸の正の向きである。
   大きさは：
   $$F_x = k \frac{q \cdot (3q)}{a^2} = \frac{3kq^2}{a^2}$$
2. **電荷 B（$q$）が原点の電荷 C（$q$）に及ぼす静電気力 $\vec{F}_B$**：
   B は $(0, -2a)$ にあり同符号であるため、斥力（B から遠ざかる向き）となる。
   したがって、向きは $+y$ 軸の正の向きである。
   距離は $2a$ であるから、大きさは：
   $$F_y = k \frac{q \cdot q}{(2a)^2} = \frac{kq^2}{4a^2}$$
3. **合力の方向正接 $|\tan\theta|$ の計算**：
   $$|\tan\theta| = \frac{F_y}{F_x} = \frac{\frac{kq^2}{4a^2}}{\frac{3kq^2}{a^2}} = \frac{\frac{1}{4}}{3} = \frac{1}{12}$$
したがって、正しい値は **$\textcircled{1}$**（$\frac{1}{12}$）である。

## 問14：3個のコンデンサーの直列回路における中間接続点の電位

**【考査考点】**：コンデンサーの直列合成容量 $\frac{1}{C_{\text{eq}}} = \sum \frac{1}{C_i}$, 直列回路での蓄積電荷の共通性 $Q_1 = Q_2 = Q_3$, 基準電位（接地）からの電位降下による各点電位の決定

**【題目大意】**
起電力 $V$ の電池に、容量 $C$、$C/2$、$C/3$ の3個のコンデンサーが直列接続され、一端 P が接地されている。
充電完了後、容量 $C$ と $C/2$ の接続点 A の電位 $V_A$ について、比 $\frac{V_A}{V}$ を求めよ。

**【公式正解】**：$\textcircled{6}$（$\frac{5}{6}$）

**【詳細推導・解答プロセス】**
1. **3つのコンデンサーの直列合成容量 $C_{\text{eq}}$**：
   $$\frac{1}{C_{\text{eq}}} = \frac{1}{C} + \frac{1}{\frac{1}{2}C} + \frac{1}{\frac{1}{3}C} = \frac{1}{C} + \frac{2}{C} + \frac{3}{C} = \frac{6}{C}$$
   したがって、$C_{\text{eq}} = \frac{C}{6}$ である。
2. **蓄積される電荷 $Q$**：
   直列回路であるから、各コンデンサーに蓄えられる電荷の大きさは等しく：
   $$Q = C_{\text{eq}} V = \frac{1}{6} C V$$
3. **各コンデンサーの端子間電圧**：
   - 容量 $C$ のコンデンサーにかかる電圧：
     $$V_1 = \frac{Q}{C} = \frac{\frac{1}{6}CV}{C} = \frac{1}{6}V$$
   回路構成より、電池の正極側の電位は $V$ であり、容量 $C$ のコンデンサーを通って点 A に至る。
   したがって、点 A の電位は：
   $$V_A = V - V_1 = V - \frac{1}{6}V = \frac{5}{6}V$$
   （検算：点 A から接地 P までの電圧は $V_2 + V_3 = \frac{Q}{C/2} + \frac{Q}{C/3} = \frac{2}{6}V + \frac{3}{6}V = \frac{5}{6}V$ となり完全一致）
4. **比 $\frac{V_A}{V}$**：
   $$\frac{V_A}{V} = \frac{5}{6}$$
したがって、正しい選択肢は **$\textcircled{6}$** である。

**【題目大意】**
$xy$ 平面上の点 A(0, 0) と点 B(d, 0) を通る2本の直線導線に電流 $I_A, I_B$ が流れている。
$x$ 軸上の磁場 $H_y$ の測定グラフにおいて、$H_y = 0$ となる点が $x = 0.25d$ にある。
B の電流の向きと比 $\frac{I_B}{I_A}$ を求めよ。

**【公式正解】**：$\textcircled{2}$（裏から表の向き、$\frac{I_B}{I_A} = 3$）

**【詳細推導・解答プロセス】**
1. **B を流れる電流の向きの決定**：
   A を流れる電流 $I_A$（裏から表向き）は、$x$ 軸上の区間 $0 < x < d$ で右ねじの法則により $+y$ 向きの磁場をつくる。

   グラフより、磁場が 0 となる位置は $x = 0.25d = \frac{1}{4}d$ である。
   - A からの距離：$r_A = \frac{1}{4}d$
   - B からの距離：$r_B = d - \frac{1}{4}d = \frac{3}{4}d$

   $$\frac{I_A}{2\pi r_A} = \frac{I_B}{2\pi r_B} \implies \frac{I_A}{\frac{1}{4}d} = \frac{I_B}{\frac{3}{4}d}$$
   $$\frac{I_B}{I_A} = \frac{\frac{3}{4}d}{\frac{1}{4}d} = 3$$
したがって、電流の向きは「裏から表の向き」、比は「3」である。
正しい選択肢は **$\textcircled{2}$** である。

## 問18：回転する長方形コイルの電磁誘導と磁場の向きの決定

**【考査考点】**：ファラデーの電磁誘導の法則 $V = -\frac{\Delta\Phi}{\Delta t}$, レンツの法則による誘導電流の向きの同定, 3次元空間における磁束変化と磁場ベクトルの決定

**【題目大意】**
一様な磁場 $\vec{H}$ の空間内で長方形コイルを回転させた実験結果から、磁場 $\vec{H}$ の向きを特定する。
(1) 回転軸が $y$ 軸正の向きのとき、誘導起電力は生じなかった。
(2) 回転軸が $z$ 軸正の向きで、$xz$ 平面から $yz$ 平面に向かうとき、$A \to B \to C \to D$ の向きに起電力が生じた。

**【公式正解】**：$\textcircled{4}$（$y$ 軸の負の向き）

**【詳細推導・解答プロセス】**
1. **条件(1)からの判定**：
   コイルが $y$ 軸のまわりに回転したとき、いかなる回転角でも誘導起電力が生じない（$= 0$）。
   これはコイルを貫く磁束が常に一定（0）であることを意味する。
   したがって、磁場 $\vec{H}$ はコイルの法線と常に直交、すなわち磁場 $\vec{H}$ は**$y$ 軸に平行**でなければならない（$x$ 成分・$z$ 成分は 0）。
2. **条件(2)からの向きの判定**：
   回転軸が $z$ 軸正の向きのとき、コイル面が $xz$ 平面から $yz$ 平面に向かって回転する。
   このとき、起電力が $A \to B \to C \to D$ の向き（右ねじを回すと $+y$ 向きに進む向き）に生じた。
   レンツの法則により、誘導電流がつくる磁場は「コイルを貫く外部磁束の減少を補う」、または「増加を妨げる」向きにはたらく。
   回転に伴いコイル面が $yz$ 平面に近づくにつれて、$y$ 軸方向の法線面積が増加し、$-y$ 向きの磁束が増加する。
   この増加を妨げるために誘導電流は $+y$ 向きの磁場をつくるように流れる（$A \to B \to C \to D$）。
   したがって、外部磁場 $\vec{H}$ は **$y$ 軸の負の向き** である。
よって、正しい選択肢は **$\textcircled{4}$** である。

## 問19：原子核のアルファ崩壊・ベータ崩壊と核反応の質量数・原子番号保存則

**【考査考点】**：アルファ崩壊に伴う質量数（$-4$）と原子番号（$-2$）の変化, ベータ崩壊に伴う質量数（不変）と原子番号（$+1$）の変化, 核反応方程式の連立一次方程式による回数決定

**【題目大意】**
トリウムの原子核 $^{232}_{90}\text{Th}$ が、$\alpha$ 崩壊を $a$ 回、$\beta$ 崩壊を $b$ 回起こして、ラドンの原子核 $^{220}_{86}\text{Rn}$ になった。
$a$ と $b$ の値を求めよ。

**【公式正解】**：$\textcircled{1}$（$a = 3, b = 2$）

**【詳細推導・解答プロセス】**
1. **崩壊に伴う粒子と変化**：
   - $\alpha$ 粒子はヘリウムの原子核 $^{4}_{2}\text{He}$ であり、1 回の $\alpha$ 崩壊で質量数は 4 減少し、原子番号は 2 減少する。
   - $\beta^-$ 粒子は電子 $^{0}_{-1}\text{e}$ であり、1 回の $\beta$ 崩壊で質量数は変化せず、原子番号は 1 増加する。
2. **核反応方程式の立式**：
   $$^{232}_{90}\text{Th} \longrightarrow {}^{220}_{86}\text{Rn} + a \, {}^{4}_{2}\text{He} + b \, {}^{0}_{-1}\text{e}$$
3. **質量数の保存則**：
   $$232 = 220 + 4a + 0 \cdot b$$
   $$4a = 232 - 220 = 12 \implies a = 3$$
4. **原子番号（電荷）の保存則**：
   $$90 = 86 + 2a - b$$
   $a = 3$ を代入すると：
   $$90 = 86 + 2(3) - b = 92 - b \implies b = 92 - 90 = 2$$
したがって、$a = 3, b = 2$ である。
正しい選択肢は **$\textcircled{1}$** である。
