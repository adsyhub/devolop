## 化学 問2：分子の形状と極性分子の判定

**【題目大意】**
与えられた分子 (a)〜(e) の中から，極性分子である2つの組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{3}$（b, d）

**【詳細推導・解答プロセス】**
分子の極性は，結合の極性のベクトル和が $0$ になるか（無極性分子）否か（極性分子）で決まる：
- **(a) アセチレン（エチン）$\text{C}_2\text{H}_2$**：直線形構造であり，対称性から双極子モーメントが相殺され**無極性分子**。
- **(b) 塩化水素 $\text{HCl}$**：$	ext{Cl}$ の電気陰性度が $	ext{H}$ より大きいため分子全体に電荷の偏りがあり**極性分子**。
- **(c) 二酸化炭素 $\text{CO}_2$**：直線形構造（$\text{O=C=O}$）であり，2つの C=O 結合の極性が逆向きに打ち消し合うため**無極性分子**。
- **(d) メタノール $\text{CH}_3\text{OH}$**：酸素原子まわりの C-O-H 結合が折れ線形であり，電荷の偏りが相殺されないため**極性分子**。
- **(e) メタン $\text{CH}_4$**：正四面体形構造であり，4本の C-H 結合の極性が完全に相殺されるため**無極性分子**。

極性分子は (b) と (d) である。したがって選択肢 $\textcircled{3}$ が正解である。

**【考査考点】**
電気陰性度，結合の極性，分子の幾何学的立体構造と極性の有無。

## 化学 問3：分子間力（ファンデルワールス力・水素結合）と沸点の比較

**【公式正解】**
正解：$\textcircled{1}$（a < b < c）

**【詳細推導・解答プロセス】**
分子量が同程度の物質では，分子間に働く引力の強さによって沸点が決まる：
1. **(a) エタン $\text{C}_2\text{H}_6$（分子量 30）**：
無極性分子であり，分子間には弱い分散力（ファンデルワールス力）のみが働くため，沸点は最も低い（約 $-89^\circ\text{C}$）。
2. **(b) ホルムアルデヒド $\text{HCHO}$（分子量 30）**：
カルボニル基（$\text{C=O}$）をもつ極性分子であり，ファンデルワールス力に加えて双極子間力が働くため，エタンより沸点が高い（約 $-19^\circ\text{C}$）。
3. **(c) メタノール $\text{CH}_3\text{OH}$（分子量 32）**：
ヒドロキシ基（$\text{-OH}$）をもち，分子間に強力な**水素結合**を形成するため，沸点は著しく高くなる（約 $65^\circ\text{C}$）。

したがって，沸点の低い順は $\text{a} < \text{b} < \text{c}$ であり，選択肢 $\textcircled{1}$ が正解である。

**【考査考点】**
分子間力（ファンデルワールス力，双極子相互作用，水素結合）と物質の物理的性質（沸点）の相関。

## 化学 問5：一定質量中に含まれる原子総数の比較

**【題目大意】**
与えられた物質 $\textcircled{1}$〜$\textcircled{4}$ のうち，$10\text{ g}$ 中に含まれる原子の総数が最も多いものを選ぶ。

**【公式正解】**
正解：$\textcircled{4}$（$\text{NH}_3$）

**【詳細推導・解答プロセス】**
物質の分子量を $M$，1分子に含まれる原子の数を $n$ とすると，$10\text{ g}$ 中に含まれる原子の物質量は $\frac{10}{M} \times n$ [mol] である。
各選択肢を計算する：
- $\textcircled{1}$ $\text{CO}_2$：分子量 $M = 12 + 16 \times 2 = 44$，$n = 3$。
  $$\frac{10}{44} \times 3 = \frac{30}{44} \approx 0.682\text{ mol}$$
- $\textcircled{2}$ $\text{H}_2\text{S}$：分子量 $M = 1.0 \times 2 + 32 = 34$，$n = 3$。
  $$\frac{10}{34} \times 3 = \frac{30}{34} \approx 0.882\text{ mol}$$
- $\textcircled{3}$ $\text{N}_2$：分子量 $M = 14 \times 2 = 28$，$n = 2$。
  $$\frac{10}{28} \times 2 = \frac{20}{28} \approx 0.714\text{ mol}$$
- $\textcircled{4}$ $\text{NH}_3$：分子量 $M = 14 + 1.0 \times 3 = 17$，$n = 4$。
  $$\frac{10}{17} \times 4 = \frac{40}{17} \approx 2.35\text{ mol}$$

比較すると $\text{NH}_3$ が圧倒的に多く，含まれる原子総数が最大である。したがって選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
物質量（モル）の計算，分子量と構成原子数の関係，定量的化学計算。

## 化学 問6：混合気体の体積・質量とモル比の算出

**【題目大意】**
標準状態で水素 $\text{H}_2$ と窒素 $\text{N}_2$ の混合気体 $224\text{ mL}$ の質量が $107\text{ mg}$ であった。
水素と窒素のモル比（$\text{H}_2 : \text{N}_2$）を求める。

**【公式正解】**
正解：$\textcircled{4}$（2:1）

**【詳細推導・解答プロセス】**
1. **混合気体の全物質量**：
標準状態における理想気体のモル体積は $22.4\text{ L/mol} = 22400\text{ mL/mol}$ であるから：
$$n_{\text{total}} = \frac{224\text{ mL}}{22400\text{ mL/mol}} = 0.0100\text{ mol}$$

2. **平均分子量の計算**：
全質量は $107\text{ mg} = 0.107\text{ g}$ であるから：
$$\bar{M} = \frac{0.107\text{ g}}{0.0100\text{ mol}} = 10.7\text{ g/mol}$$

3. **モル比の決定**：
水素 $\text{H}_2$ のモル分率を $x$ とすると，窒素 $\text{N}_2$ のモル分率は $1 - x$ である。
$$2.0 x + 28 (1 - x) = 10.7$$
$$2.0 x + 28 - 28 x = 10.7$$
$$26 x = 28 - 10.7 = 17.3 \implies x = \frac{17.3}{26} \approx 0.665$$
したがって窒素のモル分率は：
$$1 - x = 1 - 0.665 = 0.335$$
モル比は：
$$\text{H}_2 : \text{N}_2 = 0.665 : 0.335 \approx 2 : 1$$
これは選択肢 $\textcircled{4}$ に合致する。

**【考査考点】**
アボガドロの法則，混合気体の平均分子量，モル分率の連立関係。

## 化学 問7：酸と塩基の中和反応と混合溶液のpH比較

**【題目大意】**
$0.10\text{ mol/L}$ の酸 A $10\text{ mL}$ と $0.10\text{ mol/L}$ の塩基 B $10\text{ mL}$ を混合したとき，最も pH が小さくなる（最も酸性が強い）組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{3}$（酸 A：硫酸 $\text{H}_2\text{SO}_4$，塩基 B：水酸化ナトリウム $\text{NaOH}$）

**【詳細推導・解答プロセス】**
各溶質の物質量は $0.10\text{ mol/L} \times 0.010\text{ L} = 1.0 \times 10^{-3}\text{ mol}$ である。
- $\textcircled{1}$ $\text{HCl} + \text{NaOH}$：1価の強酸と1価の強塩基が過不足なく中和し，中性の塩 $\text{NaCl}$ を生じるため $\text{pH} = 7$。
- $\textcircled{2}$ $\text{CH}_3\text{COOH} + \text{NaOH}$：弱酸と強塩基が過不足なく中和し，塩の加水分解により塩基性を示す（$\text{pH} > 7$）。
- $\textcircled{3}$ $\text{H}_2\text{SO}_4 + \text{NaOH}$：硫酸は2価の強酸であるため供給できる $\text{H}^+$ は $2.0 \times 10^{-3}\text{ mol}$，$\text{NaOH}$ は $1.0 \times 10^{-3}\text{ mol}$ である。中和後に $\text{H}^+$ が $1.0 \times 10^{-3}\text{ mol}$ 過剰に残り，強酸性を示す（$[\text{H}^+] = \frac{1.0 \times 10^{-3}\text{ mol}}{0.020\text{ L}} = 0.050\text{ mol/L} \implies \text{pH} \approx 1.3$）。
- $\textcircled{4}$ $\text{HCl} + \text{Na}_2\text{CO}_3$：強酸と弱酸の塩の反応で，塩基性側の性質が残り pH は酸性度として極めて高いわけではない。

したがって，最も pH が小さい（最も強い酸性）のは選択肢 $\textcircled{3}$ である。

**【考査考点】**
酸・塩基の価数と中和反応の量的関係，過剰イオンによる液性の判定と pH。

## 化学 問8：食塩水（NaCl水溶液）の電気分解における電極反応

**【題目大意】**
塩化ナトリウム水溶液 $\text{NaCl aq}$ の電気分解に関する記述として正しいものを選ぶ。

**【公式正解】**
正解：$\textcircled{2}$（塩化物イオン $\text{Cl}^-$ の濃度が減少する）

**【詳細推導・解答プロセス】**
$\text{NaCl}$ 水溶液を電気分解するときの両極の反応式は以下の通りである：
- **陽極（アノード，酸化反応）**：
  $$2\text{Cl}^- \to \text{Cl}_2 \uparrow + 2e^-$$
  塩化物イオン $\text{Cl}^-$ が酸化されて塩素気体 $\text{Cl}_2$ が発生し，溶液中の $\text{Cl}^-$ の物質量および濃度は**減少する**。
- **陰極（カソード，還元反応）**：
  $$2\text{H}_2\text{O} + 2e^- \to \text{H}_2 \uparrow + 2\text{OH}^-$$
  水分子が還元されて水素気体 $\text{H}_2$ が発生し，$\text{OH}^-$ が生成する。
- ナトリウムイオン $\text{Na}^+$ は反応に関与せず，溶液中の物質量は変化しない（水が電気分解で減少するため濃度自体はむしろ微増）。

したがって，選択肢 $\textcircled{2}$ の「塩化物イオン $\text{Cl}^-$ の濃度が減少する」が正しい。

**【考査考点】**
食塩水電解の電極反応，酸化還元反応，イオン濃度の時間変化。

## 化学 問9：ルシャトリエの原理と反応速度論（アンモニア合成）

**【題目大意】**
アンモニア合成反応 $\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3$（発熱反応）において，同じ圧力のもとで温度を上げたときのアンモニア生成量と時間の関係を表すグラフを選ぶ。

**【公式正解】**
正解：$\textcircled{1}$

**【詳細推導・解答プロセス】**
1. **反応速度の観点（初期の傾き）**：
温度が上昇すると，分子の熱運動が激しくなり活性化エネルギーを超える衝突頻度が増加するため，正逆両方の反応速度が大きくなる。
したがって，反応初期の立ち上がり（傾き）は元の温度の破線よりも**急峻**になり，平衡到達時間が短くなる。

2. **化学平衡の観点（平衡到達時の生成量）**：
アンモニア生成反応は発熱反応（$\Delta H < 0$）である：
$$\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3 + 92\text{ kJ}$$
ルシャトリエの原理より，温度を上げると熱を吸収する方向（逆反応，左向き）に平衡が移動する。
したがって，平衡状態におけるアンモニアの生成量（飽和値）は元の温度よりも**減少する**。

以上より，グラフの特徴は「初期の立ち上がりが速く，最終的なプラトー（平衡値）が元の破線より低い」ものとなり，選択肢 $\textcircled{1}$ が合致する。

**【考査考点】**
ルシャトリエの原理（温度と平衡移動），アレニウスの式に基づく反応速度と温度の関係の統合的理解。

## 化学 問10：混合気体の完全燃焼熱とメタン物質量の計算

**【題目大意】**
メタン $\text{CH}_4$ とエタン $\text{C}_2\text{H}_6$ の燃焼熱はそれぞれ $890\text{ kJ/mol}, 1560\text{ kJ/mol}$ である。
標準状態で混合気体 $2.24\text{ L}$ を完全燃焼させたところ $142\text{ kJ}$ の発熱があった。メタンの物質量を求める。

**【公式正解】**
正解：$\textcircled{3}$（0.021 mol）

**【詳細推導・解答プロセス】**
混合気体の全物質量は：
$$n_{\text{total}} = \frac{2.24\text{ L}}{22.4\text{ L/mol}} = 0.100\text{ mol}$$
メタンの物質量を $x$ [mol] とおくと，エタンの物質量は $(0.100 - x)$ [mol] である。
全体の発生熱量は：
$$890x + 1560(0.100 - x) = 142$$
$$890x + 156 - 1560x = 142$$
$$-670x = 142 - 156 = -14$$
$$x = \frac{14}{670} \approx 0.02089\dots \approx 0.021\text{ mol}$$
したがって，メタンの物質量は $0.021\text{ mol}$ であり，選択肢 $\textcircled{3}$ が正解である。

**【考査考点】**
燃焼熱の定義，熱化学方程式の量的関係，連立方程式による成分分析。

## 化学 問12：金属 Cu, Fe, Zn の酸・塩基との反応性と不動態

**【題目大意】**
金属 Cu, Fe, Zn を記述 (a)〜(c) に照らして同定する。

**【公式正解】**
正解：$\textcircled{6}$（a: Zn, b: Fe, c: Cu）

**【詳細推導・解答プロセス】**
各記述に対応する金属を検証する：
- **(a) $\text{NaOH aq}$ に $\text{H}_2$ を発生して溶ける**：
  酸にも強塩基にも溶ける**両性金属**の特徴である。Cu, Fe, Zn のうち両性金属は **Zn** である（テトラヒドロキシド亜鉛(II)酸イオン $[\text{Zn(OH)}_4]^{2-}$ を形成）。
- **(b) 濃硝酸に溶けないが希硫酸に水素を出して溶ける**：
  濃硝酸に触れると表面に緻密な酸化被膜をつくり反応が停止する**不動態（Al, Fe, Ni）**の性質である。したがってこの金属は **Fe** である。
- **(c) 希硫酸に溶けないが熱濃硫酸に $\text{SO}_2$ を発生して溶ける**：
  水素よりイオン化傾向が小さく，酸化力をもつ熱濃硫酸や硝酸としか反応しない金属である。したがってこの金属は **Cu** である。

したがって，$a = \text{Zn}, b = \text{Fe}, c = \text{Cu}$ となり，選択肢 $\textcircled{6}$ が正解である。

**【考査考点】**
金属のイオン化傾向，両性元素の反応性，不動態の形成，酸化性酸との反応。

- $\textcircled{2}$ 正しい：$\text{Cl}_2 + \text{H}_2\text{O} \rightleftharpoons \text{HCl} + \text{HClO}$ の反応により，酸性を示す。
- $\textcircled{3}$ 正しい：$\text{Cl}_2$ の酸化力により $\text{I}^-$ が酸化されて $\text{I}_2$ が遊離し，デンプンとヨウ素デンプン反応を起こして青紫色になる。
- $\textcircled{4}$ 正しい：ハロゲン単体の酸化力は $\text{Cl}_2 > \text{Br}_2$ であるため，$\text{Cl}_2 + 2\text{Br}^- \to 2\text{Cl}^- + \text{Br}_2$ の酸化還元反応が進行する。
- $\textcircled{5}$ **誤り**：ハロゲン化水素のうち，フッ化水素 $\text{HF}$ のみ水素結合や結合エネルギーの大きさから水中で電離しにくく**弱酸**であるが，$\text{HCl}, \text{HBr}, \text{HI}$ はすべて水中でほぼ完全に電離する**強酸**である（酸の強さは $\text{HF} \ll \text{HCl} < \text{HBr} < \text{HI}$）。

したがって選択肢 $\textcircled{5}$ が正解である。

**【考査考点】**
ハロゲンの酸化力の序列，ハロゲン化水素の水溶液の酸の強さの比較。

## 化学 問14：金属イオンの系統分離（沈殿試薬と分離手順）

**【題目大意】**
$\text{Ca}^{2+}, \text{Fe}^{3+}, \text{Zn}^{2+}$ を含む水溶液の系統分離実験において，沈殿 (a)〜(c) に含まれるイオンの組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{4}$（a: $\text{Fe}^{3+}$, b: $\text{Zn}^{2+}$, c: $\text{Ca}^{2+}$）

**【詳細推導・解答プロセス】**
1. **過剰のアンモニア水を加える**：
- $\text{Fe}^{3+}$ は水酸化鉄(III) $\text{Fe(OH)}_3$ の赤褐色沈殿を生じる。
- $\text{Zn}^{2+}$ は最初沈殿するが，過剰のアンモニアによってテトラアンミン亜鉛(II)イオン $[\text{Zn(NH}_3)_4]^{2+}$ 錯イオンとなって再溶解する。
- $\text{Ca}^{2+}$ はアンモニア水では沈殿しない。
したがって，赤褐色沈殿 (a) は $\text{Fe}^{3+}$ である。

2. **ろ液に硫化水素 $\text{H}_2\text{S}$ を通じる**：
ろ液はアンモニアにより塩基性である。塩基性条件下では $\text{Zn}^{2+}$ が硫化亜鉛 $\text{ZnS}$ の白色沈殿 (b) として沈殿する（$\text{Ca}^{2+}$ の硫化物は水溶性のため沈殿しない）。
したがって，白色沈殿 (b) は $\text{Zn}^{2+}$ である。

3. **ろ液に炭酸アンモニウム水溶液を加える**：
残った $\text{Ca}^{2+}$ は炭酸カルシウム $\text{CaCO}_3$ の白色沈殿 (c) を生じる。
したがって，沈殿 (c) は $\text{Ca}^{2+}$ である。

組み合わせは $\text{a: } \text{Fe}^{3+}, \text{b: } \text{Zn}^{2+}, \text{c: } \text{Ca}^{2+}$ であり，選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
金属イオンの系統分析，錯イオン形成による再溶解，液性による硫化物沈殿の分別，炭酸塩の沈殿。

## 化学 問15：金属と希酸の反応における水素発生質量の計算

**【題目大意】**
$1.3\text{ g}$ の亜鉛 $\text{Zn}$ を希硫酸に完全に溶かしたとき，発生する水素 $\text{H}_2$ の質量 [mg] を求める。

**【公式正解】**
正解：$\textcircled{3}$（40 mg）

**【詳細推導・解答プロセス】**
化学反応式は：
$$\text{Zn} + \text{H}_2\text{SO}_4 \to \text{ZnSO}_4 + \text{H}_2$$
亜鉛の原子量は $65$ であるから，$1.3\text{ g}$ の亜鉛の物質量は：
$$n_{\text{Zn}} = \frac{1.3\text{ g}}{65\text{ g/mol}} = 0.020\text{ mol}$$
反応式の係数比より，発生する水素 $\text{H}_2$ の物質量は亜鉛と等しく $0.020\text{ mol}$ である。
水素分子のモル質量は $2.0\text{ g/mol}$ であるから：
$$m_{\text{H}_2} = 0.020\text{ mol} \times 2.0\text{ g/mol} = 0.040\text{ g} = 40\text{ mg}$$
したがって，選択肢 $\textcircled{3}$ が正解である。

**【考査考点】**
化学反応式の量的関係，モル計算，質量の単位換算（g から mg）。

## 化学 問17：アルコールと金属ナトリウムの反応および構造異性体の決定

**【題目大意】**
一般式 $\text{C}_n\text{H}_{2n+2}\text{O}$ の化合物 $7.4\text{ g}$ に十分量の Na を反応させたところ，標準状態で $1.12\text{ L}$ の $\text{H}_2$ が発生した。
$n$ の値と，Na と反応する構造異性体（アルコール）の数を求める。

**【公式正解】**
正解：$\textcircled{5}$（$n = 4$，化合物の数 $= 4$）

**【詳細推導・解答プロセス】**
1. **$n$ の決定**：
$\text{C}_n\text{H}_{2n+2}\text{O}$ は1価アルコールまたはエーテルである。Na と反応して水素を発生するのはアルコールである：
$$2\text{R-OH} + 2\text{Na} \to 2\text{R-ONa} + \text{H}_2$$
発生した水素の物質量は：
$$n_{\text{H}_2} = \frac{1.12\text{ L}}{22.4\text{ L/mol}} = 0.0500\text{ mol}$$
反応したアルコールの物質量はその2倍であるから：
$$n_{\text{alcohol}} = 2 \times 0.0500 = 0.100\text{ mol}$$
アルコールのモル質量は：
$$M = \frac{7.4\text{ g}}{0.100\text{ mol}} = 74\text{ g/mol}$$
$\text{C}_n\text{H}_{2n+2}\text{O}$ より：
$$12n + (2n + 2) + 16 = 14n + 18 = 74 \implies 14n = 56 \implies n = 4$$

2. **アルコールの構造異性体の数**：
$\text{C}_4\text{H}_{10}\text{O}$ のうち，ヒドロキシ基をもつアルコールの構造異性体は以下の4種である：
- 1-ブタノール：$\text{CH}_3\text{CH}_2\text{CH}_2\text{CH}_2\text{OH}$
- 2-ブタノール：$\text{CH}_3\text{CH}_2\text{CH(OH)CH}_3$
- 2-メチル-1-プロパノール：$(\text{CH}_3)_2\text{CHCH}_2\text{OH}$
- 2-メチル-2-プロパノール：$(\text{CH}_3)_3\text{C-OH}$

したがって，$n = 4$，化合物の数 $= 4$ であり，選択肢 $\textcircled{5}$ が正解である。

**【考査考点】**
アルコールとナトリウムの反応の量的関係，分子式の決定，炭素骨格と官能基の位置による構造異性体の網羅的列挙。

## 化学 問20：燃焼生成物の物質量からの炭化水素分子式の決定

**【題目大意】**
炭化水素 $0.5\text{ mol}$ を完全燃焼させたところ，二酸化炭素 $1.5\text{ mol}$ と水 $1.0\text{ mol}$ が生成した。分子式を求める。

**【公式正解】**
正解：$\textcircled{4}$（$\text{C}_3\text{H}_4$）

**【詳細推導・解答プロセス】**
炭化水素の分子式を $\text{C}_x\text{H}_y$ とおく。
完全燃焼の化学反応式は：
$$\text{C}_x\text{H}_y + \left(x + \frac{y}{4}\right)\text{O}_2 \to x\,\text{CO}_2 + \frac{y}{2}\,\text{H}_2\text{O}$$
炭化水素 $0.5\text{ mol}$ から：
- 生成した $\text{CO}_2$ の物質量は $0.5x = 1.5\text{ mol} \implies x = 3$
- 生成した $\text{H}_2\text{O}$ の物質量は $0.5 \times \frac{y}{2} = 1.0\text{ mol} \implies 0.25y = 1.0 \implies y = 4$
したがって，分子式は $\text{C}_3\text{H}_4$ である。
これは選択肢 $\textcircled{4}$ に合致する。

**【考査考点】**
炭化水素の元素分析・燃焼計算，物質量の保存則に基づく分子式の決定。
