**【公式正解】**
正解：$\textcircled{1}$（エタン）

**【詳細推導・解答プロセス】**
各分子の共有結合に使われる価電子数を数える：
- $\textcircled{1}$ エタン C₂H₆：C-C結合1本(2個) + C-H結合6本(12個) = 14個
- $\textcircled{2}$ エチレン C₂H₄：C=C二重結合(4個) + C-H結合4本(8個) = 12個
- $\textcircled{3}$ 窒素 N₂：N≡N三重結合 = 6個

しかし、実際にはCO₂の共有結合電子数 = 8個。
- $\textcircled{5}$ 水 H₂O：O-H結合2本 = 4個

エタンが最も多い（14個）ので $\textcircled{1}$ が正解。

**【考査考点】**

## 化学 問3：非共有電子対の数

**【題目大意】**

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
各分子の中心原子の電子配置を考える：
- **CH₄**（メタン）：炭素は4個の価電子をすべて共有結合に使い，非共有電子対は **0組**。
- **H₂O**（水）：酸素の6個の価電子のうち2個が共有結合に使われ，残り4個が **2組** の非共有電子対を形成。

したがって CH₄: 0, H₂O: 2, NH₃: 1 の組み合わせが正解で $\textcircled{3}$。

**【考査考点】**
非共有電子対（孤立電子対），ルイス構造式。

## 化学 問7：燃焼熱と反応熱の計算

**【題目大意】**
炭素 1.00 mol が燃焼して 0.500 mol の CO と 0.500 mol の CO₂ が生成したとき，発生する熱量を求める。

**【公式正解】**
正解：$\textcircled{2}$（253 kJ）

**【詳細推導・解答プロセス】**
ヘスの法則を適用する：
- C + O₂ → CO₂：$\Delta H_1 = -394$ kJ/mol
- C + ½O₂ → CO：$\Delta H_2 = -394 + 283 = -111$ kJ/mol（ヘスの法則より）

1.00 mol C → 0.500 mol CO + 0.500 mol CO₂：
$$Q = 0.500 \times 394 + 0.500 \times 111 = 197 + 55.5 = 252.5 \approx 253 \text{ kJ}$$

より正確には：C → CO の反応熱は $\Delta H = -(394 - 283) = -111$ kJ/mol。
$$Q = 0.500 \times 394 + 0.500 \times 111 = 252.5 \text{ kJ}$$

これは選択肢 $\textcircled{2}$（253 kJ）に最も近い。

**【考査考点】**
ヘスの法則，燃焼熱，反応熱の計算。

## 化学 問9：理想気体の温度-圧力グラフ

**【題目大意】**
体積が変わらない容器に封じこめた理想気体の温度 $T$ [K] と圧力 $P$ [Pa] との関係のグラフを選ぶ。

**【公式正解】**
正解：$\textcircled{5}$

**【詳細推導・解答プロセス】**
定容変化において $PV = nRT$ より：
$$P = \frac{nR}{V} T$$
これは $P$ と $T$（絶対温度）の比例関係であり，原点を通る直線である。
グラフの横軸が絶対温度 $T$ [K] の場合は原点を通る正比例のグラフとなる。
$\textcircled{5}$ が正解。

**【考査考点】**
シャルルの法則，理想気体の状態方程式。

## 化学 問10：鉛蓄電池の放電時の質量変化

**【題目大意】**
鉛蓄電池の放電時に 10.0 A で 965 秒電流が流れたとき，負極と正極の質量変化を求める。

**【公式正解】**
正解：$\textcircled{1}$

**【詳細推導・解答プロセス】**
電気量：$Q = 10.0 \times 965 = 9650$ C
電子のモル数：$n_e = \frac{9650}{96500} = 0.100$ mol

**負極**：Pb → PbSO₄（2e⁻ 放出）
0.100 mol e⁻ に対して 0.050 mol の Pb が反応。
質量増加 = 0.050 × (303 - 207) = 0.050 × 96 = 4.8 g
（PbSO₄ の式量 303, Pb の原子量 207，SO₄ の式量 96）

**正極**：PbO₂ → PbSO₄（2e⁻ 吸収）
0.100 mol e⁻ に対して 0.050 mol の PbO₂ が反応。
質量増加 = 0.050 × (303 - 239) = 0.050 × 64 = 3.2 g
（PbO₂ の式量 239）

これは選択肢 $\textcircled{1}$ に該当する。

**【考査考点】**
電気化学，ファラデーの法則，鉛蓄電池の反応。

## 化学 問20：芳香族化合物の呈色反応（FeCl₃）

**【題目大意】**
芳香族化合物(a)〜(e)のうち，FeCl₃水溶液で青〜紫色の呈色反応を示すものの組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{6}$

**【詳細推導・解答プロセス】**
FeCl₃ 水溶液による呈色反応は，**フェノール性ヒドロキシ基**（-OH が直接ベンゼン環に結合）をもつ化合物に対して起こる。

各化合物を検証する：
- (a) ベンジルアルコール CH₂OH-C₆H₅：アルコール性OH（ベンゼン環に直接結合していない）→ **反応しない**
- (b) 安息香酸 C₆H₅COOH：カルボキシ基 → **反応しない**
- (c) フェノール C₆H₅OH：フェノール性OH → **呈色する** ✓
- (d) 酢酸フェニル C₆H₅OCOCH₃：エステル結合（OH基なし）→ **反応しない**
- (e) サリチル酸メチル：フェノール性OHをもつ → **呈色する** ✓

したがって (c) と (e) の組み合わせが正解で $\textcircled{6}$。

**【考査考点】**
フェノール性ヒドロキシ基の検出反応，FeCl₃呈色反応。
