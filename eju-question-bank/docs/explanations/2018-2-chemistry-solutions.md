## 問1：電子配置と周期表における同族元素の判定

**【考査考点】**：電子配置（K, L, M 殻）の解読, 原子番号と元素の同定, 最外殻電子（価電子）数と同族元素（希ガス元素）の共通性

**【題目大意】**
電子配置が表で与えられた原子 a～d のうち、周期表で同じ族（同族元素）に属する組み合わせを選べ。
- a：K(2), L(0), M(0)
- b：K(2), L(2), M(0)
- c：K(2), L(8), M(6)
- d：K(2), L(8), M(8)

**【公式正解】**：$\textcircled{3}$（a, d）

**【詳細推導・解答プロセス】**
各原子の全電子数から原子番号と元素を特定する：
1. **a**：全電子数 2 $\implies$ 原子番号 2 のヘリウム $\text{He}$（第1周期 18族、閉殻配置）。
2. **b**：全電子数 4 $\implies$ 原子番号 4 のベリリウム $\text{Be}$（第2周期 2族、アルカリ土類金属類）。
3. **c**：全電子数 16 $\implies$ 原子番号 16 の硫黄 $\text{S}$（第3周期 16族、酸素族）。
4. **d**：全電子数 18 $\implies$ 原子番号 18 のアルゴン $\text{Ar}$（第3周期 18族、閉殻配置）。

ヘリウム $\text{He}$（a）とアルゴン $\text{Ar}$（d）は、ともに周期表の **第18族（希ガス / 貴ガス元素）** に属する同族元素である。
よって、正解は選択肢 $\textcircled{3}$ である。

## 問2：第2周期元素の性質（イオン化エネルギー・陰イオン・三重結合）

**【考査考点】**：第2周期元素（Li～Ne）の第一イオン化エネルギーの周期性, 2価の陰イオン（$O^{2-}$）と希ガス配置, 窒素分子（$N_2$）の三重結合

**【題目大意】**
第2周期元素（Li, Be, B, C, N, O, F, Ne）について、記述 (a)～(c) にあてはまる元素の組み合わせを選べ。
(a) 原子の第一イオン化エネルギーが最も大きいもの
(b) 2価の陰イオンが希ガス型電子配置となるもの
(c) 同じ原子同士で三重結合をもつ二原子分子をつくるもの

**【公式正解】**：$\textcircled{6}$（a：Ne、b：O、c：N）

**【詳細推導・解答プロセス】**
1. **記述 (a) の検討**：
   同周期の典型元素では、原子番号の増加（有効核電荷の増加）とともに第一イオン化エネルギーは概ね増加し、閉殻構造をもつ希ガスで最大となる。
   第2周期で最も第一イオン化エネルギーが大きい元素は **ネオン $\text{Ne}$** である。
2. **記述 (b) の検討**：
   最外殻電子数が 6（16族）の元素は、2 個の電子を受け取って 2 価の陰イオン（$-2$）となり、ネオン型電子配置をとる。
   第2周期の 16族元素は **酸素 $\text{O}$** である（$\text{O}^{2-}$ は $\text{Ne}$ と同じ電子配置）。
3. **記述 (c) の検討**：
   同種原子同士で三重結合を形成する二原子分子は、価電子を 5 個もつ 15族の **窒素 $\text{N}$** である（$\text{N} \equiv \text{N}$ 分子）。
以上より、a は $\text{Ne}$、b は $\text{O}$、c は $\text{N}$ である。
よって、正解は選択肢 $\textcircled{6}$ である。

## 問3：金属酸化物の組成式の決定

**【考査考点】**：質量保存の法則による酸素質量の算出, 物質量比（モル比）の計算と整数比への変換

**【題目大意】**
原子量 51 の金属 M の酸化物 $1.82\text{ g}$ 中に、$1.02\text{ g}$ の金属 M が含まれていた。
この酸化物の組成式を求めよ（$\text{O} = 16$ とする）。

**【公式正解】**：$\textcircled{5}$（$\text{M}_2\text{O}_5$）

**【詳細推導・解答プロセス】**
1. **各構成元素の質量の算出**：
   - 金属 M の質量：$m_{\text{M}} = 1.02\text{ g}$
   - 酸素 O の質量：$m_{\text{O}} = 1.82\text{ g} - 1.02\text{ g} = 0.80\text{ g}$
2. **物質量（モル数）の計算**：
   - 金属 M の物質量：
     $$n_{\text{M}} = \frac{1.02\text{ g}}{51\text{ g/mol}} = 0.020\text{ mol}$$
   - 酸素 O の物質量：
     $$n_{\text{O}} = \frac{0.80\text{ g}}{16\text{ g/mol}} = 0.050\text{ mol}$$
3. **原子数の整数比の決定**：
   $$n_{\text{M}} : n_{\text{O}} = 0.020 : 0.050 = 2 : 5$$
   したがって、酸化物の組成式は **$\text{M}_2\text{O}_5$**（五酸化二バナジウム $\text{V}_2\text{O}_5$ に相当）である。
よって、正解は選択肢 $\textcircled{5}$ である。

## 問4：標準状態における二酸化炭素中の全原子数の計算

**【考査考点】**：気体のモル体積 $22.4\text{ L/mol}$ による物質量の導出, 3原子分子に含まれる構成原子数の積算, アボガドロ定数 $N_A = 6.02 \times 10^{23}\text{ /mol}$

**【題目大意】**
標準状態（$0^\circ\text{C}, 1.01 \times 10^5\text{ Pa}$）において体積 $5.6\text{ L}$ の二酸化炭素 $\text{CO}_2$ に含まれるすべての原子の数を求めよ。

**【公式正解】**：$\textcircled{3}$（$4.5 \times 10^{23}$）

**【詳細推導・解答プロセス】**
1. **$\text{CO}_2$ 分子の物質量の計算**：
   標準状態における理想気体のモル体積は $22.4\text{ L/mol}$ であるから：
   $$n_{\text{CO}_2} = \frac{5.6\text{ L}}{22.4\text{ L/mol}} = 0.25\text{ mol}$$
2. **全原子数の計算**：
   二酸化炭素分子 1 個（$\text{CO}_2$）は、炭素原子 1 個と酸素原子 2 個の計 3 個の原子から構成される。
   したがって、含まれる全原子の物質量は：
   $$n_{\text{atoms}} = 0.25\text{ mol} \times 3 = 0.75\text{ mol}$$
   アボガドロ定数 $N_A = 6.02 \times 10^{23}\text{ /mol}$ を掛けると：
   $$N = 0.75\text{ mol} \times 6.02 \times 10^{23}\text{ /mol} = 4.515 \times 10^{23} \approx 4.5 \times 10^{23}$$
よって、正解は選択肢 $\textcircled{3}$ である。

## 問5：酸化数の判定（硫黄の最低酸化数と窒素の最高酸化数）

**【考査考点】**：酸化数の計算規則, 硫黄 S のとり得る酸化数範囲（$-2 \sim +6$）, 窒素 N のとり得る酸化数範囲（$-3 \sim +5$）

**【題目大意】**
硫黄原子 S の酸化数が最低のもの（$-2$）と、窒素原子 N の酸化数が最高のもの（$+5$）の組み合わせを選べ。

**【公式正解】**：$\textcircled{4}$（$\text{H}_2\text{S}, \text{NO}_3^-$）

**【詳細推導・解答プロセス】**
1. **硫黄原子 S の酸化数の比較**：
   - $\text{SO}_4^{2-}$：$\text{S} + 4(-2) = -2 \implies \text{S} = +6$
   - $\text{SO}_2$：$\text{S} + 2(-2) = 0 \implies \text{S} = +4$
   - $\text{S}_8$（単体）：$\text{S} = 0$
   - $\text{S}_2\text{O}_3^{2-}$：$2\text{S} + 3(-2) = -2 \implies \text{S} = +2$
   - $\text{H}_2\text{S}$ および $\text{Na}_2\text{S}$：$2(+1) + \text{S} = 0 \implies \text{S} = -2$
   硫黄の最低酸化数は **$-2$**（$\text{H}_2\text{S}$ または $\text{Na}_2\text{S}$）である。
2. **窒素原子 N の酸化数の比較**：
   - $\text{NH}_3$：$\text{N} + 3(+1) = 0 \implies \text{N} = -3$
   - $\text{N}_2$（単体）：$\text{N} = 0$
   - $\text{NO}_2^-$：$\text{N} + 2(-2) = -1 \implies \text{N} = +3$
   - $\text{NO}_2$：$\text{N} + 2(-2) = 0 \implies \text{N} = +4$
   - $\text{NO}_3^-$ および $\text{HNO}_3$：$\text{N} + 3(-2) = -1 \implies \text{N} = +5$
   窒素の最高酸化数は **$+5$**（$\text{NO}_3^-$ または $\text{HNO}_3$）である。
3. **選択肢の組み合わせの選定**：
   $\text{S}$ が $-2$ で $\text{N}$ が $+5$ となっている組み合わせは、選択肢 $\textcircled{4}$（$\text{H}_2\text{S}, \text{NO}_3^-$）である。
よって、正解は選択肢 $\textcircled{4}$ である。

## 問6：ブレンステッド・ローリーの定義による塩基の判定

**【考査考点】**：ブレンステッド・ローリーの酸塩基定義（酸＝水素イオン供与体、塩基＝水素イオン受容体）, 反応前後でのプロトン（$H^+$）の移動追跡

**【題目大意】**
反応式 (a)～(e) のうち、下線部の物質がブレンステッド・ローリーの定義による「塩基」としてはたらいているもの 2 つの組み合わせを選べ。
(a) $\underline{\text{Mg}} + 2\text{HCl} \longrightarrow \text{MgCl}_2 + \text{H}_2$
(b) $\text{HCl} + \underline{\text{H}_2\text{O}} \longrightarrow \text{H}_3\text{O}^+ + \text{Cl}^-$
(c) $\underline{\text{NH}_4^+} + \text{H}_2\text{O} \longrightarrow \text{NH}_3 + \text{H}_3\text{O}^+$
(d) $\underline{\text{HCO}_3^-} + \text{OH}^- \longrightarrow \text{H}_2\text{O} + \text{CO}_3^{2-}$
(e) $\underline{\text{CH}_3\text{COO}^-} + \text{H}_2\text{O} \longrightarrow \text{CH}_3\text{COOH} + \text{OH}^-$

**【公式正解】**：$\textcircled{4}$（b, e）

**【詳細推導・解答プロセス】**
ブレンステッド・ローリーの定義において、相手から水素イオン $\text{H}^+$ を受け取る物質を「塩基」、水素イオン $\text{H}^+$ を相手に与える物質を「酸」と呼ぶ。
1. **(a)**：$\text{Mg}$ は電子を失って酸化されている（酸化還元反応）。酸・塩基反応ではない。
2. **(b)**：$\text{H}_2\text{O}$ は $\text{HCl}$ から $\text{H}^+$ を受け取って $\text{H}_3\text{O}^+$ に変化している。したがって、$\text{H}_2\text{O}$ は **塩基** としてはたらいている。
3. **(c)**：$\text{NH}_4^+$ は $\text{H}_2\text{O}$ に $\text{H}^+$ を与えて $\text{NH}_3$ に変化している。したがって、$\text{NH}_4^+$ は **酸** である。
4. **(d)**：$\text{HCO}_3^-$ は $\text{OH}^-$ に $\text{H}^+$ を与えて $\text{CO}_3^{2-}$ に変化している。したがって、$\text{HCO}_3^-$ は **酸** である。
5. **(e)**：$\text{CH}_3\text{COO}^-$ は $\text{H}_2\text{O}$ から $\text{H}^+$ を受け取って $\text{CH}_3\text{COOH}$ に変化している。したがって、$\text{CH}_3\text{COO}^-$ は **塩基** としてはたらいている。

塩基としてはたらいているのは **b と e** である。
よって、正解は選択肢 $\textcircled{4}$ である。

## 問7：希薄溶液の凝固点降下と凝固開始順序の判定

**【考査考点】**：凝固点降下度 $\Delta T_f = K_f m$, 電離度と全溶質粒子数（イオン・分子）の比較, 凝固開始温度（凝固点が高いものほど先に凝固）

**【題目大意】**
水 $100\text{ g}$ に溶質 $10\text{ g}$ を溶かした水溶液 A, B, C を冷却するとき、凝固が始まる順序を求めよ。
- A：尿素 $\text{CO}(\text{NH}_2)_2$ $10\text{ g}$（分子量 60、非電解質）
- B：塩化ナトリウム $\text{NaCl}$ $10\text{ g}$（式量 58.5、強電解質）
- C：塩化カルシウム $\text{CaCl}_2$ $10\text{ g}$（式量 111、強電解質）

**【公式正解】**：$\textcircled{2}$（A $\to$ C $\to$ B）

**【詳細推導・解答プロセス】**
1. **凝固点降下と凝固開始順序**：
   水溶液を冷却するとき、凝固点降下度 $\Delta T_f$ が小さい水溶液ほど凝固点が高く、先に凝固が始まる。
   $\Delta T_f$ は水溶液中の **全溶質粒子の質量モル濃度（総粒子数）** に比例する。
2. **各水溶液中の溶質粒子の物質量の比較（水 $100\text{ g}$ あたり）**：
   - **水溶液 A（尿素）**：
     非電解質であるため、電離しない。
     $$n_A = \frac{10\text{ g}}{60\text{ g/mol}} \approx 0.167\text{ mol}$$
   - **水溶液 B（$\text{NaCl}$）**：
     $\text{NaCl} \to \text{Na}^+ + \text{Cl}^-$（1 分子あたり 2 個のイオンが生じる）。
     $$n_B = \frac{10\text{ g}}{58.5\text{ g/mol}} \times 2 \approx 0.171 \times 2 = 0.342\text{ mol}$$
   - **水溶液 C（$\text{CaCl}_2$）**：
     $\text{CaCl}_2 \to \text{Ca}^{2+} + 2\text{Cl}^-$（1 分子あたり 3 個のイオンが生じる）。
     $$n_C = \frac{10\text{ g}}{111\text{ g/mol}} \times 3 \approx 0.0901 \times 3 = 0.270\text{ mol}$$
3. **粒子数と凝固点の比較**：
   総粒子数の大きさ：$n_A (0.167) < n_C (0.270) < n_B (0.342)$
   したがって、凝固点降下度は $\Delta T_{f, A} < \Delta T_{f, C} < \Delta T_{f, B}$ となる。
   凝固点の高さは $T_{f, A} > T_{f, C} > T_{f, B}$ である。
   冷却していくと、凝固点が高いものから順に凝固するため、開始順は **A $\to$ C $\to$ B** である。
よって、正解は選択肢 $\textcircled{2}$ である。

## 問8：化学平衡の移動（ルシャトリエの原理・不活性気体添加と温度変化）

**【考査考点】**：等温・定圧条件下での不活性気体添加による体積膨張と平衡移動, 温度上昇によるルシャトリエの原理（吸熱方向への移動）と反応熱 $Q$ の正負

**【題目大意】**
可逆気体反応 $a\text{A} + b\text{B} = c\text{C} + Q\text{ [kJ]}$ について以下の実験結果を得た。
(i) 温度・体積一定で Ar を加えても平衡は移動しなかった。
(ii) 温度・全圧一定で Ar を加えたところ、平衡は左に移動した。
(iii) 圧力を一定に保って温度を高くしたところ、平衡は左に移動した。
$a, b, c$ の関係と反応熱 $Q$ の正負を求めよ。

**【公式正解】**：$\textcircled{2}$（$a+b > c, \; Q > 0$）

**【詳細推導・解答プロセス】**
1. **実験 (ii) から係数関係の導出**：
   温度と全圧を一定に保って不活性気体（Ar）を加えると、混合気体の全圧を保つために容器の体積が膨張する。
   体積膨張により、各反応成分 A, B, C の分圧は減少する。
   ルシャトリエの原理により、気体分子数を増やして分圧の減少を緩和する向きに平衡が移動する。
   平衡が左に移動したということは、左辺（原料側）の気体分子数が右辺（生成物側）より多いことを意味する：
   $$a + b > c$$
2. **実験 (iii) から反応熱 $Q$ の正負の決定**：
   温度を高くすると、ルシャトリエの原理により、熱を吸収する向き（吸熱反応の向き）に平衡が移動する。
   温度を上げると平衡が左に移動したことから、逆反応（$\leftarrow$）が吸熱反応であることがわかる。
   したがって、正反応（$\rightarrow$）は発熱反応であり、反応熱 $Q$ は正である：
   $$Q > 0$$
以上より、$a + b > c$ かつ $Q > 0$ である。
よって、正解は選択肢 $\textcircled{2}$ である。

## 問9：直列電解槽におけるファラデーの電気分解の法則

**【考査考点】**：ファラデーの法則 $Q = It$, 流れた電子の物質量 $n(e^-) = \frac{Q}{F}$, 陽極での気体発生量と陰極での金属析出量

**【題目大意】**
陽イオン交換膜で仕切られた NaCl 水溶液槽と $\text{CuSO}_4$ 水溶液槽を $2.00\text{ A}$ で 32 分 10 秒間電気分解した。
電極 I で発生する気体の標準状態における体積 [L] と、電極 IV で析出する金属の質量 [g] を求めよ（$\text{Cu} = 64.0$, $F = 96500\text{ C/mol}$）。

**【公式正解】**：$\textcircled{4}$（気体体積：$0.448\text{ L}$、金属質量：$1.28\text{ g}$）

**【詳細推導・解答プロセス】**
1. **流れた電気量と電子の物質量**：
   - 通電時間：$t = 32\text{ 分} 10\text{ 秒} = 32 \times 60 + 10 = 1930\text{ s}$
   - 流れた総電気量：
     $$Q = I t = 2.00\text{ A} \times 1930\text{ s} = 3860\text{ C}$$
   - 流れた電子の物質量：
     $$n(e^-) = \frac{3860\text{ C}}{96500\text{ C/mol}} = 0.0400\text{ mol}$$
2. **電極 I における気体発生反応（NaCl 水溶液の陽極）**：
   陽極では塩化物イオンが酸化されて塩素ガスが発生する：
   $$2\text{Cl}^- \longrightarrow \text{Cl}_2 + 2e^-$$
   発生する $\text{Cl}_2$ の物質量は：
   $$n(\text{Cl}_2) = \frac{0.0400\text{ mol}}{2} = 0.0200\text{ mol}$$
   標準状態での体積は：
   $$V = 0.0200\text{ mol} \times 22.4\text{ L/mol} = 0.448\text{ L}$$
3. **電極 IV における金属析出反応（$\text{CuSO}_4$ 水溶液の陰極）**：
   陰極では銅(II)イオンが還元されて単体の銅が析出する：
   $$\text{Cu}^{2+} + 2e^- \longrightarrow \text{Cu}$$
   析出する $\text{Cu}$ の物質量は：
   $$n(\text{Cu}) = \frac{0.0400\text{ mol}}{2} = 0.0200\text{ mol}$$
   析出する銅の質量は：
   $$m = 0.0200\text{ mol} \times 64.0\text{ g/mol} = 1.28\text{ g}$$
よって、正解は選択肢 $\textcircled{4}$ である。

## 問10：塩化ナトリウム型結晶格子の密度計算

**【考査考点】**：NaCl 単位格子に含まれるイオン数（$\text{Na}^+ : 4$, $\text{Cl}^- : 4$）, 単位格子の体積 $V = a^3$, 密度公式 $d = \frac{Z \times M}{N_A \times a^3}$

**【題目大意】**
塩化ナトリウム $\text{NaCl}$ の単位格子は一辺 $a = 0.564\text{ nm}$ の立方体である。
$\text{NaCl}$ の密度 [$\text{g/cm}^3$] に最も近い値を求めよ（$0.564^3 = 0.179$, $\text{NaCl} = 58.5$, $N_A = 6.02 \times 10^{23}\text{ /mol}$）。

**【公式正解】**：$\textcircled{4}$（2.2）

**【詳細推導・解答プロセス】**
1. **単位格子中の組成と質量**：
   $\text{NaCl}$ の単位格子中には、$\text{Na}^+$ が 4 個、$\text{Cl}^-$ が 4 個含まれるため、$\text{NaCl}$ の化学式 4 組分が存在する。
   単位格子 1 個あたりの質量 $m$ は：

## 問15：金属イオン（$Al^{3+}, Fe^{3+}, Zn^{2+}$）の系統分離と錯イオン形成

**【考査考点】**：アンモニア水過剰添加における両性錯イオン形成（Znはテトラアンミン亜鉛錯体で溶解、AlとFeは沈殿）, 強塩基（NaOH）過剰添加における両性水酸化物の再溶解（Alはテトラヒドロキシドアルミン酸で溶解、Feは不溶）

**【題目大意】**
$\text{Al}^{3+}, \text{Fe}^{3+}, \text{Zn}^{2+}$ を含む水溶液に操作 A, B を行った。
- 操作 A：過剰のアンモニア水を加え沈殿を除いてろ液 X を得た。
- 操作 B：操作 A の沈殿に過剰の水酸化ナトリウム水溶液を加え沈殿を除いてろ液 Y を得た。
ろ液 X, Y に含まれる金属イオンの組み合わせを選べ。

**【公式正解】**：$\textcircled{5}$（X：$\text{Zn}^{2+}$、Y：$\text{Al}^{3+}$）

**【詳細推導・解答プロセス】**
1. **操作 A（過剰のアンモニア水 $\text{NH}_3\text{aq}$ の添加）**：
   - $\text{Al}^{3+}$ は白色ゲル状沈殿 $\text{Al}(\text{OH})_3$ を生じ、過剰のアンモニア水には再溶解しない。
   - $\text{Fe}^{3+}$ は赤褐色沈殿 $\text{Fe}(\text{OH})_3$ を生じ、過剰のアンモニア水には再溶解しない。
   - $\text{Zn}^{2+}$ は最初白色沈殿 $\text{Zn}(\text{OH})_2$ を生じるが、過剰の $\text{NH}_3$ と錯形成反応を起こして無色のテトラアンミン亜鉛(II)錯イオン $[\text{Zn}(\text{NH}_3)_4]^{2+}$ となって **再溶解する**。
   したがって、沈殿をろ過した **ろ液 X に含まれる金属イオンは $\text{Zn}^{2+}$** である。
2. **操作 B（沈殿への過剰の水酸化ナトリウム水溶液 $\text{NaOHaq}$ の添加）**：
   沈殿は $\text{Al}(\text{OH})_3$ と $\text{Fe}(\text{OH})_3$ の混合物である。
   - $\text{Fe}(\text{OH})_3$ は両性金属ではないため、強塩基を過剰に加えても沈殿のまま残る。
   - $\text{Al}(\text{OH})_3$ は両性金属の水酸化物であるため、強塩基と反応して無色のテトラヒドロキシドアルミン酸イオン $[\text{Al}(\text{OH})_4]^-$ を形成して **再溶解する**。
   したがって、残った沈殿をろ過した **ろ液 Y に含まれる金属イオンは $\text{Al}^{3+}$** である。
以上より、X は $\text{Zn}^{2+}$、Y は $\text{Al}^{3+}$ である。
よって、正解は選択肢 $\textcircled{5}$ である。

   酢酸とエタノールの脱水縮合によって合成される低分子エステル化合物であり、カルボニル基と酸素原子からなる **エステル結合（$-\text{COO}-$）** をもつ。
2. **ポリエチレンテレフタラート（PET）の構造**：
   テレフタル酸（$p$-$\text{C}_6\text{H}_4(\text{COOH})_2$）とエチレングリコール（$\text{HOCH}_2\text{CH}_2\text{OH}$）の重縮合によって得られる代表的な合成高分子（ポリエステル）である。
   その繰り返し単位の中にはエステル結合 **$-\text{COO}-$**（$-\text{C}(=\text{O})-\text{O}-$）が含まれる。
3. **選択肢の比較**：
   $\textcircled{1}$ はエーテル結合、$\textcircled{3}$ はケトン（カルボニル結合）、$\textcircled{5}$ はアミド結合である。
   両者に共通して存在する構造はエステル結合を示す選択肢 $\textcircled{4}$ である。
よって、正解は選択肢 $\textcircled{4}$ である。

## 問20：デンプンとセルロースの構造と性質の比較

**【考査考点】**：天然高分子多糖類の分子式 $(\text{C}_6\text{H}_{10}\text{O}_5)_n$, グリコシド結合の違い（デンプンは $\alpha$-結合、セルロースは $\beta$-結合）, 酸触媒加熱によるグルコースへの完全加水分解

**【題目大意】**
記述 (a)～(d) のうち、デンプンとセルロースの両方にあてはまるものの組み合わせを選べ。
(a) 分子式は $(\text{C}_6\text{H}_{10}\text{O}_5)_n$ で表される。
(b) らせん構造をもつ。
(c) 酸を加えて熱すると、加水分解されてグルコースを生じる。
(d) 還元性があり、銀鏡反応がおこる。

**【公式正解】**：$\textcircled{2}$（a, c）

**【詳細推導・解答プロセス】**
各記述を吟味する：
1. **記述 (a) 正しい**：
   デンプンもセルロースも、多数のグルコース分子（$\text{C}_6\text{H}_{12}\text{O}_6$）が脱水縮合してできた高分子多糖類であり、どちらも分子式（一般式）は **$(\text{C}_6\text{H}_{10}\text{O}_5)_n$** で表される。
2. **記述 (b) 誤り**：
   デンプン（アミロース）は $\alpha-1,4$-グリコシド結合により規則正しい中空の「らせん構造」をとるが、セルロースは $\beta-1,4$-グリコシド結合によりグルコース単位が 180 度反転して直鎖状に伸びたシート状構造をとり、らせん構造はもたない。
3. **記述 (c) 正しい**：
   希硫酸などの酸触媒とともに加熱すると、グリコシド結合が完全に加水分解され、どちらも単糖である **グルコースを生じる**。
4. **記述 (d) 誤り**：
   デンプンやセルロースは重合度が非常に大きく分子量が極めて高いため、末端に存在するわずかなヘミアセタール構造による還元性は実質的に現れず、銀鏡反応は示さない。

両方にあてはまる記述は **a と c** である。
よって、正解は選択肢 $\textcircled{2}$ である。
