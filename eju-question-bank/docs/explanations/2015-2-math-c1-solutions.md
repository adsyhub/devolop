## 大問I 問1：2次関数の動的定義域における最大値・最小値の場合分けと係数決定
- **Local Key**: `math-q-I_1`
- **Answer Ref**: `MATH_C1:I_1`
- **公式正解**: `{'AB': '39', 'C': '3', 'D': '5', 'E': '7', 'F': '5', 'G': '8', 'H': '6', 'I': '5'}`

**【題目大意】**
実数 $a, b$ ($0 < b < 7$) に対し、2次関数 $f(x) = x^2 - 6x + a$ の区間 $b \leq x \leq 7$ における最大値 $M$ と最小値 $m$ を考える。
(1) $b$ の値の範囲によって場合分けし、$M, m$ を求める。
(2) $M = 13, m = 1$ となるときの $a, b$ の値を決定する。

**【公式正解】**
- $\text{AB} = 39$ ($f(x) = (x - 3)^2 + a - 9$)
- $\text{C} = 3$ (境界値 $b = 3$)
- $\text{D} = 5, \text{E} = 7$ ($0 < b \leq 3$ のとき $M = a + 7, m = a - 9$)
- $\text{F} = 5, \text{G} = 8$ ($3 < b < 7$ のとき $M = a + 7, m = b^2 - 6b + a$)
- $\text{H} = 6, \text{I} = 5$ ($a = 6, b = 5$)

**【詳細推導・解答プロセス】**
**(1) 平方完成と頂点・軸の特定**
関数 $f(x)$ を平方完成する：
$$f(x) = x^2 - 6x + a = (x - 3)^2 + a - 9$$
したがって、放物線は下に凸で、軸は直線 $x = 3$、頂点は $(3, a - 9)$ である。
よって、$\text{A} = 3, \text{B} = 9$ (AB = 39) である。

**(2) 場合分けによる最大値 $M$ と最小値 $m$ の導出**
区間の右端は $x = 7$ で固定されている。
端点での値は：
$$f(7) = (7 - 3)^2 + a - 9 = 16 + a - 9 = a + 7$$
軸 $x = 3$ からの距離を比較すると、右端 $x = 7$ までの距離は $7 - 3 = 4$ である。
$0 < b < 7$ より、左端 $b$ から軸 $x = 3$ までの距離は $|b - 3| < 3 < 4$ であるから、常に $f(7) > f(b)$ が成り立つ。
したがって、最大値は常に $x = 7$ でとる：
$$M = f(7) = a + 7 \quad (\textcircled{5})$$

最小値 $m$ については、軸 $x = 3$ が区間 $[b, 7]$ に含まれるかどうかで場合分けが生じる：
(i) $0 < b \leq 3$ のとき（軸 $x = 3$ が区間内に含まれる）：
頂点で最小となるため：
$$m = f(3) = a - 9 \quad (\textcircled{7})$$
したがって、$\text{C} = 3, \text{D} = 5, \text{E} = 7$ である。

(ii) $3 < b < 7$ のとき（軸 $x = 3$ が区間の左外にある）：
区間 $[b, 7]$ において $f(x)$ は単調増加であるから、左端 $x = b$ で最小となる：
$$m = f(b) = b^2 - 6b + a \quad (\textcircled{8})$$
したがって、$\text{F} = 5, \text{G} = 8$ である。

**(3) $M = 13, m = 1$ による $a, b$ の決定**
最大値の条件より：
$$M = a + 7 = 13 \implies a = 6$$
もし場合 (i) $0 < b \leq 3$ ならば、$m = a - 9 = 6 - 9 = -3 \neq 1$ となり不適である。
したがって場合 (ii) $3 < b < 7$ である。
$$m = b^2 - 6b + 6 = 1 \implies b^2 - 6b + 5 = 0$$
$$(b - 1)(b - 5) = 0$$
$3 < b < 7$ より、$b = 5$ である。
よって、$\text{H} = 6, \text{I} = 5$ である。

**【考査考点】**
- 2次関数の軸と動く定義域端点との位置関係による最大・最小の場合分け。
- 軸からの距離の対称性と最大値を与える端点の判定。
- 条件を満たすパラメータの適格性判定（場合分けの前提条件との照合）。

## 大問I 問2：3個のさいころの目に関する事象の個数と和事象の確率
- **Local Key**: `math-q-I_2`
- **Answer Ref**: `MATH_C1:I_2`
- **公式正解**: `{'J': '6', 'KL': '10', 'MN': '15', 'O': '1', 'P': '2', 'Q': '0', 'RSTUV': '23216'}`

**【題目大意】**
大中小3個のさいころの目を $x, y, z$ とし、事象 $A: x = y = z$、$B: x + y + z = 6$、$C: x + y = z$ を定義する。各事象および積事象の起こる場合の数、さらに和事象 $B \cup C$ の起こる確率を求める。

**【公式正解】**
- $\text{J} = 6$ (事象 $A$ は 6 通り)
- $\text{KL} = 10$ (事象 $B$ は 10 通り)
- $\text{MN} = 15$ (事象 $C$ は 15 通り)
- $\text{O} = 1$ ($A \cap B$ は 1 通り)
- $\text{P} = 2$ ($B \cap C$ は 2 通り)
- $\text{Q} = 0$ ($C \cap A$ は 0 通り)
- $\text{RSTUV} = 23216$ ($P(B \cup C) = \frac{23}{216}$)

**【詳細推導・解答プロセス】**
全事象の総数は $6^3 = 216$ 通りである。

**(1) 事象 $A, B, C$ の場合の数**
- 事象 $A$ ($x = y = z$)：
  $(1, 1, 1), (2, 2, 2), \dots, (6, 6, 6)$ の 6 通り。
  よって、$\text{J} = 6$ である。
- 事象 $B$ ($x + y + z = 6$)：
  自然数解 $(x, y, z)$ の個数は、重複組合せ（仕切り棒）の考え方により $\binom{6-1}{3-1} = \binom{5}{2} = 10$ 通り。
  具体的には $(1, 1, 4)$ の並べ替え 3 通り、$(1, 2, 3)$ の並べ替え 6 通り、$(2, 2, 2)$ の 1 通りで、計 $3 + 6 + 1 = 10$ 通り。
  よって、$\text{KL} = 10$ である。
- 事象 $C$ ($x + y = z$)：
  $z \in \{1, 2, 3, 4, 5, 6\}$ に対し、適する $(x, y)$ の個数を数える：
  - $z = 1$：なし（$0$ 通り）
  - $z = 2$：$(1, 1)$ の 1 通り
  - $z = 3$：$(1, 2), (2, 1)$ の 2 通り
  - $z = 4$：$(1, 3), (2, 2), (3, 1)$ の 3 通り
  - $z = 5$：$(1, 4), (2, 3), (3, 2), (4, 1)$ の 4 通り
  - $z = 6$：$(1, 5), (2, 4), (3, 3), (4, 2), (5, 1)$ の 5 通り
  合計：$1 + 2 + 3 + 4 + 5 = 15$ 通り。
  よって、$\text{MN} = 15$ である。

**(2) 積事象の場合の数**
- $A \cap B$：$x = y = z$ かつ $x + y + z = 6 \implies 3x = 6 \implies x = 2$。
  $(2, 2, 2)$ の 1 通りのみ。よって、$\text{O} = 1$ である。
- $B \cap C$：$x + y + z = 6$ かつ $x + y = z$。
  代入すると $z + z = 6 \implies 2z = 6 \implies z = 3$。
  このとき $x + y = 3$ より $(x, y) = (1, 2), (2, 1)$ の 2 通り。
  すなわち $(1, 2, 3), (2, 1, 3)$ の 2 通り。よって、$\text{P} = 2$ である。
- $C \cap A$：$x = y = z$ かつ $x + y = z \implies 2x = x \implies x = 0$。
  さいころの目は $1 \leq x \leq 6$ であるから、解はない。
  0 通り。よって、$\text{Q} = 0$ である。

**(3) 和事象 $B \cup C$ の確率**
包含と排除の原理（加法定理）より：
$$n(B \cup C) = n(B) + n(C) - n(B \cap C) = 10 + 15 - 2 = 23$$
したがって、求める確率は：
$$P(B \cup C) = \frac{23}{216}$$
よって、$\text{RS} = 23, \text{TUV} = 216$ (RSTUV = 23216) である。

**【考査考点】**
- さいころの試行における基本事象の網羅的数え上げ。
- 連立方程式による積事象の共通条件の導出。
- 和事象の確率公式 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ の適用。

## 大問II 問1：絶対値関数の折れ線グラフと最小値をとる条件
- **Local Key**: `math-q-II_1`
- **Answer Ref**: `MATH_C1:II_1`
- **公式正解**: `{'ABC': '231', 'DE': '12', 'FG': '23', 'H': '1', 'IJ': '12', 'KL': '12', 'M': '1'}`

**【題目大意】**
式 $P = |x - 1| + |x - 2| + |x - a|$ が $x = a$ で最小値をとるような実数 $a$ の範囲を、関数 $y = |x - 1| + |x - 2|$ のグラフを考察することによって求める。

**【公式正解】**
- $\text{ABC} = 231$ ($-2x + 3 \quad (x < 1)$)
- $\text{DE} = 12$ ($1 \quad (1 \leq x \leq 2)$)
- $\text{FG} = 23$ ($2x - 3 \quad (2 < x)$)
- $\text{H} = 1, \text{IJ} = 12$ (最小値 1、区間 $1 \leq x \leq 2$)
- $\text{KL} = 12, \text{M} = 1$ ($1 \leq a \leq 2$ で最小値 1)

**【詳細推導・解答プロセス】**
**(1) $y = |x - 1| + |x - 2|$ の区間分け**
- $x < 1$ のとき：$x - 1 < 0, x - 2 < 0$ であるから：
  $$y = -(x - 1) - (x - 2) = -2x + 3$$
  したがって、$\text{A} = 2, \text{B} = 3, \text{C} = 1$ (ABC = 231) である。
- $1 \leq x \leq 2$ のとき：$x - 1 \geq 0, x - 2 \leq 0$ であるから：
  $$y = (x - 1) - (x - 2) = 1$$
  したがって、$\text{D} = 1, \text{E} = 2$ (DE = 12) である。
- $2 < x$ のとき：$x - 1 > 0, x - 2 > 0$ であるから：
  $$y = (x - 1) + (x - 2) = 2x - 3$$
  したがって、$\text{F} = 2, \text{G} = 3$ (FG = 23) である。

**(2) $y$ の最小値と最小値をとる区間**
グラフは $x < 1$ で傾き $-2$ で減少し、$1 \leq x \leq 2$ で一定値 $1$ をとり、$x > 2$ で傾き $2$ で増加する「舟形」の折れ線である。
したがって、$y$ の最小値は $1$ であり、不等式 $1 \leq x \leq 2$ を満たすすべての $x$ でこの値をとる。
よって、$\text{H} = 1, \text{I} = 1, \text{J} = 2$ (IJ = 12) である。

**(3) $P$ が $x = a$ で最小となる条件**
任意の $x$ に対し $|x - a| \geq 0$ であり、等号は $x = a$ のときにのみ成り立つ。
したがって：
$$P(x) = y(x) + |x - a| \geq y(x) \geq 1$$
$x = a$ を代入すると：
$$P(a) = y(a) + |a - a| = y(a)$$
$P(x)$ の大域的最小値が $x = a$ で達成されるためには、$y(a)$ が $y(x)$ の最小値 1 に一致することが必要十分である。
すなわち、$y(a) = 1$ となる $a$ の範囲は：
$$1 \leq a \leq 2$$
このとき、$P$ の最小値は $P(a) = 1$ である。
よって、$\text{K} = 1, \text{L} = 2$ (KL = 12)、$\text{M} = 1$ である。

**【考査考点】**
- 絶対値関数の場合分けによる除去と折れ線グラフの作図。
- 区間における定数関数の最小値特性。
- 不等式 $P(x) \geq y(x)$ を用いた等号成立条件の論理的分析。

## 大問II 問2：最大公約数・最小公倍数と不定方程式（因数分解形）
- **Local Key**: `math-q-II_2`
- **Answer Ref**: `MATH_C1:II_2`
- **公式正解**: `{'N': '3', 'OPQ': '321', 'RST': '237', 'U': '5', 'V': '2', 'WX': '15', 'Y': '6'}`

**【題目大意】**
自然数 $a, b$ の最大公約数は 3 であり、最小公倍数を $\ell$ とする。等式 $3a - 2b = \ell + 3$ $\textcircled{1}$ を満たす自然数 $a, b$ を求める。

**【公式正解】**
- $\text{N} = 3$ ($\ell = 3pq$)
- $\text{OPQ} = 321$ ($pq - 3p + 2q + 1 = 0$)
- $\text{RST} = 237$ ($(p + 2)(q - 3) = -7$)
- $\text{U} = 5, \text{V} = 2$ ($p = 5, q = 2$)
- $\text{WX} = 15, \text{Y} = 6$ ($a = 15, b = 6$)

**【詳細推導・解答プロセス】**
**(1) $\ell$ の表現と等式の変形**
$\gcd(a, b) = 3$ であるから、$a = 3p, b = 3q$ とおくことができる。ここで $p, q$ は互いに素な自然数（$\gcd(p, q) = 1, p \geq 1, q \geq 1$）である。
最小公倍数 $\ell$ は：
$$\ell = 3pq$$
よって、$\text{N} = 3$ である。
これを等式 $\textcircled{1}$ に代入する：
$$3(3p) - 2(3q) = 3pq + 3$$
$$9p - 6q = 3pq + 3$$
両辺を 3 で割ると：
$$3p - 2q = pq + 1 \implies pq - 3p + 2q + 1 = 0$$
問題の形 $pq - \text{O}p + \text{P}q + \text{Q} = 0$ と比較すると：
$$\text{O} = 3, \quad \text{P} = 2, \quad \text{Q} = 1$$
よって、$\text{OPQ} = 321$ である。

**(2) 因数分解形への変形**
左辺を因数分解する：
$$p(q - 3) + 2(q - 3) + 6 + 1 = 0$$
$$(p + 2)(q - 3) + 7 = 0 \implies (p + 2)(q - 3) = -7$$
問題の形 $(p + \text{R})(q - \text{S}) = -\text{T}$ と比較すると：
$$\text{R} = 2, \quad \text{S} = 3, \quad \text{T} = 7$$
よって、$\text{RST} = 237$ である。

**(3) 整数解の絞り込み**
$p$ は自然数であるから $p \geq 1$、したがって $p + 2 \geq 3$ である。
$-7$ の因数分解において、$p + 2$ が 3 以上の約数となる組み合わせは：
$$p + 2 = 7$$
のみである。
このとき：
$$p = 7 - 2 = 5$$
$$q - 3 = -1 \implies q = 3 - 1 = 2$$
$p = 5$ と $q = 2$ はともに自然数であり、互いに素である（$\gcd(5, 2) = 1$）。
したがって、条件をすべて満たす。
よって、$\text{U} = 5, \text{V} = 2$ である。

**(4) $a, b$ の決定**
$$a = 3p = 3 \times 5 = 15$$
$$b = 3q = 3 \times 2 = 6$$
よって、$\text{WX} = 15, \text{Y} = 6$ である。

**【考査考点】**
- 最大公約数と最小公倍数の関係式（$ab = g\ell$）。
- 2元1次式の因数分解による格子点探索（$(x - \alpha)(y - \beta) = k$ 型）。
- 自然数条件および互いに素な条件による解の一意特定。

## 大問III [1]：2次不等式の因数分解とパラメータを含む不等式の解
- **Local Key**: `math-q-III_1`
- **Answer Ref**: `MATH_C1:III_1`
- **公式正解**: `{'AB': '43', 'CD': '11', 'EF': '17'}`

**【題目大意】**
$0 < a < 1$ とする。連立不等式
$$\begin{cases} x^2 - 2x < 3 & \textcircled{1} \\ ax^2 - ax - x + 1 > 0 & \textcircled{2} \end{cases}$$
について、不等式 $\textcircled{1}$ および $\textcircled{2}$ のそれぞれの解を求める。

**【公式正解】**
- $\text{AB} = 43$ ($-1 < x < 3$)
- $\text{CD} = 11$ ($(ax - 1)(x - 1) > 0$)
- $\text{EF} = 17$ ($x < 1$ または $\frac{1}{a} < x$)

**【詳細推導・解答プロセス】**
**(1) 不等式 $\textcircled{1}$ の解**
$$x^2 - 2x - 3 < 0$$
左辺を因数分解すると：
$$(x + 1)(x - 3) < 0$$
したがって、解は：
$$-1 < x < 3$$
問題の選択肢において、$-1$ は $\textcircled{4}$、$3$ は $\textcircled{3}$ である。
よって、$\text{A} = 4, \text{B} = 3$ (AB = 43) である。

**(2) 不等式 $\textcircled{2}$ の因数分解と解**
不等式 $\textcircled{2}$ の左辺を共通因数でくくる：
$$ax(x - 1) - (x - 1) > 0 \implies (ax - 1)(x - 1) > 0$$
問題の形 $(ax - C)(x - D) > 0$ と比較すると：
$$C = 1, \quad D = 1$$
よって、$\text{CD} = 11$ である。

境界値は $x = 1$ および $ax - 1 = 0 \implies x = \frac{1}{a}$ である。
条件 $0 < a < 1$ より、その逆数は：
$$\frac{1}{a} > 1$$
また $a > 0$ であるから、2次不等式 $(ax - 1)(x - 1) > 0$ の解は 2 つの根の外側となる：
$$x < 1 \quad \text{または} \quad \frac{1}{a} < x$$
問題の選択肢において、$1$ は $\textcircled{1}$、$\frac{1}{a}$ は $\textcircled{7}$ である。
よって、$\text{E} = 1, \text{F} = 7$ (EF = 17) である。

**【考査考点】**
- 2次不等式の因数分解と標準的解法。
- 文字係数を含む因数分解と大小関係の比較（$0 < a < 1 \implies \frac{1}{a} > 1$）。

## 大問III [2]：連立不等式の共通範囲のパラメータ場合分け

   $$(-1, 3) \cap (-\infty, 1) = (-1, 1)$$

   $$(-1, 3) \cap \left(\frac{1}{a}, \infty\right)$$
   この共通部分が存在するかどうかは、$\frac{1}{a}$ と右端 $3$ の大小関係による：
   $$\frac{1}{a} < 3 \iff a > \frac{1}{3}$$

$$-1 < x < 1$$
選択肢において、$\frac{1}{3}$ は $\textcircled{6}$、$-1$ は $\textcircled{4}$、$1$ は $\textcircled{1}$ である。

$1 < \frac{1}{a} < 3$ となるため、右側にも共通範囲 $\frac{1}{a} < x < 3$ が生じる。
したがって、解は：
$$-1 < x < 1 \quad \text{または} \quad \frac{1}{a} < x < 3$$
選択肢において、$-1$ は $\textcircled{4}$、$1$ は $\textcircled{1}$、$\frac{1}{a}$ は $\textcircled{7}$、$3$ は $\textcircled{3}$ である。

**【考査考点】**
- 数直線を用いた不等式の共通集合（連立不等式）の解析。

## 大問IV [2]：面積の差による三角形 PQR の面積と3点共線条件
- **Local Key**: `math-q-IV_2`
- **Answer Ref**: `MATH_C1:IV_2`
- **公式正解**: `{'NO': '31', 'P': '0', 'QRS': '152'}`

**【題目大意】**
$\triangle PQR$ の面積を求め、3点 P, Q, R が一直線上に並ぶ時刻 $t$ を求める。

**【公式正解】**
- $\text{NO} = 31$ ($\triangle PQR = \frac{\sqrt{3}}{4}|-t^2 + t + 1|$)
- $\text{P} = 0$ ($t^2 - t - 1 = 0$)
- $\text{QRS} = 152$ ($t = \frac{1 + \sqrt{5}}{2}$ 秒)

**【詳細推導・解答プロセス】**
**(1) $\triangle PQR$ の面積の導出**
半直線 OZ は角の内部にあるため、点 Q は線分 PR に関して原点 O と同じ側または反対側にある。
幾何学的配置より、$\triangle PQR$ の面積は外側の三角形から内側の 2 つの三角形の和を引いた絶対値として表される：
$$\triangle PQR = |\triangle OPR - (\triangle OPQ + \triangle ORQ)|$$
共通の係数 $\frac{\sqrt{3}}{4}$ でまとめると：
$$\triangle OPR - (\triangle OPQ + \triangle ORQ) = \frac{\sqrt{3}}{4} \left[ (t + 1)(2t + 1) - t(t + 1) - t(2t + 1) \right]$$
括弧内を展開・整理する：
$$(2t^2 + 3t + 1) - (t^2 + t) - (2t^2 + t) = 2t^2 + 3t + 1 - 3t^2 - 2t = -t^2 + t + 1$$
したがって：
$$\triangle PQR = \frac{\sqrt{3}}{4} \left| -t^2 + t + 1 \right|$$
問題の形 $\frac{\sqrt{N}}{4}|-t^2 + t + O|$ と比較すると：
$$N = 3, \quad O = 1$$
よって、$\text{NO} = 31$ である。

**(2) 3点 P, Q, R が一直線上に並ぶ条件と時間 $t$ の導出**
3点 P, Q, R が同一直線上にあるための必要十分条件は、三角形 PQR の面積が 0 となることである：
$$\triangle PQR = 0 \iff -t^2 + t + 1 = 0 \iff t^2 - t - 1 = 0$$
問題の形 $t^2 - t - O = P$ と比較すると、$\text{P} = 0$ である。
この2次方程式を解の公式で解く：
$$t = \frac{1 \pm \sqrt{(-1)^2 - 4(1)(-1)}}{2} = \frac{1 \pm \sqrt{5}}{2}$$
$t > 0$ であるから、正の解をとる：
$$t = \frac{1 + \sqrt{5}}{2}$$
問題の形 $t = \frac{Q + \sqrt{R}}{S}$ と比較すると：
$$Q = 1, \quad R = 5, \quad S = 2$$
よって、$\text{QRS} = 152$ である。

**【考査考点】**
- 平面幾何における図形の面積分割関係（加減算）。
- 3点共線条件と三角形面積ゼロ条件の同値性。
- 2次方程式の解の公式および幾何学的制約（時間 $t > 0$）による解の選定。
