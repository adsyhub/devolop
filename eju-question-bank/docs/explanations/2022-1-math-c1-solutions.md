## 第I問 問1：2次関数の頂点の軌跡と区間線分上の制約条件・2次式の値域

**【考査考点】**：2次関数の平方完成と頂点座標の決定, 線分上の点であることによるパラメータの範囲制約（動く頂点）, パラメータ $a$ による2次関数の平方完成と閉区間における最大値・最小値

### 【第I問 問1】詳細解答と解説

#### (1) 放物線の頂点 P の座標
与えられた2次関数は $f(x) = x^2 + ax + b$ である。平方完成を行うと：
$$f(x) = \left(x + \frac{a}{2}\right)^2 - \frac{a^2}{4} + b$$
したがって、放物線 $y = f(x)$ の頂点 P の座標は：
$$\text{P}\left(-\frac{a}{\mathbf{2}}, -\frac{a^2}{\mathbf{4}} + b\right)$$
よって、$\mathbf{A = 2, B = 4}$（解答番号 $\mathbf{AB = 24}$）。

#### (2) 点 P が線分 AB 上にある条件と $a, b$ の関係式
1次関数 $h(x) = -2x$ のグラフと直線 $x = 3$ との交点は $\text{A}(3, -6)$、直線 $x = -2$ との交点は $\text{B}(-2, 4)$ である。
線分 AB は直線 $y = -2x$ 上の $-2 \le x \le 3$ の部分である。
頂点 P の $x$ 座標 $-\frac{a}{2}$ がこの区間内にあるため：
$$-2 \le -\frac{a}{2} \le 3 \iff -6 \le a \le 4$$
問題文の形式 $-C \le a \le D$ と比較して：
$$\mathbf{C = 6, D = 4}\quad(\text{解答番号 } \mathbf{CD = 64})$$
また、点 P は直線 $y = -2x$ 上にあるため、その座標を代入すると：
$$-\frac{a^2}{4} + b = -2\left(-\frac{a}{2}\right) = a \implies b = \frac{a^2}{\mathbf{4}} + a$$
よって、$\mathbf{E = 4}$。

#### (3) $L$ の $a$ による表現と値の範囲
定義式 $L = \{f(3) - h(3)\} + \{f(-2) - h(-2)\}$ を計算する。
差の関数 $f(x) - h(x)$ は：
$$f(x) - h(x) = x^2 + ax + b - (-2x) = x^2 + (a + 2)x + b$$
各値を代入すると：
- $f(3) - h(3) = 3^2 + (a + 2)\cdot 3 + b = 9 + 3a + 6 + b = 3a + b + 15$
- $f(-2) - h(-2) = (-2)^2 + (a + 2)(-2) + b = 4 - 2a - 4 + b = -2a + b$
したがって：
$$L = (3a + b + 15) + (-2a + b) = a + 2b + 15$$
$b = \frac{a^2}{4} + a$ を代入すると：
$$L = a + 2\left(\frac{a^2}{4} + a\right) + 15 = a + \frac{a^2}{2} + 2a + 15 = \frac{1}{2}a^2 + \mathbf{3}a + \mathbf{15}$$
よって、$\mathbf{F = 3, GH = 15}$（解答番号 $\mathbf{FGH = 315}$）。

定義域 $-6 \le a \le 4$ における $L(a)$ の増減を調べるため、$L(a)$ を平方完成する：
$$L(a) = \frac{1}{2}(a^2 + 6a) + 15 = \frac{1}{2}\left((a + 3)^2 - 9\right) + 15 = \frac{1}{2}(a + 3)^2 + \frac{21}{2}$$
- 軸は $a = -3$ であり、これは定義域 $[-6, 4]$ の内部にある。
- 下に凸であるから、頂点 $a = -3$ で最小値をとる：
  $$L_{\min} = L(-3) = \frac{21}{2}$$
- 最大値は軸 $a = -3$ から最も遠い端点 $a = 4$ でとる（軸からの距離：$|-6 - (-3)| = 3$ に対し $|4 - (-3)| = 7$）：
  $$L_{\max} = L(4) = \frac{1}{2}(4 + 3)^2 + \frac{21}{2} = \frac{49}{2} + \frac{21}{2} = \frac{70}{2} = 35$$
したがって、$L$ のとり得る値の範囲は：
$$\frac{\mathbf{21}}{\mathbf{2}} \le L \le \mathbf{35}$$
よって、$\mathbf{IJ = 21, K = 2}$（解答番号 $\mathbf{IJK = 212}$）、$\mathbf{LM = 35}$ である。

## 第I問 問2：カードの置換操作と確率・反復試行と条件付き確率

**【考査考点】**：順列・置換の互換操作, 全事象 $\binom{9}{2} = 36$ 通りにおける偶数末尾の分類討論, 操作履歴（非復元抽出型制約）による条件付き確率の計算

### 【第I問 問2】詳細解答と解説

#### 問題の設定
1から9までの数字が書かれた9枚のカードが左から昇順 $[1, 2, 3, 4, 5, 6, 7, 8, 9]$ で並んでいる。
9桁の整数が偶数になるための必要十分条件は、**最下位（第9番目・末尾）のカードが偶数（2, 4, 6, 8 のいずれか）** であることである。
偶数カードは 4 枚、奇数カードは 5 枚（1, 3, 5, 7, 9）である。初期状態では第9位は「9」（奇数）である。

#### (1) 1回目・2回目ともに9枚の中から2枚を選んで入れ換える場合
全事象の選び方は各回 $\binom{9}{2} = 36$ 通りである。

**(i) 1回目に「9」以外のカードを入れ換える場合**
- 1回目に「9」以外の8枚から2枚を選ぶ方法は $\binom{8}{2} = 28$ 通り。
- この操作後、第9位は依然として「9」のままである。また偶数4枚は依然として第1～8位のいずれかにある。
- 2回目の操作で第9位を偶数にするには、第9位の「9」と偶数4枚のいずれかを入れ換える必要があるため、選び方は 4 通り。
したがって、この事象が起こる確率は：
$$P = \frac{28}{36} \times \frac{4}{36} = \frac{7}{9} \times \frac{1}{9} = \frac{\mathbf{7}}{\mathbf{81}}$$
よって、$\mathbf{N = 7, OP = 81}$（解答番号 $\mathbf{NOP = 781}$）。

**(ii) 1回目に「9」の書かれたカードを他のカードと入れ換える場合**
1回目に「9」と他のカードを入れ換える方法は $8$ 通り。
- **Subcase A（「9」と偶数カードを交換）**：選び方は 4 通り。
  1回目の操作後、第9位は偶数となる。2回目の操作後も第9位が偶数であり続けるためには：
  1. 第9位を含まない8枚から2枚を選ぶ：$\binom{8}{2} = 28$ 通り。
  2. 第9位の偶数と、第1～8位にある他の偶数（3枚）のいずれかを入れ換える：$3$ 通り。
  よって適する選び方は $28 + 3 = 31$ 通り。
  確率は $\frac{4}{36} \times \frac{31}{36} = \frac{124}{1296}$。
- **Subcase B（「9」と他の奇数 1, 3, 5, 7 を交換）**：選び方は 4 通り。
  1回目の操作後、第9位は別の奇数となる。第1～8位には偶数4枚がすべて残っている。
  2回目で第9位を偶数にするには、第9位とその偶数4枚のいずれかを入れ換える必要があり、選び方は 4 通り。
  確率は $\frac{4}{36} \times \frac{4}{36} = \frac{16}{1296}$。
両者を合算すると：
$$P = \frac{124 + 16}{1296} = \frac{140}{1296} = \frac{\mathbf{35}}{\mathbf{324}}$$
よって、$\mathbf{QR = 35, STU = 324}$（解答番号 $\mathbf{QRSTU = 35324}$）。

したがって、(1)において2回の操作で偶数になる全確率は (i) と (ii) の和である：
$$P_{\text{全}} = \frac{7}{81} + \frac{35}{324} = \frac{28 + 35}{324} = \frac{63}{324} = \frac{\mathbf{7}}{\mathbf{36}}$$
よって、$\mathbf{V = 7, WX = 36}$（解答番号 $\mathbf{VWX = 736}$）。

#### (2) 2回目は1回目で選んだ2枚を除く残りの7枚から選ぶ場合
2回目の選び方は $\binom{7}{2} = 21$ 通りである。
- **Case 1: 1回目に第9位の「9」と偶数カードを入れ換えた場合（4通り）**
  1回目の操作後、第9位は偶数となる。2回目の操作対象となる7枚には第9位のカードが含まれないため、第9位は変更されず必ず偶数のまま保たれる。
  したがって、2回目のどのような選び方（21通りすべて）でも条件を満たす。
  この確率成分は：$\frac{4}{36} \times \frac{21}{21} = \frac{4}{36}$。
- **Case 2: 1回目に第9位以外のカードを入れ換えた場合（$\binom{8}{2} = 28$ 通り）**
  第9位は「9」のままであり、1回目で操作されていないため、2回目の7枚の中に第9位（「9」）が必ず含まれる。
  2回目で偶数にするには、第9位と残り7枚の中にある偶数を入れ換えなければならない。
  1回目で操作された2枚に含まれる偶数の枚数で場合分けする：
  - 奇数2枚を交換（$\binom{4}{2} = 6$ 通り）：残り7枚に偶数は 4 枚 $\implies$ 選び方は 4 通り。
  - 奇数1枚・偶数1枚を交換（$4 \times 4 = 16$ 通り）：残り7枚に偶数は 3 枚 $\implies$ 選び方は 3 通り。
  - 偶数2枚を交換（$\binom{4}{2} = 6$ 通り）：残り7枚に偶数は 2 枚 $\implies$ 選び方は 2 通り。
  2回目に条件を満たす総数は $6 \times 4 + 16 \times 3 + 6 \times 2 = 24 + 48 + 12 = 84$ 通り。
  この確率成分は：$\frac{84}{36 \times 21} = \frac{4}{36}$。
以上より、求める確率は：
$$P = \frac{4}{36} + \frac{4}{36} = \frac{8}{36} = \frac{\mathbf{2}}{\mathbf{9}}$$
よって、$\mathbf{Y = 2, Z = 9}$（解答番号 $\mathbf{YZ = 29}$）。

## 第II問 問1：無理数の整数部分・対称式の計算と小数第1位の決定

**【考査考点】**：平方根の不等式評価と整数部分の特定, 基本対称式 $xy, x+y, x-y$ の正確な値の計算, 平方根の近似値による小数第1位の決定

### 【第II問 問1】詳細解答と解説

#### (1) $\sqrt{55}$ の評価および $x, y$ の整数部分
$7^2 = 49 < 55 < 64 = 8^2$ より：
$$\mathbf{7} < \sqrt{55} < 8$$
よって、$\mathbf{A = 7}$。
- $x^2 = 8 + \sqrt{55}$ について：
  $$8 + 7 < x^2 < 8 + 8 \iff 15 < x^2 < 16$$
  $x > 0$ であるから $\sqrt{15} < x < 4$。$3^2 = 9 < 15$ より $3 < x < 4$ である。
  したがって、$x$ の整数部分は **3** である。よって、$\mathbf{B = 3}$。
- $y^2 = 8 - \sqrt{55}$ について：
  $$8 - 8 < y^2 < 8 - 7 \iff 0 < y^2 < 1$$
  $y > 0$ であるから $0 < y < 1$ である。
  したがって、$y$ の整数部分は **0** である。よって、$\mathbf{C = 0}$。

#### (2) 対称式 $xy, x+y, x-y$ の計算
1. 積 $xy$：
   $$(xy)^2 = x^2 y^2 = (8 + \sqrt{55})(8 - \sqrt{55}) = 8^2 - 55 = 64 - 55 = 9$$
   $x > 0, y > 0$ より $xy > 0$ であるから：
   $$xy = \sqrt{9} = \mathbf{3}$$
   よって、$\mathbf{D = 3}$。
2. 和 $x + y$：
   $$(x + y)^2 = x^2 + y^2 + 2xy = (8 + \sqrt{55} + 8 - \sqrt{55}) + 2(3) = 16 + 6 = 22$$
   $x + y > 0$ より：
   $$x + y = \sqrt{x^2 + y^2 + \mathbf{2}xy} = \sqrt{\mathbf{22}}$$
   よって、$\mathbf{E = 2, FG = 22}$。
3. 差 $x - y$：
   $x^2 > y^2$ かつ $x, y > 0$ より $x > y \implies x - y > 0$ である。
   $$(x - y)^2 = x^2 + y^2 - 2xy = 16 - 2(3) = 10$$
   $$x - y = \sqrt{x^2 + y^2 - \mathbf{2}xy} = \sqrt{\mathbf{10}}$$
   よって、$\mathbf{H = 2, IJ = 10}$。
連立方程式 $(x+y) + (x-y) = 2x$ および $(x+y) - (x-y) = 2y$ より：
$$x = \frac{\sqrt{22} + \sqrt{10}}{\mathbf{2}}, \quad y = \frac{\sqrt{22} - \sqrt{10}}{\mathbf{2}}$$
よって、$\mathbf{K = 2}$。

#### (3) $x + y$ の小数第1位の数字
$x + y = \sqrt{22}$ である。
小数第1位を求めるため、小数の2乗を評価する：
- $4.6^2 = 21.16 < 22$
- $4.7^2 = 22.09 > 22$
これより $4.6 < \sqrt{22} < 4.7$ であるから、$x + y = 4.6\cdots$ である。
したがって、$x + y$ の小数第1位の数字は **6** である。
よって、$\mathbf{L = 6}$。

## 第II問 問2：分式関数の値域と判別式・最大値・最小値をとる $x$ の決定

**【考査考点】**：実数条件と2次方程式の判別式 $D \ge 0$, 分母が常に正（$x^2-2x+2 = (x-1)^2+1 > 0$）である性質の活用, 重解公式による最大値・最小値を与える $x$ の導出

### 【第II問 問2】詳細解答と解説

#### (1) 2次方程式の整理と $k = 0$ の場合
分母は $x^2 - 2x + 2 = (x - 1)^2 + 1 \ge 1 > 0$ であり、任意の実数 $x$ で定義される。
$k = \frac{6x + 2}{x^2 - 2x + 2}$ とおいて両辺に分母をかけると：
$$k(x^2 - 2x + 2) = 6x + 2 \implies kx^2 - 2kx + 2k - 6x - 2 = 0$$
$$kx^2 - \mathbf{2}(k + \mathbf{3})x + \mathbf{2}(k - \mathbf{1}) = 0 \quad \cdots\textcircled{1}$$
問題文の形式 $kx^2 - M(k + N)x + O(k - P) = 0$ と比較して：
$$\mathbf{M = 2, N = 3, O = 2, P = 1}\quad(\text{解答番号 } \mathbf{MNOP = 2321})$$

ここで $k = 0$ のとき、方程式 $\textcircled{1}$ は：
$$-2(0 + 3)x + 2(0 - 1) = 0 \implies -6x - 2 = 0 \implies x = -\frac{2}{6} = -\frac{\mathbf{1}}{\mathbf{3}}$$
よって、$\mathbf{Q = 1, R = 3}$（解答番号 $\mathbf{QR = 13}$）。

#### (2) $k \neq 0$ における判別式と値域
$k \neq 0$ のとき、$\textcircled{1}$ は $x$ に関する2次方程式である。
$x$ が実数解をもつための必要十分条件は、判別式 $D/4 \ge 0$ である：
$$\frac{D}{4} = \{-(k + 3)\}^2 - k \cdot 2(k - 1) = (k^2 + 6k + 9) - (2k^2 - 2k) = -k^2 + 8k + 9 \ge 0$$
両辺に $-1$ をかけると：
$$k^2 - \mathbf{8}k - \mathbf{9} \le 0$$
よって、$\mathbf{S = 8, T = 9}$（解答番号 $\mathbf{ST = 89}$）。

この2次不等式を解くと：
$$(k - 9)(k + 1) \le 0 \implies -1 \le k \le 9$$
$k \neq 0$ であるから：
$$-\mathbf{1} \le k < 0, \quad 0 < k \le \mathbf{9}$$
よって、$\mathbf{U = 1, V = 9}$。
$k = 0$ でも実数解 $x = -1/3$ が存在するため、全体としての値域は $-1 \le \frac{6x+2}{x^2-2x+2} \le 9$ である。

#### (3) 最大値・最小値をとる $x$ の値
端点 $k = 9$ および $k = -1$ では判別式 $D = 0$ となり、2次方程式は重解をもつ。
重解の公式 $x = -\frac{b}{2a} = \frac{2(k+3)}{2k} = \frac{k+3}{k}$ より：
- 最大値 $k = 9$ をとるとき：
  $$x = \frac{9 + 3}{9} = \frac{12}{9} = \frac{\mathbf{4}}{\mathbf{3}}$$
  よって、$\mathbf{W = 4, X = 3}$（解答番号 $\mathbf{WX = 43}$）。
- 最小値 $k = -1$ をとるとき：
  $$x = \frac{-1 + 3}{-1} = \frac{2}{-1} = -\mathbf{2}$$
  問題文の形式 $x = -Y$ より、$\mathbf{Y = 2}$。

## 第III問 [1]：オイラーのファイ関数・素因数分解と互いに素な整数の個数

**【考査考点】**：互いに素の定義とオイラー関数の基本値の計算, 素数べきおよび積に対する倍数の個数の包除原理（容斥原理）, 乗法性 $A(pq) = A(p)A(q) = (p-1)(q-1)$ の証明と展開

### 【第III問 [1]】詳細解答と解説

#### (1) 基本的な数値における $A(n)$ の計算
$A(n)$ は $n$ 以下の正の整数で $n$ と互いに素（最大公約数が 1）であるものの個数（オイラーの $\phi$ 関数）を表す。
1. $A(5)$：$5$ は素数であるから、$1, 2, 3, 4$ の 4 個すべてが 5 と互いに素である。
   $$A(5) = \mathbf{4} \quad (\mathbf{A = 4})$$
2. $A(6)$：$1, 2, 3, 4, 5, 6$ のうち、$6 = 2 \times 3$ と互いに素なのは $1, 5$ の 2 個である。
   $$A(6) = \mathbf{2} \quad (\mathbf{B = 2})$$
3. $A(12)$：$12 = 2^2 \times 3$。1から12の中で2の倍数でも3の倍数でもないのは $1, 5, 7, 11$ の 4 個である。
   $$A(12) = \mathbf{4} \quad (\mathbf{C = 4})$$

#### (2) 素数 $p, q$ による一般公式の導出
**(i) 素数 $p$ の場合**
$p$ 以下の正の整数 $1, 2, \dots, p$ のうち、$p$ と互いに素でないのは $p$ 自身（1個）のみである。
したがって：
$$A(p) = p - 1$$
選択肢 $\textcircled{5}$「$p-1$」が適する。よって、$\mathbf{D = 5}$。

**(ii) $A(pq)$ および $A(p^2q)$ の導出**
- **$A(pq)$ について（包除原理）**：
  $1$ から $pq$ までの整数の中で：
  - $p$ の倍数は $p, 2p, \dots, qp$ の $q$ 個（選択肢 $\textcircled{3}$）$\implies \mathbf{E = 3}$。
  - $q$ の倍数は $q, 2q, \dots, pq$ の $p$ 個（選択肢 $\textcircled{2}$）$\implies \mathbf{F = 2}$。
  - $pq$ の倍数は $pq$ の $1$ 個（選択肢 $\textcircled{1}$）$\implies \mathbf{G = 1}$。
  $p$ と $q$ は異なる素数であるから、$pq$ と互いに素なものの個数は：
  $$A(pq) = pq - (q + p - 1) = pq - p - q + 1 = (p - 1)(q - 1)$$
  選択肢 $\textcircled{7}$「$(p-1)(q-1)$」が適する。よって、$\mathbf{H = 7}$。

- **$A(p^2q)$ について**：
  $1$ から $p^2q$ までの整数の中で：
  - $p$ の倍数は $\frac{p^2q}{p} = pq$ 個（選択肢 $\textcircled{0}$）$\implies \mathbf{I = 0}$。
  - $q$ の倍数は $\frac{p^2q}{q} = p^2$ 個（選択肢 $\textcircled{4}$）$\implies \mathbf{J = 4}$。
  - $pq$ の倍数は $\frac{p^2q}{pq} = p$ 個（選択肢 $\textcircled{2}$）$\implies \mathbf{K = 2}$。
  包除原理より、$p$ の倍数または $q$ の倍数の個数は $pq + p^2 - p$ 個である。
  したがって、互いに素な数の個数は：
  $$A(p^2q) = p^2q - (pq + p^2 - p) = p^2q - p^2 - pq + p = p(pq - p - q + 1) = p(p - 1)(q - 1)$$
  選択肢 $\textcircled{9}$「$p(p-1)(q-1)$」が適する。よって、$\mathbf{L = 9}$。

## 第III問 [2]：素因数分解と不定方程式・条件を満たす素数対の決定

**【考査考点】**：整数の素因数分解の一意性, 素数制約下での方程式 $p(p-1)(q-1) = 36$ の絞り込み, 全候補の吟味と解の完全性の保証

### 【第III問 [2]】詳細解答と解説

#### (iii) $A(p^2q) = 36$ となる素数対 $(p, q)$ の決定
36 を素因数分解すると：
$$36 = 2^2 \cdot 3^2$$
問題文の形式 $36 = M^N \cdot O^P$（ただし $M < O$）と比較して：
$$\mathbf{M = 2, N = 2, O = 3, P = 2}\quad(\text{解答番号 } \mathbf{MNOP = 2232})$$

方程式 $A(p^2q) = p(p - 1)(q - 1) = 36$ を解く。
$p$ は素数であり、$p$ は $36 = 2^2 \cdot 3^2$ の約数でなければならない。
したがって、素数 $p$ の候補は **$p = 2$** または **$p = 3$** に限られる。

**Case 1: $p = 2$ のとき**
$$2(2 - 1)(q - 1) = 36 \implies 2 \times 1 \times (q - 1) = 36 \implies q - 1 = 18 \implies q = 19$$
$19$ は素数であり、$p = 2$ と異なるので適する。
よって、$(p, q) = (\mathbf{2}, \mathbf{19})$。
したがって、$\mathbf{Q = 2, RS = 19}$。

**Case 2: $p = 3$ のとき**
$$3(3 - 1)(q - 1) = 36 \implies 3 \times 2 \times (q - 1) = 36 \implies 6(q - 1) = 36 \implies q - 1 = 6 \implies q = 7$$
$7$ は素数であり、$p = 3$ と異なるので適する。
よって、$(p, q) = (\mathbf{3}, \mathbf{7})$。
したがって、$\mathbf{T = 3, U = 7}$。

以上より、求める組は **$(p, q) = (2, 19), (3, 7)$** である。

## 第IV問 [1]：円に内接し2辺に接する小円の幾何学的性質・半径の算出

**【考査考点】**：正三角形の外接円の性質（中心角と円周角）, 円に内接し2本の弦に接する小円の中心軌跡（角の二等分線）, 直角三角形の三角比を用いた小円半径 $r$ の立式と求解

### 【第IV問 [1]】詳細解答と解説

#### (1) 内接する小円 O の半径 $r$ の導出
半径 $R = 2$ の円周上に 3 点 A, B, C があり、$AB = AC, \angle BAC = 60^\circ$ である。
これより $\triangle ABC$ は正三角形である。
円 O はこの大円に内接し、かつ線分 AB, AC に接する。
- 対称性より、円 O の中心 O は $\angle BAC$ の二等分線上に存在する。
  点 D を線分 AB と円 O の接点とすると、$\angle OAD = \frac{1}{2}\angle BAC = \mathbf{30^\circ}$ である。
  よって、$\mathbf{AB = 30}$。
- 直角三角形 OAD において、$\sin \angle OAD = \sin 30^\circ = \frac{r}{AO} = \frac{1}{2}$ より：
  $$AO = 2r$$
- また、点 A から大円の中心を経て対蹠点に至る線分は円の直径であり、長さは $2R = 2 \times 2 = 4$ である。
  円 O はこの対蹠点で大円に内接するため、A から円 O の最も遠い点までの距離が直径 4 に等しい：
  $$AO + r = 4 \implies AO = \mathbf{4} - r$$
  よって、$\mathbf{C = 4}$。
この2式より：
$$2r = 4 - r \implies 3r = 4 \implies r = \frac{\mathbf{4}}{\mathbf{3}}$$
よって、$\mathbf{D = 4, E = 3}$（解答番号 $\mathbf{DE = 43}$）。

## 第IV問 [2]：円周上の動点と余弦定理・囲まれた図形の周長と面積の求積

**【考査考点】**：正弦定理・余弦定理による線分長 $BC$ および $PC$ の計算, 同一円弧を見込む円周角の定理（$\angle BPC = 60^\circ$）, 孤長公式と三角形・弓形（セグメント）面積の割付けと加法

### 【第IV問 [2]】詳細解答と解説

#### (2) 弧 $L_2$ 上の点 P と線分長 $PC = x$ の決定
正三角形 ABC の外接円の半径は $R = 2$ であるから、正弦定理より：
$$BC = 2R \sin 60^\circ = 2 \times 2 \times \frac{\sqrt{3}}{2} = \mathbf{2\sqrt{3}}$$
よって、$\mathbf{F = 2, G = 3}$（解答番号 $\mathbf{FG = 23}$）。

点 P は長い方の弧 $L_2$（点 A を含む側の弧）上にあり、$BP = 3$ を満たす。
点 P と点 A は弦 BC に対して同じ側に位置するため、円周角の定理により：
$$\angle BPC = \angle BAC = 60^\circ$$
$\triangle PBC$ において余弦定理を適用する：
$$BC^2 = PB^2 + PC^2 - 2 \cdot PB \cdot PC \cos 60^\circ$$
$$(2\sqrt{3})^2 = 3^2 + x^2 - 2 \cdot 3 \cdot x \cdot \frac{1}{2} \implies 12 = 9 + x^2 - 3x$$
整理すると：
$$x^2 - \mathbf{3}x - \mathbf{3} = 0$$
よって、$\mathbf{H = 3, I = 3}$（解答番号 $\mathbf{HI = 33}$）。

解の公式より（$x > 0$）：
$$x = \frac{3 + \sqrt{(-3)^2 - 4(1)(-3)}}{2} = \frac{\mathbf{3} + \sqrt{\mathbf{21}}}{\mathbf{2}}$$
よって、$\mathbf{J = 3, KL = 21, M = 2}$（解答番号 $\mathbf{JKLM = 3212}$）。

#### (3) 周の長さ $\ell$ の計算
図形の周は、線分 PB、線分 PC、および短い方の弧 $L_1$（弧 BC）からなる。
短い方の弧 $L_1$ に対する中心角は $2 \times 60^\circ = 120^\circ = \frac{2\pi}{3}$ である。
大円の半径は $2$ であるから、弧 $L_1$ の長さは：
$$\text{弧 } L_1 = 2 \times \frac{2\pi}{3} = \frac{4}{3}\pi$$
線分の長さの和は：
$$PB + PC = 3 + \frac{3 + \sqrt{21}}{2} = \frac{6 + 3 + \sqrt{21}}{2} = \frac{9 + \sqrt{21}}{2}$$
したがって、周の長さ $\ell$ は：
$$\ell = \frac{\mathbf{4}}{\mathbf{3}}\pi + \frac{\mathbf{9} + \sqrt{21}}{2}$$
よって、$\mathbf{NO = 43, P = 9}$。

#### (4) 三角形 PBC の面積 $S'$ と図形全体の面積 $S$
三角形 PBC の面積 $S'$ は：
$$S' = \frac{1}{2} \cdot PB \cdot PC \sin 60^\circ = \frac{1}{2} \cdot 3 \cdot \frac{3 + \sqrt{21}}{2} \cdot \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}(3 + \sqrt{21})}{8}$$
分子を展開すると：
$$3\sqrt{3} \times 3 + 3\sqrt{3}\sqrt{21} = 9\sqrt{3} + 3\sqrt{63} = 9\sqrt{3} + 3(3\sqrt{7}) = 9\sqrt{3} + 9\sqrt{7} = 9(\sqrt{3} + \sqrt{7})$$
したがって：
$$S' = \frac{\mathbf{9}(\sqrt{\mathbf{3}} + \sqrt{\mathbf{7}})}{\mathbf{8}}$$
よって、$\mathbf{Q = 9, R = 3, S = 7, T = 8}$（解答番号 $\mathbf{QRST = 9378}$）。

図形全体の面積 $S$ は、三角形 PBC の面積 $S'$ と、弦 BC および弧 $L_1$ で囲まれた弓形（セグメント）の面積の和である。
弓形の面積は、中心角 $120^\circ$ の扇形の面積から二等辺三角形 OBC の面積を引いたものである：
$$\text{扇形 OBC} = \frac{1}{2} \cdot 2^2 \cdot \frac{2\pi}{3} = \frac{4}{3}\pi$$
$$\triangle OBC = \frac{1}{2} \cdot 2 \cdot 2 \sin 120^\circ = 2 \times \frac{\sqrt{3}}{2} = \sqrt{3}$$
$$\text{弓形の面積} = \frac{4}{3}\pi - \sqrt{3}$$
したがって、求める面積 $S$ は：
$$S = S' + \left(\frac{4}{3}\pi - \sqrt{3}\right) = \frac{4}{3}\pi + \frac{9\sqrt{3} + 9\sqrt{7}}{8} - \sqrt{3} = \frac{4}{3}\pi + \frac{9\sqrt{3} + 9\sqrt{7} - 8\sqrt{3}}{8} = \frac{\mathbf{4}}{\mathbf{3}}\pi + \frac{\sqrt{\mathbf{3}} + \mathbf{9}\sqrt{\mathbf{7}}}{\mathbf{8}}$$
よって、$\mathbf{UV = 43, W = 3, X = 9, Y = 7, Z = 8}$（解答番号 $\mathbf{WXYZ = 3978}$）。
