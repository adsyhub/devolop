## 第I問 問1：2次関数の平行移動と定義域における最大値

**【考查考点】**：2次関数の頂点・平方完成, グラフの平行移動, 動く軸と固定された定義域における最大値の分類討議

### 【第I問 問1】詳細解答と解説

#### (1) 放物線の頂点座標
与えられた2次関数は $f(x) = -x^2 + 4x + 5$。
平方完成を行うと：
$$f(x) = -(x^2 - 4x) + 5 = -((x - 2)^2 - 4) + 5 = -(x - 2)^2 + 9$$
したがって、放物線 $y = f(x)$ の頂点の座標は **$(2, 9)$** である。
よって、$\mathbf{A = 2, B = 9}$（解答番号 $\mathbf{AB = 29}$）。

#### (2) 平行移動後の放物線
放物線 $y = f(x)$ を $x$ 軸方向に $k$、$y$ 軸方向に $-4$ だけ平行移動した放物線を $y = g(x)$ とする。
頂点の移動に着目すると、元の頂点 $(2, 9)$ は $(2 + k, 9 - 4) = (k + 2, 5)$ に移る。
2次の係数は変わらず $-1$ のままであるから：
$$g(x) = -(x - (2 + k))^2 + 5 = -(x - 2 - k)^2 + 5$$
問題文の形式 $g(x) = -(x - \text{C} - k)^2 + \text{D}$ と比較して：
$$\mathbf{C = 2, D = 5}$$（解答番号 $\mathbf{CD = 25}$）。

#### (3) 定義域 $-1 \le x \le 4$ における最大値が 3 となる $k$ の条件
放物線 $y = g(x)$ は上に凸で、頂点の $y$ 座標は $5$、軸の方程式は $x = k + 2$ である。
もし軸 $x = k + 2$ が定義域 $[-1, 4]$ の内部（$-1 \le k + 2 \le 4 \iff -3 \le k \le 2$）にあれば、最大値は頂点の $y$ 座標 $5$ となり、条件「最大値が 3」を満たさない。
したがって、最大値が 3 となるためには、軸が定義域の外側になければならず、端点で最大値 3 をとる。

**Case 1: 軸が定義域の左側にある場合（$k + 2 < -1 \iff k < -3$）**
このとき、$-1 \le x \le 4$ において $g(x)$ は単調減少するので、最大値は左端 $x = -1$ でとる。
$$g(-1) = -(-1 - 2 - k)^2 + 5 = -(k + 3)^2 + 5 = 3$$
$$-(k + 3)^2 = -2 \implies (k + 3)^2 = 2 \implies k^2 + 6k + 9 = 2 \implies k^2 + 6k + 7 = 0$$
二次方程式を解くと $k = -3 \pm \sqrt{2}$。
$k < -3$ より、適するのは $k = -3 - \sqrt{2}$ である。
この条件は選択肢 $\textcircled{3}$「$k < -3$ かつ $k^2 + 6k + 7 = 0$」に一致する。
よって、$\mathbf{E = 3}$。
また、$k = -\text{G} - \sqrt{\text{H}}$ より $\mathbf{G = 3, H = 2}$（解答番号 $\mathbf{GH = 32}$）。

**Case 2: 軸が定義域の右側にある場合（$k + 2 > 4 \iff k > 2$）**
このとき、$-1 \le x \le 4$ において $g(x)$ は単調増加するので、最大値は右端 $x = 4$ でとる。
$$g(4) = -(4 - 2 - k)^2 + 5 = -(2 - k)^2 + 5 = -(k - 2)^2 + 5 = 3$$
$$-(k - 2)^2 = -2 \implies (k - 2)^2 = 2 \implies k^2 - 4k + 4 = 2 \implies k^2 - 4k + 2 = 0$$
二次方程式を解くと $k = 2 \pm \sqrt{2}$。
$k > 2$ より、適するのは $k = 2 + \sqrt{2}$ である。
この条件は選択肢 $\textcircled{7}$「$k > 2$ かつ $k^2 - 4k + 2 = 0$」に一致する。
よって、$\mathbf{F = 7}$。
また、$k = \text{I} + \sqrt{\text{J}}$ より $\mathbf{I = 2, J = 2}$（解答番号 $\mathbf{IJ = 22}$）。

**【解法テクニック・易錯点】**
- 放物線の軸の位置（$k+2$）が定義域の内側にあるか外側にあるかを即座に見抜くことがポイントです。頂点最大値が 5 であるため、3 に下がるには必ず軸が区間外に外れなければなりません。

## 第I問 問2：正多面体（正四面体・立方体）の面の塗り分けと対称性

**【考查考点】**：組み合わせ（Combination）, 円順列・空間回転群（3次元回転対称性）, 二面体群による面の同値類

### 【第I問 問2】詳細解答と解説

#### (1) 正四面体の各面の塗り分け（6色から4色）
相異なる 6 色から使用する 4 色を選ぶ組み合わせの数は：
$$\binom{6}{4} = \binom{6}{2} = \frac{6 \times 5}{2 \times 1} = 15 \text{ 通り}$$
よって、$\mathbf{KL = 15}$。

選ばれた 4 色（例えば赤、青、黄、緑）を用いて正四面体の 4 面を塗る場合：
回転させて重なるものを同一視するため、まず「赤」で塗る面を底面に固定して空間の向きを固定する。
残りの 3 面（側面 3 つ）は、底面の上から見て円周上に並ぶため、残りの 3 色による円順列の数となる：
$$(3 - 1)! = 2! = 2 \text{ 通り}$$
よって、$\mathbf{M = 2}$。

したがって、6 色から 4 面を塗るすべての方法は：
$$15 \times 2 = 30 \text{ 通り}$$
よって、$\mathbf{NO = 30}$。

#### (2) 立方体の各面の塗り分け
**(i) 6 色すべてを使って塗る方法**
立方体には 6 つの面がある。
回転による同値性を除くため、基準となる 1 色（例えば色 1）をある面（上面）に固定する。
次に、その対面（底面）に塗る色を残り 5 色から選ぶため、$5$ 通りある。
残った 4 つの側面を残り 4 色で塗るが、上面・底面を結ぶ軸のまわりの回転（4 回回転対称）により同値となるため、4 色の円順列となる：
$$(4 - 1)! = 3! = 6 \text{ 通り}$$
したがって、求める塗り方の総数は：
$$5 \times 6 = 30 \text{ 通り}$$
よって、$\mathbf{PQ = 30}$。

**(ii) 紫を除いた 5 色をすべて使って塗る方法（隣接面は異色）**
立方体の 6 面を 5 色で塗るため、鳩の巣原理より必ず 1 色が 2 面に塗られる。
「隣り合った面の色が異なる」という制約から、同一色で塗られる 2 つの面は必ず「向かい合う面（対面）」でなければならない。
立方体には向かい合う面のペアが 3 組ある。
1. まず、5 色の中から対面に塗る「重複する 1 色」を選ぶ：$\binom{5}{1} = 5$ 通り。
2. その色を塗る対面（上面・底面）に固定する。
3. 残りの 4 面（側面環）を、残り 4 色で 1 面ずつ塗る。
ここで、空間の回転対称性を慎重に考える：
- 上面・底面を結ぶ軸まわりの回転により 4 つの側面は円順列となり、$(4 - 1)! = 6$ 通りある。
- さらに、上面と底面は「同じ色」で塗られているため、側面の中央を通る水平軸まわりの 180° 反転（立方体の空間回転）によって上面と底面が入れ替わっても同じ塗り方とみなされる。
- 側面環の順序を反転させる対称変換（裏返し）が空間の剛体回転として存在するため、対面が同色の場合は円順列 6 通りのうち鏡映反転ペア同士が同一視され、実質的な配置数は：
$$\frac{(4 - 1)!}{2} = \frac{6}{2} = 3 \text{ 通り}$$
したがって、求める総数は：
$$5 \times 3 = 15 \text{ 通り}$$
よって、$\mathbf{RS = 15}$。

**【解法テクニック・易錯点】**
- (ii) では上面と底面が同色であるため、立方体の「裏返し回転（180° flip）」が作用することを見落として $5 \times 6 = 30$ としてしまう受験生が非常に多い典型的な罠問題です。必ず面が同色であることによる付加的な対称性を除算してください。

## 第II問 問1：多項式展開・小数の循環節・無限等比数列と既約分数

**【考查考点】**：多項式展開における特定項の係数決定, 分数の小数展開と循環節の周期性, 循環小数の分数表示

### 【第II問 問1】詳細解答と解説

#### (1) 多項式展開における $xyz$ の係数
展開する式は $(-x + 2y + 3z)(2x - 3y + 4z)(3x + 4y - 5z)$。
3つの各因数から $x, y, z$ を1つずつ選んで掛け合わせる選び方は $3! = 6$ 通りある：
1. $(-x) \times (-3y) \times (-5z) = -15xyz$
2. $(-x) \times (4z) \times (4y) = -16xyz$
3. $(2y) \times (2x) \times (-5z) = -20xyz$
4. $(2y) \times (4z) \times (3x) = +24xyz$
5. $(3z) \times (2x) \times (4y) = +24xyz$
6. $(3z) \times (-3y) \times (3x) = -27xyz$
これらをすべて足し合わせると：
$$-15 - 16 - 20 + 24 + 24 - 27 = -78 + 48 = -30$$
したがって、$xyz$ の係数は **$-30$** である。
よって、$\mathbf{ABC = -30}$。

#### (2) $\frac{479}{700}$ の小数第 2023 位の数字
まず分母の 100 を分離して考える：
$$\frac{479}{700} = \frac{1}{100} \times \frac{479}{7}$$
$479$ を $7$ で割ると：$479 = 7 \times 68 + 3$ であるから：
$$\frac{479}{7} = 68 + \frac{3}{7}$$
分母 7 の小数は有名であり、循環節は 6 桁である：
$$\frac{3}{7} = 0.\dot{4}2857\dot{1} = 0.428571428571\dots$$
これを 100 で割ると：
$$\frac{479}{700} = 0.68\,428571\,428571\dots$$
小数第 1 位は 6、第 2 位は 8（非循環部）。
小数第 3 位以降に 6 桁の循環節 $(4, 2, 8, 5, 7, 1)$ が繰り返される。
小数第 2023 位の数字を求めるには、非循環の 2 桁を除いた循環部の桁数を調べる：
$$2023 - 2 = 2021$$
$2021$ を循環節の長さ $6$ で割ると：
$$2021 = 6 \times 336 + 5$$
余りが 5 であるから、循環節 $(4, 2, 8, 5, 7, 1)$ の第 5 番目の数字となる。
第 5 番目の数字は **7** である。
よって、$\mathbf{D = 7}$。

#### (3) 循環小数と既約分数
$a = 0.\dot{2}2\dot{8} = \frac{228}{999} = \frac{76}{333}$。
$b = 0.\dot{3}3524\dot{4}$ 等の計算により、$x = 2a - b$ を計算すると純循環小数 $x = 0.\dot{1}\dot{2} = 0.121212\dots$ が得られる。
よって、$x = 0.\dot{\text{E}}\dot{\text{F}} \implies \mathbf{EF = 12}$。
このとき、$100x = 12.121212\dots = 12 + x$ であるから：
$$100x = \mathbf{12} + x$$
よって、$\mathbf{GH = 12}$。
これを解くと：
$$99x = 12 \implies x = \frac{12}{99} = \frac{4}{33}$$
これは既約分数であるから：
$$x = \frac{\mathbf{4}}{\mathbf{33}}$$
よって、$\mathbf{I = 4, JK = 33}$（解答番号 $\mathbf{IJK = 433}$）。

## 第II問 問2：文字係数2次不等式の解の分類と包含関係・共通部分

**【考查考点】**：2次不等式の因数分解と根の大小関係の分類, 区間の包含条件, 共通部分をもたない条件（背理法・対偶）

### 【第II問 問2】詳細解答と解説

#### (1) 不等式 $\textcircled{1}$ の解
$$x^2 - 3x + 2 < 0 \iff (x - 1)(x - 2) < 0 \iff 1 < x < 2$$
よって、$\mathbf{L = 1, M = 2}$（解答番号 $\mathbf{LM = 12}$）。

#### (2) 不等式 $\textcircled{2}$ の解の分類
$$x^2 - 2ax - 3a^2 < 0 \iff (x - 3a)(x + a) < 0$$
2根は $-a$ と $3a$ である。
両者の差は $3a - (-a) = 4a$ であるから、$a$ の符号によって根の大小が定まる：
- $a > 0$ のとき：$-a < 3a$ であるから、解は **$-a < x < 3a$**（選択肢 $\textcircled{1}$）。
- $a = 0$ のとき：$x^2 < 0$ となり、実数解は存在しない（**解はなし**，選択肢 $\textcircled{9}$）。
- $a < 0$ のとき：$3a < -a$ であるから、解は **$3a < x < -a$**（選択肢 $\textcircled{4}$）。
問題文の記述：
「$a > N$ のとき $O$, $a = N$ のとき $P$, $a < N$ のとき $Q$」より：
$$\mathbf{N = 0, O = 1, P = 9, Q = 4}$$

#### (3) $\textcircled{1}$ を満たすすべての $x$ について $\textcircled{2}$ が成り立つ条件
これは、区間 $(1, 2)$ が不等式 $\textcircled{2}$ の解集合に含まれる（$(1, 2) \subseteq \text{Sol}(\textcircled{2})$）条件と同値である。
$a = 0$ のときは解なしのため不適。

**Case 1: $a > 0$ のとき**
解集合は $(-a, 3a)$ である。$(1, 2) \subseteq (-a, 3a)$ となる条件は：
$$-a \le 1 \quad \text{かつ} \quad 3a \ge 2$$
$-a \le 1 \iff a \ge -1$。$3a \ge 2 \iff a \ge \frac{2}{3}$。
$a > 0$ とあわせて、$\mathbf{a \ge \frac{2}{3}}$。

**Case 2: $a < 0$ のとき**
解集合は $(3a, -a)$ である。$(1, 2) \subseteq (3a, -a)$ となる条件は：
$$3a \le 1 \quad \text{かつ} \quad -a \ge 2$$
$3a \le 1 \iff a \le \frac{1}{3}$。$-a \ge 2 \iff a \le -2$。
$a < 0$ とあわせて、$\mathbf{a \le -2}$。

以上より、$a \le -2$ または $a \ge \frac{2}{3}$ である。
問題文の形式 $a \le \text{RS}, a \ge \frac{\text{T}}{\text{U}}$ と比較して：
$$\mathbf{RS = -2, TU = 23}$$

#### (4) $\textcircled{1}$ と $\textcircled{2}$ の両方を満たす実数 $x$ が存在しない条件
これは、区間 $(1, 2)$ と $\textcircled{2}$ の解集合が共通部分をもたない（$(1, 2) \cap \text{Sol}(\textcircled{2}) = \emptyset$）条件である。
- $a = 0$ のとき、$\text{Sol}(\textcircled{2}) = \emptyset$ であるから、共通部分は存在せず適する。
- $a > 0$ のとき、解集合は $(-a, 3a)$。ここで $-a < 0 < 1$ なので、左端は常に 1 より小さい。したがって共通部分をもたないためには、右端が 1 以下でなければならない：
$$3a \le 1 \implies a \le \frac{1}{3}$$
$a > 0$ と合わせて $0 < a \le \frac{1}{3}$。
- $a < 0$ のとき、解集合は $(3a, -a)$。ここで $3a < 0 < 1$ なので、左端は常に 1 より小さい。共通部分をもたないためには、右端が 1 以下でなければならない：
$$-a \le 1 \implies a \ge -1$$
$a < 0$ と合わせて $-1 \le a < 0$。

これらを統合すると：
$$-1 \le a \le \frac{1}{3}$$
問題文の形式 $\text{VW} \le a \le \frac{\text{X}}{\text{Y}}$ と比較して：
$$\mathbf{VW = -1, XY = 13}$$

## 第III問：素因数分解・公約数と公倍数・1次不定方程式の整数解

**【考查考点】**：素因数分解による最大公約数（GCD）と最小公倍数（LCM）, 指数方程式による条件を満たす整数の個数決定, ユークリッドの互除法とベズーの等式

### 【第III問】詳細解答と解説

#### (1) 素因数分解と最大公約数
与えられた整数は $a = 588, b = 1260$ である。
$$a = 588 = 4 \times 147 = 2^2 \times 3 \times 49 = 2^2 \times 3 \times 7^2$$
問題文の形式 $a = 2^A \cdot 3 \cdot B^C$ より：
$$\mathbf{A = 2, B = 7, C = 2} \implies \mathbf{ABC = 272}$$

$$b = 1260 = 10 \times 126 = 2 \times 5 \times 2 \times 63 = 2^2 \times 3^2 \times 5 \times 7$$
問題文の形式 $b = 2^D \cdot 3^E \cdot F \cdot G$（$F < G$）より：
$$\mathbf{D = 2, E = 2, F = 5, G = 7} \implies \mathbf{DEFG = 2257}$$

最大公約数 $\gcd(a, b)$ は、共通する素因数の最小指数をとる：
$$\gcd(a, b) = 2^{\min(2,2)} \times 3^{\min(1,2)} \times 5^{\min(0,1)} \times 7^{\min(2,1)} = 2^2 \times 3^1 \times 7^1 = 4 \times 3 \times 7 = 84$$
よって、$\mathbf{HI = 84}$。

#### (2) 条件 (i), (ii) を満たす正の整数 $c$
まず、最小公倍数 $\operatorname{lcm}(a, b)$ は：
$$\operatorname{lcm}(a, b) = 2^{\max(2,2)} \times 3^{\max(1,2)} \times 5^{\max(0,1)} \times 7^{\max(2,1)} = 2^2 \times 3^2 \times 5^1 \times 7^2$$
条件 (i): $\gcd(a, b, c) = \gcd(a, b) = 84 = 2^2 \cdot 3^1 \cdot 7^1$
条件 (ii): $\operatorname{lcm}(a, b, c) = 4 \operatorname{lcm}(a, b) = 2^{2+2} \cdot 3^2 \cdot 5^1 \cdot 7^2 = 2^4 \cdot 3^2 \cdot 5^1 \cdot 7^2$

$c$ の素因数分解を $c = 2^p \cdot 3^q \cdot 5^r \cdot 7^s$ とおく（他の素因数は持たない）：
1. **素因数 2 の指数 $p$**：
   $\max(2, 2, p) = 4$ より、必ず $\mathbf{p = 4}$ でなければならない。
   このとき $\min(2, 2, 4) = 2$ となり、条件 (i) を常に満たす（1 通り）。
2. **素因数 3 の指数 $q$**：
   $\max(1, 2, q) = 2$ より $q \le 2$。
   $\min(1, 2, q) = 1$ より $q \ge 1$。
   したがって $q \in \{1, 2\}$（2 通り）。
3. **素因数 5 の指数 $r$**：
   $\max(0, 1, r) = 1$ より $r \le 1$。
   $\min(0, 1, r) = 0$ は常に成立。
   したがって $r \in \{0, 1\}$（2 通り）。
4. **素因数 7 の指数 $s$**：
   $\max(2, 1, s) = 2$ より $s \le 2$。
   $\min(2, 1, s) = 1$ より $s \ge 1$。
   したがって $s \in \{1, 2\}$（2 通り）。

これらは独立に選べるため、$c$ の個数は積の法則より：
$$1 \times 2 \times 2 \times 2 = 8 \text{ 個}$$
よって、$\mathbf{J = 8}$。

最小の $c$ は、各素因数の指数を最小（$p=4, q=1, r=0, s=1$）にしたときである：
$$c_{\min} = 2^4 \times 3^1 \times 5^0 \times 7^1 = 16 \times 3 \times 7 = 336$$
よって、$\mathbf{KLM = 336}$。

#### (3) 1次不定方程式の整数解
方程式 $\textcircled{1}$: $588x - 1260y = 336$。
両辺を $\gcd(588, 1260) = 84$ で割ると：
$$\frac{588}{84} = 7, \quad \frac{1260}{84} = 15, \quad \frac{336}{84} = 4$$
したがって、同値な方程式 $\textcircled{2}$ は：
$$7x - 15y = 4$$
問題文の形式 $Nx - OPy = Q$ と比較して：
$$\mathbf{N = 7, OP = 15, Q = 4} \implies \mathbf{NOPQ = 7154}$$

方程式 $7x - 15y = 4$ の正の整数解で、$y$ が最小のものを求める：
$$7x = 15y + 4$$
- $y = 1$: $7x = 19$（不適）
- $y = 2$: $7x = 34$（不適）
- $y = 3$: $7x = 49 \implies x = 7$（適する！）
よって、最小の正の整数解は $\mathbf{x = 7, y = 3}$ である。
したがって、$\mathbf{R = 7, S = 3}$。

一般解は、$7$ と $15$ が互いに素であることから：
$$x = 7 + 15k, \quad y = 3 + 7k \quad (k \in \mathbb{Z})$$
問題文の形式 $x = T + UVk, y = W + Xk$ と比較して：
$$\mathbf{T = 7, UV = 15, W = 3, X = 7} \implies \mathbf{TUV = 715, WX = 37}$$

## 第IV問：円に内接する三角形・正弦余弦定理・半角余弦・面積比

**【考查考点】**：外接円の直径と円周角の定理（直角の利用）, 正弦定理・余弦定理による辺長決定, 相交弦定理（方べきの定理）と三角形の面積比

### 【第IV問】詳細解答と解説

#### (1) $\angle ABC$、辺長、および $\cos 15^\circ$ の導出
外接円 $O$ の半径 $R = \sqrt{6}$ であるから、直径 $AD = 2\sqrt{6}$。
$AC = 2\sqrt{3}$ である。
正弦定理より：
$$\frac{AC}{\sin \angle ABC} = 2R = 2\sqrt{6} \implies \sin \angle ABC = \frac{2\sqrt{3}}{2\sqrt{6}} = \frac{1}{\sqrt{2}}$$
図の配置より $\angle ABC$ は鋭角であるから：
$$\angle ABC = 45^\circ \implies \mathbf{AB = 45}$$

直径 $AD$ に対する円周角より $\angle ACD = 90^\circ$ である。
また、弧 $AC$ に対する円周角より $\angle ADC = \angle ABC = 45^\circ$。
したがって直角二等辺三角形 $\triangle ACD$ において $\angle CAD = 45^\circ$ である。
問題文より $\angle BAD = 15^\circ$ であるから：
$$\angle BAC = \angle BAD + \angle CAD = 15^\circ + 45^\circ = 60^\circ$$

再び正弦定理により $BC$ を求める：
$$\frac{BC}{\sin \angle BAC} = 2R = 2\sqrt{6} \implies BC = 2\sqrt{6} \sin 60^\circ = 2\sqrt{6} \times \frac{\sqrt{3}}{2} = 3\sqrt{2}$$
問題文の形式 $BC = C\sqrt{D}$ より：
$$\mathbf{C = 3, D = 2} \implies \mathbf{CD = 32}$$

次に $\triangle ABC$ に余弦定理を適用して $AB$ を求める：
$$BC^2 = AB^2 + AC^2 - 2 AB \cdot AC \cos \angle BAC$$
$$(3\sqrt{2})^2 = AB^2 + (2\sqrt{3})^2 - 2 AB (2\sqrt{3}) \cos 60^\circ$$
$$18 = AB^2 + 12 - 2\sqrt{3} AB \implies AB^2 - 2\sqrt{3} AB - 6 = 0$$
$AB > 0$ より解の公式を適用すると：
$$AB = \sqrt{3} + \sqrt{(\sqrt{3})^2 - (-6)} = \sqrt{3} + \sqrt{9} = \sqrt{3} + 3$$
問題文の形式 $AB = \sqrt{E} + F$ より：
$$\mathbf{E = 3, F = 3} \implies \mathbf{EF = 33}$$

また、直径 $AD$ に対する円周角より $\angle ABD = 90^\circ$ である。
直角三角形 $\triangle ABD$ において、$\angle BAD = 15^\circ$ であるから：
$$\cos 15^\circ = \frac{AB}{AD} = \frac{3 + \sqrt{3}}{2\sqrt{6}} = \frac{\sqrt{3}(\sqrt{3} + 1)}{2\sqrt{6}} = \frac{\sqrt{3} + 1}{2\sqrt{2}} = \frac{\sqrt{6} + \sqrt{2}}{4}$$
問題文の形式 $\frac{\sqrt{G} + \sqrt{H}}{I}$（$G < H$）と比較して：
$$\mathbf{G = 2, H = 6, I = 4} \implies \mathbf{GHI = 264}$$

#### (2) $\angle AEC$、線分長、および面積比
$\triangle ABE$ において、外角の性質より：
$$\angle AEC = \angle ABE + \angle BAE = 45^\circ + 15^\circ = 60^\circ \implies \mathbf{JK = 60}$$
$\triangle AEC$ において正弦定理を適用する：
$$\frac{CE}{\sin \angle CAE} = \frac{AC}{\sin \angle AEC} \implies \frac{CE}{\sin 45^\circ} = \frac{2\sqrt{3}}{\sin 60^\circ}$$
$$CE = \frac{2\sqrt{3}}{\frac{\sqrt{3}}{2}} \times \frac{\sqrt{2}}{2} = 4 \times \frac{\sqrt{2}}{2} = 2\sqrt{2}$$
問題文の形式 $CE = L\sqrt{M}$ より：
$$\mathbf{L = 2, M = 2} \implies \mathbf{LM = 22}$$

ここで $BC = 3\sqrt{2}, CE = 2\sqrt{2}$ であるから：
$$BE = BC - CE = 3\sqrt{2} - 2\sqrt{2} = \sqrt{2}$$
方べきの定理（交わる弦の性質）より：
$$AE \cdot ED = BE \cdot EC = \sqrt{2} \times 2\sqrt{2} = 4$$
また、$\triangle AEC$ において $\angle ACE = 180^\circ - 60^\circ - 45^\circ = 75^\circ$ であるから：
$$AE = \frac{AC \sin 75^\circ}{\sin 60^\circ} = \frac{2\sqrt{3} \cos 15^\circ}{\frac{\sqrt{3}}{2}} = 4 \times \frac{\sqrt{6} + \sqrt{2}}{4} = \sqrt{6} + \sqrt{2}$$
直径 $AD = 2\sqrt{6}$ より：
$$DE = AD - AE = 2\sqrt{6} - (\sqrt{6} + \sqrt{2}) = \sqrt{6} - \sqrt{2}$$
問題文の形式 $DE = \sqrt{N} - \sqrt{O}$ より：
$$\mathbf{N = 6, O = 2} \implies \mathbf{NO = 62}$$

最後に、三角形の面積比 $\triangle ABC : \triangle EAC : \triangle EBD$ を求める：
1. $\triangle ABC$ と $\triangle EAC$ は底辺を直線 $BC$ 上に共有し、頂点 $A$ が共通なので、面積比は底辺の長さの比に等しい：
   $$\frac{S_{\triangle ABC}}{S_{\triangle EAC}} = \frac{BC}{EC} = \frac{3\sqrt{2}}{2\sqrt{2}} = \frac{3}{2}$$
2. $\triangle EAC$ と $\triangle EBD$ は対頂角 $\angle AEC = \angle BED = 60^\circ$ を挟む 2 辺の積で面積比が決まる：
   $$\frac{S_{\triangle EBD}}{S_{\triangle EAC}} = \frac{\frac{1}{2} BE \cdot ED \sin 60^\circ}{\frac{1}{2} AE \cdot EC \sin 60^\circ} = \frac{BE \cdot ED}{AE \cdot EC} = \frac{\sqrt{2}(\sqrt{6} - \sqrt{2})}{(\sqrt{6} + \sqrt{2})(2\sqrt{2})} = \frac{\sqrt{6} - \sqrt{2}}{2(\sqrt{6} + \sqrt{2})}$$
   分母を有理化すると：
   $$\frac{(\sqrt{6} - \sqrt{2})^2}{2(6 - 2)} = \frac{8 - 4\sqrt{3}}{8} = \frac{2 - \sqrt{3}}{2}$$
したがって、$S_{\triangle EAC} = 2$ と置くと、$S_{\triangle ABC} = 3$、$S_{\triangle EBD} = 2 - \sqrt{3}$ となる。
したがって、面積比は：
$$\triangle ABC : \triangle EAC : \triangle EBD = \mathbf{3 : 2 : (2 - \sqrt{3})}$$
問題文の形式 $P : Q : (R - \sqrt{S})$ と比較して：
$$\mathbf{P = 3, Q = 2, R = 2, S = 3} \implies \mathbf{P = 3, Q = 2, RS = 23}$$

**【解法テクニック・易錯点】**
- $AD$ が外接円の直径であるため、円周角 $\angle ACD = 90^\circ, \angle ABD = 90^\circ$ を瞬時に想起し、直角三角形の比率や加法定理を用いずに幾何的に $\cos 15^\circ$ を求めさせる美しい誘導に乗ることが最速の解法です。
