## 第I問 問1：2次関数の最大・最小とグラフの対称移動・平行移動

**【考查考点】**：2次関数の頂点・平方完成, 動く係数と定義域における最大値・最小値の決定, 放物線のx軸対称移動とy軸平行移動

### 【第I問 問1】詳細解答と解説

**【題目大意】**
2次関数 $y = ax^2 - 6ax + 2b$ について、定義域 $1 \le x \le 4$ における最大値が $6$、最小値が $-2$ となる定数 $a, b$ を決定する問題。

#### (1) 放物線の頂点座標の算出
与えられた2次関数 $y = ax^2 - 6ax + 2b$ を平方完成する：
$$y = a(x^2 - 6x) + 2b = a((x - 3)^2 - 9) + 2b = a(x - 3)^2 - 9a + 2b$$
したがって、放物線の頂点の座標は **$(3, -9a + 2b)$** である。
問題文の形式 $(\text{A}, -\text{B}a + \text{C}b)$ と照合すると：
$$\mathbf{A = 3, B = 9, C = 2}$$（解答番号 $\mathbf{A = 3, BC = 92}$）。

#### (2) $a > 0$ の場合（下に凸の放物線）
放物線の軸は $x = 3$ であり、定義域 $1 \le x \le 4$ の内部に含まれる。
- 軸 $x = 3$ からの距離を比較すると、左端 $x = 1$ までの距離は $|1 - 3| = 2$、右端 $x = 4$ までの距離は $|4 - 3| = 1$。
- $a > 0$ のときグラフは下に凸であるため、軸から最も遠い左端 $x = 1$ で最大値をとり、頂点 $x = 3$ で最小値をとる。
よって：
$$\mathbf{D = 1, E = 3}$$

条件より最大値が $6$、最小値が $-2$ であるから：
$$y(1) = a(1)^2 - 6a(1) + 2b = -5a + 2b = 6 \quad \cdots (\text{i})$$
$$y(3) = -9a + 2b = -2 \quad \cdots (\text{ii})$$
$(\text{i}) - (\text{ii})$ より：
$$(-5a + 2b) - (-9a + 2b) = 6 - (-2) \implies 4a = 8 \implies \mathbf{a = 2}$$
これを $(\text{ii})$ に代入して：
$$-9(2) + 2b = -2 \implies 2b = 16 \implies \mathbf{b = 8}$$
$a = 2 > 0$ を満たすので適する。
よって、$\mathbf{F = 2, G = 8}$ である。

#### (3) $a < 0$ の場合（上に凸の放物線）
$a < 0$ のときグラフは上に凸であるため：
- 頂点 $x = 3$ で最大値をとり、軸から最も遠い左端 $x = 1$ で最小値をとる。
よって：
$$\mathbf{H = 3, I = 1}$$

条件より最大値が $6$、最小値が $-2$ であるから：
$$y(3) = -9a + 2b = 6 \quad \cdots (\text{iii})$$
$$y(1) = -5a + 2b = -2 \quad \cdots (\text{iv})$$
$(\text{iv}) - (\text{iii})$ より：
$$(-5a + 2b) - (-9a + 2b) = -2 - 6 \implies 4a = -8 \implies \mathbf{a = -2}$$
これを $(\text{iv})$ に代入して：
$$-5(-2) + 2b = -2 \implies 10 + 2b = -2 \implies 2b = -12 \implies \mathbf{b = -6}$$
$a = -2 < 0$ を満たすので適する。
よって、$\mathbf{JK = -2, LM = -6}$ である。

#### (4) グラフの対称移動と平行移動の関係
(2) で求めた2次関数は $f(x) = 2x^2 - 12x + 16$。
(3) で求めた2次関数は $g(x) = -2x^2 + 12x - 12$。
$f(x)$ のグラフを $x$ 軸に関して対称移動した放物線の方程式は：
$$y = -f(x) = -(2x^2 - 12x + 16) = -2x^2 + 12x - 16$$
この放物線を $y$ 軸方向に $N$ だけ平行移動すると：
$$y = -2x^2 + 12x - 16 + N$$
これが $g(x) = -2x^2 + 12x - 12$ に一致するためには：
$$-16 + N = -12 \implies \mathbf{N = 4}$$
よって、$\mathbf{N = 4}$ である。

## 第I問 問2：3色カードの同時抽出・確率と余事象の計算

**【考查考点】**：組合せの総数 $\binom{n}{r}$, 同色・異色の確率計算, 条件を満たす整数の和の組合せ, 余事象と包除原理の応用

### 【第I問 問2】詳細解答と解説

**【題目大意】**
袋の中に白色カード2枚（1, 2）、赤色カード3枚（3, 4, 5）、青色カード4枚（6, 7, 8, 9）の計9枚が入っている。
この袋から同時に3枚のカードを取り出す試行を行う。すべての取り出し方の総数は：
$$N = \binom{9}{3} = \frac{9 \times 8 \times 7}{3 \times 2 \times 1} = 84$$

#### (1) 同色および全異色の確率
1. **3枚とも同じ色である事象**：
   - 白色は2枚しかないため、白色3枚はあり得ない。
   - 赤色3枚を取り出す方法：$\binom{3}{3} = 1$ 通り。
   - 青色3枚を取り出す方法：$\binom{4}{3} = 4$ 通り。
   合計 $1 + 4 = 5$ 通り。
   したがって、確率は $\frac{5}{84}$ である。よって $\mathbf{OPQ = 584}$。

2. **3枚とも異なる色である事象**：
   白色から1枚、赤色から1枚、青色から1枚を取り出す方法：
   $$\binom{2}{1} \times \binom{3}{1} \times \binom{4}{1} = 2 \times 3 \times 4 = 24 \text{ 通り}$$
   したがって、確率は $\frac{24}{84} = \frac{2}{7}$ である。よって $\mathbf{RS = 27}$。

#### (2) 取り出された3枚のカードの数の和が10である確率
取り出せるカードの数は 1 から 9 までの相異なる3数である。
和が 10 となる 3 数の組合せ $(x < y < z)$ を辞書式に漏れなく列挙する：
- $x = 1$ のとき：$y + z = 9$ かつ $1 < y < z$ より：
  - $(1, 2, 7)$
  - $(1, 3, 6)$
  - $(1, 4, 5)$
- $x = 2$ のとき：$y + z = 8$ かつ $2 < y < z$ より：
  - $(2, 3, 5)$
- $x \ge 3$ のとき：最小の和は $3 + 4 + 5 = 12 > 10$ となり存在しない。
該当する組合せは上記の **4通り** のみである。
各カードはすべて数字が異なるため、それぞれ1通りずつ取り出せる。
したがって、和が 10 となる確率は：
$$\frac{4}{84} = \frac{1}{21}$$
よって、$\mathbf{TUV = 121}$ である。

#### (3) 異なる色のカードが少なくとも2枚含まれ、かつ偶数が少なくとも1枚含まれる確率
全事象 $U$（$|U| = 84$）において、条件を満たさない事象の余事象を考える。
- 事象 $A$：「3枚のカードがすべて同じ色である」
- 事象 $B$：「3枚のカードがすべて奇数である」
求める事象は $\overline{A} \cap \overline{B} = \overline{A \cup B}$ である。

1. **$|A|$ の要素数**：
   (1) より、すべて同色となるのは 5 通り（赤3枚：{3,4,5}、青3枚：{6,7,8}, {6,7,9}, {6,8,9}, {7,8,9}）。
   この 5 通りにはいずれも少なくとも 1 枚の偶数（赤なら4、青なら6または8）が含まれている。
2. **$|B|$ の要素数（すべて奇数）**：
   カードの中の奇数は {1, 3, 5, 7, 9} の計 5 枚（白1枚、赤2枚、青2枚）。
   この 5 枚から 3 枚を取り出す方法の総数は：
   $$|B| = \binom{5}{3} = 10 \text{ 通り}$$
3. **$A \cap B$ の要素数（同色かつすべて奇数）**：
   同色で3枚取り出すには赤または青でなければならないが、赤の奇数は2枚（3,5）、青の奇数は2枚（7,9）しかなく、3枚の奇数を同じ色から取ることはできない。
   したがって、$A \cap B = \emptyset$（空集合、0通り）である。

よって、包除原理より：
$$|A \cup B| = |A| + |B| - |A \cap B| = 5 + 10 - 0 = 15 \text{ 通り}$$
求める事象の要素数は：
$$84 - 15 = 69 \text{ 通り}$$
したがって、求める確率は：
$$\frac{69}{84} = \frac{23}{28}$$
よって、$\mathbf{WXYZ = 2328}$ である。

## 第II問 問1：無理数の整数部分・小数部分と有理数方程式

**【考查考点】**：根号を含む数の評価・整数部分と小数部分, 有理数と無理数の相等の原理, 連立方程式の解法

### 【第II問 問1】詳細解答と解説

**【題目大意】**
$3\sqrt{5} + 2$ の整数部分を $a$、小数部分を $b$ とする。このとき $\frac{x}{b} + \frac{b}{y} = a$ を満たす有理数 $x, y$ を求める。

#### (1) $a$ と $b$ の決定
$3\sqrt{5} = \sqrt{45}$ である。$36 < 45 < 49$ より：
$$6 < 3\sqrt{5} < 7$$
したがって $\mathbf{A = 6}$ である。
各辺に 2 を加えると：
$$8 < 3\sqrt{5} + 2 < 9$$
よって、$3\sqrt{5} + 2$ の整数部分は **$a = 8$**（$\mathbf{B = 8}$）。
小数部分 $b$ は元の数から整数部分を引いたものであるから：
$$b = (3\sqrt{5} + 2) - 8 = 3\sqrt{5} - 6$$
したがって $\mathbf{C = 6}$ である。

#### (2) 式の変形と恒等関係の導出
$\frac{x}{b} + \frac{b}{y}$ に $b = 3\sqrt{5} - 6$ を代入して通分・有理化する：
まず、$\frac{x}{b} = \frac{x}{3(\sqrt{5} - 2)} = \frac{x(\sqrt{5} + 2)}{3(5 - 4)} = \frac{x(\sqrt{5} + 2)}{3}$。
これと $\frac{b}{y} = \frac{3\sqrt{5} - 6}{y}$ を通分すると：
$$\frac{x}{b} + \frac{b}{y} = \frac{xy(\sqrt{5} + 2) + 3(3\sqrt{5} - 6)}{3y} = \frac{(xy + 9)\sqrt{5} + (2xy - 18)}{3y} = \frac{(xy + 9)\sqrt{5} + 2(xy - 9)}{3y}$$
問題文の形式 $\frac{(xy + \text{D})\sqrt{5} + \text{E}(xy - \text{F})}{\text{G}y}$ と照合すると：
$$\mathbf{D = 9, E = 2, F = 9, G = 3}$$（解答番号 $\mathbf{DEFG = 9293}$）。

この式の値が整数 $B = 8$ に等しい：
$$\frac{(xy + 9)\sqrt{5} + 2(xy - 9)}{3y} = 8$$
両辺に $3y$ を掛けると：
$$(xy + 9)\sqrt{5} + 2(xy - 9) = 24y$$
$(xy + 9)\sqrt{5} + (2(xy - 9) - 24y) = 0$
$x, y$ は有理数であるから、$xy + 9$ および $2(xy - 9) - 24y$ も有理数である。
$\sqrt{5}$ は無理数であるため、「有理数と無理数の相等」より：
$$xy + 9 = 0 \implies \mathbf{H = 0}$$
かつ
$$2(xy - 9) - 24y = 0 \implies xy - 9 = 12y$$
問題文の $xy - \text{F} = \text{IJ}y$ と比較して $\mathbf{IJ = 12}$。

#### (3) $x, y$ の値の決定
$xy + 9 = 0$ より $xy = -9$。
これを $xy - 9 = 12y$ に代入すると：
$$-9 - 9 = 12y \implies 12y = -18 \implies y = -\frac{18}{12} = -\frac{3}{2}$$
よって、$y = -\frac{L}{M}$ より $\mathbf{L = 3, M = 2}$（解答番号 $\mathbf{LM = 32}$）。
また、$x = \frac{-9}{y} = \frac{-9}{-3/2} = 6$。
よって、$\mathbf{K = 6}$ である。

## 第II問 問2：2次方程式の解の配置・判別式と軸・端点値の条件

**【考查考点】**：2次方程式の判別式 $D/4 > 0$, 解の配置問題（2正解条件、異符号解条件）, 指定区間 $(0, 2)$ および $(2, \infty)$ に解をもつ条件

### 【第II問 問2】詳細解答と解説

**【題目大意】**
2次関数 $f(x) = 2x^2 - 4ax + 2a^2 + a - 3$ に対し、2次方程式 $f(x) = 0 \quad \cdots \textcircled{1}$ の解の存在範囲に関する条件を求める。

#### (1) 異なる2つの実数解をもつ条件
方程式 $\textcircled{1}$ の判別式を $D$ とすると：
$$\frac{D}{4} = (-2a)^2 - 2(2a^2 + a - 3) = 4a^2 - 4a^2 - 2a + 6 = -2a + 6$$
異なる2つの実数解をもつ条件は $\frac{D}{4} > 0$ であるから：
$$-2a + 6 > 0 \implies 2a < 6 \implies a < 3$$
したがって、$\mathbf{N = 3}$ である。

#### (2) 2解がともに正である条件
$y = f(x)$ のグラフは下に凸で、軸の方程式は $x = a$、頂点の $y$ 座標は $a - 3$ である。
異なる2つの解がともに正であるための必要十分条件は次の3点である：
1. $\frac{D}{4} > 0 \iff a < 3$
2. 軸が正：$a > 0$
3. 端点値 $f(0) > 0$：
   $$f(0) = 2a^2 + a - 3 > 0$$
   因数分解して $(2a + 3)(a - 1) > 0 \iff a < -\frac{3}{2}$ または $a > 1$

これら3つの共通範囲をとると：
$$a < 3 \quad \text{かつ} \quad a > 0 \quad \text{かつ} \quad (a < -\frac{3}{2} \text{ または } a > 1)$$
$$\implies 1 < a < 3$$
したがって、$\mathbf{O = 1, P = 3}$ である。

#### (3) 一方が正で他方が負である条件（異符号解）
下に凸の放物線において、解が原点 $x = 0$ を挟んで1つずつ存在するための必要十分条件は、端点値 $f(0) < 0$ である（このとき自動的に $D > 0$ も満たされる）：
$$f(0) = 2a^2 + a - 3 < 0$$
$$(2a + 3)(a - 1) < 0 \implies -\frac{3}{2} < a < 1$$
問題文の形式 $\frac{\text{QR}}{\text{S}} < a < \text{T}$ と照合すると：
$$\mathbf{QR = -3, S = 2, T = 1}$$
解答番号 $\mathbf{QRS = -32, T = 1}$ である。

#### (4) 一方が $0 < x < 2$、他方が $x > 2$ にある条件
下に凸の放物線が $0 < x < 2$ と $x > 2$ の領域に1つずつ解をもつための条件は：
- $x = 0$ でグラフが正：$f(0) > 0$
- $x = 2$ でグラフが負：$f(2) < 0$
（$f(2) < 0$ により異なる2解が存在し、その間を $x = 2$ が通り、$f(0) > 0$ より小さいほうの解は $0$ より右にある）

1. $f(0) > 0 \iff a < -\frac{3}{2}$ または $a > 1$
2. $f(2) < 0$：
   $$f(2) = 2(2)^2 - 4a(2) + 2a^2 + a - 3 = 8 - 8a + 2a^2 + a - 3 = 2a^2 - 7a + 5$$
   因数分解して $(2a - 5)(a - 1) < 0 \iff 1 < a < \frac{5}{2}$

1 と 2 の共通範囲をとると：
$$1 < a < \frac{5}{2}$$
問題文の形式 $\text{U} < a < \frac{\text{V}}{\text{W}}$ と比較して：
$$\mathbf{U = 1, V = 5, W = 2}$$
解答番号 $\mathbf{U = 1, VW = 52}$ である。

## 第III問（前半）：合同式と一次不定方程式による整数の表現

**【考查考点】**：中国剰余定理（Chinese Remainder Theorem）の解法手順, 連立一次不定方程式の特解の構成, パラメータ表示の導出

### 【第III問 前半】詳細解答と解説

**【題目大意】**
条件を満たす整数 $N$ を求める：
- 3 で割り切れる：$N = 3x \quad \cdots \textcircled{1}$
- 5 で割ると 3 余る：$N = 5y + 3 \quad \cdots \textcircled{2}$
- 7 で割ると 4 余る：$N = 7z + 4 \quad \cdots \textcircled{3}$

#### (1) $\textcircled{1}, \textcircled{2}$ から $y$ の関係式の導出
$3x = 5y + 3$ より：
$$3x - 3 = 5y \implies 3(x - 1) = 5y$$
したがって $\mathbf{A = 3, B = 1, C = 5}$（解答番号 $\mathbf{ABC = 315}$）。
3 と 5 は互いに素であるから、$y$ は 3 の倍数でなければならない。
整数 $k$ を用いて $y = 3k$ と表される。よって $\mathbf{D = 3}$ である。

#### (2) $\textcircled{2}, \textcircled{3}$ から $y$ の関係式の導出
$5y + 3 = 7z + 4$ より：
$$7z - 5y = -1$$
特解として $z = 2, y = 3$ を見つけると、$7(2) - 5(3) = 14 - 15 = -1$ が成り立つ。
辺々引いて：
$$7(z - 2) - 5(y - 3) = 0 \implies 7(z - 2) = 5(y - 3)$$
したがって $\mathbf{E = 7, F = 2, G = 3}$（解答番号 $\mathbf{EFG = 723}$）。
7 と 5 は互いに素であるから、$y - 3$ は 7 の倍数である。
整数 $l$ を用いて $y - 3 = 7l \implies y = 7l + 3$ と表される。
したがって $\mathbf{H = 7, I = 3}$（解答番号 $\mathbf{HI = 73}$）。

#### (3) $k$ と $l$ の連立から $k$ のパラメータ表示の導出
$y = 3k$ かつ $y = 7l + 3$ より：
$$7l + 3 = 3k \implies 7l = 3k - 3 = 3(k - 1)$$
問題文の形式 $\text{H}l = \text{D}(k - \text{J})$ と照合して $\mathbf{J = 1}$。
7 と 3 は互いに素であるから、$k - 1$ は 7 の倍数である。
整数 $m$ を用いて：
$$k - 1 = 7m \implies k = 7m + 1$$
したがって $\mathbf{K = 7}$ である。

## 第III問（後半）：一般解の決定と3桁最小値・500以下の自然数の個数

**【考查考点】**：周期（公倍数）の決定 $105m + 18$, 条件を満たす最小の自然数の決定, 範囲内の整数個数カウントと最大値

### 【第III問 後半】詳細解答と解説

#### (1) $N$ の一般式の導出
前半で得られた $k = 7m + 1$ を $y = 3k$ に代入すると：
$$y = 3(7m + 1) = 21m + 3$$
これを $\textcircled{2}$ $N = 5y + 3$ に代入すると：
$$N = 5(21m + 3) + 3 = 105m + 15 + 3 = 105m + 18$$
問題文の形式 $N = \text{LMN}m + \text{OP}$ と照合して：
$$\mathbf{LMN = 105, OP = 18}$$（解答番号 $\mathbf{LMNOP = 10518}$）。

#### (2) 条件を満たす3桁の最小の自然数
$N = 105m + 18$ において $m$ は整数である。
- $m = 0$ のとき：$N = 18$（2桁）
- $m = 1$ のとき：$N = 105(1) + 18 = 123$（3桁）
したがって、3桁の最小の自然数は **123** である。
よって、$\mathbf{QRS = 123}$ である。

#### (3) 500以下の自然数の個数と最大値
条件を満たす自然数（$N > 0$）かつ $N \le 500$ となる $m$ の範囲を求める：
$$105m + 18 > 0 \implies m \ge 0$$
$$105m + 18 \le 500 \implies 105m \le 482 \implies m \le \frac{482}{105} = 4.59...$$
したがって、$m$ は $0, 1, 2, 3, 4$ の **5個** の整数値をとる。
よって、500以下の自然数は **5個** ある（$\mathbf{T = 5}$）。

その中で最も大きい自然数は $m = 4$ のときであり：
$$N = 105 \times 4 + 18 = 420 + 18 = 438$$
よって、$\mathbf{UVW = 438}$ である。

## 第IV問（前半）：余弦定理と角の二等分線定理による線分長の決定

**【考查考点】**：三角形における余弦定理, 角の二等分線定理 $AB : AD = BC : CD$, 2次方程式の連立と線分長の決定

### 【第IV問 前半】詳細解答と解説

**【題目大意】**
$\triangle ABC$ は $AB = 4, BC = 2, CA = 3$ を満たす。
辺 $BC$ の延長上に $\angle CAD = \angle BAC$ となる点 $D$ をとる。
線分 $AD$ の长さを $x$、線分 $CD$ の長さを $y$ とする。

#### (1) $\cos \angle BAC$ の計算
$\triangle ABC$ において余弦定理を適用する：
$$\cos \angle BAC = \frac{AB^2 + CA^2 - BC^2}{2 \cdot AB \cdot CA} = \frac{4^2 + 3^2 - 2^2}{2 \cdot 4 \cdot 3} = \frac{16 + 9 - 4}{24} = \frac{21}{24} = \frac{7}{8}$$
したがって、$\mathbf{AB = 78}$ である。

#### (2) $\triangle ACD$ における余弦定理と関係式の導出
$\angle CAD = \angle BAC$ より $\cos \angle CAD = \frac{7}{8}$ である。
$\triangle ACD$ において、辺は $AC = 3, CD = y, AD = x$ であるから、余弦定理より：
$$CD^2 = AC^2 + AD^2 - 2 \cdot AC \cdot AD \cos \angle CAD$$
$$y^2 = 3^2 + x^2 - 2 \cdot 3 \cdot x \cdot \frac{7}{8} = x^2 - \frac{21}{4}x + 9$$
移項して整理すると：
$$x^2 - y^2 - \frac{21}{4}x + 9 = 0$$
問題文の形式 $x^2 - y^2 - \frac{\text{CD}}{\text{E}}x + \text{F} = 0$ と照合して：
$$\mathbf{CD = 21, E = 4, F = 9}$$（解答番号 $\mathbf{CDEF = 2149}$）。

#### (3) 角の二等分線定理と $x, y$ の算出
$\triangle ABD$ において、線分 $AC$ は $\angle BAD$ の内角の二等分線である（$\angle BAC = \angle CAD$）。
したがって、角の二等分線定理より：
$$\frac{AB}{AD} = \frac{BC}{CD} \implies \frac{4}{x} = \frac{2}{y} \implies x = 2y$$
したがって $\mathbf{G = 2}$ である。

この $y = \frac{x}{2}$ を先ほどの関係式に代入する：
$$x^2 - \left(\frac{x}{2}\right)^2 - \frac{21}{4}x + 9 = 0$$
$$\frac{3}{4}x^2 - \frac{21}{4}x + 9 = 0$$
両辺に $\frac{4}{3}$ を掛けると：
$$x^2 - 7x + 12 = 0 \implies (x - 3)(x - 4) = 0$$
ここで点 $D$ は辺 $BC$ の $C$ 側の延長上にある。
もし $x = 4$ とすると $y = 2$ となり、$CD = 2 = BC$ となるが、このとき $\triangle ABD$ は $AB = AD = 4$ の二等辺三角形となり、$AC$ は底辺の中点を通るため $AC \perp BD$ となる。しかし $\cos \angle BCA = \frac{2^2 + 3^2 - 4^2}{2 \cdot 2 \cdot 3} = -\frac{3}{12} = -\frac{1}{4} \neq 0$ であるため不適である。
したがって適するのは **$x = 3$** である。
よって：
$$x = 3, \quad y = \frac{3}{2}$$
$\mathbf{H = 3, I = 3, J = 2}$（解答番号 $\mathbf{H = 3, IJ = 32}$）。

## 第IV問（後半）：三角形の面積比・内接円の半径比・内心間距離の決定

**【考查考点】**：三角形の面積比（底辺の比）, 内接円の半径と周長・面積の公式 $S = \frac{1}{2}r(a+b+c)$, 内心の性質と内心間距離の幾何学的導出

### 【第IV問 後半】詳細解答と解説

#### (1) 面積比と内接円の半径比
1. **面積比 $\frac{S_2}{S_1}$**：
   $\triangle ABC$ と $\triangle ABD$ は共通の頂点 $A$ をもち、底辺 $BC$ と $BD$ は同一直線上にある。
   したがって、面積比は底辺の長さの比に等しい：
   $$BD = BC + CD = 2 + \frac{3}{2} = \frac{7}{2}$$
   $$\frac{S_2}{S_1} = \frac{BD}{BC} = \frac{7/2}{2} = \frac{7}{4}$$

2. **内接円の半径比 $\frac{r_2}{r_1}$**：
   三角形の面積と内接円の半径 $r$、周の長さ $L$ の関係式 $S = \frac{1}{2}r L \implies r = \frac{2S}{L}$ より：
   $$\frac{r_2}{r_1} = \frac{S_2}{S_1} \times \frac{L_1}{L_2}$$
   各三角形の周長を計算すると：
   - $\triangle ABC$ の周長：$L_1 = AB + BC + CA = 4 + 2 + 3 = 9$
   - $\triangle ABD$ の周長：$L_2 = AB + BD + DA = 4 + \frac{7}{2} + 3 = 7 + \frac{7}{2} = \frac{21}{2}$
   したがって：
   $$\frac{L_1}{L_2} = \frac{9}{21/2} = \frac{18}{21} = \frac{6}{7}$$
   よって、$\frac{r_2}{r_1} = \frac{6}{7}\frac{S_2}{S_1}$ であり、$\mathbf{KL = 67}$ である。
   さらに数値を代入すると：
   $$\frac{r_2}{r_1} = \frac{6}{7} \times \frac{7}{4} = \frac{6}{4} = \frac{3}{2}$$
   したがって、$\mathbf{MN = 32}$ である。

#### (2) 内心間距離 $I_1 I_2$ の算出
内心 $I_1$ は $\triangle ABC$ の内角の二等分線の交点、$I_2$ は $\triangle ABD$ の内角の二等分線の交点である。
$B, C, D$ は一直線上にあるため、$\angle ABD$ は $\angle ABC$ そのものである。
したがって、$\angle B$ の内角の二等分線上に $I_1$ と $I_2$ がともに乗っている。
すなわち、**$B, I_1, I_2$ は一直線上にある**。

1. **線分 $BI_2$ の長さ $l$**：
   $\triangle ABD$ において、各辺は $AB = 4, BD = \frac{7}{2}, DA = 3$ である。
   $I_2$ は角の二等分線の交点であり、公式により：
   $$BI_2^2 = c a \left(1 - \frac{b^2}{(a+c)^2}\right) \quad (a = BD = 7/2, c = AB = 4, b = DA = 3)$$
   あるいは $\triangle ABI_2$ に余弦定理を適用して計算する：
   余弦定理より $\cos \angle B = \frac{4^2 + (7/2)^2 - 3^2}{2 \cdot 4 \cdot (7/2)} = \frac{16 + 49/4 - 9}{28} = \frac{77/4}{28} = \frac{11}{16}$。
   半角の公式より $\cos^2 \frac{B}{2} = \frac{1 + \cos B}{2} = \frac{1 + 11/16}{2} = \frac{27}{32}$。
   角の二等分線と対辺の交点や内接円の幾何関係から解くと、$l = \sqrt{6}$ が得られる。
   したがって $\mathbf{O = 6}$ である。

2. **比率 $\frac{I_1 I_2}{BI_1}$**：
   同様に $BI_1$ を求めると、$BI_1 = \frac{2}{3}\sqrt{6}$ となり、$BI_2 = \sqrt{6}$ であるから：
   $$I_1 I_2 = BI_2 - BI_1 = \sqrt{6} - \frac{2}{3}\sqrt{6} = \frac{1}{3}\sqrt{6}$$
   したがって：
   $$\frac{I_1 I_2}{BI_1} = \frac{\frac{1}{3}\sqrt{6}}{\frac{2}{3}\sqrt{6}} = \frac{1}{2}$$
   よって、$\mathbf{PQ = 12}$ である。
   また、$I_1 I_2 = \frac{\sqrt{6}}{3}$ であるから、$\mathbf{R = 6, S = 3}$（解答番号 $\mathbf{RS = 63}$）である。
