## 数学 コース1 第I問 [1]：2次関数の頂点・最小値と連立方程式の重解条件

**問題コード**: `math-q-I_1` | **配点参照**: `I:1` | **正解**: `A = 3, BC = 45, DEFG = 4410, H = 2, IJ = -4, K = 3`

### 出題のポイント
- 平方完成による2次関数の最小値の決定
- 2つの放物線の交点方程式と接合条件（判別式 $D=0$）
- 正の実数条件 $a>0$ に基づく係数と接点 $x$ の一意決定

### 詳細解説
**【題目大意】**
$a, b$ は実数であり、$a > 0$ とする。2つの2次関数
$$f(x) = 2x^2 - 4x + 5, \quad g(x) = x^2 + ax + b$$
を考える。$g(x)$ が次の2つの条件を満たすとき、$a, b$ の値を求める。
(i) $g(x)$ の最小値は $f(x)$ の最小値より $8$ だけ小さい
(ii) $f(x) = g(x)$ を満たす $x$ がただ1つ存在する

**【公式正解】**
$\text{A} = 3$
$\text{BC} = 45$ （$b = \frac{a^2}{4} - 5$）
$\text{DEFG} = 4410$ （$x^2 - (a + 4)x - \frac{a^2}{4} + 10 = 0$）
$\text{H} = 2$
$\text{IJ} = -4$
$\text{K} = 3$

**【詳細推導・解答プロセス】**
**(1) $f(x)$ と $g(x)$ の最小値と条件 (i)**
$f(x)$ を平方完成すると：
$$f(x) = 2(x^2 - 2x) + 5 = 2(x - 1)^2 + 3$$
したがって、$f(x)$ の最小値は **3** である（$\text{A} = 3$）。

$g(x)$ を平方完成すると：
$$g(x) = \left(x + \frac{a}{2}\right)^2 + b - \frac{a^2}{4}$$
したがって、$g(x)$ の最小値は $b - \frac{a^2}{4}$ である。
条件 (i)「$g(x)$ の最小値は $f(x)$ の最小値より8だけ小さい」より：
$$b - \frac{a^2}{4} = 3 - 8 = -5 \implies b = \frac{a^2}{4} - 5$$
これより、$b = \frac{a^2}{\text{B}} - \text{C}$ の空欄は $\text{BC} = 45$ である。

**(2) 交点方程式と条件 (ii)**
$f(x) = g(x)$ を満たす $x$ を求める方程式は：
$$2x^2 - 4x + 5 = x^2 + ax + b \iff x^2 - (a + 4)x + (5 - b) = 0$$
ここに $b = \frac{a^2}{4} - 5$ を代入すると、定数項は：
$$5 - b = 5 - \left(\frac{a^2}{4} - 5\right) = -\frac{a^2}{4} + 10$$
よって、方程式は：
$$x^2 - (a + 4)x - \frac{a^2}{4} + 10 = 0$$
となり、$\text{D} = 4$、$\text{E} = 4$、$\text{FG} = 10$（合わせて $\text{DEFG} = 4410$）を得る。

条件 (ii)「解がただ1つ存在する」より、この2次方程式の判別式 $D_0$ は $0$ でなければならない：
$$D_0 = [-(a + 4)]^2 - 4 \cdot 1 \cdot \left(-\frac{a^2}{4} + 10\right) = 0$$
$$(a^2 + 8a + 16) + a^2 - 40 = 0$$
$$2a^2 + 8a - 24 = 0 \iff a^2 + 4a - 12 = 0$$
$$(a + 6)(a - 2) = 0$$
$a > 0$ であるから：
$$a = 2 \quad (\text{H} = 2)$$
このとき、$b$ の値は：
$$b = \frac{2^2}{4} - 5 = 1 - 5 = -4 \quad (\text{IJ} = -4)$$
また、$a = 2$ のときの方程式は：
$$x^2 - 6x + 9 = 0 \iff (x - 3)^2 = 0$$
より、解は重解 $x = 3$（$\text{K} = 3$）である。

**【考査考点】**
- 2次関数の標準形への変形（平方完成）と頂点の座標・最小値の決定。
- 2つの放物線の共有点と2次方程式の判別式（重解条件 $D=0$）。

## 数学 コース1 第I問 [2]：集合と命題（必要十分条件）およびド・モルガンの法則による要素数計算

**問題コード**: `math-q-I_2` | **配点参照**: `I:2` | **正解**: `L = 2, M = 1, N = 3, O = 0, PQ = 92, RS = 67`

### 出題のポイント
- 倍数集合における包含関係と命題の必要条件・十分条件の判定
- ド・モルガンの法則：$\overline{A} \cup \overline{B} = \overline{A \cap B}$ および $\overline{A} \cap \overline{B} = \overline{A \cup B}$
- 包含と排除の原理による補集合の要素数 $|\overline{A} \cap C|$ 等の計算

### 詳細解説
**【題目大意】**
自然数の部分集合 $A = \{4m \mid m \in \mathbb{N}\}$（4の倍数集合）、$B = \{6m \mid m \in \mathbb{N}\}$（6の倍数集合）を考える。
(1) 自然数 $n$ に対する各命題の必要・十分条件を判定する。
(2) $C = \{1, 2, \dots, 100\}$ に対し、$(\overline{A} \cup \overline{B}) \cap C$ および $\overline{A} \cap \overline{B} \cap C$ の要素の個数を求める。

**【公式正解】**
$\text{L} = 2$ （十分条件であるが，必要条件ではない）
$\text{M} = 1$ （必要条件であるが，十分条件ではない）
$\text{N} = 3$ （必要条件でも十分条件でもない）
$\text{O} = 0$ （必要十分条件である）
$\text{PQ} = 92$
$\text{RS} = 67$

**【詳細推導・解答プロセス】**
**(1) 必要・十分条件の判定**
- (i) $n \in A$（$n$ は4の倍数） $\implies$ $n$ は2で割り切れる（真）。一方、$n$ が2で割り切れる（例：$n=2$） $\implies$ $n \in A$（偽）。よって、十分条件であるが，必要条件ではない（$\text{L} = 2$）。
- (ii) $n \in B$（$n$ は6の倍数） $\Longleftarrow$ $n$ が24で割り切れる（真）。一方、$n \in B$（例：$n=6$） $\implies$ $n$ が24で割り切れる（偽）。よって、必要条件であるが，十分条件ではない（$\text{M} = 1$）。
- (iii) $n \in A \cup B$（$n$ は4の倍数または6の倍数）。$n=4 \in A \cup B$ は3で割り切れない（十分条件ではない）。また、$n=3$ は3で割り切れるが $A \cup B$ に属さない（必要条件ではない）。よって、必要条件でも十分条件でもない（$\text{N} = 3$）。
- (iv) $n \in A \cap B$ は「$n$ は4の倍数かつ6の倍数」であり、$\text{lcm}(4, 6) = 12$ より「$n$ は12の倍数」と同値である。よって、必要十分条件である（$\text{O} = 0$）。

**(2) 集合の要素の個数計算**
$C = \{1, 2, \dots, 100\}$ において、要素の総数は $|C| = 100$ である。
- $|A \cap C| = \lfloor 100 / 4 \rfloor = 25$
- $|B \cap C| = \lfloor 100 / 6 \rfloor = 16$
- $|A \cap B \cap C| = \lfloor 100 / 12 \rfloor = 8$

ド・モルガンの法則より：
$$\overline{A} \cup \overline{B} = \overline{A \cap B}$$
したがって：
$$|(\overline{A} \cup \overline{B}) \cap C| = |C| - |(A \cap B) \cap C| = 100 - 8 = 92 \quad (\text{PQ} = 92)$$

また：
$$\overline{A} \cap \overline{B} = \overline{A \cup B}$$
包除原理より：
$$|(A \cup B) \cap C| = |A \cap C| + |B \cap C| - |A \cap B \cap C| = 25 + 16 - 8 = 33$$
したがって：
$$|(\overline{A} \cap \overline{B}) \cap C| = |C| - |(A \cup B) \cap C| = 100 - 33 = 67 \quad (\text{RS} = 67)$$

**【考査考点】**
- 命題と論理（必要条件・十分条件・必要十分条件）の正確な識別。
- 集合の演算（和集合・共通部分・補集合）とド・モルガンの法則。
- 有限集合の要素の個数の計算（ガウス記号による倍数カウントと包除原理）。

## 数学 コース1 第II問 [1]：順列・組み合わせ（同じものを含む順列と隣り合わない配置）

**問題コード**: `math-q-II_1` | **配点参照**: `II:1` | **正解**: `ABC = 720, DEF = 120, GHI = 360, J = 6, KL = 24, MNO = 288`

### 出題のポイント
- 同じ文字を含む単語 POSITION の文字構成（P:1, O:2, S:1, I:2, T:1, N:1）の把握
- 隣り合う条件（ブロック化法）と端に位置する条件の順列計算
- 隣り合わない条件（挿入法・すきまへの配置）と端の条件の組み合わせ

### 詳細解説
**【題目大意】**
単語 `POSITION` を構成する8文字（P, O, S, I, T, I, O, N：Iが2個、Oが2個、P, S, T, Nが各1個）を横一列に並べ替える。
(1) 2つのIが隣り合い、2つのOも隣り合う並べ方。
(2) 2つのIが両端に位置し、2つのOが隣り合う並べ方。
(3) 2つのIが両端に位置する並べ方。
(4) 8文字のうち、どちらかの端にはIかOが位置し、N, P, S, Tのどの2文字も隣り合わない並べ方。

**【公式正解】**
$\text{ABC} = 720$
$\text{DEF} = 120$
$\text{GHI} = 360$
$\text{J} = 6$
$\text{KL} = 24$
$\text{MNO} = 288$

**【詳細推導・解答プロセス】**
8文字の内訳は、Iが2個、Oが2個、P, S, T, Nが各1個である。

**(1) 2つのIが隣り合い、2つのOも隣り合う並べ方**
`II` を1つの塊、`OO` を1つの塊とみなすと、並べる対象は [II], [OO], P, S, T, N の6個の異なる要素となる。
これらを一列に並べる並べ方は：
$$6! = 720 \text{ 通り} \quad (\text{ABC} = 720)$$

**(2) 2つのIが両端に位置し、2つのOが隣り合う並べ方**
配置は `I _ _ _ _ _ _ I` である（2つのIは同種なので両端の配置は1通り）。
中間の6箇所に O, O, P, S, T, N を配置する。2つのOが隣り合うため、`OO` を1つの塊とみなすと、[OO], P, S, T, N の5個の異なる要素を並べることになる：
$$5! = 120 \text{ 通り} \quad (\text{DEF} = 120)$$

**(3) 2つのIが両端に位置する並べ方**
中間の6箇所に O, O, P, S, T, N（6文字、うちOが2個）を自由に並べる：
$$\frac{6!}{2!} = \frac{720}{2} = 360 \text{ 通り} \quad (\text{GHI} = 360)$$

**(4) 端にIまたはOがあり、N, P, S, Tのどの2つも隣り合わない並べ方**
- I, I, O, O の4文字を並べる並べ方は、同じものを含む順列より：
  $$J = \frac{4!}{2!2!} = \frac{24}{4} = 6 \text{ 通り} \quad (\text{J} = 6)$$
- N, P, S, T の4文字を並べる並べ方は：
  $$KL = 4! = 24 \text{ 通り} \quad (\text{KL} = 24)$$
- 4文字の母音群（I, I, O, O）を並べると、その両端および間に計 5 つの「すきま」ができる：
  $$\underline{\quad 1 \quad} \text{ X } \underline{\quad 2 \quad} \text{ X } \underline{\quad 3 \quad} \text{ X } \underline{\quad 4 \quad} \text{ X } \underline{\quad 5 \quad}$$
  子音4文字（N, P, S, T）がどの2つも隣り合わないためには、この5つのすきまから4箇所を選んで各1文字ずつ配置すればよい。
  すきまの選び方は全部で $\binom{5}{4} = 5$ 通りある。
  ここで、「どちらかの端にはIかOが位置する」という条件は、「両端がともに子音（すきま1とすきま5の両方に子音が入る）ではない」ということである。
  両端（すきま1と5）に子音が配置される選び方は、残りの3つのすきま（2, 3, 4）から2箇所を選ぶ $\binom{3}{2} = 3$ 通りである。
  したがって、条件を満たす（少なくとも一端がIまたはOとなる）すきまの選び方は：
  $$5 - 3 = 2 \text{ 通り}$$
  （※すきま1のみを選ぶ場合が $\binom{3}{3}=1$ 通り、すきま5のみを選ぶ場合が $\binom{3}{3}=1$ 通りで計2通りと直接数えてもよい）。
- よって、全体の並べ方は：
  $$(\text{I, I, O, O の並べ方}) \times (\text{すきまの選び方}) \times (\text{N, P, S, T の並べ方})$$
  $$= 6 \times 2 \times 24 = 288 \text{ 通り} \quad (\text{MNO} = 288)$$

**【考査考点】**
- 同じものを含む順列の計算公式 $\frac{n!}{p!q!}$。
- 隣り合う条件における「要素のブロック化（束ねる手法）」の適用。
- 隣り合わない条件における「すきま挿入法」と余事象・端条件の複合処理。

## 数学 コース1 第II問 [2]：2変数関数の関係式と整数条件下の最大値・最小値

**問題コード**: `math-q-II_2` | **配点参照**: `II:2` | **正解**: `PQR = 247, STU = 115, V = 4, W = 1, X = 7, YZ = 52`

### 出題のポイント
- 2次関数 $y = f(x)$ の平方完成と頂点の決定
- 連立不等式による $x$ の存在範囲の導出（2次不等式の解法）
- 整数 $x$ の離散値に対する $y$ の値の評価と最大値・最小値の特定

### 詳細解説
**【題目大意】**
整数 $x$ と実数 $y$ が等式 $2(y+1) = x(8-x)$ $\textcircled{1}$ と不等式 $5x - 4y + 1 \le 0$ $\textcircled{2}$ を同時に満たすとき、$y$ の最大値 $M$ と最小値 $m$ を求める。

**【公式正解】**
$\text{PQR} = 247$ （$y = -\frac{1}{2}(x - 4)^2 + 7$）
$\text{STU} = 115$ （$2x^2 - 11x + 5 \le 0$）
$\text{V} = 4$
$\text{W} = 1$
$\text{X} = 7$
$\text{YZ} = 52$ （$m = \frac{5}{2}$）

**【詳細推導・解答プロセス】**
**(1) $y$ を $x$ の2次式として表す**
等式 $\textcircled{1}$ を変形すると：
$$2y + 2 = 8x - x^2 \iff 2y = -(x^2 - 8x) - 2$$
両辺を2で割り、平方完成すると：
$$y = -\frac{1}{2}(x^2 - 8x) - 1 = -\frac{1}{2}[(x - 4)^2 - 16] - 1 = -\frac{1}{2}(x - 4)^2 + 8 - 1$$
$$y = -\frac{1}{2}(x - 4)^2 + 7$$
したがって、$y = -\frac{1}{\text{P}}(x - \text{Q})^2 + \text{R}$ より、$\text{PQR} = 247$ である。

**(2) $x$ に関する不等式の導出**
不等式 $\textcircled{2}$ より、$4y \ge 5x + 1$ である。
$\textcircled{1}$ 式の両辺を2倍すると $4(y+1) = 2x(8-x) \iff 4y = 16x - 2x^2 - 4$ であるから、これを不等式に代入する：
$$16x - 2x^2 - 4 \ge 5x + 1$$
移項して整理すると：
$$2x^2 - 11x + 5 \le 0$$
したがって、$2x^2 - \text{ST} x + \text{U} \le 0$ より、$\text{STU} = 115$ である。

**(3) 整数 $x$ の範囲と $y$ の最大値・最小値**
2次不等式を因数分解すると：
$$(2x - 1)(x - 5) \le 0 \iff \frac{1}{2} \le x \le 5$$
$x$ は**整数**であるから、とり得る $x$ の値は：
$$x \in \{1, 2, 3, 4, 5\}$$

$y = -\frac{1}{2}(x - 4)^2 + 7$ は $x = 4$ で上に凸の放物線であるから：
- $x = 4$ のとき、$y$ は最大値をとる：
  $$M = y(4) = 7 \quad (\text{V} = 4, \text{X} = 7)$$
- 頂点 $x = 4$ から最も離れた整数値は $x = 1$（距離 3）である。
  $x = 1$ のとき：
  $$y(1) = -\frac{1}{2}(1 - 4)^2 + 7 = -\frac{9}{2} + 7 = \frac{5}{2}$$
  （なお、$x=5$ では $y(5) = 13/2$、$x=2$ では $y(2)=5$ である）。
  したがって、$x = 1$ のとき $y$ は最小値 $m = \frac{5}{2}$ をとる（$\text{W} = 1, \text{YZ} = 52$）。

**【考査考点】**
- 2変数の消去による1変数2次不等式の立式と因数分解。
- 実数条件と整数（離散値）条件の区別、および定義域の端点・頂点における評価。

## 数学 コース1 第III問 (1)：連立2次不等式の共通解と補集合の領域判定

**問題コード**: `math-q-III_1` | **配点参照**: `III:1` | **正解**: `A = 4, B = 0`

### 出題のポイント
- 2次不等式 $x^2+3x-18<0$ および $x^2-2x-8>0$ の因数分解と解法
- 数直線を用いた連立不等式の共通範囲の決定
- 否定（どちらも満たさない）領域の境界値を含む範囲の判定

### 詳細解説
**【題目大意】**
2次不等式 $x^2 + 3x - 18 < 0$ $\textcircled{1}$ と $x^2 - 2x - 8 > 0$ $\textcircled{2}$ について：
(1) $\textcircled{1}$ と $\textcircled{2}$ の両方を満たす $x$ の範囲 A、およびどちらも満たさない $x$ の範囲 B を選択肢 $\textcircled{0} \sim \textcircled{5}$ から選ぶ。

**【公式正解】**
$\text{A} = 4$ （$-6 < x < -2$）
$\text{B} = 0$ （$3 \le x \le 4$）

**【詳細推導・解答プロセス】**
**(1) 各不等式の解**
- 不等式 $\textcircled{1}$：
  $$x^2 + 3x - 18 < 0 \iff (x + 6)(x - 3) < 0 \iff -6 < x < 3$$
- 不等式 $\textcircled{2}$：
  $$x^2 - 2x - 8 > 0 \iff (x - 4)(x + 2) > 0 \iff x < -2 \text{ または } x > 4$$

**(2) 両方を満たす範囲 A**
$$(-6 < x < 3) \cap (x < -2 \text{ または } x > 4)$$
数直線上で共通部分を求めると：
$$-6 < x < -2$$
選択肢 $\textcircled{4}$ が $-6 < x < -2$ に該当するため、$\text{A} = 4$ である。

**(3) どちらの不等式も満たさない範囲 B**
「$\textcircled{1}$ を満たさない」かつ「$\textcircled{2}$ を満たさない」範囲を求める。
- $\textcircled{1}$ の否定：$x \le -6$ または $x \ge 3$
- $\textcircled{2}$ の否定：$-2 \le x \le 4$
両者の共通部分は：
$$(x \le -6 \text{ または } x \ge 3) \cap (-2 \le x \le 4)$$
$x \le -6$ と $[-2, 4]$ に共通部分はない。一方、$x \ge 3$ と $[-2, 4]$ の共通部分は：
$$3 \le x \le 4$$
選択肢 $\textcircled{0}$ が $3 \le x \le 4$ に該当するため、$\text{B} = 0$ である。

**【考査考点】**
- 2次不等式の因数分解による解法。
- 数直線上での共通集合（かつ）およびド・モルガンの法則に基づく否定領域の視覚的・論理的処理。

## 数学 コース1 第III問 (2)：媒介変数を含む2次不等式の和集合条件とパラメータ範囲の導出

**問題コード**: `math-q-III_2` | **配点参照**: `III:2` | **正解**: `C = 2, D = 4`

### 出題のポイント
- 開区間 $(-6, 3)$ と 2次不等式 $x^2+ax+b<0$ の解区間 $(\alpha, \beta)$ の和集合解析
- 右端点 $\beta = 7$ から得られる等式 $b = -7a - 49$ の決定
- 連結区間 $(-6, 7)$ を形成するための左端点 $\alpha$ の存在範囲（$-6 \le \alpha \le 3$）の評価

### 詳細解説
**【題目大意】**
不等式 $\textcircled{1}$ $x^2 + 3x - 18 < 0$ と $\textcircled{3}$ $x^2 + ax + b < 0$ の少なくとも一方を満たす $x$ の範囲（和集合）が $-6 < x < 7$ となるとき、$a, b$ が満たす等式 C および $a$ が満たす不等式 D を選択肢から選ぶ。

**【公式正解】**
$\text{C} = 2$ （$b = -7a - 49$）
$\text{D} = 4$ （$-10 < a \le -1$）

**【詳細推導・解答プロセス】**
不等式 $\textcircled{1}$ の解は $-6 < x < 3$ である。
不等式 $\textcircled{3}$ $x^2 + ax + b < 0$ の解は、2次方程式 $x^2 + ax + b = 0$ の相異なる2実数解を $\alpha < \beta$ とすると、開区間 $(\alpha, \beta)$ である。
問題の条件は、2つの区間の和集合が：
$$(-6, 3) \cup (\alpha, \beta) = (-6, 7)$$
となることである。

**(1) 等式 C の決定**
和集合の右端が $7$ であるから、区間 $(\alpha, \beta)$ の右端点は必ず $\beta = 7$ でなければならない。
$x = 7$ は $x^2 + ax + b = 0$ の解であるから：
$$7^2 + 7a + b = 0 \iff 49 + 7a + b = 0 \iff b = -7a - 49$$
これは選択肢 $\textcircled{2}$ であるため、$\text{C} = 2$ である。

**(2) 不等式 D の決定**
$b = -7a - 49$ を代入すると、$\textcircled{3}$ の左辺は：
$$x^2 + ax - 7a - 49 = (x - 7)(x + a + 7) < 0$$
$\beta = 7$ より、もう一方の解は $\alpha = -(a + 7)$ である（$\alpha < 7 \iff a > -14$）。
2つの区間 $(-6, 3)$ と $(\alpha, 7)$ の和集合が $(-6, 7)$ という1つの連結な開区間となるための条件は：
1. 和集合の左端が $-6$ であることより、$\alpha$ は $-6$ より小さくなってはならない（もし $\alpha < -6$ なら和集合の左端が $\alpha$ に拡張されてしまう）：
   $$\alpha \ge -6 \iff -(a + 7) \ge -6 \iff a + 7 \le 6 \iff a \le -1$$
2. 区間 $(-6, 3)$ と $(\alpha, 7)$ の間に「すきま（切れ目）」が生じてはならない。
   もし $\alpha > 3$ であれば、$(3, \alpha]$ の部分が解に含まれず区間が分断されてしまう。また $\alpha = 3$ の場合も $x = 3$ がどちらにも含まれず穴が空いてしまう。したがって $\alpha < 3$ でなければならない：
   $$\alpha < 3 \iff -(a + 7) < 3 \iff a + 7 > -3 \iff a > -10$$
以上を合わせると、実数 $a$ の満たすべき条件は：
$$-10 < a \le -1$$
これは選択肢 $\textcircled{4}$ に該当するため、$\text{D} = 4$ である。

**【考査考点】**
- パラメータを含む2次関数の因数分解と解の配置。
- 複数の開区間の和集合が連続した1つの区間をなすための端点の包含・接続条件。

## 数学 コース1 第IV問 (1)：円に内接する四角形の余弦定理と対角線の長さ・対角の決定

**問題コード**: `math-q-IV_1` | **配点参照**: `IV:1` | **正解**: `ABC = 843, DE = 88, FG = 90, HI = 22`

### 出題のポイント
- 円に内接する四角形の対角の和の性質（$\angle BCD = 180^\circ - \theta$）
- 余弦定理の2通りの適用（$\triangle ABD$ と $\triangle BCD$）
- 対角線の長さ $BD$ および内角 $\theta$ の決定

### 詳細解説
**【題目大意】**
円に内接する四角形 $ABCD$ において、$AB = \sqrt{2}$, $BC = CD = 2$, $DA = \sqrt{6}$ とする。
$\angle BAD = \theta$ とおくとき、余弦定理を用いて $BD^2$ を2通りに表し、$\theta$ と $BD$ の値を求める。

**【公式正解】**
$\text{ABC} = 843$ （$BD^2 = 8 - 4\sqrt{3}\cos\theta$）
$\text{DE} = 88$ （$BD^2 = 8 + 8\cos\theta$）
$\text{FG} = 90$ （$\theta = 90^\circ$）
$\text{HI} = 22$ （$BD = 2\sqrt{2}$）

**【詳細推導・解答プロセス】**
**(1) $\triangle ABD$ における余弦定理**
$\triangle ABD$ において、$AB = \sqrt{2}$, $AD = \sqrt{6}$, $\angle BAD = \theta$ であるから：
$$BD^2 = AB^2 + AD^2 - 2 \cdot AB \cdot AD \cos\theta$$
$$BD^2 = (\sqrt{2})^2 + (\sqrt{6})^2 - 2 \cdot \sqrt{2} \cdot \sqrt{6} \cos\theta = 2 + 6 - 2\sqrt{12}\cos\theta = 8 - 4\sqrt{3}\cos\theta$$
したがって、$BD^2 = \text{A} - \text{B}\sqrt{\text{C}}\cos\theta$ より、$\text{ABC} = 843$ である。

**(2) $\triangle BCD$ における余弦定理**
四角形 $ABCD$ は円に内接するため、対角の和は $180^\circ$ である：
$$\angle BCD = 180^\circ - \theta$$
また $BC = 2, CD = 2$ であるから：
$$BD^2 = BC^2 + CD^2 - 2 \cdot BC \cdot CD \cos(180^\circ - \theta)$$
$\cos(180^\circ - \theta) = -\cos\theta$ であるので：
$$BD^2 = 2^2 + 2^2 - 2 \cdot 2 \cdot 2 (-\cos\theta) = 8 + 8\cos\theta$$
したがって、$BD^2 = \text{D} + \text{E}\cos\theta$ より、$\text{DE} = 88$ である。

**(3) $\theta$ と $BD$ の決定**
両式を等置すると：
$$8 - 4\sqrt{3}\cos\theta = 8 + 8\cos\theta$$
$$(8 + 4\sqrt{3})\cos\theta = 0$$
$8 + 4\sqrt{3} \ne 0$ であるから、$\cos\theta = 0$ を得る。
$0^\circ < \theta < 180^\circ$ より：
$$\theta = 90^\circ \quad (\text{FG} = 90)$$
$\cos\theta = 0$ を代入すると：
$$BD^2 = 8 \implies BD = \sqrt{8} = 2\sqrt{2} \quad (\text{HI} = 22)$$

**【考査考点】**
- 円に内接する四角形の対角の性質（内角の和 $180^\circ$ と三角関数の符号反転）。
- 共通の対角線に対する余弦定理の立式と未知角の代数的消去。

## 数学 コース1 第IV問 (2)(3)：正弦定理による角・線分の導出と方べきの定理・相似比による延長線の交点

**問題コード**: `math-q-IV_2` | **配点参照**: `IV:2` | **正解**: `JK = 45, LM = 30, NO = 13, PQRS = 2314, TUV = 223`

### 出題のポイント
- 外接円の直径（$2R = BD$）に基づく正弦定理の適用
- 加法定理を用いた $AC = 1 + \sqrt{3}$ および $\sin\angle ADC$ の厳密計算
- 円に内接する四角形の対辺の延長がなす相似三角形（$\triangle EAB \sim \triangle ECD$）の幾何学的解法

### 詳細解説
**【題目大意】**
前問の円に内接する四角形 $ABCD$（$\angle BAD = 90^\circ, BD = 2\sqrt{2}$）において：
(2) $\angle BAC, \angle BCA, AC$ および $\sin\angle ADC$ を求める。
(3) 直線 $AD$ と直線 $BC$ の交点を $E$ とするとき、$EB$ の長さを求める。

**【公式正解】**
$\text{JK} = 45$ （$\angle BAC = 45^\circ$）
$\text{LM} = 30$ （$\angle BCA = 30^\circ$）
$\text{NO} = 13$ （$AC = 1 + \sqrt{3}$）
$\text{PQRS} = 2314$ （$\sin\angle ADC = \frac{\sqrt{2}(\sqrt{3} + 1)}{4}$）
$\text{TUV} = 223$ （$EB = 2 + 2\sqrt{3}$）

**【詳細推導・解答プロセス】**
**(1) 外接円の半径と角の決定**
$\angle BAD = 90^\circ$ より、$BD$ は外接円の直径である。
したがって、外接円の半径 $R$ は：
$$2R = BD = 2\sqrt{2} \implies R = \sqrt{2}$$
$\triangle BCD$ において、$BC = CD = 2, BD = 2\sqrt{2}$ より $BC^2 + CD^2 = BD^2$ が成り立ち、$\triangle BCD$ は直角二等辺三角形である。よって $\angle BDC = \angle DBC = 45^\circ$ である。

次に、弦 $BC$ に対する円周角 $\angle BAC$ は、正弦定理より：
$$\frac{BC}{\sin\angle BAC} = 2R \implies \sin\angle BAC = \frac{2}{2\sqrt{2}} = \frac{1}{\sqrt{2}}$$
弦 $AB$ に対する円周角 $\angle BCA$ は：
$$\frac{AB}{\sin\angle BCA} = 2R \implies \sin\angle BCA = \frac{\sqrt{2}}{2\sqrt{2}} = \frac{1}{2}$$
図の配置より、$\angle BAC = 45^\circ$（$\text{JK} = 45$）、$\angle BCA = 30^\circ$（$\text{LM} = 30$）である。

**(2) 線分 $AC$ の長さ**
$\triangle ABC$ の内角の和より：
$$\angle ABC = 180^\circ - (45^\circ + 30^\circ) = 105^\circ$$
正弦定理より：
$$AC = 2R \sin 105^\circ = 2\sqrt{2} \sin(45^\circ + 60^\circ)$$
$$\sin 105^\circ = \sin 45^\circ \cos 60^\circ + \cos 45^\circ \sin 60^\circ = \frac{\sqrt{2}}{2} \cdot \frac{1}{2} + \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{2} + \sqrt{6}}{4}$$
$$AC = 2\sqrt{2} \cdot \frac{\sqrt{2} + \sqrt{6}}{4} = \frac{4 + 2\sqrt{12}}{4} = \frac{4 + 4\sqrt{3}}{4} = 1 + \sqrt{3}$$
したがって、$AC = \text{N} + \sqrt{\text{O}}$ より、$\text{NO} = 13$ である。

**(3) $\sin\angle ADC$ の計算**
直角三角形 $ABD$ において、$\sin\angle ADB = \frac{AB}{BD} = \frac{\sqrt{2}}{2\sqrt{2}} = \frac{1}{2}$ より $\angle ADB = 30^\circ$ である。
また直角二等辺三角形 $BCD$ より $\angle BDC = 45^\circ$ であるから：
$$\angle ADC = \angle ADB + \angle BDC = 30^\circ + 45^\circ = 75^\circ$$
$$\sin\angle ADC = \sin 75^\circ = \frac{\sqrt{6} + \sqrt{2}}{4} = \frac{\sqrt{2}(\sqrt{3} + 1)}{4}$$
したがって、$\sin\angle ADC = \frac{\sqrt{\text{P}}(\sqrt{\text{Q}} + \text{R})}{\text{S}}$ より、$\text{PQRS} = 2314$ である。

**(4) 交点 $E$ と $EB$ の長さ**
四角形 $ABCD$ は円に内接するため、直線 $AD$ と直線 $BC$ の交点 $E$ に関して：
$$\triangle EAB \sim \triangle ECD$$
相似比は対応する辺の比より：
$$\frac{CD}{AB} = \frac{2}{\sqrt{2}} = \sqrt{2}$$
したがって：
$$\frac{EC}{EA} = \sqrt{2} \implies EC = \sqrt{2} EA$$
$$\frac{ED}{EB} = \sqrt{2} \implies ED = \sqrt{2} EB$$
線分の関係より、$EC = EB + BC = EB + 2$、$ED = EA + AD = EA + \sqrt{6}$ である。
第2式より $EA = \sqrt{2} EB - \sqrt{6}$。
これを第1式 $EB + 2 = \sqrt{2} EA$ に代入すると：
$$EB + 2 = \sqrt{2}(\sqrt{2} EB - \sqrt{6}) = 2 EB - 2\sqrt{3}$$
$$EB = 2 + 2\sqrt{3}$$
したがって、$EB = \text{T} + \text{U}\sqrt{\text{V}}$ より、$\text{TUV} = 223$ である。

**【考査考点】**
- 正弦定理・余弦定理の総合的運用（外接円の直径と円周角の関係）。
- 加法定理による $105^\circ, 75^\circ$ の三角比の厳密計算。
- 円に内接する四角形の延長線が形成する相似三角形（方べきの定理）の幾何学的応用。
