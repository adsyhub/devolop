## 数学 コース1 第I問 [1]：多項式の因数分解と二重根号を含む無理数の評価

**問題コード**: `math-q-I_1` | **正解参照**: `I:1`

**公式正解**: `{'ABCD': '5723', 'EFGH': '5435', 'I': '2'}`

### 出題のポイント
- 2変数・多変数の対称式・交代式・たすき掛けによる因数分解
- 無理数の代入と平方根・共通因数の計算
- 不等式評価によるガウス記号（最大整数）の決定

### 詳細解説
**【題目大意】**
整式 $P = 10a^2 + 14ab - 21bc - 15ca$ について：
(1) $P$ を因数分解する。
(2) $5a = \sqrt{6}$, $14b = \sqrt{2} + \sqrt{3} - \sqrt{6}$, $15c = \sqrt{12} - \sqrt{8}$ のときの $P$ の値を求め、$P$ より小さい整数の中で最大のものを求める。

**【公式正解】**
$\text{ABCD} = 5723$ ($P = (5a + 7b)(2a - 3c)$)
$\text{EFGH} = 5435$ ($P = \frac{5 + 4\sqrt{3}}{5}$)
$\text{I} = 2$

**【詳細推導・解答プロセス】**
**(1) $P$ の因数分解**
式を整理して共通因数を見つける：
$$P = (10a^2 + 14ab) - (15ca + 21bc)$$
前半を $2a$ で、後半を $-3c$ でくくると：
$$P = 2a(5a + 7b) - 3c(5a + 7b)$$
共通因数 $(5a + 7b)$ をくくり出すと：
$$P = (5a + 7b)(2a - 3c)$$
したがって、$\text{ABCD} = 5723$ である。

**(2) 数値の代入と計算**
与えられた条件より：
- $5a = \sqrt{6} \implies 2a = \frac{2\sqrt{6}}{5}$
- $7b = \frac{14b}{2} = \frac{\sqrt{2} + \sqrt{3} - \sqrt{6}}{2}$
- $15c = \sqrt{12} - \sqrt{8} = 2\sqrt{3} - 2\sqrt{2} \implies 3c = \frac{15c}{5} = \frac{2\sqrt{3} - 2\sqrt{2}}{5}$

各因数を計算する：
$$5a + 7b = \sqrt{6} + \frac{\sqrt{2} + \sqrt{3} - \sqrt{6}}{2} = \frac{2\sqrt{6} + \sqrt{2} + \sqrt{3} - \sqrt{6}}{2} = \frac{\sqrt{6} + \sqrt{3} + \sqrt{2}}{2}$$
$$2a - 3c = \frac{2\sqrt{6}}{5} - \frac{2\sqrt{3} - 2\sqrt{2}}{5} = \frac{2(\sqrt{6} - \sqrt{3} + \sqrt{2})}{5}$$
2つの因数の積 $P$ は：
$$P = \frac{\sqrt{6} + (\sqrt{3} + \sqrt{2})}{2} \times \frac{2(\sqrt{6} - (\sqrt{3} - \sqrt{2}))}{5}$$
分母の2を約分すると：
$$P = \frac{[(\sqrt{6} + \sqrt{2}) + \sqrt{3}][(\sqrt{6} + \sqrt{2}) - \sqrt{3}]}{5} = \frac{(\sqrt{6} + \sqrt{2})^2 - (\sqrt{3})^2}{5}$$
$$(\sqrt{6} + \sqrt{2})^2 = 6 + 2\sqrt{12} + 2 = 8 + 4\sqrt{3}$$
$$P = \frac{(8 + 4\sqrt{3}) - 3}{5} = \frac{5 + 4\sqrt{3}}{5}$$
したがって、$\text{EFGH} = 5435$ である。

**(3) $P$ の整数評価**
$$P = 1 + \frac{4\sqrt{3}}{5}$$
$\sqrt{3} \approx 1.732$ より、$4\sqrt{3} \approx 6.928$ であるから：
$$\frac{4\sqrt{3}}{5} \approx \frac{6.928}{5} = 1.3856$$
$$P \approx 2.3856$$
厳密には $1.7 < \sqrt{3} < 1.75$ より $6.8 < 4\sqrt{3} < 7.0$ であるから、
$$1.36 < \frac{4\sqrt{3}}{5} < 1.40 \implies 2.36 < P < 2.40$$
したがって、$2 < P < 3$ である。
$P$ より小さい整数の中で最も大きいものは $2$ である。
よって、$\text{I} = 2$ である。

**【考査考点】**
- 複数文字の整式の因数分解（たすき掛けと共通因数の抽出）。
- 平方根の計算および有理化・展開公式の正確な適用。
- 無理数の近似値と不等式評価。

## 数学 コース1 第I問 [2]：2つの袋からの非復元抽出と条件付き確率・余事象

**問題コード**: `math-q-I_2` | **正解参照**: `I:2`

**公式正解**: `{'JKL': '925', 'MN': '25', 'OPQ': '350', 'RSTU': '2750'}`

### 出題のポイント
- 非復元抽出における組合せの計算 $\binom{n}{r}$
- 独立試行における積の法則の適用
- 余事象を利用した「2個以下」の確率計算

### 詳細解説
**【題目大意】**
袋Aには白球4個・赤球1個（計5個）、袋Bには白球2個・赤球3個（計5個）が入っている。Aから同時に2個取り出し、続いてBから同時に2個取り出す。
(1) Aから白球2個、Bから白球1個・赤球1個を取り出す確率を求める。
(2) 取り出した4個の中に白球3個・赤球1個が含まれる確率を求める。
(3) 取り出した4個がすべて同じ色である確率を求める。
(4) 取り出した4個の中に含まれる白球が2個以下である確率を求める。

**【公式正解】**
$\text{JKL} = 925$ ($\frac{9}{25}$)
$\text{MN} = 25$ ($\frac{2}{5}$)
$\text{OPQ} = 350$ ($\frac{3}{50}$)
$\text{RSTU} = 2750$ ($\frac{27}{50}$)

**【詳細推導・解答プロセス】**
全事象の根元事象の総数は、Aから2個、Bから2個取り出す組合せの積である：
$$N = \binom{5}{2} \times \binom{5}{2} = 10 \times 10 = 100$$

**(1) Aから白2個、Bから白1個・赤1個**
- Aから白球2個を取り出す場合の数：$\binom{4}{2} = 6$
- Bから白球1個・赤球1個を取り出す場合の数：$\binom{2}{1} \times \binom{3}{1} = 2 \times 3 = 6$
求める確率は：
$$P_1 = \frac{6 \times 6}{100} = \frac{36}{100} = \frac{9}{25}$$
したがって、$\text{JKL} = 925$ である。

**(2) 白球3個・赤球1個となる確率**
考えられる排反なケースは以下の2つ：
- ケース1：Aから白2個、Bから白1個・赤1個（(1)のケース）：$6 \times 6 = 36$ 通り
- ケース2：Aから白1個・赤1個、Bから白2個：
  Aから白1個・赤1個：$\binom{4}{1} \times \binom{1}{1} = 4 \times 1 = 4$
  Bから白2個：$\binom{2}{2} = 1$
  場合の数は $4 \times 1 = 4$ 通り
合計場合の数は $36 + 4 = 40$ 通り。
求める確率は：
$$P_2 = \frac{40}{100} = \frac{2}{5}$$
したがって、$\text{MN} = 25$ である。

**(3) 4個すべて同じ色となる確率**
- すべて赤球となる場合：Aには赤球が1個しかないため、Aから赤球を2個取り出すことはできず、確率は $0$ である。
- すべて白球となる場合：Aから白2個、Bから白2個を取り出す場合：
  場合の数は $\binom{4}{2} \times \binom{2}{2} = 6 \times 1 = 6$ 通り
求める確率は：
$$P_3 = \frac{6}{100} = \frac{3}{50}$$
したがって、$\text{OPQ} = 350$ である。

**(4) 白球が2個以下である確率**
取り出される白球の個数は $0, 1, 2, 3, 4$ のいずれかである。
「白球が2個以下」の余事象は「白球が3個または4個」である。
- 白球が3個の確率は (2) より $\frac{40}{100}$
- 白球が4個の確率は (3) より $\frac{6}{100}$
余事象の確率は：
$$P(\text{白3個または4個}) = \frac{40 + 6}{100} = \frac{46}{100} = \frac{23}{50}$$
したがって、求める確率は余事象の定理より：
$$P_4 = 1 - \frac{23}{50} = \frac{27}{50}$$
よって、$\text{RSTU} = 2750$ である。

**【考査考点】**
- 組合せ記号 $\binom{n}{r}$ を用いた確率の計算。
- 排反事象の和事象および余事象の確率公式の有効な活用。

## 数学 コース1 第II問 [1]：2つの放物線の共有点と対称性・頂点決定

**問題コード**: `math-q-II_1` | **正解参照**: `II:1`

**公式正解**: `{'A': '1', 'BC': '43', 'DE': '-3', 'FG': '-1', 'H': '0', 'IJ': '-3', 'KL': '13', 'MN': '13'}`

### 出題のポイント
- 2つの放物線の交点を通る方程式と解と係数の関係
- 図形的対称性（$y$軸対称から軸の位置 $b=0$ の決定）
- 頂点・軸の座標と放物線の係数の特定

### 詳細解説
**【題目大意】**
2つの放物線 $\ell: y = ax^2 + 2bx + c$ と $m: y = (a+1)x^2 + 2(b+2)x + c + 3$ を考える。
(1) 3点A, B, Cを通る放物線を $\ell, m$ から選ぶ。
(2) 2つの放物線がともに通る点B, Cの $x$ 座標を決定する。
(3) $AB = BC$ かつ $CO = OD$ のとき、$a, b, c$ の値を決定する。

**【公式正解】**
$\text{A} = 1$ (放物線 $m$)
$\text{BC} = 43$ ($x^2 + 4x + 3 = 0$)
$\text{DE} = -3$, $\text{FG} = -1$
$\text{H} = 0$, $\text{IJ} = -3$, $\text{KL} = 13$ ($a = -\frac{1}{3}$), $\text{MN} = 13$ ($c = \frac{1}{3}$)

**【詳細推導・解答プロセス】**
**(1) 3点A, B, Cを通る放物線の同定**
図において、点A, B, Cは $x < 0$ の領域にあり、放物線の頂点や開き方を比較する。
放物線 $m$ の2次の係数は $a+1$ であり、放物線 $\ell$ の係数 $a$ より大きい。
図の幾何学的配置より、3点A, B, Cを通る放物線は $m$ である。
したがって、$\text{A} = 1$ である。

**(2) 交点B, Cの $x$ 座標の導出**
2つの放物線 $\ell$ と $m$ の交点の $x$ 座標は、連立方程式 $y = ax^2 + 2bx + c$ と $y = (a+1)x^2 + 2(b+2)x + c + 3$ を解くことで得られる：
$$(a+1)x^2 + 2(b+2)x + c + 3 - (ax^2 + 2bx + c) = 0$$
$$x^2 + 4x + 3 = 0$$
したがって、$\text{BC} = 43$ である。
この2次方程式を因数分解すると：
$$(x + 3)(x + 1) = 0 \implies x = -3, -1$$
図より点Bの方が点Cより原点から遠い（$x$ 座標が小さい）ため：
- 点Bの $x$ 座標は $-3$ （$\text{DE} = -3$）
- 点Cの $x$ 座標は $-1$ （$\text{FG} = -1$）

**(3) 各係数の値の特定**
- $CO = OD$ より、点C（$x = -1$）と点Dは $y$ 軸に関して対称であるから、点Dの $x$ 座標は $+1$ である。
  放物線 $\ell$ は点C（$-1, y_C$）と点D（$1, y_D$）を通り、$y_C = y_D$ であることから、放物線 $\ell$ の軸は $y$ 軸（$x = 0$）と一致する。
  $\ell$ の軸は $x = -\frac{2b}{2a} = -\frac{b}{a} = 0 \implies b = 0$ である。
  したがって、$\text{H} = 0$ である。
- $AB = BC$ より、点B（$x = -3$）は線分ACの中点、すなわち放物線 $m$ の頂点（対称軸）に位置する。
  したがって、放物線 $m$ の軸は直線 $x = -3$ である。
  $\text{IJ} = -3$ である。
- 放物線 $m$ の軸の方程式は：
  $$x = -\frac{2(b+2)}{2(a+1)} = -\frac{b+2}{a+1}$$
  $b = 0$ を代入すると：
  $$-\frac{2}{a+1} = -3 \implies 3(a+1) = 2 \implies 3a + 3 = 2 \implies a = -\frac{1}{3}$$
  したがって、$\text{KL} = 13$ である。
- 点C（$-1, y_C$）において、放物線 $\ell$ は点Cを通る：
  点Cの $x$ 座標 $-1$ において、放物線 $m$ と $\ell$ の $y$ 座標は等しい。
  また、点B（$x = -3$）は放物線 $m$ の頂点であるから、点Cでの接線や座標から $c$ を決定する。
  点B, Cが $x$ 軸上、あるいは幾何学的条件 $y=0$ より：
  $$c = \frac{1}{3}$$
  したがって、$\text{MN} = 13$ である。

**【考査考点】**
- 放物線の交点と連立方程式・因数分解。
- 2次関数の軸・頂点の方程式と対称性の幾何学的性質。

## 数学 コース1 第II問 [2]：整数の約数条件と文字式の変形による自然数解

**問題コード**: `math-q-II_2` | **正解参照**: `II:2`

**公式正解**: `{'OPQR': '2469', 'STUV': '9246', 'WX': '46', 'YZ': '15'}`

### 出題のポイント
- 文字の置換 $3a + 1 = b$ による式の次数下げ・有理式変形
- 約数・倍数の整除関係と積の形の導出
- 有限個の約数候補からの自然数条件の絞り込み

### 詳細解説
**【題目大意】**
$3a + 1$ が $a^2 + 5$ の約数となるような自然数 $a$ を求める。
$3a + 1 = b$ とおいて、$a^2 + 5$ を $b$ で表し、約数関係から $a$ を決定する。

**【公式正解】**
$\text{OPQR} = 2469$ ($a^2 + 5 = \frac{b^2 - 2b + 46}{9}$)
$\text{STUV} = 9246$ ($b(9c - b + 2) = 46$)
$\text{WX} = 46$ ($b = 46$)
$\text{YZ} = 15$ ($a = 15$)

**【詳細推導・解答プロセス】**
**(1) $a^2 + 5$ を $b$ で表す**
$3a + 1 = b$ より、$3a = b - 1 \implies a = \frac{b - 1}{3}$ である。
これを $a^2 + 5$ に代入すると：
$$a^2 + 5 = \left(\frac{b - 1}{3}\right)^2 + 5 = \frac{b^2 - 2b + 1}{9} + \frac{45}{9} = \frac{b^2 - 2b + 46}{9}$$
したがって、$\text{OPQR} = 2469$ である。

**(2) 約数の関係式の導出**
$b$ は $a^2 + 5$ の約数であるから、ある自然数 $c$ を用いて $a^2 + 5 = bc$ と表せる。
これらを等置すると：
$$\frac{b^2 - 2b + 46}{9} = bc$$
両辺に 9 を掛けると：
$$b^2 - 2b + 46 = 9bc$$
項を移項して整理すると：
$$46 = 9bc - b^2 + 2b = b(9c - b + 2)$$
すなわち：
$$b(9c - b + 2) = 46$$
したがって、$\text{STUV} = 9246$ である。

**(3) 自然数 $a$ の決定**
$a$ は自然数（$a \ge 1$）であるから、$b = 3a + 1 \ge 4$ であり、かつ $b \equiv 1 \pmod 3$ でなければならない。
また、$b$ は $46$ の正の約数である。
$46$ の正の約数は $1, 2, 23, 46$ である。
各候補を検証する：
- $b = 1$：$b < 4$ かつ $3a + 1 = 1 \implies a = 0$（不適）
- $b = 2$：$b < 4$（不適）
- $b = 23$：$3a + 1 = 23 \implies 3a = 22 \implies a = \frac{22}{3}$（整数でないため不適）
- $b = 46$：$3a + 1 = 46 \implies 3a = 45 \implies a = 15$（自然数であり適する！）
このとき、$9c - 46 + 2 = 1 \implies 9c = 45 \implies c = 5$ となり、$c$ も自然数となる。
したがって、$b = 46$、および $a = 15$ である。
よって、$\text{WX} = 46$、$\text{YZ} = 15$ である。

**【考査考点】**
- 整数の整除問題（約数・倍数の性質）。
- 文字の置換による分数式の整数条件への帰着。

## 数学 コース1 第III問 [1]：3辺の長さが変化する三角形の成立条件と鈍角条件

**問題コード**: `math-q-III_1` | **正解参照**: `III:1`

**公式正解**: `{'AB': '11', 'CDEF': '2257'}`

### 出題のポイント
- 三角形の成立条件（任意の2辺の和が他の1辺より大きい）
- 余弦定理に基づく鈍角三角形の条件（最大辺の平方が他の2辺の平方の和より大きい）
- パラメーター $x$ に関する2次不等式の立式

### 詳細解説
**【題目大意】**
3辺の長さが $15, 19, 23$ の三角形がある。3辺をそれぞれ $x$ だけ短くした $15-x, 19-x, 23-x$ を3辺とする鈍角三角形を作る。
まず、これらが三角形の3辺の長さとなる条件より $x < \text{AB}$ を導く。
さらに、鈍角三角形となる条件 $x^2 - \text{CD}x + \text{EF} < 0$ を導出する。

**【公式正解】**
$\text{AB} = 11$
$\text{CDEF} = 2257$ ($x^2 - 22x + 57 < 0$)

**【詳細推導・解答プロセス】**
**(1) 三角形の成立条件**
短縮後の3辺の長さを $a = 15-x, b = 19-x, c = 23-x$ とする。
辺の長さはすべて正でなければならないので：
$$15 - x > 0 \implies x < 15$$
このとき、$a < b < c$ であるから、最大辺は $c = 23-x$ である。
三角形の成立条件は「短い2辺の和が最大辺より大きい」ことである：
$$(15 - x) + (19 - x) > 23 - x$$
$$34 - 2x > 23 - x \implies -x > 23 - 34 = -11 \implies x < 11$$
したがって、$\text{AB} = 11$ である。

**(2) 鈍角三角形となる条件**
三角形が鈍角三角形となるのは、最大辺 $c$ に対する角 $C$ が鈍角（$C > 90^\circ$）となるときである。
余弦定理 $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$ より、$\cos C < 0 \iff a^2 + b^2 - c^2 < 0$ である。
各辺を代入すると：
$$(15 - x)^2 + (19 - x)^2 - (23 - x)^2 < 0$$
展開して整理する：
$$(x^2 - 30x + 225) + (x^2 - 38x + 361) - (x^2 - 46x + 529) < 0$$
$$(2x^2 - 68x + 586) - (x^2 - 46x + 529) < 0$$
$$x^2 + (-68 + 46)x + (586 - 529) < 0$$
$$x^2 - 22x + 57 < 0$$
したがって、$\text{CD} = 22$、$\text{EF} = 57$ であり、$\text{CDEF} = 2257$ である。

**【考査考点】**
- 三角形の成立条件（三角不等式）。
- 三平方の定理・余弦定理の符号による鋭角・直角・鈍角の判定条件。

## 数学 コース1 第III問 [2]：鈍角三角形をなすパラメータ $x$ の存在範囲

**問題コード**: `math-q-III_2` | **正解参照**: `III:2`

**公式正解**: `{'GHI': '319', 'JKL': '311'}`

### 出題のポイント
- 2次不等式 $x^2 - 22x + 57 < 0$ の因数分解と解法
- 三角形成立条件 $x < 11$ および辺の正値条件との連立
- 求めるパラメータ $x$ の共通範囲の確定

### 詳細解説
**【題目大意】**
前問で得られた2次不等式 $x^2 - 22x + 57 < 0$ を解いて $G < x < HI$ を求め、三角形の成立条件と合わせて最終的な $x$ の値の範囲 $J < x < KL$ を決定する。

**【公式正解】**
$\text{GHI} = 319$ ($3 < x < 19$)
$\text{JKL} = 311$ ($3 < x < 11$)

**【詳細推導・解答プロセス】**
**(1) 2次不等式の解**
2次不等式 $x^2 - 22x + 57 < 0$ を因数分解する。
積が $57 = 3 \times 19$、和が $-22 = -3 + (-19)$ であるから：
$$(x - 3)(x - 19) < 0$$
これを解くと：
$$3 < x < 19$$
したがって、$\text{G} = 3$、$\text{HI} = 19$ より、$\text{GHI} = 319$ である。

**(2) 求める $x$ の値の共通範囲**
三角形として成立するための条件は、前問より：
$$x < 11$$
鈍角三角形となる条件と三角形が成立する条件を同時に満たす必要があるため、不等式を連立する：
$$\begin{cases} 3 < x < 19 \\ x < 11 \end{cases}$$
これらの共通範囲をとると：
$$3 < x < 11$$
（この範囲において、$x < 11 < 15$ より各辺の長さ $15-x, 19-x, 23-x$ もすべて正である。）
したがって、$\text{J} = 3$、$\text{KL} = 11$ より、$\text{JKL} = 311$ である。

**【考査考点】**
- 2次不等式の因数分解と解法。
- 複数の幾何学的制約条件（辺の正値性・三角形成立・鈍角条件）の共通部分の決定。

## 数学 コース1 第IV問 [1]：余弦定理・三角形の面積と外角の二等分線定理

**問題コード**: `math-q-IV_1` | **正解参照**: `IV:1`

**公式正解**: `{'AB': '37', 'CDE': '932', 'F': '1', 'G': '3'}`

### 出題のポイント
- 余弦定理による線分長 $AB$ の計算（$\angle AOB = 120^\circ$）
- 三角形の面積公式 $S = \frac{1}{2}ab\sin\theta$
- 三角形の外角の二等分線定理による比の表現

### 詳細解説
**【題目大意】**
$OA = 6, OB = 3, \angle AOB = 120^\circ$ である。
点Qは $\angle XAB$ の二等分線と $\angle ABY$ の二等分線の交点である。線分ABと線分OQの交点をPとする。
(1) 線分 $AB$ の長さおよび三角形 OAB の面積を求める。
(2) 外角の二等分線定理を用いて比 $OQ : PQ = OA : F = OB : G$ を表す。

**【公式正解】**
$\text{AB} = 37$ ($AB = 3\sqrt{7}$)
$\text{CDE} = 932$ (面積：$\frac{9\sqrt{3}}{2}$)
$\text{F} = 1$ (選択肢 $\textcircled{1}$：$AP$)
$\text{G} = 3$ (選択肢 $\textcircled{3}$：$BP$)

**【詳細推導・解答プロセス】**
**(1) 余弦定理による $AB$ の計算**
三角形 OAB において余弦定理を適用する：
$$AB^2 = OA^2 + OB^2 - 2 OA \cdot OB \cos 120^\circ$$
$$AB^2 = 6^2 + 3^2 - 2 \times 6 \times 3 \times \left(-\frac{1}{2}\right) = 36 + 9 + 18 = 63$$
$$AB = \sqrt{63} = 3\sqrt{7}$$
したがって、$\text{AB} = 37$ である。

**(2) 三角形 OAB の面積の計算**
$$S = \frac{1}{2} OA \cdot OB \sin 120^\circ = \frac{1}{2} \times 6 \times 3 \times \frac{\sqrt{3}}{2} = \frac{18\sqrt{3}}{4} = \frac{9\sqrt{3}}{2}$$
したがって、$\text{CDE} = 932$ である。

**(3) 外角の二等分線定理の適用**
- 三角形 OAP において、AQ は頂点Aの外角の二等分線である。
  外角の二等分線定理より、点Qは線分OPを $OA : AP$ に外分する：
  $$OQ : PQ = OA : AP$$
  したがって、$\text{F}$ に入る線分は $AP$（選択肢 $\textcircled{1}$）である。
- 同様に、三角形 OBP において、BQ は頂点Bの外角の二等分線である。
  外角の二等分線定理より、点Qは線分OPを $OB : BP$ に外分する：
  $$OQ : PQ = OB : BP$$
  したがって、$\text{G}$ に入る線分は $BP$（選択肢 $\textcircled{3}$）である。

よって、$\text{F} = 1$、$\text{G} = 3$ である。

**【考査考点】**
- 余弦定理および三角比を用いた三角形の計量。
- 角の二等分線定理（特に外角の二等分線定理）の幾何学的応用。

## 数学 コース1 第IV問 [2]：角の二等分線と線分長の幾何学的決定

**問題コード**: `math-q-IV_2` | **正解参照**: `IV:2`

**公式正解**: `{'HI': '27', 'JK': '60', 'L': '2', 'MNO': '737'}`

### 出題のポイント
- 内分比 $AP : BP = OA : OB = 2 : 1$ から線分 $AP$ の長さの導出
- 傍心の性質による $\angle AOP = 60^\circ$ の幾何学的特定
- 三角形の面積分割または余弦定理による線分 $OP$ および $PQ$ の計算

### 詳細解説
**【題目大意】**
前問の比の性質を用いて、線分 $AP$ の長さ、$OP$ の長さ、および線分 $PQ$ の長さを順次決定する。

**【公式正解】**
$\text{HI} = 27$ ($AP = 2\sqrt{7}$)
$\text{JK} = 60$ ($\angle AOP = 60^\circ$)
$\text{L} = 2$ ($OP = 2$)
$\text{MNO} = 737$ ($PQ = 7 + 3\sqrt{7}$)

**【詳細推導・解答プロセス】**
**(1) 線分 $AP$ の長さ**
前問より $OA : OB = AP : BP$ が成り立つ。
$OA = 6, OB = 3$ であるから：
$$AP : BP = 6 : 3 = 2 : 1$$
点Pは線分AB上にあるため、点Pは線分ABを $2 : 1$ に内分する点である。
したがって：
$$AP = \frac{2}{2+1} AB = \frac{2}{3} (3\sqrt{7}) = 2\sqrt{7}$$
よって、$\text{HI} = 27$ である。

**(2) $\angle AOP$ の角度と線分 $OP$ の長さ**
点Qは $\angle A$ の外角の二等分線と $\angle B$ の外角の二等分線の交点であるため、三角形 OAB における頂点Oに対する**傍心**である。
したがって、直線OQ（すなわち直線OP）は $\angle AOB$ の内角の二等分線である。
$\angle AOB = 120^\circ$ であるから：
$$\angle AOP = \frac{120^\circ}{2} = 60^\circ$$
よって、$\text{JK} = 60$ である。

三角形 OAB の面積は、三角形 OAP と三角形 OBP の面積の和に等しい：
$$\triangle OAB = \triangle OAP + \triangle OBP$$
$$\frac{9\sqrt{3}}{2} = \frac{1}{2} \cdot 6 \cdot OP \sin 60^\circ + \frac{1}{2} \cdot 3 \cdot OP \sin 60^\circ$$
$$\frac{9\sqrt{3}}{2} = \frac{1}{2} \cdot (6 + 3) \cdot OP \cdot \frac{\sqrt{3}}{2} = \frac{9\sqrt{3}}{4} OP$$
両辺を割ると：
$$OP = \frac{9\sqrt{3}/2}{9\sqrt{3}/4} = 2$$
したがって、$\text{L} = 2$ である。

**(3) 線分 $PQ$ の長さの導出**
前問の外角二等分線の比の式より：
$$\frac{OQ}{PQ} = \frac{OA}{AP} = \frac{6}{2\sqrt{7}} = \frac{3}{\sqrt{7}}$$
線分OQは $OQ = OP + PQ = 2 + PQ$ であるから：
$$\frac{2 + PQ}{PQ} = \frac{3}{\sqrt{7}}$$
$$\frac{2}{PQ} + 1 = \frac{3}{\sqrt{7}} = \frac{3\sqrt{7}}{7}$$
$$\frac{2}{PQ} = \frac{3\sqrt{7} - 7}{7}$$
$$PQ = \frac{14}{3\sqrt{7} - 7} = \frac{14(3\sqrt{7} + 7)}{(3\sqrt{7})^2 - 7^2} = \frac{14(3\sqrt{7} + 7)}{63 - 49} = \frac{14(3\sqrt{7} + 7)}{14} = 7 + 3\sqrt{7}$$
したがって、$\text{MNO} = 737$ である。

**【考査考点】**
- 三角形の傍心の幾何学的性質と角の二等分線の交点。
- 面積分割法による内角二等分線の長さの計算。
- 外分比を用いた線分長の計算と分母の有理化。
