## 生物 問2：浸透現象と植物細胞の原形質分離

**【題目大意】**
5%スクロース溶液を入れた半透膜ろうとを濃度 a, b, c の溶液に浸した実験結果と，植物細胞を浸した観察図 X, Y, Z の対応関係を選ぶ。

**【公式正解】**
正解：$\textcircled{5}$（X: c, Y: a, Z: b）

**【詳細推導・解答プロセス】**
1. **スクロース溶液の濃度判定（図2）**：
- 溶液 a に浸した管：管内の液面が上昇した $\implies$ ビーカー外液から水が流入した $\implies$ 外液 a の濃度は管内（5%）より低い（低張液，濃度 $a < 5\%$）。
- 溶液 b に浸した管：液面の変化がほとんどない $\implies$ 浸透圧が等しい（等張液，濃度 $b \approx 5\%$）。
- 溶液 c に浸した管：管内の液面が低下した $\implies$ 管内から外液へ水が流出した $\implies$ 外液 c の濃度は管内（5%）より高い（高張液，濃度 $c > 5\%$）。
したがって濃度の順は $a < b < c$ である。

2. **植物細胞の形状（図3）**：
- **細胞 X**：細胞膜が細胞壁から大きく離れ，激しい**原形質分離**を起こしている $\implies$ 高張液（最も濃度の高い **c**）に浸した状態。
- **細胞 Y**：細胞が吸水して液胞が大きく膨らみ，膨圧が最大となった**膨満状態** $\implies$ 低張液（最も濃度の低い **a**）に浸した状態。
- **細胞 Z**：通常状態ないし限界原形質分離に近い状態 $\implies$ 等張液（中間濃度の **b**）に浸した状態。

したがって，$X = c, Y = a, Z = b$ となり，選択肢 $\textcircled{5}$ が正解である。

**【考査考点】**
浸透圧の基本原理，半透膜モデル，植物細胞の吸水力・膨圧・原形質分離。

図の大形相同染色体の対応する位置は **V** である。

したがって，$a = \text{V}, b = \text{VI}$ であり，選択肢 $\textcircled{6}$ が正解である。

## 生物 問6：ZW型性決定様式における伴性遺伝と伴性鑑別

**【題目大意】**
ウズラ（オス ZZ，メス ZW）において，Z 染色体上に存在する羽色遺伝子（$Z^B$: 野生型・優性，$Z^b$: 茶色・劣性）を利用して，生まれたヒナの雌雄を羽の色だけで判別できる親の遺伝子型の組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{3}$（メス：$Z^B W$，オス：$Z^b Z^b$）

**【詳細推導・解答プロセス】**
鳥類の性染色体構成はメスがヘテロ（ZW），オスがホモ（ZZ）である。
親の交配によって子の雌雄で表現型が完全に分離（交差遺伝）する条件を考える：
- **メス親に優性形質 $Z^B W$（野生型）** を選ぶ。
- **オス親に劣性ホモ接合 $Z^b Z^b$（茶色）** を選ぶ。
この交配から生じる子の性染色体と表現型は：
1. **オスのヒナ（ZZ）**：
   母親から $Z^B$，父親から $Z^b$ を受け継ぐため，遺伝子型はすべて $Z^B Z^b$ となり，表現型はすべて**野生型**となる。
2. **メスのヒナ（ZW）**：
   母親から W 染色体，父親から $Z^b$ を受け継ぐため，遺伝子型はすべて $Z^b W$ となり，表現型はすべて**茶色**となる。
このように，羽の色が野生型ならオス，茶色ならメスと $100\%$ 鑑別できる。
したがって，選択肢 $\textcircled{3}$（メス：$Z^B W$，オス：$Z^b Z^b$）が正解である。

**【考査考点】**
ZW 型性決定，伴性遺伝（性連鎖遺伝）の交差遺伝パターン，ひなの雌雄鑑別原理。

## 生物 問12：ミトコンドリアと葉緑体の比較（脱炭酸反応回路の有無）

**【題目大意】**

**【公式正解】**
正解：$\textcircled{4}$（脱炭酸反応を行う回路をもっている）

**【詳細推導・解答プロセス】**
各選択肢を検討する：
- $\textcircled{1}$：ミトコンドリア（呼吸）も葉緑体（光リン酸化）もともに ATP を合成する（両者に共通）。
- $\textcircled{2}$：ミトコンドリア（クリステ膜）も葉緑体（チラコイド膜）も電子伝達系をもつ（両者に共通）。
- $\textcircled{3}$：グルコースをピルビン酸に分解するのは細胞質基質で行われる**解糖系**であり，ミトコンドリアの反応ではない。
- $\textcircled{4}$ **正しい**：ミトコンドリアのマトリックスには**クエン酸回路（TCA回路）**が存在し，ピルビン酸から生じたアセチルCoAを酸化分解して $\text{CO}_2$ を放出する**脱炭酸反応**を行う。葉緑体のカルビン・ベンソン回路は逆に $\text{CO}_2$ を固定する回路であり，脱炭酸回路ではない。
- $\textcircled{5}$：両者ともに細胞内共生に由来する二重膜構造をもつ（両者に共通）。

したがって，ミトコンドリアのみに当てはまるのは選択肢 $\textcircled{4}$ である。

**【考査考点】**
細胞小器官の機能比較（異化と同化），クエン酸回路の脱炭酸反応，細胞内共生説の証拠。

## 生物 問13(1)：ツンベルク管実験における脱気の目的（酸素の排除）

**【題目大意】**
コハク酸脱水素酵素の反応をメチレンブルーを用いて調べるツンベルク管実験において，管内の空気を抜く（脱気する）目的を選ぶ。

**【公式正解】**
正解：$\textcircled{4}$（管内の酸素を除くため）

**【詳細推導・解答プロセス】**
コハク酸脱水素酵素は，コハク酸から水素を奪ってフマル酸に酸化する：
$$\text{コハク酸} + \text{酸化型メチレンブルー（青色）} \to \text{フマル酸} + \text{還元型メチレンブルー（無色）}$$
還元型メチレンブルー（ロイコ化合物）は無色であるが，酸素 $\text{O}_2$ が共存していると酸素によって直ちに再酸化され，青色に戻ってしまう：
$$\text{還元型メチレンブルー（無色）} + \text{O}_2 \to \text{酸化型メチレンブルー（青色）} + \text{H}_2\text{O}$$
脱水素酵素の活性による還元反応の進行を色の変化（青 $\to$ 無色）によって正確に追跡するためには，管内から**酸素を排除**しておくことが不可欠である。

したがって，選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
ツンベルク管の構造と実験原理，脱水素酵素の作用，人工電子受容体（メチレンブルー）の酸化還元反応。

## 生物 問13(2)：温度条件と熱変性による酵素反応速度の比較

**【題目大意】**
ツンベルク管 A〜D におけるメチレンブルーの退色結果として正しい記述を選ぶ。

**【公式正解】**
正解：$\textcircled{3}$（無色になるのは B, C であり，最も早く無色になるのは B である）

**【詳細推導・解答プロセス】**
各条件における酵素活性を検討する：
- **管 A**：生理食塩水のみであり，酵素（コハク酸脱水素酵素）が存在しないため，反応は起こらず青色のまま変化しない。
- **管 B**：肝臓抽出液（酵素含有）を $40^\circ\text{C}$ で保温した。動物酵素の最適温度（約 $37\sim 40^\circ\text{C}$）に近く，反応速度が最大となるため，**最も早く無色になる**。
- **管 C**：肝臓抽出液を $20^\circ\text{C}$ で保温した。酵素は活性をもつが，温度が低いため分子運動と触媒速度が低下し，B より遅れて無色になる。
- **管 D**：$100^\circ\text{C}$ で3分間加熱処理したため，タンパク質である酵素が**熱変性して失活**している。したがって反応は進行せず青色のままである。

以上より，無色になるのは B と C であり，最も早く無色になるのは B である。
これは選択肢 $\textcircled{3}$ に合致する。

**【考査考点】**
酵素反応の温度特性，最適温度，高温による熱変性と失活，対照実験の評価。

## 生物 問14：スプライシング後のエキソン長からのアミノ酸数の算出

**【題目大意】**
真核細胞の遺伝子 X は 3000 塩基対からなり，75% がイントロンで残りがエキソンである。
この遺伝子からつくられるタンパク質を構成するアミノ酸の数を求める。

**【公式正解】**
正解：$\textcircled{1}$（250個）

**【詳細推導・解答プロセス】**
1. **スプライシング後のエキソン塩基数の計算**：
遺伝子 X の塩基対数は $3000\text{ bp}$ である。
転写後にイントロン部分（75%）がスプライシングによって除去され，エキソン部分（25%）のみが連結されて成熟 mRNA となる：
$$3000 \times (1 - 0.75) = 3000 \times 0.25 = 750\text{ 塩基対}$$
一本鎖の成熟 mRNA の翻訳領域には約 $750$ 個の塩基が含まれる。

2. **アミノ酸数の計算**：
遺伝暗号（コドン）は連続する3個の塩基（トリプレット）が1個のアミノ酸を指定する。
したがって，指定されるアミノ酸の数は：
$$\frac{750}{3} = 250\text{ 個}$$
したがって，選択肢 $\textcircled{1}$ が正解である。

**【考査考点】**
真核生物の遺伝子発現，スプライシング（エキソンとイントロン），遺伝暗号のトリプレット説。

## 生物 問15(2)：転写と翻訳の進行方向の判定

**【題目大意】**
図中の RNAポリメラーゼ a が DNA 上を動く方向と，リボソーム b が mRNA c 上を動く方向の正しい組み合わせを選ぶ。

**【公式正解】**
正解：$\textcircled{4}$（a が動く方向：右，b が動く方向：下）

**【詳細推導・解答プロセス】**
1. **RNAポリメラーゼ a が動く方向**：
図を見ると，DNA から伸びている mRNA 鎖 c の長さは，左側では短く，**右側に向かうにつれて長く**なっている。
転写は mRNA が伸長する方向に進むため，RNAポリメラーゼ a は DNA 上を**左から右へ（右方向）**動いている。

2. **リボソーム b が動く方向**：
一本の mRNA 鎖 c に注目すると，リボソームから伸びているタンパク質鎖（ポリペプチド鎖）d の長さは，mRNA の根元（上側）にあるリボソームでは短く，**先端（下側）に向かうリボソームほど長く**なっている。
翻訳はタンパク質鎖が伸長する方向に進行するため，リボソーム b は mRNA 上を**上から下へ（下方向）**動いている（$5' \to 3'$ 方向）。

したがって，a の方向は「右」，b の方向は「下」であり，選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
ポリソーム（ポリリボソーム）の電子顕微鏡像の模式図解釈，転写の方向性と翻訳の方向性の視覚的判定。
