## 物理 問1：鉛直運動における $h-t$ グラフの加速度と糸の張力

**問題コード**: `phys-q-01` | **正解参照**: `PHYSICS:1` | **正解**: `3`

### 出題のポイント
- 運動方程式 $T - mg = ma$ による張力 $T$ の決定条件
- $h-t$ グラフの曲率（2階微分 $\frac{d^2h}{dt^2}$）と加速度 $a$ の符号・大きさの対応
- 上向き加速度が最大となる時刻の特定

### 詳細解説
**【題目大意】**
天井から糸でつるされた質量 $m$ のおもりを鉛直方向に運動させた。おもりの床からの高さ $h$ の時間変化を表す $h-t$ グラフから、糸の張力が最も大きくなる時刻を $t_1 \sim t_4$ の中から選ぶ。

**【公式正解】**
正解：$\textcircled{3}$ （時刻 $t_3$）

**【詳細推導・解答プロセス】**
**(1) 糸の張力とおもりの加速度の関係**
鉛直上向きを正とする。おもりの質量を $m$、加速度を $a$、重力加速度を $g$、糸の張力を $T$ とすると、運動方程式は：
$$m a = T - mg \implies T = m(g + a)$$
したがって、糸の張力 $T$ が最も大きくなるのは、鉛直上向きの加速度 $a$ が最大となる時刻である。

**(2) $h-t$ グラフにおける加速度の幾何学的解釈**
位置 $h$ の時間変化を表すグラフにおいて：
- 速度 $v = \frac{dh}{dt}$ は接線の傾きを表す。
- 加速度 $a = \frac{dv}{dt} = \frac{d^2h}{dt^2}$ はグラフの曲がり方（下に凸なら $a > 0$、上に凸なら $a < 0$）を表す。

**(3) 各時刻での加速度の比較**
- $t_1$：最高点付近であり、グラフは上に凸（傾きが減少中）であるため、$a < 0$（下向き加速度）。$T < mg$ となる。
- $t_2, t_4$：変曲点付近または等速下降・上昇過程であり、接線の傾きの変化が小さく、加速度 $a \approx 0$ である。
- $t_3$：グラフの最下点（谷）付近であり、急激に下降から上昇へと向きを変えるため、下に凸の曲率が最大（接線の傾きの増加率が最大）となる。したがって、上向き加速度 $a > 0$ が最大となる。
このとき、$T = m(g + a)$ は最大値をとる。
よって、糸の張力が最も大きくなる時刻は $t_3$ であり、正解は $\textcircled{3}$ である。

**【考査考点】**
- 鉛直方向の運動方程式と見かけの重力（慣性力・加速度と張力の関係）。
- 位置-時間（$h-t$）グラフにおける速度（傾き）および加速度（曲率・凸凹）の物理的読解。

## 物理 問2：2物体が一体となって運動する最大外力（すべり出し条件）

**問題コード**: `phys-q-02` | **正解参照**: `PHYSICS:2` | **正解**: `3`

### 出題のポイント
- 全体系の加速度 $a = \frac{F}{M+m}$ の立式
- 下側の物体 A を加速する力が静止摩擦力であることの理解
- 最大静止摩擦力 $f_{\text{max}} = \mu mg$ による限界外力 $F_0$ の決定

### 詳細解説
**【題目大意】**
滑らかな水平床上に質量 $M$ の物体 A があり、その上に質量 $m$ の物体 B が載っている。A と B の間の静止摩擦係数は $\mu$ である。B に水平右向きの力 $F$ を加えて徐々に大きくしたとき、B が A の上を滑り出す限界の力 $F_0$ を求める。

**【公式正解】**
正解：$\textcircled{3}$ （$\frac{\mu(M+m)mg}{M}$）

**【詳細推導・解答プロセス】**
**(1) 一体となって運動しているときの運動方程式**
物体 A と B が滑らずに一体となって水平加速度 $a$ で運動しているとする。
A と B 全体を一つの系とみなすと、床との間に摩擦はないため、水平方向の外力は $F$ のみである：
$$(M + m)a = F \implies a = \frac{F}{M + m}$$

**(2) 物体 A の運動方程式と摩擦力**
物体 A に着目すると、床面からの摩擦はなく、A を右向きに加速させている唯一の水平力は B から受ける静止摩擦力 $f$ である。
A の運動方程式は：
$$M a = f$$
一体加速度 $a = \frac{F}{M+m}$ を代入すると：
$$f = M \cdot \frac{F}{M + m} = \frac{M}{M + m}F$$

**(3) 滑り出さないための条件と限界値 $F_0$**
A と B の間の垂直抗力は $N = mg$ であるから、最大静止摩擦力は：
$$f_{\text{max}} = \mu N = \mu mg$$
B が A の上を滑り出さないためには、$f \leq f_{\text{max}}$ が成り立つ必要がある：
$$\frac{M}{M + m}F \leq \mu mg \implies F \leq \frac{\mu(M + m)mg}{M}$$
したがって、B が滑り出す限界の外力 $F_0$ は：
$$F_0 = \frac{\mu(M + m)mg}{M}$$
よって、正解は $\textcircled{3}$ である。

**【考査考点】**
- 接触した2物体の連立運動方程式。
- 静止摩擦力の役割の特定（外力が直接加わっていない物体を駆動する力）。
- 最大静止摩擦力の限界条件式。

## 物理 問3：可動台と小球の水平運動量保存と力学的エネルギー保存

**問題コード**: `phys-q-03` | **正解参照**: `PHYSICS:3` | **正解**: `1`

### 出題のポイント
- 台固定時の小球の最高到達高度（力学的エネルギー保存則）
- 台が自由に動ける場合の水平方向運動量保存則
- 相対的に鉛直へ打ち出される瞬間の系全体のエネルギー保存と高度比 $\frac{h}{H}$ の導出

### 詳細解説
**【題目大意】**
質量 $M$ の台の水平面 AB 上にある質量 $m$ の小物体に初速 $v$ を与え、面 CD から真上に飛び出させる。台が固定されている場合の最高高度を $H$、台が滑らかな床上で自由に動ける場合の最高高度を $h$ とするとき、比 $\frac{h}{H}$ を求める。

**【公式正解】**
正解：$\textcircled{1}$ （$\frac{M}{M+m}$）

**【詳細推導・解答プロセス】**
**(1) 台が固定されている場合**
小物体は初速度 $v$ で水平面 AB を進み、CD 面を経て鉛直上向きに速さ $v$ で飛び出す。
力学的エネルギー保存則より：
$$\frac{1}{2}mv^2 = mgH \implies H = \frac{v^2}{2g}$$

**(2) 台が自由に動ける場合**
台と床の間には摩擦がないため、小物体と台の全体系において水平方向の外力は働かず、水平方向の運動量が保存される。
小物体が鉛直面 CD から鉛直上向きに飛び出す瞬間、小物体は台に対して鉛直方向に運動しているため、小球の水平速度は台の水平速度 $V$ と等しくなる。
水平方向の運動量保存則より：
$$mv = (M + m)V \implies V = \frac{m}{M + m}v$$
次に、小物体が最高点（高さ $h$）に達した瞬間、小物体と台の水平方向の速度はともに $V$ であり、小物体の鉛直方向の速度は 0 である。
全体系の力学的エネルギー保存則より：
$$\frac{1}{2}mv^2 = \frac{1}{2}(M + m)V^2 + mgh$$
ここで $V = \frac{m}{M + m}v$ を代入すると：
$$mgh = \frac{1}{2}mv^2 - \frac{1}{2}(M + m)\left(\frac{m}{M + m}v\right)^2 = \frac{1}{2}mv^2 - \frac{1}{2}\frac{m^2}{M + m}v^2$$
$$mgh = \frac{1}{2}mv^2 \left(1 - \frac{m}{M + m}\right) = \frac{1}{2}mv^2 \left(\frac{M}{M + m}\right)$$
両辺を $mg$ で割ると：
$$h = \frac{v^2}{2g} \left(\frac{M}{M + m}\right) = H \left(\frac{M}{M + m}\right)$$
したがって：
$$\frac{h}{H} = \frac{M}{M + m}$$
よって、正解は $\textcircled{1}$ である。

**【考査考点】**
- 水平方向の外力がゼロであることによる運動量保存則の成立。
- 分離・飛び出し時における相対運動と拘束条件。
- 系全体の力学的エネルギー保存則とエネルギー配分比の導出。

## 物理 問4：力積-時間グラフ（F-t図）の面積と運動量変化

**問題コード**: `phys-q-04` | **正解参照**: `PHYSICS:4` | **正解**: `4`

### 出題のポイント
- 初期運動量 $p_0 = mv_0$ の計算
- $F-t$ グラフの面積による力積 $I = \int F dt$ の導出
- 運動量と力積の関係式 $p = p_0 + I$ の適用

### 詳細解説
**【題目大意】**
質量 $4.0\text{ kg}$ の物体が滑らかな水平面上を速さ $3.0\text{ m/s}$ で等速直線運動している。進行方向と同じ向きに時間変化する力 $F(t)$ を 4.0 秒間加えたときの最終的な運動量を求める。

**【公式正解】**
正解：$\textcircled{4}$ （$28\text{ kg}\cdot\text{m/s}$）

**【詳細推導・解答プロセス】**
**(1) 初期の運動量の計算**
物体の質量 $m = 4.0\text{ kg}$、初速度 $v_0 = 3.0\text{ m/s}$ であるから、力を加える前の運動量 $p_0$ は：
$$p_0 = m v_0 = 4.0 \times 3.0 = 12\text{ kg}\cdot\text{m/s}$$

**(2) 加えられた力積の計算**
物体に加えられた力積 $I$ は、$F-t$ グラフにおける曲線（直線）と $t$ 軸で囲まれた面積に等しい。
$t = 0$ から $t = 4.0\text{ s}$ の間の三角形（底辺 $4.0\text{ s}$、高さ $8.0\text{ N}$）の面積を計算すると：
$$I = \frac{1}{2} \times 4.0\text{ s} \times 8.0\text{ N} = 16\text{ N}\cdot\text{s} = 16\text{ kg}\cdot\text{m/s}$$

**(3) 力を加えた後の運動量の決定**
運動量と力積の関係（$p = p_0 + I$）より：
$$p = 12 + 16 = 28\text{ kg}\cdot\text{m/s}$$
したがって、最も適当な値は 28 であり、正解は $\textcircled{4}$ である。

**【考査考点】**
- 運動量 $p = mv$ の定義。
- $F-t$ グラフの積分面積が力積を表すことの理解。
- 力積による運動量の変化量定理。

## 物理 問5：ばねの並列接続と単振動の周期比

**問題コード**: `phys-q-05` | **正解参照**: `PHYSICS:5` | **正解**: `2`

### 出題のポイント
- 単一ばねの単振動周期公式 $T_1 = 2\pi\sqrt{\frac{m}{k}}$
- 並列接続された2つのばねの合成ばね定数 $k_{\text{eff}} = 2k$
- 合成周期 $T_2$ と周期比 $\frac{T_2}{T_1} = \frac{\sqrt{2}}{2}$ の導出

### 詳細解説
**【題目大意】**
ばね定数 $k$ のばねにおもりをつるしたときの単振動の周期を $T_1$ とする。同じばねを2つ並列に配置し、質量の無視できる棒を介しておもりをつるしたときの周期を $T_2$ とするとき、比 $\frac{T_2}{T_1}$ を求める。

**【公式正解】**
正解：$\textcircled{2}$ （$\frac{\sqrt{2}}{2}$）

**【詳細推導・解答プロセス】**
**(1) 単一ばねの単振動の周期 $T_1$**
おもりの質量を $m$、ばね定数を $k$ とすると、単一のばねによる単振動の周期は：
$$T_1 = 2\pi \sqrt{\frac{m}{k}}$$

**(2) 2本のばねを並列接続したときの合成ばね定数と周期 $T_2$**
同じばね定数 $k$ のばねを 2 本並列に接続しておもりをつり下げた場合、おもりが変位 $x$ だけ下方に動くと、各ばねがそれぞれ $x$ だけ伸びる。
おもり（棒）に働く上向きの復元力は：
$$F = -(kx + kx) = -2kx$$
したがって、系の合成ばね定数は $k_{\text{eff}} = 2k$ である。
このときの単振動の周期 $T_2$ は：
$$T_2 = 2\pi \sqrt{\frac{m}{2k}} = \frac{1}{\sqrt{2}} \left(2\pi \sqrt{\frac{m}{k}}\right) = \frac{1}{\sqrt{2}} T_1 = \frac{\sqrt{2}}{2} T_1$$

**(3) 周期の比 $\frac{T_2}{T_1}$**
したがって：
$$\frac{T_2}{T_1} = \frac{\sqrt{2}}{2}$$
よって、正解は $\textcircled{2}$ である。

**【考査考点】**
- ばね振り子の周期の決定公式。
- ばねの並列合成における有効ばね定数の加法性 ($k_{\text{eff}} = k_1 + k_2$)。
- 周期とばね定数の平方根逆比例関係。

## 物理 問6：円筒面上の滑走と小球の面からの離脱条件

**問題コード**: `phys-q-06` | **正解参照**: `PHYSICS:6` | **正解**: `2`

### 出題のポイント
- 力学的エネルギー保存則による角度 $\theta$ での速度 $v$ の導出
- 円運動の向心方向の運動方程式と垂直抗力 $N$ の立式
- 離脱条件 $N = 0$ からの初速度 $v_0$ の表現

### 詳細解説
**【題目大意】**
半径 $r$ の円柱面の上端 A に接続した水平面から初速 $v_0$ で小物体を滑り込ませたところ、中心角 $\angle AOB = \theta$ の点 B で円柱表面から離れた。$v_0$ を表す式を求める。

**【公式正解】**
正解：$\textcircled{2}$ （$\sqrt{(3\cos \theta - 2)gr}$）

**【詳細推導・解答プロセス】**
**(1) 力学的エネルギー保存則**
点 A を基準の高さとすると、鉛直線から角度 $\theta$ の位置にある点 B の高さは、点 A よりも $r(1 - \cos \theta)$ だけ低い。
摩擦はないため力学的エネルギーが保存される。点 B における速さを $v$ とすると：
$$\frac{1}{2}mv_0^2 + mgr = \frac{1}{2}mv^2 + mgr \cos \theta$$
整理すると：
$$v^2 = v_0^2 + 2gr(1 - \cos \theta)$$

**(2) 円運動の運動方程式と垂直抗力**
点 B において、小物体には重力 $mg$（鉛直下向き）と円柱面からの垂直抗力 $N$（外向き法線方向）が働く。
円の中心に向かう法線方向成分の運動方程式は：
$$m \frac{v^2}{r} = mg \cos \theta - N$$
垂直抗力 $N$ について解くと：
$$N = mg \cos \theta - m \frac{v^2}{r}$$

**(3) 離脱条件の適用**
小物体が点 B で円柱の表面から離れる瞬間、垂直抗力は $N = 0$ となる。
$$mg \cos \theta = m \frac{v^2}{r} \implies v^2 = gr \cos \theta$$
エネルギー保存則で得られた $v^2$ を代入すると：
$$v_0^2 + 2gr(1 - \cos \theta) = gr \cos \theta$$
$$v_0^2 + 2gr - 2gr \cos \theta = gr \cos \theta$$
$$v_0^2 = 3gr \cos \theta - 2gr = (3\cos \theta - 2)gr$$
$v_0 > 0$ より：
$$v_0 = \sqrt{(3\cos \theta - 2)gr}$$
よって、正解は $\textcircled{2}$ である。

**【考査考点】**
- 円軌道運動における向心力と垂直抗力の釣合方程式。
- 重力場における力学的エネルギー保存則。
- 面からの離脱（束縛の消失）条件 $N = 0$ の適用。

## 物理 問7：氷と容器の加熱・状態変化における融解時間の算出

**問題コード**: `phys-q-07` | **正解参照**: `PHYSICS:7` | **正解**: `4`

### 出題のポイント
- 容器と氷の全熱容量 $C_{\text{tot}}$ と熱供給速度 $\frac{dQ}{dt}$ の算出
- 氷の融解に必要な潜熱 $Q_{\text{melt}} = mL$ の計算
- 温度一定（0°C）の潜熱吸収時間の導出

### 詳細解説
**【題目大意】**
熱容量 $1.0 \times 10^3\text{ J/K}$ の容器に $-20^\circ\text{C}$ の氷 $1.0\text{ kg}$（比熱 $2.0 \times 10^3\text{ J/(kg}\cdot\text{K)}$、融解熱 $3.3 \times 10^5\text{ J/kg}$）を入れ、一定熱量を与え続けた。昇温速度が $10\text{ K/min}$ であったとき、$0^\circ\text{C}$ で温度が一定であった時間（融解時間）を求める。

**【公式正解】**
正解：$\textcircled{4}$ （$11$ 分）

**【詳細推導・解答プロセス】**
**(1) 容器および氷の全熱容量と単位時間あたりの熱供給量**
$-20^\circ\text{C}$ から $0^\circ\text{C}$ までの温度上昇時において、容器の熱容量は $C = 1.0 \times 10^3\text{ J/K}$、氷の熱容量は：
$$C_{\text{ice}} = m c = 1.0\text{ kg} \times 2.0 \times 10^3\text{ J/(kg}\cdot\text{K)} = 2.0 \times 10^3\text{ J/K}$$
したがって、系全体の熱容量は：
$$C_{\text{tot}} = C + C_{\text{ice}} = 1.0 \times 10^3 + 2.0 \times 10^3 = 3.0 \times 10^3\text{ J/K}$$
温度上昇速度は毎分 $10\text{ K}$ であるから、ヒーターが系に供給する熱量速度（単位時間あたりの熱量）$\frac{dQ}{dt}$ は：
$$\frac{dQ}{dt} = C_{\text{tot}} \times 10\text{ K/min} = 3.0 \times 10^3 \times 10 = 3.0 \times 10^4\text{ J/min}$$

**(2) 氷の融解に必要な総熱量**
氷 $1.0\text{ kg}$ が $0^\circ\text{C}$ の水に完全に融解するために必要な熱量 $Q_{\text{melt}}$ は：
$$Q_{\text{melt}} = m L = 1.0\text{ kg} \times 3.3 \times 10^5\text{ J/kg} = 3.3 \times 10^5\text{ J}$$

**(3) 融解にかかる時間（温度一定の時間）**
供給熱量速度は一定であるから、融解に要する時間 $t$ は：
$$t = \frac{Q_{\text{melt}}}{\frac{dQ}{dt}} = \frac{3.3 \times 10^5\text{ J}}{3.0 \times 10^4\text{ J/min}} = 11\text{ 分}$$
したがって、正解は $\textcircled{4}$ である。

**【考査考点】**
- 比熱と熱容量の定義および合成熱容量の計算。
- 熱量保存則と熱流率（仕事率）の定式化。
- 状態変化における潜熱（融解熱）の吸収過程と所要時間の計算。

## 物理 問8：断熱連結容器における気体の混合と物質量比

**問題コード**: `phys-q-08` | **正解参照**: `PHYSICS:8` | **正解**: `1`

### 出題のポイント
- 理想気体の状態方程式による初期物質量 $n_A, n_B$ の特定
- 断熱自由混合における全内部エネルギーおよび温度の保存
- 平衡後の圧力と容器 A 内の残存物質量比 $\frac{n_A'}{n_A}$ の導出

### 詳細解説
**【題目大意】**
断熱容器 A（容積 $V$、圧力 $8p$、温度 $T$）と断熱容器 B（容積 $4V$、圧力 $p$、温度 $T$）をコックでつなぐ。コックを開いて十分に混合させた後の容器 A 内の物質量 $n_A'$ と初期物質量 $n_A$ の比 $\frac{n_A'}{n_A}$ を求める。

**【公式正解】**
正解：$\textcircled{1}$ （$\frac{3}{10}$）

**【詳細推導・解答プロセス】**
**(1) 混合前の各容器内の物質量**
気体定数を $R$ とする。状態方程式 $PV = nRT$ より：
- 容器 A：$n_A = \frac{(8p)V}{RT} = \frac{8pV}{RT}$
- 容器 B：$n_B = \frac{p(4V)}{RT} = \frac{4pV}{RT}$
系全体の気体の総物質量は：
$$n_{\text{tot}} = n_A + n_B = \frac{8pV}{RT} + \frac{4pV}{RT} = \frac{12pV}{RT}$$

**(2) 混合後の温度と圧力**
容器と細管は断熱材でできており、外部との熱のやり取りはなく、外部へ仕事をすることもない。
さらに、混合前の A と B の温度はともに $T$ で等しいため、内部エネルギーの保存より、混合後の平衡温度も $T$ のままである。
全容積は $V_{\text{tot}} = V + 4V = 5V$ である。
混合後の平衡圧力 $p'$ は：
$$p' = \frac{n_{\text{tot}} RT}{V_{\text{tot}}} = \frac{12pV}{5V} = \frac{12}{5}p$$

**(3) 容器 A 内の混合後の物質量 $n_A'$ と比の導出**
混合後、気体は全容積 $5V$ に均一に分布する。
容器 A（容積 $V$）内の気体の物質量 $n_A'$ は：
$$n_A' = \frac{p' V}{RT} = \frac{\frac{12}{5}pV}{RT} = \frac{12}{5} \cdot \frac{pV}{RT}$$
初期の $n_A = \frac{8pV}{RT}$ との比をとると：
$$\frac{n_A'}{n_A} = \frac{\frac{12}{5} \cdot \frac{pV}{RT}}{8 \cdot \frac{pV}{RT}} = \frac{12}{5 \times 8} = \frac{12}{40} = \frac{3}{10}$$
よって、正解は $\textcircled{1}$ である。

**【考査考点】**
- 理想気体の状態方程式の適用。
- 断熱自由混合における熱力学第1法則と平衡温度の決定。
- 分圧・分体積の法則と物質量分配比の導出。

## 物理 問9：$p-V$ グラフ上の直線状態変化における絶対温度の大小関係

**問題コード**: `phys-q-09` | **正解参照**: `PHYSICS:9` | **正解**: `2`

### 出題のポイント
- 絶対温度 $T$ と状態量の積 $pV$ の比例関係（$T = \frac{pV}{nR}$）
- $p-V$ 線形変化直線 $p = -aV + b$ による温度関数 $T(V)$ の2次関数化
- 下に凸／上に凸な放物線の頂点における最高温度と端点温度の比較

### 詳細解説
**【題目大意】**
$p-V$ グラフ上で状態 A から B へ直線的に変化させた。中点を C とするとき、各状態の絶対温度 $T_A, T_B, T_C$ の間の大小関係を求める。

**【公式正解】**
正解：$\textcircled{2}$ （$T_A = T_B < T_C$）

**【詳細推導・解答プロセス】**
**(1) 温度と $pV$ 積の関係**
理想気体の状態方程式 $pV = nRT$ より、一定物質量のもとで絶対温度 $T$ は積 $pV$ に正比例する：
$$T \propto pV$$

**(2) 直線変化における $pV$ の関数表現**
$p-V$ 平面上で状態 A から B への変化を表す直線は右下がりの直線であり、傾きを $-a$ ($a > 0$)、切片を $b$ とすると：
$$p(V) = -aV + b$$
状態 A と B で温度が等しい（等温曲線 $pV = \text{const}$ と直線が 2 点 A, B で交わる）場合、$p_A V_A = p_B V_B$ であり、$T_A = T_B$ である。
このとき、積 $pV$ を $V$ の関数として表すと：
$$f(V) = p(V)V = (-aV + b)V = -aV^2 + bV$$
これは $V$ に関する上に凸の2次関数である。

**(3) 中点 C における温度の比較**
上に凸の2次関数 $f(V)$ において、$f(V_A) = f(V_B)$ であるから、その放物線の対称軸（頂点）は線分 AB の中点：
$$V_C = \frac{V_A + V_B}{2}$$
に位置する。
したがって、中点 C において積 $pV$、すなわち絶対温度 $T$ は極大かつ最大値をとる：
$$T_C > T_A = T_B$$
すなわち：
$$T_A = T_B < T_C$$
よって、正解は $\textcircled{2}$ である。

**【考査考点】**
- $p-V$ 図における等温線（反比例曲線）の配置と温度勾配の理解。
- 直線経路上の状態量積 $pV$ の2次関数解析。
- 相異なる2点で等しい値をとる2次関数の対称性と中点での最大値特性。

## 物理 問10：固定端および自由端における反射波の合成波形

### 詳細解説
**【題目大意】**
位置 $x=0$ に固定端 A、$x=L$ に自由端 B がある。$t=0$ で $x$ 軸正の向きに進む波形が与えられているとき、時刻 $t = \frac{2L}{v}$ における波形を選択する。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
**(1) 各反射端における境界条件**
- 固定端（$x=0$）：変位が常に 0 に固定されるため、反射波は上下反転（位相が $\pi$ 変化）して反射する。
- 自由端（$x=L$）：端点が自由に動くため、反射波は上下そのまま（同位相）で反射する。

**(2) 経過時間 $t = \frac{2L}{v}$ における伝播履歴**

右向きに進む成分は $x=L$ の自由端で反射して左向きになり、さらに $x=0$ の固定端で反射して再び右向きになる。
1回の自由端反射（符号変化なし：$+1$）と1回の固定端反射（符号反転：$-1$）を受けるため、往復 $2L$ 伝播した波は全体として符号が反転（上下逆）する。
進行方向も往復によって再び初期と同じ $+x$ 向きとなる。
これに対応する波形パターンを肢の中から選ぶと、$\textcircled{3}$ の波形となる。
よって、正解は $\textcircled{3}$ である。

**【考査考点】**
- 固定端反射と自由端反射の位相変化則。
- 反射波の作図法および往復伝播による全位相変化の計算。
- 波動の独立性と重ね合わせの原理。

音源が直線上を一定速度で移動する。観測点 P と Q において観測される振動数の時間変化を表すグラフの正しい組み合わせを選ぶ。

**【公式正解】**

**【詳細推導・解答プロセス】**
**(1) ドップラー効果の基本原理**
音速を $V$、音源の固有振動数を $f_0$、音源の移動速度を $u$ とする。
- 音源が観測者に向かって一直線上に近づくとき：観測振動数は高くなり一定値 $f = \frac{V}{V - u} f_0 > f_0$。

- 直線から離れた側方の観測点 Q では、音源が近づくにつれて視線速度が徐々に減少し、最接近時に $f = f_0$ となり、その後遠ざかるにつれて連続的・滑らかに減少する（グラフ (c)）。

## 物理 問12：くさび形空気層による光の干渉と暗線間隔

**問題コード**: `phys-q-12` | **正解参照**: `PHYSICS:12` | **正解**: `2`

### 出題のポイント
- くさび形空気層の光路差 $\Delta = 2d$ と固定端反射（位相反転 $\pi$）による暗線条件
- 幾何学的比例関係 $\frac{d}{x} = \frac{D}{L}$ と暗線間隔 $\Delta x = \frac{\lambda L}{2D}$
- 厚さ $D$ の厳密な数値計算

### 詳細解説
**【題目大意】**
長さ $L = 10\text{ cm}$ の2枚のガラス板の一端に厚さ $D$ のフィルムを挟んでくさび形空気層を作った。波長 $\lambda = 5.0 \times 10^{-7}\text{ m}$ の単色光を垂直に入射させたところ、暗線間隔 $\Delta x = 0.50\text{ mm}$ の縞模様が観測された。フィルムの厚さ $D$ [mm] を求める。

**【公式正解】**
正解：$\textcircled{2}$ （$0.050\text{ mm}$）

**【詳細推導・解答プロセス】**
**(1) くさび形干渉における干渉条件**
接触端から距離 $x$ における空気層の厚さを $d$ とする。
上のガラス下面での反射（屈折率大から小）では位相変化なし。
下のガラス上面での反射（屈折率小から大）では位相が $\pi$ 反転する。
往復の光路差は $2d$ であるから、暗線が生じる条件は：
$$2d = m\lambda \quad (m = 0, 1, 2, \dots)$$

**(2) 幾何学的関係と暗線間隔の導出**
くさびの傾きが微小であるため、相似関係より：
$$\frac{d}{x} = \frac{D}{L} \implies d = \frac{D}{L}x$$
これを暗線条件に代入すると：
$$2\left(\frac{D}{L}x\right) = m\lambda \implies x = m \frac{\lambda L}{2D}$$
隣り合う暗線の間隔 $\Delta x$ は：
$$\Delta x = x_{m+1} - x_m = \frac{\lambda L}{2D}$$

**(3) フィルムの厚さ $D$ の算出**
与えられた数値を SI 単位系または mm 単位で統一する：
- $L = 10\text{ cm} = 100\text{ mm} = 0.10\text{ m}$
- $\lambda = 5.0 \times 10^{-7}\text{ m} = 5.0 \times 10^{-4}\text{ mm}$
- $\Delta x = 0.50\text{ mm}$
$D$ について解くと：
$$D = \frac{\lambda L}{2\Delta x} = \frac{5.0 \times 10^{-4}\text{ mm} \times 100\text{ mm}}{2 \times 0.50\text{ mm}} = \frac{0.050\text{ mm}^2}{1.0\text{ mm}} = 0.050\text{ mm}$$
したがって、正解は $\textcircled{2}$ である。

**【考査考点】**
- 薄膜干渉における反射面での位相のずれ（固定端反射と同位相反射）。
- くさび形薄膜の幾何学的線形性と干渉縞間隔公式の導出。
- 単位系の換算（m, cm, mm）と正確な代数計算。

## 物理 問13：正負の点電荷がつくる電場のベクトル合成

**問題コード**: `phys-q-01` | **正解参照**: `PHYSICS:13` | **正解**: `3`

### 出題のポイント
- クーロンの法則 $E = \frac{kQ}{r^2}$ による各点電荷からの電場強度の算出
- 正三角形をなす幾何学的配置（距離 $a$、角度 $60^\circ$）の把握
- 対称性による $y$ 成分の相殺と $x$ 成分の合成による電場強度の決定

### 詳細解説
**【題目大意】**
原点 $(0, 0)$ に電荷 $+Q$、点 $(a, 0)$ に電荷 $-Q$ が固定されている。点 $\text{P}\left(\frac{a}{2}, \frac{\sqrt{3}}{2}a\right)$ における電場の強さを求める。

**【公式正解】**
正解：$\textcircled{3}$ （$\frac{kQ}{a^2}$）

**【詳細推導・解答プロセス】**
**(1) 各点電荷から観測点 P までの距離**
原点 $\text{O}(0, 0)$ と $\text{P}\left(\frac{a}{2}, \frac{\sqrt{3}}{2}a\right)$ の距離 $r_1$ は：
$$r_1 = \sqrt{\left(\frac{a}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}a\right)^2} = \sqrt{\frac{a^2}{4} + \frac{3a^2}{4}} = \sqrt{a^2} = a$$
点 $(a, 0)$ と P の距離 $r_2$ は：
$$r_2 = \sqrt{\left(a - \frac{a}{2}\right)^2 + \left(0 - \frac{\sqrt{3}}{2}a\right)^2} = \sqrt{\frac{a^2}{4} + \frac{3a^2}{4}} = a$$
したがって、O, $(a, 0)$, P の 3 点は一辺の長さが $a$ の正三角形を形成する。

**(2) 各電荷による電場ベクトル**
- $+Q$ による電場 $\vec{E}_1$：P から遠ざかる向き（$x$ 軸正の向きから $+60^\circ$ の方向）。
大きさは：
$$E_1 = \frac{kQ}{r_1^2} = \frac{kQ}{a^2}$$
- $-Q$ による電場 $\vec{E}_2$：点 $(a, 0)$ へ向かう向き（$x$ 軸正の向きから $-60^\circ$ の方向）。
大きさは：
$$E_2 = \frac{kQ}{r_2^2} = \frac{kQ}{a^2}$$

**(3) 電場のベクトル合成**
対称性より、$y$ 方向の成分は：
$$E_y = E_1 \sin 60^\circ - E_2 \sin 60^\circ = 0$$
一方、$x$ 方向の成分は強め合う：
$$E_x = E_1 \cos 60^\circ + E_2 \cos 60^\circ = \frac{kQ}{a^2} \cdot \frac{1}{2} + \frac{kQ}{a^2} \cdot \frac{1}{2} = \frac{kQ}{a^2}$$
したがって、全電場の強さは：
$$E = \sqrt{E_x^2 + E_y^2} = \frac{kQ}{a^2}$$
よって、正解は $\textcircled{3}$ である。

**【考査考点】**
- クーロン電場の強さと向き（正電荷から湧き出し、負電荷に引き込まれる）。
- 幾何学的対称性を利用した直交成分分解。
- 電場の重ね合わせの原理。

## 物理 問15：抵抗の幾何学的寸法と直流回路における消費電力比

### 出題のポイント
- 抵抗の長さと断面積による抵抗値の決定（$R = \rho \frac{l}{S}$）

### 詳細解説
**【題目大意】**
材質・断面積が等しく、長さが 2 倍である抵抗 X と Y（$R_Y = 2R_X$）がある。スイッチを X に入れたとき、X と R の消費電力がともに $P_X$ であった。スイッチを Y に切り替えたときの Y の消費電力を $P_Y$ とするとき、比 $\frac{P_Y}{P_X}$ を求める。

スイッチを X に接続したとき、X と抵抗 R は直列接続されており、共通の電流が流れる。
両者の消費電力が等しい（$I_X^2 R_X = I_X^2 R$）ことから：
$$R = R_X = R_0$$

**(2) スイッチを X に入れたときの消費電力 $P_X$**
電池の起電力を $E$ とする。
回路の全合成抵抗は $R_X + R = R_0 + R_0 = 2R_0$ である。
流れる電流は：
$$I_X = \frac{E}{2R_0}$$
X での消費電力 $P_X$ は：
$$P_X = I_X^2 R_X = \left(\frac{E}{2R_0}\right)^2 R_0 = \frac{E^2}{4R_0}$$

**(3) スイッチを Y に入れたときの消費電力 $P_Y$**
スイッチを Y に接続すると、Y と抵抗 R（$R = R_0$）が直列接続される。
全合成抵抗は $R_Y + R = 2R_0 + R_0 = 3R_0$ である。
流れる電流は：
$$I_Y = \frac{E}{3R_0}$$
Y での消費電力 $P_Y$ は：
$$P_Y = I_Y^2 R_Y = \left(\frac{E}{3R_0}\right)^2 (2R_0) = \frac{E^2}{9R_0^2} \times 2R_0 = \frac{2E^2}{9R_0}$$

**(4) 消費電力の比 $\frac{P_Y}{P_X}$**
両者の比を計算すると：
$$\frac{P_Y}{P_X} = \frac{\frac{2E^2}{9R_0}}{\frac{E^2}{4R_0}} = \frac{2}{9} \times 4 = \frac{8}{9}$$
よって、正解は $\textcircled{4}$ である。

**【考査考点】**
- 抵抗の法則（長さ・断面積と抵抗値）。
- 直列回路におけるオームの法則と分圧・消費電力計算。
- 電源の起電力を基準とした回路状態変化の定量的比較。

## 物理 問16：コンデンサーの充放電と抵抗で発生するジュール熱

**問題コード**: `phys-q-04` | **正解参照**: `PHYSICS:16` | **正解**: `6`

### 出題のポイント
- 充電完了時における初期蓄積静電エネルギー $U_i = \frac{1}{2}C_A V^2$
- 孤立導体における電荷保存則と合成後の共通電位 $V'$ の導出
- 静電エネルギーの差引による発生ジュール熱 $Q = \frac{1}{2}\frac{C_A C_B}{C_A + C_B}V^2$ の計算

### 詳細解説
**【題目大意】**
起電力 $V$ の電源でコンデンサー $C_A$ を充電した後、電源を切り離し、$S_2$ を閉じて抵抗を介して $C_B$ と並列に接続した。平衡に達するまでに抵抗で発生した全ジュール熱を求める。

**【公式正解】**
正解：$\textcircled{6}$ （$\frac{1}{2}\frac{C_A C_B}{C_A + C_B}V^2$）

**【詳細推導・解答プロセス】**
**(1) 初期の電荷と静電エネルギー**
$S_1$ を閉じて $C_A$ を十分に充電したとき、蓄えられた電気量 $Q_0$ および静電エネルギー $U_i$ は：
$$Q_0 = C_A V, \quad U_i = \frac{1}{2}C_A V^2$$
このとき、$C_B$ には電荷は蓄えられていない。

**(2) $S_2$ を閉じた後の最終平衡状態**
$S_1$ を開き $S_2$ を閉じると、$C_A$ から抵抗を通って $C_B$ へ電荷が移動し、両端の電圧が共通の $V'$ となったときに電流が止まる。
極板間の孤立部分において電荷の総和が保存されるため：
$$(C_A + C_B)V' = Q_0 = C_A V \implies V' = \frac{C_A}{C_A + C_B}V$$
最終的な2つのコンデンサーの静電エネルギーの和 $U_f$ は：
$$U_f = \frac{1}{2}(C_A + C_B){V'}^2 = \frac{1}{2}(C_A + C_B)\left(\frac{C_A}{C_A + C_B}V\right)^2 = \frac{1}{2}\frac{C_A^2}{C_A + C_B}V^2$$

**(3) 抵抗で発生するジュール熱**
外部からのエネルギー供給はないため、減少した静電エネルギーの全量が抵抗で発生したジュール熱 $W_{\text{J}}$ に等しい：
$$W_{\text{J}} = U_i - U_f = \frac{1}{2}C_A V^2 - \frac{1}{2}\frac{C_A^2}{C_A + C_B}V^2$$
$$= \frac{1}{2}C_A V^2 \left(1 - \frac{C_A}{C_A + C_B}\right) = \frac{1}{2}C_A V^2 \left(\frac{C_B}{C_A + C_B}\right) = \frac{1}{2}\frac{C_A C_B}{C_A + C_B}V^2$$
したがって、正解は $\textcircled{6}$ である。

**【考査考点】**
- コンデンサーの基本式 $Q = CV$ および静電エネルギー公式 $U = \frac{1}{2}CV^2$。
- スイッチ切り替え回路における電荷保存則。
- 回路におけるエネルギー保存則（静電エネルギー減少量 $=$ ジュール熱）。

## 物理 問17：直線電流がつくる磁場と地磁気の合成・方位磁針の振れ角

**問題コード**: `phys-q-05` | **正解参照**: `PHYSICS:17` | **正解**: `7`

### 出題のポイント
- 直線電流がつくる同心円状磁場の公式 $H = \frac{I}{2\pi r}$ と右ねじの法則
- 地磁気 $\vec{H}_0$（北向き）と電流磁場 $\vec{H}_{\text{wire}}$ のベクトル合成
- 磁針の向き $\overrightarrow{OP}$（北から東へ $30^\circ$）条件による電流の向きと大きさの決定

### 詳細解説
**【題目大意】**
点 O を貫く鉛直直線導線がある。O から北から東へ $30^\circ$ の向き、距離 $r$ の点 P に置いた方位磁針が、無通電時には北向きを指していたが、通電後に $\overrightarrow{OP}$ の向きを指した。流した電流の向きと大きさを求める。

**【公式正解】**
正解：$\textcircled{7}$ （向き：紙面表から裏の向き、大きさ：$\pi r H_0$）

**【詳細推導・解答プロセス】**
**(1) 磁場の幾何学的配置とベクトル関係**
地磁気 $\vec{H}_0$ は真北を向いている。
直線電流がつくる磁場 $\vec{H}_{\text{wire}}$ は、導線を中心とする円の接線方向を向くため、位置ベクトル $\overrightarrow{OP}$ と常に直交する（$\vec{H}_{\text{wire}} \perp \overrightarrow{OP}$）。
合成磁場 $\vec{H}_{\text{net}} = \vec{H}_0 + \vec{H}_{\text{wire}}$ が $\overrightarrow{OP}$ 方向（北から東へ $30^\circ$）を指している。

**(2) 電流の向きの判定**
真北を向く $\vec{H}_0$ に、$\overrightarrow{OP}$ に垂直なベクトル $\vec{H}_{\text{wire}}$ を加えて、向きを東へ $30^\circ$ 傾かせるためには、$\vec{H}_{\text{wire}}$ は「南東方向（$\overrightarrow{OP}$ に対して時計回りに垂直）」を向く必要がある。
点 P において円周の時計回り方向の磁場をつくるためには、右ねじの法則より、電流は「紙面表から裏（下向き）」に流す必要がある。

**(3) 電流の大きさの算出**
$\vec{H}_{\text{net}}$ が $\overrightarrow{OP}$ に沿っており、$\vec{H}_{\text{wire}}$ は $\overrightarrow{OP}$ に垂直であるから、$\vec{H}_{\text{net}}$ と $\vec{H}_{\text{wire}}$ のなす角は $90^\circ$ である。
ベクトル三角形において、斜辺は地磁気 $\vec{H}_0$（北向き）であり、$\vec{H}_{\text{net}}$（北から東へ $30^\circ$）とのなす角が $30^\circ$ である。
したがって、直角三角形の幾何学的関係より：
$$H_{\text{wire}} = H_0 \sin 30^\circ = \frac{1}{2}H_0$$
直線電流がつくる磁場の強さの公式 $H_{\text{wire}} = \frac{I}{2\pi r}$ より：
$$\frac{I}{2\pi r} = \frac{1}{2}H_0 \implies I = \pi r H_0$$
したがって、向きは「紙面表から裏」、大きさは「$\pi r H_0$」である。
よって、正解は $\textcircled{7}$ である。

**【考査考点】**
- アンペールの法則による直線電流の磁場公式 $H = \frac{I}{2\pi r}$。
- 右ねじの法則による電流と磁場の向きの関係。
- 地磁気と人工磁場の直交ベクトル合成および幾何学的三角比の適用。

## 物理 問18：電場によるイオン加速と磁場中の質量分析（偏向距離比）

**問題コード**: `phys-q-06` | **正解参照**: `PHYSICS:18` | **正解**: `6`

### 出題のポイント
- 電位差 $V$ による加速と運動エネルギーの関係 $\frac{1}{2}mv^2 = qV$
- 磁場中におけるローレンツ力による等速円運動の軌道半径 $R = \frac{mv}{qB}$
- 偏向距離 $d = 2R$ の質量依存性（$d \propto \sqrt{m}$）と質量比 $\frac{m'}{m}$ の導出

### 詳細解説
**【題目大意】**
電荷 $q$、質量 $m$ のイオンを電位差 $V$ で加速して磁場 $B$ に垂直に入射させたところ、半円を描いて距離 $d$ 離れた点から飛び出した。質量 $m'$ の別のイオンで同様に行ったところ、飛び出し距離が $4d$ であった。質量比 $\frac{m'}{m}$ を求める。

**【公式正解】**
正解：$\textcircled{6}$ （$16$）

**【詳細推導・解答プロセス】**
**(1) 電位差加速によるイオンの速度**
初速度 0 のイオンが電位差 $V$ で加速されるとき、得られる運動エネルギーは：
$$\frac{1}{2}mv^2 = qV \implies v = \sqrt{\frac{2qV}{m}}$$

**(2) 磁場中の円軌道半径と出射距離 $d$**
磁場 $B$ 中でイオンはローレンツ力 $qvB$ を向心力として等速円運動を行う：
$$m \frac{v^2}{R} = qvB \implies R = \frac{mv}{qB}$$
速さ $v$ の式を代入すると：
$$R = \frac{m}{qB}\sqrt{\frac{2qV}{m}} = \frac{1}{B}\sqrt{\frac{2mV}{q}}$$
イオンは半円を描くため、入射点と飛び出し点との間の距離 $d$ は軌道の直径 $2R$ に等しい：
$$d = 2R = \frac{2}{B}\sqrt{\frac{2mV}{q}}$$
したがって、距離 $d$ は質量の平方根 $\sqrt{m}$ に比例する（$d \propto \sqrt{m}$）。

**(3) 質量比 $\frac{m'}{m}$ の計算**
質量 $m'$ のイオンに対する出射距離が $4d$ であるから：
$$\frac{d'}{d} = \sqrt{\frac{m'}{m}} = 4$$
両辺を2乗すると：
$$\frac{m'}{m} = 4^2 = 16$$
よって、正解は $\textcircled{6}$ である。

**【考査考点】**
- 静電場による荷電粒子の加速と仕事・エネルギー定理。
- 一様磁場中における荷電粒子の等速円運動（ローレンツ力）。
- 質量分析器の測定原理とスケーリング則。

## 物理 問19：X線の発生スペクトル・特性X線と連続X線の最短波長

**問題コード**: `phys-q-01` | **正解参照**: `PHYSICS:19` | **正解**: `6`

### 出題のポイント
- 特性X線（固有X線）の波長がターゲット金属の固有準位で定まり加速電圧に無関係であること
- 連続X線の最短波長 $\lambda_0$（デュアン・ハントの法則 $\lambda_0 = \frac{hc}{eV}$）
- 電子の運動エネルギー増加に伴う各波長の変化の判定

### 詳細解説
**【題目大意】**
高電圧で加速した電子を金属に衝突させて発生するX線スペクトルにおいて、加速電圧を大きくして電子の運動エネルギーを増加させたときの、鋭いピークの波長（特性X線）と最短波長（連続X線の限界波長）の変化を判定する。

**【公式正解】**
正解：$\textcircled{6}$ （鋭いピークの波長：変わらない、最短波長：短くなる）

**【詳細推導・解答プロセス】**
**(1) 鋭いピーク（特性X線・固有X線）の波長**
スペクトルに見られる鋭いピークは「特性X線」である。
これは、衝突した高速電子がターゲット金属原子の内殻電子（K殻やL殻など）を弾き飛ばし、生じた空孔に外殻の電子が遷移するときに放出される光子である。
光子のエネルギー準位差はターゲット金属原子の固有の殻構造によって一意に決まるため、入射電子のエネルギー（加速電圧）を変化させても、鋭いピークの波長は**変わらない**。

**(2) 最短波長（連続X線）の変化**
連続的なスペクトルは、電子が金属原子核のクーロン力によって急激に減速される際に放射される制動放射（連続X線）である。
1個の電子がもつ運動エネルギー $eV$ のすべてが一度に1個のX線光子へと変換されたときに、発生する光子のエネルギーは最大となり、波長は最短となる（デュアン・ハントの法則）：
$$eV = h \nu_{\text{max}} = \frac{hc}{\lambda_0} \implies \lambda_0 = \frac{hc}{eV}$$
加速電圧 $V$ を大きくすると、最短波長 $\lambda_0$ は反比例して小さくなる（**短くなる**）。

**(3) 結論**
- 鋭いピークの波長：変わらない
- 最短波長：短くなる
したがって、正しい組み合わせは $\textcircled{6}$ である。

**【考査考点】**
- X線管におけるX線の発生機構（制動放射と内殻遷移放射）。
- 特性X線の元素固有性と光子エネルギー準位差。
- 光量子仮説に基づく最短波長公式（デュアン・ハントの限界波長）。
