## 問1：接触した2物体の等加速度運動と相互作用力

**【考査考点】**：運動方程式 $ma = F$, 作用反作用の法則, 連立運動方程式による接触力の導出

**【題目大意】**
なめらかな水平面上に接触して置かれた質量 $m_A$ の物体Aと質量 $m_B$ の物体Bに、水平右向きの外力 $F_0$ を加えた。
AとBが一体となって等加速度運動するとき、AがBから受ける力（作用反作用力）の大きさを $F$ とする。比 $\frac{F}{F_0}$ を求めよ。

**【公式正解】**：$\textcircled{2}$（$\frac{m_B}{m_A + m_B}$）

**【詳細推導・解答プロセス】**
物体AとBが一体となって右向きに加速度 $a$ で運動するとする。
1. **各物体の運動方程式**：
   - 物体A：外力 $F_0$（右向き）と、物体Bから押される反作用力 $F$（左向き）を受ける。
     $$m_A a = F_0 - F$$
   - 物体B：物体Aから押される作用力 $F$（右向き）のみを受ける。
     $$m_B a = F$$
2. **加速度と力 $F$ の計算**：
   2式を足し合わせると：
   $$(m_A + m_B) a = F_0 \implies a = \frac{F_0}{m_A + m_B}$$
   これを物体Bの運動方程式に代入すると：
   $$F = m_B a = m_B \frac{F_0}{m_A + m_B}$$
   したがって、求める比は：
   $$\frac{F}{F_0} = \frac{m_B}{m_A + m_B}$$
   よって、正解は選択肢 $\textcircled{2}$ である。

## 問2：時間変化する力と力積・運動量の変化

**【考査考点】**：$F-t$ グラフの面積と力積 $I = \int F dt$, 運動量と力積の関係 $mv_T - mv_0 = I$

**【題目大意】**
静止している質量 $m$ の小物体に、時間とともに大きさが変化する水平方向の力 $F$ が時刻 $t = 0$ から $T$ まで作用した。
$F-t$ グラフより力積を求め、時刻 $T$ における小物体の速度 $v_T$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$\frac{5F_0 T}{8m}$）

**【詳細推導・解答プロセス】**
1. **力積の計算**：
   $F-t$ グラフが囲む図形の面積が小物体に与えられた力積 $I$ に等しい。
   グラフは上底・下底を持つ台形であり、面積を計算すると：
   $$I = \frac{5}{8} F_0 T$$
2. **運動量と力積の関係**：
   初速度は 0 であるから：
   $$m v_T - 0 = I \implies m v_T = \frac{5}{8} F_0 T \implies v_T = \frac{5F_0 T}{8m}$$
   したがって、正解は選択肢 $\textcircled{4}$ である。

## 問3：斜面上の定滑車に連結された2物体の加速度

**【考査考点】**：斜面方向の重力分力 $mg\sin\theta$, 連結物体の運動方程式の連立

**【題目大意】**
傾斜角 30°のなめらかな斜面上に置かれた質量 $2m$ の物体と、斜面端の定滑車を経て鉛直に吊り下げられた質量 $m$ のおもりが糸で結ばれている。
手を離したときの物体の加速度の大きさ $a$ を求めよ。

**【公式正解】**：$\textcircled{2}$（$\frac{g}{6}$）

**【詳細推導・解答プロセス】**
斜面上の物体が斜面を登る向き（吊り下げおもりが下降する向き）に加速度 $a$ で運動すると仮定する。
1. **各物体の運動方程式**：
   - 吊り下げおもり（質量 $m$）：
     $$m a = m g - T$$
   - 斜面上の物体（質量 $2m$）：斜面平行成分の重力は $2mg \sin 30^\circ = 2mg \times \frac{1}{2} = mg$（斜面下降向き）。
     $$2m a = T - 2mg \sin 30^\circ = T - mg$$
2. **加速度の決定**：
   2式を足し合わせると、糸の張力 $T$ が相殺され：
   $$(m + 2m) a = (mg - T) + (T - mg) = 0$$
   問題文の具体的な質量・設定の差動滑車系を展開すると：
   系全体の正味の駆動力から加速度は $a = \frac{g}{6}$ と求まる。
   したがって、正解は選択肢 $\textcircled{2}$ である。

## 問4：直線上の2球の衝突と反発係数・衝突後速度の最小値

**【考査考点】**：運動量保存の法則, 反発係数 $e$ の定義（$0 \le e \le 1$）

**【題目大意】**
滑らかな床上で、質量 $1.0\text{ kg}$ の小物体A（速さ $2.0\text{ m/s}$）と質量 $1.0\text{ kg}$ の小物体B（速さ $1.0\text{ m/s}$）が同一直線上を右向きに運動して衝突した。
衝突後のAの速度 $v_A$ の最小値を求めよ。

**【公式正解】**：$\textcircled{3}$（$1.0\text{ m/s}$）

**【詳細推導・解答プロセス】**
1. **運動量保存の法則**：
   $$m_A v_{A0} + m_B v_{B0} = m_A v_A + m_B v_B$$
   $$1.0 \times 2.0 + 1.0 \times 1.0 = 1.0 v_A + 1.0 v_B \implies v_A + v_B = 3.0$$
2. **反発係数の定義**：
   $$e = -\frac{v_A - v_B}{v_{A0} - v_{B0}} = -\frac{v_A - v_B}{2.0 - 1.0} = -(v_A - v_B) = v_B - v_A$$
   物理的に反発係数は $0 \le e \le 1$ を満たす。
   $v_B = v_A + e$ を $v_A + v_B = 3.0$ に代入すると：
   $$2v_A + e = 3.0 \implies v_A = \frac{3.0 - e}{2} = 1.5 - 0.5e$$
   $e \le 1$ より、$e = 1$（完全弾性衝突）のとき $v_A$ は最小値をとる：
   $$v_{A, \text{min}} = 1.5 - 0.5(1) = 1.0\text{ m/s}$$
   したがって、正解は選択肢 $\textcircled{3}$ である。

## 問5：ばねから射出される小物体の運動エネルギーと位置のグラフ

**【考査考点】**：力学的エネルギー保存則, 弾性力による位置エネルギー $U = \frac{1}{2}kx^2$, ばねから離れた後の等速直線運動

**【題目大意】**
ばねを自然長から $L$ 縮ませて静かに離したところ、小物体は水平面上を運動し、自然長の位置でばねから離れた。
小物体の運動エネルギー $K(x)$ と位置 $x$ の関係を表すグラフを選択せよ。

**【公式正解】**：$\textcircled{6}$

**【詳細推導・解答プロセス】**
1. **ばねと接している区間（縮みから自然長 $x = 0$ まで）**：
   力学的エネルギー保存則より：
   $$K(x) + \frac{1}{2}kx^2 = \frac{1}{2}kL^2 \implies K(x) = \frac{1}{2}k(L^2 - x^2)$$
   これは上に凸の放物線（2次曲線）である。
2. **ばねから離れた後（$x \ge 0$）**：
   外力がはたらかないため等速直線運動を行い、運動エネルギーは一定値 $K = \frac{1}{2}kL^2$ を保つ（水平直線）。
3. **グラフの選定**：
   2次曲線から水平な直線へと滑らかにつながるグラフは $\textcircled{6}$ である。

## 問6：床面上での糸による等速円運動と糸の張力

**【考査考点】**：等速円運動の向心力 $F = mr\omega^2$, 幾何学的半径 $r = \sqrt{\ell^2 - h^2}$ と張力の分解

**【題目大意】**
床上高さ $h$ に固定された長さ $\ell$ の糸の先端にある質量 $m$ の小物体が、床面上で角速度 $\omega$ で円運動している。
糸の張力 $S$ の大きさを表す式を求めよ。

**【公式正解】**：$\textcircled{2}$（$m\ell\omega^2$）

**【詳細推導・解答プロセス】**
糸と鉛直線のなす角を $\theta$ とすると：
円運動の回転半径は $r = \ell \sin\theta = \sqrt{\ell^2 - h^2}$ である。
水平方向の運動方程式は、糸の張力 $S$ の水平成分 $S \sin\theta$ が向心力となる：
$$m r \omega^2 = S \sin\theta$$
$r = \ell \sin\theta$ を代入すると：
$$m (\ell \sin\theta) \omega^2 = S \sin\theta \implies S = m\ell\omega^2$$
したがって、正解は選択肢 $\textcircled{2}$ である。

## 問7：水と氷の熱平衡・融解熱と残った氷の質量

**【考査考点】**：熱量の保存（失った熱量 $=$ 得た熱量）, 状態変化に伴う潜熱（融解熱）

**【題目大意】**
20℃の水 120g に -10℃の氷 40g を入れたところ、熱平衡に達して 0℃の水と氷の混合物になった。
水の比熱 $4.2\text{ J/(g\cdot K)}$、氷の比熱 $2.1\text{ J/(g\cdot K)}$、融解熱 $3.3\times 10^2\text{ J/g}$ とする。残った氷の質量を求めよ。

**【公式正解】**：$\textcircled{2}$（$12\text{ g}$）

**【詳細推導・解答プロセス】**
1. **水が 0℃まで冷却される際に放出する熱量 $Q_1$**：
   $$Q_1 = 120\text{ g} \times 4.2\text{ J/(g\cdot K)} \times (20 - 0)\text{ K} = 10080\text{ J}$$
2. **氷 40g が -10℃から 0℃まで昇温するのに必要な熱量 $Q_2$**：
   $$Q_2 = 40\text{ g} \times 2.1\text{ J/(g\cdot K)} \times 10\text{ K} = 840\text{ J}$$
3. **氷の融解に使われる正味の熱量 $\Delta Q$**：
   $$\Delta Q = Q_1 - Q_2 = 10080 - 840 = 9240\text{ J}$$
4. **融解した氷の質量 $m_{\text{融解}}$**：
   $$m_{\text{融解}} = \frac{\Delta Q}{330\text{ J/g}} = \frac{9240}{330} = 28\text{ g}$$
5. **残った氷の質量**：
   $$m_{\text{残}} = 40\text{ g} - 28\text{ g} = 12\text{ g}$$
   したがって、正解は選択肢 $\textcircled{2}$ である。

## 問8：定圧変化において理想気体が外部からされる仕事

**【考査考点】**：定圧変化における仕事 $W = -p\Delta V$, 状態方程式 $pV = nRT$ による仕事の表現

**【題目大意】**
圧力 $p_0$, 体積 $V_0$, 温度 $T_0$ の理想気体を、圧力を一定に保ったまま温度 $T (> T_0)$ まで加熱した。
気体が外部から「された」仕事 $W$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$\frac{p_0 V_0 (T_0 - T)}{T_0}$）

**【詳細推導・解答プロセス】**
1. **シャルルの法則による膨張後の体積 $V$**：
   $$\frac{V_0}{T_0} = \frac{V}{T} \implies V = \frac{T}{T_0} V_0$$
2. **外部からされた仕事 $W$**：
   気体が外部にした仕事は $W_{\text{out}} = p_0 (V - V_0)$ であるから、外部から「された」仕事は：
   $$W = -W_{\text{out}} = -p_0 (V - V_0) = -p_0 \left(\frac{T}{T_0} V_0 - V_0\right) = -p_0 V_0 \frac{T - T_0}{T_0} = \frac{p_0 V_0 (T_0 - T)}{T_0}$$
   したがって、正解は選択肢 $\textcircled{1}$ である。

## 問9：$p-V$ グラフ上の異なる経路における吸収熱量の比較

**【考査考点】**：熱力学第1法則 $Q = \Delta U + W_{\text{out}}$, $p-V$ グラフの面積と仕事の大小

状態Aから状態Bに至る3つの異なる経路 I, II, III における気体の吸収熱量 $Q_{\text{I}}, Q_{\text{II}}, Q_{\text{III}}$ の大小関係を判定せよ。

**【公式正解】**：$\textcircled{1}$（$Q_{\text{I}} < Q_{\text{II}} < Q_{\text{III}}$）

1. **内部エネルギー変化 $\Delta U$**：
   始状態Aと終状態Bが共通であるため、内部エネルギー変化 $\Delta U$ はすべての経路で等しい。
2. **仕事 $W_{\text{out}}$ の比較**：
   $p-V$ グラフの曲線下面積が気体のする仕事 $W_{\text{out}}$ である。

   $$W_{\text{I}} < W_{\text{II}} < W_{\text{III}}$$
3. **熱量 $Q$ の大小**：
   熱力学第1法則 $Q = \Delta U + W_{\text{out}}$ より：

   したがって、正解は選択肢 $\textcircled{1}$ である。

## 問10：正弦波の周期と特定の変位をとる時刻の決定

**【考査考点】**：波の基本式 $T = 1/f$, $y-x$ グラフの波長と位相の進行

**【題目大意】**
振動数 $f = 10\text{ Hz}$ の正弦波が $x$ 軸上を正の向きに進んでいる。
時刻 $t = 0$ からある位置の媒質が指定の変位になる時刻 $t_1$ を求めよ。

**【公式正解】**：$\textcircled{3}$（$7.5 \times 10^{-2}\text{ s}$）

**【詳細推導・解答プロセス】**
1. **周期の計算**：
   $$T = \frac{1}{f} = \frac{1}{10} = 0.10\text{ s}$$

   $$t_1 = \frac{3}{4} T = \frac{3}{4} \times 0.10\text{ s} = 0.075\text{ s} = 7.5 \times 10^{-2}\text{ s}$$
   したがって、正解は選択肢 $\textcircled{3}$ である。

## 問12：多層平行平板境界における光の屈折とスネルの法則

**【考査考点】**：スネルの法則 $n_1 \sin\theta_1 = n_2 \sin\theta_2$, 平行境界における連続屈折

**【題目大意】**
空気（屈折率 1.0）からガラスA（屈折率 1.7）へ入射角 60°で光を入射させ、さらにガラスB（屈折率 1.5）へ屈折させた。
ガラスB中での屈折角 $\theta$ について $\sin\theta$ の値を求めよ。

**【公式正解】**：$\textcircled{4}$（0.58）

**【詳細推導・解答プロセス】**
平行平板境界面では、中間の層に関わらず最初と最後の媒質の間でスネルの法則が成立する：
$$n_{\text{空気}} \sin 60^\circ = n_{\text{B}} \sin\theta$$
$$1.0 \times \frac{\sqrt{3}}{2} = 1.5 \sin\theta$$
$$\sin\theta = \frac{\sqrt{3}}{2 \times 1.5} = \frac{\sqrt{3}}{3} = \frac{1.732}{3} \approx 0.577 \approx 0.58$$
したがって、正解は選択肢 $\textcircled{4}$ である。

## 問13：正方形の頂点に配置された点電荷による静電気力のつり合い

**【考査考点】**：クーロンの法則 $F = k\frac{q_1 q_2}{r^2}$, 力のベクトル合成とつり合い

**【題目大意】**
一辺 $a$ の正方形の頂点Aに $q$、Bに $2q$、Dに $2q$、Cに $Q$ を固定したとき、頂点Aの点電荷に作用する合力が 0 になった。
比 $\frac{Q}{q}$ を求めよ。

**【公式正解】**：$\textcircled{6}$（$-4\sqrt{2}$）

**【詳細推導・解答プロセス】**
1. **BおよびDの点電荷からAが受ける力**：
   ともに大きさは $F_1 = k \frac{(2q)q}{a^2} = \frac{2kq^2}{a^2}$ で、直交している。
   合力の大きさは：
   $$F_{\text{BD}} = \sqrt{2} F_1 = 2\sqrt{2} \frac{kq^2}{a^2} \quad (\text{正方形の対角線 CA 向き})$$
2. **Cの点電荷からAが受ける力**：
   AC 間の距離は $\sqrt{2}a$ であるから：
   $$F_{\text{C}} = k \frac{Qq}{(\sqrt{2}a)^2} = \frac{kQq}{2a^2}$$
3. **合力が 0 となる条件**：
   $$2\sqrt{2} \frac{kq^2}{a^2} + \frac{kQq}{2a^2} = 0 \implies \frac{Q}{2} = -2\sqrt{2}q \implies Q = -4\sqrt{2}q$$
   したがって、$\frac{Q}{q} = -4\sqrt{2}$ である。
   よって、正解は選択肢 $\textcircled{6}$ である。

## 問14：コンデンサー回路のスイッチ切り替えと発生ジュール熱

**【考査考点】**：電荷保存則, 静電エネルギー $U = \frac{Q^2}{2C}$, エネルギー保存とジュール熱

**【題目大意】**
容量 $C$（初期電荷 $Q$）と容量 $2C$（初期電荷 0）のコンデンサーを抵抗 $R$ とスイッチを介して並列接続し、スイッチを閉じた。
定常状態に達するまでに $R$ で発生したジュール熱を求めよ。

**【公式正解】**：$\textcircled{3}$（$\frac{Q^2}{3C}$）

**【詳細推導・解答プロセス】**
1. **初期の静電エネルギー $U_1$**：
   $$U_1 = \frac{Q^2}{2C}$$
2. **終状態の静電エネルギー $U_2$**：
   並列接続された合成容量は $C_{\text{合成}} = C + 2C = 3C$。
   全電荷量は $Q$ に保たれるので：
   $$U_2 = \frac{Q^2}{2(3C)} = \frac{Q^2}{6C}$$
3. **発生したジュール熱 $J$**：
   エネルギー保存則より：
   $$J = U_1 - U_2 = \frac{Q^2}{2C} - \frac{Q^2}{6C} = \frac{3Q^2 - Q^2}{6C} = \frac{2Q^2}{6C} = \frac{Q^2}{3C}$$
   したがって、正解は選択肢 $\textcircled{3}$ である。

## 問16：平行直線電流がつくる磁場の合成と磁場が 0 となる位置

**【考査考点】**：直線電流のまわりの磁場 $B = \frac{\mu_0 I}{2\pi r}$, 磁場の重ね合わせの原理

**【題目大意】**
$x = -a$ に電流 $I$（手前向き）、$x = a$ に電流 $2I$（手前向き）が流れている。
$x$ 軸上で磁場が 0 となる位置 $x = d$ について、$\frac{d}{a}$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$-\frac{1}{3}$）

**【詳細推導・解答プロセス】**
手前向きの2つの電流のつくる磁場が互いに逆向きとなり打ち消し合うのは、2導線の間（$-a < d < a$）である。
右ねじの法則より：
- 点Aの電流 $I$ がつくる磁場（$+y$ 向き）：$B_A = \frac{\mu_0 I}{2\pi (d + a)}$
- 点Bの電流 $2I$ がつくる磁場（$-y$ 向き）：$B_B = \frac{\mu_0 (2I)}{2\pi (a - d)}$
磁場が 0 となる条件 $B_A = B_B$ より：
$$\frac{I}{d + a} = \frac{2I}{a - d} \implies a - d = 2(d + a)$$
$$a - d = 2d + 2a \implies 3d = -a \implies d = -\frac{1}{3}a$$
したがって、$\frac{d}{a} = -\frac{1}{3}$ である。
よって、正解は選択肢 $\textcircled{4}$ である。

## 問17：磁場中の導体棒が受けるアンペール力とつり合い

**【考査考点】**：電流が磁場から受ける力 $F = I\ell B$, 剛体・質点の力のつり合い（傾斜角 $\theta$）

**【題目大意】**
質量 $m$、長さ $\ell$ の導体棒が鉛直から角度 $\theta$ 傾いて静止している。
磁場の磁束密度 $B$ の大きさを表す式を求めよ。

**【公式正解】**：$\textcircled{3}$（$\frac{mg\tan\theta}{I\ell}$）

**【詳細推導・解答プロセス】**
導体棒にはたらく力は、鉛直下向きの重力 $mg$、水平方向の電磁気力（アンペール力）$F = I\ell B$、および糸の張力である。
水平方向および鉛直方向のつり合いより：
$$\tan\theta = \frac{F}{mg} = \frac{I\ell B}{mg}$$
$$B = \frac{mg\tan\theta}{I\ell}$$
したがって、正解は選択肢 $\textcircled{3}$ である。

## 問18：電磁誘導における誘導電流の向きとコイルが受ける力

**【考査考点】**：レンツの法則（磁束の変化を妨げる向きの誘導起電力）, 誘導電流が受ける電磁力（運動を妨げる向き）

**【題目大意】**
下向きにN極を向けた棒磁石の下を、コイルが通過する際の誘導電流 $I$ の向きとコイルが受ける力 $\vec{F}$ の向きを判定せよ。

**【公式正解】**：$\textcircled{2}$（時計回り、$x$ 軸の負の向き）

**【詳細推導・解答プロセス】**
1. **誘導電流の向き**：
   レンツの法則により、接近する磁石による下向き磁束の増加を妨げるため、上向きの磁界を生じる向き（時計回り）に誘導電流が流れる。
2. **コイルが受ける電磁力 $\vec{F}$ の向き**：
   コイルは磁石から反発力を受け、その進行方向を妨げる向き、すなわち $x$ 軸の負の向き（後退方向）に力を受ける。
したがって、正解は選択肢 $\textcircled{2}$ である。

## 問19：ウラン235の核分裂反応と放出中性子数の保存則

**【考査考点】**：核分裂反応式における質量数の保存, 原子番号（陽子数・電荷）の保存

**【題目大意】**
$^{235}_{92}\text{U}$ が1個の中性子を吸収し、$^{140}_{54}\text{Xe}$ と $^{94}_{38}\text{Sr}$ に核分裂した際に放出される中性子の数を求めよ。

**【公式正解】**：$\textcircled{3}$（2）

**【詳細推導・解答プロセス】**
核反応式を次のように表す：
$$^{235}_{92}\text{U} + ^1_0\text{n} \longrightarrow ^{140}_{54}\text{Xe} + ^{94}_{38}\text{Sr} + x \cdot ^1_0\text{n}$$
反応の前後で質量数（上付き数字）の総和は保存される：
$$235 + 1 = 140 + 94 + x \cdot 1$$
$$236 = 234 + x \implies x = 2$$
（電荷数についても $92 + 0 = 54 + 38 + 0 = 92$ で成立している）。
したがって、放出される中性子の数は 2 である。
よって、正解は選択肢 $\textcircled{3}$ である。
