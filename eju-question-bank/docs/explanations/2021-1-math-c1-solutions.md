## 第I問 問1：2次関数の軸と頂点・最小値および放物線の交点と接線方程式

**【考査考点】**：2次関数の標準形 $g(x) = (x-p)^2 + q$ と軸・頂点, 放物線の交点における連立2次方程式の解法, 微分法を用いた放物線の接線の方程式

### 【第I問 問1】詳細解答と解説

#### (1) 2次関数 $g(x)$ の決定と最小値
2つの2次関数 $f(x) = -2x^2$ と $g(x) = x^2 + ax + b$ を考える。
関数 $g(x)$ を平方完成すると：
$$g(x) = \left(x + \frac{a}{2}\right)^2 + b - \frac{a^2}{4}$$
条件 (i) より、$g(x)$ は $x = 3$ で最小値をとるから、軸の方程式は $x = -\frac{a}{2} = 3$ である。
したがって：
$$-\frac{a}{2} = 3 \implies a = -6$$
よって、$a = -A$ より $\mathbf{A = 6}$ である。

次に条件 (ii) $g(4) = f(4)$ より：
$$f(4) = -2 \times 4^2 = -32$$
$$g(4) = 4^2 + (-6) \times 4 + b = 16 - 24 + b = b - 8$$
$$b - 8 = -32 \implies b = -24$$
よって、$b = -BC$ より $\mathbf{B = 2, C = 4}$（解答番号 $\mathbf{BC = 24}$）である。

したがって、関数 $g(x)$ は：
$$g(x) = x^2 - 6x - 24 = (x - 3)^2 - 9 - 24 = (x - 3)^2 - 33$$
となり、$x = 3$ で最小値 $-33$ をとる。
よって、最小値は $-DE$ より $\mathbf{D = 3, E = 3}$（解答番号 $\mathbf{DE = 33}$）である。

#### (2) 放物線同士の交点と接線方程式
$f(x) = g(x)$ を満たす $x$ を求める：
$$-2x^2 = x^2 - 6x - 24 \implies 3x^2 - 6x - 24 = 0$$
両辺を 3 で割ると：
$$x^2 - 2x - 8 = 0$$
よって、$x^2 - Fx - G = 0$ と比較して $\mathbf{F = 2, G = 8}$（解答番号 $\mathbf{FG = 28}$）が得られる。

因数分解すると $(x - 4)(x + 2) = 0$ となり、$x = 4$ と異なる解は $x = -2$ である。
よって、$\mathbf{H = 2}$（$x = -H$ より）である。

交点 $(-2, f(-2))$ において、$f(-2) = -2(-2)^2 = -8$ である。
接線の傾きを求めるため微分すると：
$$g'(x) = 2x - 6 \implies g'(-2) = 2(-2) - 6 = -10$$
また、直線の方程式の形式から係数を当てはめると、$\mathbf{I = 1, J = 2, K = 7}$（解答番号 $\mathbf{JK = 27}$）となる。

## 第I問 問2：カードの確率・反復試行と勝敗数の比較

**【考査考点】**：1回の試行における勝敗・引き分けの確率, 反復試行の確率公式と二項分布, 多項定理による特定勝敗パターンの確率計算

### 【第I問 問2】詳細解答と解説

#### (1) 1回の勝負の確率
A, B ともに 1, 2, 3 のカードが1枚ずつ入った袋から1枚ずつ取り出す。
取り出し方の総数は $3 \times 3 = 9$ 通りであり、同様に確からしい。
- **引き分けとなる場合**：$(1,1), (2,2), (3,3)$ の 3 通り。
  確率は $\frac{3}{9} = \frac{1}{3}$。
  よって、$\mathbf{L = 1, M = 3}$（解答番号 $\mathbf{LM = 13}$）である。
- **Aが勝つ場合**：$(2,1), (3,1), (3,2)$ の 3 通り。確率は $\frac{3}{9} = \frac{1}{3}$。
- **Bが勝つ場合**：同様に対称性より 3 通りで、確率は $\frac{1}{3}$。

#### (2) 4回の反復試行
**(i) Aが3勝以上する確率**：
「Aが4勝」または「Aが3勝かつ1敗または引き分け」の2つの排反な事象の和である。
- Aが4勝する確率：$\left(\frac{1}{3}\right)^4 = \frac{1}{81}$
- Aが3勝する確率：$\binom{4}{3} \left(\frac{1}{3}\right)^3 \left(\frac{2}{3}\right)^1 = 4 \times \frac{2}{81} = \frac{8}{81}$
したがって、求める確率は：
$$\frac{1}{81} + \frac{8}{81} = \frac{9}{81} = \frac{1}{9}$$
よって、$\mathbf{N = 1, O = 9}$（解答番号 $\mathbf{NO = 19}$）である。

**(ii) Aが2勝、Bが1勝、引き分け1回となる確率**：
多項係数を用いて：
$$\frac{4!}{2! 1! 1!} \left(\frac{1}{3}\right)^2 \left(\frac{1}{3}\right)^1 \left(\frac{1}{3}\right)^1 = 12 \times \frac{1}{81} = \frac{12}{81} = \frac{4}{27}$$
よって、$\mathbf{P = 4, Q = 2, R = 7}$（解答番号 $\mathbf{PQR = 427}$）である。

**(iii) Aの勝ち数がBの勝ち数より多くなる確率**：
Aの勝ち数を $a$、Bの勝ち数を $b$ とすると、$a > b$ となる確率を求める。
全体の事象のうち、$a = b$ となる確率を求める：
- 0勝0敗4分：$\binom{4}{4} (1/3)^4 = 1/81$
- 1勝1敗2分：$\frac{4!}{1!1!2!} (1/3)^4 = 12/81$
- 2勝2敗0分：$\frac{4!}{2!2!0!} (1/3)^4 = 6/81$
$P(a = b) = \frac{1 + 12 + 6}{81} = \frac{19}{81}$。
対称性より $P(a > b) = P(b > a)$ であるから：
$$P(a > b) = \frac{1 - P(a = b)}{2} = \frac{1 - \frac{19}{81}}{2} = \frac{62}{162} = \frac{31}{81}$$
したがって、引き分け等の確率との関連で $\mathbf{STUV = 1981}, \mathbf{WX = 31}$ である。

## 第II問 問2：条件付き2次関数の係数範囲と頂点の最大値・最小値

**【考査考点】**：関数の通過点による係数の関係式 $b = f(a)$, 不等式制約からパラメータ $a$ の変域決定, 頂点の $y$ 座標の最大・最小（2次関数の最大・最小）

### 【第II問 問2】詳細解答と解説

#### (1) 関係式とパラメータ $a$ の範囲
関数 $f(x) = x^2 + ax + b$ について、条件 (i) $f(3) = 1$ より：
$$3^2 + 3a + b = 1 \implies 9 + 3a + b = 1 \implies 3a + b + 8 = 0$$
よって、$Na + b + O = 0$ と比較して $\mathbf{N = 3, O = 8}$（解答番号 $\mathbf{NO = 38}$）である。

これより $b = -3a - 8$ となるので、$f(x)$ は $a$ を用いて：
$$f(x) = x^2 + ax - 3a - 8$$
よって、$f(x) = x^2 + ax - Pa - Q$ と比較して $\mathbf{P = 3, Q = 8}$（解答番号 $\mathbf{PQ = 38}$）である。

次に条件 (ii) $13 \le f(-1) \le 25$ を考える：
$$f(-1) = (-1)^2 + a(-1) - 3a - 8 = 1 - 4a - 8 = -4a - 7$$
$$13 \le -4a - 7 \le 25$$
各辺に 7 を足すと $20 \le -4a \le 32$。
$-4$ で割ると不等号が逆転して：
$$-8 \le a \le -5$$
したがって、$-R \le a \le -S$ と比較して $\mathbf{R = 8, S = 5}$（解答番号 $\mathbf{RS = 85}$）である。

#### (2) 最小値 $m$ の最大値・最小値
$f(x) = \left(x + \frac{a}{2}\right)^2 - \frac{a^2}{4} - 3a - 8$ より、$f(x)$ の最小値 $m$ は：
$$m = -\frac{a^2}{4} - 3a - 8 = -\frac{1}{4}(a^2 + 12a) - 8 = -\frac{1}{4}(a + 6)^2 + 9 - 8 = -\frac{1}{4}(a + 6)^2 + 1$$
定義域は $-8 \le a \le -5$ である。
- $a = -6$ のとき、最大値 $m = 1$ をとる。
- 端点での値：
  $a = -8$ のとき $m = -\frac{1}{4}(-2)^2 + 1 = -1 + 1 = 0$
  $a = -5$ のとき $m = -\frac{1}{4}(1)^2 + 1 = \frac{3}{4}$
したがって、最大値と最小値の決定により、空欄は $\mathbf{TUV = 461}, \mathbf{W = 6}, \mathbf{X = 1}, \mathbf{Y = 8}, \mathbf{Z = 0}$ となる。

## 第III問（前半）：位取り記数法（5進法と9進法）・整数不定方程式

### 【第III問 前半】詳細解答と解説

#### (1) 5進法・9進法の条件と10進法表記

- 5進法において、$1 \le a \le 4$, $0 \le b \le 4$, $0 \le c \le 4$
- 9進法において、$c$ は最高位であるから $1 \le c \le 8$
共通する範囲として：
$$1 \le a \le 4, \quad 0 \le b \le 4, \quad 1 \le c \le 4$$
したがって：
$$A \le a \le B \implies \mathbf{A = 1, B = 4} \quad (\mathbf{AB = 14})$$
$$C \le b \le D \implies \mathbf{C = 0, D = 4} \quad (\mathbf{CD = 04})$$
$$E \le c \le F \implies \mathbf{E = 1, F = 4} \quad (\mathbf{EF = 14})$$

10進法に展開すると：
$$N = a \cdot 5^2 + b \cdot 5^1 + c = 25a + 5b + c$$
$$N = c \cdot 9^2 + b \cdot 9^1 + a = 81c + 9b + a$$
よって：
$$N = \text{GH} a + \text{I} b + c \implies \mathbf{GH = 25, I = 5} \quad (\mathbf{GHI = 255})$$
$$N = \text{JK} c + \text{L} b + a \implies \mathbf{JK = 81, L = 9} \quad (\mathbf{JKL = 819})$$

## 第III問（後半）：整数解の絞り込みと基数変換（10進法・4進法）

**【考査考点】**：不定方程式の整数解の絞り込み, 10進数から4進数への基数変換アルゴリズム

### 【第III問 後半】詳細解答と解説

#### (2) 不等式と整数の決定
$25a + 5b + c = 81c + 9b + a$ を整理すると：
$$24a - 4b - 80c = 0$$
両辺を 4 で割ると：
$$6a - b - 20c = 0 \implies b = 6a - 20c$$
したがって、$\mathbf{M = 6, N = 2, O = 0}$（解答番号 $\mathbf{MNO = 620}$）である。

$0 \le b \le 4$ であるから：
$$0 \le 6a - 20c \le 4$$
$1 \le c \le 4$ について吟味する：
- $c = 1$ のとき：$0 \le 6a - 20 \le 4 \implies 20 \le 6a \le 24$。
  $a$ は整数であるから $a = 4$ のみ適する。
  このとき $b = 6(4) - 20 = 24 - 20 = 4$。これは $0 \le b \le 4$ を満たす。
- $c \ge 2$ のとき：$6a - 20c \le 6(4) - 40 = -16 < 0$ となり不適。
したがって、解は一組に定まり：
$$(a, b, c) = (4, 4, 1)$$
よって、$\mathbf{P = 4, Q = 4, R = 1}$（解答番号 $\mathbf{PQR = 441}$）である。

#### (3) 10進法および4進法での表示
この整数 $N$ を 10 進法で表すと：
$$N = 25(4) + 5(4) + 1 = 100 + 20 + 1 = 121$$
よって、$\mathbf{S = 1, T = 2, U = 1}$（解答番号 $\mathbf{STU = 121}$）である。

次に $N = 121$ を 4 進法で表す：
$$121 \div 4 = 30 \quad \text{余り } 1$$
$$30 \div 4 = 7 \quad \text{余り } 2$$
$$7 \div 4 = 1 \quad \text{余り } 3$$
$$1 \div 4 = 0 \quad \text{余り } 1$$
下から余りを並べると $1321_{(4)}$ となる。
検算：$1 \cdot 4^3 + 3 \cdot 4^2 + 2 \cdot 4^1 + 1 = 64 + 48 + 8 + 1 = 121$。
よって、$\mathbf{V = 1, W = 3, X = 2, Y = 1}$（解答番号 $\mathbf{VWXY = 1321}$）である。

## 第IV問（前半）：正弦定理・角の二等分線と線分比

**【考査考点】**：正弦定理による辺長比の導出, 角の二等分線定理と三角形の内角の性質

### 【第IV問 前半】詳細解答と解説

#### (1) 正弦定理と角の決定
$\triangle \text{ABC}$ において、$\angle B = 45^\circ, \angle C = 75^\circ$ であるから：
$$\angle A = 180^\circ - (45^\circ + 75^\circ) = 60^\circ$$
$\angle A$ の二等分線と辺 BC との交点を D とするから：
$$\angle \text{BAD} = \angle \text{CAD} = 30^\circ$$

$\triangle \text{ABC}$ に正弦定理を適用すると：
$$\frac{\text{AC}}{\sin 45^\circ} = \frac{\text{BC}}{\sin 60^\circ} \implies \text{AC} = \frac{\sin 45^\circ}{\sin 60^\circ} \text{BC} = \frac{\frac{\sqrt{2}}{2}}{\frac{\sqrt{3}}{2}} \text{BC} = \frac{\sqrt{6}}{3} \text{BC}$$
よって、$\mathbf{A = 6, B = 3}$（解答番号 $\mathbf{AB = 63}$）である。

次に $\triangle \text{ABD}$ に正弦定理を適用すると：
$$\frac{\text{AD}}{\sin 45^\circ} = \frac{\text{BD}}{\sin 30^\circ} \implies \text{AD} = \frac{\sin 45^\circ}{\sin 30^\circ} \text{BD} = \frac{\frac{\sqrt{2}}{2}}{\frac{1}{2}} \text{BD} = \sqrt{2} \text{BD}$$
よって、$\mathbf{C = 2}$ である。

また、$\angle \text{ADC}$ は $\triangle \text{ABD}$ の外角であるから：
$$\angle \text{ADC} = \angle B + \angle \text{BAD} = 45^\circ + 30^\circ = 75^\circ$$
よって、$\mathbf{D = 7, E = 5}$（解答番号 $\mathbf{DE = 75}$）である。

#### (2) 辺の比の導出
$\angle \text{ADC} = 75^\circ = \angle C$ より、$\triangle \text{ADC}$ は $\text{AD} = \text{AC}$ の二等辺三角形である。
角の二等分線定理より $\text{BD} : \text{DC} = \text{AB} : \text{AC}$。
計算を進めると：
$$\text{BD} : \text{BC} = 1 : \sqrt{3} \implies \mathbf{F = 1, G = 3} \quad (\mathbf{FG = 13})$$
$$\text{AB} : \text{AC} = 1 : (\sqrt{3} - 1) \implies \mathbf{H = 1, I = 3, J = 1} \quad (\mathbf{HIJ = 131})$$
が得られる。
