### 【第II問 問1】詳細解答と解説

## 第III問 問2：漸化式で定められた数列の一般項と無限級数の収束・和
**考查要点：** 隣接2項間漸化式 $a_{n+1} = p a_n + q$ の特性方程式による解法、等比数列の一般項 $a_n = c \cdot r^{n-1}$ の決定、無限等比級数の収束条件 $|r| < 1$ とその和 $S = \frac{a}{1 - r}$ の導出
**参考正解：** {"A": "3", "B": "5", "CD": "16"}

### 【第III問 問2】詳細解答と解説

#### (1) 特性方程式による一般項の導出
漸化式 $a_{n+1} = \frac{1}{3}a_n + 2$ に対し、特性方程式 $\alpha = \frac{1}{3}\alpha + 2$ を解くと $\alpha = 3$ である。
式変形すると $a_{n+1} - 3 = \frac{1}{3}(a_n - 3)$ となる。
数列 $\{a_n - 3\}$ は公比 $\frac{1}{3}$ の等比数列であるから、初項 $a_1 - 3$ を用いて：
$$a_n - 3 = (a_1 - 3)\left(\frac{1}{3}\right)^{n-1} \implies a_n = 3 + (a_1 - 3)\left(\frac{1}{3}\right)^{n-1}$$
$n \to \infty$ のとき公比が $\left|\frac{1}{3}\right| < 1$ であるため極限値は $3$ に収束する。

## 第IV問 問1：商の微分法・対数関数の増減表と極値・変曲点
**考查要点：** 商の微分公式 $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ の適用、第1次導関数 $f'(x)$ の符号変化による極大値・極小値の判別、第2次導関数 $f''(x)$ による凹凸判定と変曲点の決定
**参考正解：** {"AB": "11", "CD": "23", "EF": "47"}

### 【第IV問 問1】詳細解答と解説

#### (1) 関数の微分と増減の解析
定義域 $x > 0$ における関数 $f(x) = \frac{\ln x}{x}$ を微分する：
$$f'(x) = \frac{\frac{1}{x}\cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$
$f'(x) = 0 \iff 1 - \ln x = 0 \iff x = e$。
- $0 < x < e$ では $f'(x) > 0$（単調増加）
- $x > e$ では $f'(x) < 0$（単調減少）
したがって $x = e$ において極大値 $f(e) = \frac{1}{e}$ をとる。
変曲点は $f''(x) = \frac{2\ln x - 3}{x^3} = 0$ より $x = e^{3/2}$ である。

### 【第IV問 問2】詳細解答と解説

#### (1) 部分積分法による面積計算
曲線 $y = x e^{-x}$ と $x$ 軸および直線 $x = 1$ で囲まれた領域の面積を求める：
