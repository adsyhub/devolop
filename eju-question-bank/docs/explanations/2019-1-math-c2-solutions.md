## 第I問 問1：2次関数のグラフと係数の符号判定・二次式の最小値問題

**【考査考点】**：2次関数 $y = ax^2 + bx + c$ のグラフの開き（$a$ の正負）と軸の位置（$-b/(2a)$）, $y$ 切片（$c$）と特定の値 $x = 1, -1, 2$ における関数値の符号判定, 判別式 $D = b^2 - 4ac$ による共有点の判定, 条件 $a+b+c=0$ のもとでの $a^2 - 8b - 8c$ の最小化と変数 $b$ の取り得る値の範囲

### 【第I問 問1】詳細解答と解説

#### (1) グラフの幾何学的特徴から係数の符号判定
与えられた 2 次関数は $y = ax^2 + bx + c$ である。
問題図より、放物線は以下の特徴をもつ：
1. **上に凸の放物線**：
   放物線が上に凸（開口下向き）であることから、$a < 0$ である。
   選択肢 $\textcircled{9}$（$<$）より、$\mathbf{A = 9}$。
2. **対称軸の位置**：
   放物線の軸の方程式は $x = -\frac{b}{2a}$ である。
   図より軸は $y$ 軸の右側（$x > 0$）にある。
   $a < 0$ より $-2a > 0$ であるから、$-\frac{b}{2a} > 0 \iff b > 0$ である。
   選択肢 $\textcircled{7}$（$>$）より、$\mathbf{B = 7}$。
3. **$y$ 切片の符号**：
   $x = 0$ のときの $y$ 座標は $c$ である。
   図よりグラフと $y$ 軸の交点は原点より上（$y > 0$）にあるため、$c > 0$ である。
   選択肢 $\textcircled{7}$（$>$）より、$\mathbf{C = 7}$。
4. **$x = 1$ における関数値**：
   図より、放物線は点 $(1, 0)$ を通過している（$x$ 軸との右側の交点が $x = 1$）。
   したがって、$x = 1$ を代入した値 $a(1)^2 + b(1) + c = a + b + c = 0$ である。
   選択肢 $\textcircled{8}$（$=$）より、$\mathbf{D = 8}$。
5. **$x = -1$ における関数値**：
   図より、$x = -1$ でのグラフの点は $x$ 軸より下方（$y < 0$）にある。
   したがって、$a(-1)^2 + b(-1) + c = a - b + c < 0$ である。
   選択肢 $\textcircled{9}$（$<$）より、$\mathbf{E = 9}$。
6. **$x = 2$ における関数値**：
   軸が $0 < x < 1$ にあり、$x = 1$ で $y = 0$、上に凸であるため、$x = 2$ では $y$ 座標は負となる。
   したがって、$a(2)^2 + b(2) + c = 4a + 2b + c < 0$ である。
   選択肢 $\textcircled{9}$（$<$）より、$\mathbf{F = 9}$。
7. **判別式の符号**：
   放物線は $x$ 軸と異なる 2 点で交わっているため、2次方程式 $ax^2 + bx + c = 0$ の判別式は正である。
   したがって、$b^2 - 4ac > 0$ である。
   選択肢 $\textcircled{7}$（$>$）より、$\mathbf{G = 7}$。

#### (2) 条件を満たすときの最小値問題と変数の範囲
条件 (i) より $a < 0, b > 0, c > 0$、条件 (ii) より $a + b + c = 0$ である。
$a + b + c = 0$ より $c = -a - b$ であるから、対象の式を変形する：
$$a^2 - 8b - 8c = a^2 - 8b - 8(-a - b) = a^2 - 8b + 8a + 8b = a^2 + 8a$$
$b$ の項が相殺され、$a$ の 2次関数となる：
$$a^2 + 8a = (a + 4)^2 - 16$$
選択肢の数値欄（$\textcircled{0}:0, \dots, \textcircled{5}:-2, \textcircled{6}:-4$）から、$a < 0$ の範囲でこの 2次式が最小値をとるのは頂点 $a = -4$ のときである。
選択肢 $\textcircled{6}$（$-4$）より、$\mathbf{H = 6}$（数値としては $a = -4$）。

$a = -4$ のとき、$c = -a - b = 4 - b$ となる。
これを $y = ax^2 + bx + c$ に代入すると：
$$y = -4x^2 + bx + (4 - b) = -4x^2 + bx - b + 4$$
問題文の形式 $y = \text{H} x^2 + bx - b + \text{I}$ と比較すると、$\text{I}$ の位置には $+4$ が入る。
したがって、$\mathbf{I = 4}$。

最後に、$b$ の取り得る値の範囲を決定する：
- $b > 0$ であること（条件 (i) より）。
- $c > 0 \iff 4 - b > 0 \iff b < 4$ であること（条件 (i) より）。
- また、$x = 1$ で $y = 0$ は常に満たされ、軸 $x = -\frac{b}{2(-4)} = \frac{b}{8}$ は $0 < b < 4$ のとき $0 < x < \frac{1}{2}$ となり、$0 < x < 1$ にあることとも完全に整合する。
したがって、求める $b$ の範囲は $0 < b < 4$ である。
よって、$\mathbf{J = 0, K = 4}$。

## 第I問 問2：不正なサイコロの確率・独立試行と事象の比較

**【考査考点】**：確率の公理と全事象の確率（和が 1）, 独立試行における余事象の確率計算, 2回の試行における確率の差の評価（$1/36$ との比較）, 3回の試行における倍率評価（2倍未満・以上の判定）

### 【第I問 問2】詳細解答と解説

#### (1) 各目が出る確率 $p$ の決定
サイコロ X において、1 から 5 までの目が出る確率はそれぞれ $p$ で等しく、6 の目が出る確率は他の目の 2 倍である。
したがって、6 の目が出る確率は $2p$ である。よって、$\mathbf{L = 2}$。
全事象の確率は 1 であるから、$\mathbf{M = 1}$。
すべての目の確率の和をとると：
$$5 \times p + 2p = 7p = 1 \implies p = \frac{1}{7}$$
したがって、$\mathbf{NO = 17}$（$p = 1/7$）。
これより：
- 1 から 5 までの目が出る確率：$5p = \frac{5}{7}$
- 6 の目が出る確率：$2p = \frac{2}{7}$

#### (2) 2回投げたときの事象 $A, B$ の確率と差の評価
- 事象 $A$（2回とも 1 から 5 の目が出る）：
  各回独立であるから：
  $$P(A) = \left(\frac{5}{7}\right)^2 = \frac{25}{49}$$
  したがって、$\mathbf{PQRS = 2549}$（$P(A) = 25/49$）。
- 事象 $B$（少なくとも 1 回は 6 の目が出る）：
  事象 $B$ は事象 $A$ の余事象（全事象から「2回とも 1～5」を除いたもの）であるから：
  $$P(B) = 1 - P(A) = 1 - \frac{25}{49} = \frac{24}{49}$$
  したがって、$\mathbf{TUVW = 2449}$（$P(B) = 24/49$）。

- $P(A)$ と $P(B)$ の比較：
  $$P(A) - P(B) = \frac{25}{49} - \frac{24}{49} = \frac{1}{49} > 0$$
  より、$P(A)$ の方が $P(B)$ より高い。
  この差 $\frac{1}{49}$ と $\frac{1}{36}$ の大小を比較すると：
  $$49 > 36 \implies \frac{1}{49} < \frac{1}{36}$$
  したがって、「$P(A)$ の方が $P(B)$ より高く、その差は $\frac{1}{36}$ 未満」である。
  対応する選択肢は $\textcircled{4}$ である。よって、$\mathbf{X = 4}$。

#### (3) 3回投げたときの事象 $C, D$ の確率と倍率の評価
- 事象 $C$（3回とも 1 から 5 の目が出る）：
  $$P(C) = \left(\frac{5}{7}\right)^3 = \frac{125}{343}$$
- 事象 $D$（少なくとも 1 回は 6 の目が出る）：
  $$P(D) = 1 - P(C) = 1 - \frac{125}{343} = \frac{218}{343}$$
  $125 < 218$ より、$P(C)$ の方が $P(D)$ より低い。
- $P(D)$ と $P(C)$ の比（倍率）：
  $$\frac{P(D)}{P(C)} = \frac{218}{125} = 1.744$$
  $1.744 < 2$ であるから、$P(D)$ は $P(C)$ の 2倍未満である。
  したがって、「$P(C)$ の方が $P(D)$ より低く、$P(D)$ は $P(C)$ の 2倍未満」である。
  対応する選択肢は $\textcircled{1}$ である。よって、$\mathbf{Y = 1}$。

## 第II問 問1：球に内接する四面体と空間ベクトル・重心と共線条件

**【考査考点】**：球の直径（対蹠点 $\vec{d} = -\vec{b}$）と空間ベクトルの基底表示, 線分の中点ベクトル（$\overrightarrow{DA}, \overrightarrow{MN}, \overrightarrow{OP}$）の導出, 三角形の重心ベクトル $\overrightarrow{OG} = \frac{\vec{b}+\vec{c}+\vec{d}}{3}$, 内積によるベクトルの大きさの計算（$|\overrightarrow{PG}|$）, 共線条件（実数倍関係 $\overrightarrow{AG} = k \overrightarrow{AP}$）の証明

### 【第II問 問1】詳細解答と解説

原点 O を中心とする半径 2 の球面上に 4 つの頂点をもつ四面体 ABCD を考える。
球面上にあるため、$|\vec{a}| = |\vec{b}| = |\vec{c}| = |\vec{d}| = 2$ である。
また、$AB = BC = CA = 2$ であり、辺 BD は球の直径であるから、$\vec{d} = -\vec{b}$ である。

#### (1) ベクトル $\overrightarrow{DA}$ および $\overrightarrow{MN}$ の計算
1. **$\overrightarrow{DA}$ の表示**：
   $$\overrightarrow{DA} = \vec{a} - \vec{d} = \vec{a} - (-\vec{b}) = \vec{a} + \vec{b}$$
   選択肢の対応表（$\textcircled{6}: \vec{a} + \vec{b}$）より、$\mathbf{A = 6}$。

2. **$\overrightarrow{MN}$ の表示**：
   M は線分 DA の中点であるから：
   $$\overrightarrow{OM} = \frac{\vec{d} + \vec{a}}{2} = \frac{-\vec{b} + \vec{a}}{2}$$
   N は線分 BC の中点であるから：
   $$\overrightarrow{ON} = \frac{\vec{b} + \vec{c}}{2}$$
   したがって：
   $$\overrightarrow{MN} = \overrightarrow{ON} - \overrightarrow{OM} = \frac{\vec{b} + \vec{c}}{2} - \frac{-\vec{b} + \vec{a}}{2} = \frac{2\vec{b} + \vec{c} - \vec{a}}{2} = \frac{\vec{c} - \vec{a}}{2} + \vec{b}$$
   問題文の形式 $\frac{\text{B}}{\text{C}} + \text{D}$ と比較して：
   選択肢 $\textcircled{5}$ は $\vec{c} - \vec{a}$、選択肢 $\textcircled{1}$ は $\vec{b}$ であるから：
   $$\mathbf{B = 5, C = 2, D = 1} \implies \mathbf{BCD = 521}$$

#### (2) 点 P, G の位置ベクトルと線分長 $|\overrightarrow{PG}|$、共線条件の導出
1. **線分 MN の中点 P の位置ベクトル $\overrightarrow{OP}$**：
   $$\overrightarrow{OP} = \frac{\overrightarrow{OM} + \overrightarrow{ON}}{2} = \frac{\frac{\vec{a} - \vec{b}}{2} + \frac{\vec{b} + \vec{c}}{2}}{2} = \frac{\vec{a} + \vec{c}}{4}$$
   選択肢 $\textcircled{8}$ は $\vec{c} + \vec{a}$ であるから：
   $$\mathbf{E = 8, F = 4} \implies \mathbf{EF = 84}$$

2. **三角形 BCD の重心 G の位置ベクトル $\overrightarrow{OG}$**：
   $$\overrightarrow{OG} = \frac{\vec{b} + \vec{c} + \vec{d}}{3} = \frac{\vec{b} + \vec{c} - \vec{b}}{3} = \frac{\vec{c}}{3}$$
   選択肢 $\textcircled{2}$ は $\vec{c}$ であるから：
   $$\mathbf{G = 2, H = 3} \implies \mathbf{GH = 23}$$

3. **線分長 $|\overrightarrow{PG}|$ の計算**：
   $$\overrightarrow{PG} = \overrightarrow{OG} - \overrightarrow{OP} = \frac{\vec{c}}{3} - \frac{\vec{a} + \vec{c}}{4} = \frac{\vec{c} - 3\vec{a}}{12}$$
   ここで、$|\vec{a}| = 2, |\vec{c}| = 2$、また $CA = 2$ より：
   $$|\vec{c} - \vec{a}|^2 = |\vec{c}|^2 - 2\vec{a}\cdot\vec{c} + |\vec{a}|^2 = 4 - 2\vec{a}\cdot\vec{c} + 4 = 2^2 = 4$$
   $$8 - 2\vec{a}\cdot\vec{c} = 4 \implies 2\vec{a}\cdot\vec{c} = 4 \implies \vec{a}\cdot\vec{c} = 2$$
   したがって：
   $$|\vec{c} - 3\vec{a}|^2 = |\vec{c}|^2 - 6\vec{a}\cdot\vec{c} + 9|\vec{a}|^2 = 4 - 6(2) + 9(4) = 4 - 12 + 36 = 28$$
   $$|\vec{c} - 3\vec{a}| = \sqrt{28} = 2\sqrt{7}$$
   よって：
   $$|\overrightarrow{PG}| = \frac{2\sqrt{7}}{12} = \frac{\sqrt{7}}{6}$$
   形式 $\frac{\sqrt{\text{I}}}{\text{J}}$ より：
   $$\mathbf{I = 7, J = 6} \implies \mathbf{IJ = 76}$$

4. **共線条件 $\overrightarrow{AG} = k \overrightarrow{AP}$ の係数比**：
   $$\overrightarrow{AP} = \overrightarrow{OP} - \vec{a} = \frac{\vec{a} + \vec{c}}{4} - \vec{a} = \frac{\vec{c} - 3\vec{a}}{4}$$
   $$\overrightarrow{AG} = \overrightarrow{OG} - \vec{a} = \frac{\vec{c}}{3} - \vec{a} = \frac{\vec{c} - 3\vec{a}}{3}$$
   両者を比較すると：
   $$\overrightarrow{AG} = \frac{4}{3} \overrightarrow{AP}$$
   形式 $\frac{\text{K}}{\text{L}}$ より：
   $$\mathbf{K = 4, L = 3} \implies \mathbf{KL = 43}$$
   実数倍の関係が成り立つため、3点 A, P, G は同一直線上にある。

## 第II問 問2：複素数平面上の正三角形・回転と拡大および三角形の面積

**【考査考点】**：複素数の比 $\frac{\gamma - \alpha}{\beta - \alpha}$ と2次方程式の解法, 絶対値（比が 1）と偏角（$\pm \frac{2}{3}\pi$）の幾何学的解釈, 因数分解・複素数の合成による辺長の決定, 正三角形または二等辺三角形の面積公式

### 【第II問 問2】詳細解答と解説

複素数平面上の異なる3点 A($\alpha$), B($\beta$), C($\gamma$) が
$$(\gamma - \alpha)^2 + (\gamma - \alpha)(\beta - \alpha) + (\beta - \alpha)^2 = 0 \quad \cdots \textcircled{1}$$
$$|\beta - 2\alpha + \gamma| = 3 \quad \cdots \textcircled{2}$$
を満たす。

#### (1) 複素数の比 $\frac{\gamma - \alpha}{\beta - \alpha}$ の絶対値と偏角
A, B は異なる点であるから $\beta - \alpha \neq 0$ である。
$\textcircled{1}$ の両辺を $(\beta - \alpha)^2$ で割ると：
$$\left(\frac{\gamma - \alpha}{\beta - \alpha}\right)^2 + \frac{\gamma - \alpha}{\beta - \alpha} + 1 = 0$$
これは 1 の虚数立方根 $\omega$ の満たす方程式 $z^2 + z + 1 = 0$ である。
解の公式より：
$$\frac{\gamma - \alpha}{\beta - \alpha} = \frac{-1 \pm \sqrt{3}i}{2}$$
問題文の形式 $\frac{-\text{M} \pm \sqrt{\text{N}}i}{\text{O}}$ と比較して：
$$\mathbf{M = 1, N = 3, O = 2} \implies \mathbf{MNO = 132}$$

この複素数の絶対値と偏角を求める：
$$\left|\frac{\gamma - \alpha}{\beta - \alpha}\right| = \sqrt{\left(-\frac{1}{2}\right)^2 + \left(\pm\frac{\sqrt{3}}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{3}{4}} = 1$$
したがって、$\mathbf{P = 1}$（$AC = AB$ を意味する）。

偏角は：
$$\arg\frac{\gamma - \alpha}{\beta - \alpha} = \pm \frac{2}{3}\pi$$
形式 $\pm \frac{\text{Q}}{\text{R}}\pi$ より：
$$\mathbf{Q = 2, R = 3} \implies \mathbf{QR = 23}$$
（これは、点 C が点 A を中心として点 B を $\pm 120^\circ$ 回転した点であることを意味する。）

#### (2) 線分長 $|\beta - \alpha|$ の決定
$\beta - 2\alpha + \gamma$ を $(\beta - \alpha)$ でくくる：
$$\beta - 2\alpha + \gamma = (\beta - \alpha) + (\gamma - \alpha) = (\beta - \alpha) \left(1 + \frac{\gamma - \alpha}{\beta - \alpha}\right)$$
ここで、
$$1 + \frac{-1 \pm \sqrt{3}i}{2} = \frac{2 - 1 \pm \sqrt{3}i}{2} = \frac{1 \pm \sqrt{3}i}{2}$$
問題文の形式 $(\beta - \alpha) \cdot \frac{\text{S} \pm \sqrt{\text{T}}i}{\text{U}}$ と比較して：
$$\mathbf{S = 1, T = 3, U = 2} \implies \mathbf{STU = 132}$$

$\textcircled{2}$ より $|\beta - 2\alpha + \gamma| = 3$ であるから：
$$\left|(\beta - \alpha) \cdot \frac{1 \pm \sqrt{3}i}{2}\right| = 3$$
$$\left|\frac{1 \pm \sqrt{3}i}{2}\right| = \sqrt{\frac{1}{4} + \frac{3}{4}} = 1$$
したがって：
$$|\beta - \alpha| \times 1 = 3 \implies |\beta - \alpha| = 3$$
よって、$\mathbf{V = 3}$。

#### (3) 三角形 ABC の面積
$\triangle ABC$ において：
- $AB = |\beta - \alpha| = 3$
- $AC = |\gamma - \alpha| = |\beta - \alpha| = 3$
- 頂角 $\angle BAC = \left|\arg\frac{\gamma - \alpha}{\beta - \alpha}\right| = \frac{2}{3}\pi = 120^\circ$
したがって、三角形 ABC の面積は：
$$\text{Area} = \frac{1}{2} AB \cdot AC \sin 120^\circ = \frac{1}{2} \times 3 \times 3 \times \frac{\sqrt{3}}{2} = \frac{9\sqrt{3}}{4}$$
形式 $\frac{\text{W}\sqrt{\text{X}}}{\text{Y}}$ より：
$$\mathbf{W = 9, X = 3, Y = 4} \implies \mathbf{WXY = 934}$$

## 第III問（前半）：単位円上の動点と線分長・3倍角の公式と微分の極値

**【考査考点】**：動点 P, Q の座標表示と線分長 $\ell = |\cos 3\theta - \cos\theta|$, 3倍角の公式 $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$, 変数変換 $t = \cos\theta$ と微分による増減・極値・最大値 $\frac{8\sqrt{3}}{9}$ の決定

### 【第III問（前半）】詳細解答と解説

単位円 $C$ 上の動点 P$(\cos\theta, \sin\theta)$、Q$(\cos 3\theta, \sin 3\theta)$（$0 \le \theta \le \pi$）がある。
点 P, Q から $x$ 軸に下ろした垂線の足をそれぞれ A$(\cos\theta, 0)$、B$(\cos 3\theta, 0)$ とすると、線分 AB の長さは：
$$\ell = |\cos 3\theta - \cos\theta|$$

#### (1) $\theta = \frac{\pi}{3}$ のときの $\ell$
$$\cos\theta = \cos\frac{\pi}{3} = \frac{1}{2}, \quad \cos 3\theta = \cos\pi = -1$$
$$\ell = \left|-1 - \frac{1}{2}\right| = \left|-\frac{3}{2}\right| = \frac{3}{2}$$
形式 $\frac{\text{A}}{\text{B}}$ より：
$$\mathbf{A = 3, B = 2} \implies \mathbf{AB = 32}$$

#### (2) 3倍角の公式による関数化と微分の導出
3倍角の公式 $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$ を用いる。
$\cos\theta = t$ とおくと（$0 \le \theta \le \pi$ より $-1 \le t \le 1$）：
$$\cos 3\theta - \cos\theta = (4t^3 - 3t) - t = 4t^3 - 4t$$
したがって、$\ell = |4t^3 - 4t|$ である。
問題文の形式 $\ell = |\text{C}t^{\text{D}} - \text{E}t|$ と比較して：
$$\mathbf{C = 4, D = 3, E = 4} \implies \mathbf{CDE = 434}$$

$g(t) = 4t^3 - 4t$ とおき、$t$ で微分する：
$$g'(t) = 12t^2 - 4 = 4(3t^2 - 1)$$
問題文の形式 $g'(t) = \text{F}(\text{G}t^{\text{H}} - 1)$ と比較して：
$$\mathbf{F = 4, G = 3, H = 2} \implies \mathbf{FGH = 432}$$

#### (3) 最大値の決定
$g'(t) = 0 \iff 3t^2 - 1 = 0 \iff t = \pm \frac{1}{\sqrt{3}} = \pm \frac{\sqrt{3}}{3}$ である。
形式 $\cos\theta = \pm \frac{\sqrt{\text{I}}}{\text{J}}$ より：
$$\mathbf{I = 3, J = 3} \implies \mathbf{IJ = 33}$$

$g(t)$ の増減および絶対値の評価：
- $t = \frac{1}{\sqrt{3}}$ のとき：
  $$g\left(\frac{1}{\sqrt{3}}\right) = 4\left(\frac{1}{3\sqrt{3}}\right) - 4\left(\frac{1}{\sqrt{3}}\right) = -\frac{8}{3\sqrt{3}} = -\frac{8\sqrt{3}}{9}$$
  $$\ell = |g(t)| = \frac{8\sqrt{3}}{9}$$
- $t = -\frac{1}{\sqrt{3}}$ のとき：
  $$g\left(-\frac{1}{\sqrt{3}}\right) = \frac{8\sqrt{3}}{9} \implies \ell = \frac{8\sqrt{3}}{9}$$
- 端点 $t = \pm 1$ では $g(\pm 1) = 0$。
したがって、$\ell$ の最大値は $\frac{8\sqrt{3}}{9}$ である。
形式 $\frac{\text{K}\sqrt{\text{L}}}{\text{M}}$ より：
$$\mathbf{K = 8, L = 3, M = 9} \implies \mathbf{KLM = 839}$$

## 第III問（後半）：$\ell$ が最大となる点 P, Q の座標決定

**【考査考点】**：三角関数の相互関係 $\sin\theta = \sqrt{1 - \cos^2\theta}$, 3倍角の公式 $\sin 3\theta = 3\sin\theta - 4\sin^3\theta$, 動点 P, Q の具体的な座標計算と選択肢の同定

### 【第III問（後半）】詳細解答と解説

$\ell$ が最大値をとる点 P, Q の座標（2組）を求める。

#### (1) 組 1：$t = \cos\theta = +\frac{\sqrt{3}}{3}$ のとき
$0 \le \theta \le \pi$ より $\sin\theta \ge 0$ であるから：
$$\sin\theta = \sqrt{1 - \cos^2\theta} = \sqrt{1 - \frac{1}{3}} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}$$
選択肢の表より、$\textcircled{0}$ は $\frac{\sqrt{6}}{3}$ である。
したがって、点 P の座標は $P\left(\frac{\sqrt{3}}{3}, \text{N}\right)$ より：
$$\mathbf{N = 0}$$

次に点 Q$(\cos 3\theta, \sin 3\theta)$ の座標を求める：
- $x_Q = \cos 3\theta = 4t^3 - 3t = 4\left(\frac{\sqrt{3}}{9}\right) - 3\left(\frac{\sqrt{3}}{3}\right) = \frac{4\sqrt{3} - 9\sqrt{3}}{9} = -\frac{5\sqrt{3}}{9}$。
  選択肢 $\textcircled{5}$ は $-\frac{5\sqrt{3}}{9}$ である。$\implies \mathbf{O = 5}$。
- $y_Q = \sin 3\theta = 3\sin\theta - 4\sin^3\theta = \sin\theta(3 - 4\sin^2\theta)$。
  $$y_Q = \frac{\sqrt{6}}{3} \left(3 - 4 \times \frac{2}{3}\right) = \frac{\sqrt{6}}{3} \left(3 - \frac{8}{3}\right) = \frac{\sqrt{6}}{3} \times \frac{1}{3} = \frac{\sqrt{6}}{9}$$
  選択肢 $\textcircled{6}$ は $\frac{\sqrt{6}}{9}$ である。$\implies \mathbf{P = 6}$。
したがって、$\mathbf{OP = 56}$。

#### (2) 組 2：$t = \cos\theta = -\frac{\sqrt{3}}{3}$ のとき
同様に $\sin\theta = \sqrt{1 - \frac{1}{3}} = \frac{\sqrt{6}}{3}$（選択肢 $\textcircled{0}$）であるから：
$$P\left(-\frac{\sqrt{3}}{3}, \text{Q}\right) \implies \mathbf{Q = 0}$$

点 Q の座標：
- $x_Q = \cos 3\theta = 4\left(-\frac{\sqrt{3}}{9}\right) - 3\left(-\frac{\sqrt{3}}{3}\right) = \frac{5\sqrt{3}}{9}$。
  選択肢 $\textcircled{4}$ は $\frac{5\sqrt{3}}{9}$ である。$\implies \mathbf{R = 4}$。
- $y_Q = \sin 3\theta = \frac{\sqrt{6}}{9}$。
  選択肢 $\textcircled{6}$ は $\frac{\sqrt{6}}{9}$ である。$\implies \mathbf{S = 6}$。
したがって、$\mathbf{RS = 46}$。

## 第IV問（前半）：対数不等式 $x-1 \ge \log x$ の証明と囲まれた面積 $S$ の定積分

**【考査考点】**：関数 $f(x) = x - 1 - \log x$ の導関数 $f'(x) = 1 - 1/x$ と最小値 0, 基本不等式 $x - 1 \ge \log x$ による上下関係の決定, 部分積分法による $\int \log x \, dx = x(\log x - 1)$, 区間 $[n, n+1]$ における定積分の展開計算

### 【第IV問（前半）】詳細解答と解説

#### (1) $f(x) = x - 1 - \log x$ の導関数と最小値
定義域は $x > 0$ である。
導関数は：
$$f'(x) = 1 - \frac{1}{x}$$
問題文の形式 $f'(x) = \text{A} - \frac{\text{B}}{x}$ より：
$$\mathbf{A = 1, B = 1} \implies \mathbf{AB = 11}$$

増減を調べると：
- $0 < x < 1$ で $f'(x) < 0$（単調減少）
- $x = 1$ で $f'(1) = 0$
- $x > 1$ で $f'(x) > 0$（単調増加）
したがって、$f(x)$ は $x = 1$ において最小値をとる：
$$f(1) = 1 - 1 - \log 1 = 0$$
したがって、$x = C$ において最小値 $D$ より：
$$\mathbf{C = 1, D = 0}$$
最小値が 0 であることから、すべての $x > 0$ で $f(x) \ge 0 \iff x - 1 \ge \log x$ が成立する。

#### (2) 面積 $S$ の定積分表示と展開計算
$u = \frac{x}{k}$ とおくと、(1) の不等式より $\frac{x}{k} - 1 \ge \log\frac{x}{k}$ が成立する。
したがって、区間 $[n, n+1]$ において直線 $y = \frac{x}{k} - 1$ は常に曲線 $y = \log\frac{x}{k}$ の上側にある。
囲まれた図形の面積 $S$ は：
$$S = \int_n^{n+1} \left(\frac{x}{k} - 1 - \log\frac{x}{k}\right) dx = \int_n^{n+1} \left(\frac{x}{k} - 1 - \log x + \log k\right) dx$$

不定積分を求める：
- $\int \frac{x}{k} dx = \frac{x^2}{2k}$（形式 $\frac{x^{\text{E}}}{\text{F}k}$ より $\mathbf{E = 2, F = 2} \implies \mathbf{EF = 22}$）
- $\int (1 + \log x) dx$ を考えると、$\int \log x \, dx = x\log x - x = x(\log x - 1)$ である。
  選択肢 $\textcircled{1}$ は $x(\log x - 1)$ である。
  これを用いると：
  $$-x - x(\log x - 1) = -x - x\log x + x = -x\log x$$
  となり、$-\int (1 + \log x)dx = -x - \text{G}$ の形式と一致する。
  よって、$\mathbf{G = 1}$。

端点 $x = n+1, n$ を代入して展開する：
$$S = \left[\frac{x^2}{2k} - x\log x + x\log k\right]_n^{n+1}$$
1. $\frac{x^2}{2k}$ の項：
   $$\frac{(n+1)^2 - n^2}{2k} = \frac{2n + 1}{2k}$$
2. $x\log k$ の項：
   $$(n+1)\log k - n\log k = \log k$$
3. $-x\log x$ の項：
   $$-(n+1)\log(n+1) + n\log n$$
これらを合わせると：
$$S = \frac{2n + 1}{2k} + \log k - (n + 1)\log(n + 1) + n\log n$$
問題文の形式 $\frac{\text{H}n + 1}{\text{I}k} + \log k - (n + \text{J})\log(n + \text{K}) + n\log n$ と比較して：
$$\mathbf{H = 2, I = 2, J = 1, K = 1} \implies \mathbf{HIJK = 2211}$$

## 第IV問（後半）：面積 $S$ の最小値 $a_n$ と極限値 $\lim_{n\to\infty} a_n$

**【考査考点】**：$k$ に関する微分 $\frac{dS}{dk} = \frac{2k - (2n+1)}{2k^2}$, 極小・最小点 $k = n + 1/2$ の導出, 最小値 $a_n$ の対数変形と自然対数の底 $e$ の定義による極限計算

### 【第IV問（後半）】詳細解答と解説

#### (1) $S$ の $k$ による微分と最小点
$S = \frac{2n + 1}{2k} + \log k - (n + 1)\log(n + 1) + n\log n$ を $k$ で微分する：
$$\frac{dS}{dk} = -\frac{2n + 1}{2k^2} + \frac{1}{k} = \frac{2k - (2n + 1)}{2k^2}$$
問題文の形式 $\frac{\text{L}k - (\text{M}n + 1)}{\text{N}k^2}$ と比較して：
$$\mathbf{L = 2, M = 2, N = 2} \implies \mathbf{LMN = 222}$$

$\frac{dS}{dk} = 0$ とおくと：
$$2k - (2n + 1) = 0 \implies 2k = 2n + 1 \implies k = n + \frac{1}{2}$$
増減表より、$k = n + \frac{1}{2}$ で $S$ は極小かつ最小となる。
形式 $k = n + \frac{\text{O}}{\text{P}}$ より：
$$\mathbf{O = 1, P = 2} \implies \mathbf{OP = 12}$$

#### (2) 最小値 $a_n$ の対数表示
$k = n + \frac{1}{2} = \frac{2n+1}{2}$ を $S$ に代入する：
$$\frac{2n+1}{2k} = \frac{2n+1}{2 \cdot \frac{2n+1}{2}} = 1$$
したがって：
$$a_n = 1 + \log\left(\frac{2n+1}{2}\right) - (n+1)\log(n+1) + n\log n$$
対数部分を整理する：
$$-(n+1)\log(n+1) + n\log n = -\log\left((n+1)^{n+1}\right) + \log(n^n) = -\log\left(\frac{(n+1)^n (n+1)}{n^n}\right) = -\log\left(\left(1 + \frac{1}{n}\right)^n (n+1)\right)$$
これに $\log\left(\frac{2n+1}{2}\right)$ を加えると：
$$\log\left(\frac{2n+1}{2}\right) - \log\left(\left(1 + \frac{1}{n}\right)^n (n+1)\right) = -\left[\log\left(\left(1 + \frac{1}{n}\right)^n (n+1)\right) - \log\left(\frac{2n+1}{2}\right)\right]$$
$$= -\log\left\{ \left(1 + \frac{1}{n}\right)^n \cdot \frac{n+1}{\frac{2n+1}{2}} \right\} = -\log\left\{ \left(1 + \frac{1}{n}\right)^n \cdot \frac{2n+2}{2n+1} \right\}$$
したがって：
$$a_n = 1 - \log\left\{ \left(1 + \frac{1}{n}\right)^n \cdot \frac{2n+2}{2n+1} \right\}$$
問題文の形式 $a_n = \text{Q} - \log\left\{ \left(\text{R} + \frac{\text{S}}{n}\right)^n \cdot \frac{\text{T}n + \text{U}}{\text{V}n + 1} \right\}$ と比較して：
$$\mathbf{Q = 1, R = 1, S = 1, T = 2, U = 2, V = 2} \implies \mathbf{QRSTUV = 111222}$$

#### (3) 極限値 $\lim_{n \to \infty} a_n$ の計算
$n \to \infty$ のとき：
- 自然対数の底 $e$ の定義より：
  $$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$
- 分数式の極限：
  $$\lim_{n \to \infty} \frac{2n+2}{2n+1} = \lim_{n \to \infty} \frac{2 + 2/n}{2 + 1/n} = 1$$
したがって、対数の中身の極限は：
$$\lim_{n \to \infty} \left\{ \left(1 + \frac{1}{n}\right)^n \cdot \frac{2n+2}{2n+1} \right\} = e \times 1 = e$$
これより：
$$\lim_{n \to \infty} a_n = 1 - \log(e) = 1 - 1 = 0$$
したがって、$\mathbf{W = 0}$。
