## 生物 問1：細胞膜の構造・機能と物質輸送（エンドサイトーシスとエキソサイトーシス）

**問題コード**: `bio-q-01` | **正解参照**: `BIOLOGY:1` | **正解**: `3`

### 出題のポイント
- 生体膜（脂質二重層）の透過性（疎水性分子は通過しやすく、親水性高分子・イオンは通過しにくい）
- 膜貫通タンパク質の役割（イオンチャネル、受容体、ナトリウムポンプなど）
- エンドサイトーシス（食作用・飲作用による細胞内取り込み）とエキソサイトーシス（小胞分泌による細胞外放出）の定義と相違

### 詳細解説
**【題目大意】**
細胞膜（生体膜）の構造と機能に関する記述 $\textcircled{1}$～$\textcircled{4}$ のうち、**誤っているもの**を1つ選択する。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
各選択肢の生体膜に関する記述を詳細に吟味する：

- $\textcircled{1}$ **正しい**：細胞膜の基本骨格はリン脂質二重層であり、その内部は疎水性（非極性）である。したがって、親水性（極性）のアミノ酸や糖、荷電したイオンなどの水溶性分子は、膜を直接拡散・透過することが極めて困難である。
- $\textcircled{2}$ **正しい**：細胞膜を貫通する膜タンパク質には、濃度勾配に従って特定のイオンを受動輸送する「イオンチャネル」や、ATPのエネルギーを利用して $\text{Na}^+$ を排出し $\text{K}^+$ を取り込む能動輸送を行う「ナトリウムポンプ（$\text{Na}^+/\text{K}^+$ -ATPアーゼ）」などがある。
- $\textcircled{3}$ **誤り**：タンパク質などの高分子や異物粒子など、膜を直接通過できない巨大物質を小胞を形成して細胞内に取り込む現象は**エンドサイトーシス（endocytosis；食作用・飲作用）**と呼ばれる。これに対し、細胞内で合成・凝縮された分泌小胞が細胞膜と融合し、内容物を細胞外へ放出する現象が**エキソサイトーシス（exocytosis；外分泌）**である。記述では細胞内への取り込みを「エキソサイトーシス」としており、定義が逆で誤りである。
- $\textcircled{4}$ **正しい**：細胞膜表面には、ホルモンや神経伝達物質などの細胞外シグナル分子を受容・結合し、細胞内へ情報を伝える受容体タンパク質（レセプター）や、細胞同士の接着・認識を担う糖タンパク質が存在する。

誤っているものは $\textcircled{3}$ である。

**【考査考点】**
- リン脂質二重層の物理化学的性質（親水性頭部と疎水性尾部）と選択的透過性。
- 膜タンパク質の機能分類（チャネル、トランスポーター、ポンプ、受容体）。
- 小胞輸送（エンドサイトーシスとエキソサイトーシス）の機構と方向性の識別。

## 生物 問2：アミノ酸の脱水縮合とトリペプチドの化学構造

**問題コード**: `bio-q-02` | **正解参照**: `BIOLOGY:2` | **正解**: `5`

### 出題のポイント
- アミノ酸の基本構造（アミノ基 $-\text{NH}_2$、カルボキシ基 $-\text{COOH}$、側鎖 $\text{R}$）
- ペプチド結合（$-\text{CO}-\text{NH}-$）の形成反応（脱水縮合）
- 3つのアミノ酸が結合したトリペプチド鎖の化学骨格の同定

### 詳細解説
**【題目大意】**
側鎖 $\text{R}_1, \text{R}_2, \text{R}_3$ をもつ3種類のアミノ酸が脱水縮合してペプチド結合（peptide bond）を形成したトリペプチドの構造として正しいものを選択する。

**【公式正解】**
正解：$\textcircled{5}$

**【詳細推導・解答プロセス】**
**(1) アミノ酸の構造とペプチド結合の形成機構**
一般のアミノ酸は、同一の炭素原子（$\alpha$ 炭素）にアミノ基（$-\text{NH}_2$）、カルボキシ基（$-\text{COOH}$）、水素原子（$-\text{H}$）、および特異的な側鎖（$-\text{R}$）が結合した構造をもつ：
$$\text{H}_2\text{N}-\text{CH}(\text{R})-\text{COOH}$$

2つのアミノ酸が結合する際、一方のアミノ酸のカルボキシ基（$-\text{COOH}$）と、他方のアミノ酸のアミノ基（$-\text{NH}_2$）との間から1分子の水 $\text{H}_2\text{O}$ が脱離し（脱水縮合）、酸アミド結合である**ペプチド結合**（$-\text{CO}-\text{NH}-$）が形成される：
$$\text{H}_2\text{N}-\text{CH}(\text{R}_1)-\text{COOH} + \text{H}_2\text{N}-\text{CH}(\text{R}_2)-\text{COOH} \longrightarrow \text{H}_2\text{N}-\text{CH}(\text{R}_1)-\text{CO}-\text{NH}-\text{CH}(\text{R}_2)-\text{COOH} + \text{H}_2\text{O}$$

**(2) 3つのアミノ酸からなるトリペプチド鎖の骨格**
3種類のアミノ酸が順に結合する場合、2カ所のペプチド結合が形成される。その主鎖骨格は N末端から C末端に向かって次のようになる：
$$\text{H}_2\text{N}-\text{CH}(\text{R}_1)-\text{CO}-\text{NH}-\text{CH}(\text{R}_2)-\text{CO}-\text{NH}-\text{CH}(\text{R}_3)-\text{COOH}$$
各 $\alpha$ 炭素には、それぞれ側鎖 $\text{R}_1, \text{R}_2, \text{R}_3$ と水素原子 $-\text{H}$ が結合しており、主鎖は $-\text{N}-\text{C}-\text{C}-\text{N}-\text{C}-\text{C}-\text{N}-\text{C}-\text{C}-$ の繰り返し配列をとる。

選択肢のうち、2つのペプチド結合 $-\text{CO}-\text{NH}-$ が正しく形成され、側鎖 $\text{R}_1, \text{R}_2, \text{R}_3$ がそれぞれの $\alpha$ 炭素に正しく配置されている構造は $\textcircled{5}$ である。

**【考査考点】**
- タンパク質の一次構造の基本単位であるペプチド結合の化学構造。
- アミノ酸の脱水縮合反応における反応部位（アミノ基とカルボキシ基）の特異性。

## 生物 問3：呼吸の反応過程（解糖系とクエン酸回路の反応部位）

**問題コード**: `bio-q-03` | **正解参照**: `BIOLOGY:3` | **正解**: `5`

### 出題のポイント
- 好気呼吸の3段階（解糖系、クエン酸回路、電子伝達系）の反応場所の識別
- 解糖系：細胞質基質におけるグルコースからピルビン酸への分解
- クエン酸回路：ミトコンドリアのマトリックスにおけるピルビン酸の完全酸化と補酵素の還元

### 詳細解説
**【題目大意】**
細胞呼吸（好気呼吸）に関する説明文の下線部A～Fのうち誤っているもの1カ所と、その正しい修正語句の組み合わせを選択する。

**【公式正解】**
正解：$\textcircled{5}$ （E → マトリックス）

**【詳細推導・解答プロセス】**
好気呼吸の主要段階と生起場所を整理する：

1. **解糖系（glycolysis）**：
   - 反応場所：**細胞質基質**（C）
   - 反応：1分子の**グルコース**（$\text{C}_6\text{H}_{12}\text{O}_6$、A）が分解され、2分子の**ピルビン酸**（$\text{C}_3\text{H}_4\text{O}_3$、B）と $2\text{NADH}$、$2\text{ATP}$ が生じる。下線部A、B、Cはすべて正しい。
2. **クエン酸回路（citric acid cycle）**：
   - 反応場所：ミトコンドリアの**マトリックス（matrix）**（内膜に囲まれた基質部分）
   - ピルビン酸がマトリックスへ輸送され、アセチルCoAを経てオキサロ酢酸と結合してクエン酸となり、一連の脱炭酸酵素や脱水素酵素の働きによって二酸化炭素（$\text{CO}_2$、F）と多量の還元型補酵素（$\text{NADH}, \text{FADH}_2$）を生じる。
   - 文中の下線部Eでは「外膜（outer membrane）」とされているが、外膜ではなく**マトリックス**で行われるため、下線部Eが誤りである。
   - （※なお、ミトコンドリア内膜はクリステを形成し、電子伝達系およびATP合成酵素が局在する）。

したがって、誤っている下線部と修正語句の組み合わせは「E → マトリックス（matrix）」であり、正解は $\textcircled{5}$ である。

**【考査考点】**
- 呼吸の各反応段階（解糖系・クエン酸回路・電子伝達系）における生化学反応と細胞内局在。
- ミトコンドリアの微細構造（外膜、内膜・クリステ、膜間腔、マトリックス）と機能分担。

## 生物 問4：メセルソンとスタールの実験（DNAの半保存的複製）

**問題コード**: `bio-q-04` | **正解参照**: `BIOLOGY:4` | **正解**: `2`

### 出題のポイント
- 半保存的複製（semiconservative replication）の機構
- 重窒素 $^{15}\text{N}$ と軽窒素 $^{14}\text{N}$ によるDNA分子密度の分別
- 3世代（3回分裂）後における3種のDNA分子（重・中・軽）の存在比率の数学的計算

### 詳細解説
**【題目大意】**
全窒素が $^{15}\text{N}$ である大腸菌（0世代）を $^{14}\text{N}$ 培地に移して3世代増殖させたとき、生じた大腸菌DNAの分子種（$^{15}\text{N}$ のみを含む「重いDNA」、$^{15}\text{N}$ と $^{14}\text{N}$ のハイブリッド「中間のDNA」、$^{14}\text{N}$ のみを含む「軽いDNA」）の比率を求める。

**【公式正解】**
正解：$\textcircled{2}$ （$0 : 1 : 3$）

**【詳細推導・解答プロセス】**
DNAの複製は**半保存的複製**である。2本鎖DNAがほどけ、それぞれの1本鎖が鋳型（template）となり、培地中のヌクレオチド（ここでは $^{14}\text{N}$）を用いて新たな相補鎖が合成される。

初期状態（0世代）の $^{15}\text{N}$ 鎖を $\text{H}$（Heavy）、培地から供給される $^{14}\text{N}$ 鎖を $\text{L}$（Light）と表す。

- **0世代（初期）**：
  - DNA分子数：$1$ 分子
  - 鎖の構成：$\text{H}-\text{H}$（重いDNA）が $1$ 分子
  - 重 : 中 : 軽 $= 1 : 0 : 0$

- **1世代（1回分裂後）**：
  - DNA分子数：$2^1 = 2$ 分子
  - 鎖の構成：2本の $\text{H}$ 鎖が鋳型となり、新たに $\text{L}$ 鎖が合成されるため、$\text{H}-\text{L}$（中間のDNA）が $2$ 分子。
  - 重 : 中 : 軽 $= 0 : 2 : 0 = 0 : 1 : 0$

- **2世代（2回分裂後）**：
  - DNA分子数：$2^2 = 4$ 分子
  - 鋳型鎖は $\text{H}$ 鎖が $2$ 本、$\text{L}$ 鎖が $2$ 本。
  - 合成される分子：$\text{H}-\text{L}$ が $2$ 分子、$\text{L}-\text{L}$（軽いDNA）が $2$ 分子。
  - 重 : 中 : 軽 $= 0 : 2 : 2 = 0 : 1 : 1$

- **3世代（3回分裂後）**：
  - DNA分子数：$2^3 = 8$ 分子
  - 2世代の4分子に含まれる8本の鎖の内訳は、$\text{H}$ 鎖が最初からの $2$ 本、$\text{L}$ 鎖が $6$ 本である。
  - 新たにすべて $\text{L}$ 鎖が対合して合成されるため：
    - $\text{H}-\text{H}$（$^{15}\text{N}$ のみ・重）：$0$ 分子
    - $\text{H}-\text{L}$（$^{15}\text{N}$ と $^{14}\text{N}$・中間）：$2$ 分子
    - $\text{L}-\text{L}$（$^{14}\text{N}$ のみ・軽）：$8 - 2 = 6$ 分子
  - 比率は：
    $$\text{重} : \text{中間} : \text{軽} = 0 : 2 : 6 = 0 : 1 : 3$$

したがって、正解は $\textcircled{2}$ である。

**【考査考点】**
- メセルソンとスタールによる密度勾配遠心法と半保存的複製の証明原理。
- 各世代における鋳型鎖の保存則と二本鎖DNA分子構成比の定量的追跡。

## 生物 問5：真核生物の転写・スプライシング・翻訳の基本機構

**問題コード**: `bio-q-05` | **正解参照**: `BIOLOGY:5` | **正解**: `3`

### 出題のポイント
- 転写の開始（プロモーターへのRNAポリメラーゼの結合）
- 真核生物の遺伝子構造（エキソンとイントロン）
- スプライシングによるmRNA成熟過程の定義

### 詳細解説
**【題目大意】**
真核生物における遺伝情報の転写（transcription）および翻訳（translation）に関する記述 $\textcircled{1}$～$\textcircled{4}$ のうち、**正しいもの**を1つ選択する。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
各選択肢を精査する：

- $\textcircled{1}$ 誤り：転写が開始される際、プロモーター領域に結合してRNA合成を行う酵素は **RNAポリメラーゼ（RNA polymerase）** である。文中の「DNAポリメラーゼ」はDNA複製を行う酵素であるため誤り。
- $\textcircled{2}$ 誤り：真核生物の遺伝子において、最終的にタンパク質のアミノ酸配列として翻訳される情報を担う部分を**エキソン（exon）**といい、翻訳されない介在配列を**イントロン（intron）**という。選択肢は翻訳されない配列をエキソンとしており定義が逆である。
- $\textcircled{3}$ **正しい**：真核生物では、DNAから転写されて生じた前駆体RNA（pre-mRNA）から、タンパク質に翻訳されないイントロン配列が切り出され、必要なエキソン配列同士が連結される。この過程を**スプライシング（splicing）**と呼び、スプライシングや $5'$ キャップ構造の付加、ポリA尾部の付加を受けた後の完成したRNAが成熟 **mRNA** として核外へ輸送される。記述は完全に正しい。
- $\textcircled{4}$ 誤り：翻訳の開始は、mRNAの開始コドン（$\text{AUG}$）付近にリボソーム小サブユニットが結合し、そこにメチオニンを結合した開始tRNA（Met-tRNA）が結合した後に大サブユニットが会合することで起こる。「リボソームとtRNAの結合で始まる」という記述は不適当である。

したがって、正しい記述は $\textcircled{3}$ である。

**【考査考点】**
- セントラルドグマ（DNA $\to$ RNA $\to$ タンパク質）の各ステップの分子機構。
- 真核生物特有の転写後修飾（mRNA前駆体のスプライシング、エキソンとイントロンの区別）。

## 生物 問6(1)：減数分裂における相同染色体の対合と染色体数

**問題コード**: `bio-q-06` | **正解参照**: `BIOLOGY:6` | **正解**: `3`

### 出題のポイント
- 二価染色体（tetrad/bivalent）の構造と相同染色体対合の観察
- 二価染色体数 $n$ と体細胞の染色体数 $2n$ の関係
- 図の観察に基づく染色体数 $2n=8$ の決定

### 詳細解説
**【題目大意】**
減数分裂中の細胞を示す模式図（図1）から、この生物の体細胞染色体数 $2n = a$ の空欄 $a$ に入る数値を求める。

**【公式正解】**
正解：$\textcircled{3}$ （$a = 8$）

**【詳細推導・解答プロセス】**
**(1) 図1の細胞の分裂段階と構造**
- 図1では、相同染色体同士が密接に対合してできた**二価染色体（二重染色体；bivalent）**が赤道面に整列している様子が描かれている。
- これは**減数第一分裂中期（metaphase I）**の特徴である。

**(2) 染色体数の算定**
- 1つの二価染色体は、父方由来と母方由来の相同染色体 $2$ 本が対合した構造である。
- 図1を観察すると、対合した二価染色体が **4組** 描かれている（$n = 4$）。
- したがって、この生物の半数体染色体数（ゲノム）は $n = 4$ であり、体細胞における二倍体の染色体数は：
$$2n = 2 \times 4 = 8$$
となる。
よって、空欄 $a$ に入る数値は **8** である。

正解は $\textcircled{3}$ である。

**【考査考点】**
- 減数第一分裂における相同染色体の対合と二価染色体の形成機構。
- 核相（$n$ と $2n$）の定義と染色体数の観察・同定能力。

## 生物 問6(2)：減数分裂の進行過程と細胞あたりDNA量の周期的推移

**問題コード**: `bio-q-07` | **正解参照**: `BIOLOGY:7` | **正解**: `2`

### 出題のポイント
- 減数分裂に伴うDNA複製と2回の連続分裂におけるDNA量の変動
- 第一分裂前〜中期のDNA量（DNA量 $= 4$、時期B）の同定
- 減数第一分裂（$4 \to 2$）および第二分裂（$2 \to 1$）の推移の理解

### 詳細解説
**【題目大意】**
図1で示された減数第一分裂中期の細胞が、細胞あたりの相対DNA量の変化グラフ（図2）中のどの時期（A～D）に該当するかを同定する。

**【公式正解】**
正解：$\textcircled{2}$ （時期 B）

**【詳細推導・解答プロセス】**
減数分裂におけるDNA量（相対値）の変化過程を各時期ごとに整理する：

1. **G1期（分裂準備期前）**：体細胞の基準DNA量を $2$ とする。
2. **S期（DNA合成期；グラフの時期A）**：間期においてDNAが複製され、DNA量は $2 \to 4$ に倍増する。
3. **減数第一分裂（前期・中期・後期；グラフの時期B）**：
   - DNAの複製が完了し、細胞あたりのDNA量は最大値の **4** に達している。
   - この時期に相同染色体が対合して二価染色体を形成し、赤道面に整列する（図1の中期の状態）。したがって、図1の細胞はこの**時期B**に存在する。
4. **第一分裂完了から第二分裂（時期C）**：
   - 相同染色体が両極へ分離し、2個の細胞に分かれるため、細胞あたりのDNA量は $4 \to 2$ に半減する。
5. **第二分裂完了（時期D）**：
   - 姉妹染色分体が分離して娘細胞に配分されるため、DNA量はさらに $2 \to 1$ に半減し、生殖細胞（配偶子）が完成する。

図1の二価染色体が観察される細胞は減数第一分裂中期の細胞であるため、DNA量が 4 である**時期B**に該当する。
したがって、正解は $\textcircled{2}$ である。

**【考査考点】**
- 減数分裂の各ステージ（第一分裂と第二分裂）における染色体の動態。
- DNA合成期（S期）および2回の細胞質分裂に伴う細胞あたりDNA量の定量的推移。

## 生物 問7：被子植物の花粉形成過程と減数分裂産物（花粉四分子）

**問題コード**: `bio-q-08` | **正解参照**: `BIOLOGY:8` | **正解**: `1`

### 出題のポイント
- 葯（やく）の中の花粉母細胞（$2n$）の減数分裂
- 減数分裂直後に生じる4つの娘細胞の集合体（花粉四分子, $n$）
- その後の花粉粒形成過程（体細胞分裂による花粉管細胞と雄原細胞の分化）

### 詳細解説
**【題目大意】**
被子植物のおしべの葯における花粉形成過程において、減数分裂の最後に生じる細胞として最も適当なものを選択する。

**【公式正解】**
正解：$\textcircled{1}$ （花粉四分子）

**【詳細推導・解答プロセス】**
被子植物の花粉形成（雄性配偶子形成）の全ステップを順を追って確認する：

1. **花粉母細胞（pollen mother cell, $2n$）**：
   - 葯内の花粉嚢で分化し、減数分裂を開始する。
2. **減数分裂の完了と花粉四分子（pollen tetrad, $n$）の形成**：
   - 1個の花粉母細胞（$2n$）が減数第一分裂および第二分裂を行うことで、半数体（$n$）の4個の小胞子（microspore）が生じる。これら4個の細胞が互いに接着した状態を**花粉四分子**（花粉四分子）と呼ぶ。減数分裂の最後にできる直接の産物はこれである。
3. **花粉四分子の分離と花粉粒の成熟**：
   - 花粉四分子は互いに離れて1個ずつの花粉（小胞子）となり、外壁（エキシンなど）が発達する。
   - 各細胞が不均等な体細胞分裂を1回行い、大型の**花粉管細胞（栄養細胞）**と、小型の**雄原細胞（生殖細胞）**からなる成熟した**花粉粒（pollen grain）**となる。
   - 雄原細胞は花粉管内でさらに体細胞分裂を行い、2個の**精細胞（sperm cells）**を形成する。

設問は「減数分裂の最後にできる細胞」を問うているため、正解は **花粉四分子（$\textcircled{1}$）** である。

**【考査考点】**
- 被子植物の花粉形成と胚嚢形成（重複受精に至る生殖系列の分化経路）。
- 減数分裂の直接産物（花粉四分子・大胞子）と体細胞分裂による配偶子分化の区別。

## 生物 問8：ヒトの腎臓における尿生成機構と浸透圧調節（バソプレシン）

**問題コード**: `bio-q-09` | **正解参照**: `BIOLOGY:9` | **正解**: `3`

### 出題のポイント

- 集合管における水チャネル（アクアポリン）の発現と水分の再吸収促進

### 詳細解説
**【題目大意】**
ヒトの腎臓における尿生成と体液濃度調節に関する記述 $\textcircled{1}$～$\textcircled{4}$ のうち、**正しいもの**を1つ選択する。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
腎臓のネフロン（腎単位）におけるろ過・再吸収およびホルモン調節を吟味する：

- $\textcircled{1}$ 誤り：体液の塩類濃度（浸透圧）が低すぎる（$\text{Na}^+$ 不足など）場合、副腎皮質から**鉱質コルチコイド（アルドステロン）**の分泌が**促進**され、遠位細尿管や集合管における $\text{Na}^+$ の再吸収が促進される。「分泌が抑制されて再吸収量が減る」は逆である。

- $\textcircled{4}$ 誤り：原尿中のグルコースは健康な人では細尿管で $100\%$ 再吸収されるが、尿素は老廃物であり、細尿管で一部（約 $50\%$ 程度）受動的に再吸収されるものの大部分は尿として排出される。「尿素はすべて再吸収される」は明白な誤り。

したがって、正しい記述は $\textcircled{3}$ である。

**【考査考点】**
- 腎臓のネフロン構造（糸球体・ボーマン嚢・細尿管・集合管）とろ過・再吸収の選択性。

## 生物 問9：自然免疫における食細胞（食作用をもつ免疫細胞群）

**問題コード**: `bio-q-10` | **正解参照**: `BIOLOGY:10` | **正解**: `1`

### 出題のポイント
- 食作用（phagocytosis；エンドサイトーシスによる病原体異物の貪食・消化）の機能
- 食細胞の同定：マクロファージ、樹状細胞、好中球の3種
- リンパ球（T細胞、B細胞）の獲得免疫における役割との機能的区別

### 詳細解説
**【題目大意】**
体内に侵入した異物を細胞膜で包み込んで小胞を形成し、リソソーム酵素等で消化・分解する働き（食作用；phagocytosis）をもつ免疫細胞を提示された群（a～f）の中からすべて選択する。

**【公式正解】**
正解：$\textcircled{1}$ （a, b, e）

**【詳細推導・解答プロセス】**
提示された各免疫細胞の主要機能を確認する：

- **a マクロファージ（macrophage）**：代表的な**食細胞**であり、組織に広く分布して侵入した病原体や死細胞を強力に貪食・消化分解し、抗原提示も行う。
- **b 樹状細胞（dendritic cell）**：皮膚や粘膜組織に存在し、活発な**食作用**によって病原体を取り込んで断片化し、所属リンパ節へ移動してヘルパーT細胞へ抗原提示を行う最重要の食細胞・抗原提示細胞である。
- **c キラーT細胞（killer T cell）**：獲得免疫の細胞性免疫を担当するリンパ球であり、ウイルス感染細胞やがん細胞をパーフォリンやグランザイムなどの細胞傷害性分子によりアポトーシスへ導き直接破壊する。食作用は行わない。
- **d ヘルパーT細胞（helper T cell）**：抗原提示を受けて活性化し、インターロイキンなどのサイトカインを放出してB細胞やキラーT細胞、マクロファージを活性化・司令するリンパ球である。食作用は行わない。
- **e 好中球（neutrophil）**：血液中の白血球の約 $50\% \sim 70\%$ を占め、感染初期に毛細血管壁を通り抜けて病巣に真っ先に集積し、病原体を盛んに**食作用**で貪食・殺菌する代表的な食細胞である。
- **f B細胞（B cell）**：獲得免疫において体液性免疫を担当し、抗原受容体（BCR）で特異的抗原を認識し、ヘルパーT細胞の助けを受けて形質細胞へ分化し抗体を産生・放出する。一般的な貪食・殺菌を行う食細胞ではない。

以上より、食作用をもつ免疫細胞は **a（マクロファージ）、b（樹状細胞）、e（好中球）** の3つである。
この組み合わせは $\textcircled{1}$ である。

**【考査考点】**
- 生体防御機構における自然免疫（食作用）と獲得免疫（細胞性・体液性免疫）の分担。
- 食細胞（好中球・マクロファージ・樹状細胞）の細胞生物学的特徴。

## 生物 問10(1)：体液性免疫の細胞間情報伝達カスケード（樹状細胞・ヘルパーT細胞・B細胞）

**問題コード**: `bio-q-11` | **正解参照**: `BIOLOGY:11` | **正解**: `2`

### 出題のポイント
- 抗原の取り込みと抗原提示を行う抗原提示細胞（X：樹状細胞）の特定
- 提示された抗原断片を認識してサイトカインで指令を出す細胞（Y：ヘルパーT細胞）の同定
- 活性化されて抗体産生細胞（形質細胞）へ分化する細胞（Z：B細胞）の同定

### 詳細解説
**【題目大意】**
ヒトの体液性免疫（humoral immunity）の細胞応答プロセス図における細胞 X、Y、Z の名称の組み合わせを選択する。

**【公式正解】**
正解：$\textcircled{2}$ （X：樹状細胞、Y：ヘルパーT細胞、Z：B細胞）

**【詳細推導・解答プロセス】**
体液性免疫の一連の反応カスケードを図の流れに従って追跡する：

1. **細胞 X（抗原の取り込み・抗原提示）**：
   - 病原体などの抗原を取り込み、細胞内でペプチド断片に分解してMHCクラスII分子上に載せて細胞表面に提示（抗原提示）する細胞である。これは典型的な抗原提示細胞である**樹状細胞（dendritic cell）**（またはマクロファージ）に該当する。
2. **細胞 Y（抗原の認識と活性化）**：
   - Xから抗原提示を受け、T細胞受容体（TCR）を介して抗原を特異的に認識して活性化し、サイトカインを分泌して他の免疫細胞を増殖・分化させる司令塔となる細胞である。これは**ヘルパーT細胞（helper T cell）**である。
3. **細胞 Z（抗原認識・分裂・分化）**：
   - 抗原と結合し、さらに活性化したヘルパーT細胞（Y）からの刺激（インターロイキン等）を受け取って増殖し、最終的に大量の抗体を分泌・放出する抗体産生細胞（形質細胞；plasma cell）へと分化する。これは**B細胞（B cell）**である。

したがって、対応関係は：
$$\text{X：樹状細胞}、\quad \text{Y：ヘルパーT細胞}、\quad \text{Z：B細胞}$$
となり、正解は $\textcircled{2}$ である。

**【考査考点】**
- 体液性免疫における細胞間相互作用（抗原提示細胞 $\to$ ヘルパーT細胞 $\to$ B細胞 $\to$ 形質細胞）。
- 各リンパ球および抗原提示細胞の役割と分化経路。

## 生物 問10(2)：抗体（免疫グロブリン）の分子構造と可変部・定常部

**問題コード**: `bio-q-12` | **正解参照**: `BIOLOGY:12` | **正解**: `4`

### 出題のポイント
- 抗体のタンパク質としての分類：免疫グロブリン（immunoglobulin, a）
- 抗体分子の基本骨格：2本のH鎖（重鎖）と2本のL鎖（軽鎖）からなるY字型構造
- 抗原結合部位を構成する多様性に富む先端領域（b：可変部, variable region）

### 詳細解説
**【題目大意】**
抗体のタンパク質としての名称（空欄 a）と、抗体分子模式図における抗原結合先端部 A の名称（空欄 b）の正しい組み合わせを選択する。

**【公式正解】**
正解：$\textcircled{4}$ （a：グロブリン、b：可変部）

**【詳細推導・解答プロセス】**
**(1) 空欄 a について**
- 抗体（antibody）は血清タンパク質のうち $\gamma$-グロブリン分画に属する球状タンパク質であり、免疫系で機能することから**免疫グロブリン（immunoglobulin, Ig）**と呼ばれる。
- ヘモグロビン（hemoglobin）は赤血球内に存在し酸素を運搬するヘム鉄を含む複合タンパク質であり、抗体とは全く異なる。したがって、$a$ に入る語句は**グロブリン（globulin）**である。

**(2) 空欄 b（図中の領域 A）について**
- 抗体分子は、2本の同一なH鎖（重鎖；Heavy chain）と2本の同一なL鎖（軽鎖；Light chain）がジスルフィド結合（$-\text{S}-\text{S}-$ 結合）で架橋されたY字型の4量体構造をとる。
- Y字の2本の腕の先端部分（領域A）は、抗体ごとにアミノ酸配列が著しく異なっており、特定の抗原エピトープと鍵と鍵穴のように立体的に結合する部位である。この先端領域を**可変部（variable region；V領域）**と呼ぶ。
- 一方、Y字の幹および腕の基部側は同一起源の抗体で共通のアミノ酸配列をもち、補体結合や受容体結合を担う**定常部（constant region；C領域）**と呼ばれる。
- したがって、先端部Aに該当する $b$ は**可変部**である。

以上より、組み合わせは $a$：グロブリン、$b$：可変部 であり、正解は $\textcircled{4}$ である。

**【考査考点】**
- 抗体の化学的本質（免疫グロブリンの基本4本鎖構造）。
- 可変部（抗原認識の多様性と特異性）と定常部（エフェクター機能）の構造と役割の対比。

## 生物 問11：ニューロンの興奮伝導・全か無かの法則と刺激強度（頻度符号化）

**問題コード**: `bio-q-13` | **正解参照**: `BIOLOGY:13` | **正解**: `4`

### 出題のポイント
- 単一神経細胞（軸索）における全か無かの法則（all-or-none law）の成立
- 閾値以上の刺激強度増加に対する活動電位（活動電流）の振幅の不変性
- 刺激強度の情報伝達様式：活動電位の大きさではなく発火頻度（frequency）の増加による符号化

### 詳細解説
**【題目大意】**
単一のニューロンに一定時間の電気刺激を与えたときの刺激強度と興奮に関する記述 a, b の正誤（○・×）の組み合わせを選択する。

**【公式正解】**
正解：$\textcircled{4}$ （a：×、b：×）

**【詳細推導・解答プロセス】**
単一ニューロンの興奮発生の基本生理学的原理を検討する：

- **文 a の検討**：「ニューロンに与える刺激を強くするほど，興奮の大きさは大きくなる。」
  - 単一のニューロン（神経線維）において、刺激が閾値（threshold）に達しない場合は活動電位が発生せず（興奮ゼロ）、閾値以上の刺激を与えると直ちに最大振幅の活動電位が発生する。
  - 一度閾値を超えた後は、刺激をさらに強くしても発生する活動電位の大きさ（振幅、活動電位の電位差）は一定であり、大きくならない。これを**全か無かの法則（all-or-none law）**という。
  - したがって、文 a は**誤り（×）**である。

- **文 b の検討**：「ニューロンに刺激を与えると興奮がみられるが，さらに刺激を強くしても，興奮の頻度（frequency）は変化しない。」
  - 神経系が生体内で刺激の強弱を伝達・認識する仕組みは、活動電位の大きさではなく、単位時間あたりに発生する**活動電位の頻度（インパルスの発火頻度）**の高低によって情報が符号化されている（**頻度符号化；frequency coding**）。
  - 閾値を超える強い刺激を持続的に与えると、不応期の影響を受けつつも発生する活動電位の頻度は著しく増加する。「頻度は変化しない」とする文 b は明白に**誤り（×）**である。

したがって、a は ×、b は × であり、正解は $\textcircled{4}$ である。

**【考査考点】**
- 単一神経線維における活動電位発生のメカニズムと全か無かの法則。
- 刺激強度の増大に伴うインパルス発火頻度の変調（神経情報伝達の周波数変調）。

## 生物 問12：花芽形成ホルモン（フロリゲン/FTタンパク質）の合成部位と輸送経路

## 生物 問13：世界の陸上バイオーム（温帯内陸部のステップ）の環境と植生

**問題コード**: `bio-q-15` | **正解参照**: `BIOLOGY:15` | **正解**: `6`

### 出題のポイント
- 年平均気温と年間降水量に基づく世界の陸上バイオーム分類図（ホイタッカーの図）の読解
- 温帯内陸部で降水量が少なく樹木が発達しない草原バイオーム：ステップ（steppe）の同定
- 図中の記号 F がステップに該当することの判定

### 詳細解説
**【題目大意】**
年間降水量と年平均気温との関係を示したバイオーム分布図において、「温帯の内陸部に分布し、降水量が少ないため樹木は育たず、イネ科などの草本が見られるバイオーム」に該当する記号を選択する。

**【公式正解】**
正解：$\textcircled{6}$ （F：ステップ）

**【詳細推導・解答プロセス】**
**(1) バイオームの気候条件と植生特徴の整理**
- 問題文の定義：「温帯の内陸部に分布」「降水量が少なく樹木は育たない」「イネ科などの草本が優占する草原」
- これは温帯草原である**ステップ（steppe）**（北米ではプレーリー、南米ではパンパと呼ばれる）の典型的な特徴である。

**(2) ホイタッカーのバイオーム分布図における領域の同定**
- **A**：高温多雨（年間降水量極大・高温） $\to$ **熱帯多雨林**
- **B**：熱帯で乾季と雨季がある中降水量 $\to$ **雨緑樹林**
- **C**：暖温帯で年間を通じて温暖湿潤 $\to$ **照葉樹林**
- **D**：地中海性気候（夏に乾燥） $\to$ **硬葉樹林**
- **E**：冷温帯で湿潤 $\to$ **夏緑樹林**
- **G**：熱帯・亜熱帯の低降水量（乾季あり）の草原（イネ科草本＋アカシア等の低木） $\to$ **サバナ（savanna）**
- **F**：温帯（中温域）で降水量が $500\sim 1000\text{ mm}$ 前後と少なく、樹木林が成立できない草原 $\to$ **ステップ（steppe）**
- **H**：極端に降水量が少ない乾燥地域 $\to$ **砂漠（desert）**（寒冷域ではツンドラ）

したがって、温帯の乾燥草原であるステップに該当する領域は **F** である。
よって、正解は $\textcircled{6}$ である。

**【考査考点】**
- 世界の陸上バイオーム（森林・草原・荒原）の気温・降水量に応じた水平分布。
- ステップ、サバナ、熱帯多雨林、照葉樹林などの代表的バイオームの生態学的特徴。

## 生物 問14：森林生態系における生産者の物質収支（純生産量と成長量の計算）

**問題コード**: `bio-q-16` | **正解参照**: `BIOLOGY:16` | **正解**: `6`

### 出題のポイント
- 総生産量（Gross Primary Production, GPP）と純生産量（Net Primary Production, NPP）の関係式：$\text{純生産量} = \text{総生産量} - \text{呼吸量}$
- 純生産量の分配式：$\text{純生産量} = \text{成長量} + \text{枯死量} + \text{被食量}$
- 表の数値データを用いた定量的計算の実行

### 詳細解説
**【題目大意】**
ある森林生態系における植物（生産者）の年間の物質収支データ（総生産量 $2650$、呼吸量 $1450$、枯死量 $670$、被食量 $30\;[\text{g}/\text{m}^2/\text{年}]$）から、純生産量 A と成長量 B の数値を求める。

**【公式正解】**
正解：$\textcircled{6}$ （A：1200、B：500）

**【詳細推導・解答プロセス】**
生態系における生産者の物質収支の基本平衡方程式を適用する：

**(1) 純生産量 A の計算**
生産者が光合成によって一定期間内に合成したすべての有機物量を**総生産量（GPP）**という。このうち、植物自身の生命維持のために消費される有機物量が**呼吸量（R）**であり、総生産量から呼吸量を差し引いた残りが**純生産量（NPP, A）**である：
$$\text{純生産量 } A = \text{総生産量} - \text{呼吸量}$$
表の数値を代入すると：
$$A = 2650 - 1450 = 1200\;[\text{g}/\text{m}^2/\text{年}]$$

**(2) 成長量 B の計算**
純生産量は、次の3つの用途に分配される：
1. 枯死や落葉・落枝となって失われる**枯死量**（$670$）
2. 一次消費者（植食動物）に食べられる**被食量**（$30$）
3. 新たな植物体（幹・枝・根・葉など）として蓄積される**成長量**（$B$）

したがって、純生産量の収支方程式は：
$$\text{純生産量 } A = \text{成長量 } B + \text{枯死量} + \text{被食量}$$
$$B = A - (\text{枯死量} + \text{被食量})$$
数値を代入すると：
$$B = 1200 - (670 + 30) = 1200 - 700 = 500\;[\text{g}/\text{m}^2/\text{年}]$$

したがって、組み合わせは $A = 1200$、$B = 500$ である。
対応する選択肢は $\textcircled{6}$ である。

**【考査考点】**
- 生態系における生産者のエネルギー・物質収支体系の完全理解。
- 総生産量・呼吸量・純生産量・枯死量・被食量・成長量の数学的定義と定量関係。

## 生物 問15：極相林（照葉樹林・夏緑樹林）の鉛直構造（階層構造）

**問題コード**: `bio-q-17` | **正解参照**: `BIOLOGY:17` | **正解**: `4`

### 出題のポイント
- 発達した極相林における光環境の鉛直勾配（林冠から林床への光減衰）
- 階層構造の構成要素：高木層、亜高木層、低木層、草本層、地衣コケ層
- 林床付近の植物の適応（陰生植物の生育、独立栄養の維持）

### 詳細解説
**【題目大意】**
照葉樹林や夏緑樹林などの充分に発達した森林（極相林）の構造に関する記述 $\textcircled{1}$～$\textcircled{4}$ のうち、**最も適当なもの**を1つ選択する。

**【公式正解】**
正解：$\textcircled{4}$

**【詳細推導・解答プロセス】**
発達した極相林の鉛直方向の構造と生態学的特徴を吟味する：

- $\textcircled{1}$ 誤り：発達した成熟森林では、多様な樹種が混交し、芽生えから老木まで様々な樹齢の樹木が存在する。「大部分は同一の種類で樹木の年齢は同じ」という記述は人工林（単一植林）などの特徴であり、自然林の記述として誤り。
- $\textcircled{2}$ 誤り：林床（地表に近い部分）は上層の樹冠に遮られて光強度が極めて低いため、弱光環境に適応した**陰生植物（shade plant）**が生育する。強い光を好む「陽生植物」が生育することはできない。
- $\textcircled{3}$ 誤り：低木層や草本層の植物もすべて独立栄養生物であり、弱光下でも補償点・光飽和点が低い陰生葉を発達させて**光合成**を行い、有機物を合成して成長する。「光合成以外の栄養獲得で成長する」は明らかな誤り（従属栄養生物ではない）。
- $\textcircled{4}$ **正しい**：十分発達した森林では、光環境の勾配に応じて樹木の高さが多段階に分化し、最上部の**高木層**、その下の**亜高木層**、**低木層**、林床近くの**草本層**、さらに地表の地衣コケ層といった垂直方向の明確な**階層構造（stratified structure）**が形成される。記述は極相林の特徴として完全に適切である。

したがって、正解は $\textcircled{4}$ である。

**【考査考点】**
- 極相林における群落の鉛直構造（階層構造）の形成。
- 森林内部の相対照度の減衰と植物の光適応（陽生植物と陰生植物の生態的住み分け）。

## 生物 問16：細胞内共生説（ミトコンドリアと葉緑体の起源と好気性細菌・シアノバクテリア）

**問題コード**: `bio-q-18` | **正解参照**: `BIOLOGY:18` | **正解**: `2`

### 出題のポイント
- マーグリスらによる細胞内共生説の根拠（二重膜、独自の環状DNA、独自のリボソーム、二分裂増殖）
- ミトコンドリアの起源：好気性細菌（$\alpha$-プロテオバクテリアの祖先）の共生
- 葉緑体の起源：シアノバクテリア（ラン藻・光合成細菌）の共生

### 詳細解説
**【題目大意】**
真核細胞のミトコンドリアと葉緑体の起源に関する細胞内共生説（endosymbiotic theory）の記述 $\textcircled{1}$～$\textcircled{4}$ のうち、**誤っているもの**を1つ選択する。

**【公式正解】**
正解：$\textcircled{2}$

**【詳細推導・解答プロセス】**
細胞内共生説の学説内容を精査する：

- $\textcircled{1}$ **正しい**：ミトコンドリアと葉緑体は、核DNAとは独立した独自の環状DNAをもち、独自に転写・翻訳を行って増殖する。これは原核生物が細胞内に共生したことを示す最も強力な証拠（根拠）の1つである。
- $\textcircled{2}$ **誤り**：細胞内共生説において、原始的な真核生物に取り込まれて**ミトコンドリアの起源**となったのは酸素を用いて呼吸を行う**好気性細菌（aerobic bacteria）**である。一方、光合成を行う**シアノバクテリア（cyanobacteria）**が細胞内に共生して起源となったのは**葉緑体（chloroplast）**である。記述では「シアノバクテリアがミトコンドリアの起源となった」としており、起源生物の対応が逆であり明白に誤りである。
- $\textcircled{3}$ **正しい**：原始大気中に酸素濃度が上昇した際、宿主細胞が好気性細菌を取り込んで共生させたことにより、酸素を利用した効率的なATP産生機構（好気呼吸・電子伝達系）を獲得したと考えられている。
- $\textcircled{4}$ **正しい**：嫌気性の原始真核生物（古細菌様祖先細胞）がまず好気性細菌を取り込んで動物細胞・真菌の祖先（従属栄養真核細胞）へと進化し、その一部がさらに光合成を行うシアノバクテリアを取り込んで植物細胞（独立栄養真核細胞）へと進化したと考えられている（二次共生・オルガネラ化の歴史的順序）。

誤っているものは $\textcircled{2}$ である。

**【考査考点】**
- 真核生物の起源と進化（細胞内共生説の基本原理）。
- ミトコンドリア（好気性細菌起源）と葉緑体（シアノバクテリア起源）のそれぞれの共生起源の正確な識別。
