## 問1：直交する2斜面上の球のつり合いと垂直抗力
- **問題番号**：問1
- **公式正解**：選択肢 $\textcircled{4}$
- **重要論点**：
  - 直角に交わる斜面A（傾斜角 60°）と斜面B（傾斜角 30°）の幾何学的対称性
  - 重力と各斜面からの垂直抗力 F_A, F_B の直交成分分解
  - 力のつり合い方程式による各垂直抗力の大きさの正確な導出

**【題目大意】**
水平面とのなす角が $60^\circ$ の斜面Aと、$30^\circ$ の斜面Bが直角（$90^\circ$）につながっている。質量 $M$ の球がこの2斜面の間で静止しているとき、球が斜面Aから受ける垂直抗力 $F_A$ と斜面Bから受ける垂直抗力 $F_B$ の大きさを求める。

**【公式正解】**
選択肢 $\textcircled{4}$ ($F_A = \frac{1}{2}Mg, \quad F_B = \frac{\sqrt{3}}{2}Mg$)

**【詳細推導・解答プロセス】**
摩擦のない2斜面から受ける力 $F_A, F_B$ は、それぞれ斜面に垂直な抗力である。
- 斜面Aの傾斜角は $60^\circ$ であるから、その法線（$F_A$ の方向）は水平面から $30^\circ$ 上向き（鉛直上方から $60^\circ$ 傾いた向き）である。
- 斜面Bの傾斜角は $30^\circ$ であるから、その法線（$F_B$ の方向）は水平面から $60^\circ$ 上向き（鉛直上方から $30^\circ$ 傾いた向き）である。
球には重力 $Mg$（鉛直下向き）と、$F_A, F_B$ の 3 力がはたらき、静止してつり合っている。

水平方向および鉛直方向のつり合いの式を立てる：
- 水平方向のつり合い：
  $$F_A \cos 30^\circ = F_B \cos 60^\circ \implies F_A \cdot \frac{\sqrt{3}}{2} = F_B \cdot \frac{1}{2} \implies F_B = \sqrt{3}F_A$$
- 鉛直方向のつり合い：
  $$F_A \sin 30^\circ + F_B \sin 60^\circ = Mg$$
  $F_B = \sqrt{3}F_A$ を代入すると：
  $$F_A \cdot \frac{1}{2} + (\sqrt{3}F_A) \cdot \frac{\sqrt{3}}{2} = Mg \implies F_A\left(\frac{1}{2} + \frac{3}{2}\right) = 2F_A = Mg$$
  $$F_A = \frac{1}{2}Mg$$
したがって：
$$F_B = \sqrt{3}F_A = \frac{\sqrt{3}}{2}Mg$$
これは選択肢 $\textcircled{4}$ に一致する。

**【考査考点】**
剛体・質点の力のつり合い、直交座標系へのベクトル分解、幾何学的角度（斜面傾斜角と法線方向角）の正確な把握。

## 問2：重ね合わされた2物体の最大静止摩擦力と運動開始条件
- **問題番号**：問2
- **公式正解**：選択肢 $\textcircled{5}$
- **重要論点**：
  - 床と物体A、物体Aと物体Bの間の垂直抗力および最大静止摩擦力の評価
  - 系全体（A+B）の水平方向の外力のつり合いと運動開始限界
  - 一体となって運動を開始するための摩擦力制約の検証

**【題目大意】**
水平な床の上に質量 $6\text{ kg}$ の直方体Aを置き、その上に質量 $4\text{ kg}$ の直方体Bを置く。Bを水平左向きに $10\text{ N}$ で引き、Aを水平右向きに力 $F$ で引く。静止摩擦係数は床-A間、A-B間ともに $\mu = 0.5$、$g = 10\text{ m/s}^2$ である。AとBが一体のまま動き始める最小の力 $F_0$ を求める。

**【公式正解】**
選択肢 $\textcircled{5}$ ($60\text{ N}$)

**【詳細推導・解答プロセス】**
AとBを合わせた一体の系（全質量 $M = 6 + 4 = 10\text{ kg}$）に作用する外力を考える。
床から受ける全垂直抗力は：
$$N_{\text{floor}} = (m_A + m_B)g = (6 + 4) \times 10 = 100\text{ N}$$
したがって、床とAの間の最大静止摩擦力は：
$$f_{\max, \text{floor}} = \mu N_{\text{floor}} = 0.5 \times 100 = 50\text{ N}$$

系全体を右向きに動かそうとする力は $F$、左向きに引っ張る外力は $10\text{ N}$、床からの静止摩擦力（最大 $50\text{ N}$、左向き）である。
系全体が右向きに動き始める限界において：
$$F_0 - 10 - f_{\max, \text{floor}} = 0 \implies F_0 = 10 + 50 = 60\text{ N}$$

（検証：このときAとBの間で滑りが生じないか）
AとBの間の最大静止摩擦力は：
$$f_{\max, AB} = \mu m_B g = 0.5 \times (4 \times 10) = 20\text{ N}$$
動き始める直前において、Bに加わっている左向きの外力は $10\text{ N}$ であり、これは最大静止摩擦力 $20\text{ N}$ 以下であるため、BはAに対して滑らず一体となって動き始める。
したがって、$F_0 = 60\text{ N}$ である。

**【考査考点】**
連結物体の摩擦力、最大静止摩擦力の公式 $f = \mu N$、系全体と各物体の運動方程式および運動開始条件の連立。

## 問3：1次元衝突と水平投射の水平到達距離の比
- **問題番号**：問3
- **公式正解**：選択肢 $\textcircled{5}$
- **重要論点**：
  - 運動量保存則とはね返り係数（反発係数）の定義式の連立
  - 衝突後の各小球の初速度の計算
  - 水平投射における等速直線運動と落下時間の共通性

**【題目大意】**
質量が等しい小物体AとBがあり、初速 $v_0$ のAが静止したBと衝突する（はね返り係数 $e = 0.60$）。衝突後、2物体は同じ高さの台端から水平に飛び出して床に落下する。落下地点までの水平距離の比 $\frac{x_B}{x_A}$ を求める。

**【公式正解】**
選択肢 $\textcircled{5}$ ($4.0$)

**【詳細推導・解答プロセス】**
小物体の質量をともに $m$ とする。
衝突前のAの速度を $v_0$、Bの速度を $0$ とし、衝突直後の速度をそれぞれ $v_A, v_B$ とする。
- 運動量保存則：
  $$m v_A + m v_B = m v_0 \implies v_A + v_B = v_0$$
- はね返り係数の式（$e = 0.60$）：
  $$v_B - v_A = e v_0 = 0.60 v_0$$
2式を加えると：
$$2v_B = 1.60 v_0 \implies v_B = 0.80 v_0$$
$$v_A = v_0 - v_B = v_0 - 0.80 v_0 = 0.20 v_0$$

台の端から床までの高さを $h$ とすると、水平投射された物体の鉛直方向の運動は自由落下であるため、床に到達するまでの時間 $t$ は等しく：
$$t = \sqrt{\frac{2h}{g}}$$
水平方向は等速直線運動であるから、水平到達距離はそれぞれ：
$$x_A = v_A t, \quad x_B = v_B t$$
したがって、水平到達距離の比は初速度の比に等しい：
$$\frac{x_B}{x_A} = \frac{v_B t}{v_A t} = \frac{v_B}{v_A} = \frac{0.80 v_0}{0.20 v_0} = 4.0$$
これは選択肢 $\textcircled{5}$ に一致する。

**【考査考点】**
1次元衝突における運動量保存則と反発係数の連立計算、水平投射における水平成分と鉛直成分の独立性。

## 問4：鉛直面内円運動の最下点における糸の張力
- **問題番号**：問4
- **公式正解**：選択肢 $\textcircled{3}$
- **重要論点**：
  - 力学的エネルギー保存則による最下点における小球の速さの導出
  - 円運動の向心加速度 a = v^2 / l の適用
  - 最下点における運動方程式（または遠心力とのつり合い）による張力 T の決定

**【題目大意】**
長さ $l$ の糸の一端を固定点 $O$ に止め、他端の小球（質量 $m$）を $O$ と同じ高さから鉛直下向きに初速 $v_0$ で投射した。小球が $O$ の真下（最下点）を通過するときの糸の張力 $T$ を求める。

**【公式正解】**
選択肢 $\textcircled{3}$ ($\frac{m v_0^2}{l} + 3mg$)

**【詳細推導・解答プロセス】**
小球が初速 $v_0$ を与えられた点から最下点まで、高さは $l$ だけ下降する。
重力のみが仕事をするため、力学的エネルギー保存則が成り立つ。
最下点での小球の速さを $v$ とすると：
$$\frac{1}{2}mv^2 - \frac{1}{2}mv_0^2 = mgl \implies v^2 = v_0^2 + 2gl$$

最下点において小球は半径 $l$ の円軌道を描いている。
小球に働く力は、鉛直上向きの糸の張力 $T$ と鉛直下向きの重力 $mg$ である。
中心方向（鉛直上向き）の運動方程式を立てると：
$$m\frac{v^2}{l} = T - mg$$
したがって：
$$T = mg + m\frac{v^2}{l} = mg + \frac{m(v_0^2 + 2gl)}{l} = mg + \frac{mv_0^2}{l} + 2mg = \frac{mv_0^2}{l} + 3mg$$
これは選択肢 $\textcircled{3}$ に一致する。

**【考査考点】**
鉛直面内の円運動、力学的エネルギー保存則、円運動の向心力方程式と張力の立式。

## 問5：ばねで分離する2物体の運動量保存と力学的エネルギー保存
- **問題番号**：問5
- **公式正解**：選択肢 $\textcircled{4}$
- **重要論点**：
  - 内力のみによる運動量保存則（重心静止系の関係 v_B = v_A / 2）
  - ばねの弾性エネルギーの運動エネルギーへの完全変換
  - 分離後の小物体Aの速さ v の文字式導出

**【題目大意】**
水平ななめらかな床の上で、ばね定数 $k$ の軽いばねを小物体A（質量 $m$）と小物体B（質量 $2m$）の間に挟んで $x$ だけ縮めた状態から静かに同時に手を離した。ばねが自然長に戻ってAがばねから離れた直後のAの速さ $v$ を求める。

**【公式正解】**
選択肢 $\textcircled{4}$ ($\sqrt{\frac{2k}{3m}}x$)

**【詳細推導・解答プロセス】**
水平方向には外力が働かないため、AとBからなる系の運動量は保存される。
Aの速度を左向き正としてその速さを $v$、Bの速さを $v_B$（右向き）とする。
初状態では静止していたので：
$$m v - 2m v_B = 0 \implies v_B = \frac{1}{2}v$$

床はなめらかであるから、ばねの弾性エネルギーがすべてAとBの運動エネルギーに変換される。
力学的エネルギー保存則より：
$$\frac{1}{2}kx^2 = \frac{1}{2}mv^2 + \frac{1}{2}(2m)v_B^2$$
$v_B = \frac{1}{2}v$ を代入すると：
$$\frac{1}{2}kx^2 = \frac{1}{2}mv^2 + m\left(\frac{1}{2}v\right)^2 = \frac{1}{2}mv^2 + \frac{1}{4}mv^2 = \frac{3}{4}mv^2$$
両辺を整理すると：
$$v^2 = \frac{4}{3m} \cdot \frac{1}{2}kx^2 = \frac{2k}{3m}x^2$$
$v > 0, x > 0$ であるから：
$$v = \sqrt{\frac{2k}{3m}}x$$
これは選択肢 $\textcircled{4}$ に一致する。

**【考査考点】**
分裂運動における運動量保存則、弾性エネルギーと運動エネルギーの力学的エネルギー保存則の連立。

## 問6：人工衛星の万有引力円運動と運動エネルギーの比
- **問題番号**：問6
- **公式正解**：選択肢 $\textcircled{1}$
- **重要論点**：
  - 万有引力を向心力とする等速円運動の運動方程式の立式
  - 軌道半径 R と衛星質量 m に依存する運動エネルギーの一般式 K = GMm / (2R)
  - パラメータの比率（質量比 1/2、軌道半径比 2）によるエネルギー比の計算

**【題目大意】**
地球の周りを等速円運動する人工衛星A（質量 $m$、軌道半径 $r$）とB（質量 $\frac{1}{2}m$、軌道半径 $2r$）の運動エネルギーの比 $\frac{K_B}{K_A}$ を求める。

**【公式正解】**
選択肢 $\textcircled{1}$ ($\frac{1}{4}$)

**【詳細推導・解答プロセス】**
地球の質量を $M$、万有引力定数を $G$ とする。
質量 $m_s$、軌道半径 $R$ の衛星の等速円運動の運動方程式は：
$$m_s \frac{v^2}{R} = G\frac{M m_s}{R^2} \implies m_s v^2 = \frac{G M m_s}{R}$$
したがって、その運動エネルギー $K$ は：
$$K = \frac{1}{2} m_s v^2 = \frac{G M m_s}{2R}$$

各衛星の運動エネルギーを計算する：
- 衛星A：質量 $m$、半径 $r$ より
  $$K_A = \frac{G M m}{2r}$$
- 衛星B：質量 $\frac{1}{2}m$、半径 $2r$ より
  $$K_B = \frac{G M \left(\frac{1}{2}m\right)}{2(2r)} = \frac{1}{4} \cdot \frac{G M m}{2r} = \frac{1}{4}K_A$$
したがって、運動エネルギーの比は：
$$\frac{K_B}{K_A} = \frac{1}{4}$$
これは選択肢 $\textcircled{1}$ に一致する。

**【考査考点】**
万有引力による円運動の運動方程式、円軌道の速さと運動エネルギーの公式、質量および軌道半径の比率計算。

## 問7：水と氷の熱交換と氷の融解熱・残存氷の質量計算
- **問題番号**：問7
- **公式正解**：選択肢 $\textcircled{5}$
- **重要論点**：
  - 水が 0℃ まで冷却されるときに放出する熱量の計算
  - 氷が -10℃ から 0℃ まで昇温するのに必要な熱量の計算
  - 残りの熱量による氷の融解量と残存質量の決定

**【題目大意】**
$20^\circ\text{C}$ の水 $200\text{ g}$ に $-10^\circ\text{C}$ の氷 $100\text{ g}$ を入れたところ、十分に時間が経過した後に $0^\circ\text{C}$ の水と氷の混合状態になった。残った氷の質量を求める。比熱は水 $4.2\text{ J/(g}\cdot\text{K)}$、氷 $2.1\text{ J/(g}\cdot\text{K)}$、融解熱 $3.3 \times 10^2\text{ J/g}$ である。

**【公式正解】**
選択肢 $\textcircled{5}$ ($55\text{ g}$)

**【詳細推導・解答プロセス】**
熱平衡温度が $0^\circ\text{C}$ であるから、熱量の移動を順次計算する。
1. 水 $200\text{ g}$ が $20^\circ\text{C}$ から $0^\circ\text{C}$ まで下がる際に放出する熱量 $Q_1$：
   $$Q_1 = 200 \times 4.2 \times (20 - 0) = 200 \times 84 = 16800\text{ J}$$
2. 氷 $100\text{ g}$ が $-10^\circ\text{C}$ から $0^\circ\text{C}$ まで上昇するのに吸収する熱量 $Q_2$：
   $$Q_2 = 100 \times 2.1 \times (0 - (-10)) = 100 \times 21 = 2100\text{ J}$$
3. 氷の融解に使える残りの熱量 $Q_3$：
   $$Q_3 = Q_1 - Q_2 = 16800 - 2100 = 14700\text{ J}$$
4. この熱量によって融解した氷の質量 $\Delta m$：
   $$\Delta m = \frac{Q_3}{3.3 \times 10^2} = \frac{14700}{330} \approx 44.55\text{ g}$$
5. したがって、容器内に残った氷の質量 $m_{\text{left}}$ は：
   $$m_{\text{left}} = 100 - \Delta m = 100 - 44.55 = 55.45\text{ g} \approx 55\text{ g}$$
これは選択肢 $\textcircled{5}$ に一致する。

**【考査考点】**
熱量の保存（得た熱量＝失った熱量）、顕熱と潜熱（融解熱）の段階的計算、熱平衡状態における物質量の特定。

## 問8：定圧変化における外部への仕事と内部エネルギー変化
- **問題番号**：問8
- **公式正解**：選択肢 $\textcircled{2}$
- **重要論点**：
  - 大気圧下でのピストンの移動に伴う気体の外部への仕事 W = pΔV の計算
  - 熱力学第1法則 ΔU = Q - W の適用
  - 吸収熱量と仕事からの内部エネルギー増加量の算出

**【題目大意】**
断面積 $1.0 \times 10^{-1}\text{ m}^2$ のピストンで大気圧 $1.0 \times 10^5\text{ Pa}$ の理想気体を閉じ込め、ヒーターで熱量 $2.5 \times 10^3\text{ J}$ を加えたところ、ピストンが右に $1.0 \times 10^{-1}\text{ m}$ 移動した。気体の内部エネルギーの増加量 $\Delta U$ を求める。

**【公式正解】**
選択肢 $\textcircled{2}$ ($1.5 \times 10^3\text{ J}$)

**【詳細推導・解答プロセス】**
ピストンはなめらかに動くため、気体の圧力は常に大気圧 $p = 1.0 \times 10^5\text{ Pa}$ に保たれる（定圧変化）。
気体の体積変化量 $\Delta V$ は：
$$\Delta V = A \Delta x = (1.0 \times 10^{-1}\text{ m}^2) \times (1.0 \times 10^{-1}\text{ m}) = 1.0 \times 10^{-2}\text{ m}^3$$
気体がピストンを押し広げることによって外部にした仕事 $W$ は：
$$W = p \Delta V = (1.0 \times 10^5\text{ Pa}) \times (1.0 \times 10^{-2}\text{ m}^3) = 1.0 \times 10^3\text{ J}$$

熱力学第1法則 $\Delta U = Q - W$ を適用する：
$$\Delta U = 2.5 \times 10^3\text{ J} - 1.0 \times 10^3\text{ J} = 1.5 \times 10^3\text{ J}$$
したがって、気体の内部エネルギーは $1.5 \times 10^3\text{ J}$ 増加した。
これは選択肢 $\textcircled{2}$ に一致する。

**【考査考点】**
定圧変化における気体の仕事 $W = p\Delta V$、熱力学第1法則 $\Delta U = Q - W$ の基本関係の理解と計算。

## 問9：p-V線図上の直線的状態変化における仕事・内部エネルギー・熱量

  - 熱力学第1法則 Q = ΔU + W による吸収熱量の導出

**【題目大意】**
単原子分子理想気体の状態を $p$-$V$ 図上で状態A $(V_0, p_0)$ から状態B $(3V_0, 2p_0)$ まで直線的に変化させた。気体が外部にした仕事 $W$、内部エネルギーの変化 $\Delta U$、気体が吸収した熱量 $Q$ を求める。

**【公式正解】**
選択肢 $\textcircled{6}$ ($W = 3p_0V_0, \quad \Delta U = \frac{15}{2}p_0V_0, \quad Q = \frac{21}{2}p_0V_0$)

**【詳細推導・解答プロセス】**
**(1) 気体が外部にした仕事 $W$**
$p$-$V$ グラフにおいて、気体がした仕事 $W$ はグラフと $V$ 軸で囲まれた台形の面積に等しい：
$$W = \frac{p_A + p_B}{2} \times (V_B - V_A) = \frac{p_0 + 2p_0}{2} \times (3V_0 - V_0) = \frac{3p_0}{2} \times 2V_0 = 3p_0V_0$$

**(2) 内部エネルギー変化 $\Delta U$**
単原子分子理想気体の内部エネルギーは $U = \frac{3}{2}nRT = \frac{3}{2}pV$ で与えられる。
したがって、状態変化に伴う内部エネルギーの変化は：
$$\Delta U = U_B - U_A = \frac{3}{2}(p_B V_B - p_A V_A) = \frac{3}{2}(2p_0 \times 3V_0 - p_0 V_0) = \frac{3}{2}(6p_0V_0 - p_0V_0) = \frac{15}{2}p_0V_0$$

**(3) 気体が吸収した熱量 $Q$**
熱力学第1法則 $Q = \Delta U + W$ より：
$$Q = \frac{15}{2}p_0V_0 + 3p_0V_0 = \frac{15}{2}p_0V_0 + \frac{6}{2}p_0V_0 = \frac{21}{2}p_0V_0$$
これらをまとめると：
$$W = 3p_0V_0, \quad \Delta U = \frac{15}{2}p_0V_0, \quad Q = \frac{21}{2}p_0V_0$$
これは選択肢 $\textcircled{6}$ に一致する。

**【考査考点】**
$p$-$V$ 図における仕事の幾何学的計算（台形面積）、単原子分子気体の内部エネルギー公式 $U = \frac{3}{2}pV$、熱力学第1法則によるエネルギー収支の連立。

$x$ 軸の正の向きに進む縦波について、ある時刻における媒質の密度変化 $\Delta \rho$ と位置 $x$ の関係を表すグラフが与えられている。位置Bは密、位置Dは疎である。このとき、媒質が $x$ 軸の正の向きへ最も大きく変位している位置（A, B, C, D）を特定する。

**【公式正解】**
選択肢 $\textcircled{1}$ (位置 A)

**【詳細推導・解答プロセス】**
縦波における媒質の変位を $y(x)$（$x$ 軸正の向きを正とする）とすると、媒質の密度変化 $\Delta \rho$ は変位の傾きの負に比例する：
$$\Delta \rho \propto -\frac{\partial y}{\partial x}$$
波が $x$ 軸の正の向きに進むとき、変位を正弦波 $y(x) = y_0 \sin(kx)$ とおくと：
$$\Delta \rho \propto -y_0 k \cos(kx)$$
- $\Delta \rho$ が最大（最も「密」）となるのは、$-\cos(kx) = 1 \iff \cos(kx) = -1$ の点であり、これが位置B（$kx = \pi$）である。
- $\Delta \rho$ が最小（最も「疎」）となるのは、$-\cos(kx) = -1 \iff \cos(kx) = 1$ の点であり、これが位置D（$kx = 0$ または $2\pi$）である。
- グラフ上で密度変化がゼロ（$\Delta \rho = 0$）となる境界が点Aと点Cである。
  D（$kx = 0$）から B（$kx = \pi$）に向かう途中の点Aでは $kx = \frac{\pi}{2}$ であるから：
  $$y(A) = y_0 \sin\left(\frac{\pi}{2}\right) = +y_0$$
  すなわち、変位は正の向きに最大値 $+y_0$ となる。
  一方、点C（$kx = \frac{3\pi}{2}$）では $y(C) = -y_0$ となり、負の向きに最大変位となる。
したがって、媒質が $x$ 軸の正の向きへ最も大きく変位している位置は **A** である。
これは選択肢 $\textcircled{1}$ に一致する。

**【考査考点】**
縦波の横波表示、密と疎における変位勾配の符号、変位極大点と密度極値点の位相関係（$\frac{\pi}{2}$ のずれ）。

## 問12：水面に浮かべた円板と全反射による物体の不可視限界
- **問題番号**：問12
- **公式正解**：選択肢 $\textcircled{3}$
- **重要論点**：
  - 水から空気への屈折における全反射の臨界角条件 sin θ_c = 1 / n
  - 円板の端を通過する光線の幾何学的条件 tan θ = r / l_0
  - 直角三角形の三角比関係による比 l_0 / r の導出

**【題目大意】**
水面に半径 $r$ の薄い円板を浮かべ、その中心の直下にひもでおもりを水深 $l$ に吊るす。水の空気に対する相対屈折率を $n$ とする。$l$ がある長さ $l_0$ を超えると空気中からおもりが見えるようになる。比 $\frac{l_0}{r}$ を求める。

**【公式正解】**
選択肢 $\textcircled{3}$ ($\sqrt{n^2 - 1}$)

**【詳細推導・解答プロセス】**
おもりから出た光が空気中に出てこられるかどうかを考える。
円板の直下にある水面部分は円板によって遮られているため、光が空気中に出るためには円板の外側の水面に達する必要がある。
おもりから円板の縁に向かう光線の入射角を $\theta$ とすると：
$$\sin\theta = \frac{r}{\sqrt{r^2 + l^2}}$$
水から空気への全反射の臨界角を $\theta_c$ とすると、スネルの法則より：
$$\sin\theta_c = \frac{1}{n}$$
円板の外側の水面に達するすべての光線の入射角が臨界角以上（$\theta \geq \theta_c$）であれば、光は水面で全反射され空気中に出てこないため、空気中のどこから見てもおもりは見えない。
深さ $l$ が大きくなると、円板の縁に達する光の入射角 $\theta$ は小さくなる。
おもりが空気中から見え始める限界の深さ $l_0$ では、円板の縁での入射角がちょうど臨界角 $\theta_c$ に一致する：
$$\sin\theta_c = \frac{r}{\sqrt{r^2 + l_0^2}} = \frac{1}{n}$$
両辺を2乗して逆数をとると：
$$\frac{r^2 + l_0^2}{r^2} = n^2 \implies 1 + \left(\frac{l_0}{r}\right)^2 = n^2$$
したがって：
$$\left(\frac{l_0}{r}\right)^2 = n^2 - 1 \implies \frac{l_0}{r} = \sqrt{n^2 - 1}$$
これは選択肢 $\textcircled{3}$ に一致する。

**【考査考点】**
光の屈折の法則（スネルの法則）、全反射の条件と臨界角の導出、幾何光学と直角三角形の幾何的立式。

## 問13：正三角形頂点の点電荷による重心における電場の合成
- **問題番号**：問13
- **公式正解**：選択肢 $\textcircled{6}$
- **重要論点**：
  - クーロンの法則による点電荷の電場公式 E = kQ / r^2
  - 正三角形の幾何学的性質（重心までの距離 R = a / √3）
  - 3つの点電荷による電場ベクトルの合成と基準電場 E_0 との比率換算

**【題目大意】**
1辺の長さ $a$ の正三角形ABCの頂点Aに $-Q$、頂点Bに $+Q$、頂点Cに $+Q$ の点電荷を固定する。Bの電荷がAの位置につくる電場の大きさを $E_0$ とするとき、正三角形の重心 $O$ における電場の大きさを求める。

**【公式正解】**
選択肢 $\textcircled{6}$ ($6E_0$)

**【詳細推導・解答プロセス】**
クーロンの法則の比例定数を $k$ とする。
Bにある電荷 $+Q$ が距離 $a$ 離れたAにつくる電場の大きさは：
$$E_0 = k\frac{Q}{a^2}$$

正三角形の各頂点から重心 $O$ までの距離を $R$ とすると：
$$R = \frac{a}{\sqrt{3}}$$
したがって、各電荷が重心 $O$ につくる電場の大きさ $E_1$ は共通で：
$$E_1 = k\frac{Q}{R^2} = k\frac{Q}{\left(\frac{a}{\sqrt{3}}\right)^2} = 3k\frac{Q}{a^2} = 3E_0$$

各電荷がつくる電場ベクトルの向きを考える：
1. 頂点A（電荷 $-Q$）：負電荷であるから、$O$ から A に向かう向き（大きさ $3E_0$）。
2. 頂点B（電荷 $+Q$）：正電荷であるから、$B$ から $O$ に向かう向き（大きさ $3E_0$）。
3. 頂点C（電荷 $+Q$）：正電荷であるから、$C$ から $O$ に向かう向き（大きさ $3E_0$）。

頂点Bと頂点Cによる電場ベクトル $\vec{E}_B, \vec{E}_C$ のなす角は $120^\circ$ である。
これら2つの等しい大きさ（$3E_0$）のベクトルの合力は、角の二等分線方向（すなわち $O$ から頂点Aに向かう向き）を向き、その大きさは：
$$2 \times (3E_0) \cos 60^\circ = 2 \times 3E_0 \times \frac{1}{2} = 3E_0$$
頂点Aの負電荷がつくる電場 $\vec{E}_A$ も全く同じ向き（$O$ から A へ）を向いている。
したがって、全体の合成電場の大きさ $E_{\text{total}}$ は：
$$E_{\text{total}} = 3E_0 + 3E_0 = 6E_0$$
これは選択肢 $\textcircled{6}$ に一致する。

**【考査考点】**
点電荷による電場、電場ベクトルの重ね合わせの原理、正三角形の幾何的性質（対称性とベクトル合成）。

## 問14：平行板コンデンサーへの部分導体板挿入と電気容量変化
- **問題番号**：問14
- **公式正解**：選択肢 $\textcircled{6}$
- **重要論点**：
  - 導体板の挿入による実質的極板間隔の減少（d_eff = d - t）
  - コンデンサーの並列接続モデルへの分割（面積 S/3 と 2S/3）

**【題目大意】**
極板面積 $S$、間隔 $d$ の平行板コンデンサーの電気容量を $C$ とする。この極板間に、面積 $\frac{S}{3}$、厚さ $\frac{d}{2}$ の導体板を極板と平行に挿入したときの電気容量 $C'$ と $C$ の比 $\frac{C'}{C}$ を求める。

**【公式正解】**
選択肢 $\textcircled{6}$ ($\frac{4}{3}$)

**【詳細推導・解答プロセス】**
初期の平行板コンデンサーの電気容量は：
$$C = \varepsilon_0 \frac{S}{d}$$

導体板が部分的に挿入された状態は、導体板のない領域（面積 $\frac{2}{3}S$）と、導体板のある領域（面積 $\frac{1}{3}S$）の 2 つのコンデンサーが並列に接続されていると見なすことができる。
1. **導体板のない部分の容量 $C_1$**：
   極板面積は $S - \frac{S}{3} = \frac{2}{3}S$、極板間隔は $d$ のままであるから：
   $$C_1 = \varepsilon_0 \frac{\frac{2}{3}S}{d} = \frac{2}{3}C$$
2. **導体板のある部分の容量 $C_2$**：
   極板面積は $\frac{S}{3}$ である。
   厚さ $\frac{d}{2}$ の導体板の内部では電場がゼロとなるため、実質的な極板間隔は $d - \frac{d}{2} = \frac{d}{2}$ に減少する。
   したがって：
   $$C_2 = \varepsilon_0 \frac{\frac{S}{3}}{\frac{d}{2}} = \varepsilon_0 \frac{\frac{1}{3}S}{\frac{1}{2}d} = \frac{2}{3} \varepsilon_0 \frac{S}{d} = \frac{2}{3}C$$

全体の合成容量 $C'$ は並列接続の和である：
$$C' = C_1 + C_2 = \frac{2}{3}C + \frac{2}{3}C = \frac{4}{3}C$$
したがって：
$$\frac{C'}{C} = \frac{4}{3}$$
これは選択肢 $\textcircled{6}$ に一致する。

**【考査考点】**
平行板コンデンサーの容量の定義式、導体板挿入による等価的極板間隔短縮効果、コンデンサーの並列分割モデルの構築。

  - 閉回路のオームの法則 I = E / (R + r)
  - 外部抵抗での消費電力 P = I^2 R の定式化
  - 抵抗値に関する2次方程式の解法と大小条件による解の選定

**【題目大意】**
起電力 $E = 6.0\text{ V}$、内部抵抗 $r = 1.0\ \Omega$ の電池に外部抵抗 $R$ を接続したところ、外部抵抗での消費電力が $5.0\text{ W}$ であった。外部抵抗の抵抗値が内部抵抗より大きい（$R > r$）とき、$R$ の値を求める。

**【詳細推導・解答プロセス】**

$$I = \frac{E}{R + r} = \frac{6.0}{R + 1.0}$$

$$5R^2 - 26R + 5 = 0$$

$$(5R - 1)(R - 5) = 0$$
これより $R = 0.20\ \Omega$ または $R = 5.0\ \Omega$ である。
問題文の条件「外部抵抗の抵抗値は内部抵抗（$1.0\ \Omega$）より大きい」より：

これは選択肢 $\textcircled{1}$ に一致する。

## 問16：2本の直線電流がつくる磁場の合成と打ち消し合い条件
- **問題番号**：問16
- **公式正解**：選択肢 $\textcircled{2}$
- **重要論点**：
  - アンペールの法則（右ねじの法則）による直線電流の磁場公式 B = μ_0 I / (2π r)
  - 直角二等辺三角形の幾何的配置における磁場ベクトルの成分分解
  - 指定された合成磁場方向を満たすための電流の向きと大きさの決定

**【題目大意】**
直角二等辺三角形OABの頂角 $O$（$90^\circ$）と頂点 $A$ を通る2本の十分長い直線導線がある。$O$ を通る導線には紙面裏から表向きに電流 $I$ が流れている。頂点 $B$ での磁場が $O$ から $B$ に向かう向き（$OB$ 方向）となるような、導線 $A$ を流れる電流の向きと大きさを求める。

**【公式正解】**
選択肢 $\textcircled{2}$ (向き：紙面表から裏の向き、大きさ：$2I$)

**【詳細推導・解答プロセス】**
$OA = OB = d$ とおく。頂点 $B$ の位置を考え、$O$ を原点、$OB$ を $x$ 軸、$OA$ を $y$ 軸にとる。
- 導線 $O$（原点 $(0, 0)$）の電流 $I$ は紙面裏から表向き（$+z$ 方向）である。
  右ねじの法則より、点 $B(d, 0)$ での磁場 $\vec{B}_O$ は $+y$ 方向を向く。
  その大きさは：
  $$B_O = \frac{\mu_0 I}{2\pi d}$$
- 点 $B$ での合成磁場が $O$ から $B$ に向かう向き（$+x$ 方向）になるためには、導線 $A$ による磁場 $\vec{B}_A$ の $y$ 成分が $\vec{B}_O$ を完全に打ち消さなければならない（すなわち $B_{A, y} = -B_O$）。
- 導線 $A$ は $(0, d)$ にあり、点 $B(d, 0)$ までの距離は $\sqrt{d^2 + d^2} = \sqrt{2}d$ である。
  $\vec{B}_A$ は線分 $AB$ に垂直である。
  $y$ 成分が負（下向き）になるためには、右ねじの法則より導線 $A$ の電流は**紙面表から裏の向き**（時計回りの磁場）でなければならない。
- このとき、線分 $AB$ と $x$ 軸のなす角は $45^\circ$ であるから、垂直な $\vec{B}_A$ の $y$ 成分の大きさは：
  $$B_{A, y} = B_A \cos 45^\circ = \frac{\mu_0 I_A}{2\pi (\sqrt{2}d)} \cdot \frac{1}{\sqrt{2}} = \frac{\mu_0 I_A}{4\pi d}$$
つり合いの条件 $B_{A, y} = B_O$ より：
$$\frac{\mu_0 I_A}{4\pi d} = \frac{\mu_0 I}{2\pi d} \implies I_A = 2I$$
また、このとき $\vec{B}_A$ の $x$ 成分は $+x$ 方向（$O$ から $B$ へ）を向くため、合成磁場全体も正しく $O$ から $B$ へ向かう。
したがって、電流の向きは「紙面表から裏の向き」、大きさは「$2I$」である。
これは選択肢 $\textcircled{2}$ に一致する。

**【考査考点】**
直線電流による磁場の向き（右ねじの法則）と大きさの公式、磁場ベクトルの成分分解と重ね合わせの原理。

## 問17：磁場中の長方形コイルに働く偶力のモーメントの計算
- **問題番号**：問17
- **公式正解**：選択肢 $\textcircled{2}$
- **重要論点**：
  - 磁場が電流に及ぼすアンペール力（電磁気力） F = I L B の計算
  - コイル平面の傾きに伴う偶力の腕の長さ d = b cos 60° の幾何的特定
  - 偶力のモーメント M = F d = I S B sin θ の厳密な算出

**【題目大意】**
辺 $ab = 0.30\text{ m}$、辺 $bc = 0.20\text{ m}$ の長方形コイルに電流 $I = 5.0\text{ A}$ が流れている。磁束密度 $B = 4.0\text{ T}$ の一様磁場中にコイルを置き、辺 $ab, cd$ が磁場に垂直で、辺 $da, bc$ が磁場と $60^\circ$ の角をなすように保持したとき、コイルに働く偶力のモーメントの大きさを求める。

**【公式正解】**
選択肢 $\textcircled{2}$ ($0.60\text{ N}\cdot\text{m}$)

**【詳細推導・解答プロセス】**
磁場に垂直な辺 $ab$ および辺 $cd$（長さ $L = 0.30\text{ m}$）に働く電磁気力 $F$ を考える。
電流と磁場は互いに直交しているため、各辺に働く力の大きさは：
$$F = I L B = 5.0 \times 0.30 \times 4.0 = 6.0\text{ N}$$
フレミングの左手の法則より、辺 $ab$ と辺 $cd$ に働く力は互いに逆向きであり、偶力を形成する。

偶力のモーメント $M$ の計算：
2つの平行な力の作用線の間の垂直距離（腕の長さ）を $d$ とする。
辺 $bc$（長さ $b = 0.20\text{ m}$）は磁場と $60^\circ$ の角をなしており、力 $F$ は磁場に垂直な方向に働いている。
したがって、作用線間の距離は：
$$d = b \cos 60^\circ = 0.20 \times \frac{1}{2} = 0.10\text{ m}$$
偶力のモーメントの大きさは：
$$M = F \times d = 6.0\text{ N} \times 0.10\text{ m} = 0.60\text{ N}\cdot\text{m}$$

（別解：公式 $M = I S B \cos\theta = I S B \sin\phi$ の適用）
コイルの面積 $S = 0.30 \times 0.20 = 0.060\text{ m}^2$。
コイルの法線と磁場のなす角を $\phi$ とすると、$\phi = 90^\circ - 60^\circ = 30^\circ$ である。
$$M = I S B \sin 30^\circ = 5.0 \times 0.060 \times 4.0 \times \frac{1}{2} = 0.60\text{ N}\cdot\text{m}$$
これは選択肢 $\textcircled{2}$ に一致する。

**【考査考点】**
電流が磁場から受ける力 $F = I L B$、コイルに働く偶力のモーメントの幾何学的幾何展開と計算公式。

## 問18：レンツの法則とソレノイドを通過する棒磁石の電磁誘導
- **問題番号**：問18
- **公式正解**：選択肢 $\textcircled{2}$
- **重要論点**：
  - レンツの法則による磁束変化を妨げる向きの誘導起電力の発生
  - N極接近時とS極離脱時におけるソレノイド内磁束の変化の符号判定
  - 回路図における抵抗を流れる誘導電流の向きの判定

**【題目大意】**
抵抗が接続された固定ソレノイドの中心軸に沿って、N極を下にした棒磁石を鉛直上から落下させる。棒磁石のN極がソレノイド上端を通過する直前、およびS極がソレノイド下端を通過した直後に抵抗を流れる電流の向き（a または b）を判定する。

**【公式正解】**
選択肢 $\textcircled{2}$ (通過直前：a、通過直後：b)

**【詳細推導・解答プロセス】**
レンツの法則「誘導起電力は磁束の変化を妨げる向きに生じる」を適用する。
1. **N極がソレノイド上端を通過する直前**：
   N極が下を向いて落下して近づくため、ソレノイド内を下向きに貫く磁束が増加する。
   これを妨げるため、ソレノイドには**上向きの磁界**を生じさせる向きに誘導電流が流れる。
   右ねじの法則をソレノイドの巻き線に適用すると、ソレノイドの端子から回路の抵抗へと流れる電流の向きは図の矢印 **a** となる。
2. **S極がソレノイド下端を通過した直後**：
   棒磁石はソレノイドから下へ遠ざかっていく。磁石内部から出る磁力線はS極に入っていくため、ソレノイド内を下向きに貫く磁束が減少する。
   これを補うため、ソレノイドには**下向きの磁界**を生じさせる向きに誘導電流が流れる。
   この向きは接近時と逆であるから、抵抗を流れる電流の向きは図の矢印 **b** となる。
したがって、正しい組み合わせは「通過直前：a、通過直後：b」であり、選択肢 $\textcircled{2}$ に一致する。

**【考査考点】**
ファラデーの電磁誘導の法則、レンツの法則による誘導電流の向きの決定、ソレノイドの巻き方と回路電流の経路追跡。

## 問19：新元素ニホニウムのα崩壊系列と放出α粒子数
- **問題番号**：問19
- **公式正解**：選択肢 $\textcircled{5}$
- **重要論点**：
  - α崩壊における原子番号の変化（ΔZ = -2）と質量数の変化（ΔA = -4）
  - ニホニウム（Nh, Z=113）からメンデレビウム（Md, Z=101）への崩壊過程
  - 原子番号の差によるα粒子放出数の定量的計算

**【題目大意】**
日本で合成が確認された原子番号 113 の新元素ニホニウム（Nh）の原子核が、$\alpha$ 崩壊のみを複数回繰り返して原子番号 101 のメンデレビウム（Md）の原子核に変わるまでに放出される $\alpha$ 粒子の総数を求める。

**【公式正解】**
選択肢 $\textcircled{5}$ ($6$ 個)

**【詳細推導・解答プロセス】**
$\alpha$ 粒子はヘリウムの原子核 $_2^4\text{He}$ である。
原子核が 1 回 $\alpha$ 崩壊を起こすと：
- 原子番号（陽子数、電荷数）は $2$ 減少する。
- 質量数は $4$ 減少する。
問題の設定では、ニホニウム（Nh, $Z = 113$）からメンデレビウム（Md, $Z = 101$）への変化は「$\alpha$ 崩壊のみ」を繰り返すことによって起こる。
崩壊前後の原子番号の変化量 $\Delta Z$ は：
$$\Delta Z = 113 - 101 = 12$$
1回の $\alpha$ 崩壊で原子番号が 2 減少するから、起こった $\alpha$ 崩壊の回数（放出された $\alpha$ 粒子の個数 $N$）は：
$$N = \frac{\Delta Z}{2} = \frac{12}{2} = 6$$
したがって、全部で 6 個の $\alpha$ 粒子が放出される。
これは選択肢 $\textcircled{5}$ に一致する。

**【考査考点】**
放射性崩壊の種類、$\alpha$ 崩壊における原子番号と質量数の保存則、崩壊系列における粒子放出数の算出。
