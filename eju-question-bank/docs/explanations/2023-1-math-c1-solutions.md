## 第I問 問1：2次関数の交点条件・最大値と最小値の差

**【考査考点】**：2次関数の交点条件と代数連立方程式, 平方完成による頂点座標と極値（最大値・最小値）の決定, 代数方程式による係数消元と二次方程式の解法

### 【第I問 問1】詳細解答と解説

#### (1) グラフの交点条件による関係式の導出
与えられた2つの2次関数は
$$f(x) = \frac{1}{3}x^2 + ax - b, \quad g(x) = -x^2 + cx + b$$
条件(A)より、$y = f(x)$ と $y = g(x)$ は 2 直線 $x = -1, x = 3$ 上で交わるため、$f(-1) = g(-1)$ かつ $f(3) = g(3)$ が成り立つ。

1. **$x = -1$ での交点条件**：
$$f(-1) = \frac{1}{3}(-1)^2 + a(-1) - b = \frac{1}{3} - a - b$$
$$g(-1) = -(-1)^2 + c(-1) + b = -1 - c + b$$
これらが等しいので：
$$\frac{1}{3} - a - b = -1 - c + b \implies a + 2b - c = \frac{4}{3}$$
両辺に 3 を掛けて整数係数に整理すると：
$$3a + 6b - 3c = 4 \quad \cdots \textcircled{1}$$
問題文の形式 $3a + \text{A}b - \text{B}c = \text{C}$ と比較して：
$$\mathbf{A = 6, B = 3, C = 4} \implies \mathbf{ABC = 634}$$

2. **$x = 3$ での交点条件**：
$$f(3) = \frac{1}{3}(3)^2 + a(3) - b = 3 + 3a - b$$
$$g(3) = -(3)^2 + c(3) + b = -9 + 3c + b$$
これらが等しいので：
$$3 + 3a - b = -9 + 3c + b \implies 3a - 2b - 3c = -12 \quad \cdots \textcircled{2}$$
問題文の形式 $\text{D}a - 2b - \text{E}c = -12$ と比較して：
$$\mathbf{D = 3, E = 3} \implies \mathbf{DE = 33}$$

3. **定数 $b$ の決定**：
$\textcircled{1} - \textcircled{2}$ を計算すると、$a$ と $c$ の項が同時に消去される：
$$(3a + 6b - 3c) - (3a - 2b - 3c) = 4 - (-12)$$
$$8b = 16 \implies b = 2$$
よって、$\mathbf{F = 2}$。

#### (2) 最大値と最小値の差から $a, c$ の決定
$b = 2$ を各関数に代入し、平方完成を行う：
- $g(x) = -x^2 + cx + 2 = -\left(x - \frac{c}{2}\right)^2 + \frac{c^2}{4} + 2$
  上に凸の放物線であるから、最大値は $\frac{c^2}{4} + 2$。
- $f(x) = \frac{1}{3}x^2 + ax - 2 = \frac{1}{3}\left(x^2 + 3ax\right) - 2 = \frac{1}{3}\left(x + \frac{3}{2}a\right)^2 - \frac{3}{4}a^2 - 2$
  下に凸の放物線であるから、最小値は $-\frac{3}{4}a^2 - 2$。

条件(B)「$g(x)$ の最大値と $f(x)$ の最小値の差が $\frac{16}{3}$」より：
$$\left(\frac{c^2}{4} + 2\right) - \left(-\frac{3}{4}a^2 - 2\right) = \frac{16}{3}$$
$$\frac{3}{4}a^2 + \frac{c^2}{4} + 4 = \frac{16}{3}$$
両辺に 12 を掛けると：
$$9a^2 + 3c^2 + 48 = 64 \implies 9a^2 + 3c^2 = 16$$
問題文の形式 $\text{G}a^2 + 3c^2 = \text{HI}$ と比較して：
$$\mathbf{G = 9, HI = 16} \implies \mathbf{GHI = 916}$$

さらに、$b = 2$ を $\textcircled{1}$ に代入すると：
$$3a + 12 - 3c = 4 \implies 3a - 3c = -8 \implies a = c - \frac{8}{3}$$
これを $9a^2 + 3c^2 = 16$ に代入する：
$$9\left(c - \frac{8}{3}\right)^2 + 3c^2 = 16$$
$$9\left(c^2 - \frac{16}{3}c + \frac{64}{9}\right) + 3c^2 = 16$$
$$9c^2 - 48c + 64 + 3c^2 = 16 \implies 12c^2 - 48c + 48 = 0$$
両辺を 12 で割ると：
$$c^2 - 4c + 4 = 0 \implies (c - 2)^2 = 0 \implies c = 2$$
したがって：
$$a = c - \frac{8}{3} = 2 - \frac{8}{3} = -\frac{2}{3}$$
問題文の形式 $a = -\frac{\text{J}}{\text{K}}, c = \text{L}$ より：
$$\mathbf{J = 2, K = 3} \implies \mathbf{JK = 23}, \quad \mathbf{L = 2}$$

**【解法テクニック・易錯点】**
- $x = -1$ と $x = 3$ の 2 点での条件式を作った際、引き算により $a$ と $c$ の係数が同じ比率（$3: -3$）になっていることに気付けば、直ちに $b$ が一発で求まります。
- $f(x)$ の平方完成時に、二次の係数が $\frac{1}{3}$ であるため、$\frac{1}{3}(x^2 + 3ax)$ と括り出した後の半分 $\frac{3}{2}a$ の二乗展開で係数ミスをしないよう注意しましょう。

## 第I問 問2：カードの抽出確率・条件付き不等式と余事象

**【考査考点】**：同様に確からしい事象と独立抽出の積の法則, 不等式制約条件 $a > 2b > 3c$ を満たす整数の組の分類探索, 奇数・偶数の組合せ確率と余事象の活用

### 【第I問 問2】詳細解答と解説

#### (1) 箱 A, B, C から各 1 枚取り出す試行
3つの箱 A, B, C にはそれぞれ 1 から 9 のカードが 9 枚入っている。
各箱から 1 枚ずつ取り出す事象の全事象の総数は：
$$N = 9 \times 9 \times 9 = 729$$

**(i) $a = b \neq c$ である確率**
- $a$ と $b$ の共通の数値を 1 ～ 9 の中から選ぶ方法は 9 通り。
- $c$ は $a$（$= b$）と異なる数値を選ぶので、残り $9 - 1 = 8$ 通り。
条件を満たす取り出し方の総数は $9 \times 8 = 72$ 通り。
求める確率は：
$$\frac{72}{729} = \frac{8}{81}$$
選択肢一覧より、$\textcircled{0}$ が $\frac{8}{81}$ に該当する。
よって、$\mathbf{M = 0}$。

**(ii) $a, b, c$ の中に同じものがない（すべて異なる）確率**
- $a$ の選び方は 9 通り。
- $b$ の選び方は $a$ 以外の 8 通り。
- $c$ の選び方は $a, b$ 以外の 7 通り。
総数は $9 \times 8 \times 7 = 504$ 通り。
求める確率は：
$$\frac{504}{729} = \frac{56}{81}$$
選択肢一覧より、$\textcircled{2}$ が $\frac{56}{81}$ に該当する。
よって、$\mathbf{N = 2}$。

**(iii) $a > 2b > 3c$ となる確率 $p$**
$a, b, c$ は 1 から 9 の整数である。
- $a \le 9$ より、$2b < a \le 9 \implies 2b \le 8 \implies b \le 4$。
- $c \ge 1$ より、$2b > 3c \ge 3 \implies 2b \ge 4 \implies b \ge 2$。
したがって、条件を満たす組が存在する $b$ の範囲は：
$$2 \le b \le 4$$
よって、$\mathbf{O = 2, P = 4} \implies \mathbf{OP = 24}$。

$b$ の値ごとに $(a, c)$ の組を数え上げる：
1. **$b = 2$ のとき**：
   $2b = 4$。不等式は $a > 4 > 3c$。
   - $3c < 4 \implies c = 1$（1通り）
   - $a > 4 \implies a \in \{5, 6, 7, 8, 9\}$（5通り）
   組の数は $5 \times 1 = 5$ 通り。
2. **$b = 3$ のとき**：
   $2b = 6$。不等式は $a > 6 > 3c$。
   - $3c < 6 \implies c = 1$（1通り）
   - $a > 6 \implies a \in \{7, 8, 9\}$（3通り）
   組の数は $3 \times 1 = 3$ 通り。
3. **$b = 4$ のとき**：
   $2b = 8$。不等式は $a > 8 > 3c$。
   - $3c < 8 \implies c \in \{1, 2\}$（2通り）
   - $a > 8 \implies a = 9$（1通り）
   組の数は $1 \times 2 = 2$ 通り。

以上より、条件を満たす組の総数は $5 + 3 + 2 = 10$ 通り。
したがって、確率 $p$ は：
$$p = \frac{10}{729}$$
選択肢一覧より、$\textcircled{9}$ が $\frac{10}{729}$ に該当する。
よって、$\mathbf{Q = 9}$。

#### (2) A から 3 枚、B から 2 枚、計 5 枚を取り出す試行
各箱のカード 9 枚のうち、奇数は $\{1, 3, 5, 7, 9\}$ の 5 枚、偶数は $\{2, 4, 6, 8\}$ の 4 枚である。
取り出し方の全事象の総数は：
$$N = \binom{9}{3} \times \binom{9}{2} = \frac{9 \times 8 \times 7}{3 \times 2 \times 1} \times \frac{9 \times 8}{2 \times 1} = 84 \times 36 = 3024$$

**(i) 奇数が 4 枚、偶数が 1 枚である確率**
5枚の内訳として、次の 2 つの排反な場合がある：
- **Case 1: A から奇数 3 枚、B から奇数 1 枚・偶数 1 枚**
  $$\binom{5}{3} \times \left(\binom{5}{1} \times \binom{4}{1}\right) = 10 \times (5 \times 4) = 10 \times 20 = 200 \text{ 通り}$$
- **Case 2: A から奇数 2 枚・偶数 1 枚、B から奇数 2 枚**
  $$\left(\binom{5}{2} \times \binom{4}{1}\right) \times \binom{5}{2} = (10 \times 4) \times 10 = 40 \times 10 = 400 \text{ 通り}$$
条件を満たす場合の数は $200 + 400 = 600$ 通り。
求める確率は：
$$\frac{600}{3024} = \frac{25}{126}$$
選択肢一覧より、$\textcircled{4}$ が $\frac{25}{126}$ に該当する。
よって、$\mathbf{R = 4}$。

**(ii) 奇数が少なくとも 1 枚ある確率**
余事象「5枚すべてが偶数である」を考える。
A から偶数 3 枚、B から偶数 2 枚を取り出す方法は：
$$\binom{4}{3} \times \binom{4}{2} = 4 \times 6 = 24 \text{ 通り}$$
余事象の確率は：
$$\frac{24}{3024} = \frac{1}{126}$$
したがって、求める確率は余事象を用いて：
$$1 - \frac{1}{126} = \frac{125}{126}$$
選択肢一覧より、$\textcircled{7}$ が $\frac{125}{126}$ に該当する。
よって、$\mathbf{S = 7}$。

## 第II問 問1：2変数多項式の因数分解と有理数条件

**【考査考点】**：多変数の2次式の因数分解（双たすき掛け）, 共役根・対称式による式の簡略計算（$x-z, x+z$）, 無理数の有理化条件と有理数係数の決定

### 【第II問 問1】詳細解答と解説

#### (1) 式 $P$ の因数分解
与えられた多項式は：
$$P = 2x^2 + 12y^2 - 2z^2 - 11xy + 5yz$$

1. **$x$ を含まない項の因数分解**：
$$12y^2 + 5yz - 2z^2$$
たすき掛けにより：
$$12y^2 + 5yz - 2z^2 = (4y - z)(3y + 2z)$$
問題文の形式 $(Ay - z)(By + Cz)$ と比較して：
$$\mathbf{A = 4, B = 3, C = 2} \implies \mathbf{ABC = 432}$$

2. **$P$ 全体の因数分解**：
$P$ を $x$ の2次式として整理する：
$$P = 2x^2 - 11xy + (4y - z)(3y + 2z)$$
定数項の各因数に負号をつけてたすき掛けを行う：
- $1 \times (-(3y + 2z)) + 2 \times (-(4y - z)) = -3y - 2z - 8y + 2z = -11y$
$z$ の項が見事に相殺し、1次の係数 $-11y$ に一致する。
したがって、$P$ は次のように因数分解される：
$$P = (x - (4y - z))(2x - (3y + 2z)) = (x - 4y + z)(2x - 3y - 2z)$$
選択肢一覧より、$\textcircled{1}$「$(x - 4y + z)(2x - 3y - 2z)$」が適する。
よって、$\mathbf{D = 1}$。

#### (2) 数値代入と有理数条件の適用
$x = 3 + \sqrt{5}, z = -3 + \sqrt{5}$ より：
- $x - z = (3 + \sqrt{5}) - (-3 + \sqrt{5}) = 6$。
  よって、$\mathbf{E = 6}$。
- $x + z = (3 + \sqrt{5}) + (-3 + \sqrt{5}) = 2\sqrt{5}$。
  問題文の形式 $F\sqrt{G}$ より、$\mathbf{F = 2, G = 5} \implies \mathbf{FG = 25}$。

これらを因数分解された各項に適用する：
1. **第 1 因数**：
   $$x - 4y + z = (x + z) - 4y = 2\sqrt{5} - 4(a + \sqrt{5}) = -4a - 2\sqrt{5} = -2(2a + \sqrt{5})$$
2. **第 2 因数**：
   $$2x - 3y - 2z = 2(x - z) - 3y = 2(6) - 3(a + \sqrt{5}) = 12 - 3a - 3\sqrt{5} = -3(a - 4 + \sqrt{5})$$

これらを掛け合わせると：
$$P = [-2(2a + \sqrt{5})] \times [-3(a - 4 + \sqrt{5})] = 6(2a + \sqrt{5})(a - 4 + \sqrt{5})$$
問題文の形式 $P = H(Ia + \sqrt{5})(a - J + \sqrt{5})$ と比較して：
$$\mathbf{H = 6, I = 2, J = 4} \implies \mathbf{HIJ = 624}$$

右辺を展開して $\sqrt{5}$ について整理する：
$$(2a + \sqrt{5})(a - 4 + \sqrt{5}) = 2a(a - 4) + 2a\sqrt{5} + (a - 4)\sqrt{5} + 5$$
$$= (2a^2 - 8a + 5) + (3a - 4)\sqrt{5}$$
$$P = 6(2a^2 - 8a + 5) + 6(3a - 4)\sqrt{5}$$
$a$ は有理数であるため、$P$ が有理数となるための必要十分条件は、無理数 $\sqrt{5}$ の係数が 0 となることである：
$$3a - 4 = 0 \implies a = \frac{4}{3}$$
問題文の形式 $a = \frac{\text{K}}{\text{L}}$ より：
$$\mathbf{K = 4, L = 3} \implies \mathbf{KL = 43}$$

**【解法テクニック・易錯点】**
- $x$ と $z$ は互いに有理部が符号違いで無理部が共通であるため、$x-z$ は有理数となり、$x+z$ は純粋な根号項となります。この対称性を利用して因数を $(x+z)-4y$ や $2(x-z)-3y$ と組み替えることで、複雑な根号計算を完全に回避できます。

## 第II問 問2：2次方程式の実数解条件と二次関数の最小値の分類討議

**【考査考点】**：判別式 $D \ge 0$ による実数解条件, 動く軸 $a = 2b$ と非連結定義域における2次関数の最小値の分類, すべての $a$ に対して成立するパラメータ $b$ の不等式評価

### 【第II問 問2】詳細解答と解説

#### (1) 方程式 $\textcircled{1}$ が実数解をもつ条件
方程式 $\textcircled{1}$ は $x^2 + (a - 1)x - a + 1 = 0$。
実数解をもつための判別式 $D_1 \ge 0$：
$$D_1 = (a - 1)^2 - 4(1)(-a + 1) = a^2 - 2a + 1 + 4a - 4 = a^2 + 2a - 3 \ge 0$$
選択肢一覧より、$\textcircled{1}$「$a^2 + 2a - 3$」が適する。
よって、$\mathbf{M = 1}$。

2次不等式を解くと：
$$(a + 3)(a - 1) \ge 0 \implies a \le -3, \quad 1 \le a$$
選択肢一覧より、$\textcircled{7}$「$a \le -3, 1 \le a$」が適する。
よって、$\mathbf{N = 7}$。

#### (2) 条件を満たす $b$ の範囲の決定
方程式 $\textcircled{2}$ は $4x^2 - 4ax + 4ab - 1 = 0$。
実数解をもつための判別式 $D_2 \ge 0$：
$$\frac{D_2}{4} = (-2a)^2 - 4(4ab - 1) = 4a^2 - 16ab + 4 \ge 0$$
両辺を 4 で割ると：
$$a^2 - 4ab + 1 \ge 0$$
選択肢一覧より、$\textcircled{3}$「$a^2 - 4ab + 1$」が適する。
よって、$\mathbf{O = 3}$。

$f(a) = a^2 - 4ab + 1$ を $a$ の2次関数とみて平方完成する：
$$f(a) = (a - 2b)^2 - 4b^2 + 1$$
選択肢一覧より、$\textcircled{8}$「$(a - 2b)^2 - 4b^2 + 1$」が適する。
よって、$\mathbf{P = 8}$。

#### (3) 範囲 $N$（$a \le -3$ または $a \ge 1$）における $f(a)$ の最小値 $m$ の分類討議
放物線 $y = f(a)$ は下に凸で、軸の方程式は $a = 2b$、頂点の $y$ 座標は $-4b^2 + 1$ である。
定義域 $N = (-\infty, -3] \cup [1, \infty)$ の外側にある区間 $(-3, 1)$ の中点は $\frac{-3 + 1}{2} = -1$ である。

1. **軸が $a \le -3$ の領域にあるとき（$2b \le -3 \iff b \le -\frac{3}{2}$）**：
   頂点が定義域 $N$ 内に含まれるため、最小値は頂点でとる：
   $$m = f(2b) = -4b^2 + 1$$
   $b \le Q$ の $Q$ は $-\frac{3}{2}$（$\textcircled{1}$）、$m = R$ の $R$ は $-4b^2 + 1$（$\textcircled{9}$）。
   よって、$\mathbf{Q = 1, R = 9}$。

2. **軸が $-3 < 2b \le -1$ にあるとき（$-\frac{3}{2} < b \le -\frac{1}{2}$）**：
   軸は定義域外 $(-3, 1)$ にあり、中点 $-1$ より左側にあるため、$a = -3$ の方が $a = 1$ より軸に近い。
   したがって、最小値は $a = -3$ でとる：
   $$m = f(-3) = (-3)^2 - 4(-3)b + 1 = 9 + 12b + 1 = 12b + 10$$
   $Q < b \le S$ の $S$ は $-\frac{1}{2}$（$\textcircled{3}$）、$m = T$ の $T$ は $12b + 10$（$\textcircled{7}$）。
   よって、$\mathbf{S = 3, T = 7}$。

3. **軸が $-1 < 2b < 1$ にあるとき（$-\frac{1}{2} < b < \frac{1}{2}$）**：
   軸は定義域外 $(-3, 1)$ にあり、中点 $-1$ より右側にあるため、$a = 1$ の方が軸に近い。
   したがって、最小値は $a = 1$ でとる：
   $$m = f(1) = 1^2 - 4(1)b + 1 = -4b + 2$$
   $S < b \le U$ の $U$ は $\frac{1}{2}$（$\textcircled{4}$）、$m = V$ の $V$ は $-4b + 2$（$\textcircled{5}$）。
   よって、$\mathbf{U = 4, V = 5}$。

4. **軸が $2b \ge 1$ の領域にあるとき（$b \ge \frac{1}{2}$）**：
   頂点が定義域 $N$ 内に含まれるため、最小値は頂点でとる：
   $$m = f(2b) = -4b^2 + 1$$
   $U < b$ のとき $m = W$ の $W$ は $-4b^2 + 1$（$\textcircled{9}$）。
   よって、$\mathbf{W = 9}$。

#### (4) [条件]「範囲 $N$ のすべての $a$ に対して $f(a) \ge 0$」を満たす $b$ の範囲
各区間において $m \ge 0$ となる条件を求める：
- $b \le -\frac{3}{2}$ のとき：$-4b^2 + 1 \ge 0 \implies b^2 \le \frac{1}{4} \implies -\frac{1}{2} \le b \le \frac{1}{2}$。$b \le -\frac{3}{2}$ との共通部分は存在しない（不適）。
- $-\frac{3}{2} < b \le -\frac{1}{2}$ のとき：$12b + 10 \ge 0 \implies b \ge -\frac{10}{12} = -\frac{5}{6}$。
  この区間での解は $-\frac{5}{6} \le b \le -\frac{1}{2}$。
- $-\frac{1}{2} < b \le \frac{1}{2}$ のとき：$-4b + 2 \ge 0 \implies b \le \frac{1}{2}$。
  この区間全体 $-\frac{1}{2} < b \le \frac{1}{2}$ で常に満たされる。
- $b > \frac{1}{2}$ のとき：$-4b^2 + 1 \ge 0 \implies b \le \frac{1}{2}$。$b > \frac{1}{2}$ との共通部分は存在しない（不適）。

これらを合わせると、求める $b$ の範囲は：
$$-\frac{5}{6} \le b \le \frac{1}{2}$$
選択肢一覧より、$-\frac{5}{6}$ は $\textcircled{2}$、$\frac{1}{2}$ は $\textcircled{4}$ に該当する。
よって、$\mathbf{X = 2, Y = 4}$。

## 第III問：特定数字を除外した自然数の個数・位取り記数法・倍数の判定

**【考査考点】**：特定数字を除外した整数の集合と 7 進法・5 進法によるモデル化, 位取り記数法（基底変換）による第 $n$ 項の辞書順探索, 9の倍数の判定法（各桁の和）と 18 の倍数（偶数条件）の絞り込み

### 【第III問】詳細解答と解説

全体集合 $U = \{1, 2, \dots, 999\}$（$|U| = 999$）。
各数を 3 桁の表記 $d_1 d_2 d_3$（$d_1, d_2, d_3 \in \{0, 1, \dots, 9\}$）とし、$000$ を除いたものと対応付ける。

#### (1) 集合の要素数の決定
1. **集合 $A$ の要素数**：
   7, 8, 9 を使わない数の集合であるから、使用可能な数字は $\{0, 1, 2, 3, 4, 5, 6\}$ の 7 種類。
   3桁の組み合わせから $000$ を除くと：
   $$|A| = 7^3 - 1 = 343 - 1 = 342$$
   よって、$\mathbf{ABC = 342}$。

2. **共通部分 $A \cap B$ の要素数**：
   $B$ は 3, 6, 9 を使わない集合であるから、$A \cap B$ は $\{3, 6, 7, 8, 9\}$ の 5 つを除外した集合。
   使用可能な数字は $\{0, 1, 2, 4, 5\}$ の 5 種類。
   $$|A \cap B| = 5^3 - 1 = 125 - 1 = 124$$
   よって、$\mathbf{DEF = 124}$。

3. **$\overline{A} \cap B$ の要素数**：
   $B$ の要素数は、使用可能数字 $\{0, 1, 2, 4, 5, 7, 8\}$（7種類）より：
   $$|B| = 7^3 - 1 = 343 - 1 = 342$$
   $\overline{A} \cap B = B \setminus (A \cap B)$ であるから：
   $$|\overline{A} \cap B| = |B| - |A \cap B| = 342 - 124 = 218$$
   よって、$\mathbf{GHI = 218}$。

#### (2) 160 番目の要素の決定（位取り記数法・7進法対応）
1. **$A$ の要素を小さい順に並べたときの 160 番目**：
   $A$ で使える数字は小さい順に $0, 1, 2, 3, 4, 5, 6$ であり、これは通常の 7 進法の数字と完全に一致する。
   160 を 7 進法で表記する：
   $$160 = 22 \times 7 + 6$$
   $$22 = 3 \times 7 + 1$$
   $$3 = 0 \times 7 + 3$$
   したがって、$160 = 316_{(7)}$。
   数字の対応はそのままなので、求める数は **316** である。
   よって、$\mathbf{JKL = 316}$。

2. **$B$ の要素を小さい順に並べたときの 160 番目**：
   $B$ で使える数字を小さい順に並べると、7進数の各桁と次のように対応する：
   $$0 \leftrightarrow 0, \quad 1 \leftrightarrow 1, \quad 2 \leftrightarrow 2, \quad 3 \leftrightarrow 4, \quad 4 \leftrightarrow 5, \quad 5 \leftrightarrow 7, \quad 6 \leftrightarrow 8$$
   160 番目の 7 進表記は $316_{(7)}$ である。
   各桁の数字を変換する：
   - 百の位：3 は **4** に対応
   - 十の位：1 は **1** に対応
   - 一の位：6 は **8** に対応
   したがって、求める数は **418** である。
   よって、$\mathbf{MNO = 418}$。

#### (3) $B$ に属する 9 の倍数・18 の倍数
$B$ の使用可能数字は $\{0, 1, 2, 4, 5, 7, 8\}$（3, 6, 9 は使えない）。
整数の各桁の和が 9 の倍数であることが、9 の倍数であるための必要十分条件である。

1. **2 番目に大きい 9 の倍数**：
   最も大きい 3 桁の数から探すため、百の位を最大の 8 とする。
   $8 + d_2 + d_3$ が 9 の倍数（9 または 18、最大 $8+8+8=24$ なので 27 は不可）：
   - 和が 18 のとき：$d_2 + d_3 = 10$。
     $d_2$ を大きい順に探す：
     - $d_2 = 8 \implies d_3 = 2 \implies \mathbf{882}$（最大の 9 の倍数）
     - $d_2 = 7 \implies d_3 = 3$（3 は使用不可）
     - $d_2 = 5 \implies d_3 = 5 \implies \mathbf{855}$（2 番目に大きい 9 の倍数）
   よって、2 番目に大きい 9 の倍数は **855** である。
   したがって、$\mathbf{PQR = 855}$。

2. **2 番目に小さい 18 の倍数**：
   18 の倍数は「9 の倍数」かつ「偶数（一の位 $d_3 \in \{0, 2, 4, 8\}$）」である。
   小さい方から探すため、百の位を最小の 1 とする。
   $1 + d_2 + d_3$ が 9 の倍数（9 または 18）：
   - 和が 9 のとき：$d_2 + d_3 = 8$。
     $d_3$ は偶数 $\{0, 2, 4, 8\}$：
     - $d_3 = 8 \implies d_2 = 0 \implies \mathbf{108}$（偶数、18の倍数）
     - $d_3 = 4 \implies d_2 = 4 \implies \mathbf{144}$（偶数、18の倍数）
     - $d_3 = 2 \implies d_2 = 6$（6 は使用不可）
     - $d_3 = 0 \implies d_2 = 8 \implies \mathbf{180}$（偶数、18の倍数）
   百の位が 1 のときの 18 の倍数は小さい順に $108, 144, 180$ となる。
   したがって、2 番目に小さい 18 の倍数は **144** である。
   よって、$\mathbf{STU = 144}$。

## 第IV問：円に内接する五角形・正弦定理・余弦定理と面積

**【考査考点】**：余弦定理による対角線長の計算と正弦定理による外接円半径の決定, 円周角の定理と同一円弧に対する弦の長さの等価性, 円に内接する四角形の対角の和（$180^\circ$）と2次方程式による線分長決定, 三角形の分割による多角形の求積公式（$\frac{1}{2}ab\sin\theta$）

### 【第IV問】詳細解答と解説

円 $O$ に内接する五角形 $ABCDE$ において：
$$AB = \sqrt{3}, \quad BC = 4, \quad DE = \sqrt{7}, \quad EA = 1, \quad \angle EAB = 150^\circ$$

#### (1) 線分 $EB$ の長さと円 $O$ の半径
$\triangle EAB$ において余弦定理を適用する：
$$EB^2 = EA^2 + AB^2 - 2 \cdot EA \cdot AB \cos 150^\circ$$
$$EB^2 = 1^2 + (\sqrt{3})^2 - 2(1)(\sqrt{3})\left(-\frac{\sqrt{3}}{2}\right) = 1 + 3 + 3 = 7$$
$EB > 0$ より：
$$EB = \sqrt{7}$$
よって、$\mathbf{A = 7}$。

$\triangle EAB$ の外接円は五角形の外接円 $O$ そのものである。
正弦定理より、外接円の半径を $R$ とすると：
$$\frac{EB}{\sin 150^\circ} = 2R \implies 2R = \frac{\sqrt{7}}{\frac{1}{2}} = 2\sqrt{7} \implies R = \sqrt{7}$$
したがって、円 $O$ の半径は $\sqrt{7}$ である。
よって、$\mathbf{B = 7}$。

#### (2) $\triangle BDE$ の角と線分 $BD$ の長さ
与えられた条件より $DE = \sqrt{7}$ であり、(1) より $EB = \sqrt{7}$ である。
弦の長さが等しいことから、対応する円周角も等しく、$\triangle BDE$ は $DE = EB = \sqrt{7}$ の二等辺三角形である。
正弦定理より：
$$\frac{EB}{\sin \angle BDE} = 2R = 2\sqrt{7} \implies \sin \angle BDE = \frac{\sqrt{7}}{2\sqrt{7}} = \frac{1}{2}$$
図より明らかに鋭角であるから、$\angle BDE = 30^\circ$。
よって、$\mathbf{CD = 30}$。

二等辺三角形であるから $\angle EBD = \angle BDE = 30^\circ$。
したがって、頂角 $\angle DEB$ は：
$$\angle DEB = 180^\circ - 30^\circ - 30^\circ = 120^\circ$$
よって、$\mathbf{EFG = 120}$。

再び正弦定理（または余弦定理）より $BD$ の長さを求める：
$$\frac{BD}{\sin 120^\circ} = 2R = 2\sqrt{7} \implies BD = 2\sqrt{7} \sin 120^\circ = 2\sqrt{7} \times \frac{\sqrt{3}}{2} = \sqrt{21}$$
よって、$\mathbf{HI = 21}$。

#### (3) $\angle BCD$ と辺 $CD$ の長さ
四角形 $BCDE$ は円 $O$ に内接する四角形である。
円に内接する四角形の対角の和は $180^\circ$ であるから：
$$\angle BCD + \angle DEB = 180^\circ \implies \angle BCD = 180^\circ - 120^\circ = 60^\circ$$
よって、$\mathbf{JK = 60}$。

$\triangle BCD$ において、$CD = x$ とおき、余弦定理を適用する：
$$BD^2 = BC^2 + CD^2 - 2 \cdot BC \cdot CD \cos 60^\circ$$
$$21 = 4^2 + x^2 - 2(4)(x)\left(\frac{1}{2}\right)$$
$$21 = 16 + x^2 - 4x \implies x^2 - 4x - 5 = 0$$
問題文の形式 $x^2 - Lx - M = 0$ と比較して：
$$\mathbf{L = 4, M = 5} \implies \mathbf{LM = 45}$$

2次方程式を解くと：
$$(x - 5)(x + 1) = 0$$
$x > 0$ であるから、$x = 5$。
よって、$\mathbf{N = 5}$。

#### (4) 五角形 $ABCDE$ の面積
五角形 $ABCDE$ の面積 $S$ は、3つの三角形 $\triangle EAB, \triangle BDE, \triangle BCD$ の面積の和に等しい：
1. **$S_1 = S(\triangle EAB)$**：
   $$S_1 = \frac{1}{2} \cdot EA \cdot AB \sin 150^\circ = \frac{1}{2} \times 1 \times \sqrt{3} \times \frac{1}{2} = \frac{\sqrt{3}}{4}$$
2. **$S_2 = S(\triangle BDE)$**：
   $$S_2 = \frac{1}{2} \cdot EB \cdot DE \sin 120^\circ = \frac{1}{2} \times \sqrt{7} \times \sqrt{7} \times \frac{\sqrt{3}}{2} = \frac{7\sqrt{3}}{4}$$
3. **$S_3 = S(\triangle BCD)$**：
   $$S_3 = \frac{1}{2} \cdot BC \cdot CD \sin 60^\circ = \frac{1}{2} \times 4 \times 5 \times \frac{\sqrt{3}}{2} = 5\sqrt{3} = \frac{20\sqrt{3}}{4}$$

合計面積 $S$ は：
$$S = S_1 + S_2 + S_3 = \frac{\sqrt{3} + 7\sqrt{3} + 20\sqrt{3}}{4} = \frac{28\sqrt{3}}{4} = 7\sqrt{3}$$
問題文の形式 $O\sqrt{P}$ と比較して：
$$\mathbf{O = 7, P = 3} \implies \mathbf{OP = 73}$$

**【解法テクニック・易錯点】**
- 五角形を 3 つの三角形に分割する際、共通の弦 $EB = \sqrt{7}$ と $BD = \sqrt{21}$ が各三角形の境界となり、既知の辺長と角のみで極めて明快に解くことができます。
