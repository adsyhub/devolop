## 問1：$^{40}\text{Ar}$ 原子の中性子数・電子数・最外殻電子数

**【考査考点】**：質量数＝陽子数＋中性子数, 原子番号と電子数の一致, アルゴン（希ガス）の最外殻電子数（8個）

**【題目大意】**
$^{40}\text{Ar}$（アルゴン-40）原子に含まれる、中性子の数、電子の数、および最外殻電子の数の組み合わせを選べ。

**【公式正解】**：$\textcircled{6}$（中性子数：22、電子数：18、最外殻電子数：8）

**【詳細推導・解答プロセス】**
アルゴン $\text{Ar}$ の原子番号は 18、質量数は 40 である。
1. **陽子数と電子数**：
   中性な原子において、電子の数は陽子数（原子番号）に等しい：
   $$\text{電子数} = 18$$
2. **中性子数**：
   質量数（陽子数＋中性子数）が 40 であるから：
   $$\text{中性子数} = 40 - 18 = 22$$
3. **最外殻電子数**：
   電子配置は K(2), L(8), M(8) である。したがって、最外殻である M 殻の電子数は：
   $$\text{最外殻電子数} = 8$$
   （※価電子数は希ガスのため 0 であるが、設問は「最外殻電子数」を問うているため 8 である）。
よって、正解は選択肢 $\textcircled{6}$ である。

## 問2：分子・多原子イオンに含まれる総電子数の比較

**【考査考点】**：分子およびイオンの構成原子の原子番号の和, イオンの電荷（価数）による電子数の増減加減算

**【題目大意】**

**【詳細推導・解答プロセス】**

## 問5：無声放電による酸素のオゾン化反応と物質量・体積変化の計算

**【考査考点】**：オゾン生成反応 $3\text{O}_2 \to 2\text{O}_3$, アボガドロの法則（同温・同圧での気体体積比＝物質量比）, 反応前後の体積減少量からのオゾン体積の算出

**【題目大意】**
$10.0\text{ L}$ の酸素 $\text{O}_2$ をオゾン発生器に通じたところ、同温同圧で $9.5\text{ L}$ の混合気体が得られた。
生成したオゾン $\text{O}_3$ の体積 [L] を求めよ。

**【公式正解】**：$\textcircled{2}$（$1.0\text{ L}$）

**【詳細推導・解答プロセス】**
1. **反応式の確認**：
   $$3\text{O}_2 \longrightarrow 2\text{O}_3$$
   酸素分子 3 体積が反応すると、オゾン分子 2 体積が生成し、全体として体積が 1 体積減少する。
2. **体積変化の追跡**：
   反応した酸素の体積を $3x\text{ [L]}$ とすると、生成するオゾンの体積は $2x\text{ [L]}$ である。
   反応後の混合気体の全体積は：
   $$V_{\text{after}} = (10.0 - 3x) + 2x = 10.0 - x$$
3. **数値の代入**：
   $$10.0 - x = 9.5 \implies x = 0.5\text{ L}$$
   したがって、生成したオゾンの体積は：
   $$V(\text{O}_3) = 2x = 2 \times 0.5\text{ L} = 1.0\text{ L}$$
よって、正解は選択肢 $\textcircled{2}$ である。

## 問6：気体の状態方程式と気体の密度からの分子量の決定

**【考査考点】**：気体の状態方程式 $pV = nRT = \frac{m}{M}RT$, 密度 $d = \frac{m}{V}$ と分子量 $M = \frac{dRT}{p}$ の関係

**【題目大意】**
ある気体の密度が $27^\circ\text{C}, 1.0 \times 10^5\text{ Pa}$ において $1.2\text{ g/L}$ であった。
この気体の分子量に最も近い値を求めよ（$R = 8.31 \times 10^3\text{ Pa}\cdot\text{L/(K}\cdot\text{mol)}$）。

**【公式正解】**：$\textcircled{3}$（30）

**【詳細推導・解答プロセス】**
1. **状態方程式からの分子量公式**：
   モル質量を $M$ [g/mol]、気体の質量を $m$ [g]、体積を $V$ [L] とすると：
   $$p V = \frac{m}{M} R T \implies M = \frac{m}{V} \frac{R T}{p} = \frac{d R T}{p}$$
2. **数値の代入**：
   - $d = 1.2\text{ g/L}$
   - $T = 27 + 273 = 300\text{ K}$
   - $p = 1.0 \times 10^5\text{ Pa}$
   - $R = 8.31 \times 10^3\text{ Pa}\cdot\text{L/(K}\cdot\text{mol)}$
   $$M = \frac{1.2 \times (8.31 \times 10^3) \times 300}{1.0 \times 10^5} = \frac{1.2 \times 8.31 \times 300000}{100000} = 1.2 \times 8.31 \times 3 = 29.916\text{ g/mol}$$
   最も近い整数値は **30**（一酸化窒素 NO やエタン $\text{C}_2\text{H}_6$ などに相当）である。
よって、正解は選択肢 $\textcircled{3}$ である。

## 問7：中和反応と固体溶解熱の複合熱化学計算

**【考査考点】**：固体の溶解熱と水溶液の中和熱の独立加算（ヘスの法則）, 塩酸と水酸化ナトリウムの物質量の比較と限定反応物の特定

**【題目大意】**
$0.50\text{ mol/L}$ の塩酸 $100\text{ mL}$ に固体の $\text{NaOH}$ $4.0\text{ g}$ を加えて反応させた。
発生した全熱量 [kJ] を求めよ（中和熱 $56\text{ kJ/mol}$、$\text{NaOH}$ の溶解熱 $44\text{ kJ/mol}$、$\text{NaOH} = 40$）。

**【公式正解】**：$\textcircled{2}$（$7.2\text{ kJ}$）

**【詳細推導・解答プロセス】**
1. **各反応物の物質量の算出**：
   - 塩化水素 $\text{HCl}$ の物質量：
     $$n(\text{HCl}) = 0.50\text{ mol/L} \times 0.100\text{ L} = 0.050\text{ mol}$$
   - 水酸化ナトリウム $\text{NaOH}$ の物質量：
     $$n(\text{NaOH}) = \frac{4.0\text{ g}}{40\text{ g/mol}} = 0.10\text{ mol}$$
2. **溶解熱の計算**：
   投入された $4.0\text{ g}$（$0.10\text{ mol}$）の固体 $\text{NaOH}$ はすべて水に溶解する：
   $$Q_{\text{diss}} = 0.10\text{ mol} \times 44\text{ kJ/mol} = 4.4\text{ kJ}$$
3. **中和熱の計算**：
   中和反応 $\text{H}^+ + \text{OH}^- \to \text{H}_2\text{O}$ において、$\text{HCl}$ が $0.050\text{ mol}$、$\text{NaOH}$ が $0.10\text{ mol}$ であるから、$\text{HCl}$ がすべて反応し、$0.050\text{ mol}$ の水が生じる（$\text{HCl}$ が限定反応物）：
   $$Q_{\text{neut}} = 0.050\text{ mol} \times 56\text{ kJ/mol} = 2.8\text{ kJ}$$
4. **発生した全熱量**：
   $$Q_{\text{total}} = Q_{\text{diss}} + Q_{\text{neut}} = 4.4\text{ kJ} + 2.8\text{ kJ} = 7.2\text{ kJ}$$
よって、正解は選択肢 $\textcircled{2}$ である。

## 問8：直列接続された電気分解槽（Cu電極／CuSO4 vs 炭素電極／NaCl）の各極現象

**【考査考点】**：粗銅の電解精錬と同様のCu陽極溶解とCu陰極析出, 食塩水電解における陰極での水素発生・強塩基性化, 炭素陽極での塩素ガス発生

**【題目大意】**
電解槽 I（$\text{CuSO}_4\text{aq}$、Cu 電極 A, B）と電解槽 II（$\text{NaClaq}$、炭素電極 C, D）を直列に電気分解した。
記述として誤っているものを一つ選べ。

**【公式正解】**：$\textcircled{3}$（炭素電極 C 付近の溶液は、酸性になる）

**【詳細推導・解答プロセス】**
直列回路における各極の反応を分析する：
1. **電解槽 I（銅電極）**：
   - 陽極では Cu 電極自身が酸化されて溶解する：$\text{Cu} \to \text{Cu}^{2+} + 2e^-$（電極質量減少）。
   - 陰極では水溶液中の $\text{Cu}^{2+}$ が還元されて銅が析出する：$\text{Cu}^{2+} + 2e^- \to \text{Cu}$（電極質量増加）。
2. **電解槽 II（食塩水電解）**：
   - 陽極では塩化物イオンが酸化されて塩素ガスが発生する：$2\text{Cl}^- \to \text{Cl}_2 + 2e^-$
   - 陰極では水が還元されて水素ガスと水酸化物イオンが生じる：$2\text{H}_2\text{O} + 2e^- \to \text{H}_2 + 2\text{OH}^-$
     そのため、陰極付近には $\text{OH}^-$ が蓄積して **塩基性（アルカリ性）** になる。
3. **選択肢 $\textcircled{3}$ の吟味**：
   電解槽 II の陰極側で液が酸性になるとする記述は明らかに誤りである。
よって、誤っている記述は選択肢 $\textcircled{3}$ である。

## 問9：過酸化水素の接触分解における化学反応速度論の基礎

**【考査考点】**：反応速度の定義 $v = -\frac{1}{2}\frac{\Delta[\text{H}_2\text{O}_2]}{\Delta t} = \frac{\Delta[\text{O}_2]}{\Delta t}$, 化学量論係数と生成・分解速度の倍数関係

**【題目大意】**
反応 $2\text{H}_2\text{O}_2 \longrightarrow 2\text{H}_2\text{O} + \text{O}_2$ に関する記述のうち、誤っているものを一つ選べ。

**【公式正解】**：$\textcircled{1}$（過酸化水素が分解する速度は、酸素が発生する速度の半分である）

**【詳細推導・解答プロセス】**
反応速度と化学反応式の係数の関係を整理する：
1. **係数比と反応速度の関係**：
   $$2\text{H}_2\text{O}_2 \longrightarrow 2\text{H}_2\text{O} + \text{O}_2$$
   この反応において、過酸化水素 2 分子が分解するごとに酸素分子 1 個が生成する。
   したがって、ある時間内に分解する過酸化水素の物質量は、発生する酸素の物質量の **2倍** である。
   反応速度で表すと：
   $$v(\text{H}_2\text{O}_2 \text{ の分解速度}) = 2 \times v(\text{O}_2 \text{ の発生速度})$$
   すなわち、「過酸化水素の分解速度は酸素発生速度の **2倍**」でなければならない。
2. **$\textcircled{1}$ の誤りの判定**：
   選択肢 $\textcircled{1}$ は「半分である」と述べており、主語と目的語の比率が逆になっており誤りである。
よって、正解は選択肢 $\textcircled{1}$ である。

## 問10：弱酸の電離平衡と水素イオン濃度の近似計算

**【考査考点】**：弱酸の電離定数 $K_a = \frac{[\text{H}^+][\text{A}^-]}{[\text{HA}]}$, 電離度 $\alpha \ll 1$ の近似による $[\text{H}^+] = \sqrt{c K_a}$

**【題目大意】**
弱酸 $\text{HA}$ の電離平衡 $\text{HA} \rightleftharpoons \text{H}^+ + \text{A}^-$ における電離定数 $K_a$ と水素イオン濃度 $[\text{H}^+]$ に関する正しい記述を選べ。

**【公式正解】**：$\textcircled{4}$

**【詳細推導・解答プロセス】**
1. **弱酸の電離平衡の理論式**：
   初濃度を $c$ [mol/L]、電離度を $\alpha$ とすると：
   $$[\text{HA}] = c(1-\alpha), \quad [\text{H}^+] = [\text{A}^-] = c\alpha$$
   $$K_a = \frac{c\alpha \cdot c\alpha}{c(1-\alpha)} = \frac{c\alpha^2}{1-\alpha}$$
2. **近似計算**：
   弱酸において電離度は十分に小さい（$\alpha \ll 1$）ため、$1 - \alpha \approx 1$ と近似できる：
   $$K_a \approx c\alpha^2 \implies \alpha = \sqrt{\frac{K_a}{c}}$$
   したがって、水素イオン濃度は：
   $$[\text{H}^+] = c\alpha = \sqrt{c K_a}$$
3. 選択肢の中でこの電離平衡の性質を正しく述べているものは $\textcircled{4}$ である。
よって、正解は選択肢 $\textcircled{4}$ である。

- A：ハーバー・ボッシュ法で得られる化合物（アンモニア $\text{NH}_3$）
- B：$\text{N}_2$ と $\text{O}_2$ の高温反応で生じる無色気体（一酸化窒素 $\text{NO}$）
- C：オストワルト法で製造される化合物（硝酸 $\text{HNO}_3$）

**【公式正解】**：$\textcircled{2}$（A：$-3$、B：$+2$、C：$+5$）

**【詳細推導・解答プロセス】**
各工業的窒素化合物を同定し、酸化数を計算する：
1. **化合物 A（アンモニア $\text{NH}_3$）**：
   鉄触媒を用いて窒素と水素を高圧・高温で反応させてアンモニアを合成する（ハーバー・ボッシュ法）。
   水素の酸化数を $+1$ とすると：
   $$\text{N} + 3(+1) = 0 \implies \text{N} = -3$$
2. **化合物 B（一酸化窒素 $\text{NO}$）**：
   雷放電や高温燃焼によって窒素と酸素が直接反応すると無色の一酸化窒素 $\text{NO}$ を生じる：
   $$\text{N} + (-2) = 0 \implies \text{N} = +2$$
3. **化合物 C（硝酸 $\text{HNO}_3$）**：
   アンモニアを白金触媒で酸化して一酸化窒素、二酸化窒素を経て硝酸を製造する（オストワルト法）。
   $$\text{H} (+1) + \text{N} + 3(-2) = 0 \implies \text{N} = +5$$
したがって、酸化数は A が $-3$、B が $+2$、C が $+5$ である。
よって、正解は選択肢 $\textcircled{2}$ である。

## 問19：元素分析（燃焼分析）による一価カルボン酸の分子式の決定

**【考査考点】**：生成二酸化炭素と水からの C, H, O 質量と物質量の算出, 実験式（組成式）の導出, 一価カルボン酸（Oが2個）による分子式の確定（酢酸 $\text{C}_2\text{H}_4\text{O}_2$）

**【題目大意】**
C, H, O からなる 1 価のカルボン酸 $4.50\text{ mg}$ を完全燃焼させたところ、$\text{CO}_2$ $6.60\text{ mg}$ と $\text{H}_2\text{O}$ $2.70\text{ mg}$ を生じた。
この化合物の分子式を求めよ（$\text{H}=1.0, \text{C}=12, \text{O}=16$）。

**【公式正解】**：$\textcircled{3}$（$\text{C}_2\text{H}_4\text{O}_2$）

**【詳細推導・解答プロセス】**
1. **各元素の質量の算出**：
   - 炭素 C の質量：
     $$m_{\text{C}} = 6.60\text{ mg} \times \frac{12}{44} = 1.80\text{ mg}$$
   - 水素 H の質量：
     $$m_{\text{H}} = 2.70\text{ mg} \times \frac{2.0}{18} = 0.30\text{ mg}$$
   - 酸素 O の質量：
     $$m_{\text{O}} = 4.50\text{ mg} - (1.80 + 0.30)\text{ mg} = 2.40\text{ mg}$$
2. **物質量比（モル比）の計算**：
   $$n_{\text{C}} : n_{\text{H}} : n_{\text{O}} = \frac{1.80}{12} : \frac{0.30}{1.0} : \frac{2.40}{16} = 0.150 : 0.300 : 0.150 = 1 : 2 : 1$$
   したがって、組成式（実験式）は **$\text{CH}_2\text{O}$** である。
3. **分子式の決定**：
   分子式は $(\text{CH}_2\text{O})_n$ と表される。
   この化合物は「1価のカルボン酸」であるため、分子内にカルボキシ基 $-\text{COOH}$ を 1 つもち、少なくとも 2 個の酸素原子を含まなければならない。
   したがって $n = 2$ であり、分子式は **$\text{C}_2\text{H}_4\text{O}_2$**（酢酸 $\text{CH}_3\text{COOH}$）である。
よって、正解は選択肢 $\textcircled{3}$ である。
