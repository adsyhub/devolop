## 数学 コース1 第I問 [1]：2次関数の平行移動と接線条件

**【題目大意】**
$a, b$ を定数とし，$a > 0$ とする。2次関数 $y = 4x^2 + 2ax + b$ のグラフを $x$ 軸方向に $a$，$y$ 軸方向に $1 - 7a$ だけ平行移動する。
平行移動後のグラフが点 $(0, 4)$ を通るとき，$b$ を $a$ で表し，移動後の2次関数を求め，さらにそのグラフが $x$ 軸に接するときの $a$ と接点を求める。

**【公式正解】**
正解：
$\text{ABCD} = -273$
$\text{EF} = 46$
$\text{G} = 4$
$\text{HI} = 43$
$\text{J} = 1$

**【詳細推導・解答プロセス】**
1. **平行移動後の2次関数の導出**：
元の関数 $y = 4x^2 + 2ax + b$ のグラフを $x$ 軸方向に $a$，$y$ 軸方向に $1 - 7a$ だけ平行移動すると：
$$y - (1 - 7a) = 4(x - a)^2 + 2a(x - a) + b$$
右辺を展開する：
$$y = 4(x^2 - 2ax + a^2) + 2a(x - a) + b + 1 - 7a$$
$$= 4x^2 - 8ax + 4a^2 + 2ax - 2a^2 + b + 1 - 7a$$
$$= 4x^2 - 6ax + (2a^2 + b + 1 - 7a)$$

2. **点 $(0, 4)$ を通る条件**：
移動後のグラフが $(0, 4)$ を通るため：
$$4 = 2a^2 + b + 1 - 7a$$
$$b = -2a^2 + 7a + 3$$
したがって，$\text{A} = -2, \text{B} = 7, \text{C} = 3$（$\text{ABCD} = -273$ → $A=-$, $B=2$, $C=7$, $D=3$）である。

3. **移動後の2次関数の定数項**：
$b = -2a^2 + 7a + 3$ を代入すると，定数項は：
$$2a^2 + (-2a^2 + 7a + 3) + 1 - 7a = 4$$
したがって，移動後の2次関数は：
$$y = 4x^2 - 6ax + 4$$
これより $\text{E} = 4, \text{F} = 6$（$\text{EF} = 46$），$\text{G} = 4$ である。

4. **$x$ 軸に接する条件**：
2次関数 $y = 4x^2 - 6ax + 4$ が $x$ 軸に接するための条件は判別式 $D = 0$ である：
$$D = (-6a)^2 - 4 \cdot 4 \cdot 4 = 36a^2 - 64 = 0$$
$$a^2 = \frac{64}{36} = \frac{16}{9}$$
$a > 0$ より：
$$a = \frac{4}{3}$$
これより $\text{H} = 4, \text{I} = 3$（$\text{HI} = 43$）である。

5. **接点の $x$ 座標**：
接点の $x$ 座標は：
$$x = \frac{6a}{2 \cdot 4} = \frac{6 \cdot \frac{4}{3}}{8} = \frac{8}{8} = 1$$
これより $\text{J} = 1$ である。

**【考査考点】**
2次関数の平行移動，通過点条件による未定係数の決定，判別式による接線条件の適用。

## 数学 コース1 第I問 [2]：多項式の有理数条件と素数条件

**【題目大意】**
多項式 $P = x^2 + 2(a - 1)x - 8a - 8$ を考える。
(1) $a$ を有理数とし，$x = 1 - \sqrt{2}$ のとき $P$ が有理数になる $a$ と $P$ の値を求める。
(2) $P$ を因数分解し，$x, a$ が正の整数で $P$ が素数になる条件を求める。

**【公式正解】**
正解：
$\text{K} = 0$
$\text{LM} = -7$
$\text{NOP} = 422$
$\text{Q} = 5$
$\text{R} = 2$
$\text{ST} = 11$

**【詳細推導・解答プロセス】**
1. **(1) 有理数条件**：
$x = 1 - \sqrt{2}$ を代入する：
$$P = (1 - \sqrt{2})^2 + 2(a - 1)(1 - \sqrt{2}) - 8a - 8$$
$$= 1 - 2\sqrt{2} + 2 + 2(a - 1) - 2(a - 1)\sqrt{2} - 8a - 8$$
$$= (3 + 2a - 2 - 8a - 8) + (-2 - 2a + 2)\sqrt{2}$$
$$= (-6a - 7) + (-2a)\sqrt{2}$$
$P$ が有理数であるための条件は $\sqrt{2}$ の係数が $0$ であること：
$$-2a = 0 \implies a = 0$$
これより $\text{K} = 0$ である。
このとき $P = -6(0) - 7 = -7$ である。
これより $\text{LM} = -7$ である。

2. **(2) 因数分解**：
$P = x^2 + 2(a - 1)x - 8(a + 1)$ を因数分解する。
定数項 $-8(a + 1)$ と $x$ の係数 $2(a - 1)$ から，因数を推定する：
$$(x - 4)(x + 2a + 2) = x^2 + (2a + 2 - 4)x - 4(2a + 2) = x^2 + (2a - 2)x - 8a - 8$$
$$= x^2 + 2(a - 1)x - 8(a + 1) = P$$
したがって，$\text{N} = 4, \text{O} = 2, \text{P} = 2$（$\text{NOP} = 422$）である。

3. **$P$ が素数となる条件**：
$P = (x - 4)(x + 2a + 2)$ において，$x, a$ は正の整数（$x \geq 1, a \geq 1$）である。
$P$ が素数であるためには，2つの因数の一方が $1$ で他方が素数でなければならない。
$a \geq 1$ のとき $x + 2a + 2 \geq x + 4 \geq 5 > 1$ であるから，
$$x - 4 = 1 \implies x = 5$$
これより $\text{Q} = 5$ である。

4. **最小の $a$ と $P$ の値**：
$x = 5$ のとき $P = 1 \cdot (5 + 2a + 2) = 2a + 7$ である。
$P$ が素数となる最小の正の整数 $a$ を求める：
- $a = 1$：$P = 9 = 3^2$（合成数，不適）
- $a = 2$：$P = 11$（素数 ✓）
したがって $a = 2$ で $P = 11$ である。
これより $\text{R} = 2, \text{ST} = 11$ である。

**【考査考点】**
無理数を含む式の有理化条件，多項式の因数分解，整数条件と素数判定。

## 数学 コース1 第II問 [1]：サイコロの確率と点の移動

**【題目大意】**
座標平面上の点 P は原点 $(0,0)$ にあり，サイコロを投げて3の倍数の目が出れば $x$ 軸正方向に1，それ以外なら $y$ 軸正方向に1移動する。サイコロを4回投げるとき，到達確率を求める。

**【公式正解】**
正解：
$\text{ABC} = 881$（$A/BC = 8/81$）
$\text{D} = 5$
$\text{E} = 4$
$\text{FG} = 04$（$F = 0, G = 4$）
$\text{HI} = 32$
$\text{J} = 1$
$\text{KL} = 16$

**【詳細推導・解答プロセス】**
1. **基本確率の設定**：
1個のサイコロで3の倍数の目（3, 6）が出る確率は $p = \frac{2}{6} = \frac{1}{3}$，
3の倍数でない目（1, 2, 4, 5）が出る確率は $q = \frac{4}{6} = \frac{2}{3}$ である。

2. **(1) P が $(3, 1)$ に到達する確率**：
4回中3回 $x$ 方向，1回 $y$ 方向に移動する：
$$\binom{4}{3}\left(\frac{1}{3}\right)^3\left(\frac{2}{3}\right)^1 = 4 \cdot \frac{1}{27} \cdot \frac{2}{3} = \frac{8}{81}$$
これより $\text{A} = 8, \text{BC} = 81$（$\text{ABC} = 881$）である。

3. **(2) 到達し得る点の個数と座標**：
4回投げるとき，$x$ 方向に $k$ 回，$y$ 方向に $4-k$ 回移動するから，到達点は：
$$(k, 4-k) \quad (0 \leq k \leq 4)$$
全部で $5$ 個の点に到達し得る。$\text{D} = 5, \text{E} = 4, \text{F} = 0, \text{G} = 4$ である。

4. **$p_k$ の最大値と最小値**：
$$p_k = \binom{4}{k}\left(\frac{1}{3}\right)^k\left(\frac{2}{3}\right)^{4-k}$$
各 $p_k$ を計算すると（分母は $3^4 = 81$）：
| $k$ | $\binom{4}{k}$ | $p_k$ |
|-----|------------------|--------|
| 0 | 1 | $\frac{16}{81}$ |
| 1 | 4 | $\frac{32}{81}$ |
| 2 | 6 | $\frac{24}{81}$ |
| 3 | 4 | $\frac{8}{81}$ |
| 4 | 1 | $\frac{1}{81}$ |
最大値は $p_1 = \frac{32}{81}$，最小値は $p_4 = \frac{1}{81}$ である。
これより $\text{HI} = 32, \text{J} = 1$ である。

5. **(3) $(1,1)$ を通り $(2,2)$ に到達する確率**：
2回目終了時に $(1,1)$ にいる確率：
$$\binom{2}{1}\left(\frac{1}{3}\right)^1\left(\frac{2}{3}\right)^1 = 2 \cdot \frac{1}{3} \cdot \frac{2}{3} = \frac{4}{9}$$
$(1,1)$ から残り2回で $(2,2)$ に到達する確率（さらに $x$方向1回，$y$方向1回）：
$$\binom{2}{1}\left(\frac{1}{3}\right)^1\left(\frac{2}{3}\right)^1 = \frac{4}{9}$$
したがって：
$$P = \frac{4}{9} \times \frac{4}{9} = \frac{16}{81}$$
これより $\text{KL} = 16$ である。

**【考査考点】**
二項分布，場合の数と確率，条件付き確率の乗法定理。

## 数学 コース1 第II問 [2]：三角形の内分点と面積比

**【題目大意】**
三角形 ABC の3辺 AB, BC, CA を $k:(1-k)$ の比に内分する点をそれぞれ D, E, F とする（$0 < k \leq \frac{1}{2}$）。
(1) $k = \frac{1}{3}$ のとき，$\triangle ABC$ は $\triangle DEF$ の何倍か。
(2) $\triangle DEF = \frac{1}{2} \triangle ABC$ となる $k$ を求める。

**【公式正解】**
正解：
$\text{MN} = 29$
$\text{O} = 3$
$\text{PQ} = 16$
$\text{RST} = 336$

**【詳細推導・解答プロセス】**
1. **(1) $k = \frac{1}{3}$ のときの面積比**：
辺 AB 上の点 D は $AD:DB = k:(1-k) = 1:2$ に内分する。同様に BC 上の E，CA 上の F もそれぞれ $1:2$ に内分する。
三角形 ADF について：
$$\frac{\triangle ADF}{\triangle ABC} = \frac{AD}{AB} \cdot \frac{AF}{AC} = k \cdot (1-k)$$
$k = \frac{1}{3}$ のとき：
$$\frac{\triangle ADF}{\triangle ABC} = \frac{1}{3} \cdot \frac{2}{3} = \frac{2}{9}$$
対称性により $\triangle BED = \triangle CFE = \frac{2}{9} \triangle ABC$ である。
これより $\text{M} = 2, \text{N} = 9$（$\text{MN} = 29$）である。

$$\triangle DEF = \triangle ABC - 3 \cdot \frac{2}{9} \triangle ABC = \left(1 - \frac{6}{9}\right)\triangle ABC = \frac{1}{3} \triangle ABC$$
したがって $\triangle ABC = 3 \triangle DEF$ である。
これより $\text{O} = 3$ である。

2. **(2) $\triangle DEF = \frac{1}{2} \triangle ABC$ となる条件**：
一般に $\frac{\triangle DEF}{\triangle ABC} = 1 - 3k(1-k)$ であるから：
$$1 - 3k(1-k) = \frac{1}{2} \implies k(1-k) = \frac{1}{6}$$
これより $\text{P} = 1, \text{Q} = 6$（$\text{PQ} = 16$）である。

$$k^2 - k + \frac{1}{6} = 0 \implies 6k^2 - 6k + 1 = 0$$
$$k = \frac{6 \pm \sqrt{36 - 24}}{12} = \frac{6 \pm \sqrt{12}}{12} = \frac{6 \pm 2\sqrt{3}}{12} = \frac{3 \pm \sqrt{3}}{6}$$
$0 < k \leq \frac{1}{2}$ であるから：
$$k = \frac{3 - \sqrt{3}}{6}$$
（$\frac{3 + \sqrt{3}}{6} \approx 0.789 > \frac{1}{2}$ なので不適。）
これより $\text{R} = 3, \text{S} = 3, \text{T} = 6$（$\text{RST} = 336$）である。

**【考査考点】**
三角形の辺の内分と面積比，2次方程式の解法，根号を含む式の整理。

## 数学 コース1 第III問 (前半)：放物線 y=x² 上の2点と交点・面積

**【題目大意】**
$m$ を実数とする。O を原点とする座標平面上で，放物線 $y = x^2$ とその曲線上にある2点 $A(a, ma+1)$，$B(b, mb+1)$（$a < 0 < b$）を考える。
(1) 2点の $x$ 座標 $a, b$ を $m$ で表す。
(2) 線分 AB と $y$ 軸の交点を求める。
(3) 三角形 OAB の面積を $a, b$ で表す。

**【公式正解】**
正解：
$\text{A} = 2$
$\text{B} = 2$
$\text{C} = 4$
$\text{D} = 1$
$\text{E} = 2$（選択肢 $\textcircled{2}$：$b - a$）

**【詳細推導・解答プロセス】**
1. **(1) $a, b$ の導出**：
点 A は放物線 $y = x^2$ 上にあるから：
$$a^2 = ma + 1 \implies a^2 - ma - 1 = 0$$
同様に $b^2 - mb - 1 = 0$ である。
すなわち $a, b$ は2次方程式 $x^2 - mx - 1 = 0$ の2つの解である。
解の公式より：
$$x = \frac{m \pm \sqrt{m^2 + 4}}{2}$$
$a < 0 < b$ であるから：
$$a = \frac{m - \sqrt{m^2 + 4}}{2}, \quad b = \frac{m + \sqrt{m^2 + 4}}{2}$$
したがって $\text{A} = 2, \text{B} = 2, \text{C} = 4$（$D = m^2 + 4$）である。

2. **(2) 直線 AB と $y$ 軸の交点**：
2点 A, B はともに $y = mx + 1$ を満たす（$x^2 = mx + 1$ より $y = x^2 = mx + 1$）。
したがって直線 AB の方程式は $y = mx + 1$ である。
$y$ 軸との交点は $x = 0$ を代入して $y = 1$ であるから，$c = 1$ である。
これより $\text{D} = 1$ である。

3. **(3) 三角形 OAB の面積**：
原点 O$(0, 0)$ から直線 $y = mx + 1$（すなわち $mx - y + 1 = 0$）までの距離は：
$$d = \frac{|1|}{\sqrt{m^2 + 1}} = \frac{1}{\sqrt{m^2 + 1}}$$
線分 AB の長さは：
$$|AB| = \sqrt{1 + m^2} \cdot |b - a| = \sqrt{1 + m^2} \cdot (b - a)$$
三角形 OAB の面積は：
$$S = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \sqrt{1 + m^2} \cdot (b - a) \cdot \frac{1}{\sqrt{m^2 + 1}} = \frac{1}{2}(b - a)$$
したがって $\text{E} = 2$（選択肢 $\textcircled{2}$：$b - a$）である。

**【考査考点】**
放物線と直線の関係，2次方程式の解と係数の関係，点と直線の距離公式，三角形の面積計算。

## 数学 コース1 第III問 (後半)：面積の m による表現と最小値

**【題目大意】**
前半で得た面積 $S = \frac{1}{2}(b - a)$ を $m$ の式で表し，$S$ の最小値とそのときの $m$ の値を求める。

**【公式正解】**
正解：
$\text{FGH} = 124$
$\text{I} = 0$
$\text{J} = 1$

**【詳細推導・解答プロセス】**
1. **面積の $m$ による表現**：
前半の結果より：
$$b - a = \frac{m + \sqrt{m^2 + 4}}{2} - \frac{m - \sqrt{m^2 + 4}}{2} = \sqrt{m^2 + 4}$$
したがって：
$$S = \frac{1}{2}\sqrt{m^2 + 4} = \frac{1}{2}(m^2 + 4)^{1/2}$$
これより $\text{F} = 1, \text{G} = 2, \text{H} = 4$（$\text{FGH} = 124$）である。

2. **$S$ の最小値**：
$m^2 \geq 0$ であるから $m^2 + 4 \geq 4$ であり，$S = \frac{1}{2}\sqrt{m^2 + 4}$ は $m^2 = 0$，すなわち $m = 0$ のとき最小値をとる：
$$S_{\text{min}} = \frac{1}{2}\sqrt{4} = \frac{1}{2} \cdot 2 = 1$$
これより $\text{I} = 0$（$m = 0$），$\text{J} = 1$（$S_{\text{min}} = 1$）である。

**【考査考点】**
根号関数の最小値，2次式の非負性，変数変換による面積関数の解析。

## 数学 コース1 第IV問 (前半)：2次式 A+B=0, AB=0 を満たす a の範囲

**【題目大意】**
$a$ を実数とし，$x$ の2次式 $A = x^2 + ax + 1$，$B = x^2 + (a+3)x + 4$ を考える。
(1) $A + B = 0$ を満たす実数 $x$ が存在するような $a$ の範囲を求める。
(2) $AB = 0$ を満たす実数 $x$ が存在するような $a$ の範囲を求める。

**【公式正解】**
正解：
$\text{ABCD} = 1032$
$\text{EF} = -2$
$\text{G} = 1$

**【詳細推導・解答プロセス】**
1. **(1) $A + B = 0$ の条件**：
$$A + B = 2x^2 + (2a + 3)x + 5 = 0$$
実数 $x$ が存在するための条件は判別式 $D \geq 0$：
$$D = (2a + 3)^2 - 4 \cdot 2 \cdot 5 = 4a^2 + 12a + 9 - 40 = 4a^2 + 12a - 31 \geq 0$$
解の公式より：
$$a = \frac{-12 \pm \sqrt{144 + 496}}{8} = \frac{-12 \pm \sqrt{640}}{8} = \frac{-12 \pm 8\sqrt{10}}{8} = \frac{-3 \pm 2\sqrt{10}}{2}$$
したがって：
$$a \leq \frac{-3 - 2\sqrt{10}}{2} = -\sqrt{10} - \frac{3}{2} \quad \text{または} \quad a \geq -\frac{3}{2} + \sqrt{10} = \sqrt{10} - \frac{3}{2}$$
これより $\text{A} = 10, \text{B} = 3, \text{C} = 2$（$\text{ABCD} = 1032$ → $\sqrt{\text{AB}} = \sqrt{10}, \frac{C}{D} = \frac{3}{2}$）である。

2. **(2) $AB = 0$ の条件**：
$A = 0$ または $B = 0$ を満たす実数 $x$ が存在すればよい。
- **$A = 0$**：$x^2 + ax + 1 = 0$ の判別式 $D_A = a^2 - 4 \geq 0 \implies |a| \geq 2$
  すなわち $a \leq -2$ または $a \geq 2$
- **$B = 0$**：$x^2 + (a+3)x + 4 = 0$ の判別式 $D_B = (a+3)^2 - 16 \geq 0 \implies |a+3| \geq 4$
  すなわち $a \leq -7$ または $a \geq 1$
両者の和集合をとると：
$$a \leq -2 \quad \text{または} \quad a \geq 1$$
これより $\text{EF} = -2, \text{G} = 1$ である。

**【考査考点】**
2次方程式の実数解存在条件（判別式），不等式の和集合・共通部分の処理。

## 数学 コース1 第IV問 (後半)：A²+B²=0 を満たす条件

**【題目大意】**
$A^2 + B^2 = 0$ を満たす実数 $x$ が存在するような $a$ の値と，そのときの $x$ を求める。

**【公式正解】**
正解：
$\text{H} = 2$
$\text{IJ} = -1$

**【詳細推導・解答プロセス】**
1. **$A^2 + B^2 = 0$ の必要十分条件**：
実数の2乗は非負であるから，$A^2 \geq 0$ かつ $B^2 \geq 0$ である。
したがって $A^2 + B^2 = 0$ が成り立つのは：
$$A = 0 \quad \text{かつ} \quad B = 0$$
の場合に限る。

2. **連立方程式の解法**：
$$\begin{cases} x^2 + ax + 1 = 0 \\ x^2 + (a+3)x + 4 = 0 \end{cases}$$
2式の差をとると：
$$3x + 3 = 0 \implies x = -1$$
$x = -1$ を $A = 0$ に代入すると：
$$(-1)^2 + a(-1) + 1 = 0 \implies 2 - a = 0 \implies a = 2$$
検証：$B = (-1)^2 + (2+3)(-1) + 4 = 1 - 5 + 4 = 0$ ✓

したがって $a = 2, x = -1$ である。
これより $\text{H} = 2, \text{IJ} = -1$ である。

**【考査考点】**
実数の非負性の利用（$A^2 + B^2 = 0 \iff A = B = 0$），連立方程式の消去法。
