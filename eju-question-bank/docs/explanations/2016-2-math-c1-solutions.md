## 大問I 問1：2次関数の決定（頂点・対称軸・x切片）

**問題コード**: `math-q-I_1` | **正解参照**: `MATH_C1:I_1`

### 出題のポイント
- 放物線の頂点の座標と標準形 $y = a(x - p)^2 + q$ への変形
- 軸対称性と線分の長さから $x$ 軸との交点座標の特定
- 交点代入による係数 $a, b, c$ の算出

### 詳細解説
**【題目大意】**
2次関数 $y = ax^2 + bx + c$ $\textcircled{1}$ は $x = 1$ のとき最大値 16 をとり、グラフが $x$ 軸と交わる 2 点間の距離が 8 であるとき、標準形、交点座標、および係数 $a, b, c$ を求める。

**【公式正解】**
- $\text{ABC} = 116$ ($y = a(x - 1)^2 + 16$)
- $\text{D} = 3, \text{E} = 5$ (交点座標 $(-3, 0), (5, 0)$)
- $\text{FG} = -1$ ($a = -1$)
- $\text{H} = 2, \text{IJ} = 15$ ($b = 2, c = 15$)

**【詳細推導・解答プロセス】**
**(1) 頂点による標準形の設定**
関数 $\textcircled{1}$ は $x = 1$ で最大値 16 をとるから、放物線の頂点の座標は $(1, 16)$ であり、上に凸 ($a < 0$) である。
したがって、関数は次のように表される：
$$y = a(x - 1)^2 + 16$$
よって、$\text{A} = 1, \text{BC} = 16$ である。

**(2) $x$ 軸との交点座標の決定**
放物線は対称軸 $x = 1$ に関して左右対称である。
グラフが $x$ 軸と交わる 2 点を結ぶ線分の長さが 8 であるから、軸 $x = 1$ から各交点までの距離は $8 \div 2 = 4$ である。
したがって、2 つの交点の $x$ 座標は：
$$x = 1 - 4 = -3, \quad x = 1 + 4 = 5$$
よって、交点の座標は $(-3, 0)$ および $(5, 0)$ である。
これより、$\text{D} = 3, \text{E} = 5$ である。

**(3) 係数 $a, b, c$ の決定**
交点 $(5, 0)$ を $y = a(x - 1)^2 + 16$ に代入すると：
$$0 = a(5 - 1)^2 + 16 \implies 16a + 16 = 0 \implies a = -1$$
よって、$\text{FG} = -1$ である。
この式を展開して一般形 $y = ax^2 + bx + c$ に変形すると：
$$y = -(x - 1)^2 + 16 = -(x^2 - 2x + 1) + 16 = -x^2 + 2x + 15$$
したがって、$a = -1, b = 2, c = 15$ となる。
これより、$\text{H} = 2, \text{IJ} = 15$ である。

**【考査考点】**
1. 2次関数の頂点から標準形を設定する技能。
2. 放物線の線対称性を利用して交点座標を求める幾何的考察力。
3. 標準形と一般形の相互展開および未定係数決定。

## 大問I 問2：カードの非復元抽出・復元抽出と確率（余事象・包除原理）

**問題コード**: `math-q-I_2` | **正解参照**: `MATH_C1:I_2`

### 出題のポイント
- 同時抽出（非復元抽出）における組合せ数の計算
- 最小値・最大値の範囲制約に対する余事象・包除原理の適用
- 復元抽出における独立試行の確率計算

### 詳細解説
**【題目大意】**
0 から 9 までのカード 10 枚から 3 枚を取り出す試行において、(1) 同時抽出での数の範囲確率および最小値・最大値条件付き確率、(2) 復元抽出での範囲確率を求める。

**【公式正解】**
- $\text{KLM} = 112$ (確率 $\frac{1}{12}$)
- $\text{NOPQ} = 1340$ (確率 $\frac{13}{40}$)
- $\text{RS} = 18$ (確率 $\frac{1}{8}$)

**【詳細推導・解答プロセス】**
**(1) 3枚のカードを同時に取り出す場合**
10 枚のカードから 3 枚を同時に取り出す全事象の根元事象の総数は：
$$N = \binom{10}{3} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

**(i) 3枚の数がすべて2以上6以下である確率**
集合 $\{2, 3, 4, 5, 6\}$ は計 5 枚である。
この 5 枚から 3 枚を取り出す組合せ数は：
$$\binom{5}{3} = 10$$
したがって、求める確率は：
$$P = \frac{10}{120} = \frac{1}{12}$$
よって、$\text{K} = 1, \text{LM} = 12$ (KLM = 112) である。

**(ii) 最も小さい数が2以下で、最も大きい数が8以上である確率**
取り出した 3 枚の最小値を $X$、最大値を $Y$ とする。
事象 $E: X \leq 2 \text{ かつ } Y \geq 8$ の確率を、余事象を用いて包除原理により求める。
否定を考えると、$\overline{E}: X \geq 3 \text{ または } Y \leq 7$ である。
- 事象 $A: X \geq 3$（すべて 3 以上 9 以下、対象は $\{3,4,5,6,7,8,9\}$ の 7 枚）：
  $$|A| = \binom{7}{3} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35$$
- 事象 $B: Y \leq 7$（すべて 0 以上 7 以下、対象は $\{0,1,2,3,4,5,6,7\}$ の 8 枚）：
  $$|B| = \binom{8}{3} = \frac{8 \times 7 \times 6}{3 \times 2 \times 1} = 56$$
- 事象 $A \cap B: 3 \leq X \leq Y \leq 7$（すべて 3 以上 7 以下、対象は $\{3,4,5,6,7\}$ の 5 枚）：
  $$|A \cap B| = \binom{5}{3} = 10$$
包除原理より、$|A \cup B| = |A| + |B| - |A \cap B| = 35 + 56 - 10 = 81$ 通り。
したがって、事象 $E$ を満たす場合の数は：
$$|E| = N - |A \cup B| = 120 - 81 = 39$$
求める確率は：
$$P = \frac{39}{120} = \frac{13}{40}$$
よって、$\text{NO} = 13, \text{PQ} = 40$ (NOPQ = 1340) である。

**(2) 1枚ずつ見て元に戻す試行を3回続ける場合（復元抽出）**
各回ごとに引く数は独立であり、全事象は $10^3 = 1000$ 通り。
最も小さい数が 2 以上で、最も大きい数が 6 以下であるとは、3 回とも $\{2, 3, 4, 5, 6\}$（5 枚）から引くことと同値である。
1 回あたりに 2 以上 6 以下のカードを引く確率は $\frac{5}{10} = \frac{1}{2}$ である。
3 回の独立試行により、求める確率は：
$$P = \left(\frac{1}{2}\right)^3 = \frac{1}{8}$$
よって、$\text{R} = 1, \text{S} = 8$ (RS = 18) である。

**【考査考点】**
1. 非復元抽出における組合せの計算。
2. 最小値・最大値条件における余事象と包除原理の定石的活用。
3. 復元抽出における独立試行の確率公式の理解。

## 大問II 問1：対称式の因数分解と恒等式の係数決定

**問題コード**: `math-q-II_1` | **正解参照**: `MATH_C1:II_1`

### 出題のポイント
- 恒等式の性質と特定値代入法による必要条件の導出
- 連立等式による未知係数 $a$ と次数 $n$ の決定
- 因数定理と対称式の因数分解の十分性確認

### 詳細解説
**【題目大意】**
整式 $x^n + y^n + z^n + a(xy + yz + zx)$ が $x + y + z$ を因数にもつとき、特定値代入法を用いて定数 $a$ および自然数 $n$ の値を求める。

**【公式正解】**
- $\text{A} = 2, \text{BC} = 12$ ($z = -2$, $x = y = -\frac{1}{2}$)
- $\text{DE} = 32$ ($(-A)^n = 3a - 2$)
- $\text{FGHI} = 3812$ ($(-\frac{B}{C})^n = \frac{3}{8}a - \frac{1}{2}$)
- $\text{J} = 1$ ($(3a - 2)(\frac{3}{8}a - \frac{1}{2}) = 1$)
- $\text{K} = 2, \text{L} = 2$ ($a = 2, n = 2$)

**【詳細推導・解答プロセス】**
**(1) 恒等式への特定値の代入**
与えられた恒等式は：
$$x^n + y^n + z^n + a(xy + yz + zx) = (x + y + z)P \quad \textcircled{1}$$
$x + y + z = 0$ となる組として：
- $x = y = 1$ のとき、$1 + 1 + z = 0 \implies z = -2$。よって $\text{A} = 2$。
これを $\textcircled{1}$ に代入すると、右辺は 0 となるから：
$$1^n + 1^n + (-2)^n + a\{1\cdot 1 + 1\cdot(-2) + (-2)\cdot 1\} = 0$$
$$2 + (-2)^n + a(1 - 2 - 2) = 0 \implies (-2)^n - 3a + 2 = 0$$
$$(-2)^n = 3a - 2 \quad \textcircled{2}$$
これより、$\text{D} = 3, \text{E} = 2$ (DE = 32) である。

- $z = 1$ かつ $x = y$ のとき、$x + x + 1 = 0 \implies x = y = -\frac{1}{2}$。よって $\text{B} = 1, \text{C} = 2$ (BC = 12)。
これを $\textcircled{1}$ に代入すると：
$$\left(-\frac{1}{2}\right)^n + \left(-\frac{1}{2}\right)^n + 1^n + a\left\{\left(-\frac{1}{2}\right)^2 + 2\cdot\left(-\frac{1}{2}\right)\cdot 1\right\} = 0$$
$$2\left(-\frac{1}{2}\right)^n + 1 + a\left(\frac{1}{4} - 1\right) = 0$$
$$2\left(-\frac{1}{2}\right)^n + 1 - \frac{3}{4}a = 0 \implies \left(-\frac{1}{2}\right)^n = \frac{3}{8}a - \frac{1}{2} \quad \textcircled{3}$$
これより、$\text{F} = 3, \text{G} = 8, \text{H} = 1, \text{I} = 2$ (FGHI = 3812) である。

**(2) $a$ および $n$ の算出**
$\left(-\frac{1}{2}\right)^n = \frac{1}{(-2)^n}$ であるから、$\textcircled{2}$ と $\textcircled{3}$ の両辺の積をとると：
$$(-2)^n \cdot \left(-\frac{1}{2}\right)^n = (3a - 2)\left(\frac{3}{8}a - \frac{1}{2}\right)$$
左辺は 1 であるから：
$$(3a - 2)\left(\frac{3}{8}a - \frac{1}{2}\right) = 1$$
したがって、$\text{J} = 1$ である。
両辺に 8 をかけると：
$$(3a - 2)(3a - 4) = 8 \implies 9a^2 - 18a + 8 = 8$$
$$9a^2 - 18a = 0 \implies 9a(a - 2) = 0$$
$a \neq 0$ であるから、$a = 2$ を得る。よって $\text{K} = 2$ である。
$a = 2$ を $\textcircled{2}$ に代入すると：
$$(-2)^n = 3(2) - 2 = 4 = (-2)^2$$
$n$ は自然数であるから、$n = 2$ を得る。よって $\text{L} = 2$ である。

**(3) 十分性の確認**
$a = 2, n = 2$ のとき：
$$x^2 + y^2 + z^2 + 2(xy + yz + zx) = (x + y + z)^2 = (x + y + z)(x + y + z)$$
となり、$P = x + y + z$ として $\textcircled{1}$ が恒等的に成立する。

**【考査考点】**
1. 恒等式における特定値代入法による必要条件の導出法。
2. 逆数の関係を利用した連立指数の消去法。
3. 対称式の展開公式 $(x+y+z)^2$ と因数分解の整合性。

## 大問II 問2：放物線上の一定長線分の中点の軌跡と最小値

**問題コード**: `math-q-II_2` | **正解参照**: `MATH_C1:II_2`

### 出題のポイント
- 2点間の距離の公式と対称式の関係式導出
- 中点の座標とパラメータ消去による2次方程式の立式
- 平方完成による最小値とそのときの座標の決定

### 詳細解説
**【題目大意】**
放物線 $y = x^2$ 上の両端をもつ長さ 2 の線分 PQ の中点 M について、$x$ 軸に最も近い（$y$ 座標が最小となる）点の座標を求める。

**【公式正解】**
- $\text{M} = 2, \text{N} = 4$ ($m = \frac{p^2 + q^2}{2}$, $(p - q)^2 + (p^2 - q^2)^2 = 4$)
- $\text{OPQ} = 222$ ($2m^2 + m - 2t^2 - t - 2 = 0$)
- $\text{RST} = 441$ ($m = -\frac{1}{4} + \sqrt{(t + \frac{1}{4})^2 + 1}$)
- $\text{UV} = 32, \text{W} = 1$ ($p^2 + q^2 = \frac{3}{2}, p + q = \pm 1$)
- $\text{X} = 2, \text{YZ} = 34$ (M の座標 $(\pm \frac{1}{2}, \frac{3}{4})$)

**【詳細推導・解答プロセス】**
**(1) 中点座標と三平方の定理の立式**
$P(p, p^2), Q(q, q^2)$ の中点 M の $y$ 座標 $m$ は：
$$m = \frac{p^2 + q^2}{2} \quad \textcircled{1}$$
よって、$\text{M} = 2$ である。
条件 $PQ = 2$ より、三平方の定理より：
$$(p - q)^2 + (p^2 - q^2)^2 = 2^2 = 4 \quad \textcircled{2}$$
よって、$\text{N} = 4$ である。

**(2) $m$ と $t = pq$ の関係式**
$\textcircled{1}$ より $p^2 + q^2 = 2m$ である。
各項を変形すると：
$$(p - q)^2 = p^2 + q^2 - 2pq = 2m - 2t$$
また、$p^2 - q^2 = (p - q)(p + q)$ であるから：
$$(p^2 - q^2)^2 = (p - q)^2 (p + q)^2 = (2m - 2t)(p^2 + q^2 + 2pq) = (2m - 2t)(2m + 2t) = 4(m^2 - t^2)$$
これらを $\textcircled{2}$ に代入すると：
$$(2m - 2t) + 4(m^2 - t^2) = 4$$
両辺を 2 で割ると：
$$m - t + 2(m^2 - t^2) = 2 \implies 2m^2 + m - 2t^2 - t - 2 = 0$$
したがって、$\text{O} = 2, \text{P} = 2, \text{Q} = 2$ (OPQ = 222) である。

**(3) $m$ について解き、最小値を求める**
$m$ の2次方程式 $2m^2 + m - (2t^2 + t + 2) = 0$ を解の公式により解く。
$m > 0$ であるから、正の解をとると：
$$m = \frac{-1 + \sqrt{1^2 - 4 \cdot 2 \cdot (-(2t^2 + t + 2))}}{2 \cdot 2} = \frac{-1 + \sqrt{1 + 16t^2 + 8t + 16}}{4} = -\frac{1}{4} + \frac{1}{4}\sqrt{16t^2 + 8t + 17}$$
根号内を平方完成すると：
$$16t^2 + 8t + 17 = 16\left(t^2 + \frac{1}{2}t + \frac{1}{16}\right) - 1 + 17 = 16\left(t + \frac{1}{4}\right)^2 + 16$$
したがって：
$$m = -\frac{1}{4} + \sqrt{\left(t + \frac{1}{4}\right)^2 + 1}$$
これより、$\text{R} = 4, \text{S} = 4, \text{T} = 1$ (RST = 441) である。

**(4) 最小点における座標の決定**
$\left(t + \frac{1}{4}\right)^2 \geq 0$ であるから、$m$ は $t = -\frac{1}{4}$ のとき最小値をとる。
このとき、$pq = -\frac{1}{4}$ であり、
$$m = -\frac{1}{4} + \sqrt{0 + 1} = \frac{3}{4}$$
$\textcircled{1}$ より、$p^2 + q^2 = 2m = 2 \cdot \frac{3}{4} = \frac{3}{2}$ である。
よって、$\text{U} = 3, \text{V} = 2$ (UV = 32) である。
また、$(p + q)^2 = p^2 + q^2 + 2pq = \frac{3}{2} + 2\left(-\frac{1}{4}\right) = 1$ であるから：
$$p + q = \pm 1$$
よって、$\text{W} = 1$ である。
M の $x$ 座標は $\frac{p + q}{2} = \pm \frac{1}{2}$ であるから、M の座標は：
$$\left(\pm \frac{1}{2}, \frac{3}{4}\right)$$
これより、$\text{X} = 2, \text{YZ} = 34$ である。

**【考査考点】**
1. 対称式を用いたパラメータ表示と消去のテクニック。
2. 2次方程式の解の公式および無理関数の平方完成による最小値解析。
3. 線分の中点の幾何的配置と座標計算。

## 大問III 問1：剰余類の計算とn進法（3進法から10進法への変換）

**問題コード**: `math-q-III_1` | **正解参照**: `MATH_C1:III_1`

### 出題のポイント
- 整数を法とする割り算の余りと平方式の剰余計算
- 3進法の位取り記数法から10進法への基数変換
- 3進数3桁の数の範囲（最大値・最小値）の決定

### 詳細解説
**【題目大意】**
(1) 整数 $a$ を 5 で割った余りが 4 であるときの平方式の剰余、および 3 進法の 3 桁の数に関する 10 進法変換と最大値・最小値を求める。

**【公式正解】**
- $\text{AB} = 54$ ($a = 5k + 4$)
- $\text{C} = 1$ ($a^2$ を 5 で割った余りは 1)
- $\text{DE} = 15$ ($120_{(3)} = 15$)
- $\text{FG} = 26$ (3桁の最大自然数は 26)
- $\text{H} = 9$ (3桁の最小自然数は 9)

**【詳細推導・解答プロセス】**
**(1) 剰余の計算**
$a$ を 5 で割ると 4 余るから、整数 $k$ を用いて次のように表される：
$$a = 5k + 4$$
よって、$\text{A} = 5, \text{B} = 4$ (AB = 54) である。
このとき、$a^2$ を計算すると：
$$a^2 = (5k + 4)^2 = 25k^2 + 40k + 16 = 5(5k^2 + 8k + 3) + 1$$
したがって、$a^2$ を 5 で割った余りは 1 である。
よって、$\text{C} = 1$ である。

**(2) 3進法から10進法への変換**
3 進法表記 $120_{(3)}$ を 10 進法に変換すると：
$$120_{(3)} = 1 \times 3^2 + 2 \times 3^1 + 0 \times 3^0 = 9 + 6 + 0 = 15$$
よって、$\text{DE} = 15$ である。

3 進法で 3 桁で表される自然数は、最上位が 1 または 2 である。
- 最大の自然数は各桁が最大の 2 となるときであり、$222_{(3)}$ である：
  $$222_{(3)} = 3^3 - 1 = 27 - 1 = 26$$
  よって、$\text{FG} = 26$ である。
- 最小の自然数は最上位が 1 で下位が 0 となるときであり、$100_{(3)}$ である：
  $$100_{(3)} = 1 \times 3^2 = 9$$
  よって、$\text{H} = 9$ である。

**【考査考点】**
1. 整数の除法の原理と合同式の性質。
2. $n$ 進法（位取り記数法）の定義と 10 進法への変換技能。
3. 特定桁数における最大値・最小値の決定。

## 大問III 問2：命題と論理（必要条件・十分条件の判定）

**問題コード**: `math-q-III_2` | **正解参照**: `MATH_C1:III_2`

### 出題のポイント
- 剰余命題における必要十分性の判定
- 範囲条件と3進法桁数条件の包含関係による論理判定

### 詳細解説
**【題目大意】**
整数 $a$ および自然数 $b$ に関する 2 つの条件について、必要条件・十分条件の関係を下の選択肢（$\textcircled{0} \sim \textcircled{3}$）から判定する。

**【公式正解】**
- $\text{I} = 1$ (十分条件であるが、必要条件ではない：$\textcircled{1}$)
- $\text{J} = 0$ (必要条件であるが、十分条件ではない：$\textcircled{0}$)

**【詳細推導・解答プロセス】**
**(1) (i) の判定**
条件 $p$: 「$a$ を 5 で割ると余りは 4 である」 ($a \equiv 4 \pmod 5$)
条件 $q$: 「$a^2$ を 5 で割ると余りは 1 である」 ($a^2 \equiv 1 \pmod 5$)
- $p \implies q$：
  $a \equiv 4 \equiv -1 \pmod 5$ ならば $a^2 \equiv (-1)^2 = 1 \pmod 5$ となり真である。
- $q \implies p$：
  $a^2 \equiv 1 \pmod 5 \iff a^2 - 1 = (a - 1)(a + 1) \equiv 0 \pmod 5$ より、$a \equiv 1 \pmod 5$ または $a \equiv 4 \pmod 5$ である。
  反例として $a = 1$ のとき、$a^2 = 1$ で余り 1 であるが、$a$ を 5 で割った余りは 1 であり 4 ではない。したがって偽である。
以上より、$p$ は $q$ であるための「十分条件であるが、必要条件ではない」($\textcircled{1}$)。
よって、$\text{I} = 1$ である。

**(2) (ii) の判定**
条件 $p$: 「$b$ は $6 \leq b \leq 30$ を満たす」
条件 $q$: 「$b$ を 3 進法で表すと 3 桁である」
前問より、3 進法で 3 桁の自然数 $b$ の範囲は $9 \leq b \leq 26$ である。すなわち条件 $q$ は $9 \leq b \leq 26$ である。
- $p \implies q$：
  反例として $b = 7$ は $6 \leq b \leq 30$ を満たすが、$b < 9$ であるため 3 進法では 2 桁 ($21_{(3)}$) となり、条件 $q$ を満たさない。したがって偽である。
- $q \implies p$：
  $9 \leq b \leq 26$ ならば、区間 $[9, 26] \subset [6, 30]$ であるから、常に $6 \leq b \leq 30$ が成り立つ。したがって真である。
以上より、$p$ は $q$ であるための「必要条件であるが、十分条件ではない」($\textcircled{0}$)。
よって、$\text{J} = 0$ である。

**【考査考点】**
1. 命題の真偽と反例の構成法。
2. 必要条件・十分条件の定義と集合の包含関係（$P \subset Q \implies p$ は十分条件）の理解。

## 大問IV 問1：角の二等分線と面積比の代数表示

**問題コード**: `math-q-IV_1` | **正解参照**: `MATH_C1:IV_1`

### 出題のポイント
- 三角形の面積の分割と角の二等分線の長さ $d$ の導出
- 垂線の長さと垂線の足がなす三角形の面積公式
- 面積比 $k$ の辺比 $x = b/c$ による関数表示

### 詳細解説
**【題目大意】**
$\angle \text{BAC} = 60^\circ$ の $\triangle \text{ABC}$ において、$\angle \text{A}$ の二等分線と BC の交点を D、D から AB, AC への垂線を DE, DF とする。$x = \frac{AB}{AC}$ とするとき、面積比 $k = \frac{\triangle \text{DEF}}{\triangle \text{ABC}}$ を $x$ の関数として表す。

**【公式正解】**
- $\text{A} = 3$ ($d = \frac{\sqrt{3} bc}{b + c}$)
- $\text{BC} = 12$ ($\text{DE} = \text{DF} = \frac{1}{2} d$)
- $\text{DEF} = 316$ ($\triangle \text{DEF} = \frac{\sqrt{3}}{16} d^2$)
- $\text{G} = 4$ ($k = \frac{d^2}{4 bc}$)
- $\text{HI} = 34$ ($k = \frac{3}{4} \frac{bc}{(b + c)^2}$)
- $\text{JKL} = 341$ ($k = \frac{3x}{4(x + 1)^2}$)

**【詳細推導・解答プロセス】**
**(1) 角の二等分線 $d = \text{AD}$ の導出**
$\text{AB} = b, \text{AC} = c, \text{AD} = d$ とする。$\angle \text{BAC} = 60^\circ$ であり、AD は二等分線であるから：
$$\angle \text{BAD} = \angle \text{CAD} = 30^\circ$$
三角形の面積の和 $\triangle \text{ABD} + \triangle \text{ACD} = \triangle \text{ABC}$ より：
$$\frac{1}{2} b d \sin 30^\circ + \frac{1}{2} c d \sin 30^\circ = \frac{1}{2} b c \sin 60^\circ$$
$$\frac{1}{4} (b + c) d = \frac{\sqrt{3}}{4} b c \implies d = \frac{\sqrt{3} b c}{b + c} \quad \textcircled{1}$$
したがって、$\text{A} = 3$ である。

**(2) 垂線の長さと $\triangle \text{DEF}$ の面積**
直角三角形 ADE において、$\angle \text{DAE} = 30^\circ$ であるから：
$$\text{DE} = d \sin 30^\circ = \frac{1}{2} d$$
同様に、直角三角形 ADF において $\text{DF} = d \sin 30^\circ = \frac{1}{2} d$ である。
よって、$\text{DE} = \text{DF} = \frac{1}{2} d$ より、$\text{B} = 1, \text{C} = 2$ (BC = 12) である。
四角形 AEDF において、$\angle \text{AED} = \angle \text{AFD} = 90^\circ, \angle \text{EAF} = 60^\circ$ であるから、内角の和より：
$$\angle \text{EDF} = 180^\circ - 60^\circ = 120^\circ$$
したがって、$\triangle \text{DEF}$ の面積は：
$$\triangle \text{DEF} = \frac{1}{2} \text{DE} \cdot \text{DF} \sin 120^\circ = \frac{1}{2} \left(\frac{1}{2} d\right)^2 \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{16} d^2 \quad \textcircled{2}$$
よって、$\text{D} = 3, \text{EF} = 16$ (DEF = 316) である。

**(3) 面積比 $k$ の計算**
$\triangle \text{ABC} = \frac{\sqrt{3}}{4} b c$ であるから：
$$k = \frac{\triangle \text{DEF}}{\triangle \text{ABC}} = \frac{\frac{\sqrt{3}}{16} d^2}{\frac{\sqrt{3}}{4} b c} = \frac{d^2}{4 b c}$$
これより、$\text{G} = 4$ である。
$\textcircled{1}$ より $d^2 = \frac{3 b^2 c^2}{(b + c)^2}$ を代入すると：
$$k = \frac{1}{4 b c} \cdot \frac{3 b^2 c^2}{(b + c)^2} = \frac{3}{4} \frac{b c}{(b + c)^2}$$
これより、$\text{H} = 3, \text{I} = 4$ (HI = 34) である。
$x = \frac{b}{c}$ であるから、分母・分子を $c^2$ で割ると：
$$\frac{b c}{(b + c)^2} = \frac{b/c}{(b/c + 1)^2} = \frac{x}{(x + 1)^2}$$
したがって：
$$k = \frac{3x}{4(x + 1)^2}$$
よって、$\text{J} = 3, \text{K} = 4, \text{L} = 1$ (JKL = 341) である。

**【考査考点】**
1. 面積等式による角の二等分線の長さ公式の導出技能。
2. 四角形の内角関係からの交角特定と三角形の面積計算。
3. 幾何学的な比の式から無次元比 $x$ による関数表示への代数変形。

## 大問IV 問2：角の二等分線の性質による数値計算

**問題コード**: `math-q-IV_2` | **正解参照**: `MATH_C1:IV_2`

### 出題のポイント
- 角の二等分線定理による辺の比 $x = AB/AC$ の決定
- 前問で導出した面積比の公式への数値代入

### 詳細解説
**【題目大意】**
$\text{BD} = 8, \text{BC} = 10$ のとき、辺の比 $x = \frac{AB}{AC}$ および面積比 $k$ の値を求める。

**【公式正解】**
- $\text{M} = 4$ ($x = 4$)
- $\text{NOP} = 325$ ($k = \frac{3}{25}$)

**【詳細推導・解答プロセス】**
**(1) $x$ の値の決定**
点 D は辺 BC 上にあるので：
$$\text{CD} = \text{BC} - \text{BD} = 10 - 8 = 2$$
線分 AD は $\angle \text{BAC}$ の二等分線であるから、角の二等分線の性質より：
$$\frac{\text{AB}}{\text{AC}} = \frac{\text{BD}}{\text{CD}}$$
したがって：
$$x = \frac{8}{2} = 4$$
よって、$\text{M} = 4$ である。

**(2) 面積比 $k$ の計算**
問 1 で求めた面積比の関数：
$$k = \frac{3x}{4(x + 1)^2}$$
に $x = 4$ を代入すると：
$$k = \frac{3 \times 4}{4(4 + 1)^2} = \frac{12}{4 \times 25} = \frac{3}{25}$$
したがって、$\text{N} = 3, \text{OP} = 25$ (NOP = 325) である。

**【考査考点】**
1. 三角形の角の二等分線定理（内分比＝隣辺比）の適用。
2. 代数的に求めた面積比関数への具象値代入と約分計算。
