## 数学 コース1 第I問 [1]：2次関数の決定と指定区間における単調増加条件

**【題目大意】**
$x$ の2次関数 $y = ax^2 + bx + c$ が，条件【*】「$x = -1$ で $y = -8$，$x = 3$ で $y = 16$ であり，区間 $-1 \le x \le 3$ において $x$ の値が増加すると共に $y$ の値も増加する」を満たすとき，$a, b, c$ の関係式および $a$ のとり得る範囲を求める。

**【公式正解】**
- $b = \boxed{\text{AB}} a + \boxed{\text{C}} \implies b = -2a + 6$ （$\text{ABC} = -26$）
- $c = \boxed{\text{DE}} a - \boxed{\text{F}} \implies c = -3a - 2$ （$\text{DEF} = -32$）
- 軸の方程式：$x = \boxed{\text{G}} - \frac{\boxed{\text{H}}}{a} \implies x = 1 - \frac{3}{a}$ （$\text{GH} = 13$）
- $a$ の範囲：$0 < a \le \frac{\boxed{\text{I}}}{\boxed{\text{J}}} \implies 0 < a \le \frac{3}{2}$ （$\text{IJ} = 32$） または $\frac{\boxed{\text{KL}}}{\boxed{\text{M}}} \le a < 0 \implies -\frac{3}{2} \le a < 0$ （$\text{KLM} = -32$）

**【詳細推導・解答プロセス】**
1. **2点を通る条件からの $b, c$ の表式**：
$y = ax^2 + bx + c$ に対し：
- $x = -1$ のとき：
$$a(-1)^2 + b(-1) + c = -8 \implies a - b + c = -8 \quad \textcircled{A}$$
- $x = 3$ のとき：
$$a(3)^2 + b(3) + c = 16 \implies 9a + 3b + c = 16 \quad \textcircled{B}$$
$\textcircled{B} - \textcircled{A}$ を計算すると：
$$(9a + 3b + c) - (a - b + c) = 16 - (-8)$$
$$8a + 4b = 24 \implies 2a + b = 6 \implies b = -2a + 6$$
よって，$\boxed{\text{AB}} = -2, \; \boxed{\text{C}} = 6$（$\text{ABC} = -26$）となる。

これを $\textcircled{A}$ に代入して $c$ を求めると：
$$c = -8 - a + b = -8 - a + (-2a + 6) = -3a - 2$$
問題文の形式 $c = \boxed{\text{DE}} a - \boxed{\text{F}}$ に合わせると：
$$c = -3a - 2 \implies \boxed{\text{DE}} = -3, \; \boxed{\text{F}} = 2$$
よって，$\text{DEF} = -32$ である。

2. **放物線の軸の方程式**：
2次関数を変形（平方完成）する：
$$y = a\left(x^2 + \frac{b}{a}x\right) + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$$
グラフの軸の方程式は：
$$x = -\frac{b}{2a} = -\frac{-2a + 6}{2a} = -\left(-1 + \frac{3}{a}\right) = 1 - \frac{3}{a}$$
したがって，$\boxed{\text{G}} = 1, \; \boxed{\text{H}} = 3$（$\text{GH} = 13$）である。

3. **区間 $[-1, 3]$ で単調増加する条件**：
区間 $-1 \le x \le 3$ で $x$ の増加に伴い $y$ も常に増加（単調増加）するためには，放物線の開きと軸の位置関係を考える必要がある：

- **ケース 1：$a > 0$（下に凸の放物線）**
下に凸の放物線は軸の右側（$x \ge \text{軸}$）で単調増加する。
したがって，区間 $[-1, 3]$ の全体が軸の右側にあればよいので：
$$\text{軸} \le -1 \implies 1 - \frac{3}{a} \le -1 \implies 2 \le \frac{3}{a}$$
$a > 0$ より両辺に $a$ を掛けて：
$$2a \le 3 \implies a \le \frac{3}{2}$$
$a > 0$ と合わせて：
$$0 < a \le \frac{3}{2} \quad (\boxed{\text{I}} = 3, \; \boxed{\text{J}} = 2 \implies \text{IJ} = 32)$$

- **ケース 2：$a < 0$（上に凸の放物線）**
上に凸の放物線は軸の左側（$x \le \text{軸}$）で単調増加する。
したがって，区間 $[-1, 3]$ の全体が軸の左側にあればよいので：
$$\text{軸} \ge 3 \implies 1 - \frac{3}{a} \ge 3 \implies -\frac{3}{a} \ge 2$$
$a < 0$ より両辺に $a$（負数）を掛けると不等号が反転する：
$$-3 \le 2a \implies a \ge -\frac{3}{2}$$
$a < 0$ と合わせて：
$$-\frac{3}{2} \le a < 0 \quad (\boxed{\text{KL}} = -3, \; \boxed{\text{M}} = 2 \implies \text{KLM} = -32)$$

**【考査考点】**
2次関数の決定（連立方程式），放物線の軸の方程式，閉区間における2次関数の単調性条件（下に凸・上に凸の場合分け）。

## 数学 コース1 第I問 [2]：区間の集合演算（共通部分・和集合・補集合）と2次不等式

**【題目大意】**
$a < b < c < d$ を満たす実数に対し，$A = [a, c], B = [b, d]$ とする。共通部分が
$$A \cap B = \{x \mid x^2 - 4x + 3 \le 0\}$$
を満たすとき，(1) $A \cup B = \{x \mid x^2 - 5x - 24 \le 0\}$ の場合，および (2) $A \cap \overline{B} = \{x \mid x^2 + 5x - 6 \le 0 \text{ かつ } x \neq 1\}, \overline{A} \cap B = \{x \mid x^2 - 9x + 18 \le 0 \text{ かつ } x \neq 3\}$ の場合における $a, b, c, d$ の値を求める。

**【公式正解】**
- (1) $a = -3, b = 1, c = 3, d = 8$ （$\text{NO} = -3, \text{P} = 1, \text{Q} = 3, \text{R} = 8$）
- (2) $a = -6, b = 1, c = 3, d = 6$ （$\text{ST} = -6, \text{U} = 1, \text{V} = 3, \text{W} = 6$）

**【詳細推導・解答プロセス】**
1. **前提条件 $A \cap B$ の解析**：
$a < b < c < d$ より，数直線上で区間 $A = [a, c]$ と $B = [b, d]$ の共通部分は：
$$A \cap B = [b, c] = \{x \mid b \le x \le c\}$$
与えられた2次不等式を解くと：
$$x^2 - 4x + 3 \le 0 \implies (x - 1)(x - 3) \le 0 \implies 1 \le x \le 3$$
したがって，$[b, c] = [1, 3]$ より直ちに次が確定する：
$$b = 1, \quad c = 3$$

2. **(1) の場合**：
和集合 $A \cup B$ は，数直線上で全体をつないだ区間であるから：
$$A \cup B = [a, d] = \{x \mid a \le x \le d\}$$
与えられた2次不等式を解くと：
$$x^2 - 5x - 24 \le 0 \implies (x + 3)(x - 8) \le 0 \implies -3 \le x \le 8$$
したがって，$[a, d] = [-3, 8]$ より：
$$a = -3, \quad d = 8$$
よって，$\boxed{\text{NO}} = -3, \; \boxed{\text{P}} = 1, \; \boxed{\text{Q}} = 3, \; \boxed{\text{R}} = 8$ である。

3. **(2) の場合**：
- $A \cap \overline{B}$ は「$A$ に属し $B$ に属さない部分」であり：
$$A \cap \overline{B} = [a, b) = [a, 1) = \{x \mid a \le x < 1\}$$
不等式 $x^2 + 5x - 6 \le 0$ を解くと $(x + 6)(x - 1) \le 0 \implies -6 \le x \le 1$。
$x \neq 1$ であるから，これは半開区間 $[-6, 1)$ を表す。
したがって：
$$a = -6$$

- $\overline{A} \cap B$ は「$B$ に属し $A$ に属さない部分」であり：
$$\overline{A} \cap B = (c, d] = (3, d] = \{x \mid 3 < x \le d\}$$
不等式 $x^2 - 9x + 18 \le 0$ を解くと $(x - 3)(x - 6) \le 0 \implies 3 \le x \le 6$。
$x \neq 3$ であるから，これは半開区間 $(3, 6]$ を表す。
したがって：
$$d = 6$$

以上より，$a = -6, \; b = 1, \; c = 3, \; d = 6$ となり：
$\boxed{\text{ST}} = -6, \; \boxed{\text{U}} = 1, \; \boxed{\text{V}} = 3, \; \boxed{\text{W}} = 6$ である。

**【考査考点】**
区間の集合演算（共通部分，和集合，補集合，差集合），2次不等式の解と境界値の対応関係。

## 数学 コース1 第II問 [1]：多項式の二項展開と特定の項の係数・最大係数

**【題目大意】**
多項式 $P = (3x + 4y + 1)^5$ の展開式における $x^n y$ の係数を $a_n$ とする。
(1) 二項定理を用いて $xy$ の係数 $a_1$ を求める。
(2) $n$ のとり得る値の総数と，$a_n$ が最大となる $n$ の値を求める。

**【公式正解】**
- 項：$\boxed{\text{AB}} (3x + 1)^{\boxed{\text{C}}} y \implies 20 (3x + 1)^4 y$ （$\text{AB} = 20, \text{C} = 4$）
- $(3x + 1)^4$ における $x$ の係数：$\boxed{\text{DE}} = 12$
- $a_1 = \boxed{\text{FGH}} = 240$
- $n$ のとり得る値の個数：$\boxed{\text{I}} = 5$
- $a_n$ が最大となる $n$：$\boxed{\text{J}} = 3$

**【詳細推導・解答プロセス】**
1. **(1) 二項定理の適用と $a_1$ の算出**：
$P = \{(3x + 1) + 4y\}^5$ とみなして二項定理を適用する：
$$P = \sum_{k=0}^5 \binom{5}{k} (3x + 1)^{5-k} (4y)^k$$
$y$ の1次の項（$y^1$）が現れるのは $k = 1$ の項である：
$$\binom{5}{1} (3x + 1)^4 (4y) = 5 \times 4y \times (3x + 1)^4 = 20 (3x + 1)^4 y$$
したがって，$\boxed{\text{AB}} = 20, \; \boxed{\text{C}} = 4$ である。

次に，$(3x + 1)^4$ を二項展開して $x$ の1次の項を求める：
$$\binom{4}{1} (3x)^1 (1)^3 = 4 \times 3x = 12x$$
したがって，$(3x + 1)^4$ における $x$ の係数は $\boxed{\text{DE}} = 12$ である。

よって，$P$ の展開式において $xy$ を含む項は：
$$20 \times (12x) \times y = 240 xy$$
となり，係数は $a_1 = \boxed{\text{FGH}} = 240$ である。

2. **(2) $n$ の個数と最大係数 $a_n$ の特定**：
$y^1$ を含む全項は $20 (3x + 1)^4 y$ を展開したものであり，$(3x + 1)^4$ に現れる $x$ の次数 $n$ は $0, 1, 2, 3, 4$ の 5 通りである。
したがって，$n$ のとり得る値の総数は $\boxed{\text{I}} = 5$ 個である。

一般項における $x^n y$ の係数 $a_n$ は：
$$a_n = 20 \times \binom{4}{n} 3^n$$
各 $n$ に対する $a_n$ の値を具体的に計算する：
- $n = 0$：$a_0 = 20 \times 1 \times 3^0 = 20$
- $n = 1$：$a_1 = 20 \times 4 \times 3^1 = 240$
- $n = 2$：$a_2 = 20 \times 6 \times 3^2 = 20 \times 54 = 1080$
- $n = 3$：$a_3 = 20 \times 4 \times 3^3 = 20 \times 108 = 2160$
- $n = 4$：$a_4 = 20 \times 1 \times 3^4 = 20 \times 81 = 1620$

値を比較すると，最大値をとるのは $n = 3$ のとき（$a_3 = 2160$）である。
したがって，$\boxed{\text{J}} = 3$ である。

**【考査考点】**
二項定理の段階的展開，多項式展開の一般項の係数計算，離散数列の最大値判定。

## 数学 コース1 第II問 [2]：整式の因数分解，不定方程式の整数解と無理数の有理化条件

**【題目大意】**
整式 $P = (x-1)^2(y+5) + (2x-3)(y+4) - (x-1)^2$ について：
(1) $P$ を $(x^2 - K)(y + L)$ の形に因数分解する。
(2) $P = 7$ となる整数解組 $(x, y)$ を求める。
(3) $a$ を有理数とし，$x = \sqrt{2} + 2\sqrt{3}, y = a + \sqrt{6}$ のとき $P$ が有理数となる $a$ の値を求める。

**【公式正解】**
- (1) $P = (x^2 - \boxed{\text{K}})(y + \boxed{\text{L}}) \implies (x^2 - 2)(y + 4)$ （$\text{KL} = 24$）
- (2) $(\pm \boxed{\text{M}}, \boxed{\text{NOP}}) = (\pm 1, -11)$ （$\text{M} = 1, \text{NOP} = -11$），$(\pm \boxed{\text{Q}}, \boxed{\text{RS}}) = (\pm 3, -3)$ （$\text{Q} = 3, \text{RS} = -3$）
- (3) $a = \boxed{\text{TU}} = -7$

**【詳細推導・解答プロセス】**
1. **(1) 整式 $P$ の因数分解**：
第1項と第3項をまとめる：
$$(x-1)^2(y+5) - (x-1)^2 = (x-1)^2 \{(y+5) - 1\} = (x-1)^2(y+4)$$
したがって，全体で共通因数 $(y+4)$ がくくり出せる：
$$P = (x-1)^2(y+4) + (2x-3)(y+4) = \left\{(x-1)^2 + (2x-3)\right\}(y+4)$$
中括弧内を展開して整理すると：
$$(x^2 - 2x + 1) + 2x - 3 = x^2 - 2$$
よって：
$$P = (x^2 - 2)(y + 4)$$
これより，$\boxed{\text{K}} = 2, \; \boxed{\text{L}} = 4$（$\text{KL} = 24$）である。

2. **(2) $P = 7$ の整数解**：
$$(x^2 - 2)(y + 4) = 7$$
$x, y$ は整数であるから，$x^2 - 2$ および $y + 4$ も整数であり，その積が素数 7 である。
7 の約数の組は $(1, 7), (7, 1), (-1, -7), (-7, -1)$ の 4 通りである。
ここで $x^2 \ge 0$ より $x^2 - 2 \ge -2$ であるから：
- $x^2 - 2 = 1 \implies x^2 = 3$ （整数解なし）
- $x^2 - 2 = 7 \implies x^2 = 9 \implies x = \pm 3$
  このとき $y + 4 = 1 \implies y = -3$
- $x^2 - 2 = -1 \implies x^2 = 1 \implies x = \pm 1$
  このとき $y + 4 = -7 \implies y = -11$
- $x^2 - 2 = -7$ は $x^2 = -5$ となり解なし。

したがって，求める整数の組 $(x, y)$ は：
$$(\pm 1, -11), \quad (\pm 3, -3)$$
これより，$\boxed{\text{M}} = 1, \; \boxed{\text{NOP}} = -11, \; \boxed{\text{Q}} = 3, \; \boxed{\text{RS}} = -3$ である。

3. **(3) $P$ が有理数となる条件**：
$x = \sqrt{2} + 2\sqrt{3}$ のとき：
$$x^2 = (\sqrt{2} + 2\sqrt{3})^2 = 2 + 4\sqrt{6} + 12 = 14 + 4\sqrt{6}$$
したがって：
$$x^2 - 2 = (14 + 4\sqrt{6}) - 2 = 12 + 4\sqrt{6} = 4(3 + \sqrt{6})$$
また，$y = a + \sqrt{6}$ より：
$$y + 4 = (a + 4) + \sqrt{6}$$
これらを $P$ に代入して積を展開する：
$$P = (12 + 4\sqrt{6})\{(a + 4) + \sqrt{6}\}$$
$$P = 12(a + 4) + 12\sqrt{6} + 4(a + 4)\sqrt{6} + 4 \times 6$$
$$P = \{12(a + 4) + 24\} + \{12 + 4(a + 4)\}\sqrt{6}$$
$a$ は有理数であるから，$\sqrt{6}$（無理数）の係数が $0$ になることが，$P$ が有理数となる必要十分条件である：
$$12 + 4(a + 4) = 0 \implies 4(a + 4) = -12 \implies a + 4 = -3 \implies a = -7$$
したがって，$\boxed{\text{TU}} = -7$ である。

**【考査考点】**
共通因数の括り出しによる因数分解，素因数分解を用いた不定方程式の整数解，無理数を含む式の有理数条件（無理数の相等）。

## 数学 コース1 第III問 (1)-(4)：2次方程式の解の配置問題と係数の符号・大小関係

**【題目大意】**
$a, b, c$ は整数，$a > 0$ とする。2次関数 $y = ax^2 - 2bx + c$ のグラフが $x$ 軸と共有点をもち，それらがすべて区間 $0 < x < 1$ の中にあるとき，(1) $a$ と $b$ の大小，(2) $b$ と $c$ の正負，(3) $2b$ と $a+c$ の大小，(4) $b$ と $c$ の大小 を判定する。

**【公式正解】**
- (1) $a$ と $b$ の大小：$\textcircled{0}$ （$a > b$）
- (2) $b$ と $c$ の条件：$\textcircled{3}$ （$b > 0, c > 0$）
- (3) $2b$ と $a + c$ の大小：$\textcircled{1}$ （$2b < a + c$）
- (4) $b$ と $c$ の大小：$\textcircled{0}$ （$b > c$）

**【詳細推導・解答プロセス】**
$f(x) = ax^2 - 2bx + c$ とおく。
条件より，放物線 $y = f(x)$ は下に凸（$a > 0$）であり，$x$ 軸との共有点の $x$ 座標（実数解）がすべて区間 $0 < x < 1$ に存在する。
解の配置理論より，次の 4 条件が同時に成り立つ：
1. **判別式**：$D/4 = (-b)^2 - ac = b^2 - ac \ge 0 \implies b^2 \ge ac$
2. **軸の位置**：軸は $x = \frac{2b}{2a} = \frac{b}{a}$ であり：
   $$0 < \frac{b}{a} < 1$$
3. **左端点での値**：$f(0) > 0$
4. **右端点での値**：$f(1) > 0$

各小問を検討する：

1. **(1) $a$ と $b$ の大小**：
軸の条件 $0 < \frac{b}{a} < 1$ において，$a > 0$ であるから両辺に $a$ を掛けると：
$$0 < b < a$$
したがって，$a > b$ である。選択肢は $\textcircled{0}$ である。

2. **(2) $b$ と $c$ の正負**：
上述の通り $b > 0$ である。
また，端点値より $f(0) = c > 0$ である。
したがって，$b > 0, c > 0$ である。選択肢は $\textcircled{3}$ である。

3. **(3) $2b$ と $a + c$ の大小**：
端点値より：
$$f(1) = a(1)^2 - 2b(1) + c = a - 2b + c > 0$$
移項すると：
$$2b < a + c$$
したがって，選択肢は $\textcircled{1}$ である。

4. **(4) $b$ と $c$ の大小**：
判別式より $ac \le b^2$ である。
また，(1)より $b < a$ であるから，両辺に正数 $b$ を掛けると $b^2 < ab$ である。
これらを合わせると：
$$ac \le b^2 < ab \implies ac < ab$$
$a > 0$ であるから，両辺を $a$ で割ると：
$$c < b \implies b > c$$
したがって，$b > c$ である。選択肢は $\textcircled{0}$ である。

**【考査考点】**
2次方程式の解の配置（判別式・軸・端点値），不等式の論理的推論と文字の大小判定。

## 数学 コース1 第III問 (5)：係数が整数の場合の a の最小値と対応する b, c の決定

**【題目大意】**
(1)～(4) の条件を満たす整数 $a, b, c$ について，$a$ のとり得る最小の整数値 $E$ と，そのときの $b, c$ の値 $F, G$ を求める。

**【公式正解】**
- $a$ の最小の整数：$\boxed{\text{E}} = 4$
- そのときの $b$ の値：$\boxed{\text{F}} = 2$
- そのときの $c$ の値：$\boxed{\text{G}} = 1$

**【詳細推導・解答プロセス】**
(1)～(4) より，整数 $a, b, c$ は以下の条件をすべて満たさなければならない：
1. $a > b > c \ge 1$ （すべて正の整数）
2. $b^2 \ge ac$ （$x$ 軸と共有点をもつ）
3. $a + c > 2b$ （$f(1) > 0$）

正の整数の大小関係 $a > b > c \ge 1$ より，最小でも $c \ge 1, b \ge 2, a \ge 3$ である。

- **$a = 3$ の場合を検証**：
  $3 > b > c \ge 1$ を満たす整数は $b = 2, c = 1$ の1組しかない。
  このとき：
  - $b^2 = 2^2 = 4$
  - $ac = 3 \times 1 = 3$
  $b^2 \ge ac$（$4 \ge 3$）は満たす。
  しかし，条件 3 を確認すると：
  $$a + c = 3 + 1 = 4, \quad 2b = 2 \times 2 = 4$$
  となり，$a + c > 2b$（$4 > 4$）を満たさない（$f(1) = 0$ となり，解 $x=1$ が区間 $0 < x < 1$ の外になってしまう）。
  したがって，$a = 3$ は不適である。

- **$a = 4$ の場合を検証**：
  $4 > b > c \ge 1$ より，$(b, c)$ の候補は $(3, 1), (3, 2), (2, 1)$ である。
  - もし $b = 3$ ならば $2b = 6$。一方 $a + c = 4 + c \le 4 + 2 = 6$ となり，$a + c > 2b$ を満たさない。
  - したがって $b = 2$ でなければならない。このとき $c < b$ より $c = 1$ と確定する。
  $(a, b, c) = (4, 2, 1)$ について各条件を確認する：
  1. $4 > 2 > 1 \ge 1$ （成立）
  2. $b^2 = 4, \; ac = 4 \times 1 = 4 \implies b^2 \ge ac$（$4 \ge 4$ で成立，重解）
  3. $a + c = 4 + 1 = 5, \; 2b = 4 \implies 5 > 4$（成立）
  4. 2次方程式は：
     $$4x^2 - 4x + 1 = 0 \implies (2x - 1)^2 = 0 \implies x = \frac{1}{2}$$
     重解 $x = \frac{1}{2}$ は確かに区間 $0 < x < 1$ の中にある。

したがって，$a$ のとり得る最小の整数は $4$ であり，そのとき $b = 2, c = 1$ である。
よって，$\boxed{\text{E}} = 4, \; \boxed{\text{F}} = 2, \; \boxed{\text{G}} = 1$ である。

**【考査考点】**
解の配置条件と整数制約の融合問題，境界条件の厳密な検証（不等号の等号成立可否）。

## 数学 コース1 第IV問 (1)：直円錐の展開図（扇形の中心角と面積）

**【題目大意】**
底面の半径 $r = 1$，母線の長さ $R = 3$ の直円錐の頂点を O とする。(1) この直円錐の側面を展開してできる扇形の中心角 $\theta$ [度] と，その面積 $S$ を求める。

**【公式正解】**
- 扇形の中心角：$\boxed{\text{ABC}} = 120^\circ$
- 扇形の面積：$\boxed{\text{D}}\pi = 3\pi$ （$\text{D} = 3$）

**【詳細推導・解答プロセス】**
1. **扇形の中心角 $\theta$ の導出**：
直円錐の側面を展開した扇形の半径は母線の長さ $R = 3$ である。
扇形の弧の長さは，底面の円周長に等しい：
$$L = 2\pi r = 2\pi \times 1 = 2\pi$$
半径 $R = 3$ の円全体の周長は $2\pi R = 6\pi$ であるから，中心角 $\theta$ は：
$$\theta = 360^\circ \times \frac{L}{2\pi R} = 360^\circ \times \frac{2\pi}{6\pi} = 360^\circ \times \frac{1}{3} = 120^\circ$$
（弧度法では $\theta = \frac{2\pi}{3}\text{ rad}$）
したがって，中心角は $\boxed{\text{ABC}} = 120^\circ$ である。

2. **扇形の面積 $S$ の算出**：
扇形の面積は：
$$S = \frac{1}{2} R L = \frac{1}{2} \times 3 \times 2\pi = 3\pi$$
（あるいは $S = \pi R^2 \times \frac{120^\circ}{360^\circ} = \pi \times 3^2 \times \frac{1}{3} = 3\pi$）
したがって，$\boxed{\text{D}} = 3$ である。

**【考査考点】**
直円錐の展開図の幾何学的性質，扇形の弧長・中心角・面積の公式。

## 数学 コース1 第IV問 (2)：円錐側面上を通る最短経路長とその最小値

**【題目大意】**
底面の直径の両端を A, B とする。母線 OB 上に点 P をとり，円錐側面に沿って A から P を通って A へ戻る道の長さを $l$ とする。
(i) $\text{OP} = 2$ のときの最小の $l$ を求める。
(ii) P が OB 上を動くとき，$l$ が最小となる $\text{OP}$ の値とそのときの $l$ の最小値を求める。

**【公式正解】**
- (i) $l = \boxed{\text{E}}\sqrt{\boxed{\text{F}}} = 2\sqrt{7}$ （$\text{EF} = 27$）
- (ii) $\text{OP} = \frac{\boxed{\text{G}}}{\boxed{\text{H}}} = \frac{3}{2}$ （$\text{GH} = 32$），$l = \boxed{\text{I}}\sqrt{\boxed{\text{J}}} = 3\sqrt{3}$ （$\text{IJ} = 33$）

**【詳細推導・解答プロセス】**
円錐の側面を展開図に広げて考える。
扇形の頂点は O，中心角は $120^\circ$ である。
母線 OA を一方の境界とし，もう一方の境界を $\text{OA}'$ とする（A と $\text{A}'$ は組み立てたときに重なる同一の点である）。
線分 AB は底面の直径であるから，底面の円周上で A から B までの弧長は全体の半分である。
したがって，展開図において線分 OB は扇形の中心角 $120^\circ$ をちょうど二等分する：
$$\angle \text{AOB} = \angle \text{BOA}' = 60^\circ$$

側面に沿って「A から出発して P を通り A（$\text{A}'$）へ戻る道」の長さ $l$ は，展開図上では「線分 AP の長さ」と「線分 $\text{PA}'$ の長さ」の和に等しい：
$$l = \text{AP} + \text{PA}'$$

1. **(i) $\text{OP} = 2$ の場合**：
$\triangle \text{OAP}$ において，$OA = 3, \; OP = 2, \; \angle \text{AOP} = 60^\circ$ である。
余弦定理を用いると：
$$\text{AP}^2 = OA^2 + OP^2 - 2 \times OA \times OP \times \cos 60^\circ$$
$$\text{AP}^2 = 3^2 + 2^2 - 2 \times 3 \times 2 \times \frac{1}{2} = 9 + 4 - 6 = 7$$
$$\text{AP} = \sqrt{7}$$
同様に，$\triangle \text{OPA}'$ も合同（$OA' = 3, \; OP = 2, \; \angle \text{POA}' = 60^\circ$）であるから：
$$\text{PA}' = \sqrt{7}$$
したがって，最小の道のりは：
$$l = \text{AP} + \text{PA}' = \sqrt{7} + \sqrt{7} = 2\sqrt{7}$$
よって，$\boxed{\text{E}} = 2, \; \boxed{\text{F}} = 7$（$\text{EF} = 27$）である。

2. **(ii) $l$ が最小となるときの $\text{OP}$ と $l$ の値**：
展開図上で点 A から点 $\text{A}'$ に至る経路の長さ $\text{AP} + \text{PA}'$ が最小となるのは，点 A と点 $\text{A}'$ を直接結ぶ線分 $\text{AA}'$ が直線となるとき（三角不等式において等号が成立するとき）である。
二等辺三角形 $\triangle \text{OAA}'$（$OA = OA' = 3, \; \angle \text{AOA}' = 120^\circ$）において，線分 OB は頂角の二等分線であるため，底辺 $\text{AA}'$ の垂直二等分線となる。
すなわち，線分 $\text{AA}'$ と線分 OB の交点を P とするとき，$\text{AP} + \text{PA}'$ は直線距離 $\text{AA}'$ と一致して最小となる。

直角三角形 $\triangle \text{OPA}$（$\angle \text{OPA} = 90^\circ, \; \angle \text{AOP} = 60^\circ$）において：
$$\text{OP} = OA \cos 60^\circ = 3 \times \frac{1}{2} = \frac{3}{2}$$
したがって，$\boxed{\text{G}} = 3, \; \boxed{\text{H}} = 2$（$\text{GH} = 32$）である。

このときの直線距離 $l = \text{AA}'$ は：
$$l = 2 \times \text{AP} = 2 \times \left(OA \sin 60^\circ\right) = 2 \times 3 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}$$
（あるいは余弦定理より $\text{AA}'^2 = 3^2 + 3^2 - 2 \times 3 \times 3 \cos 120^\circ = 9 + 9 - 18(-1/2) = 27 \implies \text{AA}' = \sqrt{27} = 3\sqrt{3}$）
したがって，$\boxed{\text{I}} = 3, \; \boxed{\text{J}} = 3$（$\text{IJ} = 33$）である。

**【考査考点】**
展開図を用いた空間幾何から平面幾何への帰着，余弦定理，最短経路問題（直線距離）。
