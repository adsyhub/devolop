## 問1：シアノバクテリア（ネンジュモ）の光合成と炭酸同化

**【考査考点】**：原核生物の酸素発生型光合成, 電子供与体としての水（$\text{H}_2\text{O}$）の光分解と酸素発生, バクテリオクロロフィル（紅色硫黄細菌等）との相違点

**【題目大意】**
ネンジュモ（*Nostoc*）などのシアノバクテリア（cyanobacteria）の炭酸同化について、**正しい文**を一つ選べ。

**【公式正解】**：$\textcircled{5}$（水の分解によって酸素を発生させる）

**【詳細推導・各選択肢分析】**
シアノバクテリアは原核生物でありながら、陸上植物と同じくチラコイド膜上に**クロロフィル a** をもち、光化学系 II と光化学系 I を用いた酸素発生型光合成をおこなう。
1. $\textcircled{1}$：バクテリオクロロフィルを利用するのは紅色細菌や緑色硫黄細菌などの光合成細菌であり、シアノバクテリアはクロロフィル a を利用する。誤り。
2. $\textcircled{2}$：シアノバクテリアは原核生物であるため、膜構造の細胞小器官である葉緑体（chloroplast）をもたない（細胞質内のチラコイド膜で光合成を行う）。誤り。
3. $\textcircled{3}$：アンモニウムイオンなどの無機物を酸化した化学エネルギーを用いるのは化学合成細菌（硝化菌など）である。誤り。
4. $\textcircled{4}$：硫化水素（$\text{H}_2\text{S}$）を電子供与体として用いるのは硫黄細菌であり、酸素は発生しない。誤り。
5. $\textcircled{5}$：シアノバクテリアは水分子（$\text{H}_2\text{O}$）を光分解して電子を取り出し、副産物として酸素（$\text{O}_2$）を発生させる。**正しい**。

したがって、適する選択肢は **$\textcircled{5}$** である。

## 問2：原核細胞・動物細胞・植物細胞の細胞構造の比較

**【考査考点】**：細胞膜の普遍性（すべての細胞に存在）, ミトコンドリアの分布（真核細胞共通、原核細胞にはない）, 葉緑体と細胞壁の有無（動物・植物・原核生物の区別）

**【題目大意】**
原核細胞、真核細胞（動物細胞・植物細胞）に含まれる細胞構造の有無（＋／－）をまとめた表から、構造 A～C の組み合わせを選べ。
- 核：原核（－）、動物（＋）、植物（＋）
- 細胞膜：原核（＋）、動物（＋）、植物（＋）
- A：原核（－）、動物（＋）、植物（＋）
- B：原核（－）、動物（－）、植物（＋）
- C：原核（＋）、動物（－）、植物（＋）

**【公式正解】**：$\textcircled{2}$（A: ミトコンドリア, B: 葉緑体, C: 細胞壁）

**【詳細推導・各構造の同定】**
1. **構造 A**：
   原核細胞には存在せず、真核細胞である動物細胞と植物細胞の双方に存在する構造は **ミトコンドリア**（呼吸を行う細胞小器官）である。
2. **構造 B**：
   原核細胞および動物細胞には存在せず、光合成をおこなう植物細胞にのみ存在する構造は **葉緑体** である。
3. **構造 C**：
   動物細胞には存在せず、原核細胞（ペプチドグリカン等）および植物細胞（セルロース）に存在する構造は **細胞壁** である。

表の組み合わせと照合すると、A: ミトコンドリア、B: 葉緑体、C: 細胞壁 となるのは **$\textcircled{2}$** である。

## 問3：細胞呼吸の経路・解糖系・クエン酸回路・電子伝達系

**【考査考点】**：解糖系の生成物（ピルビン酸）, クエン酸回路の最初の生成物（クエン酸）, 脱炭酸反応（$\text{CO}_2$ 放出）と最終電子受容体（$\text{O}_2$）

**【題目大意】**
呼吸（respiration）の模式図において、空欄 A～D にあてはまる物質の組み合わせを選べ。
- グルコース $\to$ A $\to$ アセチルCoA
- アセチルCoA が回路に入り、オキサロ酢酸と結合して B を形成 $\to$ コハク酸へ進む過程で C を放出
- 電子伝達系で NADH, $\text{FADH}_2$ からの電子と物質 D が反応して $\text{H}_2\text{O}$ を生成

**【公式正解】**：$\textcircled{4}$（A: ピルビン酸, B: クエン酸, C: $\text{CO}_2$, D: $\text{O}_2$）

**【詳細推導・各代謝段階の同定】**
1. **空欄 A**：
   細胞質基質で行われる解糖系において、グルコース（$\text{C}_6$）が分解されて生成するのは **ピルビン酸**（$\text{C}_3$）である。
2. **空欄 B**：
   ミトコンドリアのマトリックスで行われるクエン酸回路において、アセチルCoA（$\text{C}_2$）がオキサロ酢酸（$\text{C}_4$）と縮合して最初に生じるのは **クエン酸**（$\text{C}_6$）である。
3. **空欄 C**：
   クエン酸回路で脱炭酸酵素によって炭素骨格から切り離されて放出される気体は **二酸化炭素 $\text{CO}_2$** である。
4. **空欄 D**：
   ミトコンドリアの内膜で行われる電子伝達系の最終電子受容体であり、水素イオンおよび電子と結合して $\text{H}_2\text{O}$ を生成する物質は **酸素 $\text{O}_2$** である。

したがって、正しい組み合わせは **$\textcircled{4}$** である。

## 問4：植物の窒素代謝・窒素同化と根粒菌の窒素固定

**【考査考点】**：窒素同化（無機窒素化合物から有機窒素化合物の合成）, 窒素固定（大気中の $\text{N}_2$ からアンモニウムイオンへの還元）, マメ科植物と共生する根粒菌（*Rhizobium*）

**【題目大意】**
植物の窒素代謝に関する文中の空欄 a～d に入る語句の組み合わせを選べ。
「植物が根から吸収した無機窒素化合物を用いて有機物を合成する働きを [ a ] といい、つくられる有機物にはタンパク質や [ b ] などがある。
マメ科植物に共生する [ c ] は、空気中の窒素ガス（$\text{N}_2$）をアンモニウムイオンに変化させることができる。この働きを [ d ] という。」

**【公式正解】**：$\textcircled{3}$（a: 窒素同化, b: 核酸, c: 根粒菌, d: 窒素固定）

**【詳細推導・用語の整理】**
- **空欄 a**：硝酸イオンやアンモニウムイオンなどの無機窒素化合物を有機物に取り込む代謝経路は **窒素同化（nitrogen assimilation）** である。
- **空欄 b**：窒素を含む代表的な生体高分子はタンパク質（アミノ酸）と **核酸（ヌクレオチドの塩基に窒素を含む）** である。（デンプンは C, H, O のみからなり窒素を含まない。）
- **空欄 c**：マメ科植物の根に根粒を形成して共生する細菌は **根粒菌（*Rhizobium*）** である。（硝化菌は土壌中でアンモニウムイオンを亜硝酸・硝酸に酸化する独立栄養細菌。）
- **空欄 d**：大気中の不活性な窒素分子 $\text{N}_2$ をニトロゲナーゼによってアンモニウムイオンに還元する働きを **窒素固定（nitrogen fixation）** という。

したがって、適する選択肢は **$\textcircled{3}$** である。

## 問5：DNAの半保存的複製・複製フォークと伸長方向（$5' \to 3'$）

**【考査考点】**：DNAポリメラーゼの合成方向（常に $5' \to 3'$）, リーディング鎖（連続的合成）とラギング鎖（岡崎フラグメント）, 逆平行な2本鎖DNAの複製フォークの模式図

**【題目大意】**
複製フォークにおいて、新しく合成されるDNAの複製方向（矢印）が正しく示されている図を選べ。

**【公式正解】**：$\textcircled{2}$（新鎖が $5' \to 3'$ の向きに合成される図）

**【詳細推導・分子生物学的原理】**
1. **DNA複製の絶対原則**：
   DNAポリメラーゼは、既存のヌクレオチド鎖の $3'$ 末端のヒドロキシ基（$\text{-OH}$）に新しいヌクレオチドの $5'$ リン酸基をホスホジエステル結合で付加するため、**新生鎖の伸長方向は常に $5' \longrightarrow 3'$** である。
2. **鋳型鎖と新生鎖の逆平行性**：
   - 鋳型鎖が $3' \to 5'$（開裂部へ向かう鎖）の場合：新生鎖は $5' \to 3'$ の向きに複製フォークの進行方向へ向かって連続的に合成される（**リーディング鎖**）。
   - 鋳型鎖が $5' \to 3'$（開裂部へ向かう鎖）の場合：新生鎖は複製フォークの進行方向とは逆向き（開裂部から離れる向き）に $5' \to 3'$ で断片的に合成される（**ラギング鎖**）。
3. **図の判定**：
   新生鎖の矢印の根元が $5'$ 側、矢じり（先端）が $3'$ 側を指している図を選ぶと、**$\textcircled{2}$** が正確に一致する。

## 問6：遺伝暗号（コドン）の解読・アミノ酸配列の対応

**【考査考点】**：人工mRNAの繰り返し配列と読み枠（リーディングフレーム）, 2塩基・3塩基繰り返しのポリペプチド解析, システインをコードするコドンの決定

**【題目大意】**
人工合成 mRNA による無細胞翻訳系の実験結果から、システイン（cysteine）のコドンを選べ。
- $\text{UGUGUG}\dots$：システインとバリンの交互繰り返し
- $\text{UUGUUG}\dots$：ロイシンのみ、システインのみ、バリンのみの 3 種
- $\text{GGUGGU}\dots$：グリシンのみ、バリンのみ、トリプトファンのみの 3 種

**【公式正解】**：$\textcircled{1}$（UGU）

**【詳細推導・コドン解読プロセス】**
1. **$\text{UGUGUG}\dots$ の繰り返し配列**：
   トリプレット（3塩基）で区切ると、読み枠に関わらず：
   $$\text{UGU} - \text{GUG} - \text{UGU} - \text{GUG} \dots$$
   の 2 種類のコドンしか現れない。
   これがシステインとバリンのポリペプチドを与えるため、
   $$\{\text{システイン}, \text{バリン}\} = \{\text{UGU}, \text{GUG}\}$$
2. **$\text{GGUGGU}\dots$ の繰り返し配列**：
   読み枠 1：$\text{GGU}-\text{GGU}-\dots$（グリシン）
   読み枠 2：$\text{GUG}-\text{GUG}-\dots$（バリン）
   読み枠 3：$\text{UGG}-\text{UGG}-\dots$（トリプトファン）
   ここに現れるバリンは **GUG** であることが確定する。
3. **システインのコドンの決定**：
   バリンが $\text{GUG}$ であることから、ステップ 1 よりシステインをコードするコドンは残る **UGU** である。
   （検算：$\text{UUGUUG}\dots$ の 3 つの読み枠 $\text{UUG}$ (Leu), $\text{UGU}$ (Cys), $\text{GUU}$ (Val) でもシステインが正しく現れる。）

したがって、適する選択肢は **$\textcircled{1}$**（UGU）である。

## 問8：遺伝子の連鎖と組換え価の計算

**【考査考点】**：二遺伝子雑種の相反連鎖（相反配位）, 検定交雑の表現型分離比と配偶子比の一致, 組換え価の公式 $\text{組換え価} = \frac{\text{組換え配偶子数}}{\text{全配偶子数}} \times 100\%$

**【題目大意】**
遺伝子型 $\text{AAbb}$ と $\text{aaBB}$ を交雑して得た $\text{F}_1$（$\text{AaBb}$）に、検定交雑（$\text{aabb}$ を交雑）を行った。
表現型分離比が $[\text{AB}] : [\text{Ab}] : [\text{aB}] : [\text{ab}] = 1 : 8 : 8 : 1$ であったとき、$\text{F}_1$ で組換えを起こした配偶子の割合（組換え価 %）を求めよ。

**【公式正解】**：$\textcircled{3}$（11.1%）

**【詳細推導・解答プロセス】**
1. **親の染色体構成と配偶子の型**：
   親は $\text{AAbb} \times \text{aaBB}$ であるため、$\text{F}_1$ の染色体連鎖状態は $Ab$ と $aB$ が同一染色体上にある「相反（repulsion）」である。
   - 非組換え型（親型配偶子）：$Ab, aB$
   - 組換え型配偶子：$AB, ab$
2. **検定交雑と配偶子比**：
   $\text{aabb}$ の配偶子はすべて $ab$ のみであるため、次代の表現型分離比は $\text{F}_1$ が生み出した配偶子の比に等しい：
   $$[AB] : [Ab] : [aB] : [ab] = 1 : 8 : 8 : 1$$
   このうち、組換え型配偶子は $[AB]$（1）と $[ab]$（1）である。
3. **組換え価の計算**：
   $$\text{組換え配偶子の割合} = \frac{1 + 1}{1 + 8 + 8 + 1} \times 100\% = \frac{2}{18} \times 100\% = \frac{1}{9} \times 100\% \approx 11.11\%$$
選択肢の中で最も適当な値は **11.1**（選択肢 $\textcircled{3}$）である。

## 問9：精子形成過程における細胞の核相（単相 $n$）の同定

**【考査考点】**：精原細胞・一次精母細胞の核相（$2n$）, 減数第1分裂による相同染色体の分離（$2n \to n$）, 二次精母細胞（E）・精細胞（F）の単相（$n$）

**【題目大意】**
動物の精子形成過程の図において、核相が単相（半数体：$n$）である細胞の組み合わせを選べ。
- 始原生殖細胞 $\to$ A $\to$ B $\to$ C（成長） $\to$ D $\to$ E $\to$ F $\to$ 精子

**【公式正解】**：$\textcircled{5}$（E, F）

**【詳細推導・精子形成過程の追跡】**
1. **有糸分裂期（核相 $2n$）**：
   始原生殖細胞（$2n$）が体細胞分裂を繰り返して精原細胞 A, B（$2n$）になる。
2. **成長期（核相 $2n$）**：
   精原細胞 C（$2n$）が DNA を複製し、成長して肥大化した細胞 D が **一次精母細胞（$2n$）** である。
3. **減数第1分裂（核相 $2n \longrightarrow n$）**：

4. **減数第2分裂（核相 $n \longrightarrow n$）**：
   二次精母細胞 E が減数第 2 分裂を行い、姉妹染色分体が分離して生じる 4 個の細胞 F が **精細胞（$n$）** である。

したがって、核相が単相（$n$）である細胞は **E と F** であり、適する選択肢は **$\textcircled{5}$** である。

**【詳細推導・実験結果の対照分析】**

1. **無破壊**：卵細胞(+), 中央細胞(+), 助細胞 2個(+) $\implies$ 誘導率 98%
