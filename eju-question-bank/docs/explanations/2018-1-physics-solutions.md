## 問1：粗い水平面上の小物体を斜め上方に引くときの最大静止摩擦力と滑り出し条件

**【考査考点】**：水平・鉛直方向の力のつり合い, 垂直抗力 $N = mg - T\sin\theta$, 最大静止摩擦力 $F_{\text{max}} = \mu N$ と滑り出し限界

**【題目大意】**
粗い水平な床の上に質量 $m$ の小物体を置き、水平面となす角 $\theta$ を保ちながら糸を引いた。
張力が $T_0$ を超えたとき小物体が滑り始めた。床と小物体との間の静止摩擦係数を $\mu$ とするとき、比 $\frac{T_0}{mg}$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{\mu}{\cos\theta + \mu\sin\theta}$）

**【詳細推導・解答プロセス】**
小物体が滑り始める直前（張力 $T_0$）の力のつり合いを考える：
1. **鉛直方向の力のつり合い**：
   床からの垂直抗力を $N$ とすると、鉛直方向の上向きの力は $N + T_0 \sin\theta$、下向きの力は重力 $mg$ である。
   $$N + T_0 \sin\theta = mg \implies N = mg - T_0 \sin\theta$$
2. **水平方向の力のつり合い（滑り出しの限界条件）**：
   水平右向きの引く力は $T_0 \cos\theta$、左向きの最大静止摩擦力は $F_{\text{max}} = \mu N$ である。
   滑り始める限界では両者がつり合っている：
   $$T_0 \cos\theta = \mu N$$
3. **連立と整理**：
   $N$ の式を代入すると：
   $$T_0 \cos\theta = \mu (mg - T_0 \sin\theta) = \mu mg - \mu T_0 \sin\theta$$
   $T_0$ の項を左辺に移項してまとめる：
   $$T_0 (\cos\theta + \mu \sin\theta) = \mu mg$$
   したがって：
   $$\frac{T_0}{mg} = \frac{\mu}{\cos\theta + \mu \sin\theta}$$
よって、正解は選択肢 $\textcircled{5}$ である。

## 問2：連結物体の等加速度運動における加速度と張力の比較

**【考査考点】**：運動方程式の立式（系全体および個別のおもり）, 加速度 $a = \frac{m_2}{m_1 + m_2}g$, 張力 $T = \frac{m_1 m_2}{m_1 + m_2}g$

**【題目大意】**
なめらかな水平台上の質量 $m_1$ のおもり 1 と、定滑車を経てつるされた質量 $m_2$ のおもり 2 が軽い糸で結ばれている。
ケース A ($m_1=5\text{kg}, m_2=3\text{kg}$)、B ($m_1=4\text{kg}, m_2=4\text{kg}$)、C ($m_1=3\text{kg}, m_2=5\text{kg}$) について、加速度 $a$ が最大となる場合と、張力 $T$ が最大となる場合を選べ。

**【公式正解】**：$\textcircled{6}$（$a$ が最大：C、$T$ が最大：B）

**【詳細推導・解答プロセス】**
1. **運動方程式の導出**：
   - おもり 1（水平）：$m_1 a = T$
   - おもり 2（鉛直）：$m_2 a = m_2 g - T$
   両式を足すと：
   $$(m_1 + m_2) a = m_2 g \implies a = \frac{m_2}{m_1 + m_2} g$$
   糸の張力 $T$ は：
   $$T = m_1 a = \frac{m_1 m_2}{m_1 + m_2} g$$
2. **各ケースの計算（$m_1 + m_2 = 8\text{ kg}$ 一定）**：
   - **ケース A**：$a_A = \frac{3}{8} g$、 $T_A = \frac{5 \times 3}{8} g = \frac{15}{8} g$
   - **ケース B**：$a_B = \frac{4}{8} g$、 $T_B = \frac{4 \times 4}{8} g = \frac{16}{8} g = 2g$
   - **ケース C**：$a_C = \frac{5}{8} g$、 $T_C = \frac{3 \times 5}{8} g = \frac{15}{8} g$
3. **大小比較**：
   - 加速度 $a$：$a_C > a_B > a_A$ より、最大となるのは **C** である。
   - 張力 $T$：$T_B > T_A = T_C$ より、最大となるのは **B** である。
よって、正解は選択肢 $\textcircled{6}$ である。

## 問3：直線上での2連続弾性衝突における速度比の計算

**【考査考点】**：1次元弾性衝突（反発係数 $e=1$）の速度公式, 質量比による速度伝達比の連続積

**【題目大意】**
同一直線上に質量 $m$ の A、質量 $\frac{m}{2}$ の B、質量 $\frac{m}{4}$ の C が置かれている。
速さ $v_A$ の A が静止している B と弾性衝突し、続いて B が静止している C と弾性衝突した。
衝突後の C の速さ $v_C$ と $v_A$ の比 $\frac{v_C}{v_A}$ を求めよ。

**【公式正解】**：$\textcircled{6}$（$\frac{16}{9}$）

**【詳細推導・解答プロセス】**
質量 $m_1$（初速 $v_1$）の物体が静止している質量 $m_2$ の物体に弾性衝突するとき、衝突後の $m_2$ の速度 $v_2'$ は：
$$v_2' = \frac{2m_1}{m_1 + m_2} v_1$$
1. **第1の衝突（A と B）**：
   $m_A = m, m_B = \frac{m}{2}$ であるから：
   $$v_B = \frac{2m}{m + \frac{m}{2}} v_A = \frac{2}{\frac{3}{2}} v_A = \frac{4}{3} v_A$$
2. **第2の衝突（B と C）**：
   $m_B = \frac{m}{2}, m_C = \frac{m}{4}$ であるから：
   $$v_C = \frac{2 \left(\frac{m}{2}\right)}{\frac{m}{2} + \frac{m}{4}} v_B = \frac{m}{\frac{3}{4} m} v_B = \frac{4}{3} v_B$$
3. **合成速度比の算出**：
   $$v_C = \frac{4}{3} \times \left(\frac{4}{3} v_A\right) = \frac{16}{9} v_A \implies \frac{v_C}{v_A} = \frac{16}{9}$$
よって、正解は選択肢 $\textcircled{6}$ である。

## 問4：斜方投射における滞空時間と重力による力積

**【考査考点】**：斜方投射の鉛直運動と滞空時間 $t = \frac{2v\sin\theta}{g}$, 一定の力が与える力積 $I = F \Delta t = mg t$, 運動量変化と力積の関係による別解

**【題目大意】**
水平な床から質量 $m$ の小物体を初速 $v$、仰角 $\theta$ で斜方投射した。
小物体が床に達する直前までに、重力により与えられた力積の大きさを求めよ。

**【公式正解】**：$\textcircled{3}$（$2mv\sin\theta$）

**【詳細推導・解答プロセス】**
1. **解法1（力積の定義 $I = F \Delta t$）**：
   重力は鉛直下向きに大きさ $mg$ の一定の力である。
   打ち出されてから再び床に落下するまでの滞空時間 $t$ は、鉛直方向の等加速度運動より：
   $$0 = v\sin\theta \cdot t - \frac{1}{2} g t^2 \implies t = \frac{2v\sin\theta}{g}$$
   重力の力積の大きさ $I$ は：
   $$I = mg \times t = mg \times \frac{2v\sin\theta}{g} = 2mv\sin\theta$$
2. **解法2（運動量と力積の関係）**：
   落下直前の速度ベクトルは水平成分 $v\cos\theta$（不変）、鉛直成分 $-v\sin\theta$（下向き）である。
   鉛直方向の運動量変化は：
   $$\Delta p_y = (-mv\sin\theta) - (+mv\sin\theta) = -2mv\sin\theta$$
   したがって、重力積の大きさは $|\Delta p_y| = 2mv\sin\theta$ である。
よって、正解は選択肢 $\textcircled{3}$ である。

## 問5：振り子の最下点における完全非弾性衝突と上昇高度比

**【考査考点】**：力学的エネルギー保存則（衝突直前速度の導出）, 完全非弾性衝突における運動量保存則, 衝突後の力学的エネルギー保存則

**【題目大意】**
長さ $\ell$ の軽い糸の先につけた質量 $m$ の小物体 P を水平位置（高さ $\ell$）から静かに放した。
最下点で静止していた質量 $M$ の小物体 Q と衝突して一体となり、水平面から高さ $h$ まで上がった。
比 $\frac{h}{\ell}$ を表す式を求めよ。

**【公式正解】**：$\textcircled{3}$（$\left(\frac{m}{m+M}\right)^2$）

**【詳細推導・解答プロセス】**
1. **P の最下点到達時の速さ $v$（力学的エネルギー保存則）**：
   $$mg\ell = \frac{1}{2} m v^2 \implies v = \sqrt{2g\ell}$$
2. **衝突直後の速度 $V$（運動量保存則）**：
   P と Q は一体となって運動するため、運動量保存則より：
   $$m v = (m + M) V \implies V = \frac{m}{m + M} v = \frac{m}{m + M} \sqrt{2g\ell}$$
3. **衝突後の最高到達高度 $h$（力学的エネルギー保存則）**：
   一体となった物体が高さ $h$ まで上昇して静止するから：
   $$\frac{1}{2} (m + M) V^2 = (m + M) g h \implies h = \frac{V^2}{2g}$$
   $V$ を代入すると：
   $$h = \frac{1}{2g} \left(\frac{m}{m+M}\right)^2 (2g\ell) = \left(\frac{m}{m+M}\right)^2 \ell$$
   したがって：
   $$\frac{h}{\ell} = \left(\frac{m}{m+M}\right)^2$$
よって、正解は選択肢 $\textcircled{3}$ である。

## 問6：鉛直ばね振り子の自然長からの解放と振幅・周期の質量依存性

**【考査考点】**：自然長からの解放における振幅 $A = x_0 = \frac{mg}{k}$, ばね振り子の周期公式 $T = 2\pi\sqrt{\frac{m}{k}}$, 比の計算 $\frac{A_2}{A_1} = \frac{m_2}{m_1}$、$\frac{T_2}{T_1} = \sqrt{\frac{m_2}{m_1}}$

**【題目大意】**
ばね定数 $k$ の軽いばねにつるしたおもりを自然長の位置で支え、静かに手をはなした。
質量 $m_1$ のとき振幅 $A_1$、周期 $T_1$ であり、質量 $m_2$ のとき振幅 $A_2$、周期 $T_2$ であった。
比 $\frac{A_2}{A_1}$ および $\frac{T_2}{T_1}$ の組み合わせを選べ。

**【公式正解】**：$\textcircled{1}$（$\frac{A_2}{A_1} = \frac{m_2}{m_1}$、$\frac{T_2}{T_1} = \sqrt{\frac{m_2}{m_1}}$）

**【詳細推導・解答プロセス】**
1. **振幅 $A$ の決定**：
   質量 $m$ のおもりのつり合いの位置（振動中心）は、自然長から $x_0 = \frac{mg}{k}$ だけ伸びた位置である。
   自然長の位置（速度 0）から静かに放したため、自然長の位置は振動の上端（折り返し点）となる。
   したがって、振幅 $A$ は振動中心と上端の距離に等しい：
   $$A = x_0 = \frac{mg}{k}$$
   ばね定数 $k$ は共通であるから、振幅は質量 $m$ に比例する：
   $$\frac{A_2}{A_1} = \frac{\frac{m_2 g}{k}}{\frac{m_1 g}{k}} = \frac{m_2}{m_1}$$
2. **周期 $T$ の決定**：
   単振動の周期は：
   $$T = 2\pi \sqrt{\frac{m}{k}}$$
   したがって、周期は質量の平方根に比例する：
   $$\frac{T_2}{T_1} = \frac{2\pi \sqrt{\frac{m_2}{k}}}{2\pi \sqrt{\frac{m_1}{k}}} = \sqrt{\frac{m_2}{m_1}}$$
よって、正解は選択肢 $\textcircled{1}$ である。

**【考査考点】**：熱量保存則（高温物体が放出した熱量 ＝ 低温物体が吸収した熱量）, 比熱の計算式 $Q = m c \Delta T$

   問題文で与えられた質量・初期温度・比熱および平衡温度の数値を代入して解くと：

## 問8：棒で連結された対向ピストン内の気体の等温変化と絶対温度比

**【考査考点】**：棒で連結されたピストンの力のつり合い（$p_A = p_B$）, シリンダーAの等温変化（ボイルの法則 $p_A V_A = p_0 V_0$）, 全容積一定条件とシリンダーBの状態方程式

**【題目大意】**
向かい合わせの同じシリンダー A, B 内に断面積の等しいピストンを棒でつないで固定した。
初期状態はともに $p_0, V_0, T_0$ である。
A 内の温度を $T_0$ に保ったまま B の温度を $T_1$ に変化させたところ、B の圧力が $p_1$ になった。
比 $\frac{T_1}{T_0}$ を表す式を求めよ。

**【公式正解】**：$\textcircled{3}$（$\frac{2p_1}{p_0} - 1$）

**【詳細推導・解答プロセス】**
1. **ピストンのつり合いと圧力の関係**：
   2 つのピストンは棒で連結されてなめらかに動くため、静止時の両室の圧力は等しい：
   $$p_A = p_B = p_1$$
2. **シリンダー A の等温変化**：
   A 内の気体は温度 $T_0$ 一定に保たれているため、ボイルの法則が成り立つ：
   $$p_1 V_A = p_0 V_0 \implies V_A = \frac{p_0}{p_1} V_0$$
3. **シリンダー B の体積**：
   シリンダー A と B の合計体積は棒の長さが一定であるため不変（$V_A + V_B = 2V_0$）である：
   $$V_B = 2V_0 - V_A = 2V_0 - \frac{p_0}{p_1} V_0 = \left(2 - \frac{p_0}{p_1}\right) V_0$$
4. **シリンダー B の状態方程式と温度比**：
   シリンダー B の気体について：
   $$\frac{p_1 V_B}{T_1} = \frac{p_0 V_0}{T_0} \implies \frac{T_1}{T_0} = \frac{p_1 V_B}{p_0 V_0}$$
   $V_B$ を代入すると：
   $$\frac{T_1}{T_0} = \frac{p_1 \left(2 - \frac{p_0}{p_1}\right) V_0}{p_0 V_0} = \frac{2p_1 - p_0}{p_0} = \frac{2p_1}{p_0} - 1$$
よって、正解は選択肢 $\textcircled{3}$ である。

## 問9：気体分子運動論における2乗平均速度と分子量比

**【考査考点】**：気体分子の平均運動エネルギー $\frac{1}{2}m \overline{v^2} = \frac{3}{2} k_B T$, 2乗平均速度 $v_{\text{rms}} = \sqrt{\frac{3RT}{M}}$, 水素分子と酸素分子の2乗平均速度比

**【題目大意】**
等温における水素分子 $\text{H}_2$（分子量 2.0）と酸素分子 $\text{O}_2$（分子量 32）の気体がある。
水素分子の2乗平均速度と酸素分子の2乗平均速度の比 $\frac{v_{\text{rms}}(\text{H}_2)}{v_{\text{rms}}(\text{O}_2)}$ を求めよ。

**【公式正解】**：$\textcircled{4}$（4.0）

**【詳細推導・解答プロセス】**
1. **2乗平均速度の公式**：
   気体分子運動論より、絶対温度 $T$ における質量 $m$（モル質量 $M$）の気体分子の平均運動エネルギーは：
   $$\frac{1}{2} m \overline{v^2} = \frac{3}{2} k_B T \implies v_{\text{rms}} = \sqrt{\overline{v^2}} = \sqrt{\frac{3 k_B T}{m}} = \sqrt{\frac{3 R T}{M}}$$
   したがって、温度 $T$ が等しいとき、2乗平均速度は分子量（モル質量 $M$）の平方根に反比例する：
   $$v_{\text{rms}} \propto \frac{1}{\sqrt{M}}$$
2. **比の計算**：
   $$\frac{v_{\text{rms}}(\text{H}_2)}{v_{\text{rms}}(\text{O}_2)} = \sqrt{\frac{M(\text{O}_2)}{M(\text{H}_2)}} = \sqrt{\frac{32}{2.0}} = \sqrt{16} = 4.0$$
よって、正解は選択肢 $\textcircled{4}$ である。

## 問11：2音源間の移動観測者におけるうなりの消滅とドップラー効果

**【考査考点】**：移動観測者によるドップラー効果の公式, うなりが観測されない条件（2音源からの観測振動数が一致）

**【題目大意】**
一直線上に固定された音源 A ($342\text{ Hz}$) と音源 B ($338\text{ Hz}$) がある。
観測者 O が A から B の向きに速さ $v$ [m/s] で移動したところ、うなりが観測されなくなった。
音速を $340\text{ m/s}$ とするとき、$v$ の値を求めよ。

**【公式正解】**：$\textcircled{2}$（$2\text{ m/s}$）

**【詳細推導・解答プロセス】**
1. **ドップラー効果による観測振動数の立式**：
   音速を $V = 340\text{ m/s}$ とする。
   観測者 O は A から遠ざかり、B に近づく向きに速さ $v$ で移動している。
   - 音源 A から受け取る音の振動数：
     $$f_A' = \frac{V - v}{V} f_A = \frac{340 - v}{340} \times 342$$
   - 音源 B から受け取る音の振動数：
     $$f_B' = \frac{V + v}{V} f_B = \frac{340 + v}{340} \times 338$$
2. **うなりが消滅する条件**：
   うなりが観測されないということは、観測される 2 つの振動数が完全に一致する（$f_A' = f_B'$）ことを意味する：
   $$\frac{340 - v}{340} \times 342 = \frac{340 + v}{340} \times 338$$
   両辺に 340 を掛けて展開する：
   $$(340 - v) \times 342 = (340 + v) \times 338$$
   $$340 \times 342 - 342 v = 340 \times 338 + 338 v$$
   $$340 \times (342 - 338) = (342 + 338) v$$
   $$340 \times 4 = 680 v$$
   $$1360 = 680 v \implies v = 2.0\text{ m/s}$$
よって、正解は選択肢 $\textcircled{2}$ である。

## 問14：正三角形配置の4電荷がつくる静電気力のつり合い

**【考査考点】**：クーロンの法則 $F = k \frac{q_1 q_2}{r^2}$, 正三角形の幾何学（重心・中点の距離）, 頂点 A における合力ゼロ条件

**【題目大意】**
一辺 $L$ の正三角形 ABC の頂点 A に $Q > 0$、頂点 B に $-Q$、頂点 C に $-Q$ の電荷を固定した。
辺 BC の中点 D に電荷 $q$ を固定したところ、A の電荷が受ける静電気力の大きさが 0 になった。
比 $\frac{q}{Q}$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{3\sqrt{3}}{4}$）

**【詳細推導・解答プロセス】**
1. **B, C の電荷が A に及ぼす引力の合力**：
   - B の電荷 $-Q$ は A の電荷 $Q$ を距離 $L$ で引く（引力）：
     $$F_B = k \frac{Q^2}{L^2}$$
   - C の電荷 $-Q$ は A の電荷 $Q$ を距離 $L$ で引く（引力）：
     $$F_C = k \frac{Q^2}{L^2}$$
   $\triangle\text{ABC}$ は正三角形であるから、ベクトル $\vec{F}_B$ と $\vec{F}_C$ のなす角は $60^\circ$ である。
   対称性より合力は中点 D を向き、その大きさは：
   $$F_{BC} = 2 F_B \cos 30^\circ = 2 \left(k \frac{Q^2}{L^2}\right) \frac{\sqrt{3}}{2} = \sqrt{3} k \frac{Q^2}{L^2}$$
2. **D の電荷 $q$ が A に及ぼす力**：
   - 線分 AD の長さは正三角形の高さであるから：
     $$AD = L \cos 30^\circ = \frac{\sqrt{3}}{2} L$$
   - A の合力が 0 になるためには、D の電荷 $q$ は正電荷（$q > 0$）であり、A を遠ざける向き（上向き）に斥力を及ぼさなければならない。
   - その大きさは：
     $$F_D = k \frac{q Q}{AD^2} = k \frac{q Q}{\left(\frac{\sqrt{3}}{2} L\right)^2} = k \frac{q Q}{\frac{3}{4} L^2} = \frac{4}{3} k \frac{q Q}{L^2}$$
3. **力のつり合い**：
   $$F_D = F_{BC} \implies \frac{4}{3} k \frac{q Q}{L^2} = \sqrt{3} k \frac{Q^2}{L^2}$$
   両辺の $k \frac{Q}{L^2}$ を消去すると：
   $$\frac{4}{3} q = \sqrt{3} Q \implies \frac{q}{Q} = \frac{3\sqrt{3}}{4}$$
よって、正解は選択肢 $\textcircled{5}$ である。

## 問14：導体板を挿入した平行板コンデンサーの電位差配分

**【考査考点】**：導体板内部の電場はゼロ（等電位体）, 一様電場における電位差 $V = E d$, 各空隙の電位差の差 $V_1 - V_2$

**【題目大意】**
極板間隔 $3d$ のコンデンサーに厚さ $d$ の帯電していない導体板が平行に入っている。
下の極板と導体板の下面との距離は $\frac{3d}{2}$ である。起電力 $V$ の電池を接続した。
導体板と上の極板の間の電位差を $V_1$、下の極板との電位差を $V_2$ とするとき、$V_1 - V_2$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$-\frac{V}{2}$）

**【詳細推導・解答プロセス】**
1. **各領域の間隔の整理**：
   - 下の空隙の間隔：$d_2 = \frac{3d}{2}$
   - 導体板の厚さ：$d_{\text{conductor}} = d$
   - 上の空隙の間隔：全間隔 $3d$ より、
     $$d_1 = 3d - \left(\frac{3d}{2} + d\right) = 3d - \frac{5d}{2} = \frac{d}{2}$$
2. **電場と電位差の配分**：
   導体板内部の電場は 0 であり、上下の空気層には等しい一様電場 $E$ が生じる。
   導体板内部での電位降下はないため、全体の電位差 $V$ は上下の空気層の電位差の和に等しい：
   $$V = V_1 + V_2 = E d_1 + E d_2 = E \left(\frac{d}{2} + \frac{3d}{2}\right) = E (2d) \implies E = \frac{V}{2d}$$
3. **$V_1$ と $V_2$ の算出**：
   - 上の空隙の電位差：
     $$V_1 = E d_1 = \frac{V}{2d} \times \frac{d}{2} = \frac{V}{4}$$
   - 下の空隙の電位差：
     $$V_2 = E d_2 = \frac{V}{2d} \times \frac{3d}{2} = \frac{3V}{4}$$
4. **差 $V_1 - V_2$ の計算**：
   $$V_1 - V_2 = \frac{V}{4} - \frac{3V}{4} = -\frac{2V}{4} = -\frac{V}{2}$$
よって、正解は選択肢 $\textcircled{1}$ である。
