## 大問I 問1：2次関数の動的定義域における最大値・最小値の場合分けと係数決定
- **Local Key**: `math-q-I_1`
- **Answer Ref**: `MATH_C2:I_1`
- **公式正解**: `{'AB': '39', 'C': '3', 'D': '5', 'E': '7', 'F': '5', 'G': '8', 'H': '6', 'I': '5'}`

**【題目大意】**
実数 $a, b$ ($0 < b < 7$) に対し、2次関数 $f(x) = x^2 - 6x + a$ の区間 $b \leq x \leq 7$ における最大値 $M$ と最小値 $m$ を考える。
(1) $b$ の値の範囲によって場合分けし、$M, m$ を求める。
(2) $M = 13, m = 1$ となるときの $a, b$ の値を決定する。

**【公式正解】**
- $\text{AB} = 39$ ($f(x) = (x - 3)^2 + a - 9$)
- $\text{C} = 3$ (境界値 $b = 3$)
- $\text{D} = 5, \text{E} = 7$ ($0 < b \leq 3$ のとき $M = a + 7, m = a - 9$)
- $\text{F} = 5, \text{G} = 8$ ($3 < b < 7$ のとき $M = a + 7, m = b^2 - 6b + a$)
- $\text{H} = 6, \text{I} = 5$ ($a = 6, b = 5$)

**【詳細推導・解答プロセス】**
**(1) 平方完成と頂点・軸の特定**
関数 $f(x)$ を平方完成する：
$$f(x) = x^2 - 6x + a = (x - 3)^2 + a - 9$$
したがって、放物線は下に凸で、軸は直線 $x = 3$、頂点は $(3, a - 9)$ である。
よって、$\text{A} = 3, \text{B} = 9$ (AB = 39) である。

**(2) 場合分けによる最大値 $M$ と最小値 $m$ の導出**
区間の右端は $x = 7$ で固定されている。
端点での値は：
$$f(7) = (7 - 3)^2 + a - 9 = 16 + a - 9 = a + 7$$
軸 $x = 3$ からの距離を比較すると、右端 $x = 7$ までの距離は $7 - 3 = 4$ である。
$0 < b < 7$ より、左端 $b$ から軸 $x = 3$ までの距離は $|b - 3| < 3 < 4$ であるから、常に $f(7) > f(b)$ が成り立つ。
したがって、最大値は常に $x = 7$ でとる：
$$M = f(7) = a + 7 \quad (\textcircled{5})$$

最小値 $m$ については、軸 $x = 3$ が区間 $[b, 7]$ に含まれるかどうかで場合分けが生じる：
(i) $0 < b \leq 3$ のとき（軸 $x = 3$ が区間内に含まれる）：
頂点で最小となるため：
$$m = f(3) = a - 9 \quad (\textcircled{7})$$
したがって、$\text{C} = 3, \text{D} = 5, \text{E} = 7$ である。

(ii) $3 < b < 7$ のとき（軸 $x = 3$ が区間の左外にある）：
区間 $[b, 7]$ において $f(x)$ は単調増加であるから、左端 $x = b$ で最小となる：
$$m = f(b) = b^2 - 6b + a \quad (\textcircled{8})$$
したがって、$\text{F} = 5, \text{G} = 8$ である。

**(3) $M = 13, m = 1$ による $a, b$ の決定**
最大値の条件より：
$$M = a + 7 = 13 \implies a = 6$$
もし場合 (i) $0 < b \leq 3$ ならば、$m = a - 9 = 6 - 9 = -3 \neq 1$ となり不適である。
したがって場合 (ii) $3 < b < 7$ である。
$$m = b^2 - 6b + 6 = 1 \implies b^2 - 6b + 5 = 0$$
$$(b - 1)(b - 5) = 0$$
$3 < b < 7$ より、$b = 5$ である。
よって、$\text{H} = 6, \text{I} = 5$ である。

**【考査考点】**
- 2次関数の軸と動く定義域端点との位置関係による最大・最小の場合分け。
- 軸からの距離の対称性と最大値を与える端点の判定。
- 条件を満たすパラメータの適格性判定（場合分けの前提条件との照合）。

## 大問I 問2：3個のさいころの目に関する事象の個数と和事象の確率
- **Local Key**: `math-q-I_2`
- **Answer Ref**: `MATH_C2:I_2`
- **公式正解**: `{'J': '6', 'KL': '10', 'MN': '15', 'O': '1', 'P': '2', 'Q': '0', 'RSTUV': '23216'}`

**【題目大意】**
大中小3個のさいころの目を $x, y, z$ とし、事象 $A: x = y = z$、$B: x + y + z = 6$、$C: x + y = z$ を定義する。各事象および積事象の起こる場合の数、さらに和事象 $B \cup C$ の起こる確率を求める。

**【公式正解】**
- $\text{J} = 6$ (事象 $A$ は 6 通り)
- $\text{KL} = 10$ (事象 $B$ は 10 通り)
- $\text{MN} = 15$ (事象 $C$ は 15 通り)
- $\text{O} = 1$ ($A \cap B$ は 1 通り)
- $\text{P} = 2$ ($B \cap C$ は 2 通り)
- $\text{Q} = 0$ ($C \cap A$ は 0 通り)
- $\text{RSTUV} = 23216$ ($P(B \cup C) = \frac{23}{216}$)

**【詳細推導・解答プロセス】**
全事象の総数は $6^3 = 216$ 通りである。

**(1) 事象 $A, B, C$ の場合の数**
- 事象 $A$ ($x = y = z$)：
  $(1, 1, 1), (2, 2, 2), \dots, (6, 6, 6)$ の 6 通り。
  よって、$\text{J} = 6$ である。
- 事象 $B$ ($x + y + z = 6$)：
  自然数解 $(x, y, z)$ の個数は、重複組合せ（仕切り棒）の考え方により $\binom{6-1}{3-1} = \binom{5}{2} = 10$ 通り。
  具体的には $(1, 1, 4)$ の並べ替え 3 通り、$(1, 2, 3)$ の並べ替え 6 通り、$(2, 2, 2)$ の 1 通りで、計 $3 + 6 + 1 = 10$ 通り。
  よって、$\text{KL} = 10$ である。
- 事象 $C$ ($x + y = z$)：
  $z \in \{1, 2, 3, 4, 5, 6\}$ に対し、適する $(x, y)$ の個数を数える：
  - $z = 1$：なし（$0$ 通り）
  - $z = 2$：$(1, 1)$ の 1 通り
  - $z = 3$：$(1, 2), (2, 1)$ の 2 通り
  - $z = 4$：$(1, 3), (2, 2), (3, 1)$ の 3 通り
  - $z = 5$：$(1, 4), (2, 3), (3, 2), (4, 1)$ の 4 通り
  - $z = 6$：$(1, 5), (2, 4), (3, 3), (4, 2), (5, 1)$ の 5 通り
  合計：$1 + 2 + 3 + 4 + 5 = 15$ 通り。
  よって、$\text{MN} = 15$ である。

**(2) 積事象の場合の数**
- $A \cap B$：$x = y = z$ かつ $x + y + z = 6 \implies 3x = 6 \implies x = 2$。
  $(2, 2, 2)$ の 1 通りのみ。よって、$\text{O} = 1$ である。
- $B \cap C$：$x + y + z = 6$ かつ $x + y = z$。
  代入すると $z + z = 6 \implies 2z = 6 \implies z = 3$。
  このとき $x + y = 3$ より $(x, y) = (1, 2), (2, 1)$ の 2 通り。
  すなわち $(1, 2, 3), (2, 1, 3)$ の 2 通り。よって、$\text{P} = 2$ である。
- $C \cap A$：$x = y = z$ かつ $x + y = z \implies 2x = x \implies x = 0$。
  さいころの目は $1 \leq x \leq 6$ であるから、解はない。
  0 通り。よって、$\text{Q} = 0$ である。

**(3) 和事象 $B \cup C$ の確率**
包含と排除の原理（加法定理）より：
$$n(B \cup C) = n(B) + n(C) - n(B \cap C) = 10 + 15 - 2 = 23$$
したがって、求める確率は：
$$P(B \cup C) = \frac{23}{216}$$
よって、$\text{RS} = 23, \text{TUV} = 216$ (RSTUV = 23216) である。

**【考査考点】**
- さいころの試行における基本事象の網羅的数え上げ。
- 連立方程式による積事象の共通条件の導出。
- 和事象の確率公式 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ の適用。

## 大問II 問1：空間ベクトルの最小ノルム問題・法線ベクトルと三角形の面積
- **Local Key**: `math-q-II_1`
- **Answer Ref**: `MATH_C2:II_1`
- **公式正解**: `{'ABC': '962', 'DE': '13', 'F': '1', 'GH': '22', 'I': '3', 'JKL': '932'}`

**【題目大意】**
原点 O と 2 点 $A(1, -1, 0), B(-2, 1, 2)$ に対し、$\vec{a} = \overrightarrow{OA}, \vec{b} = \overrightarrow{OB}$ とする。
(1) $|\vec{a} + t\vec{b}|$ を最小にする実数 $t$ とその最小値を求める。
(2) $\vec{a}, \vec{b}$ に直交するベクトル $\vec{c}$ を求め、$\overrightarrow{OC} = (G, H, 1), \overrightarrow{OD} = 3\vec{a} + \vec{b}$ とするとき、$\angle CBD$ および $\triangle BCD$ の面積を求める。

**【公式正解】**
- $\text{ABC} = 962$ ($|\vec{a} + t\vec{b}|^2 = 9t^2 - 6t + 2$)
- $\text{DE} = 13, \text{F} = 1$ ($t = \frac{1}{3}$ で最小値 1)
- $\text{GH} = 22$ ($\vec{c} = s(2, 2, 1)$)
- $\text{I} = 3$ ($\angle CBD = \frac{\pi}{3}$)
- $\text{JKL} = 932$ (面積 $\frac{9\sqrt{3}}{2}$)

**【詳細推導・解答プロセス】**
**(1) $|\vec{a} + t\vec{b}|$ の最小値**
ベクトルの成分より：
$$|\vec{a}|^2 = 1^2 + (-1)^2 + 0^2 = 2$$
$$|\vec{b}|^2 = (-2)^2 + 1^2 + 2^2 = 4 + 1 + 4 = 9$$
$$\vec{a} \cdot \vec{b} = 1(-2) + (-1)(1) + 0(2) = -2 - 1 = -3$$
したがって：
$$|\vec{a} + t\vec{b}|^2 = |\vec{b}|^2 t^2 + 2(\vec{a} \cdot \vec{b})t + |\vec{a}|^2 = 9t^2 - 6t + 2$$
よって、$\text{ABC} = 962$ である。
これを平方完成すると：
$$9\left(t^2 - \frac{2}{3}t\right) + 2 = 9\left(t - \frac{1}{3}\right)^2 - 1 + 2 = 9\left(t - \frac{1}{3}\right)^2 + 1$$
したがって、$t = \frac{1}{3}$ のとき最小値 $\sqrt{1} = 1$ をとる。
よって、$\text{DE} = 13, \text{F} = 1$ である。

**(2) 直交ベクトル $\vec{c}$ の決定**
$\vec{c} = (x, y, 1)$ とおく。
- $\vec{c} \cdot \vec{a} = 0 \implies x - y = 0 \implies y = x$
- $\vec{c} \cdot \vec{b} = 0 \implies -2x + y + 2(1) = 0 \implies -2x + x + 2 = 0 \implies x = 2$
したがって、$y = 2$ である。
よって、$\vec{c} = s(2, 2, 1)$ と表され、$\text{GH} = 22$ である。

**(3) $\angle CBD$ と $\triangle BCD$ の面積**
点 C, D の位置ベクトルは：
$$\overrightarrow{OC} = (2, 2, 1)$$
$$\overrightarrow{OD} = 3\vec{a} + \vec{b} = 3(1, -1, 0) + (-2, 1, 2) = (1, -2, 2)$$
$B(-2, 1, 2)$ を基準としてベクトル $\overrightarrow{BC}, \overrightarrow{BD}$ を求めると：
$$\overrightarrow{BC} = \overrightarrow{OC} - \overrightarrow{OB} = (2 - (-2), 2 - 1, 1 - 2) = (4, 1, -1)$$
$$\overrightarrow{BD} = \overrightarrow{OD} - \overrightarrow{OB} = (1 - (-2), -2 - 1, 2 - 2) = (3, -3, 0)$$
それぞれの大きさと内積を計算する：
$$|\overrightarrow{BC}| = \sqrt{4^2 + 1^2 + (-1)^2} = \sqrt{18} = 3\sqrt{2}$$
$$|\overrightarrow{BD}| = \sqrt{3^2 + (-3)^2 + 0^2} = \sqrt{18} = 3\sqrt{2}$$
$$\overrightarrow{BC} \cdot \overrightarrow{BD} = 4(3) + 1(-3) + (-1)(0) = 12 - 3 = 9$$
したがって：
$$\cos \angle CBD = \frac{\overrightarrow{BC} \cdot \overrightarrow{BD}}{|\overrightarrow{BC}| |\overrightarrow{BD}|} = \frac{9}{(3\sqrt{2})(3\sqrt{2})} = \frac{9}{18} = \frac{1}{2}$$
$0 < \angle CBD < \pi$ より：
$$\angle CBD = \frac{\pi}{3}$$
よって、$\text{I} = 3$ である。
三角形 BCD の面積 $S$ は：
$$S = \frac{1}{2} |\overrightarrow{BC}| |\overrightarrow{BD}| \sin \frac{\pi}{3} = \frac{1}{2} \times 18 \times \frac{\sqrt{3}}{2} = \frac{9\sqrt{3}}{2}$$
よって、$\text{JKL} = 932$ である。

**【考査考点】**
- 空間ベクトルの内積計算と長さの2次式最小化。
- 2つのベクトルに直交する法線方向の連立方程式解法。
- 内積定義によるなす角の決定と三角形の面積公式。

**【題目大意】**
方程式 $z^4 = -324$ $\textcircled{1}$ と $z^4 = t^4$ ($t > 0$) $\textcircled{2}$ を考える。
(1) $\textcircled{1}$ の解を極形式 $z = r(\cos\theta + i\sin\theta)$ で表す。
(2) $\textcircled{1}$ の解と $\textcircled{2}$ の解の距離 $d$ について、$0 < t \leq 4$ のときの $d$ の最小値と最大値を求める。

**【公式正解】**
- $\text{MN} = 44$ ($z^4 = r^4(\cos 4\theta + i\sin 4\theta)$)
- $\text{OP} = 32$ ($r = 3\sqrt{2}$)
- $\text{QRSTU} = 14357$ ($\theta = \frac{1}{4}\pi, \frac{3}{4}\pi, \frac{5}{4}\pi, \frac{7}{4}\pi$)
- $\text{V} = 4$ (解の個数 4 個)
- $\text{W} = 3$ (距離の最小値 3)
- $\text{XY} = 58$ (距離の最大値 $\sqrt{58}$)

**【詳細推導・解答プロセス】**
**(1) $z^4 = -324$ の解の導出**
ド・モアブルの定理より：
$$z^4 = r^4 (\cos 4\theta + i \sin 4\theta)$$
したがって、$\text{M} = 4, \text{N} = 4$ (MN = 44) である。
$-324$ を極形式で表すと：
$$-324 = 324(\cos\pi + i\sin\pi)$$
$324 = 18^2 = (3^2 \times 2)^2 = 3^4 \times 4 = (3\sqrt{2})^4$ であるから：
$$r = 3\sqrt{2}$$
よって、$\text{O} = 3, \text{P} = 2$ (OP = 32) である。
偏角の条件は：
$$4\theta = \pi + 2k\pi \implies \theta = \frac{1 + 2k}{4}\pi \quad (k \in \mathbb{Z})$$
$0 < \theta \leq 2\pi$ の範囲にある解は $k = 0, 1, 2, 3$ に対応して：
$$\theta = \frac{1}{4}\pi, \quad \frac{3}{4}\pi, \quad \frac{5}{4}\pi, \quad \frac{7}{4}\pi$$
問題の形 $\frac{Q}{R}\pi, \frac{S}{R}\pi, \frac{T}{R}\pi, \frac{U}{R}\pi$ と比較すると：
$$Q = 1, \quad R = 4, \quad S = 3, \quad T = 5, \quad U = 7$$
よって、$\text{QRSTU} = 14357$ である。

**(2) 2解間の距離の最大値・最小値**
$\textcircled{1}$ の 4 つの解は直交座標表示で：
$$3\sqrt{2}\left(\pm \frac{1}{\sqrt{2}} \pm \frac{1}{\sqrt{2}}i\right) = \pm 3 \pm 3i$$
すなわち $3 + 3i, -3 + 3i, -3 - 3i, 3 - 3i$ である。
一方、$\textcircled{2}$ $z^4 = t^4$ の解は $t > 0$ に対して 4 個（$\text{V} = 4$）あり、実軸および虚軸上の点：
$$t, \quad ti, \quad -t, \quad -ti$$
である。
複素数平面の回転対称性により、$\textcircled{1}$ の解として $3 + 3i$ を固定して考えて一般性を失わない。
点 $3 + 3i$ から各点への距離の2乗 $d^2$ は：
- 点 $t$ への距離：$d^2 = (3 - t)^2 + 3^2 = (t - 3)^2 + 9$
- 点 $ti$ への距離：$d^2 = 3^2 + (3 - t)^2 = (t - 3)^2 + 9$
- 点 $-t$ への距離：$d^2 = (3 + t)^2 + 3^2 = (t + 3)^2 + 9$
- 点 $-ti$ への距離：$d^2 = 3^2 + (3 + t)^2 = (t + 3)^2 + 9$
$0 < t \leq 4$ において：
-$d$ の最小値：$(t - 3)^2 + 9$ は $t = 3$ のとき最小値 $9$ をとる。したがって最小距離は $d_{\min} = \sqrt{9} = 3$ である（$\text{W} = 3$）。
-$d$ の最大値：$(t + 3)^2 + 9$ は $t = 4$ のとき最大値 $(4 + 3)^2 + 9 = 49 + 9 = 58$ をとる。したがって最大距離は $d_{\max} = \sqrt{58}$ である（$\text{XY} = 58$）。
よって、$\text{V} = 4, \text{W} = 3, \text{XY} = 58$ である。

**【考査考点】**
- ド・モアブルの定理を用いた複素数の $n$ 乗根の決定。
- 複素数平面における正方形の幾何学的配置と回転対称性。

## 大問III [1]：4次関数の接線の方程式と $y$ 切片関数の導出

- **Answer Ref**: `MATH_C2:III_1`
- **公式正解**: `{'ABCD': '4624', 'EFGHI': '34124', 'JKLMN': '34124'}`

**【題目大意】**
関数 $f(x) = x^4 + 2x^3 - 12x^2 + 4$ と点 $P(0, p)$ に対し、点 $(t, f(t))$ における接線の方程式を求め、その接線が点 $P$ を通る条件式（$y$ 切片関数）を導く。

**【公式正解】**
- $\text{ABCD} = 4624$ (傾き $4t^3 + 6t^2 - 24t$)
- $\text{EFGHI} = 34124$ (切片 $-3t^4 - 4t^3 + 12t^2 + 4$)
- $\text{JKLMN} = 34124$ ($p = -3t^4 - 4t^3 + 12t^2 + 4$)

**【詳細推導・解答プロセス】**
**(1) 接線の方程式の導出**
関数 $f(x) = x^4 + 2x^3 - 12x^2 + 4$ を微分する：
$$f'(x) = 4x^3 + 6x^2 - 24x$$
点 $(t, f(t))$ における接線の傾きは $f'(t) = 4t^3 + 6t^2 - 24t$ である。
したがって、問題の傾きの空欄は $4t^3 + 6t^2 - 24t$ であり：
$$\text{A} = 4, \quad \text{B} = 6, \quad \text{CD} = 24$$
よって、$\text{ABCD} = 4624$ である。

接線の方程式は：
$$y - f(t) = f'(t)(x - t) \implies y = f'(t)x + f(t) - t f'(t)$$
ここで $y$ 切片を計算する：
$$f(t) - t f'(t) = (t^4 + 2t^3 - 12t^2 + 4) - t(4t^3 + 6t^2 - 24t)$$
$$= t^4 + 2t^3 - 12t^2 + 4 - 4t^4 - 6t^3 + 24t^2$$
$$= -3t^4 - 4t^3 + 12t^2 + 4$$
したがって、接線の方程式は：
$$y = (4t^3 + 6t^2 - 24t)x - 3t^4 - 4t^3 + 12t^2 + 4$$
問題の定数項の形 $-Et^4 - Ft^3 + GHt^2 + I$ と比較すると：
$$E = 3, \quad F = 4, \quad GH = 12, \quad I = 4$$
よって、$\text{EFGHI} = 34124$ である。

**(2) 点 $P(0, p)$ を通る条件**
接線が点 $P(0, p)$ を通るから、$x = 0, y = p$ を代入すると：
$$p = -3t^4 - 4t^3 + 12t^2 + 4$$
同様に、$\text{JKLMN} = 34124$ である。

**【考査考点】**
- 微分法による高次関数の接線の方程式の立式。
- 外部の点から引いた接線に関する接点 $t$ の方程式への帰着。

## 大問IV [1]：媒介変数表示された曲線の速度成分と半角の公式
- **Local Key**: `math-q-IV_1`
- **Answer Ref**: `MATH_C2:IV_1`
- **公式正解**: `{'AB': '41', 'C': '4', 'DEF': '642'}`

**【題目大意】**
動点 P の座標が $x = 4t - \sin 4t, y = 4 - \cos 4t$ で与えられているとき、$\frac{dx}{dt}, \frac{dy}{dt}$ および速度の2乗和 $\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2$ を求める。

**【公式正解】**
- $\text{AB} = 41$ ($\frac{dx}{dt} = 4(1 - \cos 4t)$)
- $\text{C} = 4$ ($\frac{dy}{dt} = 4\sin 4t$)
- $\text{DEF} = 642$ ($64\sin^2 2t$)

**【詳細推導・解答プロセス】**
**(1) $t$ についての微分**
合成関数の微分法を用いる：
$$\frac{dx}{dt} = \frac{d}{dt}(4t - \sin 4t) = 4 - 4\cos 4t = 4(1 - \cos 4t)$$
問題の形 $A(B - \cos 4t)$ と比較すると：
$$A = 4, \quad B = 1$$
よって、$\text{AB} = 41$ である。

$$\frac{dy}{dt} = \frac{d}{dt}(4 - \cos 4t) = 0 - (-4\sin 4t) = 4\sin 4t$$
よって、$\text{C} = 4$ である。

**(2) 2乗和の計算と半角の公式の適用**
$$\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 = [4(1 - \cos 4t)]^2 + (4\sin 4t)^2$$
$$= 16(1 - 2\cos 4t + \cos^2 4t) + 16\sin^2 4t$$
$$= 16(1 - 2\cos 4t + \cos^2 4t + \sin^2 4t)$$
$\cos^2 4t + \sin^2 4t = 1$ を用いると：
$$= 16(2 - 2\cos 4t) = 32(1 - \cos 4t)$$
ここで半角の公式 $1 - \cos 4t = 2\sin^2 2t$ を適用する：
$$= 32(2\sin^2 2t) = 64\sin^2 2t$$
問題の形 $DE \sin^2 Ft$ と比較すると：
$$DE = 64, \quad F = 2$$
よって、$\text{DEF} = 642$ である。

**【考査考点】**
- 媒介変数表示（サイクロイド型曲線）の微分法。

## 大問IV [2]：動点の速さの最大値・発生回数および曲線の道のり積分
- **Local Key**: `math-q-IV_2`
- **Answer Ref**: `MATH_C2:IV_2`
- **公式正解**: `{'G': '4', 'HI': '14', 'JK': '74', 'L': '8', 'MN': '24'}`

**【題目大意】**
$0 \leq t \leq 2\pi$ において速さ $v$ が最大となる回数 $G$、最初と最後の時刻 $t_0, t_1$、最大速さ $v_{\max}$、および $t_0$ から $t_1$ までの道のりを求める。

**【公式正解】**
- $\text{G} = 4$ (最大値をとる回数 4 回)
- $\text{HI} = 14$ ($t_0 = \frac{1}{4}\pi$)
- $\text{JK} = 74$ ($t_1 = \frac{7}{4}\pi$)
- $\text{L} = 8$ (最大の速さ $v = 8$)
- $\text{MN} = 24$ (道のり 24)

**【詳細推導・解答プロセス】**
**(1) 速さ $v$ の最大値と時刻**
点 P の速さ $v$ は：
$$v = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} = \sqrt{64\sin^2 2t} = 8|\sin 2t|$$
$0 \leq t \leq 2\pi$ より、$0 \leq 2t \leq 4\pi$ である。
$v$ が最大となるのは $|\sin 2t| = 1$ のときであり、最大の速さは：
$$v = 8 \times 1 = 8$$
よって、$\text{L} = 8$ である。

$|\sin 2t| = 1$ となる $2t$ の値は、区間 $[0, 4\pi]$ 内に：
$$2t = \frac{\pi}{2}, \quad \frac{3\pi}{2}, \quad \frac{5\pi}{2}, \quad \frac{7\pi}{2}$$
の全部で 4 回ある。したがって、$\text{G} = 4$ である。
各時刻は：
- 最初：$t_0 = \frac{\pi}{4}$。よって、$\text{HI} = 14$ である。
- 最後：$t_1 = \frac{7\pi}{4}$。よって、$\text{JK} = 74$ である。

**(2) 道のりの定積分**
時刻 $t = t_0 = \frac{\pi}{4}$ から $t = t_1 = \frac{7\pi}{4}$ までの間に動いた道のり $L$ は：
$$L = \int_{\pi/4}^{7\pi/4} v \, dt = \int_{\pi/4}^{7\pi/4} 8|\sin 2t| \, dt$$
周期関数 $|\sin 2t|$ の半周期は $\frac{\pi}{2}$ であり、1つの山（長さ $\frac{\pi}{2}$ の区間）の面積は：
$$\int_0^{\pi/2} 8\sin 2t \, dt = \left[ -4\cos 2t \right]_0^{\pi/2} = -4(-1) - (-4(1)) = 4 + 4 = 8$$
区間 $\left[\frac{\pi}{4}, \frac{7\pi}{4}\right]$ の長さは $\frac{7\pi}{4} - \frac{\pi}{4} = \frac{6\pi}{4} = \frac{3\pi}{2}$ であり、これはちょうど半周期 $\frac{\pi}{2}$ の 3 つ分に相当する：
$$\left[\frac{\pi}{4}, \frac{3\pi}{4}\right], \quad \left[\frac{3\pi}{4}, \frac{5\pi}{4}\right], \quad \left[\frac{5\pi}{4}, \frac{7\pi}{4}\right]$$
各区間における定積分はいずれも 8 であるから、全体の道のりは：
$$L = 8 \times 3 = 24$$
よって、$\text{MN} = 24$ である。

**【考査考点】**
- 媒介変数表示における速度ベクトルの大きさと周期関数解析。
- 弧長（道のり）の定積分計算公式 $L = \int |v| \, dt$。
- 絶対値を含む三角関数の周期対称性を利用した積分の単純化。
