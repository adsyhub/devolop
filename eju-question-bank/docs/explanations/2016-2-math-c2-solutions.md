## 大問I 問1：2次関数の決定（頂点・対称軸・x切片）

**問題コード**: `math-q-I_1` | **正解参照**: `MATH_C2:I_1`

### 出題のポイント
- 放物線の頂点の座標と標準形 $y = a(x - p)^2 + q$ への変形
- 軸対称性と線分の長さから $x$ 軸との交点座標の特定
- 交点代入による係数 $a, b, c$ の算出

### 詳細解説
**【題目大意】**
2次関数 $y = ax^2 + bx + c$ $\textcircled{1}$ は $x = 1$ のとき最大値 16 をとり、グラフが $x$ 軸と交わる 2 点間の距離が 8 であるとき、標準形、交点座標、および係数 $a, b, c$ を求める。

**【公式正解】**
- $\text{ABC} = 116$ ($y = a(x - 1)^2 + 16$)
- $\text{D} = 3, \text{E} = 5$ (交点座標 $(-3, 0), (5, 0)$)
- $\text{FG} = -1$ ($a = -1$)
- $\text{H} = 2, \text{IJ} = 15$ ($b = 2, c = 15$)

**【詳細推導・解答プロセス】**
**(1) 頂点による標準形の設定**
関数 $\textcircled{1}$ は $x = 1$ で最大値 16 をとるから、放物線の頂点の座標は $(1, 16)$ であり、上に凸 ($a < 0$) である。
したがって、関数は次のように表される：
$$y = a(x - 1)^2 + 16$$
よって、$\text{A} = 1, \text{BC} = 16$ である。

**(2) $x$ 軸との交点座標の決定**
放物線は対称軸 $x = 1$ に関して左右対称である。
グラフが $x$ 軸と交わる 2 点を結ぶ線分の長さが 8 であるから、軸 $x = 1$ から各交点までの距離は $8 \div 2 = 4$ である。
したがって、2 つの交点の $x$ 座標は：
$$x = 1 - 4 = -3, \quad x = 1 + 4 = 5$$
よって、交点の座標は $(-3, 0)$ および $(5, 0)$ である。
これより、$\text{D} = 3, \text{E} = 5$ である。

**(3) 係数 $a, b, c$ の決定**
交点 $(5, 0)$ を $y = a(x - 1)^2 + 16$ に代入すると：
$$0 = a(5 - 1)^2 + 16 \implies 16a + 16 = 0 \implies a = -1$$
よって、$\text{FG} = -1$ である。
この式を展開して一般形 $y = ax^2 + bx + c$ に変形すると：
$$y = -(x - 1)^2 + 16 = -(x^2 - 2x + 1) + 16 = -x^2 + 2x + 15$$
したがって、$a = -1, b = 2, c = 15$ となる。
これより、$\text{H} = 2, \text{IJ} = 15$ である。

**【考査考点】**
1. 2次関数の頂点から標準形を設定する技能。
2. 放物線の線対称性を利用して交点座標を求める幾何的考察力。
3. 標準形と一般形の相互展開および未定係数決定。

## 大問I 問2：カードの非復元抽出・復元抽出と確率（余事象・包除原理）

**問題コード**: `math-q-I_2` | **正解参照**: `MATH_C2:I_2`

### 出題のポイント
- 同時抽出（非復元抽出）における組合せ数の計算
- 最小値・最大値の範囲制約に対する余事象・包除原理の適用
- 復元抽出における独立試行の確率計算

### 詳細解説
**【題目大意】**
0 から 9 までのカード 10 枚から 3 枚を取り出す試行において、(1) 同時抽出での数の範囲確率および最小値・最大値条件付き確率、(2) 復元抽出での範囲確率を求める。

**【公式正解】**
- $\text{KLM} = 112$ (確率 $\frac{1}{12}$)
- $\text{NOPQ} = 1340$ (確率 $\frac{13}{40}$)
- $\text{RS} = 18$ (確率 $\frac{1}{8}$)

**【詳細推導・解答プロセス】**
**(1) 3枚のカードを同時に取り出す場合**
10 枚のカードから 3 枚を同時に取り出す全事象の根元事象の総数は：
$$N = \binom{10}{3} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = 120$$

**(i) 3枚の数がすべて2以上6以下である確率**
集合 $\{2, 3, 4, 5, 6\}$ は計 5 枚である。
この 5 枚から 3 枚を取り出す組合せ数は：
$$\binom{5}{3} = 10$$
したがって、求める確率は：
$$P = \frac{10}{120} = \frac{1}{12}$$
よって、$\text{K} = 1, \text{LM} = 12$ (KLM = 112) である。

**(ii) 最も小さい数が2以下で、最も大きい数が8以上である確率**
取り出した 3 枚の最小値を $X$、最大値を $Y$ とする。
事象 $E: X \leq 2 \text{ かつ } Y \geq 8$ の確率を、余事象を用いて包除原理により求める。
否定を考えると、$\overline{E}: X \geq 3 \text{ または } Y \leq 7$ である。
- 事象 $A: X \geq 3$（すべて 3 以上 9 以下、対象は $\{3,4,5,6,7,8,9\}$ の 7 枚）：
  $$|A| = \binom{7}{3} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35$$
- 事象 $B: Y \leq 7$（すべて 0 以上 7 以下、対象は $\{0,1,2,3,4,5,6,7\}$ の 8 枚）：
  $$|B| = \binom{8}{3} = \frac{8 \times 7 \times 6}{3 \times 2 \times 1} = 56$$
- 事象 $A \cap B: 3 \leq X \leq Y \leq 7$（すべて 3 以上 7 以下、対象は $\{3,4,5,6,7\}$ の 5 枚）：
  $$|A \cap B| = \binom{5}{3} = 10$$
包除原理より、$|A \cup B| = |A| + |B| - |A \cap B| = 35 + 56 - 10 = 81$ 通り。
したがって、事象 $E$ を満たす場合の数は：
$$|E| = N - |A \cup B| = 120 - 81 = 39$$
求める確率は：
$$P = \frac{39}{120} = \frac{13}{40}$$
よって、$\text{NO} = 13, \text{PQ} = 40$ (NOPQ = 1340) である。

**(2) 1枚ずつ見て元に戻す試行を3回続ける場合（復元抽出）**
各回ごとに引く数は独立であり、全事象は $10^3 = 1000$ 通り。
最も小さい数が 2 以上で、最も大きい数が 6 以下であるとは、3 回とも $\{2, 3, 4, 5, 6\}$（5 枚）から引くことと同値である。
1 回あたりに 2 以上 6 以下のカードを引く確率は $\frac{5}{10} = \frac{1}{2}$ である。
3 回の独立試行により、求める確率は：
$$P = \left(\frac{1}{2}\right)^3 = \frac{1}{8}$$
よって、$\text{R} = 1, \text{S} = 8$ (RS = 18) である。

**【考査考点】**
1. 非復元抽出における組合せの計算。
2. 最小値・最大値条件における余事象と包除原理の定石的活用。
3. 復元抽出における独立試行の確率公式の理解。

## 大問II 問1：常用対数による漸化式の変形と等比数列の導出

**問題コード**: `math-q-II_1` | **正解参照**: `MATH_C2:II_1`

### 出題のポイント
- 積型の非線形漸化式に常用対数をとることによる線形3項間漸化式への帰着
- 階差数列の等比構造の導出
- 初項と公比の特定

### 詳細解説
**【題目大意】**
正の数からなる数列 $a_n$ が $a_1 = 1, a_2 = 10$ および $(a_n)^2 a_{n-2} = (a_{n-1})^3$ を満たすとき、常用対数 $b_n = \log_{10} a_n$ を用いて漸化式を変形し、階差数列の一般項を求める。

**【公式正解】**
- $\text{AB} = 23$ ($2\log_{10} a_n + \log_{10} a_{n-2} = 3\log_{10} a_{n-1}$)
- $\text{C} = 2$ ($b_n - b_{n-1} = \frac{1}{2}(b_{n-1} - b_{n-2})$)
- $\text{D} = 2$ ($b_n - b_{n-1} = (\frac{1}{2})^{n-2}(b_2 - b_1)$)

**【詳細推導・解答プロセス】**
**(1) 漸化式の両辺に対数をとる**
与えられた漸化式：
$$(a_n)^2 a_{n-2} = (a_{n-1})^3 \quad (n = 3, 4, \dots) \quad \textcircled{1}$$
両辺の常用対数（底 10）をとると：
$$\log_{10} \{(a_n)^2 a_{n-2}\} = \log_{10} \{(a_{n-1})^3\}$$
対数の性質 $\log(xy) = \log x + \log y$ および $\log(x^k) = k\log x$ より：
$$2\log_{10} a_n + \log_{10} a_{n-2} = 3\log_{10} a_{n-1}$$
したがって、$\text{A} = 2, \text{B} = 3$ (AB = 23) である。

**(2) 対数列 $b_n$ の階差漸化式への変形**
$b_n = \log_{10} a_n$ とおくと、上の式は：
$$2b_n + b_{n-2} = 3b_{n-1} \quad \textcircled{2}$$
となる。これを階差の形に変形する：
$$2b_n - 2b_{n-1} = b_{n-1} - b_{n-2}$$
両辺を 2 で割ると：
$$b_n - b_{n-1} = \frac{1}{2}(b_{n-1} - b_{n-2}) \quad (n = 3, 4, \dots)$$
したがって、$\text{C} = 2$ である。

**(3) 階差数列の一般項**
数列 $\{b_n - b_{n-1}\}$ は、初項 $b_2 - b_1$、公比 $\frac{1}{2}$ の等比数列である。
したがって、$n = 2, 3, \dots$ に対して：
$$b_n - b_{n-1} = \left(\frac{1}{2}\right)^{n-2} (b_2 - b_1) \quad \textcircled{3}$$
これより、$\text{D} = 2$ である。

**【考査考点】**
1. 対数の真数条件および乗除・累乗を対数の和・スカラー倍へ還元する性質。
2. 3項間線形漸化式を階差数列の等比型へ式変形する基本定石。

## 大問II 問2：階差数列の和と数列の極限

**問題コード**: `math-q-II_2` | **正解参照**: `MATH_C2:II_2`

### 出題のポイント
- 対数列の初期値 $b_1, b_2$ の計算
- 等比数列の有限和による一般項 $b_n$ の導出
- 数列の極限 $\lim_{n \to \infty} b_n$ と元の数列 $\lim_{n \to \infty} a_n$ の算出

### 詳細解説
**【題目大意】**
前問で求めた階差数列から $b_n$ の一般項を求め、$\lim_{n \to \infty} a_n$ を求める。

**【公式正解】**
- $\text{E} = 0, \text{F} = 1$ ($b_1 = 0, b_2 = 1$)
- $\text{G} = 2$ ($b_n = \sum_{k=2}^n (\frac{1}{2})^{k-2}$)
- $\text{HI} = 22$ ($b_n = 2 - (\frac{1}{2})^{n-2}$)
- $\text{JKL} = 100$ ($\lim_{n \to \infty} a_n = 100$)

**【詳細推導・解答プロセス】**
**(1) $b_1, b_2$ の値の決定**
$a_1 = 1, a_2 = 10$ より：
$$b_1 = \log_{10} a_1 = \log_{10} 1 = 0$$
$$b_2 = \log_{10} a_2 = \log_{10} 10 = 1$$
したがって、$\text{E} = 0, \text{F} = 1$ である。
これにより、$b_2 - b_1 = 1 - 0 = 1$ となる。

**(2) 和による $b_n$ の表示**
$\textcircled{3}$ より、$b_k - b_{k-1} = \left(\frac{1}{2}\right)^{k-2}$ であるから、$n \geq 2$ に対して：
$$b_n = b_1 + \sum_{k=2}^n (b_k - b_{k-1}) = 0 + \sum_{k=2}^n \left(\frac{1}{2}\right)^{k-2}$$
したがって、$\text{G} = 2$ である。

**(3) 等比数列の和の計算**
$\sum_{k=2}^n \left(\frac{1}{2}\right)^{k-2}$ は初項 1、公比 $\frac{1}{2}$、項数 $n - 1$ の等比数列の和であるから：
$$b_n = \frac{1 - (\frac{1}{2})^{n-1}}{1 - \frac{1}{2}} = 2\left\{1 - \left(\frac{1}{2}\right)^{n-1}\right\} = 2 - 2 \cdot \left(\frac{1}{2}\right)^{n-1} = 2 - \left(\frac{1}{2}\right)^{n-2}$$
（$n = 1$ のときも $2 - (\frac{1}{2})^{-1} = 2 - 2 = 0$ となり成立する）
したがって、$\text{H} = 2, \text{I} = 2$ (HI = 22) である。

**(4) 極限値の計算**
$n \to \infty$ のとき、$\left(\frac{1}{2}\right)^{n-2} \to 0$ であるから：
$$\lim_{n \to \infty} b_n = 2$$
$b_n = \log_{10} a_n$ より、$a_n = 10^{b_n}$ である。
指数関数 $10^x$ の連続性より：
$$\lim_{n \to \infty} a_n = 10^{\lim_{n \to \infty} b_n} = 10^2 = 100$$
したがって、$\text{JKL} = 100$ である。

**【考査考点】**
1. 階差数列から一般項を復元する総和計算技能。
2. 初項 1、公比 $\frac{1}{2}$ の等比数列の有限和公式。
3. 指数・対数の連続性を用いた極限値の算出。

## 大問III 問1：複素数解の偏角と円の軌跡方程式

**問題コード**: `math-q-III_1` | **正解参照**: `MATH_C2:III_1`

### 出題のポイント
- 2次方程式の虚数解の導出と極形式・偏角の決定
- 複素数の商の偏角 $\arg \frac{\alpha - z}{\beta - z} = \frac{\pi}{2}$ と直角円周角の幾何的意味
- 円の中心と半径の特定

### 詳細解説
**【題目大意】**
2次方程式 $x^2 + \sqrt{3}x + 1 = 0$ の解 $\alpha, \beta$ の偏角を求め、条件 $\arg \frac{\alpha - z}{\beta - z} = \frac{\pi}{2}$ を満たす点 $P(z)$ の描く円の角、中心、半径を求める。

**【公式正解】**
- $\text{AB} = 56$ ($\arg \alpha = \frac{5}{6}\pi$)
- $\text{CD} = 76$ ($\arg \beta = \frac{7}{6}\pi$)
- $\text{E} = 9$ ($\angle \text{APB} = \frac{\pi}{2}$、選択肢 $\textcircled{9}$)
- $\text{FG} = 32$ (中心 $-\frac{\sqrt{3}}{2}$)
- $\text{HI} = 12$ (半径 $\frac{1}{2}$)

**【詳細推導・解答プロセス】**
**(1) $\alpha, \beta$ の偏角の決定**
2次方程式 $x^2 + \sqrt{3}x + 1 = 0$ を解くと：
$$x = \frac{-\sqrt{3} \pm \sqrt{3 - 4}}{2} = -\frac{\sqrt{3}}{2} \pm \frac{1}{2}i$$
これらを極形式で表すと：
$$\cos \theta_1 = -\frac{\sqrt{3}}{2}, \quad \sin \theta_1 = \frac{1}{2} \implies \theta_1 = \frac{5}{6}\pi$$
$$\cos \theta_2 = -\frac{\sqrt{3}}{2}, \quad \sin \theta_2 = -\frac{1}{2} \implies \theta_2 = \frac{7}{6}\pi$$
条件 $0 < \arg \alpha < \arg \beta < 2\pi$ より：
$$\arg \alpha = \frac{5}{6}\pi, \quad \arg \beta = \frac{7}{6}\pi$$
したがって、$\text{A} = 5, \text{B} = 6$ (AB = 56) および $\text{C} = 7, \text{D} = 6$ (CD = 76) である。

**(2) 点 P の軌跡（中心と半径）**
条件 $\textcircled{1}$: $\arg \frac{\alpha - z}{\beta - z} = \frac{\pi}{2}$ において、複素数平面上のベクトルを考えると：
$$\arg \frac{\alpha - z}{\beta - z} = \arg(\alpha - z) - \arg(\beta - z)$$
これは、半直線 PB から半直線 PA へ測った回転角（有向角）が $\frac{\pi}{2}$ であることを意味する。
したがって、$\angle \text{APB} = \frac{\pi}{2}$ である。選択肢より $\text{E} = 9$ ($\angle \text{APB}$) である。
円周角の定理の逆により、$\angle \text{APB} = \frac{\pi}{2}$ である点 P は、線分 AB を直径とする円周上にある。
直径の両端は $A\left(-\frac{\sqrt{3}}{2} + \frac{1}{2}i\right)$ と $B\left(-\frac{\sqrt{3}}{2} - \frac{1}{2}i\right)$ であるから：
- 中点（中心）は：
  $$\frac{\alpha + \beta}{2} = -\frac{\sqrt{3}}{2}$$
  したがって、中心は $-\frac{\sqrt{3}}{2}$ であり、$\text{F} = 3, \text{G} = 2$ (FG = 32) である。
- 半径は：
  $$r = \frac{|\alpha - \beta|}{2} = \frac{|i|}{2} = \frac{1}{2}$$
  したがって、半径は $\frac{1}{2}$ であり、$\text{H} = 1, \text{I} = 2$ (HI = 12) である。

**【考査考点】**
1. 2次方程式の複素数解とオイラーの公式・極形式の偏角決定。
2. 複素数の商の偏角の幾何的意味（有向角 $\angle APB$）の理解。
3. 直径を見込む円周角 $\pi/2$ による円の軌跡（中心と半径）の同定。

## 大問III 問2：複素数が表す直線と円弧の共有点条件（最大値とパラメータ範囲）

**問題コード**: `math-q-III_2` | **正解参照**: `MATH_C2:III_2`

### 出題のポイント
- 複素数等式 $(1+i)z + (1-i)\bar{z} + k = 0$ の直線への還元
- 偏角条件による円弧の領域制限（第2象限弧）
- 円と直線の位置関係による共有点個数の最大値とパラメータ $k$ の範囲解析

### 詳細解説
**【題目大意】**
複素数条件 $\textcircled{1}, \textcircled{2}, \textcircled{3}$ を同時に満たす複素数 $z$ の個数の最大値 $n$ と、そのときのパラメータ $k$ の値の範囲を求める。

**【公式正解】**
- $\text{J} = 1$ (直線の傾き 1、選択肢 $\textcircled{1}$)
- $\text{KL} = 12$ (虚軸との交点 $\frac{1}{2}ki$)
- $\text{M} = 2$ ($n$ の最大値は 2、選択肢 $\textcircled{2}$)
- $\text{NO} = 13, \text{PQ} = 23$ ($1 + \sqrt{3} < k < \sqrt{2} + \sqrt{3}$)

**【詳細推導・解答プロセス】**
**(1) 条件 $\textcircled{2}$ の直線の特定**
$z = x + iy$ ($x, y$ は実数) とおくと、$\bar{z} = x - iy$ である。
条件 $\textcircled{2}$: $(1 + i)z + (1 - i)\bar{z} + k = 0$ に代入すると：
$$(1 + i)(x + iy) + (1 - i)(x - iy) + k = 0$$
$$(x - y) + i(x + y) + (x - y) - i(x + y) + k = 0$$
$$2(x - y) + k = 0 \implies y = x + \frac{k}{2}$$
したがって、直線は傾きが 1 であり、虚軸との交点（$x = 0$ のとき $z = iy$）は $\frac{k}{2}i$ である。
これより、$\text{J} = 1$ (選択肢 $\textcircled{1}$) および $\text{K} = 1, \text{L} = 2$ (KL = 12) である。

**(2) 条件 $\textcircled{1}$ および $\textcircled{3}$ による点 P の軌跡領域**
中心 $C\left(-\frac{\sqrt{3}}{2}, 0\right)$、半径 $r = \frac{1}{2}$ の円の方程式は：
$$\left(x + \frac{\sqrt{3}}{2}\right)^2 + y^2 = \frac{1}{4}$$
有向角 $\arg \frac{\alpha - z}{\beta - z} = \frac{\pi}{2}$ は、点 P が直径 AB の左側の円弧（すなわち $x < -\frac{\sqrt{3}}{2}$）にあることを意味する。
さらに条件 $\textcircled{3}$: $\frac{\pi}{2} < \arg z < \pi$ より、点 P は第 2 象限（$x < 0, y > 0$）にある。
中心の $x$ 座標は $-\frac{\sqrt{3}}{2} \approx -0.866 < 0$ であり、半径 $1/2$ なので円上の点はすべて $x < 0$ を満たす。
したがって、$y > 0$ かつ $x < -\frac{\sqrt{3}}{2}$ の円弧、すなわち第 2 象限にある 4 分の 1 円弧（端点を除く）が点 P の動く軌跡である。

**(3) 共有点の個数 $n$ の最大値**
傾き 1 の直線とこの開円弧との共有点の個数は、高々 2 個である。
したがって、$n$ の最大値は 2 である。選択肢より $\text{M} = 2$ (選択肢 $\textcircled{2}$) である。

**(4) $n = 2$ となる $k$ の範囲の決定**
直線の方程式は $x - y + \frac{k}{2} = 0$ である。
円弧の両端点（開区間の境界）の座標は：
- 上端点：$A\left(-\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$
- 左端点：$\left(-\frac{\sqrt{3} + 1}{2}, 0\right)$
この 2 つの端点を結ぶ線分の傾きは：
$$\frac{\frac{1}{2} - 0}{-\frac{\sqrt{3}}{2} - \left(-\frac{\sqrt{3} + 1}{2}\right)} = \frac{1/2}{1/2} = 1$$
傾きがちょうど 1 で一致するため、直線 $y = x + \frac{k}{2}$ がこの両端点を同時に通る！
上端点 $\left(-\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$ を代入すると：
$$\frac{1}{2} = -\frac{\sqrt{3}}{2} + \frac{k}{2} \implies k = 1 + \sqrt{3}$$
次に、直線がこの円弧に接するときの $k$ を求める。
中心 $\left(-\frac{\sqrt{3}}{2}, 0\right)$ から直線 $x - y + \frac{k}{2} = 0$ までの距離が半径 $\frac{1}{2}$ に等しいから：
$$\frac{|-\frac{\sqrt{3}}{2} - 0 + \frac{k}{2}|}{\sqrt{1^2 + (-1)^2}} = \frac{1}{2} \implies \frac{|k - \sqrt{3}|}{2\sqrt{2}} = \frac{1}{2}$$
$$|k - \sqrt{3}| = \sqrt{2} \implies k = \sqrt{3} \pm \sqrt{2}$$
第 2 象限で円弧の外側に接するのは $y$ 切片が大きい側であるから、$k = \sqrt{3} + \sqrt{2} = \sqrt{2} + \sqrt{3}$ である。
直線が端点を通る割線から接する位置まで平行移動する間、開円弧と 2 点で交わる。
したがって、求める $k$ の範囲は：
$$1 + \sqrt{3} < k < \sqrt{2} + \sqrt{3}$$
$P < Q$ より、$P = 2, Q = 3$ である。
よって、$\text{NO} = 13, \text{PQ} = 23$ である。

**【考査考点】**
1. 複素数等式から直線の実座標方程式への変換技能。
2. 幾何的条件（有向偏角・象限）による円弧の正確な区間限定。
3. 点と直線の距離公式による接線条件と端点通過による共有点個数の解析。

## 大問IV 問1：対数不等式と3次関数の最大値

**問題コード**: `math-q-IV_1` | **正解参照**: `MATH_C2:IV_1`

### 出題のポイント
- 底の変換公式と対数2次不等式の解法
- 変数変換 $t = \log_3 x$ による3次関数への置換
- 導関数 $g'(t)$ による増減の分析と定義域における最大値の特定

### 詳細解説
**【題目大意】**
$x$ が不等式 $2(\log_{\frac{1}{3}} x)^2 + 9\log_{\frac{1}{3}} x + 9 \leq 0$ を満たすとき、$f(x) = (\log_3 x)(\log_3 \frac{x}{3})(\log_3 \frac{x}{9})$ の最大値およびそのときの $x$ の値を求める。

**【公式正解】**
- $\text{AB} = 33, \text{CD} = 27$ ($3\sqrt{3} \leq x \leq 27$)
- $\text{EF} = 32, \text{G} = 3$ ($\frac{3}{2} \leq t \leq 3$)
- $\text{HIJ} = 362$ ($g'(t) = 3t^2 - 6t + 2$)
- $\text{KL} = 27, \text{M} = 6$ ($x = 27$ で最大値 6)

**【詳細推導・解答プロセス】**
**(1) 対数不等式の解**
$\textcircled{1}$: $2(\log_{\frac{1}{3}} x)^2 + 9\log_{\frac{1}{3}} x + 9 \leq 0$ において、$u = \log_{\frac{1}{3}} x$ とおくと：
$$2u^2 + 9u + 9 \leq 0 \implies (2u + 3)(u + 3) \leq 0$$
したがって：
$$-3 \leq u \leq -\frac{3}{2}$$
底の変換公式より $u = \log_{\frac{1}{3}} x = -\log_3 x$ であるから：
$$-3 \leq -\log_3 x \leq -\frac{3}{2} \implies \frac{3}{2} \leq \log_3 x \leq 3$$
底 $3 > 1$ であるから：
$$3^{\frac{3}{2}} \leq x \leq 3^3 \implies 3\sqrt{3} \leq x \leq 27$$
したがって、$\text{A} = 3, \text{B} = 3$ (AB = 33) および $\text{CD} = 27$ である。

**(2) $t = \log_3 x$ による置換**
$t = \log_3 x$ とおくと、$t$ のとり得る値の範囲は：
$$\frac{3}{2} \leq t \leq 3$$
これより、$\text{E} = 3, \text{F} = 2$ (EF = 32) および $\text{G} = 3$ である。

**(3) $g(t)$ とその導関数**
対数の性質 $\log_3 \frac{x}{3} = \log_3 x - 1 = t - 1$、$\log_3 \frac{x}{9} = \log_3 x - 2 = t - 2$ より：
$$f(x) = t(t - 1)(t - 2) = t(t^2 - 3t + 2) = t^3 - 3t^2 + 2t = g(t)$$
これを $t$ で微分すると：
$$g'(t) = 3t^2 - 6t + 2$$
したがって、$\text{H} = 3, \text{I} = 6, \text{J} = 2$ (HIJ = 362) である。

**(4) 最大値の決定**
$g'(t) = 0$ を解くと：
$$t = \frac{6 \pm \sqrt{36 - 24}}{6} = \frac{6 \pm 2\sqrt{3}}{6} = 1 \pm \frac{\sqrt{3}}{3}$$
極値をとる $t$ の値は $t_1 = 1 - \frac{\sqrt{3}}{3} \approx 0.423$、および $t_2 = 1 + \frac{\sqrt{3}}{3} \approx 1.577$ である。
区間 $[\frac{3}{2}, 3] = [1.5, 3]$ において、$t = \frac{3}{2} = 1.5 < t_2$ である。
区間内の増減を調べると：
- $\frac{3}{2} \leq t < 1 + \frac{\sqrt{3}}{3}$ において $g'(t) < 0$（単調減少）
- $t = 1 + \frac{\sqrt{3}}{3}$ で極小値をとる
- $1 + \frac{\sqrt{3}}{3} < t \leq 3$ において $g'(t) > 0$（単調増加）
したがって、最大値の候補は区間の両端点 $t = \frac{3}{2}$ および $t = 3$ である。
- $t = \frac{3}{2}$ のとき：
  $$g\left(\frac{3}{2}\right) = \frac{3}{2} \left(\frac{3}{2} - 1\right) \left(\frac{3}{2} - 2\right) = \frac{3}{2} \times \frac{1}{2} \times \left(-\frac{1}{2}\right) = -\frac{3}{8}$$
- $t = 3$ のとき：
  $$g(3) = 3(3 - 1)(3 - 2) = 3 \times 2 \times 1 = 6$$
明らかに $6 > -\frac{3}{8}$ であるから、最大値は 6 である。
このとき $t = 3$ より、$x = 3^3 = 27$ である。
したがって、$f(x)$ は $x = 27$ で最大値 6 をとる。
これより、$\text{KL} = 27, \text{M} = 6$ である。

**【考査考点】**
1. 対数の底の変換公式と対数2次不等式の解法。
2. 変数置換による高次関数の標準化。
3. 導関数を用いた増減表の作成と閉区間における端点・極値の比較による最大値決定。

## 大問IV 問2：回転体の体積と微分・変化率の最大値

**問題コード**: `math-q-IV_2` | **正解参照**: `MATH_C2:IV_2`

### 出題のポイント
- 部分積分法による $x$ 軸周りの回転体の体積 $V(a)$ の定積分計算
- 速度から位置関数 $a(t)$ の導出と合成関数の微分 $\frac{dV}{dt}$ の計算
- 時間変化率の微分解析による最大値およびそのときの体積の算出

### 詳細解説
**【題目大意】**
曲線 $y = \sqrt{x}e^{-x}$ と $x$ 軸および直線 $x = a$ で囲まれた部分を $x$ 軸周りに回転させた立体の体積 $V$ を求め、点 A が速度 $4t$ で動くときの $V$ の変化率 $\frac{dV}{dt}$ の最大値とそのときの $V$ を求める。

**【公式正解】**
- $\text{NOPQ} = 2121$ ($V = -\frac{\pi}{4}\{(2a + 1)e^{-2a} - 1\}$)
- $\text{RSTU} = 8342$ ($\frac{dV}{dt} = 8\pi t^3 e^{-4t^2}$)
- $\text{V} = 6$ ($t = \frac{\sqrt{6}}{4}$ のとき変化率最大)
- $\text{WXYZ} = 5322$ ($V = -\frac{\pi}{8}(5e^{-\frac{3}{2}} - 2)$)

**【詳細推導・解答プロセス】**
**(1) 回転体の体積 $V$ の計算**
$x$ 軸周りの回転体の体積公式より：
$$V = \pi \int_0^a y^2 dx = \pi \int_0^a x e^{-2x} dx$$
部分積分法 $\int f g' dx = f g - \int f' g dx$ を用いる。$f(x) = x, g'(x) = e^{-2x}$ とすると、$g(x) = -\frac{1}{2}e^{-2x}$ であるから：
$$\int_0^a x e^{-2x} dx = \left[ -\frac{1}{2}x e^{-2x} \right]_0^a - \int_0^a \left(-\frac{1}{2}e^{-2x}\right) dx$$
$$= -\frac{1}{2}a e^{-2a} + \frac{1}{2} \left[ -\frac{1}{2}e^{-2x} \right]_0^a = -\frac{1}{2}a e^{-2a} - \frac{1}{4}\left(e^{-2a} - 1\right)$$
$$= -\frac{1}{4}\left(2a e^{-2a} + e^{-2a} - 1\right) = -\frac{1}{4}\left\{(2a + 1)e^{-2a} - 1\right\}$$
したがって、体積 $V$ は：
$$V = -\frac{\pi}{4}\left\{(2a + 1)e^{-2a} - 1\right\}$$
これより、$\text{N} = 2, \text{O} = 1, \text{P} = 2, \text{Q} = 1$ (NOPQ = 2121) である。

**(2) 時間変化率 $\frac{dV}{dt}$ の導出**
点 A は原点を出発し、$t$ 秒後の速度が $v(t) = \frac{da}{dt} = 4t$ である。
初期位置 $a(0) = 0$ であるから、$t$ 秒後の位置 $a(t)$ は：
$$a(t) = \int_0^t 4\tau d\tau = 2t^2$$
微分の連鎖律（チェインルール）より：
$$\frac{dV}{dt} = \frac{dV}{da} \cdot \frac{da}{dt}$$
微積分学の基本定理より、$\frac{dV}{da} = \pi y(a)^2 = \pi a e^{-2a}$ であるから：
$$\frac{dV}{dt} = \pi a e^{-2a} \cdot (4t) = 4\pi t \cdot (2t^2) e^{-2(2t^2)} = 8\pi t^3 e^{-4t^2}$$
したがって、$\text{R} = 8, \text{S} = 3, \text{T} = 4, \text{U} = 2$ (RSTU = 8342) である。

**(3) 変化率の最大値とそのときの時刻**
$h(t) = t^3 e^{-4t^2}$ ($t > 0$) の最大値を求める。積の微分法を用いると：
$$h'(t) = 3t^2 e^{-4t^2} + t^3 (-8t) e^{-4t^2} = t^2(3 - 8t^2) e^{-4t^2}$$
$t > 0$ において $h'(t) = 0$ となるのは：
$$3 - 8t^2 = 0 \implies t^2 = \frac{3}{8} \implies t = \sqrt{\frac{3}{8}} = \frac{\sqrt{6}}{4}$$
$t = \frac{\sqrt{6}}{4}$ の前後で $h'(t)$ の符号は正から負へ変わるため、$h(t)$ はこのとき極大かつ最大となる。
したがって、$\text{V} = 6$ である。

**(4) 変化率最大における体積 $V$ の値**
$t = \frac{\sqrt{6}}{4}$ のとき、$a = 2t^2 = 2 \times \frac{3}{8} = \frac{3}{4}$ である。
これを $V(a)$ の式に代入すると：
$$V = -\frac{\pi}{4} \left\{ \left(2 \cdot \frac{3}{4} + 1\right) e^{-2 \cdot \frac{3}{4}} - 1 \right\} = -\frac{\pi}{4} \left\{ \left(\frac{3}{2} + 1\right) e^{-\frac{3}{2}} - 1 \right\}$$
$$= -\frac{\pi}{4} \left( \frac{5}{2} e^{-\frac{3}{2}} - 1 \right) = -\frac{\pi}{8} \left( 5 e^{-\frac{3}{2}} - 2 \right)$$
したがって、$\text{W} = 5, \text{X} = 3, \text{Y} = 2, \text{Z} = 2$ (WXYZ = 5322) である。

**【考査考点】**
1. 部分積分法を用いた回転体の定積分計算技能。
2. 物理的な運動方程式（速度から位置の積分）と微積分の連鎖律の総合活用。
3. 指数関数を含む関数の導関数計算と極値解析。
