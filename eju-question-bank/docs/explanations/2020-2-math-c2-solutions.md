## 第I問 [1]：2次関数の平行移動と不等式・線分の長さ

**【考査考点】**：放物線の平行移動（2次係数の不変性）, 2次不等式の解法, 解と係数の関係を用いた線分の長さの公式

**【題目大意】**
$a$ は正の定数とする。2次関数 $y = \frac{1}{4}x^2$ のグラフを平行移動し、$x$ 軸との交点が $(-2a, 0), (4a, 0)$ である放物線を $y = f(x)$ とする。
(1) $f(x)$ の因数分解形を求めよ。
(2) 不等式 $f(x) \le 10a^2$ の解を求めよ。
(3) 直線 $y = 10a$ が放物線 $y = f(x)$ によって切り取られる線分の長さが 10 のとき、$a$ の値を求めよ。

**【公式正解】**
- $\text{ABCD} = \mathbf{1442}$
- $\text{EFG} = \mathbf{248}, \quad \text{HI} = \mathbf{68}$
- $\text{JKLM} = \mathbf{2940}, \quad \text{NO} = \mathbf{59}$

**【詳細推導・解答プロセス】**
**(1) $f(x)$ の式の決定**
平行移動した放物線の $x^2$ の係数は元の関数と同じ $\frac{1}{4}$ である。
$x$ 軸との交点が $x = -2a, 4a$ であるから、因数定理より：
$$f(x) = \frac{1}{4} (x - 4a)(x + 2a)$$
よって、$A = 1, B = 4, C = 4, D = 2$ となり、$\text{ABCD} = \mathbf{1442}$ である。

**(2) $y \le 10a^2$ の解**
不等式を展開して整理する：
$$\frac{1}{4}(x^2 - 2ax - 8a^2) \le 10a^2$$
両辺に 4 を掛けると：
$$x^2 - 2ax - 8a^2 \le 40a^2 \implies x^2 - 2ax - 48a^2 \le 0$$
したがって、$E = 2, FG = 48$（$\text{EFG} = \mathbf{248}$）である。
左辺を因数分解すると：
$$(x - 8a)(x + 6a) \le 0$$
$a > 0$ であるから、解は：
$$-6a \le x \le 8a$$
よって、$H = 6, I = 8$（$\text{HI} = \mathbf{68}$）である。

**(3) 切り取られる線分の長さと $a$ の決定**
放物線 $y = f(x)$ と直線 $y = 10a$ の交点の $x$ 座標は方程式：
$$\frac{1}{4}(x^2 - 2ax - 8a^2) = 10a \iff x^2 - 2ax - (8a^2 + 40a) = 0$$
の2実数解 $\alpha, \beta$（$\alpha < \beta$）である。
解と係数の関係より、$\alpha + \beta = 2a, \quad \alpha \beta = -(8a^2 + 40a)$ である。
切り取られる線分の長さ $L$ は：
$$L = \beta - \alpha = \sqrt{(\alpha + \beta)^2 - 4\alpha\beta} = \sqrt{(2a)^2 + 4(8a^2 + 40a)} = \sqrt{36a^2 + 160a} = 2\sqrt{9a^2 + 40a}$$
これが 10 に等しいので：
$$2\sqrt{9a^2 + 40a} = 10 \implies \sqrt{9a^2 + 40a} = 5$$
したがって、$J = 2, K = 9, LM = 40$（$\text{JKLM} = \mathbf{2940}$）である。
両辺を2乗して整理すると：
$$9a^2 + 40a = 25 \iff 9a^2 + 40a - 25 = 0$$
因数分解すると $(9a - 5)(a + 5) = 0$ となり、$a > 0$ より：
$$a = \frac{5}{9}$$
よって、$N = 5, O = 9$（$\text{NO} = \mathbf{59}$）である。

## 第I問 [2]：階段ののぼり方（1段・2段のぼり）と場合の数

**【考査考点】**：反復試行・同じものを含む順列, フィボナッチ数列による漸化式の応用, 隣り合わない（連続しない）条件における空隙挿入法

**【題目大意】**
10段の階段を、1段のぼりまたは2段のぼりで上がる（どちらも必ず1回以上使用）。
(1) 2段のぼりが連続してもよい場合：
    (i) 2段のぼりが3回のときの1段のぼりの回数と総数
    (ii) 連続してもよい場合の全通り数
(2) 2段のぼりが連続しない場合：
    (i) 2段のぼりが2回のときの1段のぼりの回数と総数
    (ii) 連続しない場合の全通り数

**【公式正解】**
- $P = \mathbf{4}, \quad \text{QR} = \mathbf{35}$
- $\text{ST} = \mathbf{87}$
- $U = \mathbf{6}, \quad \text{VW} = \mathbf{21}$
- $\text{XY} = \mathbf{40}$

**【詳細推導・解答プロセス】**
**(1) 2段のぼりが連続してもよい場合**
(i) 2段のぼりが3回のとき：
のぼる段数は $3 \times 2 = 6$ 段であるから、残る段数は $10 - 6 = 4$ 段。
したがって、1段のぼりの回数は $P = \mathbf{4}$ 回である。
のぼり方は、2段のぼり3回と1段のぼり4回の合計7回の並べ替え数であるから：
$$\binom{7}{3} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35\text{ 通り}$$
よって、$\text{QR} = \mathbf{35}$ である。

(ii) 全体ののぼり方の総数：
$n$ 段の階段を1段または2段でのぼる総数を $a_n$ とすると、第1歩が1段か2段かで漸化式 $a_n = a_{n-1} + a_{n-2}$ が成り立つ。
$a_1 = 1, a_2 = 2, a_3 = 3, a_4 = 5, a_5 = 8, a_6 = 13, a_7 = 21, a_8 = 34, a_9 = 55, a_{10} = 89$。
問題文の条件「1段のぼりも2段のぼりも必ず1回はある」より：
- すべて1段のぼり（10回）の1通りを除く
- すべて2段のぼり（5回）の1通りを除く
したがって、求める総数は：
$$89 - 1 - 1 = 87\text{ 通り}$$
よって、$\text{ST} = \mathbf{87}$ である。

**(2) 2段のぼりが連続しない場合**
(i) 2段のぼりが2回のとき：
2段のぼりによる段数は $2 \times 2 = 4$ 段、1段のぼりの回数は $10 - 4 = 6$ 回（$U = \mathbf{6}$）。
2段のぼりが連続しないためには、6回の1段のぼりの両端および隙間（合計7箇所）から2箇所を選んで2段のぼりを配置すればよい：
$$\binom{7}{2} = \frac{7 \times 6}{2 \times 1} = 21\text{ 通り}$$
よって、$\text{VW} = \mathbf{21}$ である。

(ii) 連続しない場合の全通り数：
2段のぼりの回数 $k$（$1 \le k \le 5$）で場合分けする：
- $k = 1$ のとき：1段のぼり 8 回。隙間 9 箇所から 1 箇所選ぶ $\implies \binom{9}{1} = 9$ 通り
- $k = 2$ のとき：1段のぼり 6 回。隙間 7 箇所から 2 箇所選ぶ $\implies \binom{7}{2} = 21$ 通り
- $k = 3$ のとき：1段のぼり 4 回。隙間 5 箇所から 3 箇所選ぶ $\implies \binom{5}{3} = 10$ 通り
- $k \ge 4$ のとき：2段のぼりが4回なら1段のぼりは2回で隙間3箇所しかなく不可能。
合計すると：
$$9 + 21 + 10 = 40\text{ 通り}$$
よって、$\text{XY} = \mathbf{40}$ である。

## 第II問 [1]：等差数列の和・積の数列とその和の最小値

**【考査考点】**：数列の和 $S_n$ からの一般項 $a_n$ の導出, 積の数列 $b_n = a_n a_{n+5}$ の展開とシグマ和 $T_n$, 項の符号変化に基づく和の増減と最小値の判定

**【題目大意】**
初項から第 $n$ 項までの和が $S_n = \frac{n^2 - 17n}{4}$ で表される数列 $\{a_n\}$ に対応して、数列 $\{b_n\}$ を $b_n = a_n \cdot a_{n+5} \quad (n = 1, 2, 3, \dots)$ と定める。
(1) $a_n = \text{A}, b_n = \text{B}, T_n = \sum_{k=1}^n b_k = \text{C}$ を選択肢 $\textcircled{0} \sim \textcircled{9}$ から選べ。
(2) $b_n > 0$ となる $n$ の範囲（$n \le D$ または $EF \le n$）、および $b_n < 0$ となる $n$ の範囲（$G \le n \le H$）を求めよ。
    これより $T_n$ が最小となる3つの番号 $n = I, J, K$（$I < J < K$）とその最小値 $L$ を求めよ。

**【公式正解】**
- $A = \mathbf{1}, \quad B = \mathbf{4}, \quad C = \mathbf{9}$
- $\text{DEF} = \mathbf{310} \implies D = \mathbf{3}, \quad \text{EF} = \mathbf{10}$
- $\text{GH} = \mathbf{58} \implies G = \mathbf{5}, \quad H = \mathbf{8}$
- $I = \mathbf{1}, \quad J = \mathbf{8}, \quad K = \mathbf{9}, \quad L = \mathbf{6}$

**【詳細推導・解答プロセス】**
**(1) $a_n, b_n, T_n$ の導出**
一般項 $a_n$ は $S_n$ の差分より：
$$a_n = S_n - S_{n-1} = \frac{n^2 - 17n - ((n-1)^2 - 17(n-1))}{4}$$
$$= \frac{n^2 - 17n - (n^2 - 2n + 1 - 17n + 17)}{4} = \frac{2n - 18}{4} = \frac{n - 9}{2}$$
これは $n = 1$ のとき $a_1 = \frac{1-9}{2} = -4 = S_1$ となり成り立ちます。
選択肢 $\textcircled{1} \implies A = \mathbf{1}$ である。

次に、$a_{n+5} = \frac{(n+5) - 9}{2} = \frac{n - 4}{2}$ であるから：
$$b_n = a_n \cdot a_{n+5} = \frac{n - 9}{2} \cdot \frac{n - 4}{2} = \frac{n^2 - 13n + 36}{4}$$
選択肢 $\textcircled{4} \implies B = \mathbf{4}$ である。

数列 $\{b_n\}$ の初項から第 $n$ 項までの和 $T_n$ を計算する：
$$T_n = \sum_{k=1}^n b_k = \frac{1}{4} \sum_{k=1}^n (k^2 - 13k + 36)$$
自然数の和の公式を代入する：
$$\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}, \qquad \sum_{k=1}^n k = \frac{n(n+1)}{2}, \qquad \sum_{k=1}^n 36 = 36n$$
共通因数 $\frac{n}{6}$ で括ると：
$$T_n = \frac{1}{4} \cdot \frac{n}{6} \left[ (n+1)(2n+1) - 39(n+1) + 216 \right]$$
かっこ内を整理する：
$$(2n^2 + 3n + 1) - (39n + 39) + 216 = 2n^2 - 36n + 178 = 2(n^2 - 18n + 89)$$
したがって：
$$T_n = \frac{n}{24} \cdot 2(n^2 - 18n + 89) = \frac{n(n^2 - 18n + 89)}{12}$$
選択肢 $\textcircled{9} \implies C = \mathbf{9}$ である。

**(2) $T_n$ の最小値の決定**
$b_n = \frac{(n-4)(n-9)}{4}$ の符号を調べる：
- $b_n > 0 \iff (n-4)(n-9) > 0 \iff n < 4$ または $n > 9$
  $n$ は自然数であるから、$n \le 3$ または $n \ge 10$。
  したがって、$D = 3, \text{EF} = 10$ である。
- $b_n < 0 \iff 4 < n < 9 \iff 5 \le n \le 8$
  したがって、$G = 5, H = 8$ である。
- $n = 4$ および $n = 9$ のとき $b_4 = 0, b_9 = 0$ である。

和 $T_n$ と項 $b_n$ の関係 $T_n - T_{n-1} = b_n$ より：
- $n = 1, 2, 3$ では $b_n > 0$ であるから、$T_n$ は増加する。
  $T_1 = b_1 = \frac{(-3)(-8)}{4} = 6$
  $T_2 = 6 + \frac{7}{2} = 9.5, \quad T_3 = 9.5 + \frac{3}{2} = 11$
- $n = 4$ では $b_4 = 0$ であるから、$T_4 = T_3 = 11$
- $n = 5, 6, 7, 8$ では $b_n < 0$ であるから、$T_n$ は減少する：
  $T_5 = 11 - 1 = 10, \quad T_6 = 10 - 1.5 = 8.5$
  $T_7 = 8.5 - 1.5 = 7, \quad T_8 = 7 - 1 = 6$
- $n = 9$ では $b_9 = 0$ であるから、$T_9 = T_8 = 6$
- $n \ge 10$ では $b_n > 0$ であるから、$T_n$ は再び単調増加する：
  $T_{10} = 6 + 1.5 = 7.5, \quad T_{11} = 7.5 + 3.5 = 11, \dots$

以上の推移を比較すると、$T_n$ の値は：
$$T_1 = 6, \quad T_8 = 6, \quad T_9 = 6$$
であり、他のすべての自然数 $n$ において $T_n > 6$ である。
したがって、$T_n$ は $n = 1, 8, 9$ の3箇所で最小値 6 をとる。
$I < J < K$ より、$I = \mathbf{1}, J = \mathbf{8}, K = \mathbf{9}$ であり、最小値は $L = \mathbf{6}$ である。

## 第II問 [2]：複素数平面・極形式・多項式の因数分解

**【考査考点】**：複素数の極形式表現とド・モアブルの定理, 累乗根 $z^n = w$ の解と偏角の分配, 高次複素数方程式の根の対応と積の計算

**【題目大意】**
(1) 複素数 $8 + 8\sqrt{3}i$ を極形式 $\text{MN}(\cos \frac{\pi}{O} + i\sin \frac{\pi}{P})$ で表せ。
(2) 方程式 $z^4 = 8 + 8\sqrt{3}i$（$0 \le \arg z < 2\pi$）の解を偏角順に $z_1, z_2, z_3, z_4$ とする。
    $|z| = Q$、および $\arg \frac{z_1 z_2 z_3}{z_4} = \frac{\pi}{R}$ を求めよ。
(3) 方程式 $w^8 - 16w^4 + 256 = 0$（$0 \le \arg w < 2\pi$）の8根 $w_1 \sim w_8$ のうち、$z_1 \sim z_4$ と一致する添字 $\text{STUV}$ を求めよ。
    また、$w_1 w_8 = W, w_3 w_4 = \text{XY}i$ を求めよ。

**【公式正解】**
- $\text{MN} = \mathbf{16}, \quad O = \mathbf{3}, \quad P = \mathbf{3}$
- $Q = \mathbf{2}, \quad R = \mathbf{6}$
- $\text{STUV} = \mathbf{1357}$
- $W = \mathbf{4}, \quad \text{XY} = \mathbf{-4}$

**【詳細推導・解答プロセス】**
**(1) 極形式の計算**
絶対値 $r$ は：
$$r = \sqrt{8^2 + (8\sqrt{3})^2} = \sqrt{64 + 192} = \sqrt{256} = 16$$
偏角 $\theta$ は $\cos \theta = \frac{8}{16} = \frac{1}{2}, \sin \theta = \frac{8\sqrt{3}}{16} = \frac{\sqrt{3}}{2}$ より $\theta = \frac{\pi}{3}$ である。
したがって：
$$8 + 8\sqrt{3}i = 16\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$$
よって、$\text{MN} = \mathbf{16}, O = \mathbf{3}, P = \mathbf{3}$ である。

**(2) 4乗根の決定と偏角の合成**
$z^4 = 16 e^{i\pi/3}$ より、$|z|^4 = 16 \implies |z| = \sqrt[4]{16} = 2$（$Q = \mathbf{2}$）。
偏角の範囲 $0 \le \arg z < 2\pi$ における4つの根の偏角は：
$$\arg z_k = \frac{\frac{\pi}{3} + 2k\pi}{4} = \frac{\pi}{12} + \frac{k\pi}{2} \quad (k = 0, 1, 2, 3)$$
偏角の小さい順に：
$$\arg z_1 = \frac{\pi}{12}, \quad \arg z_2 = \frac{7\pi}{12}, \quad \arg z_3 = \frac{13\pi}{12}, \quad \arg z_4 = \frac{19\pi}{12}$$
商と積の偏角公式より：
$$\arg \frac{z_1 z_2 z_3}{z_4} \equiv \arg z_1 + \arg z_2 + \arg z_3 - \arg z_4 \pmod{2\pi}$$
$$= \frac{\pi + 7\pi + 13\pi - 19\pi}{12} = \frac{2\pi}{12} = \frac{\pi}{6}$$
したがって、$R = \mathbf{6}$ である。

**(3) 8次方程式の根の対応と積**
方程式 $(w^4)^2 - 16(w^4) + 256 = 0$ を $w^4$ の2次方程式として解く：
$$w^4 = \frac{16 \pm \sqrt{256 - 1024}}{2} = \frac{16 \pm \sqrt{-768}}{2} = \frac{16 \pm 16\sqrt{3}i}{2} = 8 \pm 8\sqrt{3}i$$
- 第1の組：$w^4 = 8 + 8\sqrt{3}i = 16 e^{i\pi/3}$
  偏角は $\frac{\pi}{12}, \frac{7\pi}{12}, \frac{13\pi}{12}, \frac{19\pi}{12}$（これは $z_1, z_2, z_3, z_4$ と完全に一致）。
- 第2の組：$w^4 = 8 - 8\sqrt{3}i = 16 e^{i 5\pi/3}$
  偏角は $\frac{5\pi/3 + 2k\pi}{4} = \frac{5\pi}{12} + \frac{k\pi}{2}$ より $\frac{5\pi}{12}, \frac{11\pi}{12}, \frac{17\pi}{12}, \frac{23\pi}{12}$。

全8個の解を偏角の昇順に並べると：
1. $w_1 = z_1$（偏角 $\pi/12$）
2. $w_2$（偏角 $5\pi/12$）
3. $w_3 = z_2$（偏角 $7\pi/12$）
4. $w_4$（偏角 $11\pi/12$）
5. $w_5 = z_3$（偏角 $13\pi/12$）
6. $w_6$（偏角 $17\pi/12$）
7. $w_7 = z_4$（偏角 $19\pi/12$）
8. $w_8$（偏角 $23\pi/12$）

したがって、$w_1 = z_1, w_3 = z_2, w_5 = z_3, w_7 = z_4$ であり、$\text{STUV} = \mathbf{1357}$ である。

最後に根の積を計算する（$|w_k| = 2$）：
- $w_1 w_8$ の絶対値は $2 \times 2 = 4$、偏角は $\frac{\pi}{12} + \frac{23\pi}{12} = \frac{24\pi}{12} = 2\pi \equiv 0$ であるから：
  $$w_1 w_8 = 4(\cos 0 + i\sin 0) = 4 \implies W = \mathbf{4}$$
- $w_3 w_4$ の絶対値は $2 \times 2 = 4$、偏角は $\frac{7\pi}{12} + \frac{11\pi}{12} = \frac{18\pi}{12} = \frac{3\pi}{2}$ であるから：
  $$w_3 w_4 = 4\left(\cos\frac{3\pi}{2} + i\sin\frac{3\pi}{2}\right) = 4(0 - i) = -4i$$
  問題文の形式 $w_3 w_4 = \text{XY} i$ より、$\text{XY} = \mathbf{-4}$ である。

## 第III問 [1]：3次関数の接線方程式と交点座標

**【考査考点】**：3次関数の導関数と接線公式, 曲線外の点から引いた接線と接点の決定, 2直線の連立方程式と交点座標の計算

**【題目大意】**
関数 $f(x) = x^3 - 4x + 4$ について考える。
$y = f(x)$ のグラフ上の点 $A(-1, 7)$ における接線を $\ell$ とし、$y = f(x)$ のグラフに点 $B(0, -12)$ から引いた接線を $m$ とする。
(1) $f'(x) = A x^B - C$ を求め、接線 $\ell$ の傾き $\text{DE}$ と方程式 $y = \text{DE}x + F$ を求めよ。
(2) 接点 $(a, f(a))$ における接線 $m$ の方程式を $a$ で表し、$B(0, -12)$ を通る条件から $a = M$、接線 $m$ の方程式 $y = Nx - \text{OP}$、および交点 $C(Q, R)$ を求めよ。

**【公式正解】**
- $\text{ABC} = \mathbf{324}, \quad \text{DE} = \mathbf{-1}, \quad F = \mathbf{6}$
- $\text{GHI} = \mathbf{324}, \quad \text{JKL} = \mathbf{234}, \quad M = \mathbf{2}$
- $\text{NOP} = \mathbf{812}, \quad \text{QR} = \mathbf{24}$

**【詳細推導・解答プロセス】**
**(1) 導関数と接線 $\ell$ の方程式**
$f(x) = x^3 - 4x + 4$ を微分すると：
$$f'(x) = 3x^2 - 4$$
したがって、$A = 3, B = 2, C = 4$（$\text{ABC} = \mathbf{324}$）である。

点 $A(-1, 7)$ における接線の傾きは：
$$f'(-1) = 3(-1)^2 - 4 = 3 - 4 = -1$$
よって、接線 $\ell$ の傾きは $\text{DE} = \mathbf{-1}$ である。
接線 $\ell$ の方程式は：
$$y - 7 = -1(x - (-1)) \iff y - 7 = -x - 1 \iff y = -x + 6$$
したがって、$F = \mathbf{6}$ である。

**(2) 外部の点からの接線 $m$ と交点 $C$**
接点 $(a, a^3 - 4a + 4)$ における接線の方程式は：
$$y - (a^3 - 4a + 4) = (3a^2 - 4)(x - a)$$
展開して整理すると：
$$y = (3a^2 - 4)x - 3a^3 + 4a + a^3 - 4a + 4$$
$$y = (3a^2 - 4)x - 2a^3 + 4$$
したがって、$G = 3, H = 2, I = 4$（$\text{GHI} = \mathbf{324}$）、$J = 2, K = 3, L = 4$（$\text{JKL} = \mathbf{234}$）である。

この接線 $m$ が点 $B(0, -12)$ を通るから、$x = 0, y = -12$ を代入する：
$$-12 = -2a^3 + 4 \iff 2a^3 = 16 \iff a^3 = 8$$
$a$ は実数であるから $a = 2$ である（$M = \mathbf{2}$）。

$a = 2$ を接線方程式に代入すると：
$$y = (3 \cdot 2^2 - 4)x - 2 \cdot 2^3 + 4 = (12 - 4)x - 16 + 4 = 8x - 12$$
したがって、$N = 8, OP = 12$（$\text{NOP} = \mathbf{812}$）である。

2直線 $\ell: y = -x + 6$ と $m: y = 8x - 12$ の交点 $C$ の座標を求める：
$$-x + 6 = 8x - 12 \iff 9x = 18 \iff x = 2$$
$y = -2 + 6 = 4$。
したがって、交点 $C$ の座標は $(2, 4)$ であり、$Q = 2, R = 4$（$\text{QR} = \mathbf{24}$）である。

## 第III問 [2]：2直線のなす角となす角の正接

**【考査考点】**：直線と $x$ 軸正の向きのなす角の傾き表現（$	an 	heta = m$）, 正接の加法定理となす角公式 $	an 	heta = |\frac{\tan \beta - \tan \alpha}{1 + \tan \alpha \tan \beta}|$

**【題目大意】**
2直線 $\ell, m$ と $x$ 軸の正の向きとのなす角をそれぞれ $\alpha, \beta$ とするとき、$\tan \alpha = \text{ST}, \tan \beta = U$ を求め、2直線のなす角 $\theta \ (0 < \theta < \frac{\pi}{2})$ に対する $\tan \theta = \frac{V}{W}$ を求めよ。

**【公式正解】**
- $\text{ST} = \mathbf{-1}, \quad U = \mathbf{8}$
- $\text{VW} = \mathbf{97}$

**【詳細推導・解答プロセス】**
直線の傾きは $x$ 軸の正の向きとのなす角の正接（タンジェント）に等しい。
接線 $\ell$ の方程式は $y = -x + 6$ であるから、傾きは $-1$ である：
$$\tan \alpha = -1 \implies \text{ST} = \mathbf{-1}$$
接線 $m$ の方程式は $y = 8x - 12$ であるから、傾きは 8 である：
$$\tan \beta = 8 \implies U = \mathbf{8}$$

2直線のなす鋭角 $\theta \ (0 < \theta < \frac{\pi}{2})$ に対し、正接の加法定理より：
$$\tan \theta = |\tan(\beta - \alpha)| = \left| \frac{\tan \beta - \tan \alpha}{1 + \tan \alpha \tan \beta} \right|$$
値を代入すると：
$$\tan \theta = \left| \frac{8 - (-1)}{1 + (-1) \times 8} \right| = \left| \frac{9}{1 - 8} \right| = \left| \frac{9}{-7} \right| = \frac{9}{7}$$
形式 $\frac{V}{W}$ より、$V = 9, W = 7$。
したがって、$\text{VW} = \mathbf{97}$ である。

## 第IV問 [1]：三角関数の導関数・増減表と極値・正値性の証明

**【考査考点】**：三角関数の微分と加法定理・倍角公式による因数分解, 導関数の符号変化と関数の増減の特定, 極小値の正値性に基づく区間内正値性の証明

**【題目大意】**
区間 $0 \le x \le \pi$ において、関数 $f(x) = \sin x + \frac{\sin 2x}{2} + \frac{\sin 3x}{3}$ を考える。
(1) $f'(x) = (A\cos^2 x - B)(C\cos x + D)$ と因数分解し、$f'(x)=0$ の3根 $x = \frac{\pi}{E}, \frac{F}{G}\pi, \frac{H}{I}\pi$ を求めよ。
(2) 4つの区間における増減（0: 増加, 1: 減少）を調べ、極小値 $f(\frac{L}{M}\pi) = \frac{\sqrt{S}}{T} > 0$ を示すことで、$0 < x < \pi$ で $f(x) > 0$ を証明せよ。

**【公式正解】**
- $\text{ABCD} = \mathbf{2121}$
- $E = \mathbf{4}, \quad \text{FG} = \mathbf{23}, \quad \text{HI} = \mathbf{34}$
- $J = \mathbf{4}, \quad K = \mathbf{0}$
- $\text{LM} = \mathbf{23}, \quad N = \mathbf{1}$
- $\text{OP} = \mathbf{34}, \quad Q = \mathbf{0}$
- $R = \mathbf{1}$
- $\text{ST} = \mathbf{34}$

**【詳細推導・解答プロセス】**
**(1) 導関数の因数分解と零点の決定**
$f(x) = \sin x + \frac{1}{2}\sin 2x + \frac{1}{3}\sin 3x$ を微分する：
$$f'(x) = \cos x + \frac{1}{2}(2\cos 2x) + \frac{1}{3}(3\cos 3x) = \cos x + \cos 2x + \cos 3x$$
和積の公式 $\cos x + \cos 3x = 2\cos 2x \cos x$ を適用すると：
$$f'(x) = \cos 2x + 2\cos 2x \cos x = \cos 2x (2\cos x + 1)$$
2倍角の公式 $\cos 2x = 2\cos^2 x - 1$ を代入すると：
$$f'(x) = (2\cos^2 x - 1)(2\cos x + 1)$$
したがって、$A = 2, B = 1, C = 2, D = 1$（$\text{ABCD} = \mathbf{2121}$）である。

区間 $0 \le x \le \pi$ において $f'(x) = 0$ を解く：
1. $2\cos^2 x - 1 = 0 \iff \cos^2 x = \frac{1}{2} \iff \cos x = \pm \frac{\sqrt{2}}{2}$
   $0 \le x \le \pi$ より $x = \frac{\pi}{4}, \frac{3\pi}{4}$
2. $2\cos x + 1 = 0 \iff \cos x = -\frac{1}{2}$
   $0 \le x \le \pi$ より $x = \frac{2\pi}{3}$
解を昇順に並べると：
$$x = \frac{\pi}{4}, \quad \frac{2}{3}\pi, \quad \frac{3}{4}\pi$$
したがって、$E = 4, FG = 23, HI = 34$（$\text{FG} = \mathbf{23}, \text{HI} = \mathbf{34}$）である。

**(2) 増減の追跡と $f(x) > 0$ の証明**
4つの区間に分割して導関数の符号を調べる：
1. $0 \le x \le \frac{\pi}{4}$（$J = \mathbf{4}$）：
   $\cos x \ge \frac{\sqrt{2}}{2}$ であるから、$2\cos^2 x - 1 \ge 0$ かつ $2\cos x + 1 > 0$。
   したがって $f'(x) \ge 0$ となり「増加」（$K = \mathbf{0}$）。
2. $\frac{\pi}{4} \le x \le \frac{2}{3}\pi$（$\text{LM} = \mathbf{23}$）：
   $-\frac{1}{2} \le \cos x \le \frac{\sqrt{2}}{2}$ であるから、$2\cos^2 x - 1 \le 0$ かつ $2\cos x + 1 \ge 0$。
   したがって $f'(x) \le 0$ となり「減少」（$N = \mathbf{1}$）。
3. $\frac{2}{3}\pi \le x \le \frac{3}{4}\pi$（$\text{OP} = \mathbf{34}$）：
   $-\frac{\sqrt{2}}{2} \le \cos x \le -\frac{1}{2}$ であるから、$2\cos^2 x - 1 \le 0$ かつ $2\cos x + 1 \le 0$。
   負数同士の積は正であるから $f'(x) \ge 0$ となり「増加」（$Q = \mathbf{0}$）。
4. $\frac{3}{4}\pi \le x \le \pi$：
   $-1 \le \cos x \le -\frac{\sqrt{2}}{2}$ であるから、$2\cos^2 x - 1 \ge 0$ かつ $2\cos x + 1 < 0$。
   したがって $f'(x) \le 0$ となり「減少」（$R = \mathbf{1}$）。

極小値 $f(\frac{2}{3}\pi)$ の値を計算する：
$$f\left(\frac{2\pi}{3}\right) = \sin\frac{2\pi}{3} + \frac{1}{2}\sin\frac{4\pi}{3} + \frac{1}{3}\sin 2\pi$$
$$= \frac{\sqrt{3}}{2} + \frac{1}{2}\left(-\frac{\sqrt{3}}{2}\right) + 0 = \frac{\sqrt{3}}{2} - \frac{\sqrt{3}}{4} = \frac{\sqrt{3}}{4}$$
したがって、$S = 3, T = 4$（$\text{ST} = \mathbf{34}$）である。

境界値は $f(0) = 0, f(\pi) = 0$ であり、区間 $(0, \pi)$ 内の唯一の極小値は $f(2\pi/3) = \frac{\sqrt{3}}{4} > 0$、極大値 $f(\pi/4) > 0, f(3\pi/4) > 0$ である。
したがって、開区間 $0 < x < \pi$ において常に $f(x) > 0$ が成立する。

## 第IV問 [2]：三角関数の定積分と曲線とx軸で囲まれた部分の面積

**【考査考点】**：三角関数の基本定積分公式, 対称区間・周期性による積分の相殺, 正値領域における定積分と面積の導出

**【題目大意】**
区間 $0 \le x \le \pi$ において、曲線 $y = f(x)$ と $x$ 軸とで囲まれた部分の面積 $S$ を求めよ。

**【公式正解】**
- $\text{UVW} = \mathbf{209}$

**【詳細推導・解答プロセス】**
前問 (1) より、区間 $0 < x < \pi$ において常に $f(x) > 0$ である。
したがって、曲線 $y = f(x)$ と $x$ 軸で囲まれた部分の面積 $S$ はそのまま定積分によって計算できる：
$$S = \int_0^\pi f(x) \, dx = \int_0^\pi \left( \sin x + \frac{\sin 2x}{2} + \frac{\sin 3x}{3} \right) dx$$

各項を個別に積分する：
1. $\int_0^\pi \sin x \, dx = \left[ -\cos x \right]_0^\pi = (-\cos \pi) - (-\cos 0) = -(-1) - (-1) = 1 + 1 = 2$
2. $\int_0^\pi \frac{\sin 2x}{2} \, dx = \left[ -\frac{\cos 2x}{4} \right]_0^\pi = -\frac{1}{4}(\cos 2\pi - \cos 0) = -\frac{1}{4}(1 - 1) = 0$
3. $\int_0^\pi \frac{\sin 3x}{3} \, dx = \left[ -\frac{\cos 3x}{9} \right]_0^\pi = -\frac{1}{9}(\cos 3\pi - \cos 0) = -\frac{1}{9}(-1 - 1) = -\frac{1}{9}(-2) = \frac{2}{9}$

以上を合算すると：
$$S = 2 + 0 + \frac{2}{9} = \frac{18 + 2}{9} = \frac{20}{9}$$
形式 $\frac{\text{UV}}{W}$ より、$U = 2, V = 0, W = 9$。
したがって、$\text{UVW} = \mathbf{209}$ である。
