## 数学 コース2 第I問 [1]：2つの放物線の共有点と対称性・頂点決定

**問題コード**: `math-q-I_1` | **正解参照**: `I:1`

**公式正解**: `{'A': '1', 'BC': '43', 'DE': '-3', 'FG': '-1', 'H': '0', 'IJ': '-3', 'KL': '13', 'MN': '13'}`

### 出題のポイント
- 2次関数のグラフの配置と共有点を通る連立方程式の解法
- 図形の対称性から軸の方程式および係数 $b=0$ の同定
- 頂点条件と係数 $a, c$ の決定

### 詳細解説
**【題目大意】**
2つの放物線 $\ell: y = ax^2 + 2bx + c$ と $m: y = (a+1)x^2 + 2(b+2)x + c + 3$ を考える。
(1) 3点A, B, Cを通る放物線を $\ell, m$ から選ぶ。
(2) 2つの放物線がともに通る点B, Cの $x$ 座標を決定する。
(3) $AB = BC$ かつ $CO = OD$ のとき、$a, b, c$ の値を決定する。

**【公式正解】**
$\text{A} = 1$ (放物線 $m$)
$\text{BC} = 43$ ($x^2 + 4x + 3 = 0$)
$\text{DE} = -3$, $\text{FG} = -1$
$\text{H} = 0$, $\text{IJ} = -3$, $\text{KL} = 13$ ($a = -\frac{1}{3}$), $\text{MN} = 13$ ($c = \frac{1}{3}$)

**【詳細推導・解答プロセス】**
**(1) 3点A, B, Cを通る放物線の同定**
図において、点A, B, Cを通る放物線は上に凸の急峻な放物線であり、2次の係数は $a+1 > a$ である。
したがって、3点A, B, Cを通る放物線は $m$ である。
よって、$\text{A} = 1$ である。

**(2) 交点B, Cの $x$ 座標**
2つの放物線 $\ell$ と $m$ の交点の方程式は：
$$(a+1)x^2 + 2(b+2)x + c + 3 - (ax^2 + 2bx + c) = 0$$
$$x^2 + 4x + 3 = 0$$
したがって、$\text{BC} = 43$ である。
これを因数分解すると $(x + 3)(x + 1) = 0$ より、$x = -3, -1$ である。
図より点Bの $x$ 座標は $-3$、点Cの $x$ 座標は $-1$ である。
したがって、$\text{DE} = -3$、$\text{FG} = -1$ である。

**(3) 係数 $a, b, c$ の決定**
- $CO = OD$ より、点C（$x = -1$）と点D（$x = 1$）は $y$ 軸に関して対称である。
  放物線 $\ell$ はこの2点を通るため、軸は $y$ 軸（$x = 0$）である。
  軸の方程式 $x = -\frac{b}{a} = 0 \implies b = 0$。
  したがって、$\text{H} = 0$ である。
- $AB = BC$ より、点B（$x = -3$）は放物線 $m$ の軸上にあるため、放物線 $m$ の軸は $x = -3$ である。
  したがって、$\text{IJ} = -3$ である。
- 放物線 $m$ の軸の方程式 $x = -\frac{b+2}{a+1} = -3$ に $b=0$ を代入すると：
  $$-\frac{2}{a+1} = -3 \implies 3a + 3 = 2 \implies a = -\frac{1}{3}$$
  したがって、$\text{KL} = 13$ である。
- 点C（$-1, y_C$）において、放物線 $\ell$ と $m$ が共有点をもつことより：
  $$c = \frac{1}{3}$$
  したがって、$\text{MN} = 13$ である。

**【考査考点】**
- 2次方程式の判別式および交点条件。
- 軸の対称性から係数を特定する幾何・代数的アプローチ。

## 数学 コース2 第I問 [2]：2つの袋からの非復元抽出と条件付き確率・余事象

**問題コード**: `math-q-I_2` | **正解参照**: `I:2`

**公式正解**: `{'OPQ': '925', 'RS': '25', 'TUV': '350', 'WXYZ': '2750'}`

### 出題のポイント
- 袋A（白4・赤1）、袋B（白2・赤3）からの非復元2球抽出
- 積の法則を用いた各組合せ事象の確率計算
- 排反事象の加法定理と余事象による「白2個以下」の確率

### 詳細解説
**【題目大意】**
袋A（白4個・赤1個）、袋B（白2個・赤3個）から順にそれぞれ2個の球を取り出す。
(1) Aから白2個、Bから白1個・赤1個を取り出す確率。
(2) 取り出した4個の中に白3個・赤1個が含まれる確率。
(3) 取り出した4個がすべて同色である確率。
(4) 取り出した4個の中に含まれる白球が2個以下である確率。

**【公式正解】**
$\text{OPQ} = 925$ ($\frac{9}{25}$)
$\text{RS} = 25$ ($\frac{2}{5}$)
$\text{TUV} = 350$ ($\frac{3}{50}$)
$\text{WXYZ} = 2750$ ($\frac{27}{50}$)

**【詳細推導・解答プロセス】**
全事象の数は $\binom{5}{2} \times \binom{5}{2} = 10 \times 10 = 100$ 通りである。

**(1) Aから白2個、Bから白1個・赤1個**
$$P_1 = \frac{\binom{4}{2} \times \left[\binom{2}{1}\binom{3}{1}\right]}{100} = \frac{6 \times 6}{100} = \frac{36}{100} = \frac{9}{25}$$
したがって、$\text{OPQ} = 925$ である。

**(2) 白3個・赤1個**
- A(白2) かつ B(白1・赤1)：$6 \times 6 = 36$ 通り
- A(白1・赤1) かつ B(白2)：$\left[\binom{4}{1}\binom{1}{1}\right] \times \binom{2}{2} = 4 \times 1 = 4$ 通り
合計 $36 + 4 = 40$ 通り。
$$P_2 = \frac{40}{100} = \frac{2}{5}$$
したがって、$\text{RS} = 25$ である。

**(3) すべて同色**
赤4個はAに赤が1個しかないため不可能。
白4個となるのは、A(白2) かつ B(白2) の場合：
$$\binom{4}{2} \times \binom{2}{2} = 6 \times 1 = 6 \text{ 通り}$$
$$P_3 = \frac{6}{100} = \frac{3}{50}$$
したがって、$\text{TUV} = 350$ である。

**(4) 白球が2個以下**
余事象「白球が3個または4個」の確率は：
$$P(\text{白3または4}) = \frac{40 + 6}{100} = \frac{46}{100} = \frac{23}{50}$$
よって、求める確率は：
$$P_4 = 1 - \frac{23}{50} = \frac{27}{50}$$
したがって、$\text{WXYZ} = 2750$ である。

**【考査考点】**
- 組合せ記号 $\binom{n}{r}$ による確率の基本計算。
- 排反事象の整理と余事象の確率公式。

## 数学 コース2 第II問 [1]：ベクトルの内積となす角および4次方程式の代数変形

**問題コード**: `math-q-II_1` | **正解参照**: `II:1`

**公式正解**: `{'AB': '34', 'C': '1', 'DEFG': '4416', 'HI': '46', 'JKL': '313'}`

### 出題のポイント
- ベクトルの内積公式 $\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos\theta$
- ベクトルの大きさの展開式と内積のなす角の関係式 $(\vec{u}\cdot\vec{v})^2 = \cos^2 30^\circ |\vec{u}|^2|\vec{v}|^2$
- 複2次方程式の平方完成変形 $(x^2 - H)^2 = (Ix)^2$ と解の導出

### 詳細解説
**【題目大意】**
2つのベクトル $\vec{a}, \vec{b}$ について、$|\vec{a}| = 1, |\vec{b}| = 2$、なす角は $60^\circ$ である。
実数 $x > 1$ に対し、$\vec{u} = x\vec{a} + \vec{b}$、$\vec{v} = x\vec{a} - \vec{b}$ とする。$\vec{u}$ と $\vec{v}$ のなす角が $30^\circ$ となる $x$ の値を求める。

**【公式正解】**
$\text{AB} = 34$ ($\frac{3}{4}$)
$\text{C} = 1$ ($\vec{a}\cdot\vec{b} = 1$)
$\text{DEFG} = 4416$ ($x^4 - 44x^2 + 16 = 0$)
$\text{HI} = 46$ ($(x^2 - 4)^2 = (6x)^2$)
$\text{JKL} = 313$ ($x = 3 + \sqrt{13}$)

**【詳細推導・解答プロセス】**
**(1) なす角の関係式**
$\vec{u}$ と $\vec{v}$ のなす角が $30^\circ$ であるから：
$$\cos 30^\circ = \frac{\vec{u}\cdot\vec{v}}{|\vec{u}||\vec{v}|} = \frac{\sqrt{3}}{2}$$
両辺を2乗すると：
$$(\vec{u}\cdot\vec{v})^2 = \frac{3}{4} |\vec{u}|^2 |\vec{v}|^2$$
したがって、$\text{AB} = 34$ である。

**(2) 内積および大きさの計算**
$$\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos 60^\circ = 1 \times 2 \times \frac{1}{2} = 1$$
したがって、$\text{C} = 1$ である。
各成分を展開する：
$$\vec{u}\cdot\vec{v} = (x\vec{a} + \vec{b})\cdot(x\vec{a} - \vec{b}) = x^2 |\vec{a}|^2 - |\vec{b}|^2 = x^2(1) - 4 = x^2 - 4$$
$$|\vec{u}|^2 = |x\vec{a} + \vec{b}|^2 = x^2|\vec{a}|^2 + 2x(\vec{a}\cdot\vec{b}) + |\vec{b}|^2 = x^2 + 2x + 4$$
$$|\vec{v}|^2 = |x\vec{a} - \vec{b}|^2 = x^2|\vec{a}|^2 - 2x(\vec{a}\cdot\vec{b}) + |\vec{b}|^2 = x^2 - 2x + 4$$
積 $|\vec{u}|^2 |\vec{v}|^2$ は：
$$|\vec{u}|^2 |\vec{v}|^2 = ((x^2 + 4) + 2x)((x^2 + 4) - 2x) = (x^2 + 4)^2 - (2x)^2 = x^4 + 8x^2 + 16 - 4x^2 = x^4 + 4x^2 + 16$$

**(3) 4次方程式の整理**
関係式 $(\vec{u}\cdot\vec{v})^2 = \frac{3}{4} |\vec{u}|^2 |\vec{v}|^2$ に代入すると：
$$(x^2 - 4)^2 = \frac{3}{4}(x^4 + 4x^2 + 16)$$
両辺に 4 を掛ける：
$$4(x^4 - 8x^2 + 16) = 3(x^4 + 4x^2 + 16)$$
$$4x^4 - 32x^2 + 64 = 3x^4 + 12x^2 + 48$$
整理すると：
$$x^4 - 44x^2 + 16 = 0$$
したがって、$\text{DEFG} = 4416$ である。

**(4) 平方完成と方程式の求解**
式を変形する：
$$x^4 - 8x^2 + 16 = 36x^2$$
$$(x^2 - 4)^2 = (6x)^2$$
したがって、$H = 4, I = 6$ より、$\text{HI} = 46$ である。
平方根をとると：
$$x^2 - 4 = \pm 6x$$
- $x^2 - 6x - 4 = 0$ のとき：
  $$x = \frac{6 \pm \sqrt{36 + 16}}{2} = 3 \pm \sqrt{13}$$
  $x > 1$ より、$x = 3 + \sqrt{13}$ （$\sqrt{13} \approx 3.6$ より $3 + \sqrt{13} \approx 6.6 > 1$）
- $x^2 + 6x - 4 = 0$ のとき：
  $$x = -3 \pm \sqrt{13}$$
  正の解は $-3 + \sqrt{13} \approx 0.6 < 1$ であり、$x > 1$ を満たさない。
したがって、求める解は $x = 3 + \sqrt{13}$ である。
よって、$\text{JKL} = 313$ である。

**【考査考点】**
- 平面ベクトルの内積計算となす角の定義式。
- 複2次方程式の巧みな平方完成変形 $(x^2 - H)^2 = (Ix)^2$ による因数分解。

## 数学 コース2 第II問 [2]：複素数平面における偏角条件・直線と円の接点

**問題コード**: `math-q-II_2` | **正解参照**: `II:2`

**公式正解**: `{'M': '3', 'NOP': '033', 'QRS': '312', 'TUVW': '1343'}`

### 出題のポイント
- ド・モアブルの定理と $z^3 \in \mathbb{R}$ の偏角条件 $\arg z = \frac{k\pi}{3}$
- 複素数平面上の3直線群の幾何学的方程式
- 点と直線の距離の公式による最小距離（円と直線の接点条件）の導出

### 詳細解説
**【題目大意】**
複素数平面上で $z^3$ が実数となるような複素数 $z$ を考える。
(1) 条件を満たす $z = x + iy$ の偏角 $\arg z = \frac{\pi}{M}k$ および表される3直線の方程式を求める。
(2) 図形 $C$ 上に $|z - 1 - i| = r$ を満たす $z$ がただ1個だけ存在するとき、$r$ の値およびそのときの $z$ を決定する。

**【公式正解】**
$\text{M} = 3$
$\text{NOP} = 033$ ($y = 0, y = \sqrt{3}x, y = -\sqrt{3}x$)
$\text{QRS} = 312$ ($r = \frac{\sqrt{3} - 1}{2}$)
$\text{TUVW} = 1343$ ($z = \frac{1 + \sqrt{3}}{4}(1 + \sqrt{3}i)$)

**【詳細推導・解答プロセス】**
**(1) 偏角条件と3直線の方程式**
$z = r(\cos\theta + i\sin\theta)$ とおく。
ド・モアブルの定理より $z^3 = r^3(\cos 3\theta + i\sin 3\theta)$ である。
$z^3$ が実数となるための条件は、虚部が $0$、すなわち $\sin 3\theta = 0$ である：
$$3\theta = k\pi \implies \theta = \arg z = \frac{\pi}{3}k \quad (k \in \mathbb{Z})$$
したがって、$\text{M} = 3$ である。
$k = 0, 1, 2$ に対応する偏角は：
- $k = 0$：$\theta = 0$ または $\pi$ $\implies$ 実軸、すなわち直線 $y = 0$
- $k = 1$：$\theta = \frac{\pi}{3}$ または $\frac{4\pi}{3}$ $\implies$ 傾き $\tan\frac{\pi}{3} = \sqrt{3}$ の直線 $y = \sqrt{3}x$
- $k = 2$：$\theta = \frac{2\pi}{3}$ または $\frac{5\pi}{3}$ $\implies$ 傾き $\tan\frac{2\pi}{3} = -\sqrt{3}$ の直線 $y = -\sqrt{3}x$
したがって、$N = 0, O = 3, P = 3$ より、$\text{NOP} = 033$ である。

**(2) 円と直線の接点条件による $r$ の決定**
$|z - (1 + i)| = r$ は、点 $(1, 1)$ を中心とする半径 $r$ の円を表す。
この円と図形 $C$（3本の直線）がただ1つの共有点をもつのは、中心 $(1, 1)$ から3直線への距離のうち**最も近い直線と接する**ときである。
中心 $(1, 1)$ から各直線への距離を計算する：
1. 直線 $y = 0$ への距離：$d_1 = 1$
2. 直線 $\sqrt{3}x - y = 0$ への距離：
   $$d_2 = \frac{|\sqrt{3}(1) - 1|}{\sqrt{(\sqrt{3})^2 + (-1)^2}} = \frac{\sqrt{3} - 1}{2} \approx \frac{1.732 - 1}{2} = 0.366$$
3. 直線 $\sqrt{3}x + y = 0$ への距離：
   $$d_3 = \frac{|\sqrt{3}(1) + 1|}{2} = \frac{\sqrt{3} + 1}{2} \approx 1.366$$
距離を比較すると $d_2 < d_1 < d_3$ であるため、最も近い直線は $y = \sqrt{3}x$ である。
したがって、円が直線 $y = \sqrt{3}x$ に接するとき、共有点はただ1つとなる：
$$r = d_2 = \frac{\sqrt{3} - 1}{2}$$
したがって、$\text{QRS} = 312$ である。

**(3) 接点における複素数 $z$ の決定**
接点は中心 $(1, 1)$ から直線 $\sqrt{3}x - y = 0$ に下ろした垂線の足である。
直線の法線ベクトルは $(\sqrt{3}, -1)$ であり、大きさを1に規格化した単位法線ベクトルは $\left(\frac{\sqrt{3}}{2}, -\frac{1}{2}\right)$ である。
中心 $(1, 1)$ から直線に向かって距離 $r = \frac{\sqrt{3}-1}{2}$ だけ法線と逆方向に進むと：
$$z = (1 + i) - \frac{\sqrt{3}-1}{2}\left(\frac{\sqrt{3}}{2} - \frac{1}{2}i\right)$$
$$z = (1 + i) - \frac{(\sqrt{3}-1)(\sqrt{3}-i)}{4} = (1 + i) - \frac{3 - \sqrt{3}i - \sqrt{3} + i}{4}$$
$$z = \frac{(4 - 3 + \sqrt{3}) + i(4 + \sqrt{3} - 1)}{4} = \frac{(1 + \sqrt{3}) + i(3 + \sqrt{3})}{4}$$
虚部の係数から $1 + \sqrt{3}$ をくくり出すと：
$$3 + \sqrt{3} = \sqrt{3}(\sqrt{3} + 1)$$
したがって：
$$z = \frac{1 + \sqrt{3}}{4}(1 + \sqrt{3}i)$$
よって、$\text{TUVW} = 1343$ である。

**【考査考点】**
- 複素数の極形式とド・モアブルの定理の実数条件。
- 複素数平面における円と直線の幾何（点と直線の距離・接線の性質）。

## 数学 コース2 第III問 [1]：3次関数の導関数とパラメータによる極値・最大値の分類

**問題コード**: `math-q-III_1` | **正解参照**: `III:1`

**公式正解**: `{'A': '2', 'B': '6', 'CD': '46', 'EF': '24'}`

### 出題のポイント
- 3次関数の導関数の因数分解 $f'(x) = (x - A)(x - t)$
- パラメータ $t$ と定数 $A=2$ の大小関係による増減表の分類
- 区間端点値 $f(4)$ の計算と因数分解 $f(t) - 6 = -\frac{1}{6}(t+E)(t-F)^2$

### 詳細解説
**【題目大意】**
3次関数 $f(x) = \frac{1}{3}x^3 - \frac{t+2}{2}x^2 + 2tx + \frac{2}{3}$ の区間 $x \le 4$ における最大値が 6 より大きくなる実数 $t$ の範囲を求める。
(1) $f'(x) = (x - A)(x - t)$ を求め、$f(4) = B$ を計算する。
(2) $t = A$ のときの最大値 $f(C) = D$ を調べる。
(3) $f(t) - 6 = -\frac{1}{6}(t + E)(t - F)^2$ の恒等式変形を確認する。

**【公式正解】**
$\text{A} = 2$
$\text{B} = 6$
$\text{CD} = 46$ ($f(4) = 6$)
$\text{EF} = 24$ ($f(t) - 6 = -\frac{1}{6}(t + 2)(t - 4)^2$)

**【詳細推導・解答プロセス】**
**(1) 導関数の因数分解と $f(4)$ の計算**
$$f(x) = \frac{1}{3}x^3 - \frac{t+2}{2}x^2 + 2tx + \frac{2}{3}$$
導関数を計算する：
$$f'(x) = x^2 - (t+2)x + 2t = (x - 2)(x - t)$$
したがって、$\text{A} = 2$ である。

$x = 4$ を代入すると：
$$f(4) = \frac{1}{3}(64) - \frac{t+2}{2}(16) + 2t(4) + \frac{2}{3}$$
$$f(4) = \frac{64 + 2}{3} - 8(t+2) + 8t = \frac{66}{3} - 8t - 16 + 8t = 22 - 16 = 6$$
したがって、$f(4) = 6$ であり、$\text{B} = 6$ である。

**(2) $t = 2$ の場合**
$t = 2$ のとき、$f'(x) = (x - 2)^2 \ge 0$ となり、$f(x)$ は単調増加関数である。
したがって、区間 $x \le 4$ における最大値は右端 $x = 4$ でとり：
$$\max_{x \le 4} f(x) = f(4) = 6$$
これは「最大値が 6 より大きい」という条件を満たさない。
したがって、$\text{C} = 4, \text{D} = 6$ より、$\text{CD} = 46$ である。

**(3) $f(t) - 6$ の因数分解**
$$f(t) = \frac{1}{3}t^3 - \frac{t+2}{2}t^2 + 2t^2 + \frac{2}{3} = \frac{1}{3}t^3 - \frac{1}{2}t^3 - t^2 + 2t^2 + \frac{2}{3} = -\frac{1}{6}t^3 + t^2 + \frac{2}{3}$$
$$f(t) - 6 = -\frac{1}{6}t^3 + t^2 + \frac{2}{3} - 6 = -\frac{1}{6}t^3 + t^2 - \frac{16}{3}$$
全体を $-\frac{1}{6}$ でくくると：
$$f(t) - 6 = -\frac{1}{6}(t^3 - 6t^2 + 32)$$
$t = 4$ を代入すると $4^3 - 6(16) + 32 = 64 - 96 + 32 = 0$ となり、$t=4$ を重解にもつ。
組立除法または因数分解を行うと：
$$t^3 - 6t^2 + 32 = (t - 4)(t^2 - 2t - 8) = (t - 4)^2(t + 2)$$
したがって：
$$f(t) - 6 = -\frac{1}{6}(t + 2)(t - 4)^2$$
よって、$E = 2, F = 4$ より、$\text{EF} = 24$ である。

**【考査考点】**
- 3次関数の増減・極値と導関数の因数分解。
- パラメータを含む多項式の因数定理による分解。

## 数学 コース2 第III問 [2]：3次関数の最大値条件を満たす実数 $t$ の範囲決定

**問題コード**: `math-q-III_2` | **正解参照**: `III:2`

**公式正解**: `{'GHI': '103', 'JK': '-2'}`

### 出題のポイント
- 増減表に基づく区間 $x \le 4$ での最大値の特定（極大値と端点値の比較）
- (i) $t > 2$ における極大値 $f(2) > 6$ の不等式求解
- (iii) $t < 2$ における極大値 $f(t) > 6$ の不等式求解

### 詳細解説
**【題目大意】**
前問の分類に基づき、区間 $x \le 4$ における最大値が 6 より大きくなるような実数 $t$ の値の範囲を決定する。

**【公式正解】**
$\text{GHI} = 103$ ($t > \frac{10}{3}$)
$\text{JK} = -2$ ($t < -2$)

**【詳細推導・解答プロセス】**
**(1) 場合分け (i)：$t > 2$ のとき**
$f'(x) = (x - 2)(x - t)$ であり、$t > 2$ より：
- $x < 2$ で $f'(x) > 0$
- $2 < x < t$ で $f'(x) < 0$
- $x > t$ で $f'(x) > 0$
したがって、$f(x)$ は $x = 2$ で極大値をとる。
区間 $x \le 4$ における最大値の候補は、極大値 $f(2)$ または右端の値 $f(4)$ である。
前問より $f(4) = 6$ であるから、最大値が 6 より大きくなるための必要十分条件は：
$$f(2) > 6$$
$f(2)$ を計算する：
$$f(2) = \frac{1}{3}(8) - \frac{t+2}{2}(4) + 2t(2) + \frac{2}{3} = \frac{10}{3} - 2(t+2) + 4t = 2t - \frac{2}{3}$$
条件 $f(2) > 6$ より：
$$2t - \frac{2}{3} > 6 \implies 2t > 6 + \frac{2}{3} = \frac{20}{3} \implies t > \frac{10}{3}$$
$t > \frac{10}{3} \approx 3.33$ は前提 $t > 2$ を満たす。
したがって、$\text{GHI} = 103$ である。

**(2) 場合分け (iii)：$t < 2$ のとき**
$t < 2$ より、増減表は：
- $x < t$ で $f'(x) > 0$
- $t < x < 2$ で $f'(x) < 0$
- $x > 2$ で $f'(x) > 0$
したがって、$f(x)$ は $x = t$ で極大値をとる。
区間 $x \le 4$ における最大値が 6 より大きくなる条件は、極大値 $f(t) > 6$ である。
前問より：
$$f(t) - 6 = -\frac{1}{6}(t + 2)(t - 4)^2 > 0$$
両辺に $-6$ を掛けると：
$$(t + 2)(t - 4)^2 < 0$$
$t < 2$ のとき $(t - 4)^2 > 0$ であるから、両辺を $(t - 4)^2$ で割ると：
$$t + 2 < 0 \implies t < -2$$
これは前提 $t < 2$ を満たす。
したがって、$\text{JK} = -2$ である。

**(3) 結論**
求める $t$ の値の範囲は：
$$t > \frac{10}{3} \quad \text{または} \quad t < -2$$
よって、$\text{GHI} = 103$、$\text{JK} = -2$ である。

**【考査考点】**
- 定義域付き3次関数の最大値のパラメータによる場合分け。
- 極値と区間端点値の大小比較および高次不等式の解法。

## 数学 コース2 第IV問 [1]：商の微分法による三角関数の導関数と極値条件

**問題コード**: `math-q-IV_1` | **正解参照**: `IV:1`

**公式正解**: `{'ABCD': '3232', 'EF': '23'}`

### 出題のポイント
- 商の微分公式 $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ の適用
- 三角関数の基本関係式 $\sin^2 x + \cos^2 x = 1$ による分子の簡略化
- 極値をとる条件 $f'(\alpha) = 0$ から $\cos\alpha$ の特定

### 詳細解説
**【題目大意】**
関数 $f(x) = \frac{\sin x}{3 - 2\cos x} \quad (0 \le x \le \pi)$ について：
(1) $f'(x) = \frac{A\cos x - B}{(C - D\cos x)^2}$ を求め、極値をとる $x = \alpha$ における $\cos\alpha = \frac{E}{F}$ を求める。

**【公式正解】**
$\text{ABCD} = 3232$ ($f'(x) = \frac{3\cos x - 2}{(3 - 2\cos x)^2}$)
$\text{EF} = 23$ ($\cos\alpha = \frac{2}{3}$)

**【詳細推導・解答プロセス】**
**(1) 商の微分法による導関数の計算**
$$f(x) = \frac{\sin x}{3 - 2\cos x}$$
分子を $u(x) = \sin x$、分母を $v(x) = 3 - 2\cos x$ とおくと：
$$u'(x) = \cos x, \quad v'(x) = 2\sin x$$
商の微分公式より：
$$f'(x) = \frac{u'v - uv'}{v^2} = \frac{\cos x(3 - 2\cos x) - \sin x(2\sin x)}{(3 - 2\cos x)^2}$$
分子を展開して整理する：
$$\cos x(3 - 2\cos x) - 2\sin^2 x = 3\cos x - 2\cos^2 x - 2\sin^2 x$$
$$= 3\cos x - 2(\cos^2 x + \sin^2 x) = 3\cos x - 2$$
したがって：
$$f'(x) = \frac{3\cos x - 2}{(3 - 2\cos x)^2}$$
よって、$A = 3, B = 2, C = 3, D = 2$ より、$\text{ABCD} = 3232$ である。

**(2) 極値をとる $\alpha$ の条件**
分母 $(3 - 2\cos x)^2 > 0$ は常に正であるから、$f'(x) = 0$ となる条件は分子が $0$ となることである：
$$3\cos x - 2 = 0 \implies \cos x = \frac{2}{3}$$
区間 $0 \le x \le \pi$ において、$\cos x = \frac{2}{3}$ を満たす $x = \alpha$ がただ1つ存在する。
$\alpha$ の前後で分子 $3\cos x - 2$ は正から負へと符号を変えるため、$f(x)$ は $x = \alpha$ で極大値をとる。
したがって、$\cos\alpha = \frac{2}{3}$ であり、$\text{EF} = 23$ である。

**【考査考点】**
- 三角関数を含む分数関数の微分（商の導関数）。
- 導関数の符号変化と極値の判定条件。

## 数学 コース2 第IV問 [2]：置換積分法によるグラフで囲まれた2つの部分の面積計算

**問題コード**: `math-q-IV_2` | **正解参照**: `IV:2`

**公式正解**: `{'GHI': '231', 'JK': '32', 'LMNO': '1253', 'PQ': '13'}`

### 出題のポイント
- 置換積分 $t = \cos x$ による有理関数の積分への変換
- 積分区間の対応関係と対数関数の積分公式 $\int \frac{1}{ax+b}dx = \frac{1}{a}\log|ax+b|$
- 直線 $x=\alpha$ で分割された左右の面積 $S_1, S_2$ の精密計算

### 詳細解説
**【題目大意】**
関数 $y = f(x)$ と $x$ 軸で囲まれた領域を直線 $x = \alpha$ で2つに分けたとき、左側の面積 $S_1$ および右側の面積 $S_2$ を求める。

**【公式正解】**
$\text{GHI} = 231$ (下端 $\frac{2}{3}$，上端 $1$)
$\text{JK} = 32$ (被積分関数：$\frac{dt}{3 - 2t}$)
$\text{LMNO} = 1253$ ($S_1 = \frac{1}{2}\log\frac{5}{3}$)
$\text{PQ} = 13$ ($S_2 = \frac{1}{2}\log 3$)

**【詳細推導・解答プロセス】**
**(1) 置換積分の準備**
$0 \le x \le \pi$ において $\sin x \ge 0$、分母 $3 - 2\cos x > 0$ であるから、$f(x) \ge 0$ である。
左側の面積 $S_1$ は：
$$S_1 = \int_0^\alpha f(x) dx = \int_0^\alpha \frac{\sin x}{3 - 2\cos x} dx$$
$t = \cos x$ とおくと、$\frac{dt}{dx} = -\sin x \implies \sin x dx = -dt$ である。
積分区間の変化：
- $x = 0$ のとき $t = \cos 0 = 1$
- $x = \alpha$ のとき $t = \cos\alpha = \frac{2}{3}$
置換積分を実行すると：
$$S_1 = \int_1^{2/3} \frac{-dt}{3 - 2t} = \int_{2/3}^1 \frac{dt}{3 - 2t}$$
したがって、下端は $\frac{2}{3}$、上端は $1$ より、$\text{GHI} = 231$、分母は $3 - 2t$ より、$\text{JK} = 32$ である。

**(2) 面積 $S_1$ の値の計算**
$$\int \frac{dt}{3 - 2t} = -\frac{1}{2}\log|3 - 2t|$$
したがって：
$$S_1 = \left[ -\frac{1}{2}\log(3 - 2t) \right]_{2/3}^1 = -\frac{1}{2}\left( \log(3 - 2) - \log\left(3 - \frac{4}{3}\right) \right)$$
$$S_1 = -\frac{1}{2}\left( \log 1 - \log\frac{5}{3} \right) = \frac{1}{2}\log\frac{5}{3}$$
よって、$L = 1, M = 2, N = 5, O = 3$ より、$\text{LMNO} = 1253$ である。

**(3) 面積 $S_2$ の値の計算**
右側の面積 $S_2$ は：
$$S_2 = \int_\alpha^\pi f(x) dx = \int_\alpha^\pi \frac{\sin x}{3 - 2\cos x} dx$$
$x$ が $\alpha \to \pi$ と動くとき、$t$ は $\frac{2}{3} \to -1$ と動く。
$$S_2 = \int_{2/3}^{-1} \frac{-dt}{3 - 2t} = \int_{-1}^{2/3} \frac{dt}{3 - 2t}$$
$$S_2 = \left[ -\frac{1}{2}\log(3 - 2t) \right]_{-1}^{2/3} = -\frac{1}{2}\left( \log\left(3 - \frac{4}{3}\right) - \log(3 - 2(-1)) \right)$$
$$S_2 = -\frac{1}{2}\left( \log\frac{5}{3} - \log 5 \right) = -\frac{1}{2} \log\left(\frac{5/3}{5}\right) = -\frac{1}{2} \log\frac{1}{3} = \frac{1}{2}\log 3$$
問題の形式は $S_2 = \frac{P}{2}\log Q$ であるから、$P = 1, Q = 3$ である。
したがって、$\text{PQ} = 13$ である。

**【考査考点】**
- 三角関数の置換積分法（$\sin x dx = -d(\cos x)$）。
- 対数関数の定積分計算と対数の性質（$\log\frac{A}{B}$ の変形）。
