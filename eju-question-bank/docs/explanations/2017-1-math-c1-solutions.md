## 大問I 問1：2次関数の平行移動と対称移動・共有点問題
- **問題番号**：`math-q-I_1`
- **公式正解**：`{'ABCDE': '31214', 'F': '2', 'G': '8', 'HIJ': '326', 'K': '1', 'LM': '15'}`
- **重要論点**：
  - 2次関数の平行移動による係数決定と標準形への変形
  - 直線 y = c に関する線対称移動の式変形
  - 2つの放物線の共有点がただ1つとなる判別式重解条件の適用

**【題目大意】**
2次関数 $y = 3x^2 - 6$ を平行移動して2点 $(1, 5)$, $(4, 14)$ を通る放物線 $\textcircled{1}$ と、直線 $y = c$ に関して対称移動した放物線 $\textcircled{2}$ について、その方程式および $\textcircled{1}$ と $\textcircled{2}$ がただ1つの共有点をもつときの条件を求める。

**【公式正解】**
- $\text{ABCDE} = 31214$ ($y = 3x^2 - 12x + 14$)
- $\text{F} = 2, \text{G} = 8$ ($x$ 軸方向に 2、$y$ 軸方向に 8 平行移動)
- $\text{HIJ} = 326$ ($y = -3x^2 + 2c + 6$)
- $\text{K} = 1$ ($c = 1$)
- $\text{LM} = 15$ (共有点の座標 $(1, 5)$)

**【詳細推導・解答プロセス】**
**(1) 平行移動した放物線の方程式と平行移動量の特定**
$y = 3x^2 - 6$ のグラフを平行移動した放物線は、$x^2$ の係数が 3 のままであるから、$y = 3x^2 + bx + c'$ とおくことができる。
このグラフが 2 点 $(1, 5)$, $(4, 14)$ を通ることから：
$$
\begin{cases}
3(1)^2 + b(1) + c' = 5 \implies b + c' = 2 \\
3(4)^2 + b(4) + c' = 14 \implies 48 + 4b + c' = 14 \implies 4b + c' = -34
\end{cases}
$$
下の式から上の式を引くと：
$$3b = -36 \implies b = -12$$
これより $c' = 2 - (-12) = 14$ となる。
したがって、放物線の方程式は：
$$y = 3x^2 - 12x + 14$$
よって、$\text{A} = 3, \text{BC} = 12, \text{DE} = 14$ より $\mathbf{ABCDE = 31214}$ である。

次に平行移動量を求めるため、平方完成を行う：
$$y = 3(x^2 - 4x) + 14 = 3(x - 2)^2 - 12 + 14 = 3(x - 2)^2 + 2$$
元の放物線 $y = 3x^2 - 6$ の頂点は $(0, -6)$、移動後の放物線の頂点は $(2, 2)$ である。
したがって、$x$ 軸方向への移動量は $2 - 0 = 2$、
$y$ 軸方向への移動量は $2 - (-6) = 8$ である。
よって、$\mathbf{F = 2}, \mathbf{G = 8}$ である。

**(2) 直線 $y = c$ に関する対称移動と共有点の決定**
点 $(x, y)$ を直線 $y = c$ に関して対称移動した点を $(X, Y)$ とすると：
$$X = x, \quad \frac{y + Y}{2} = c \implies Y = 2c - y$$
元の放物線 $y = 3x^2 - 6$ に代入すると：
$$2c - y = 3x^2 - 6 \implies y = -3x^2 + 2c + 6$$
よって、$\text{H} = 3, \text{I} = 2, \text{J} = 6$ より $\mathbf{HIJ = 326}$ である。

2つの放物線 $\textcircled{1}$ と $\textcircled{2}$ が共有点を 1 つだけもつ条件を考える。
$$3x^2 - 12x + 14 = -3x^2 + 2c + 6$$
整理すると：
$$6x^2 - 12x + (8 - 2c) = 0 \iff 3x^2 - 6x + (4 - c) = 0$$
共有点が 1 つだけ存在するためには、この 2 次方程式が重解をもてばよい。
判別式を $D$ とすると：
$$D/4 = (-3)^2 - 3(4 - c) = 9 - 12 + 3c = 3c - 3 = 0 \implies c = 1$$
よって、$\mathbf{K = 1}$ である。

$c = 1$ のとき、方程式は：
$$3x^2 - 6x + 3 = 0 \iff 3(x - 1)^2 = 0 \implies x = 1$$
このときの $y$ 座標は：
$$y = 3(1)^2 - 12(1) + 14 = 5$$
したがって、共有点の座標は $(1, 5)$ である。
よって、$\text{L} = 1, \text{M} = 5$ より $\mathbf{LM = 15}$ である。

**【考査考点】**
2次関数の決定（未定係数法）、放物線の頂点座標と平行移動の関係、直線 $y = c$ に関する対称移動の幾何的代数化、2次方程式の判別式による接点条件（重解条件）の分析。

## 大問I 問2：カードの順列・組合せと非復元抽出の確率
- **問題番号**：`math-q-I_2`
- **公式正解**：`{'NO': '90', 'PQ': '12', 'RS': '33', 'TUV': '415', 'WXYZ': '1330'}`
- **重要論点**：
  - 白4枚・赤3枚・黒3枚の計10枚の相異なるカードの分配
  - 同色・異色を取り出す組合せと余事象の活用
  - 非復元抽出における条件付き事象の確率計算

**【題目大意】**
白4枚、赤3枚、黒3枚の計10枚のカード（すべて相異なる数字が記されている）からカードを選び、箱に入れたり非復元抽出したりするときの順列・組合せおよび確率を求める。

**【公式正解】**
- $\text{NO} = 90$ (全部で 90 通り)
- $\text{PQ} = 12$ (同色 12 通り)
- $\text{RS} = 33$ (異色 33 通り)
- $\text{TUV} = 415$ (同色である確率 $\frac{4}{15}$)
- $\text{WXYZ} = 1330$ (条件を満たす確率 $\frac{13}{30}$)

**【詳細推導・解答プロセス】**
**(1) 10枚から2枚を選び、箱A, Bに1枚ずつ入れる方法**
異なる10枚から相異なる2枚を選んで順序をつけて箱A, Bに入れる順列の総数は：
$$_{10}\text{P}_2 = 10 \times 9 = 90$$
よって、$\mathbf{NO = 90}$ である。

**(2) 2枚とも同じ色、および異なる色の選び方**
10枚から2枚を選ぶ組合せについて：
- 2枚とも白である選び方：$_4\text{C}_2 = \frac{4 \times 3}{2} = 6$ 通り
- 2枚とも赤である選び方：$_3\text{C}_2 = 3$ 通り
- 2枚とも黒である選び方：$_3\text{C}_2 = 3$ 通り
これらは互いに排反であるから、2枚とも同じ色となる選び方は：
$$6 + 3 + 3 = 12 \text{ 通り}$$
よって、$\mathbf{PQ = 12}$ である。

10枚から2枚を選ぶすべての組合せは：
$$_{10}\text{C}_2 = \frac{10 \times 9}{2} = 45 \text{ 通り}$$
したがって、2枚の色が異なるような選び方は余事象より：
$$45 - 12 = 33 \text{ 通り}$$
よって、$\mathbf{RS = 33}$ である。

**(3) 取り出した2枚が同じ色である確率**
同様に確からしい全事象は $_{10}\text{C}_2 = 45$ 通りであり、2枚が同じ色である事象は 12 通りであるから：
$$P = \frac{12}{45} = \frac{4}{15}$$
よって、$\text{T} = 4, \text{UV} = 15$ より $\mathbf{TUV = 415}$ である。

**(4) 1枚目が白か赤、かつ2枚目が赤か黒である確率**
1枚目に取り出す事象によって排反に場合分けする：
- **場合 1：1枚目が「白」のとき**
  1枚目に白を取り出す確率は $\frac{4}{10}$。
  白が1枚減り、残りは白3枚、赤3枚、黒3枚の計9枚となる。
  この中から2枚目に赤または黒（計6枚）を取り出す確率は $\frac{6}{9}$。
  $$P_1 = \frac{4}{10} \times \frac{6}{9} = \frac{24}{90}$$
- **場合 2：1枚目が「赤」のとき**
  1枚目に赤を取り出す確率は $\frac{3}{10}$。
  赤が1枚減り、残りは白4枚、赤2枚、黒3枚の計9枚となる。
  この中から2枚目に赤または黒（計 $2 + 3 = 5$ 枚）を取り出す確率は $\frac{5}{9}$。
  $$P_2 = \frac{3}{10} \times \frac{5}{9} = \frac{15}{90}$$
これら2つの場合は排反であるから、求める確率は：
$$P = P_1 + P_2 = \frac{24 + 15}{90} = \frac{39}{90} = \frac{13}{30}$$
よって、$\text{WX} = 13, \text{YZ} = 30$ より $\mathbf{WXYZ = 1330}$ である。

**【考査考点】**
場合の数（順列・組合せ）、余事象の考え方、非復元抽出における確率の乗法定理と排反事象の加法定理。

## 大問II 問1：絶対値を含む関数と方程式の解の存在条件
- **問題番号**：`math-q-II_1`
- **公式正解**：`{'A': '3', 'BC': '29', 'D': '6', 'E': '3', 'FG': '29', 'HI': '-3', 'JK': '-1', 'L': '2'}`
- **重要論点**：
  - 区間分割による絶対値記号の解除と折れ線関数の導出
  - 直線の平行移動に伴う解の存在条件の決定
  - 定点を通る直線の傾き変化による異なる2解の存在範囲の解析

**【題目大意】**
方程式 $|x - 3| + |x - 6| = ax + b$ の解の存在条件について考えるため、まず左辺 $y = |x - 3| + |x - 6|$ を区間ごとに絶対値を外して表し、直線 $y = ax + b$ との共有点を解析する。

**【公式正解】**
- $\text{A} = 3, \text{BC} = 29$ ($x < 3$ のとき $y = -2x + 9$)
- $\text{D} = 6, \text{E} = 3$ ($3 \leq x < 6$ のとき $y = 3$)
- $\text{FG} = 29$ ($6 \leq x$ のとき $y = 2x - 9$)
- $\text{HI} = -3$ ($a = 1$ のとき $b \geq -3$)
- $\text{JK} = -1, \text{L} = 2$ ($b = 6$ のとき $-1 < a < 2$)

**【詳細推導・解答プロセス】**
**(1) 絶対値の記号の解除**
各絶対値の符号が切り替わる境界は $x = 3$ と $x = 6$ である。
- **$x < 3$ のとき**：
  $x - 3 < 0, x - 6 < 0$ より：
  $$y = -(x - 3) - (x - 6) = -2x + 9$$
  よって、$\mathbf{A = 3}, \mathbf{BC = 29}$ である。
- **$3 \leq x < 6$ のとき**：
  $x - 3 \geq 0, x - 6 < 0$ より：
  $$y = (x - 3) - (x - 6) = 3$$
  よって、$\mathbf{D = 6}, \mathbf{E = 3}$ である。
- **$x \geq 6$ のとき**：
  $x - 3 \geq 0, x - 6 \geq 0$ より：
  $$y = (x - 3) + (x - 6) = 2x - 9$$
  よって、$\mathbf{FG = 29}$ である。

**(2) 共有点とパラメータの条件**
**(i) $a = 1$ のとき：**
方程式は $|x - 3| + |x - 6| = x + b \iff (|x - 3| + |x - 6|) - x = b$ である。
$g(x) = y - x$ の値域を調べる：
- $x < 3$ のとき：$g(x) = (-2x + 9) - x = -3x + 9$。$x < 3$ より $g(x) > 0$。
- $3 \leq x < 6$ のとき：$g(x) = 3 - x$。単調減少であり、$x = 6$ のとき $g(6) = 3 - 6 = -3$、および $x = 3$ のとき $g(3) = 0$。
- $x \geq 6$ のとき：$g(x) = (2x - 9) - x = x - 9$。$x = 6$ で $-3$ となり、$x \to \infty$ で $\infty$ へ増加する。
したがって、$g(x)$ の最小値は $-3$（$x = 6$ のとき）である。
方程式が解をもつためには、直線 $y = b$ が $g(x)$ の値域に含まれればよいので：
$$b \geq -3$$
よって、$\mathbf{HI = -3}$ である。

**(ii) $b = 6$ のとき：**
直線は $y = ax + 6$ であり、必ず $y$ 軸上の定点 $P(0, 6)$ を通る。
折れ線グラフの形状は：
- 点 $(3, 3)$ と点 $(6, 3)$ を結ぶ水平線分
- $x < 3$ で傾き $-2$、点 $(0, 9)$ を通る半直線
- $x \geq 6$ で傾き $2$ の半直線
定点 $P(0, 6)$ と各特徴点との傾きを調べる：
- $P(0, 6)$ と点 $(3, 3)$ を通る直線の傾き：$\frac{3 - 6}{3 - 0} = -1$。
  $a = -1$ のとき、直線は $y = -x + 6$ であり、$x < 3$ では傾きが $-1 > -2$ のためグラフより常に下側にあり、交点は $(3, 3)$ の1個のみとなる。
  $a > -1$ のとき、直線は $x < 3$ の半直線（傾き $-2$）と必ず 1 点で交わる（$P(0, 6)$ は $y = -2x + 9$ の下側にあるため）。
- 一方、$x \geq 6$ の半直線の傾きは $2$ である。
  $a < 2$ のとき、直線 $y = ax + 6$ は傾きが $2$ より緩やかなので、右側の半直線 $y = 2x - 9$ と必ず交わる。
  $a \geq 2$ のとき、平行またはより急になり、右側の半直線とは交わらないか共有点が1個となる。
したがって、異なる2つの解をもつための傾き $a$ の範囲は：
$$-1 < a < 2$$
よって、$\mathbf{JK = -1}, \mathbf{L = 2}$ である。

**【考査考点】**
絶対値記号を含む折れ線関数のグラフ描画、直線との共有点の幾何学的解釈、定点を通る直線束の傾きによる共有点個数の判別。

## 大問II 問2：正方形の面積の和・不等式と4次関数の最小値
- **問題番号**：`math-q-II_2`
- **公式正解**：`{'M': '8', 'NO': '44', 'P': '3', 'QR': '28', 'STUV': '1016', 'W': '2', 'X': '6'}`
- **重要論点**：
  - 幾何学的対称性をもつ2つの正方形の面積公式の立式
  - 複2次関数（t^2 の2次式）の平方完成と最小値の評価
  - 2次不等式の解法とパラメータの変域制約（0 < t < 2）の連立

**【題目大意】**
対称な2つの正方形 $ABCD$ と $PQRS$（頂点座標がパラメータ $t$ で与えられる、$0 < t < 2$）の面積 $S_1, S_2$ について、$S_1 + S_2$ の最小値および $S_1 < S_2$ となる $t$ の範囲を求める。

**【公式正解】**
- $\text{M} = 8$ ($S_1 = 8t^2$)
- $\text{NO} = 44$ ($S_2 = 4(t^2 - 4)^2$)
- $\text{P} = 3, \text{QR} = 28$ ($t = \sqrt{3}$ のとき最小値 28)
- $\text{STUV} = 1016$ ($t^4 - 10t^2 + 16 > 0$)
- $\text{W} = 2$ ($t^2 < 2$ または $8 < t^2$、選択肢 $\textcircled{2}$)
- $\text{X} = 6$ ($0 < t < \sqrt{2}$、選択肢 $\textcircled{6}$)

**【詳細推導・解答プロセス】**
**(1) 各正方形の面積の立式**
正方形 $ABCD$ の頂点は $A(2t, 0), B(0, 2t), C(-2t, 0), D(0, -2t)$ である。
対角線 $AC, BD$ はそれぞれ座標軸上にあり、長さは $4t$ で直交している。
したがって、ひし形の面積公式（あるいは1辺の長さ $\sqrt{(2t)^2 + (2t)^2} = 2\sqrt{2}t$ の2乗）より：
$$S_1 = \frac{1}{2} \times 4t \times 4t = 8t^2$$
よって、$\mathbf{M = 8}$ である。

正方形 $PQRS$ の各辺は座標軸に平行であり、頂点は $P(4 - t^2, 4 - t^2)$, $Q(-4 + t^2, 4 - t^2)$ である。
1辺の長さは：
$$(4 - t^2) - (-4 + t^2) = 8 - 2t^2 = 2(4 - t^2)$$
したがって、その面積 $S_2$ は：
$$S_2 = [2(4 - t^2)]^2 = 4(4 - t^2)^2 = 4(t^2 - 4)^2$$
よって、$\text{N} = 4, \text{O} = 4$ より $\mathbf{NO = 44}$ である。

**(2) $S_1 + S_2$ の最小値**
$$S_1 + S_2 = 8t^2 + 4(t^4 - 8t^2 + 16) = 4t^4 - 24t^2 + 64$$
$X = t^2$ とおくと、$0 < t < 2$ より $0 < X < 4$ である。
$$S_1 + S_2 = 4(X^2 - 6X) + 64 = 4(X - 3)^2 - 36 + 64 = 4(X - 3)^2 + 28$$
$X = 3$（すなわち $t^2 = 3$）は $0 < X < 4$ を満たす。
したがって、$t = \sqrt{3}$ のとき、$S_1 + S_2$ は最小値 $28$ をとる。
よって、$\mathbf{P = 3}, \mathbf{QR = 28}$ である。

**(3) $S_1 < S_2$ となる $t$ の範囲**
$$8t^2 < 4(t^2 - 4)^2 \iff 2t^2 < t^4 - 8t^2 + 16 \iff t^4 - 10t^2 + 16 > 0$$
したがって、$\text{ST} = 10, \text{UV} = 16$ より $\mathbf{STUV = 1016}$ である。

この不等式を $t^2$ について因数分解すると：
$$(t^2 - 2)(t^2 - 8) > 0$$
これより $t^2 < 2$ または $8 < t^2$ を得る。これは選択肢 $\textcircled{2}$ に対応する。
よって、$\mathbf{W = 2}$ である。

ここで、$0 < t < 2$ より $0 < t^2 < 4$ であるから、$8 < t^2$ は不適である。
したがって：
$$0 < t^2 < 2 \implies 0 < t < \sqrt{2}$$
これは選択肢 $\textcircled{6}$ に対応する。
よって、$\mathbf{X = 6}$ である。

**【考査考点】**
座標平面における図形の面積計算、置換による高次式の2次式化と平方完成、2次不等式の因数分解と定義域による絞り込み。

## 大問III 問1：不定方程式 x^2 - y^2 = n の具体的整数解
- **問題番号**：`math-q-III_1`
- **公式正解**：`{'AB': '31', 'CD': '30', 'EF': '54'}`
- **重要論点**：
  - 因数分解 (x + y)(x - y) = n による約数の組への帰着
  - x, y が非負整数であることによる大小関係とパリティ（偶奇性）の制約
  - n = 8 および n = 9 における解の完全網羅

**【題目大意】**
正の整数 $n$、負でない整数 $x, y$ についての方程式 $x^2 - y^2 = n$ $\textcircled{1}$ について、$n = 8$ および $n = 9$ のときの整数解 $(x, y)$ を求める。

**【公式正解】**
- $\text{AB} = 31$ ($n = 8$ のとき $(x, y) = (3, 1)$)
- $\text{CD} = 30, \text{EF} = 54$ ($n = 9$ のとき $(x, y) = (3, 0), (5, 4)$)

**【詳細推導・解答プロセス】**
$\textcircled{1}$ 式を因数分解すると：
$$(x + y)(x - y) = n \quad \textcircled{2}$$
$x, y$ は負でない整数であるから、$x + y \geq x - y$ であり、$(x + y) + (x - y) = 2x$（偶数）より、$x + y$ と $x - y$ は同じ偶奇（ともに偶数またはともに奇数）をもつ。

**(1) $n = 8$ のとき**
積が 8 となる正の約数の組は $(8, 1)$ と $(4, 2)$ である。
- $(x + y, x - y) = (8, 1)$ は偶奇が異なるため不適。
- $(x + y, x - y) = (4, 2)$ はともに偶数であり適する。
連立方程式を解くと：
$$2x = 4 + 2 = 6 \implies x = 3$$
$$2y = 4 - 2 = 2 \implies y = 1$$
したがって、解は $(x, y) = (3, 1)$ である。
よって、$\mathbf{AB = 31}$ である。

**(2) $n = 9$ のとき**
積が 9 となる約数の組は $(9, 1)$ と $(3, 3)$ である（ともに奇数の組）。
- $(x + y, x - y) = (3, 3)$ のとき：
  $$2x = 6 \implies x = 3, \quad 2y = 0 \implies y = 0$$
  これより $(x, y) = (3, 0)$。
- $(x + y, x - y) = (9, 1)$ のとき：
  $$2x = 10 \implies x = 5, \quad 2y = 8 \implies y = 4$$
  これより $(x, y) = (5, 4)$。
問題文の条件 $\text{C} < \text{E}$（$x$ 座標が小さい順）より：
$(x, y) = (3, 0), (5, 4)$ である。
よって、$\text{CD} = 30, \text{EF} = 54$ である。

**【考査考点】**
平方の差の因数分解、整数の約数分解、和と差の偶奇性の一致条件を利用した絞り込み。

## 大問III 問2：不定方程式 x^2 - y^2 = n の解の存在の必要十分条件の証明
- **問題番号**：`math-q-III_2`
- **公式正解**：`{'GH': '74', 'IJ': '88', 'KLM': '211', 'NO': '21', 'PQR': '211'}`
- **重要論点**：
  - 整数の平方剰余（mod 4）による必要条件の証明
  - x, y の偶奇分類に基づく n の性質（4の倍数または奇数）の導出
  - 具体的な解の構成による十分条件の証明

**【題目大意】**
方程式 $x^2 - y^2 = n$ が負でない整数解 $(x, y)$ をもつための必要十分条件が「$n$ が 4 の倍数、または奇数である」ことの証明の空欄を補充する。

**【公式正解】**
- $\text{GH} = 74$ (G: 偶数[選択肢7], H: 4[選択肢4])
- $\text{IJ} = 88$ (I: 奇数[選択肢8], J: 奇数[選択肢8])
- $\text{KLM} = 211$ (K: 2[選択肢2], L: 1[選択肢1], M: 1[選択肢1])
- $\text{NO} = 21$ (N: 2[選択肢2], O: 1[選択肢1])
- $\text{PQR} = 211$ (P: 2[選択肢2], Q: 1[選択肢1], R: 1[選択肢1])

**【詳細推導・解答プロセス】**
**(1) 必要性の証明（前半）**
$(x, y)$ が $x^2 - y^2 = n \iff (x + y)(x - y) = n$ $\textcircled{2}$ を満たすとする。
- $x, y$ がともに偶数、またはともに奇数であるとき：
  $x + y$ および $x - y$ はともに**偶数**（選択肢 $\textcircled{7}$）である。
  よって、$\textcircled{2}$ より $n$ は $2 \times 2 = \mathbf{4}$ の倍数（選択肢 $\textcircled{4}$）となる。
  よって、$\text{G} = 7, \text{H} = 4$ より $\mathbf{GH = 74}$ である。
- 次に、$x, y$ の一方が偶数で他方が奇数であるとき：
  $x + y$ および $x - y$ はともに**奇数**（選択肢 $\textcircled{8}$）である。
  奇数どうしの積であるから、$n$ は**奇数**（選択肢 $\textcircled{8}$）である。
  よって、$\text{I} = 8, \text{J} = 8$ より $\mathbf{IJ = 88}$ である。
したがって、「$n$ が 4 の倍数か、または奇数である」は必要条件である。

**(2) 十分性の証明（後半）**
逆に、$n$ が条件 $\textcircled{3}$ を満たすとする。
- $n$ が 4 の倍数であれば、$n = 4k$（$k$ は正の整数）と表される。
  そこで、$x + y = 2k$（選択肢 $\textcircled{2}$）、$x - y = 2$ とおくと：
  $$2x = 2k + 2 \implies x = k + 1 \quad (\text{L} = 1)$$
  $$2y = 2k - 2 \implies y = k - 1 \quad (\text{M} = 1)$$
  $(x, y) = (k + 1, k - 1)$ となり、$k \geq 1$ よりこれらは負でない整数解となる。
  よって、$\text{K} = 2, \text{L} = 1, \text{M} = 1$ より $\mathbf{KLM = 211}$ である。
- また、$n$ が奇数であれば、$n = 2\ell + 1$（$\ell$ は負でない整数、$\text{N} = 2, \text{O} = 1$）と表される。
  よって、$\mathbf{NO = 21}$ である。
  そこで、$x + y = 2\ell + 1$（$\text{P} = 2, \text{Q} = 1$）、$x - y = 1$ とおくと：
  $$2x = 2\ell + 2 \implies x = \ell + 1 \quad (\text{R} = 1)$$
  $$2y = 2\ell \implies y = \ell$$
  $(x, y) = (\ell + 1, \ell)$ となり、$\ell \geq 0$ よりこれらは負でない整数解となる。
  よって、$\text{P} = 2, \text{Q} = 1, \text{R} = 1$ より $\mathbf{PQR = 211}$ である。

**【考査考点】**
整数論における剰余類（mod 4）、必要十分条件の論理的証明手順、パラメータを用いた具体的整理解の構成法。

## 大問IV 問1：ひし形の内接円の幾何的性質と半径の変域
- **問題番号**：`math-q-IV_1`
- **公式正解**：`{'A': '4', 'B': '8', 'C': '1'}`
- **重要論点**：
  - ひし形の対角線の直交性と直角三角形における三角比の定義
  - 内接円の接線と半径の垂直関係（OK ⊥ AB）の利用
  - 三角関数の基本不等式による内接円半径 r の最大値の導出

**【題目大意】**
1辺の長さが $a$ のひし形 $ABCD$ の内接円 $O$（半径 $r$）について、対角線の交点 $O$ から頂点 $B$ への長さ $OB$、半径 $OK$ を $\theta = \angle ABO$ で表し、$r$ のとる値の範囲を求める。

**【公式正解】**
- $\text{A} = 4$ ($OB = a\cos\theta$、選択肢 $\textcircled{4}$)
- $\text{B} = 8$ ($OK = a\sin\theta\cos\theta$、選択肢 $\textcircled{8}$)
- $\text{C} = 1$ ($0 < r \leq \frac{a}{2}$、選択肢 $\textcircled{1}$)

**【詳細推導・解答プロセス】**
ひし形の対角線 $AC, BD$ は互いに中点で直交し、交点を原点 $O$ とする。
直角三角形 $ABO$ において、$\angle AOB = 90^\circ$、$\angle ABO = \theta$、斜辺 $AB = a$ である。
したがって：
$$OB = AB \cos\theta = a\cos\theta$$
これは選択肢 $\textcircled{4}$ であるから、$\mathbf{A = 4}$ である。

円 $O$ は辺 $AB$ に点 $K$ で接しているため、$OK \perp AB$ である。
直角三角形 $BKO$ において、$\angle BKO = 90^\circ$、$\angle KBO = \theta$ であるから：
$$OK = OB \sin\theta = (a\cos\theta)\sin\theta = a\sin\theta\cos\theta$$
これは選択肢 $\textcircled{8}$ であるから、$\mathbf{B = 8}$ である。

内接円の半径は $r = OK = a\sin\theta\cos\theta$ である。
不等式 $(\cos\theta - \sin\theta)^2 \geq 0$ を展開すると：
$$\cos^2\theta - 2\sin\theta\cos\theta + \sin^2\theta \geq 0$$
$$1 - 2\sin\theta\cos\theta \geq 0 \implies \sin\theta\cos\theta \leq \frac{1}{2}$$
両辺に $a > 0$ を掛けると：
$$r = a\sin\theta\cos\theta \leq \frac{a}{2}$$
また、$0 < \theta < \frac{\pi}{2}$ より $\sin\theta\cos\theta > 0$ であるから、$r > 0$ である。
したがって、$r$ のとる値の範囲は：
$$0 < r \leq \frac{a}{2}$$
これは選択肢 $\textcircled{1}$ であるから、$\mathbf{C = 1}$ である。

**【考査考点】**
ひし形の対称性と対角線の直交性、直角三角形における三角比の定義、接線の幾何学的性質、相加相乗平均不等式または2倍角公式による最大値評価。

## 大問IV 問2：ひし形と内接円の面積差の最大化
- **問題番号**：`math-q-IV_2`
- **公式正解**：`{'D': '0', 'E': '5', 'F': '8'}`
- **重要論点**：
  - ひし形の面積の内接円半径 r による表示
  - 2次関数の平方完成による極大値・最大値の導出
  - 変域条件（0 < r <= a/2）と最大値をとる r の整合性検証

**【題目大意】**
ひし形 $ABCD$ から内接円 $O$ を除いた部分の面積 $S$ を $r$ で表し、$S$ が最大となるときの $r$ の値と、その最大値を求める。

**【公式正解】**
- $\text{D} = 0$ ($S = 2ar - \pi r^2$、選択肢 $\textcircled{0}$)
- $\text{E} = 5$ ($r = \frac{a}{\pi}$、選択肢 $\textcircled{5}$)
- $\text{F} = 8$ (最大値 $\frac{a^2}{\pi}$、選択肢 $\textcircled{8}$)

**【詳細推導・解答プロセス】**
ひし形 $ABCD$ の面積 $S_{\text{rhombus}}$ は、4つの合同な直角三角形 $ABO$ の面積の和である：
$$S_{\text{rhombus}} = 4 \times \left(\frac{1}{2} OA \cdot OB\right) = 2(a\sin\theta)(a\cos\theta) = 2a(a\sin\theta\cos\theta) = 2ar$$
（あるいは、周囲の長さ $4a$ に内接円の半径 $r$ を掛けて 2 で割る公式 $\frac{1}{2} \times 4a \times r = 2ar$ からも直ちに得られる）
内接円の面積は $\pi r^2$ であるから、除いた部分の面積 $S$ は：
$$S = 2ar - \pi r^2$$
これは選択肢 $\textcircled{0}$ であるから、$\mathbf{D = 0}$ である。

面積 $S(r)$ は $r$ について上に凸の 2 次関数である。平方完成すると：
$$S(r) = -\pi\left(r^2 - \frac{2a}{\pi}r\right) = -\pi\left(r - \frac{a}{\pi}\right)^2 + \pi\left(\frac{a}{\pi}\right)^2 = -\pi\left(r - \frac{a}{\pi}\right)^2 + \frac{a^2}{\pi}$$
したがって、$S$ を最大にする $r$ の値は：
$$r = \frac{a}{\pi}$$
これは選択肢 $\textcircled{5}$ であるから、$\mathbf{E = 5}$ である。

ここで、$\pi > 2$ であるから：
$$0 < \frac{a}{\pi} < \frac{a}{2}$$
となり、前問で求めた $r$ の定義域 $0 < r \leq \frac{a}{2}$（条件 $\textcircled{1}$）を確かに満たしている。
したがって、$r = \frac{a}{\pi}$ のとき、面積 $S$ は最大値：
$$S_{\max} = \frac{a^2}{\pi}$$
をとる。これは選択肢 $\textcircled{8}$ であるから、$\mathbf{F = 8}$ である。

**【考査考点】**
内接円をもつ多角形の面積公式、幾何モデルから2次関数への定式化、定義域の制約を考慮した2次関数の最大値決定。
