## 第I問 問1：2次関数と水平直線の交点間距離・頂点と係数決定

**【考査考点】**：放物線の軸と水平直線との交点の対称性, 頂点標準形 $y = a(x-p)^2 + q$ による連立方程式, 通過点と頂点の範囲制約による係数の決定

### 【第I問 問1】詳細解答と解説

#### (1) 放物線の頂点と直線の交点間距離
放物線 $C: y = ax^2 + bx + c$（$a \neq 0$）の頂点の座標を $(p, q)$ とおくと、$C$ の方程式は標準形を用いて
$$y = a(x - p)^2 + q$$
と表される。放物線は軸 $x = p$ に関して線対称である。

直線 $y = 1$ と $C$ との 2 つの交点の $x$ 座標は、$a(x - p)^2 + q = 1$ の解である。
交点間の距離が 4 であるため、軸 $x = p$ から各交点までの距離はその半分の 2 である。
交点のひとつをとり、その $x$ 座標を $\alpha$ とおくと：
$$|\alpha - p| = \mathbf{2}$$
よって、$\mathbf{A = 2}$。

この交点の座標 $(\alpha, 1)$ を放物線の方程式に代入すると：
$$a(\alpha - p)^2 + q = 1 \implies a(2)^2 + q = 1 \implies \mathbf{4a + q = 1}$$
よって、$\mathbf{B = 4, C = 1}$（解答番号 $\mathbf{BC = 41}$）。

同様に、直線 $y = 3$ と $C$ との交点間の距離は 6 であるから、軸からの距離は $6 / 2 = 3$ である。
交点の座標を代入すると：
$$a(3)^2 + q = 3 \implies \mathbf{9a + q = 3}$$
よって、$\mathbf{D = 9, E = 3}$（解答番号 $\mathbf{DE = 93}$）。

これら 2 式を連立して解く：
$$\begin{cases} 4a + q = 1 \\ 9a + q = 3 \end{cases}$$
下の式から上の式を引くと：
$$5a = 2 \implies a = \frac{\mathbf{2}}{\mathbf{5}}$$
よって、$\mathbf{F = 2, G = 5}$（解答番号 $\mathbf{FG = 25}$）。

これを上の式に代入すると：
$$4 \times \frac{2}{5} + q = 1 \implies q = 1 - \frac{8}{5} = -\frac{\mathbf{3}}{\mathbf{5}}$$
よって、$q = -\frac{H}{I}$ より $\mathbf{H = 3, I = 5}$（解答番号 $\mathbf{HI = 35}$）。

#### (2) 点 $\left(2, -\frac{1}{5}\right)$ を通る条件と係数 $b, c$ の決定
$a = \frac{2}{5}, q = -\frac{3}{5}$ を放物線の式に代入すると：
$$y = \frac{2}{5}(x - p)^2 - \frac{3}{5}$$
このグラフが点 $\left(2, -\frac{1}{5}\right)$ を通るから：
$$-\frac{1}{5} = \frac{2}{5}(2 - p)^2 - \frac{3}{5}$$
両辺に 5 を掛けると：
$$-1 = 2(2 - p)^2 - 3 \implies 2(2 - p)^2 = 2 \implies (2 - p)^2 = 1$$
$$2 - p = \pm 1 \implies p = 2 \mp 1 \implies p = 1 \text{ または } 3$$
条件「頂点の $x$ 座標 $p$ が 2 より小さい（$p < 2$）」より、$\mathbf{p = 1}$ に決定される。

したがって、2次関数を展開すると：
$$y = \frac{2}{5}(x - 1)^2 - \frac{3}{5} = \frac{2}{5}(x^2 - 2x + 1) - \frac{3}{5} = \frac{2}{5}x^2 - \frac{4}{5}x + \frac{2}{5} - \frac{3}{5} = \frac{2}{5}x^2 - \frac{4}{5}x - \frac{1}{5}$$
これをもとの式 $y = ax^2 + bx + c$ と比較して：
$$b = -\frac{\mathbf{4}}{\mathbf{5}}, \quad c = -\frac{\mathbf{1}}{\mathbf{5}}$$
よって、$\mathbf{J = 4, K = 5}$（解答番号 $\mathbf{JK = 45}$）、$\mathbf{L = 1, M = 5}$（解答番号 $\mathbf{LM = 15}$）。

**【解法テクニック・易錯点】**
- 水平直線との交点距離が与えられた場合、一般形ではなく軸対称性を活かして $|x - p| = d/2$ と置くことで、計算量を劇的に減らすことができます。

## 第I問 問2：サイコロの出目の「つながり」と確率漸化・終了確率

**【考査考点】**：整数が「つながっている」（差の絶対値が 1 以下）の定義, 端の目（1, 6）と内側の目（2, 3, 4, 5）の推移確率の対称性, 試行終了と継続の余事象の確率計算

### 【第I問 問2】詳細解答と解説

#### 問題の定義と設定
2つの整数 $m$ と $n$ が「つながっている」とは、$n \in \{m-1, m, m+1\}$ であること。
サイコロを繰り返し投げ、直前の目と「つながっていない」目が出た瞬間に試行は終了する。
サイコロの各目 $1, 2, 3, 4, 5, 6$ に対し、つながっている目の個数：
- $m = 1$: $\{1, 2\}$（2個）
- $m = 2$: $\{1, 2, 3\}$（3個）
- $m = 3$: $\{2, 3, 4\}$（3個）
- $m = 4$: $\{3, 4, 5\}$（3個）
- $m = 5$: $\{4, 5, 6\}$（3個）
- $m = 6$: $\{5, 6\}$（2個）

#### (1) 2回目の操作を終えた時点で試行が終了していない確率
1回目に出る目 $X_1$ はどの目も等確率 $\frac{1}{6}$ である。
- $X_1 \in \{1, 6\}$（2通り、確率 $\frac{2}{6}$）：2回目に進む目（つながっている目）は各2個なので、継続確率は $\frac{2}{6}$。
- $X_1 \in \{2, 3, 4, 5\}$（4通り、確率 $\frac{4}{6}$）：2回目に進む目は各3個なので、継続確率は $\frac{3}{6}$。
したがって、2回目の操作を終えた時点で終了していない確率は：
$$P(\text{2回目終了せず}) = \frac{2}{6} \times \frac{2}{6} + \frac{4}{6} \times \frac{3}{6} = \frac{4 + 12}{36} = \frac{16}{36} = \frac{\mathbf{4}}{\mathbf{9}}$$
よって、$\mathbf{N = 4, O = 9}$（解答番号 $\mathbf{NO = 49}$）。

#### (2) 2回目の操作で試行が終了する確率
2回目の操作で終了する事象は、「2回目で終了していない」事象の余事象である：
$$P(\text{2回目で終了}) = 1 - \frac{4}{9} = \frac{\mathbf{5}}{\mathbf{9}}$$
よって、$\mathbf{P = 5, Q = 9}$（解答番号 $\mathbf{PQ = 59}$）。

#### (3) 3回目の操作を終えた時点で試行が終了していない確率
2回目の目 $X_2$ の値ごとの確率（2回目で終了していない条件）を求める。
対称性より $P(X_k = 1) = P(X_k = 6)$, $P(X_k = 2) = P(X_k = 5)$, $P(X_k = 3) = P(X_k = 4)$ である。
- $X_2 = 1$ となるのは、1回目が 1 または 2 のとき：
  $$P(X_2 = 1) = \frac{1}{6} \times \frac{1}{6} + \frac{1}{6} \times \frac{1}{6} = \frac{2}{36}$$
- $X_2 = 2$ となるのは、1回目が 1, 2, 3 のとき：
  $$P(X_2 = 2) = \frac{1}{6} \times \frac{1}{6} \times 3 = \frac{3}{36}$$
- $X_2 = 3$ となるのは、1回目が 2, 3, 4 のとき：
  $$P(X_2 = 3) = \frac{1}{6} \times \frac{1}{6} \times 3 = \frac{3}{36}$$

3回目の操作でつながる目が出る確率は：
- $X_2 \in \{1, 6\}$ のとき各 $\frac{2}{6}$（2通り）
- $X_2 \in \{2, 3, 4, 5\}$ のとき各 $\frac{3}{6}$（4通り）
したがって、3回目終了時点での継続確率は：
$$P(\text{3回目終了せず}) = 2 \times \left[ P(X_2 = 1) \times \frac{2}{6} + P(X_2 = 2) \times \frac{3}{6} + P(X_2 = 3) \times \frac{3}{6} \right]$$
$$= 2 \times \left[ \frac{2}{36} \times \frac{2}{6} + \frac{3}{36} \times \frac{3}{6} + \frac{3}{36} \times \frac{3}{6} \right] = 2 \times \frac{4 + 9 + 9}{216} = 2 \times \frac{22}{216} = \frac{44}{216} = \frac{\mathbf{11}}{\mathbf{54}}$$
選択肢一覧より $\frac{11}{54}$ は $\textcircled{2}$ である。よって、$\mathbf{R = 2}$。

#### (4) 3回以下の操作で試行が終了する確率
「3回以下の操作で終了する」事象は、「3回目の操作を終えた時点で終了していない」事象の余事象である：
$$P(\text{3回以下で終了}) = 1 - P(\text{3回目終了せず}) = 1 - \frac{11}{54} = \frac{\mathbf{43}}{\mathbf{54}}$$
選択肢一覧より $\frac{43}{54}$ は $\textcircled{7}$ である。よって、$\mathbf{S = 7}$。

#### (5) 3回目の操作で試行が終了する確率
「3回目の操作で終了する」とは、「2回目までは継続し、3回目の目で初めてつながりから外れる」事象である：
$$P(\text{3回目で終了}) = P(\text{2回目終了せず}) - P(\text{3回目終了せず}) = \frac{4}{9} - \frac{11}{54} = \frac{24 - 11}{54} = \frac{\mathbf{13}}{\mathbf{54}}$$
選択肢一覧より $\frac{13}{54}$ は $\textcircled{3}$ である。よって、$\mathbf{T = 3}$。

**【解法テクニック・易錯点】**
- 「3回目で終了」と「3回以下で終了」という日本語表現の違い（特定回数 vs 累積確率）を余事象の関係 $P(\le 3) = 1 - P(>3)$ および $P(=3) = P(>2) - P(>3)$ から正確に整理することが重要です。

## 第II問 問1：カードの枚数と不等式・一次不定方程式の整数解

**【考査考点】**：連立不等式による変数の範囲の絞り込み, 文字の消去法（$y$ を消去して $x$ の不等式を導出）, 整数条件（偶奇性・倍数判定）による一意決定

### 【第II問 問1】詳細解答と解説

#### (1) 不等式と等式の立式
数字 3 が書いてある青いカードの枚数を $x$、数字 2 が書いてある赤いカードの枚数を $y$ とする（$x, y$ は正の整数）。
「赤いカードの枚数は青いカードより多く、青いカードの 2 倍より少ない」より：
$$x < y < \mathbf{2}x$$
よって、$\mathbf{A = 2}$。

「全部のカードに書いてある数の和は 70」より：
$$\mathbf{3}x + \mathbf{2}y = 70$$
よって、$\mathbf{B = 3, C = 2}$（解答番号 $\mathbf{BC = 32}$）。

#### (2) $y$ の消去と $x$ の範囲の導出
$3x + 2y = 70$ より、$2y = 70 - 3x$ である。
不等式 $x < y < 2x$ の全体に 2 を掛けると：
$$2x < 2y < 4x$$
$2y = 70 - 3x$ を代入すると：
$$2x < 70 - 3x < 4x$$
各辺に $3x$ を加えると：
$$\mathbf{5}x < 70 < \mathbf{7}x$$
よって、$\mathbf{D = 5, E = 7}$（解答番号 $\mathbf{DE = 57}$）。

この連立不等式を解く：
1. $5x < 70 \implies x < 14$
2. $70 < 7x \implies x > 10$
したがって：
$$\mathbf{10} < x < \mathbf{14}$$
よって、$\mathbf{FG = 10, HI = 14}$（解答番号 $\mathbf{FGHI = 1014}$）。

#### (3) 整数条件による $x, y$ の決定
等式 $3x + 2y = 70$ より：
$$2y = 70 - 3x$$
左辺 $2y$ は偶数であり、右辺の 70 も偶数であるから、$3x$ も偶数でなければならない。
3 は奇数であるから、$x$ は **2 の倍数（偶数）** である。
よって、$\mathbf{J = 2}$。

$10 < x < 14$ かつ $x$ が 2 の倍数である整数は、ただ一つ：
$$x = \mathbf{12}$$
よって、$\mathbf{KL = 12}$。

これを $2y = 70 - 3x$ に代入すると：
$$2y = 70 - 3(12) = 70 - 36 = 34 \implies y = \mathbf{17}$$
よって、$\mathbf{MN = 17}$。
したがって、青いカードは 12 枚、赤いカードは 17 枚である。

**【解法テクニック・易錯点】**
- 不等式で範囲を絞り込み、偶奇性（mod 2）で候補を 1 つに特定する、EJU 整数・一次不定方程式の王道解法です。

## 第II問 問2：2次方程式の判別式と解の差の整数条件

**【考査考点】**：2次方程式の判別式 $D/4 > 0$ による実数解条件, 解と係数の関係および解の差の公式 $\alpha - \beta = \frac{\sqrt{D}}{a}$, 2次関数の平方完成と値域における整数値の限定

### 【第II問 問2】詳細解答と解説

#### (1) 異なる2つの実数解をもつ条件
$x$ の2次方程式 $x^2 + 2ax + 4a^2 - 10a + 7 = 0$ が異なる 2 つの実数解をもつための条件は、判別式 $D > 0$ である：
$$\frac{D}{4} = a^2 - 1 \cdot (4a^2 - 10a + 7) = -3a^2 + 10a - 7 > 0$$
両辺に $-1$ を掛けると：
$$3a^2 - 10a + 7 < 0 \implies (3a - 7)(a - 1) < 0$$
したがって、$a$ の値の範囲は：
$$\mathbf{1} < a < \frac{\mathbf{7}}{\mathbf{3}}$$
よって、$\mathbf{O = 1, P = 7, Q = 3}$（解答番号 $\mathbf{PQ = 73}$）。

#### (2) 解の差 $\alpha - \beta$ の導出
解の公式より、2つの解 $\alpha > \beta$ は：
$$x = -a \pm \sqrt{-3a^2 + 10a - 7}$$
したがって、解の差 $\alpha - \beta$ は：
$$\alpha - \beta = \mathbf{2} \sqrt{-\mathbf{3}a^2 + 10a - \mathbf{7}}$$
よって、$\mathbf{R = 2, S = 3, T = 7}$（解答番号 $\mathbf{RST = 237}$）。

#### (3) 根号内の最大値の計算
$g(a) = -3a^2 + 10a - 7$ とおく。平方完成すると：
$$g(a) = -3\left(a^2 - \frac{10}{3}a\right) - 7 = -3\left(a - \frac{5}{3}\right)^2 + 3 \times \frac{25}{9} - 7$$
$$g(a) = -3\left(a - \frac{5}{3}\right)^2 + \frac{25}{3} - \frac{21}{3} = -3\left(a - \frac{5}{3}\right)^2 + \frac{\mathbf{4}}{\mathbf{3}}$$
頂点 $a = \frac{5}{3}$ は開区間 $\left(1, \frac{7}{3}\right)$ の内部にあるから、最大値は：
$$g\left(\frac{5}{3}\right) = \frac{\mathbf{4}}{\mathbf{3}}$$
よって、$\mathbf{U = 4, V = 3}$（解答番号 $\mathbf{UV = 43}$）。

#### (4) $\alpha - \beta$ が2の倍数となる $a$ の決定
$\alpha - \beta = 2\sqrt{g(a)}$ であり、これが整数かつ「2 の倍数」であるためには：
$$\sqrt{g(a)} \text{ が正の整数でなければならない}$$
$1 < a < \frac{7}{3}$ のとき、$g(a)$ のとり得る値の範囲は $0 < g(a) \le \frac{4}{3}$ である。
この範囲に含まれる正の整数は $1$ のみである！
したがって：
$$\sqrt{g(a)} = 1 \iff -3a^2 + 10a - 7 = \mathbf{1}$$
よって、$\mathbf{W = 1}$。

この2次方程式を解く：
$$3a^2 - 10a + 8 = 0 \implies (3a - 4)(a - 2) = 0$$
$$a = \frac{\mathbf{4}}{\mathbf{3}}, \quad \mathbf{2}$$
どちらの値も $1 < a < \frac{7}{3}$ を満たしている。
よって、$\mathbf{XY = 43, Z = 2}$。

**【解法テクニック・易錯点】**
- $\alpha - \beta = 2\sqrt{g(a)}$ の係数にすでに 2 が掛かっているため、$\alpha - \beta$ が 2 の倍数になるには $\sqrt{g(a)}$ が整数でさえあれば十分です。範囲 $0 < g(a) \le 4/3$ から整数値が 1 しかあり得ないことを見抜くのが最大の決め手です。

## 第III問 [1]：3でも5でも割り切れない正の整数集合と15の剰余類

**【考査考点】**：除法の原理と剰余の範囲 $a = 15q + r, 0 \le r \le 14$, 周期性（法 15）による倍数除外とオイラーの $\phi(15) = 8$, 小さい順に並べた50番目の数の周期計算

### 【第III問 [1]】詳細解答と解説

#### (1) 15 で割った剰余と集合 $S$ の元の特徴付け
正の整数 $a$ を 15 で割った商を $q$、余りを $r$ とすると：
$$a = \mathbf{15}q + r, \quad \mathbf{0} \le r \le \mathbf{14}$$
よって、$\mathbf{AB = 15, C = 0, DE = 14}$。

集合 $S$ は「3 でも 5 でも割り切れない正の整数全体の集合」である。
$a = 15q + r$ において、15 は 3 の倍数かつ 5 の倍数であるから：
$$a \in S \iff r \text{ が 3 でも 5 でも割り切れない}$$
$0 \le r \le 14$ のうち：
- 3 の倍数：$0, 3, 6, 9, 12$（除外）
- 5 の倍数：$0, 5, 10$（除外）
残る余り $r$ は：
$$\{1, 2, 4, 7, 8, 11, 13, 14\}$$
これは選択肢 $\textcircled{3}$ に一致する。また、その個数は **8 個**である。
よって、$\mathbf{F = 3, G = 8}$。

#### (2) 小さい方から数えて 50 番目の整数
$S$ の要素は 15 を周期として 1 周期（長さ 15 の区間）あたりちょうど 8 個ずつ現れる。
50 番目の元を求めるため、$50$ を 8 で割ると：
$$50 = 8 \times 6 + 2$$
すなわち、$S$ の元は完全な 6 周期分（計 48 個）経過した後の、第 7 周期の第 2 番目の元である。
- 6 周期終了時の整数：$15 \times 6 = 90$
- 第 7 周期の余りのリスト：$1, \mathbf{2}, 4, 7, 8, 11, 13, 14$
第 2 番目の余りは 2 であるから、求める 50 番目の数は：
$$a_{50} = 90 + 2 = \mathbf{92}$$
よって、$\mathbf{HI = 92}$。

## 第III問 [2]：50以下の要素数計数と指定された和の剰余条件

**【考査考点】**：指定範囲内の要素数計数（周期部分と端数部分の和）, 和 $a+b$ の法 15 における剰余条件の立式, 相異なる元の組合せと絞り込みによる整数の決定

### 【第III問 [2]】詳細解答と解説

#### (3) $a \le 50$ を満たす $S$ の要素の個数 $n$
$45 = 15 \times 3$ であるから、$1 \le a \le 45$ にはちょうど 3 周期分の $S$ の元が含まれる：
$$3 \times 8 = \mathbf{24} \text{ 個}$$
よって、$\mathbf{JK = 24}$。

残る $46 \le a \le 50$ の整数を調べる：
- 46：$46 = 15 \times 3 + 1 \in S$
- 47：$47 = 15 \times 3 + 2 \in S$
- 48：3 の倍数（$\notin S$）
- 49：$49 = 15 \times 3 + 4 \in S$
- 50：5 の倍数（$\notin S$）
この区間に含まれる $S$ の元は $46, 47, 49$ の 3 個である。
したがって、$a \le 50$ を満たす個数 $n$ は：
$$n = 24 + 3 = \mathbf{27}$$
よって、$\mathbf{LM = 27}$。

#### (4) $30 \le a < b \le 45$ かつ $a+b \equiv 2 \pmod{15}$ となる組
$30 \le a < b \le 45$ に含まれる $S$ の元は、余り $r \in \{1, 2, 4, 7, 8, 11, 13, 14\}$ に 30 を足した数である：
$$\{31, 32, 34, 37, 38, 41, 43, 44\}$$
$a = 30 + r_a$, $b = 30 + r_b$（$r_a < r_b$）とすると：
$$a + b = 60 + (r_a + r_b) \equiv r_a + r_b \pmod{15}$$
したがって、$r_a + r_b \equiv 2 \pmod{15}$ となる組を探す。
$r_a < r_b$ より $r_a + r_b = 2$ または $17$ である。
- $r_a + r_b = 2$：相異なる元で満たすものはない（$1+1=2$ は $r_a < r_b$ に反する）。
- $r_a + r_b = 17$：余りのリストから和が 17 となるペアを探すと：
  $$4 + 13 = 17$$
  （他のペア $3+14, 8+9$ 等は 3 や 9 が $S$ の余りリストに含まれないため不適）
したがって、適するのは $r_a = 4, r_b = 13$ のみである：
$$a = 30 + 4 = \mathbf{34}, \quad b = 30 + 13 = \mathbf{43}$$
よって、$\mathbf{NO = 34, PQ = 43}$。

**【解法テクニック・易錯点】**
- 周期 15 による剰余の群構造とオイラー関数 $\phi(15) = 8$ を把握しておくことで、元の個数や順番の計算を誤りなく迅速に処理できます。

## 第IV問 [1]：長方形と内接半円・接線の性質と三角形の面積比

**【考査考点】**：円の外部の点から引いた2本の接線の長さの等質性 $PT = PB, DT = DC$, 三平方の定理による長方形の縦横比 $AB : BC = 1 : \sqrt{3}$ の決定, 共通の角や底辺をもつ三角形の面積比の計算

### 【第IV問 [1]】詳細解答と解説

#### (1) 長方形の各辺の比と面積比の算出
長方形 ABCD において、辺 AB を $1:3$ に内分する点を P とする。
したがって：
$$PB = \frac{\mathbf{3}}{\mathbf{4}} AB$$
よって、$\mathbf{AB = 34}$。

半円 O の直径は BC であり、長方形の角は直角であるから、直線 AB は点 B で半円に接し、直線 CD は点 C で半円に接している。
点 P から半円 O に引いた 2 本の接線は PB と PT であるから、接線の長さは等しい：
$$PT = PB = \frac{3}{4} AB$$
同様に、点 D から半円 O に引いた 2 本の接線は DC と DT であるから：
$$DT = DC = AB$$
したがって、線分 PD の長さは：
$$PD = PT + DT = \frac{3}{4} AB + AB = \frac{\mathbf{7}}{\mathbf{4}} AB$$
よって、$\mathbf{CD = 74}$。

P から辺 CD に下ろした垂線の足を H とすると、四角形 PBC H は長方形となり、$PH = BC$、$CH = PB = \frac{3}{4}AB$ である。
直角三角形 PHD において：
$$DH = CD - CH = AB - \frac{3}{4}AB = \frac{1}{4}AB$$
三平方の定理 $PD^2 = PH^2 + DH^2$ より：
$$\left(\frac{7}{4}AB\right)^2 = BC^2 + \left(\frac{1}{4}AB\right)^2$$
$$BC^2 = \left(\frac{49}{16} - \frac{1}{16}\right) AB^2 = \frac{48}{16} AB^2 = 3 AB^2 \implies BC = \sqrt{3} AB$$
したがって、縦と横の比は $AB : BC = 1 : \sqrt{3} = \sqrt{\mathbf{1}} : \sqrt{\mathbf{3}}$ である。
よって、$\mathbf{EF = 13}$。

BC の中点を M（半円の中心）とすると、$MC = \frac{1}{2} BC = \frac{\sqrt{3}}{2} AB$ である。
比 $PB : MC$ は：
$$PB : MC = \frac{3}{4}AB : \frac{\sqrt{3}}{2}AB = 3 : 2\sqrt{3} = \sqrt{\mathbf{3}} : \mathbf{2}$$
よって、$\mathbf{GH = 32}$。

点 T は半円周上の点であり、BC は直径であるから $\angle BTC = 90^\circ$ である。
また、対称性より $\triangle TBC$ の辺の比は $BT : CT = PB : MC = \sqrt{\mathbf{3}} : \mathbf{2}$ となる。
よって、$\mathbf{IJ = 32}$。

三角形の面積比：
1. $\frac{\triangle PBT}{\triangle MCT} = \frac{\mathbf{3}}{\mathbf{4}}$（よって、$\mathbf{KL = 34}$）
2. $\frac{\triangle MBT}{\triangle DCT} = \frac{\mathbf{3}}{\mathbf{4}}$（よって、$\mathbf{MN = 34}$）
これらを掛け合わせると、$\triangle MCT = \triangle MBT$（底辺 $BM = MC$ かつ高さ共通）であるから：
$$\frac{\triangle PBT}{\triangle DCT} = \frac{\triangle PBT}{\triangle MCT} \times \frac{\triangle MBT}{\triangle DCT} = \frac{3}{4} \times \frac{3}{4} = \frac{\mathbf{9}}{\mathbf{16}}$$
よって、$\mathbf{OPQ = 916}$。

## 第IV問 [2]：接線と直角三角形における三角比の計算

**【考査考点】**：直角三角形における正接 $\tan\theta$ の計算, 相互関係 $1 + \tan^2\theta = \frac{1}{\cos^2\theta}$ による余弦の計算, 角度の幾何的関係 $\angle DCT = 90^\circ - \theta$ による $\cos\angle DCT$ の導出

### 【第IV問 [2]】詳細解答と解説

#### (2) $\cos\angle DCT$ の値の算出
$\angle PBT = \theta$ とおく。
直角三角形の幾何的関係より：
$$\tan\theta = \frac{\sqrt{\mathbf{3}}}{\mathbf{2}}$$
よって、$\mathbf{RS = 32}$。

三角比の相互関係 $1 + \tan^2\theta = \frac{1}{\cos^2\theta}$ より：
$$\cos^2\theta = \frac{1}{1 + 3/4} = \frac{4}{7} \implies \cos\theta = \frac{2}{\sqrt{7}} = \frac{\mathbf{2}\sqrt{\mathbf{7}}}{\mathbf{7}}$$
よって、$\mathbf{T = 2, U = 7, V = 7}$（解答番号 $\mathbf{TUV = 277}$）。

角の和の幾何学的関係より、$\angle DCT = 90^\circ - \theta$ であるから：
$$\cos\angle DCT = \cos(90^\circ - \theta) = \sin\theta = \tan\theta \cdot \cos\theta = \frac{\sqrt{3}}{2} \times \frac{2}{\sqrt{7}} = \frac{\sqrt{3}}{\sqrt{7}} = \frac{\sqrt{\mathbf{21}}}{\mathbf{7}}$$
よって、$\mathbf{WX = 21, Y = 7}$（解答番号 $\mathbf{WXY = 217}$）。

**【解法テクニック・易錯点】**
- 円の外部の点からの接線長が等しいという基本性質（$PT=PB, DT=DC$）から $PD$ を表し、三平方の定理に持ち込むのが最大のブレークスルーです。
