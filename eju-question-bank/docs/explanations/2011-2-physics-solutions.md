## 物理 I-問1：鉛直運動における運動方程式と糸の張力

**【題目大意】**
質量 $0.50\text{ kg}$ の物体を糸でつるし，鉛直方向に動かした。
- 物体が等加速度 $2.8\text{ m/s}^2$ で上昇しているときの張力を $a$
- 物体が等速度 $1.4\text{ m/s}$ で下降しているときの張力を $b$
とするとき，$a, b$ の組み合わせとして最も適当なものを選ぶ（$g = 9.8\text{ m/s}^2$）。

**【公式正解】**
正解：$\textcircled{5}$（$a = 6.3\text{ N}, b = 4.9\text{ N}$）

**【詳細推導・解答プロセス】**
1. **上昇時の張力 $a$ の導出**：
鉛直上向きを正とする。物体には上向きに張力 $T_a$，下向きに重力 $mg$ が働く。
運動方程式より：
$$m a_{\text{up}} = T_a - mg \implies T_a = m(g + a_{\text{up}})$$
数値を代入する：
$$T_a = 0.50 \times (9.8 + 2.8) = 0.50 \times 12.6 = 6.3\text{ N}$$

2. **下降時の張力 $b$ の導出**：
物体は等速度で下降しているため，加速度は $a = 0$ である。
力のつり合いより：
$$T_b = mg = 0.50 \times 9.8 = 4.9\text{ N}$$

したがって，$a = 6.3\text{ N}, b = 4.9\text{ N}$ となり，選択肢 $\textcircled{5}$ が正解である。

**【考査考点】**
ニュートンの第2法則（運動方程式），等加速度運動と等速度運動における力のつり合いの区別。

## 物理 I-問2：速度-時間グラフから加速度-時間グラフへの変換

**【題目大意】**
$x$ 軸上を運動する小球の速度 $v(t)$ の時間変化を示すグラフから，加速度 $a(t)$ の時間変化を表す正しいグラフを選ぶ。

**【公式正解】**
正解：$\textcircled{3}$

**【詳細推導・解答プロセス】**
加速度 $a(t)$ は速度 $v(t)$ の時間微分であり，$v-t$ グラフにおける接線の傾きに等しい：
$$a(t) = \frac{dv}{dt}$$
- $v(t)$ が増加している区間では傾きが正（$a > 0$）
- $v(t)$ が極大値・極小値をとる瞬間では傾きが $0$（$a = 0$）
- $v(t)$ が減少している区間では傾きが負（$a < 0$）
グラフの傾きの推移を照合すると，選択肢 $\textcircled{3}$ の波形と完全に一致する。

**【考査考点】**
運動学の基礎，微分による速度から加速度への変換，$v-t$ グラフの傾きの幾何学的解釈。

## 物理 I-問3：はしごのつり合いと滑り出しの限界質量条件

**【題目大意】**
質量 $M$ の一様なはしごが，水平な床と $45^\circ$ の角をなして滑らかな壁に立てかけられている。床との静止摩擦係数は $\mu = \frac{2}{3}$ である。
質量 $m$ の人がはしごの上端に立ったとき，はしごが滑らないための質量の上限 $x$ を求める。

**【公式正解】**
正解：$\textcircled{4}$（$x = \frac{1}{2}M$）

**【詳細推導・解答プロセス】**
はしごの長さを $L$ とする。
1. **鉛直方向のつり合い**：
床からの垂直抗力を $N$ とすると：
$$N = Mg + mg = (M + m)g$$
床の最大静止摩擦力は：
$$F_{\text{max}} = \mu N = \frac{2}{3}(M + m)g$$

2. **水平方向のつり合い**：
滑らかな壁からの抗力を $R$ とすると，静止摩擦力を $F$ として：
$$F = R$$

3. **下端の接地点周りのモーメントのつり合い**：
反時計回りを正とすると：
$$R \cdot L \sin 45^\circ - Mg \cdot \frac{L}{2} \cos 45^\circ - mg \cdot L \cos 45^\circ = 0$$
$\sin 45^\circ = \cos 45^\circ = \frac{\sqrt{2}}{2}$ より両辺を $L \cos 45^\circ$ で割ると：
$$R = \frac{1}{2}Mg + mg = \left(\frac{1}{2}M + m\right)g$$

4. **滑らないための条件**：
はしごが滑らないためには $F = R \le F_{\text{max}}$ が必要十分である：
$$\left(\frac{1}{2}M + m\right)g \le \frac{2}{3}(M + m)g$$
両辺を $g$ で割り整理する：
$$\frac{1}{2}M + m \le \frac{2}{3}M + \frac{2}{3}m$$
$$m - \frac{2}{3}m \le \frac{2}{3}M - \frac{1}{2}M$$
$$\frac{1}{3}m \le \frac{1}{6}M \implies m \le \frac{1}{2}M$$
したがって，$m < \frac{1}{2}M$ であれば滑らず，$m > \frac{1}{2}M$ であれば滑る。臨界質量は $x = \frac{1}{2}M$ である。
これは選択肢 $\textcircled{4}$ に該当する。

**【考査考点】**
剛体の静止平衡条件（力のつり合いとモーメントのつり合い），最大静止摩擦力。

## 物理 I-問4：滑らかな面上から垂れ下がったひもの加速度と長さの関係

**【題目大意】**
長さ $L$ の一様なひもの一部を滑らかな台の上に置き，残りを台の端から鉛直に垂らした。
垂れ下がった部分の長さを $x$ とするとき，ひもの加速度 $a$ と $x$ の関係を表すグラフを選ぶ。

**【公式正解】**
正解：$\textcircled{5}$

**【詳細推導・解答プロセス】**
ひもの全質量を $M$，線密度を $\rho = \frac{M}{L}$ とする。
垂れ下がっている部分の長さが $x$ であるとき，その質量は $m_x = \rho x = \frac{x}{L}M$ である。
台の面は水平で摩擦が無視できるため，ひも全体（質量 $M$）を引っ張る外力は垂れ下がり部分に働く重力のみである：
$$F = m_x g = \frac{x}{L}Mg$$
ひも全体の運動方程式は：
$$M a = F = \frac{x}{L}Mg \implies a = \frac{g}{L} x$$
したがって，加速度 $a$ は垂れ下がった長さ $x$ に比例し，グラフは原点を通る右上がりの直線となる。
これに合致するグラフは選択肢 $\textcircled{5}$ である。

**【考査考点】**
連続体（ひも）の運動方程式，重力駆動による加速度の線形変化。

## 物理 I-問5：板で支えたばね振り子の力学的エネルギー変化

**【題目大意】**
ばねに質量 $m$ のおもりをつり下げ，はじめ自然長の位置でおもりを板で支えた（図1，力学的エネルギー $U_1$）。
板をゆっくり下げ，ばねが $d$ だけ伸びたところでおもりは板を離れて静止した（図2，力学的エネルギー $U_2$）。
$U_2 - U_1$ の値を求める。

**【公式正解】**
正解：$\textcircled{2}$（$-\frac{1}{2}mgd$）

**【詳細推導・解答プロセス】**
自然長の位置を重力の位置エネルギーの基準面（$h = 0$）とする。
1. **図1の力学的エネルギー $U_1$**：
- 運動エネルギー：$0$
- ばねの弾性エネルギー：ばねは自然長なので $0$
- 重力の位置エネルギー：基準面にあるので $0$
$$U_1 = 0$$

2. **図2の力学的エネルギー $U_2$**：
ばねが $d$ 伸びた位置でおもりが板から離れてつり合っているため，フックの法則より：
$$kd = mg \implies k = \frac{mg}{d}$$
図2の状態において：
- 運動エネルギー：$0$
- ばねの弾性エネルギー：$\frac{1}{2}kd^2 = \frac{1}{2}\left(\frac{mg}{d}\right)d^2 = \frac{1}{2}mgd$
- 重力の位置エネルギー：距離 $d$ だけ下降したため $-mgd$
したがって：
$$U_2 = \frac{1}{2}mgd - mgd = -\frac{1}{2}mgd$$

3. **エネルギーの差**：
$$U_2 - U_1 = -\frac{1}{2}mgd - 0 = -\frac{1}{2}mgd$$
（注：板がおもりを支えながらゆっくり下げる過程で，板が負の仕事 $-\frac{1}{2}mgd$ をしたため，系の力学的エネルギーはその分だけ減少した。）
これは選択肢 $\textcircled{2}$ に合致する。

**【考査考点】**
弾性エネルギーと重力の位置エネルギー，つり合い条件と外力の仕事による力学的エネルギーの変化。

## 物理 I-問6：鉛直円軌道上の向心力の計算

**【題目大意】**
滑らかな曲面上で，高さ $h$ の点 A から質量 $m$ の小物体を静かに滑らせた。曲線 BC は直径 $h$ の半円である。
B からの高さが $\frac{2}{3}h$ である点 P を通過するときの小物体が受ける向心力の大きさを求める。

**【公式正解】**
正解：$\textcircled{3}$（$\frac{4}{3}mg$）

**【詳細推導・解答プロセス】**
1. **力学的エネルギー保存則による点 P での速さ $v$ の導出**：
最下点 B を高さの基準面とする。
曲面は滑らかであるため，力学的エネルギーが保存される：
$$mgh + 0 = mg\left(\frac{2}{3}h\right) + \frac{1}{2}mv^2$$
$$\frac{1}{2}mv^2 = mgh - \frac{2}{3}mgh = \frac{1}{3}mgh \implies v^2 = \frac{2}{3}gh$$

2. **向心力の計算**：
円軌道 BC の直径は $h$ であるから，曲率半径は：
$$R = \frac{h}{2}$$
円運動において，物体が受ける向心力 $F_c$ の大きさは：
$$F_c = m \frac{v^2}{R} = m \frac{\frac{2}{3}gh}{\frac{1}{2}h} = m \cdot \frac{4}{3}g = \frac{4}{3}mg$$
したがって，向心力の大きさは $\frac{4}{3}mg$ であり，選択肢 $\textcircled{3}$ が正解である。

**【考査考点】**
力学的エネルギー保存則，円運動の向心力公式 $F = m\frac{v^2}{r}$，軌道半径の幾何学的把握。

## 物理 I-問7：万有引力による人工衛星の向心加速度

**【題目大意】**
国際宇宙ステーション（ISS）が，地表からの高度 $h$ の円軌道上を一定の速さで運動している。
ISS の向心加速度の大きさを，地球半径 $R$ と地表での重力加速度 $g$ を用いて表す。

**【公式正解】**
正解：$\textcircled{1}$（$\frac{R^2}{(R+h)^2}g$）

**【詳細推導・解答プロセス】**
地球の質量を $M$，万有引力定数を $G$ とする。
1. **軌道上における万有引力と向心加速度**：
地球の中心から ISS までの距離は $r = R + h$ である。
ISS（質量 $m$）が受ける万有引力は：
$$F = G\frac{Mm}{(R+h)^2}$$
向心加速度 $a$ は運動方程式 $ma = F$ より：
$$a = \frac{GM}{(R+h)^2}$$

2. **地表の重力加速度 $g$ との結びつけ**：
地表面（距離 $R$）における重力加速度 $g$ は：
$$g = \frac{GM}{R^2} \implies GM = gR^2$$
これを向心加速度の式に代入すると：
$$a = \frac{gR^2}{(R+h)^2} = \frac{R^2}{(R+h)^2}g$$
これは選択肢 $\textcircled{1}$ に該当する。

**【考査考点】**
万有引力の法則，円軌道の向心加速度，地表の重力加速度との比例関係。

## 物理 II-A 問1：一定加熱下の水の混合と昇温所要時間の計算

**【題目大意】**
20°Cの水 2.0 kg をヒーターで42分加熱すると 80°C になった。これに 20°C の水 1.0 kg を追加し，引き続き同じヒーターで加熱した。
水の温度が 100°C に到達するのは，水を追加してから何分後か。

**【公式正解】**
正解：$\textcircled{4}$（42分）

**【詳細推導・解答プロセス】**
水の比熱を $c = 4.2\text{ J/(g·K)}$，ヒーターの単位時間あたりの発熱量を $P$ [J/分] とする。
1. **前半の加熱過程**：
質量 $m_1 = 2.0\text{ kg}$ の水が $\Delta T_1 = 80 - 20 = 60^\circ\text{C}$ 上昇するのに要した熱量は：
$$Q_1 = m_1 c \Delta T_1 = 2.0 \times c \times 60 = 120c$$
ヒーターの供給熱量より：
$$P \times 42 = 120c \implies P = \frac{120c}{42}$$

2. **水を追加した直後の温度**：
80°C の水 2.0 kg と 20°C の水 1.0 kg が混合したときの熱平衡温度 $T_{\text{mix}}$ は：
$$T_{\text{mix}} = \frac{2.0 \times 80 + 1.0 \times 20}{2.0 + 1.0} = \frac{160 + 20}{3.0} = 60^\circ\text{C}$$

3. **100°C までの追加加熱**：
全質量 $m_2 = 3.0\text{ kg}$ の水を 60°C から 100°C まで上昇させるための熱量は：
$$Q_2 = m_2 c \Delta T_2 = 3.0 \times c \times (100 - 60) = 3.0 \times c \times 40 = 120c$$
必要な加熱時間 $t$ は：
$$t = \frac{Q_2}{P} = \frac{120c}{\frac{120c}{42}} = 42\text{ 分}$$
したがって，42分後であり，選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
熱容量と比熱の計算，熱量の保存と混合平衡温度，熱量保存則に基づく所要時間の算出。

## 物理 III-B 問2：音波の干渉と弱め合う点の個数からの振動数範囲の決定

**【題目大意】**
距離 $2.50\text{ m}$ 離れた地点 A, B に同位相で発振する周波数 $f$ の音源がある。
線分 AB 上で音が弱め合う地点が20箇所（A, B を除く）あった。音速を $350\text{ m/s}$ とするとき，$f$ の範囲を求める。

**【公式正解】**
正解：$\textcircled{1}$（$1330\text{ Hz} < f \le 1470\text{ Hz}$）

**【詳細推導・解答プロセス】**
線分 AB 上では，両音源からの波が干渉して定在波が形成される。
同位相音源であるため，線分 AB の中点は腹（強め合う点）となる。
弱め合う点（節）は中点に関して対称に分布し，隣り合う節と節の間隔は $\frac{\lambda}{2}$ である。
全体で節が20箇所あるということは，中点の両側にそれぞれ10箇所ずつの節が存在することを意味する。
中点から端点（A または B）までの距離は $\frac{L}{2} = 1.25\text{ m}$ である。
中点（腹）から第 $k$ 番目の節までの距離は $\left(k - \frac{1}{2}\right)\frac{\lambda}{2}$ である。
第10番目の節が線分内部に存在し，第11番目の節が線分の外側にある（または端点上）条件は：
$$\left(10 - \frac{1}{2}\right)\frac{\lambda}{2} < 1.25 \le \left(11 - \frac{1}{2}\right)\frac{\lambda}{2}$$
$$\frac{19}{4}\lambda < 1.25 \le \frac{21}{4}\lambda$$
両辺に 2 を掛けて全線分長 $L = 2.50\text{ m}$ で表すと：
$$\frac{19}{2}\lambda < 2.50 \le \frac{21}{2}\lambda$$
音速 $V = 350\text{ m/s}$，波長 $\lambda = \frac{V}{f} = \frac{350}{f}$ を代入する：
$$\frac{19}{2} \cdot \frac{350}{f} < 2.50 \le \frac{21}{2} \cdot \frac{350}{f}$$
- 左の不等式より：
  $$2.50 f > 19 \times 175 = 3325 \implies f > \frac{3325}{2.5} = 1330\text{ Hz}$$
- 右の不等式より：
  $$2.50 f \le 21 \times 175 = 3675 \implies f \le \frac{3675}{2.5} = 1470\text{ Hz}$$
したがって：
$$1330\text{ Hz} < f \le 1470\text{ Hz}$$
これは選択肢 $\textcircled{1}$ に合致する。

**【考査考点】**
定在波の節と腹の間隔，2源の干渉条件，不等式による周波数範囲の絞り込み。

## 物理 III-C 問3：くさび形空気層による光の干渉縞と波長

**【題目大意】**
2枚の板ガラスの間に微小角 $\theta$ のくさび形空間をつくり，垂直に波長 $\lambda$ の単色光を照射した。
端 O から距離 $x_1$ の点 P と $x_2$ の点 Q の間に $N$ 本の明線が観測された。波長 $\lambda$ を表す式を求める。

**【公式正解】**
正解：$\textcircled{2}$（$\lambda = \frac{2(x_2 - x_1)\theta}{N}$）

**【詳細推導・解答プロセス】**
端 O からの距離を $x$ とすると，空気層の厚さは $d(x) = x \tan\theta \approx x\theta$ である。
上の板ガラス下面での反射（屈折率大 $\to$ 小）では位相変化なし。
下の板ガラス上面での反射（屈折率小 $\to$ 大）では位相が $\pi$ 反転する。
したがって，光路差 $2d$ に対する干渉条件は：
- 明線条件：$2x\theta = \left(m + \frac{1}{2}\right)\lambda \quad (m = 0, 1, 2, \dots)$
隣り合う明線の間隔 $\Delta x$ は：
$$2(\Delta x)\theta = \lambda \implies \Delta x = \frac{\lambda}{2\theta}$$
区間 $[x_1, x_2]$ の距離は $x_2 - x_1$ であり，この間に含まれる明線の本数 $N$ は：
$$N = \frac{x_2 - x_1}{\Delta x} = \frac{2(x_2 - x_1)\theta}{\lambda}$$
これを $\lambda$ について解くと：
$$\lambda = \frac{2(x_2 - x_1)\theta}{N}$$
これは選択肢 $\textcircled{2}$ に合致する。

**【考査考点】**
薄膜干渉，くさび形空気層の光路差，反射に伴う位相の反転，干渉縞の間隔の計算。

## 物理 IV-A 問1：糸で吊るした荷電小球のクーロン力と電気量比

**【題目大意】**
長さ $\ell$ の2本の絶縁体の糸で吊るされた等しい質量の小球に，電荷 $q_1$ を与えたとき（図1）と $q_2$ を与えたとき（図2）の静止状態を比較し，電荷の比 $\frac{q_2}{q_1}$ を求める。

**【公式正解】**
正解：$\textcircled{4}$（$\frac{q_2}{q_1} = 3$）

**【詳細推導・解答プロセス】**
糸が鉛直線となす角を $\theta$ とすると，小球間の距離は $r = 2\ell\sin\theta$ である。
小球に働く力は重力 $mg$，糸の張力 $T$，水平方向のクーロン反発力 $F_e$ である：
$$\tan\theta = \frac{F_e}{mg} = \frac{k q^2}{r^2 mg} = \frac{k q^2}{4\ell^2 \sin^2\theta mg}$$
$$q^2 = \frac{4\ell^2 mg}{k} \sin^2\theta \tan\theta$$
図の角度から計算すると，$\frac{q_2^2}{q_1^2} = 9 \implies \frac{q_2}{q_1} = 3$ となる。
したがって選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
クーロンの法則，力のつり合いとベクトル合成，幾何学的角度条件。

## 物理 IV-D 問4：平行直線電流がつくる磁場の重ね合わせ

**【題目大意】**
距離 $a$ 離れた平行な2本の直線導線 A, B がある。A には上向きに電流 $I$ が流れている。
A から $2a$，B から $3a$ の距離にある点 P において，B に電流 $I_B$ を流したところ，磁束密度の大きさは B の電流がない場合の $\frac{1}{4}$ 倍となり，向きは変わらなかった。
B に流した電流の向きと大きさ $I_B$ を求める。

**【公式正解】**
正解：$\textcircled{2}$（向き：$\downarrow$，$I_B = \frac{9}{8}I$）

**【詳細推導・解答プロセス】**
1. **導線 A のみによる点 P の磁場**：
右ねじの法則より，A を上向きに流れる電流 $I$ が距離 $2a$ の点 P につくる磁場 $B_A$ は紙面の裏向き（奥向き）であり：
$$B_A = \frac{\mu_0 I}{2\pi (2a)} = \frac{\mu_0 I}{4\pi a}$$

2. **導線 B の電流による磁場**：
B に電流を流した後の点 P での合成磁場 $B_{\text{total}}$ は，向きが変わらず大きさが $\frac{1}{4} B_A$ となった：
$$B_{\text{total}} = \frac{1}{4} B_A \quad \text{（紙面裏向き）}$$
磁場の重ね合わせの原理より $B_{\text{total}} = B_A - B_B$ であるから，導線 B による磁場 $B_B$ は紙面表向き（手前向き）でなければならない：
$$B_B = B_A - \frac{1}{4} B_A = \frac{3}{4} B_A = \frac{3}{4} \cdot \frac{\mu_0 I}{4\pi a} = \frac{3\mu_0 I}{16\pi a}$$

3. **電流 $I_B$ の向きと大きさの決定**：
点 P は導線 B の右側にある。右ねじの法則より，右側の点 P で紙面手前向きの磁場をつくるには，導線 B の電流は**下向き（$\downarrow$）**でなければならない。
B から P までの距離は $3a$ であるから：
$$B_B = \frac{\mu_0 I_B}{2\pi (3a)} = \frac{\mu_0 I_B}{6\pi a}$$
これを等置すると：
$$\frac{\mu_0 I_B}{6\pi a} = \frac{3\mu_0 I}{16\pi a}$$
$$I_B = 6 \times \frac{3}{16} I = \frac{18}{16} I = \frac{9}{8}I$$
したがって，向きは下向き（$\downarrow$），大きさは $I_B = \frac{9}{8}I$ である。
これは選択肢 $\textcircled{2}$ に合致する。

**【考査考点】**
直線電流がつくる磁場の公式，右ねじの法則，磁場の重ね合わせ（ベクトル和）。

## 物理 IV-E 問5：鉛直一様磁場中の電流が受けるアンペール力と剛体の回転平衡

**【題目大意】**
$AB = BC = CD = a$ の針金 ABCD（全質量 $m$）を PA, DQ で水平に支え，$A \to B \to C \to D$ の向きに電流 $I$ を流した。
鉛直上向きに磁束密度 $B$ の一様磁場をかけたところ，鉛直線から $30^\circ$ 傾いてつり合った。電流 $I$ を求める。

**【公式正解】**
正解：$\textcircled{4}$（$I = \frac{2\sqrt{3}}{9}\frac{mg}{Ba}$）

**【詳細推導・解答プロセス】**
1. **磁場から受ける力（アンペール力）**：
磁場は鉛直上向きである。
- AB, CD 部分：鉛直面内を傾いているが，電流成分と磁場の外積から生じる力のうち，回転軸周りのモーメントに寄与する成分を考える。
- BC 部分：水平で長さ $a$，電流は向きをもつ。フレミングの左手の法則より，水平方向の力 $F = I B a$ を受ける。

2. **回転軸周りのモーメントのつり合い**：
針金全体の質量は $m$ であり，3辺の長さが等しいため各辺の質量は $\frac{m}{3}$ である。
傾斜角を $\theta = 30^\circ$ とする。
各部分の重力による復元モーメントの和は：
$$M_g = mg \cdot d_G \sin\theta$$
重心の軸からの距離は $d_G = \frac{2 \times (\frac{m}{3}) \cdot \frac{a}{2} + (\frac{m}{3}) \cdot a}{m} = \frac{\frac{a}{3} + \frac{a}{3}}{1} = \frac{2}{3}a$ である。
したがって重力のモーメントは：
$$M_g = mg \cdot \left(\frac{2}{3}a\right) \sin 30^\circ = \frac{2}{3}mga \cdot \frac{1}{2} = \frac{1}{3}mga$$

水平方向の磁気力 $F = I B a$ は軸からの鉛直距離 $a \cos 30^\circ$ に働くため，磁気力のモーメントは：
$$M_B = F \cdot a \cos 30^\circ = (IBa) \cdot a \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{2} I B a^2$$
つり合いより：
$$\frac{\sqrt{3}}{2} I B a^2 = \frac{1}{3} mga \implies I = \frac{\frac{1}{3}mg}{\frac{\sqrt{3}}{2}Ba} = \frac{2}{3\sqrt{3}} \frac{mg}{Ba} = \frac{2\sqrt{3}}{9} \frac{mg}{Ba}$$
したがって選択肢 $\textcircled{4}$ が正解である。

**【考査考点】**
電流が磁場から受ける力（アンペール力），剛体の重心位置の算出，回転軸周りの力のモーメントのつり合い。

## 物理 IV-F 問6：磁束の時間変化とファラデーの電磁誘導の法則

**【題目大意】**
1巻のコイルを貫く磁束の時間変化グラフから，生じる誘導起電力の時間変化グラフを選ぶ。

**【公式正解】**
正解：$\textcircled{2}$

**【詳細推導・解答プロセス】**
ファラデーの電磁誘導の法則より，1巻のコイルに生じる誘導起電力 $V$ は：
$$V = -\frac{d\Phi}{dt}$$
すなわち，誘導起電力は磁束 $\Phi(t)$ の時間変化率（グラフの傾き）の符号を反転させたものに比例する：
- $\Phi$ が正の傾きで一定増加している区間：$\frac{d\Phi}{dt} > 0 \implies V$ は負の一定値。
- $\Phi$ が一定（傾き 0）の区間：$\frac{d\Phi}{dt} = 0 \implies V = 0$。
- $\Phi$ が負の傾きで減少している区間：$\frac{d\Phi}{dt} < 0 \implies V$ は正の一定値。
この規則に従って各区間の起電力の正負・大きさを正しく表しているのは選択肢 $\textcircled{2}$ である。

**【考査考点】**
ファラデーの電磁誘導の法則，レンツの法則，グラフの微分関係の定性・定量分析。
