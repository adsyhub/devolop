## 数学 コース1 第I問 [1]：2次関数の原点対称移動と指定区間における最大・最小値

**【題目大意】**
$a \neq 0$ とする。2次関数 $y = ax^2 - 4x - 4a$ $\cdots\textcircled{1}$ のグラフと原点 $(0, 0)$ に関して対称な曲線を $G$ とする。
(1) $\textcircled{1}$ の頂点の座標を求める。
(2) 曲線 $G$ を表す2次関数を選択肢の中から選ぶ。
(3) $G$ と $\textcircled{1}$ の交点の座標を求める。
(4) $a = 2$ のとき，区間 $DE \leq x \leq G$ における $G$ の最大値と最小値を求める。

**【公式正解】**
正解：
$\text{AB} = 24$
$\text{C} = 4$
$\text{DEF} = -28$
$\text{GHI} = 2-8$
$\text{JK} = 10$
$\text{LM} = -8$

**【詳細推導・解答プロセス】**
1. **(1) 頂点座標の算出**：
与えられた2次関数の式を変形（平方完成）する：
$$y = a\left(x^2 - \frac{4}{a}x\right) - 4a = a\left(x - \frac{2}{a}\right)^2 - a \cdot \frac{4}{a^2} - 4a = a\left(x - \frac{2}{a}\right)^2 - \frac{4}{a} - 4a$$
したがって，頂点の座標は：
$$\left(\frac{2}{a}, -\frac{4}{a} - 4a\right)$$
これより，$\text{A} = 2, \text{B} = 4$（$\text{AB} = 24$）である。

2. **(2) 原点対称移動による曲線 $G$ の方程式**：
点 $(x, y)$ を原点に関して対称移動させると $(-x, -y)$ に移る。
元の関数 $y = ax^2 - 4x - 4a$ の $x$ を $-x$ に，$y$ を $-y$ に置き換えると：
$$-y = a(-x)^2 - 4(-x) - 4a = ax^2 + 4x - 4a$$
両辺に $-1$ を掛けて整理すると：
$$y = -ax^2 - 4x + 4a$$
これは選択肢 $\textcircled{4}$ に一致する。したがって $\text{C} = 4$ である。

3. **(3) 2つの放物線の交点座標**：
$\textcircled{1}$ と $G$ の連立方程式を解く：
$$ax^2 - 4x - 4a = -ax^2 - 4x + 4a$$
両辺の $-4x$ を消去し，移行して整理すると：
$$2ax^2 = 8a$$
$a \neq 0$ より，両辺を $2a$ で割ると：
$$x^2 = 4 \implies x = \pm 2$$
- $x = -2$ のとき：
  $$y = a(-2)^2 - 4(-2) - 4a = 4a + 8 - 4a = 8$$
  交点は $(-2, 8)$ である。これより $\text{DE} = -2, \text{F} = 8$（$\text{DEF} = -28$）。
- $x = 2$ のとき：
  $$y = a(2)^2 - 4(2) - 4a = 4a - 8 - 4a = -8$$
  交点は $(2, -8)$ である。これより $\text{G} = 2, \text{HI} = -8$（$\text{GHI} = 2-8$）。

4. **(4) $a=2$ のときの区間 $[-2, 2]$ における最大値・最小値**：
$a = 2$ のとき，曲線 $G$ の方程式は：
$$y = -2x^2 - 4x + 8 = -2(x^2 + 2x) + 8 = -2(x + 1)^2 + 10$$
これは上に凸の放物線であり，軸は $x = -1$ である。
指定された区間は $-2 \leq x \leq 2$ である：
- 軸 $x = -1$ は区間 $[-2, 2]$ の内部に含まれるため，最大値は頂点でとり：
  $$y_{\text{max}} = 10 \quad (x = -1 \text{ のとき})$$
  これより $\text{JK} = 10$ である。
- 最小値は軸 $x = -1$ から最も遠い端点 $x = 2$ でとり：
  $$y_{\text{min}} = -2(2+1)^2 + 10 = -18 + 10 = -8 \quad (x = 2 \text{ のとき})$$
  これより $\text{LM} = -8$ である。

**【考査考点】**
2次関数の平方完成，図形の原点対称移動，2次方程式による共有点の算出，定義域制限下の2次関数の最大・最小値問題。

## 数学 コース1 第I問 [2]：絶対値を含む1次方程式の解法と整数解条件

**【題目大意】**
$a$ を定数とし，$x$ の方程式 $|ax - 11| = 4x - 10$ $\cdots\textcircled{1}$ を考える。
(1) 絶対値の記号を使わない形に変形する。
(2) $a = \sqrt{7}$ のときの方程式の解を求める。
(3) $a$ が正の整数のとき，方程式が正の整数解をもつような $a$ とその解 $x$ を求める。

**【公式正解】**
正解：
$\text{NO} = 41$
$\text{PQR} = 421$
$\text{STUV} = 7473$
$\text{W} = 3$
$\text{X} = 3$

**【詳細推導・解答プロセス】**
1. **(1) 絶対値の解除**：
絶対値の中身の正負によって場合分けする：
- $ax - 11 \geq 0$，すなわち $ax \geq 11$ のとき：
  $$ax - 11 = 4x - 10 \implies (a - 4)x = 1$$
  これより $\text{N} = 4, \text{O} = 1$（$\text{NO} = 41$）。
- $ax - 11 < 0$，すなわち $ax < 11$ のとき：
  $$-(ax - 11) = 4x - 10 \implies -ax + 11 = 4x - 10 \implies (a + 4)x = 21$$
  これより $\text{P} = 4, \text{QR} = 21$（$\text{PQR} = 421$）。

2. **(2) $a = \sqrt{7}$ のときの解**：
右辺 $4x - 10$ は絶対値と等しいため，$4x - 10 \geq 0 \implies x \geq \frac{5}{2} = 2.5$ でなければならない。
- もし $ax \geq 11$ の場合：
  $(\sqrt{7} - 4)x = 1 \implies x = \frac{1}{\sqrt{7} - 4} < 0$ となり，不適。
- したがって $ax < 11$ の場合である：
  $$(\sqrt{7} + 4)x = 21 \implies x = \frac{21}{4 + \sqrt{7}}$$
  分母を有理化すると：
  $$x = \frac{21(4 - \sqrt{7})}{(4 + \sqrt{7})(4 - \sqrt{7})} = \frac{21(4 - \sqrt{7})}{16 - 7} = \frac{21(4 - \sqrt{7})}{9} = \frac{7(4 - \sqrt{7})}{3}$$
  この値について確認すると：
  $\sqrt{7} \approx 2.646$ より $4 - \sqrt{7} \approx 1.354$ であり，$x = \frac{7 \times 1.354}{3} \approx 3.16 > 2.5$ である。
  また $ax = \sqrt{7} \times 3.16 \approx 8.36 < 11$ を満たす。
  したがって，$x = \frac{7(4 - \sqrt{7})}{3}$ である。
  これより $\text{S} = 7, \text{T} = 4, \text{U} = 7, \text{V} = 3$（$\text{STUV} = 7473$）。

3. **(3) $a$ が正の整数で正の整数解をもつ条件**：
$x$ が正の整数であるとき，方程式の解の候補を吟味する：
- **場合 1**：$ax \geq 11$ のとき，$(a - 4)x = 1$
  $a, x$ は整数であるから，$a - 4$ と $x$ は 1 の約数である。
  $x > 0$ より $x = 1, a - 4 = 1 \implies a = 5$。
  このとき $ax = 5 \times 1 = 5$ であるが，前提条件 $ax \geq 11$ に反するため不適。
- **場合 2**：$ax < 11$ のとき，$(a + 4)x = 21$
  $a$ は正の整数（$a \geq 1$）であるから，$a + 4 \geq 5$ である。
  21 の正の約数は $1, 3, 7, 21$ であるから，$a + 4$ の候補は $7$ または $21$ である。
  - $a + 4 = 7$ のとき：$a = 3$
    このとき $x = \frac{21}{7} = 3$ である。
    条件 $ax < 11$ を確認すると $3 \times 3 = 9 < 11$ を満たし，適する。
  - $a + 4 = 21$ のとき：$a = 17$
    このとき $x = 1$ であるが，$ax = 17 \times 1 = 17 > 11$ となり条件 $ax < 11$ に反するため不適。
したがって，求める値は $a = 3, x = 3$ である。
これより $\text{W} = 3, \text{X} = 3$ である。

**【考査考点】**
絶対値の定義による場合分け，無理数の有理化，約数を用いた整数の不定方程式の整数解の絞り込み。

## 数学 コース1 第II問 [1]：2つの箱からのカード抽出と積の確率分布

**【題目大意】**
箱 A には「0」のカード3枚，「2」のカード2枚，「3」のカード1枚が入っている（計6枚）。
箱 B には「1」のカード2枚，「2」のカード3枚が入っている（計5枚）。
箱 A から同時に2枚，箱 B から1枚を取り出し，3枚のカードに書かれた数字の積を $X$ とする。
$X$ のとり得る値の総数，最大値，最小値，およびそれらをとる確率を求める。

**【公式正解】**
正解：
$\text{A} = 5$
$\text{BC} = 12$
$\text{D} = 0$
$\text{EFG} = 225$
$\text{HI} = 45$

**【詳細推導・解答プロセス】**
1. **$X$ のとり得る値の列挙**：
箱 A から取り出される2枚の数の組み合わせとその積：
- $\{0, 0\} \implies$ 積 $0$
- $\{0, 2\} \implies$ 積 $0$
- $\{0, 3\} \implies$ 積 $0$
- $\{2, 2\} \implies$ 積 $4$
- $\{2, 3\} \implies$ 積 $6$
箱 B から取り出される数は $1$ または $2$ である。
したがって，3枚の積 $X$ は：
- A の積が $0$ のとき：$0 \times 1 = 0,\; 0 \times 2 = 0 \implies X = 0$
- A の積が $4$ のとき：$4 \times 1 = 4,\; 4 \times 2 = 8 \implies X = 4,\; 8$
- A の積が $6$ のとき：$6 \times 1 = 6,\; 6 \times 2 = 12 \implies X = 6,\; 12$
したがって，$X$ のとり得る値の集合は $\{0, 4, 6, 8, 12\}$ であり，全部で **5 個**ある（$\text{A} = 5$）。
最大値は **12**（$\text{BC} = 12$），最小値は **0**（$\text{D} = 0$）である。

2. **$X = 12$ となる確率**：
$X = 12$ となるのは，「A から 2 と 3 を各1枚」「B から 2 を1枚」取り出す場合に限られる。
- A からの全取り出し方は $\binom{6}{2} = \frac{6 \times 5}{2} = 15$ 通り。
  2 を1枚，3 を1枚引く組み合わせは $\binom{2}{1} \times \binom{1}{1} = 2 \times 1 = 2$ 通り。
  確率：$P_A = \frac{2}{15}$
- B から 2 を引く確率は $P_B = \frac{3}{5}$
両者は独立であるから：
$$P(X = 12) = \frac{2}{15} \times \frac{3}{5} = \frac{2}{25}$$
これより $\text{E} = 2, \text{FG} = 25$（$\text{EFG} = 225$）である。

3. **$X = 0$ となる確率**：
$X = 0$ となるのは，A から取り出した2枚の中に少なくとも1枚の「0」が含まれる場合である（余事象の利用が簡明）：
- A から「0」を1枚も引かない（すなわち 0 以外の 3 枚 $\{2, 2, 3\}$ から 2 枚引く）確率：
  $$P(\text{Aに0なし}) = \frac{\binom{3}{2}}{\binom{6}{2}} = \frac{3}{15} = \frac{1}{5}$$
- したがって，A に少なくとも1枚の 0 が含まれる確率は：
  $$P(X = 0) = 1 - \frac{1}{5} = \frac{4}{5}$$
これより $\text{H} = 4, \text{I} = 5$（$\text{HI} = 45$）である。

**【考査考点】**
組合せを用いた確率の計算，独立試行の乗法定理，余事象の確率の利用，離散確率変数の値域の全列挙。

## 数学 コース1 第II問 [2]：三角形の面積を二等分する線分長の最小化問題

**【題目大意】**
$AB = 8, AC = 5, \angle BAC = 60^\circ$ である三角形 ABC を考える。辺 AB, AC 上にそれぞれ点 D, E を，線分 DE が $\triangle ABC$ の面積を二等分するようにとる。$AD = x$ とする。
(1) $AE$ を $x$ の式で表す。
(2) 点 E が辺 AC 上を動くときの $x$ の範囲を求める。
(3) $DE^2$ を $x$ の式で変形し，線分 DE の最小値とそのときの $x$ の値を求める。

**【公式正解】**
正解：
$\text{JK} = 20$
$\text{L} = 4$
$\text{M} = 8$
$\text{NOPQ} = 2020$
$\text{RS} = 25$
$\text{TU} = 25$

**【詳細推導・解答プロセス】**
1. **(1) $AE$ の立式**：
三角形の面積の公式より：
$$S_{\triangle ABC} = \frac{1}{2} AB \cdot AC \sin 60^\circ$$
$$S_{\triangle ADE} = \frac{1}{2} AD \cdot AE \sin 60^\circ = \frac{1}{2} x \cdot AE \sin 60^\circ$$
線分 DE が面積を二等分するため：
$$\frac{S_{\triangle ADE}}{S_{\triangle ABC}} = \frac{x \cdot AE}{AB \cdot AC} = \frac{1}{2}$$
$$x \cdot AE = \frac{1}{2} \times 8 \times 5 = 20 \implies AE = \frac{20}{x}$$
したがって $\text{JK} = 20$ である。

2. **(2) $x$ の変域の決定**：
点 D は辺 AB（長さ 8）上にあるため $0 < x \leq 8$ である。
点 E は辺 AC（長さ 5）上にあるため：
$$0 < AE \leq 5 \implies \frac{20}{x} \leq 5 \implies x \geq 4$$
両者を合わせると，$x$ のとり得る範囲は：
$$4 \leq x \leq 8$$
これより $\text{L} = 4, \text{M} = 8$ である。

3. **(3) $DE^2$ の変形と最小値の導出**：
$\triangle ADE$ において余弦定理を適用する（$\cos 60^\circ = \frac{1}{2}$）：
$$DE^2 = AD^2 + AE^2 - 2 AD \cdot AE \cos 60^\circ$$
$$DE^2 = x^2 + \left(\frac{20}{x}\right)^2 - 2 \times x \times \frac{20}{x} \times \frac{1}{2} = x^2 + \frac{400}{x^2} - 20$$
平方の形に変形すると：
$$DE^2 = \left(x - \frac{20}{x}\right)^2 + 2 \cdot x \cdot \frac{20}{x} - 20 = \left(x - \frac{20}{x}\right)^2 + 40 - 20 = \left(x - \frac{20}{x}\right)^2 + 20$$
これより $\text{NO} = 20, \text{PQ} = 20$（$\text{NOPQ} = 2020$）。

4. **最小値の算定**：
実数の平方は常に $0$ 以上であるから，$\left(x - \frac{20}{x}\right)^2 \geq 0$ である。
等号成立条件は：
$$x - \frac{20}{x} = 0 \implies x^2 = 20 \implies x = \sqrt{20} = 2\sqrt{5}$$
$2\sqrt{5} = \sqrt{20}$ は $4 = \sqrt{16} < \sqrt{20} < \sqrt{64} = 8$ を満たすため，区間 $[4, 8]$ に含まれており適する。
このとき，$DE^2$ の最小値は $20$ であるから，線分 DE の最小値は：
$$DE = \sqrt{20} = 2\sqrt{5}$$
したがって，$x = 2\sqrt{5}$ のとき最小値 $2\sqrt{5}$ をとる。
これより $\text{R} = 2, \text{S} = 5$（$\text{RS} = 25$），$\text{T} = 2, \text{U} = 5$（$\text{TU} = 25$）である。

**【考査考点】**
三角形の面積比公式，三角比と余弦定理，平方完成による相加相乗的関数の最小値決定，定義域内の実現可能性検証。

## 数学 コース1 第III問 (前半)：角を切り取った多角形における辺の関係式と2元2次方程式

**【題目大意】**
長方形の2つの角を直角三角形として切り取った図形がある。
各辺の長さは $AB = 11, BC = 4, CD = 2\sqrt{13}, DE = 5, EF = 2\sqrt{5}, FA = 6$ である。
切り取った直角三角形の直角を挟む辺を $x, y$ および $u, v$ とするとき，辺の関係式を立式し，$x$ を $y$ で表す式を導く。

**【公式正解】**
正解：
$\text{A} = 6$
$\text{B} = 2$
$\text{CD} = 52$
$\text{EF} = 20$
$\text{GH} = 32$

**【詳細推導・解答プロセス】**
1. **辺の幾何学的関係と直角三角形の斜辺**：
長方形の角を切り取った図において，直角を挟む辺の幾何関係を見る：
- $FA = 6$ であるから，対向する辺との垂直方向の関係より：
  $$u = 6 - y \implies \text{A} = 6$$
- 水平方向の寸法の差より：
  $$v = x + (AB - DE - BC) = x + (11 - 5 - 4) = x + 2 \implies \text{B} = 2$$
- 三平方の定理より：
  $$u^2 + v^2 = CD^2 = (2\sqrt{13})^2 = 4 \times 13 = 52 \implies \text{CD} = 52$$
  $$x^2 + y^2 = EF^2 = (2\sqrt{5})^2 = 4 \times 5 = 20 \implies \text{EF} = 20$$

2. **$x$ と $y$ の1次関係式の導出**：
$u = 6 - y$ と $v = x + 2$ を $u^2 + v^2 = 52$ に代入する：
$$(6 - y)^2 + (x + 2)^2 = 52$$
展開すると：
$$36 - 12y + y^2 + x^2 + 4x + 4 = 52$$
ここで $x^2 + y^2 = 20$ を代入すると：
$$20 + 40 + 4x - 12y = 52$$
$$4x - 12y + 60 = 52 \implies 4x - 12y = -8$$
両辺を 4 で割ると：
$$x - 3y = -2 \implies x = 3y - 2$$
これより $\text{G} = 3, \text{H} = 2$（$\text{GH} = 32$）である。

**【考査考点】**
幾何図形の線分長の代数化，三平方の定理（ピタゴラスの定理），2次式の連立消去による1次関係式の導出。

## 数学 コース1 第III問 (後半)：2次方程式の求解と全寸法の決定・図形面積の算出

**【題目大意】**
前半で得られた $x = 3y - 2$ を用いて $y$ の2次方程式を導いて解き，各辺の寸法を決定して図形全体の面積を求める。

**【公式正解】**
正解：
$\text{IJK} = 568$
$\text{L} = 2$
$\text{M} = 4$
$\text{N} = 4$
$\text{O} = 6$
$\text{PQ} = 94$

**【詳細推導・解答プロセス】**
1. **$y$ についての2次方程式の立式と求解**：
$x = 3y - 2$ を $x^2 + y^2 = 20$ に代入する：
$$(3y - 2)^2 + y^2 = 20$$
$$9y^2 - 12y + 4 + y^2 = 20$$
$$10y^2 - 12y - 16 = 0$$
両辺を 2 で割ると：
$$5y^2 - 6y - 8 = 0$$
したがって $\text{I} = 5, \text{J} = 6, \text{K} = 8$（$\text{IJK} = 568$）である。

因数分解すると：
$$(5y + 4)(y - 2) = 0$$
$y$ は線分の長さであるため $y > 0$ である。したがって：
$$y = 2$$
これより $\text{L} = 2$ である。

2. **各線分の長さの決定**：
- $x = 3(2) - 2 = 6 - 2 = 4 \implies \text{M} = 4$
- $u = 6 - y = 6 - 2 = 4 \implies \text{N} = 4$
- $v = x + 2 = 4 + 2 = 6 \implies \text{O} = 6$

3. **図形の面積の計算**：
角を切る前の元の外接長方形の寸法を求める：
- 横の長さ：$AB = 11$
- 縦の長さ：$FA + BC = 6 + 4 = 10$
したがって，外接長方形の面積は：
$$S_{\text{長方形}} = 11 \times 10 = 110$$
切り取られた2つの直角三角形の面積は：
- 三角形1（辺 $x, y$）：$\frac{1}{2} \times 4 \times 2 = 4$
- 三角形2（辺 $u, v$）：$\frac{1}{2} \times 4 \times 6 = 12$
したがって，求める図形の面積 $S$ は：
$$S = 110 - 4 - 12 = 94$$
これより $\text{PQ} = 94$ である。

**【考査考点】**
2次方程式の解法，多角形の求積法（補集合的分割による求積），平面幾何と代数の融合問題。

## 数学 コース1 第IV問 (前半)：2変数2次制約条件における和 a = x + y の変域決定

**【題目大意】**
2つの実数 $x, y$ が $3x^2 + 2xy + 3y^2 = 32$ $\cdots\textcircled{1}$ を満たすとき，$x + y = a$ $\cdots\textcircled{2}$ とおき，$y$ を消去して $x$ の2次方程式を導き，$x$ が実数である条件から $a$ のとり得る値の範囲を求める。

**【公式正解】**
正解：
$\text{ABC} = 443$
$\text{DEF} = -44$

**【詳細推導・解答プロセス】**
1. **$y$ の消去と2次方程式の導出**：
$\textcircled{2}$ より $y = a - x$ である。これを $\textcircled{1}$ に代入する：
$$3x^2 + 2x(a - x) + 3(a - x)^2 = 32$$
各項を展開すると：
$$3x^2 + 2ax - 2x^2 + 3(x^2 - 2ax + a^2) = 32$$
$$x^2 + 2ax + 3x^2 - 6ax + 3a^2 = 32$$
同類項をまとめると：
$$4x^2 - 4ax + 3a^2 - 32 = 0$$
したがって，$\text{A} = 4, \text{B} = 4, \text{C} = 3$（$\text{ABC} = 443$）である。

2. **実数解条件による $a$ の範囲の決定**：
$x$ は実数であるから，この $x$ の2次方程式は実数解をもたなければならない。
判別式を $D$ とすると，$D/4 \geq 0$ が必要十分条件である：
$$\frac{D}{4} = (-2a)^2 - 4(3a^2 - 32) \geq 0$$
$$4a^2 - 12a^2 + 128 \geq 0$$
$$-8a^2 + 128 \geq 0$$
両辺を $-8$ で割ると（不等号が反転する）：
$$a^2 - 16 \leq 0 \implies (a + 4)(a - 4) \leq 0$$
したがって：
$$-4 \leq a \leq 4$$
これより $\text{DE} = -4, \text{F} = 4$（$\text{DEF} = -44$）である。

**【考査考点】**
文字消去法，2次方程式の実数解存在条件（判別式 $D \geq 0$），2次不等式の解法。

## 数学 コース1 第IV問 (後半)：対称式の関係式と積 b = xy の値域決定

**【題目大意】**
$xy = b$ とおくとき，$b$ を $a$ の式で表し，前半で求めた $a$ の範囲を用いて $b$ がとる値の範囲を求める。

**【公式正解】**
正解：
$\text{GHI} = 348$
$\text{JK} = -8$
$\text{L} = 4$

**【詳細推導・解答プロセス】**
1. **$b$ を $a$ の式で表す**：
与式 $\textcircled{1}$ は $x, y$ の対称式である：
$$3x^2 + 2xy + 3y^2 = 3(x^2 + 2xy + y^2) - 4xy = 3(x + y)^2 - 4xy$$
$x + y = a$ および $xy = b$ を代入すると：
$$3a^2 - 4b = 32$$
$4b = 3a^2 - 32$ より：
$$b = \frac{3}{4}a^2 - 8$$
したがって，$\text{G} = 3, \text{H} = 4, \text{I} = 8$（$\text{GHI} = 348$）である。

2. **$b$ の値域の決定**：
前半の $\textcircled{3}$ より，$-4 \leq a \leq 4$ であるから：
$$0 \leq a^2 \leq 16$$
この範囲において $b = \frac{3}{4}a^2 - 8$ の増減を考える：
- $a^2 = 0$（すなわち $a = 0$）のとき，最小値：
  $$b_{\text{min}} = \frac{3}{4}(0) - 8 = -8$$
- $a^2 = 16$（すなわち $a = \pm 4$）のとき，最大値：
  $$b_{\text{max}} = \frac{3}{4}(16) - 8 = 12 - 8 = 4$$
したがって，$b$ のとり得る値の範囲は：
$$-8 \leq b \leq 4$$
これより $\text{JK} = -8, \text{L} = 4$ である。

**【考査考点】**
対称式の基本対称式（$x+y, xy$）による表現，変数の変換と値域の連鎖的決定，楕円上の点の二次形式の極値問題。
