## 第I問 問1：2次関数と水平直線の交点間距離・頂点と係数決定

**【考査考点】**：放物線の軸と水平直線との交点の対称性, 頂点標準形 $y = a(x-p)^2 + q$ による連立方程式, 通過点と頂点の範囲制約による係数の決定

### 【第I問 問1】詳細解答と解説

#### (1) 放物線の頂点と直線の交点間距離
放物線 $C: y = ax^2 + bx + c$（$a \neq 0$）の頂点の座標を $(p, q)$ とおくと、$C$ の方程式は標準形を用いて
$$y = a(x - p)^2 + q$$
と表される。放物線は軸 $x = p$ に関して線対称である。

直線 $y = 1$ と $C$ との 2 つの交点の $x$ 座標は、$a(x - p)^2 + q = 1$ の解である。
交点間の距離が 4 であるため、軸 $x = p$ から各交点までの距離はその半分の 2 である。
交点のひとつをとり、その $x$ 座標を $\alpha$ とおくと：
$$|\alpha - p| = \mathbf{2}$$
よって、$\mathbf{A = 2}$。

この交点の座標 $(\alpha, 1)$ を放物線の方程式に代入すると：
$$a(\alpha - p)^2 + q = 1 \implies a(2)^2 + q = 1 \implies \mathbf{4a + q = 1}$$
よって、$\mathbf{B = 4, C = 1}$（解答番号 $\mathbf{BC = 41}$）。

同様に、直線 $y = 3$ と $C$ との交点間の距離は 6 であるから、軸からの距離は $6 / 2 = 3$ である。
交点の座標を代入すると：
$$a(3)^2 + q = 3 \implies \mathbf{9a + q = 3}$$
よって、$\mathbf{D = 9, E = 3}$（解答番号 $\mathbf{DE = 93}$）。

これら 2 式を連立して解く：
$$\begin{cases} 4a + q = 1 \\ 9a + q = 3 \end{cases}$$
下の式から上の式を引くと：
$$5a = 2 \implies a = \frac{\mathbf{2}}{\mathbf{5}}$$
よって、$\mathbf{F = 2, G = 5}$（解答番号 $\mathbf{FG = 25}$）。

これを上の式に代入すると：
$$4 \times \frac{2}{5} + q = 1 \implies q = 1 - \frac{8}{5} = -\frac{\mathbf{3}}{\mathbf{5}}$$
よって、$q = -\frac{H}{I}$ より $\mathbf{H = 3, I = 5}$（解答番号 $\mathbf{HI = 35}$）。

#### (2) 点 $\left(2, -\frac{1}{5}\right)$ を通る条件と係数 $b, c$ の決定
$a = \frac{2}{5}, q = -\frac{3}{5}$ を放物線の式に代入すると：
$$y = \frac{2}{5}(x - p)^2 - \frac{3}{5}$$
このグラフが点 $\left(2, -\frac{1}{5}\right)$ を通るから：
$$-\frac{1}{5} = \frac{2}{5}(2 - p)^2 - \frac{3}{5}$$
両辺に 5 を掛けると：
$$-1 = 2(2 - p)^2 - 3 \implies 2(2 - p)^2 = 2 \implies (2 - p)^2 = 1$$
$$2 - p = \pm 1 \implies p = 2 \mp 1 \implies p = 1 \text{ または } 3$$
条件「頂点の $x$ 座標 $p$ が 2 より小さい（$p < 2$）」より、$\mathbf{p = 1}$ に決定される。

したがって、2次関数を展開すると：
$$y = \frac{2}{5}(x - 1)^2 - \frac{3}{5} = \frac{2}{5}(x^2 - 2x + 1) - \frac{3}{5} = \frac{2}{5}x^2 - \frac{4}{5}x + \frac{2}{5} - \frac{3}{5} = \frac{2}{5}x^2 - \frac{4}{5}x - \frac{1}{5}$$
これをもとの式 $y = ax^2 + bx + c$ と比較して：
$$b = -\frac{\mathbf{4}}{\mathbf{5}}, \quad c = -\frac{\mathbf{1}}{\mathbf{5}}$$
よって、$\mathbf{J = 4, K = 5}$（解答番号 $\mathbf{JK = 45}$）、$\mathbf{L = 1, M = 5}$（解答番号 $\mathbf{LM = 15}$）。

**【解法テクニック・易錯点】**
- 水平直線との交点距離が与えられた場合、一般形ではなく軸対称性を活かして $|x - p| = d/2$ と置くことで、計算量を劇的に減らすことができます。

## 第I問 問2：サイコロの出目の「つながり」と確率漸化・終了確率

**【考査考点】**：整数が「つながっている」（差の絶対値が 1 以下）の定義, 端の目（1, 6）と内側の目（2, 3, 4, 5）の推移確率の対称性, 試行終了と継続の余事象の確率計算

### 【第I問 問2】詳細解答と解説

#### 問題の定義と設定
2つの整数 $m$ と $n$ が「つながっている」とは、$n \in \{m-1, m, m+1\}$ であること。
サイコロを繰り返し投げ、直前の目と「つながっていない」目が出た瞬間に試行は終了する。
サイコロの各目 $1, 2, 3, 4, 5, 6$ に対し、つながっている目の個数：
- $m = 1$: $\{1, 2\}$（2個）
- $m = 2$: $\{1, 2, 3\}$（3個）
- $m = 3$: $\{2, 3, 4\}$（3個）
- $m = 4$: $\{3, 4, 5\}$（3個）
- $m = 5$: $\{4, 5, 6\}$（3個）
- $m = 6$: $\{5, 6\}$（2個）

#### (1) 2 回目を投げた後、試行が終了していない確率
1 回目のサイコロの目により場合分けを行う：
- 1 回目が 1 または 6（確率 $\frac{2}{6} = \frac{1}{3}$）：つながる目は 2 個なので、2 回目もつながる確率は $\frac{2}{6} = \frac{1}{3}$。
- 1 回目が 2, 3, 4, 5（確率 $\frac{4}{6} = \frac{2}{3}$）：つながる目は 3 個なので、2 回目もつながる確率は $\frac{3}{6} = \frac{1}{2}$。
したがって、2 回目を投げた後も終了していない確率 $P(\text{継続}_2)$ は：
$$P(\text{継続}_2) = \frac{1}{3} \times \frac{1}{3} + \frac{2}{3} \times \frac{1}{2} = \frac{1}{9} + \frac{1}{3} = \frac{\mathbf{4}}{\mathbf{9}}$$
よって、$\mathbf{NO = 49}$。

#### (2) 2 回目で試行が終了する確率
「2 回目で終了する」は「2 回目を投げて終了していない」の余事象である：
$$P(\text{終了}_2) = 1 - P(\text{継続}_2) = 1 - \frac{4}{9} = \frac{\mathbf{5}}{\mathbf{9}}$$
よって、$\mathbf{PQ = 59}$。

#### (3) 3 回目を投げた後、試行が終了していない確率
2 回目の出目が端か内側かで 3 回目の継続確率が変わるため、2 回目の目の分布を求める。
1 回目 $\to$ 2 回目の推移でつながるペア（計 $2\times 2 + 4\times 3 = 16$ 通り）：
- 2 回目の目が端（1 または 6）となる出目：
  - 2 回目が 1：1回目が 1 または 2（2通り）
  - 2 回目が 6：1回目が 5 または 6（2通り）
  合計 $2 + 2 = 4$ 通り。確率 $= \frac{4}{36} = \frac{1}{9}$。
- 2 回目の目が内側（2, 3, 4, 5）となる出目：
  - 16通り中 $16 - 4 = 12$ 通り。確率 $= \frac{12}{36} = \frac{1}{3}$。

3 回目に試行が継続する条件付き確率：
- 2 回目が端（1, 6）：3 回目につながる確率は $\frac{2}{6} = \frac{1}{3}$。
- 2 回目が内側（2, 3, 4, 5）：3 回目につながる確率は $\frac{3}{6} = \frac{1}{2}$。
したがって、3 回目を投げた後も終了していない確率 $P(\text{継続}_3)$ は：
$$P(\text{継続}_3) = \frac{1}{9} \times \frac{1}{3} + \frac{1}{3} \times \frac{1}{2} = \frac{1}{27} + \frac{1}{6} = \frac{2 + 9}{54} = \mathbf{\frac{11}{54}}$$
これは選択肢 $\textcircled{2}$ に一致する。よって、$\mathbf{R = 2}$。

#### (4) 3 回以下の試行で終了する確率
「3 回以下で終了する」は「3 回目を投げた後も終了していない」の余事象である：
$$1 - P(\text{継続}_3) = 1 - \frac{11}{54} = \mathbf{\frac{43}{54}}$$
これは選択肢 $\textcircled{7}$ に一致する。よって、$\mathbf{S = 7}$。

#### (5) ちょうど 3 回目で終了する確率
「2 回目まで継続し、3 回目に終了する」確率である：
$$P(\text{継続}_2) - P(\text{継続}_3) = \frac{4}{9} - \frac{11}{54} = \frac{24 - 11}{54} = \mathbf{\frac{13}{54}}$$
これは選択肢 $\textcircled{3}$ に一致する。よって、$\mathbf{T = 3}$。

**【解法テクニック・易錯点】**
- 状態推移（端の目か内側の目か）を把握し、余事象 $P(\text{終了}) = 1 - P(\text{継続})$ を利用することで、膨大な場合分けをスマートに整理できます。

## 第II問 問1：2次式数列の因数分解と倍数条件・総和計算

**【考査考点】**：2次式の因数分解 $4n^2 + 5n - 6 = (n+2)(4n-3)$, 素数 5 による倍数判定と不定方程式の整数解, 最初の20項における対象項の計数と数列の和の公式

### 【第II問 問1】詳細解答と解説

#### (1) 数列 $a_n = 4n^2 + 5n - 6$ の因数分解と 5 の倍数条件
$a_n = 4n^2 + 5n - 6$ をたすき掛けにより因数分解する：
$$4n^2 + 5n - 6 = (n + 2)(4n - 3)$$
形式 $a_n = (n + A)(Bn - C)$ と比較すると：
$$A = 2, \quad B = 4, \quad C = 3$$
よって、$\mathbf{A = 2, B = 4, C = 3}$（解答番号 $\mathbf{ABC = 243}$）。

5 は素数であるから、$a_n = (n + 2)(4n - 3)$ が 5 の倍数となるための必要十分条件は、
$n + 2$ が 5 の倍数であるか、または $4n - 3$ が 5 の倍数であることである。

**(i) $n + 2$ が 5 の倍数のとき**
整数 $k$ を用いて $n + 2 = 5k$ と表せるから：
$$n = \mathbf{5k - 2}$$
選択肢一覧より、$5k - 2$ は選択肢 $\textcircled{1}$ に該当する。よって、$\mathbf{D = 1}$。

このとき、$a_n$ を $k$ を用いて表す：
$$n + 2 = 5k$$
$$4n - 3 = 4(5k - 2) - 3 = 20k - 8 - 3 = 20k - 11$$
したがって：
$$a_n = 5k(20k - 11) = \mathbf{5(20k^2 - 11k)}$$
これは選択肢 $\textcircled{5}$ に該当する。よって、$\mathbf{E = 5}$。

**(ii) $4n - 3$ が 5 の倍数のとき**
整数 $j$ を用いて表すと：
$$4n - 3 = \mathbf{5}j$$
よって、$\mathbf{F = 5}$。

この式を変形する：
$$4n - 3 = 5j \implies 5n - n - 3 = 5j \implies n + 3 = 5(n - j)$$
形式 $n + G = F(n - j)$ と比較すると、$G = 3$ である。
よって、$\mathbf{G = 3}$。

ここで $k = n - j$（整数）とおくと、$n + 3 = 5k$ より：
$$n = \mathbf{5k - 3}$$
これは選択肢 $\textcircled{2}$ に該当する。よって、$\mathbf{H = 2}$。

このとき、$a_n$ を $k$ を用いて表す：
$$n + 2 = (5k - 3) + 2 = 5k - 1$$
$$4n - 3 = 5(n - j) = 5k$$
したがって：
$$a_n = (5k - 1) \cdot 5(4k - 3) \dots \text{ではなく } 4n-3 = 4(5k-3)-3 = 20k - 15 = 5(4k - 3)$$
$$a_n = (5k - 1) \cdot 5(4k - 3) = 5(20k^2 - 15k - 4k + 3) = \mathbf{5(20k^2 - 19k + 3)}$$
これは選択肢 $\textcircled{9}$ に該当する。よって、$\mathbf{I = 9}$。

#### (2) 最初 20 項の中で 5 の倍数である項の個数と総和 $S$
$1 \le n \le 20$ において、5 の倍数となる $n$ を数える：
- $n = 5k - 2$ の場合：$k = 1, 2, 3, 4$ のとき $n = 3, 8, 13, 18$（4個）。
- $n = 5k - 3$ の場合：$k = 1, 2, 3, 4$ のとき $n = 2, 7, 12, 17$（4個）。
これらは互いに重複しないため、対象となる項の個数は：
$$4 + 4 = \mathbf{8} \text{ 個}$$
よって、$\mathbf{J = 8}$。

各 $k \in \{1, 2, 3, 4\}$ に対し、該当する 2 項の和をまとめると：
$$5(20k^2 - 11k) + 5(20k^2 - 19k + 3) = 5(40k^2 - 30k + 3)$$
したがって、総和 $S$ は次のように 1 つのシグマ記号で表せる：
$$S = \sum_{k=1}^{\mathbf{4}} \mathbf{5(40k^2 - 30k + 3)}$$
上限は $K = 4$、被加数式は選択肢 $\textcircled{6}$ である。
よって、$\mathbf{K = 4, L = 6}$。

この和を計算する：
- $k = 1$: $5(40 - 30 + 3) = 5 \times 13 = 65$
- $k = 2$: $5(160 - 60 + 3) = 5 \times 103 = 515$
- $k = 3$: $5(360 - 90 + 3) = 5 \times 273 = 1365$
- $k = 4$: $5(640 - 120 + 3) = 5 \times 523 = 2615$
総和は：
$$S = 65 + 515 + 1365 + 2615 = \mathbf{4560}$$
これは選択肢 $\textcircled{2}$ に一致する。よって、$\mathbf{M = 2}$。

**【解法テクニック・易錯点】**
- 2つの合同類 $n \equiv 2, 3 \pmod 5$ を $k=1$ から $4$ までの組としてペア化することで、シグマ計算を 1 つに統合して計算ミスを防止できます。

## 第II問 問2：複素数平面における回転・線対称と三角形の幾何量

**【考査考点】**：複素数の商と絶対値・偏角の計算, 複素数平面上の三角形の面積公式 $S = \frac{1}{2}|\alpha||\beta|\sin\theta$, 直線に関する対称点の複素数表示と正弦定理による角の正弦値

### 【第II問 問2】詳細解答と解説

#### (1) $|\beta|$ の算出
与えられた関係式は：
$$|\alpha| = \sqrt{10}, \quad 4(1+3i)\alpha - (7+i)\beta = 0$$
したがって、$\beta$ は次のように表される：
$$\beta = \frac{4(1+3i)}{7+i} \alpha$$
係数の複素数を簡単にする：
$$\frac{4(1+3i)}{7+i} = \frac{4(1+3i)(7-i)}{7^2 + 1^2} = \frac{4(7 - i + 21i + 3)}{50} = \frac{4(10 + 20i)}{50} = \frac{4}{5}(1+2i)$$
したがって：
$$\left|\frac{\beta}{\alpha}\right| = \frac{4}{5}|1+2i| = \frac{4}{5}\sqrt{1^2 + 2^2} = \frac{4\sqrt{5}}{5}$$
これより、$|\beta|$ は：
$$|\beta| = \frac{4\sqrt{5}}{5} |\alpha| = \frac{4\sqrt{5}}{5} \times \sqrt{10} = \frac{4\sqrt{50}}{5} = \frac{4 \times 5\sqrt{2}}{5} = \mathbf{4\sqrt{2}}$$
よって、$\mathbf{N = 4, O = 2}$（解答番号 $\mathbf{NO = 42}$）。

#### (2) $\frac{\beta}{\alpha}$ の偏角 $\theta$ と $\sin\theta$
$\frac{\beta}{\alpha} = \frac{4}{5}(1+2i)$ であるから：
$$\cos\theta + i\sin\theta = \frac{\beta / \alpha}{|\beta / \alpha|} = \frac{\frac{4}{5}(1+2i)}{\frac{4\sqrt{5}}{5}} = \frac{1+2i}{\sqrt{5}} = \frac{1}{\sqrt{5}} + \frac{2}{\sqrt{5}}i$$
虚部を比較して有理化すると：
$$\sin\theta = \frac{2}{\sqrt{5}} = \frac{\mathbf{2}\sqrt{\mathbf{5}}}{\mathbf{5}}$$
よって、$\mathbf{P = 2, Q = 5, R = 5}$（解答番号 $\mathbf{PQR = 255}$）。

#### (3) 三角形 OAB の面積
原点 O、点 A($\alpha$)、点 B($\beta$) が作る三角形 OAB の面積 $S$ は：
$$S = \frac{1}{2} |\alpha| |\beta| \sin\theta = \frac{1}{2} \times \sqrt{10} \times 4\sqrt{2} \times \frac{2}{\sqrt{5}} = \frac{1}{2} \times 4\sqrt{20} \times \frac{2}{\sqrt{5}} = 2 \times 2\sqrt{5} \times \frac{2}{\sqrt{5}} = \mathbf{8}$$
よって、$\mathbf{S = 8}$。

#### (4) 直線 OB に関する対称点 C の複素数表示
直線 OB は偏角 $\arg(\beta)$ の直線であり、$\arg(\beta) - \arg(\alpha) = \theta$ である。
点 A を直線 OB に関して対称移動した点 C は、OA と同じ長さ $|\gamma| = |\alpha|$ をもち、
偏角は $\arg(\alpha) + 2\theta$ となる（線対称の角移動量は $2\theta$）。
したがって、C は原点 O を中心として A を $\mathbf{2}\theta$ だけ回転させた点である。
よって、$\mathbf{T = 2}$。

回転を表す複素数は：
$$\cos 2\theta + i\sin 2\theta = (\cos\theta + i\sin\theta)^2 = \left(\frac{1+2i}{\sqrt{5}}\right)^2 = \frac{1 + 4i - 4}{5} = \frac{-3 + 4i}{5}$$
形式 $\gamma = \frac{-U + Vi}{W}\alpha$ と比較して：
$$\mathbf{U = 3, V = 4, W = 5}$$
よって、解答番号 $\mathbf{UVW = 345}$。

#### (5) $\sin\angle OBA = \sin\varphi$ の算出
三角形 OAB において、線分 AB の長さを求める：
$$\beta - \alpha = \left[\frac{4}{5}(1+2i) - 1\right]\alpha = \frac{-1 + 8i}{5}\alpha$$
$$|\beta - \alpha| = \frac{\sqrt{(-1)^2 + 8^2}}{5}|\alpha| = \frac{\sqrt{65}}{5} \times \sqrt{10} = \frac{\sqrt{650}}{5} = \frac{5\sqrt{26}}{5} = \sqrt{26}$$

三角形 OAB に正弦定理を適用すると：
$$\frac{OA}{\sin\varphi} = \frac{AB}{\sin\theta} \implies \sin\varphi = \frac{OA \cdot \sin\theta}{AB}$$
数値を代入すると：
$$\sin\varphi = \frac{\sqrt{10} \times \frac{2}{\sqrt{5}}}{\sqrt{26}} = \frac{2\sqrt{2}}{\sqrt{26}} = \frac{2}{\sqrt{13}} = \frac{\mathbf{2}\sqrt{\mathbf{13}}}{\mathbf{13}}$$
形式 $\frac{X\sqrt{YZ}}{YZ}$ と比較すると、$X = 2, Y = 1, Z = 3$ である。
よって、$\mathbf{XYZ = 213}$。

## 第III問 [1]：対数関数の置換による3次関数の導出と導関数の構造

**【考査考点】**：対数法則と置換 $t = \log_4 x, p = \log_4 a, q = \log_4 b$, 3次多項式 $g(t) = t^3 + 3(p+q)t^2 + 3(p^2-q^2)t$ の導出, 導関数の因数分解構造 $g'(t) = 3\{t^2 + 2(p+q)t + (p^2-q^2)\}$

### 【第III問 [1]】詳細解答と解説

#### (1) 対数関数の置換と多項式 $g(t)$ の導出
与えられた $x$ の関数は：
$$y = (\log_4 a^3)(\log_4 x)(\log_4 ax) + (\log_4 b^3)\left(\log_4 \frac{x}{b}\right)(\log_4 x) + (\log_4 x)^3$$
$\log_4 a = p, \log_4 b = q, \log_4 x = t$ とおくと：
- $\log_4 a^3 = 3\log_4 a = 3p$
- $\log_4 ax = \log_4 a + \log_4 x = p + t$
- $\log_4 b^3 = 3\log_4 b = 3q$
- $\log_4 \frac{x}{b} = \log_4 x - \log_4 b = t - q$

これらを代入して整理する：
$$y = (3p) \cdot t \cdot (p + t) + (3q) \cdot (t - q) \cdot t + t^3$$
$$y = t^3 + 3pt(t + p) + 3qt(t - q)$$
$$y = t^3 + 3pt^2 + 3p^2 t + 3qt^2 - 3q^2 t$$
$$y = t^3 + \mathbf{3(p + q)} t^2 + \mathbf{3(p^2 - q^2)} t$$

問題文の選択肢一覧：
- $\textcircled{0}: p - q, \quad \textcircled{1}: 2(p - q), \quad \textcircled{2}: 3(p - q)$
- $\textcircled{3}: p^2 - q^2, \quad \textcircled{4}: 3(p^2 - q^2)$
- $\textcircled{5}: p + q, \quad \textcircled{6}: 2(p + q), \quad \textcircled{7}: 3(p + q)$
- $\textcircled{8}: p^2 + q^2, \quad \textcircled{9}: 3(p^2 + q^2)$

形式 $y = t^3 + [A]t^2 + [B]t$ と比較すると：
- $A$ は $3(p + q)$ であるから、選択肢 $\textcircled{7}$。
- $B$ は $3(p^2 - q^2)$ であるから、選択肢 $\textcircled{4}$。
よって、$\mathbf{A = 7, B = 4}$（解答番号 $\mathbf{AB = 74}$）。

#### (2) 導関数 $g'(t)$ の導出
この右辺を $g(t)$ とおいて $t$ で微分する：
$$\frac{dy}{dt} = g'(t) = 3t^2 + 6(p + q)t + 3(p^2 - q^2)$$
共通因数 3 でくくると：
$$g'(t) = \mathbf{3}\left\{ t^2 + \mathbf{2(p + q)}t + \mathbf{(p^2 - q^2)} \right\}$$
形式 $C\{t^2 + Dt + E\}$ と比較すると：
- $C = 3$
- $D$ は $2(p+q)$ であるから、選択肢 $\textcircled{6}$。
- $E$ は $p^2 - q^2$ であるから、選択肢 $\textcircled{3}$。
よって、$\mathbf{C = 3, D = 6, E = 3}$（解答番号 $\mathbf{CDE = 363}$）。

#### (3) 極値をとる $t$ の値と関係式
$x$ の関数 $y$ が極値をとるとき、$\frac{dy}{dx} = \frac{dy}{dt} \frac{dt}{dx} = g'(t) \frac{1}{x \ln 4} = 0$ より、$g'(t) = 0$ となる。
条件より、極値をとる $x$ は $x = \frac{1}{2}$ と $x = 8$ であるから：
- $x = \frac{1}{2}$ のとき：$t = \log_4 \frac{1}{2} = \log_4 2^{-1} = -\frac{\mathbf{1}}{\mathbf{2}}$
  よって、$\mathbf{FG = 12}$。
- $x = 8$ のとき：$t = \log_4 8 = \log_4 2^3 = \frac{\mathbf{3}}{\mathbf{2}}$
  よって、$\mathbf{HI = 32}$。

これらは 2次方程式 $t^2 + Dt + E = 0$ の解であるから：
1. $t = -\frac{1}{2}$ を代入：
   $$\left(-\frac{1}{2}\right)^2 - \frac{1}{2}D + E = 0 \implies \frac{\mathbf{1}}{\mathbf{4}} - \mathbf{(p + q)} + E = 0$$
   形式 $\frac{J}{K} - L + E = 0$ より、$J = 1, K = 4$ であり、$L = p+q$（選択肢 $\textcircled{5}$）である。
   よって、$\mathbf{JKL = 145}$。

2. $t = \frac{3}{2}$ を代入：
   $$\left(\frac{3}{2}\right)^2 + \frac{3}{2}D + E = 0 \implies \frac{\mathbf{9}}{\mathbf{4}} + \mathbf{3(p + q)} + E = 0$$
   形式 $\frac{M}{N} + O + E = 0$ より、$M = 9, N = 4$ であり、$O = 3(p+q)$（選択肢 $\textcircled{7}$）である。
   よって、$\mathbf{MNO = 947}$。

## 第III問 [2]：解と係数の関係による定数決定と極値の差

**【考査考点】**：解と係数の関係による $p+q$ および $p^2-q^2$ の決定, 連立一次方程式から $p, q$ および定数 $a, b$ の導出, 3次関数の極値の差 $|m_1 - m_2| = \frac{|a|}{2}(\beta - \alpha)^3$

### 【第III問 [2]】詳細解答と解説

#### (1) $p, q$ および定数 $a, b$ の決定
2次方程式 $t^2 + 2(p+q)t + (p^2 - q^2) = 0$ の 2 つの実数解が $t = -\frac{1}{2}$ と $t = \frac{3}{2}$ である。
解と係数の関係を適用する：
- 解の和：
  $$\left(-\frac{1}{2}\right) + \frac{3}{2} = 1 = -2(p+q) \implies p + q = -\frac{1}{2}$$
- 解の積：
  $$\left(-\frac{1}{2}\right) \times \frac{3}{2} = -\frac{3}{4} = p^2 - q^2 = (p+q)(p-q)$$

$p+q = -\frac{1}{2}$ を代入すると：
$$\left(-\frac{1}{2}\right)(p - q) = -\frac{3}{4} \implies p - q = \frac{3}{2}$$

これらを足し引きして $p$ と $q$ を解く：
- 和：$2p = -\frac{1}{2} + \frac{3}{2} = 1 \implies p = \frac{\mathbf{1}}{\mathbf{2}}$
  よって、$\mathbf{P = 1, Q = 2}$（解答番号 $\mathbf{PQ = 12}$）。
- 差：$2q = -\frac{1}{2} - \frac{3}{2} = -2 \implies q = \mathbf{-1}$
  よって、$\mathbf{RS = -1}$。

これらから定数 $a, b$ を求める：
$$a = 4^p = 4^{1/2} = \mathbf{2}$$
よって、$\mathbf{T = 2}$。
$$b = 4^q = 4^{-1} = \frac{\mathbf{1}}{\mathbf{4}}$$
よって、$\mathbf{UV = 14}$。

#### (2) 極値の差 $|m_1 - m_2|$ の算出
$g(t)$ の極値 $m_1 = g(-1/2), m_2 = g(3/2)$ の差の絶対値は、導関数の積分に等しい：
$$|m_1 - m_2| = \left| \int_{-1/2}^{3/2} g'(t) dt \right|$$
$g'(t) = 3\left(t + \frac{1}{2}\right)\left(t - \frac{3}{2}\right)$ であり、区間 $[-1/2, 3/2]$ で $g'(t) \le 0$ であるから：
$$|m_1 - m_2| = -\int_{-1/2}^{3/2} 3\left(t + \frac{1}{2}\right)\left(t - \frac{3}{2}\right) dt = 3 \int_{-1/2}^{3/2} \left(t + \frac{1}{2}\right)\left(\frac{3}{2} - t\right) dt$$
2次関数の定積分公式（$\frac{1}{6}$ 公式）を用いる：
$$\int_{\alpha}^{\beta} (x - \alpha)(\beta - x) dx = \frac{(\beta - \alpha)^3}{6}$$
ここで $\beta - \alpha = \frac{3}{2} - \left(-\frac{1}{2}\right) = 2$ であるから：
$$|m_1 - m_2| = 3 \times \frac{2^3}{6} = 3 \times \frac{8}{6} = \mathbf{4}$$
よって、$\mathbf{W = 4}$。

**【解法テクニック・易錯点】**
- 3次関数の極大値と極小値の差は、一般に $\frac{|k|}{2}(\beta - \alpha)^3$（$k$ は最高次の係数、ここでは $k=1$ なので $\frac{1}{2} \times 2^3 = 4$）という美しい公式が成り立ちます。直接 $g(t)$ に代入する手間を省いて瞬時に検算可能です。

## 第IV問 [1]：有理関数の接線方程式と導関数による増減表

**【考査考点】**：商の微分法による曲線 $y = \frac{x-2}{x^2}$ の導関数導出, 点 $(t, f(t))$ における接線方程式と通過点 $(1, a)$ の代入, 接点 $t$ の関数 $f(t) = \frac{2t^2-7t+4}{t^3}$ の微分と増減の判定

### 【第IV問 [1]】詳細解答と解説

#### (1) 接線の方程式の導出
点 $(1, a)$ を通って、曲線 $y = \frac{x-2}{x^2}$ にちょうど 3 本の接線が引けるような $a$ の範囲を求める。
曲線上の接点の座標を $\left(t, \frac{t-2}{t^2}\right)$（$t \neq 0$）とおく。
$y = x^{-1} - 2x^{-2}$ を微分すると：
$$y' = -x^{-2} + 4x^{-3} = \frac{-x + 4}{x^3} = -\frac{x - 4}{x^3}$$
したがって、接線の方程式は：
$$y - \frac{t-2}{t^2} = -\frac{t-4}{t^3}(x - t)$$
右辺を展開して整理する：
$$y = -\frac{t - 4}{t^3} x + \frac{t - 4}{t^2} + \frac{t - 2}{t^2} = -\frac{t - \mathbf{4}}{t^3} x + \frac{\mathbf{2}t - \mathbf{6}}{t^2}$$
形式 $y = -\frac{t - A}{t^3}x + \frac{Bt - C}{t^2}$ と比較すると：
$$A = 4, \quad B = 2, \quad C = 6$$
よって、$\mathbf{ABC = 426}$。

#### (2) 通過点 $(1, a)$ の代入と $t$ の方程式
この接線が点 $(1, a)$ を通るので、$(x, y) = (1, a)$ を代入する：
$$a = -\frac{t - 4}{t^3}(1) + \frac{2t - 6}{t^2} = \frac{-(t - 4) + t(2t - 6)}{t^3} = \frac{-t + 4 + 2t^2 - 6t}{t^3} = \frac{\mathbf{2}t^2 - \mathbf{7}t + \mathbf{4}}{t^3} \quad \dots \text{①}$$
形式 $a = \frac{Dt^2 - Et + F}{t^3}$ と比較すると：
$$D = 2, \quad E = 7, \quad F = 4$$
よって、$\mathbf{DEF = 274}$。

#### (3) 関数 $f(t)$ の微分と増減の判定
3 本の接線が引ける条件は、$t$ に関する方程式 ① が異なる 3 つの実数解をもつことである。
$$f(t) = \frac{2t^2 - 7t + 4}{t^3}$$
とおき、$f(t)$ を微分する。商の微分法により：
$$f'(t) = \frac{(4t - 7)t^3 - (2t^2 - 7t + 4)(3t^2)}{t^6} = \frac{(4t - 7)t - 3(2t^2 - 7t + 4)}{t^4}$$
分子を展開して整理する：
$$(4t^2 - 7t) - (6t^2 - 21t + 12) = -2t^2 + 14t - 12 = -2(t^2 - 7t + 6) = -2(t - 1)(t - 6)$$
したがって：
$$f'(t) = -\frac{2(t - \mathbf{1})(t - \mathbf{6})}{t^4}$$
条件 $G < H$ より、$G = 1, H = 6$ である。
よって、$\mathbf{GH = 16}$。

分母 $t^4 > 0$（$t \neq 0$）であるから、$f'(t)$ の符号は分子の符号 $-2(t-1)(t-6)$ に一致する。
境界となる点は $t = 0, 1, 6$ であるから、各区間での増減は以下の通りとなる：
- $t < \mathbf{0}$（$I = 0$）のとき：$-2(-)(- ) < 0$ より $f'(t) < 0$（**減少**：選択肢 $\textcircled{3}$）。
  よって、$\mathbf{I = 0, J = 3}$。
- $\mathbf{0} < t < \mathbf{1}$（$K = 1$）のとき：$-2(-)(-) < 0$ より $f'(t) < 0$（**減少**：選択肢 $\textcircled{3}$）。
  よって、$\mathbf{K = 1, L = 3}$。
- $\mathbf{1} < t < \mathbf{6}$（$M = 6$）のとき：$-2(+)(-) > 0$ より $f'(t) > 0$（**増加**：選択肢 $\textcircled{2}$）。
  よって、$\mathbf{M = 6, N = 2}$。
- $\mathbf{6} < t$ のとき：$-2(+)(+) < 0$ より $f'(t) < 0$（**減少**：選択肢 $\textcircled{3}$）。
  よって、$\mathbf{O = 3}$。

## 第IV問 [2]：関数の極限と方程式の実数解個数（3本の接線条件）

**【考査考点】**：有理関数の無限遠および原点付近の極限, 極値の計算 $f(1) = -1, f(6) = \frac{17}{108}$, 定数分離法による直線 $y = a$ と曲線 $y = f(t)$ の交点個数と $a$ の範囲決定

### 【第IV問 [2]】詳細解答と解説

#### (1) 関数 $f(t)$ の極限の計算
$f(t) = \frac{2t^2 - 7t + 4}{t^3} = \frac{2}{t} - \frac{7}{t^2} + \frac{4}{t^3}$ の極限を求める：
- 無限遠での極限：
  $$\lim_{t \to \infty} f(t) = \lim_{t \to -\infty} f(t) = \mathbf{0}$$
  選択肢 $\textcircled{0}$ より、$\mathbf{P = 0}$。
- $t \to +0$ での右極限：
  分子は $4 > 0$、分母は $+0$ であるから：
  $$\lim_{t \to +0} f(t) = \mathbf{+\infty}$$
  選択肢 $\textcircled{4}$ より、$\mathbf{Q = 4}$。
- $t \to -0$ での左極限：
  分子は $4 > 0$、分母は $-0$ であるから：
  $$\lim_{t \to -0} f(t) = \mathbf{-\infty}$$
  選択肢 $\textcircled{5}$ より、$\mathbf{R = 5}$。

#### (2) 極値の計算とグラフの全体像
増減表に基づき、極値を計算する：
- $t = 1$ で極小値：
  $$f(1) = \frac{2(1)^2 - 7(1) + 4}{1^3} = \frac{2 - 7 + 4}{1} = -1$$
- $t = 6$ で極大値：
  $$f(6) = \frac{2(36) - 7(6) + 4}{216} = \frac{72 - 42 + 4}{216} = \frac{34}{216} = \frac{17}{108}$$

各区間における値域と単調性：
1. $t \in (-\infty, 0)$：$0$ から $-\infty$ まで単調減少。値域は $(-\infty, 0)$。
2. $t \in (0, 1]$：$+\infty$ から極小値 $-1$ まで単調減少。
3. $t \in [1, 6]$：極小値 $-1$ から極大値 $\frac{17}{108}$ まで単調増加。
4. $t \in [6, \infty)$：極大値 $\frac{17}{108}$ から $0$ まで単調減少。

#### (3) 3 本の接線が引ける $a$ の範囲の決定
方程式 $f(t) = a$ の実数解の個数は、曲線 $y = f(t)$ と水平直線 $y = a$ の共有点の個数に等しい。
共有点がちょうど 3 個となる $a$ の範囲を調べる：

**(i) $a < 0$ の場合**
- 区間 $t < 0$ において、値域は $(-\infty, 0)$ であり単調減少であるから、任意の実数 $a < 0$ に対しちょうど 1 つの共有点をもつ。
- したがって、3 本の接線をもつためには、区間 $t > 0$ において残る 2 つの共有点をもつ必要がある。
- $t > 0$ における極小値は $-1$ であり、$t \to +\infty$ で $f(t) \to 0$ である。
- よって、$-1 < a < 0$ のとき、区間 $(0, 1)$ で 1 個、区間 $(1, \infty)$ で 1 個の計 2 個の共有点をもつ。
したがって、このときの実数解は $t < 0$ から 1 個、$t > 0$ から 2 個の計 3 個となる！
範囲：$\mathbf{-1 < a < 0}$
形式 $-S < a < T$ と比較して：
$$\mathbf{S = 1, T = 0}$$

**(ii) $a > 0$ の場合**
- 区間 $t < 0$ においては $f(t) < 0$ であるため、$a > 0$ との共有点は存在しない（0個）。
- したがって、3 つの共有点はすべて区間 $t > 0$ に存在しなければならない。
- $t > 0$ において、関数は $+\infty$ から $-1$ に下がり、$\frac{17}{108}$ に上がり、そこから $0$ に収束する。
- 直線 $y = a$ が 3 回交差するためには、水平漸近線 $y = 0$ と極大値 $y = \frac{17}{108}$ の間にある必要がある：
  $$0 < a < \frac{17}{108}$$
  このとき：
  - 区間 $(0, 1)$ で 1 個（$+\infty \to -1$ の途中）
  - 区間 $(1, 6)$ で 1 個（$-1 \to 17/108$ の途中）
  - 区間 $(6, \infty)$ で 1 個（$17/108 \to 0$ の途中）
  計 3 個の共有点をもつ！
範囲：$\mathbf{0 < a < \frac{17}{108}}$
形式 $U < a < \frac{VW}{XYZ}$ と比較して：
$$\mathbf{U = 0, VW = 17, XYZ = 108}$$
よって、解答番号 $\mathbf{VWXYZ = 17108}$。

**【解法テクニック・易錯点】**
- $t < 0$ の枝は負の値しかとらないため、$a < 0$ のときは負の側で 1 解、正の側で 2 解となります。一方 $a > 0$ では負の側で解をもたないため、正の側で 3 解すべてをまかなう必要があります。この枝ごとの符号の違いを見落とさないことが極めて重要です。
