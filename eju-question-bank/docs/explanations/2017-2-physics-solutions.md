## 問1：3本の糸による小球のつり合いと張力の計算
- **解答番号**：PHYSICS:1
- **正解**：`1`
- **重要論点**：
  - 鉛直・水平方向の力の成分分解
  - 2本の天井からの糸と小球の重力のつり合い方程式
  - 張力 Ta の導出

**【題目大意】**
天井から鉛直方向とそれぞれ $60^\circ$, $30^\circ$ をなす2本の軽い糸 a, b でつるされた質量 $m$ の小球がある。糸 a の張力 $T_a$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$\frac{1}{2}mg$）

**【詳細推導・解答プロセス】**
糸 a, b の張力をそれぞれ $T_a, T_b$ とする。
小球にはたらく力は、糸 a の張力 $T_a$、糸 b の張力 $T_b$、および鉛直下向きの重力 $mg$ である。
水平方向の力のつり合いより：
$$T_a \sin 60^\circ = T_b \sin 30^\circ$$
$$T_a \frac{\sqrt{3}}{2} = T_b \frac{1}{2} \implies T_b = \sqrt{3} T_a$$

鉛直方向の力のつり合いより：
$$T_a \cos 60^\circ + T_b \cos 30^\circ = mg$$
$$T_a \frac{1}{2} + (\sqrt{3}T_a) \frac{\sqrt{3}}{2} = mg$$
$$\frac{1}{2}T_a + \frac{3}{2}T_a = 2T_a = mg \implies T_a = \frac{1}{2}mg$$

よって、正解は選択肢 $\textcircled{1}$ である。

## 問2：粗い斜面上の物体が滑り出す限界の引張力 F₀
- **解答番号**：PHYSICS:2
- **正解**：`2`
- **重要論点**：
  - 斜面方向と垂直方向の力の分解
  - 最大静止摩擦力と運動の開始条件
  - 下向き滑落の限界における力のつり合い

**【題目大意】**
傾角 $\theta$ の粗い斜面上の質量 $m$ の小物体に、斜面に沿って上向きに力 $F$ を加える。$F$ を徐々に小さくしていき、ある値 $F_0$ より小さくなったとき小物体が斜面を滑り始めた。$F_0$ を求めよ。

**【公式正解】**：$\textcircled{2}$（$mg(\sin\theta - \mu\cos\theta)$）

**【詳細推導・解答プロセス】**
斜面に垂直な方向の力のつり合いより、垂直抗力 $N$ は：
$$N = mg \cos\theta$$
最大静止摩擦力の大きさは $R_{\max} = \mu N = \mu mg \cos\theta$ である。
力 $F$ を小さくしていくと、小物体は斜面下方へ滑り出そうとする。
したがって、滑り始める直前（限界状態）では、静止摩擦力は斜面に沿って上向きに最大値 $\mu mg \cos\theta$ ではたらく。
斜面に沿った方向の力のつり合いより：
$$F_0 + \mu mg \cos\theta = mg \sin\theta$$
$$F_0 = mg(\sin\theta - \mu \cos\theta)$$

よって、正解は選択肢 $\textcircled{2}$ である。

## 問3：定滑車で連結された2物体の力学的エネルギー保存則
- **解答番号**：PHYSICS:3
- **正解**：`5`
- **重要論点**：
  - 2物体系の力学的エネルギー保存則の立式
  - 重力による位置エネルギーの変化量の差引
  - 落下高さ h と衝突直前の速さ v の関係

**【題目大意】**
定滑車にかけられた糸の両端に質量 $m$ の小物体 A と質量 $2m$ の小物体 B がつるされている。B を床から高さ $h$ の位置から静かにはなしたとき、B が床に衝突する直前の速さは $v$ であった。$h$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{3v^2}{2g}$）

**【詳細推導・解答プロセス】**
B が床に向かって距離 $h$ だけ下降するとき、糸で結ばれた A は鉛直上向きに距離 $h$ だけ上昇する。
系全体（A＋B）の力学的エネルギー保存則を適用する：
- 重力による位置エネルギーの変化：
  B の減少量 $= 2mgh$
  A の増加量 $= mgh$
  系全体の位置エネルギー減少量 $= 2mgh - mgh = mgh$
- 運動エネルギーの増加量：
  A と B の速さはともに $v$ であるから、
  $\Delta K = \frac{1}{2}mv^2 + \frac{1}{2}(2m)v^2 = \frac{3}{2}mv^2$
力学的エネルギー保存則より：
$$mgh = \frac{3}{2}mv^2 \implies h = \frac{3v^2}{2g}$$

よって、正解は選択肢 $\textcircled{5}$ である。

## 問4：静止物体の分裂における運動量保存則と運動エネルギー比
- **解答番号**：PHYSICS:4
- **正解**：`4`
- **重要論点**：
  - 運動量保存則による速度比の導出
  - 運動エネルギーの公式 K = p^2 / (2m)
  - 運動エネルギー比の質量逆比特性

**【題目大意】**
静止していた物体が2つの物体 A（質量 $m_A$, 速さ $v_A$, 運動エネルギー $K_A$）と B（質量 $m_B$, 速さ $v_B$, 運動エネルギー $K_B$）に分裂した。$\frac{v_A}{v_B}$ と $\frac{K_A}{K_B}$ を求めよ。

**【公式正解】**：$\textcircled{4}$（$\frac{v_A}{v_B} = \frac{m_B}{m_A}, \quad \frac{K_A}{K_B} = \frac{m_B}{m_A}$）

**【詳細推導・解答プロセス】**
分裂前後で外力ははたらかないため、運動量保存則が成り立つ。
初めの全運動量は 0 であるから：
$$m_A v_A - m_B v_B = 0 \implies m_A v_A = m_B v_B$$
$$\frac{v_A}{v_B} = \frac{m_B}{m_A}$$

次に、運動エネルギーの比を計算する：
$$\frac{K_A}{K_B} = \frac{\frac{1}{2}m_A v_A^2}{\frac{1}{2}m_B v_B^2} = \frac{m_A}{m_B} \left(\frac{v_A}{v_B}\right)^2 = \frac{m_A}{m_B} \left(\frac{m_B}{m_A}\right)^2 = \frac{m_B}{m_A}$$
（あるいは、運動量 $p = m_A v_A = m_B v_B$ が等しいことから $K = \frac{p^2}{2m}$ より直ちに $\frac{K_A}{K_B} = \frac{m_B}{m_A}$ と求まる）。

よって、正解は選択肢 $\textcircled{4}$ である。

## 問5：水平ばね振り子の単振動における力学的エネルギー保存則
- **解答番号**：PHYSICS:5
- **正解**：`6`
- **重要論点**：
  - 振幅 d と自然長通過時の最大速度 v0 の関係
  - 速さが v0/2 のときの位置エネルギーと変位 x
  - 力学的エネルギー保存則の計算

**【題目大意】**
自然長から距離 $d$ 引いてはなしたばね振り子が振幅 $d$ の単振動をする。自然長通過時の速さは $v_0$ である。速さが $\frac{v_0}{2}$ のときの自然長からの距離 $x$ を求めよ。

**【公式正解】**：$\textcircled{6}$（$\frac{\sqrt{3}}{2}d$）

**【詳細推導・解答プロセス】**
ばね定数を $k$、小球の質量を $m$ とする。
単振動における力学的エネルギー保存則より：
$$E = \frac{1}{2}kd^2 = \frac{1}{2}mv_0^2$$
小球の速さが $v = \frac{v_0}{2}$ であるとき、変位を $x$ とすると：
$$\frac{1}{2}mv^2 + \frac{1}{2}kx^2 = E$$
$$\frac{1}{2}m\left(\frac{v_0}{2}\right)^2 + \frac{1}{2}kx^2 = \frac{1}{2}mv_0^2$$
$$\frac{1}{4}\left(\frac{1}{2}mv_0^2\right) + \frac{1}{2}kx^2 = \frac{1}{2}mv_0^2$$
$$\frac{1}{2}kx^2 = \frac{3}{4}\left(\frac{1}{2}mv_0^2\right) = \frac{3}{4}\left(\frac{1}{2}kd^2\right)$$
両辺を比較して：
$$x^2 = \frac{3}{4}d^2 \implies x = \frac{\sqrt{3}}{2}d$$

よって、正解は選択肢 $\textcircled{6}$ である。

## 問6：ケプラーの第2法則（面積速度一定の法則）と楕円軌道の速度比
- **解答番号**：PHYSICS:6
- **正解**：`3`
- **重要論点**：
  - 楕円軌道の幾何学的性質（長半径 a, 短半径 b, 焦点距離 c）
  - 近地点および短軸頂点における位置ベクトルと速度の内積
  - 面積速度一定則を用いた速度比 v1/v0 の算出

**【題目大意】**
地球を焦点とする長軸 $10r$、短軸 $6r$ の楕円軌道を周回する人工衛星がある。近地点距離が $r$ で速さが $v_0$、短軸上の位置を通過するときの速さが $v_1$ であるとき、$\frac{v_1}{v_0}$ を求めよ。

**【公式正解】**：$\textcircled{3}$（$\frac{1}{3}$）

**【詳細推導・解答プロセス】**
楕円の幾何学的寸法を整理する：
- 半長軸：$a = \frac{10r}{2} = 5r$
- 半短軸：$b = \frac{6r}{2} = 3r$
- 中心から焦点までの距離：$c = \sqrt{a^2 - b^2} = \sqrt{(5r)^2 - (3r)^2} = 4r$
地球（焦点）から近地点までの距離は $a - c = 5r - 4r = r$ であり問題文と整合する。

ケプラーの第2法則（中心力場における角運動量保存則 / 面積速度一定の法則）を適用する：
1. **近地点**：速度ベクトル $\vec{v}_0$ は動径ベクトル $\vec{r}$ と直交するため、面積速度は：
   $$S_0 = \frac{1}{2} r v_0$$
2. **短軸頂点**：楕円の幾何学的性質により、短軸の端点における接線は長軸と平行である。
   したがって、焦点（地球）から短軸端点における速度ベクトル $\vec{v}_1$ の作用線（長軸に平行な直線）までの垂直距離は、まさに半短軸の長さ $b = 3r$ に等しい。
   したがって、短軸頂点における面積速度は：
   $$S_1 = \frac{1}{2} b v_1 = \frac{1}{2} (3r) v_1$$
面積速度が一定であることから：
$$\frac{1}{2} r v_0 = \frac{1}{2} (3r) v_1 \implies r v_0 = 3r v_1 \implies \frac{v_1}{v_0} = \frac{1}{3}$$

よって、正解は選択肢 $\textcircled{3}$ である。

## 問7：氷の融解を伴う熱平衡状態と最終温度の計算
- **解答番号**：PHYSICS:7
- **正解**：`2`
- **重要論点**：
  - 氷の融解熱（潜熱）の計算
  - 水が放出する熱量と氷が吸収する熱量の熱量保存則
  - 最終温度の算出

**【題目大意】**
断熱容器内の $30^\circ\text{C}$ の水 $1000\text{ g}$ に、$0^\circ\text{C}$ の氷 $200\text{ g}$ を投入した。熱平衡に達した後の温度を求めよ（氷の融解熱 $330\text{ J/g}$、水の比熱 $4.2\text{ J/(g}\cdot\text{K)}$）。

**【公式正解】**：$\textcircled{2}$（$12^\circ\text{C}$）

**【詳細推導・解答プロセス】**
1. $0^\circ\text{C}$ の氷 $200\text{ g}$ をすべて融解させて $0^\circ\text{C}$ の水にするのに必要な熱量 $Q_1$：
   $$Q_1 = 200\text{ g} \times 330\text{ J/g} = 66000\text{ J}$$
2. $30^\circ\text{C}$ の水 $1000\text{ g}$ が $0^\circ\text{C}$ まで冷えるときに放出できる最大熱量 $Q_2$：
   $$Q_2 = 1000\text{ g} \times 4.2\text{ J/(g}\cdot\text{K)} \times (30 - 0) = 126000\text{ J}$$
$Q_2 > Q_1$ であるから、氷はすべて融解し、最終温度 $T$ は $0^\circ\text{C} < T < 30^\circ\text{C}$ となる。

3. 熱量の保存則を立てる：
   （水 $1000\text{ g}$ が失った熱量）$=$（氷が融解する熱量）$+$（融解した水 $200\text{ g}$ が $T$ まで上昇する熱量）
   $$1000 \times 4.2 \times (30 - T) = 66000 + 200 \times 4.2 \times (T - 0)$$
   $$4200(30 - T) = 66000 + 840T$$
   $$126000 - 4200T = 66000 + 840T$$
   $$5040T = 60000 \implies T = \frac{60000}{5040} = \frac{250}{21} \approx 11.9^\circ\text{C}$$
最も適当な整数値は $12^\circ\text{C}$ である。

よって、正解は選択肢 $\textcircled{2}$ である。

## 問8：連結ピストンで結合された2気室の圧力平衡と温度比
- **解答番号**：PHYSICS:8
- **正解**：`5`
- **重要論点**：
  - 滑らかに動く連結ピストンの力のつり合いによる圧力一致条件
  - 気体の状態方程式と体積変化の関係
  - 温度比 TA/TB の計算

**【題目大意】**
向かい合った同じシリンダー A（$0.20\text{ mol}$）と B（$0.60\text{ mol}$）のピストンが共通の軸で連結されている。初め同温・同圧であったが、A を加熱したところ A の体積が初めの $1.5$ 倍になった。このときの温度比 $\frac{T_A}{T_B}$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$1.8$）

**【詳細推導・解答プロセス】**
1. **初期状態**：
   A, B の初めの圧力を $p_0$、温度を $T_0$ とすると、状態方程式より体積はモル数に比例する：
   $$V_{A0} = \frac{0.20 R T_0}{p_0}, \quad V_{B0} = \frac{0.60 R T_0}{p_0} = 3 V_{A0}$$
   全シリンダーの有効総体積は $V_{\text{total}} = V_{A0} + V_{B0} = 4 V_{A0}$ である。

2. **加熱後の状態**：
   A の体積が $1.5$ 倍になったので：
   $$V_A = 1.5 V_{A0}$$
   ピストンが剛体軸で連結されているため、B の体積は：
   $$V_B = V_{\text{total}} - V_A = 4 V_{A0} - 1.5 V_{A0} = 2.5 V_{A0}$$
   ピストンは摩擦なく滑らかに動くため、静止後の平衡状態では両室の気体の圧力がつり合っている：$p_A = p_B = p$。

3. **温度比の算出**：
   状態方程式より：
   $$T_A = \frac{p V_A}{n_A R} = \frac{p (1.5 V_{A0})}{0.20 R}, \quad T_B = \frac{p V_B}{n_B R} = \frac{p (2.5 V_{A0})}{0.60 R}$$
   したがって、温度比は：
   $$\frac{T_A}{T_B} = \frac{\frac{1.5}{0.20}}{\frac{2.5}{0.60}} = \frac{1.5}{0.20} \times \frac{0.60}{2.5} = 7.5 \times 0.24 = 1.8$$

よって、正解は選択肢 $\textcircled{5}$ である。

## 問9：気体の状態変化（V-T図からp-V図への変換）
- **解答番号**：PHYSICS:9
- **正解**：`8`
- **重要論点**：
  - V-T 図における原点を通る直線の等圧線的意味
  - 等温変化・定積変化の p-V 線図への対応
  - サイクルの各状態点の対応付け

**【題目大意】**
理想気体の $V-T$ 図におけるサイクル $A \rightarrow B \rightarrow C \rightarrow D \rightarrow A$ を $p-V$ 図へ対応させたときの状態変化の順序を選べ。

**【公式正解】**：$\textcircled{8}$（$d \rightarrow c \rightarrow b \rightarrow a \rightarrow d$）

**【詳細推導・解答プロセス】**
理想気体の状態方程式 $pV = nRT \implies V = \left(\frac{nR}{p}\right)T$ より：
- $V-T$ 図において、原点を通る直線は **等圧変化** を表し、その傾き $\frac{nR}{p}$ が小さいほど圧力 $p$ は高い。
- 水平線は **定積変化**（$V = \text{const}$）を表す。
- 鉛直線は **等温変化**（$T = \text{const}$）を表す。

$V-T$ 図の各状態点 $A, B, C, D$ の圧力・体積を評価し、$p-V$ 図上の点 $a, b, c, d$ と照合する：
状態 A は点 d に、状態 B は点 c に、状態 C は点 b に、状態 D は点 a に対応する。
したがって、$A \rightarrow B \rightarrow C \rightarrow D \rightarrow A$ の変化は、$p-V$ 図上では $d \rightarrow c \rightarrow b \rightarrow a \rightarrow d$ となる。

よって、正解は選択肢 $\textcircled{8}$ である。

## 問10：進行波の波形グラフから媒質の速度ベクトルの判定
- **解答番号**：PHYSICS:10
- **正解**：`2`
- **重要論点**：
  - 波の伝播方向と媒質の運動方向の関係
  - 波形微小平行移動法による媒質変位の増減判定
  - 媒質の速度公式 vy = -v (dy/dx) による最大速度点の特定

**【題目大意】**
$x$ 軸正の向きに伝わる横波の波形グラフにおいて、媒質の速度が $y$ 軸の負の向きに最大である位置を選べ。

**【公式正解】**：$\textcircled{2}$（B）

**【詳細推導・解答プロセス】**
波の伝播に伴う媒質の速度 $v_y$ を求める：
波が速さ $v$ で $x$ 軸の正の向きに進むとき、波の式 $y(x, t) = f(x - vt)$ より：
$$v_y = \frac{\partial y}{\partial t} = -v f'(x - vt) = -v \frac{\partial y}{\partial x}$$
したがって、媒質の速度が $y$ 軸の負の向きに最大（$v_y < 0$ で大きさが最大）となるのは、波形の傾き $\frac{\partial y}{\partial x}$ が **正で最大** となる位置である。

各点の波形グラフの傾きを確認する：
- 位置 A（山）：傾き 0 $\implies v_y = 0$
- 位置 C（谷）：傾き 0 $\implies v_y = 0$
- 位置 B（山と谷の間で上り坂）：傾きが正で最大 $\implies v_y$ は負の向きに最大
- 位置 O, D：傾きが負 $\implies v_y$ は正の向き

よって、正解は選択肢 $\textcircled{2}$ である。

## 問11：超音波の反射によるドップラー効果と物体の接近速度
- **解答番号**：PHYSICS:11
- **正解**：`5`
- **重要論点**：
  - 観測者（移動物体）が受ける振動数 f1 の導出
  - 反射源（移動物体）から静止測定器へ届く振動数 f の導出
  - 接近速度 v の代数解法

**【題目大意】**
静止した装置が振動数 $f_0$ の超音波（音速 $V$）を速さ $v$ で近づく物体に向けて発し、反射波の振動数を測定したところ $f$ であった。物体の速さ $v$ を求めよ。

**【公式正解】**：$\textcircled{5}$（$\frac{f - f_0}{f + f_0}V$）

**【詳細推導・解答プロセス】**
ドップラー効果を2段階で解析する：
1. **第1段階（物体が音波を受ける）**：
   静止音源（装置）から、速さ $v$ で近づく観測者（物体）が受ける振動数 $f_1$ は：
   $$f_1 = \frac{V + v}{V} f_0$$
2. **第2段階（物体が音波を反射して装置が受ける）**：
   物体は振動数 $f_1$ で振動する音源として速さ $v$ で静止観測者（装置）に近づきながら音波を出す。装置が受け取る振動数 $f$ は：
   $$f = \frac{V}{V - v} f_1 = \frac{V}{V - v} \left(\frac{V + v}{V} f_0\right) = \frac{V + v}{V - v} f_0$$
3. **速さ $v$ の導出**：
   $$f(V - v) = f_0(V + v)$$
   $$fV - fv = f_0V + f_0v \implies (f + f_0)v = (f - f_0)V$$
   $$v = \frac{f - f_0}{f + f_0} V$$

よって、正解は選択肢 $\textcircled{5}$ である。

## 問12：くさび形空気層による光の干渉と暗線間隔の計算
- **解答番号**：PHYSICS:12
- **正解**：`3`
- **重要論点**：
  - くさび形薄膜の光路差 2d と反射に伴う位相の反転（固定端反射）
  - 暗線条件 2d = mλ
  - 幾何学的比例関係による縞の間隔 Δx の算出

**【題目大意】**
長さ $L = 300\text{ mm}$ のガラス板2枚を重ね、端に厚さ $D = 0.030\text{ mm}$ のすきまを開けた。波長 $\lambda = 600\text{ nm} = 6.0 \times 10^{-7}\text{ m}$ の単色光を垂直に入射したときの暗線間隔を求めよ。

**【公式正解】**：$\textcircled{3}$（$3.0\text{ mm}$）

**【詳細推導・解答プロセス】**
ガラス板の接触点からの距離を $x$ とすると、その位置における空気層の厚さ $d$ は：
$$d = \frac{D}{L} x$$
薄膜干渉において、下側ガラス上面での反射で位相が $\pi$ 反転（固定端反射）し、上側ガラス下面での反射では位相変化がない（自由端反射）。
したがって、干渉による暗線の条件は：
$$2d = m\lambda \quad (m = 0, 1, 2, \dots)$$
隣り合う暗線（$m$ と $m+1$）の空気層の厚さの差 $\Delta d$ は：
$$2\Delta d = \lambda \implies \Delta d = \frac{\lambda}{2}$$
暗線の間隔 $\Delta x$ は：
$$\Delta x = \frac{L}{D} \Delta d = \frac{L}{D} \frac{\lambda}{2} = \frac{L\lambda}{2D}$$
数値を代入する（単位を $\text{m}$ で揃える）：
- $L = 300\text{ mm} = 0.30\text{ m}$
- $D = 0.030\text{ mm} = 3.0 \times 10^{-5}\text{ m}$
- $\lambda = 6.0 \times 10^{-7}\text{ m}$
$$\Delta x = \frac{0.30 \times 6.0 \times 10^{-7}}{2 \times 3.0 \times 10^{-5}} = \frac{1.8 \times 10^{-7}}{6.0 \times 10^{-5}} = 3.0 \times 10^{-3}\text{ m} = 3.0\text{ mm}$$

よって、正解は選択肢 $\textcircled{3}$ である。

## 問14：静電場における電位の対称性と静電気力のする仕事

2点 $(-d, 0)$ と $(d, 0)$ に正電荷 $Q$ が固定されている。電荷 $q$ の点電荷 P を経路 (a), (b), (c) に沿って移動させたとき、静電気力がする仕事が 0 となる経路を選べ。

## 問15：コンデンサーの極板間隔変化・再充電と静電エネルギー比
- **解答番号**：PHYSICS:15
- **正解**：`1`
- **重要論点**：
  - スイッチ開放時（電荷一定）における極板間隔倍加時の静電エネルギー U1
  - スイッチ再閉（電圧一定）における静電エネルギー U2
  - エネルギー比 U2/U1 の計算

**【題目大意】**
最初、電圧 $E$ で充電したコンデンサーのスイッチ S を開き、極板間隔を2倍にしたときの静電エネルギーを $U_1$ とする。次に極板間隔を2倍のまま S を閉じて充電したときの静電エネルギーを $U_2$ とする。$\frac{U_2}{U_1}$ を求めよ。

**【公式正解】**：$\textcircled{1}$（$\frac{1}{4}$）

**【詳細推導・解答プロセス】**
初めの極板間隔における電気容量を $C_0$ とする。

1. **状態 1（S を開いて極板間隔を 2 倍にする）**：

   $$U_1 = \frac{Q^2}{2C_1} = \frac{(C_0 E)^2}{2 \left(\frac{1}{2}C_0\right)} = C_0 E^2$$

   スイッチを閉じたため、コンデンサーの極板間電圧は電池の起電力 $E$ に固定される。

   $$U_2 = \frac{1}{2} C_1 E^2 = \frac{1}{2} \left(\frac{1}{2}C_0\right) E^2 = \frac{1}{4} C_0 E^2$$

3. **比の計算**：
   $$\frac{U_2}{U_1} = \frac{\frac{1}{4} C_0 E^2}{C_0 E^2} = \frac{1}{4}$$

## 問18：3本の平行導線間に働く電磁力と未知電流・受力方向の決定
- **解答番号**：PHYSICS:18
- **正解**：`5`
- **重要論点**：
  - 平行電流間の引力・斥力の法則（同方向は引力、逆方向は斥力）
  - L1, L2 に働く正味の力に基づく L3 の電流向きと大きさの連立解析
  - 作用・反作用の法則および L3 に働く力の導出

**【題目大意】**
等間隔 $a$ で並ぶ平行導線 $L_1, L_2, L_3$ について、$L_1, L_2$ には上向きの電流 $I$ が流れている。$L_1$ には単位長さあたり右向きに大きさ $F$ の力が、$L_2$ には左向きに大きさ $2F$ の力が働いているとき、$L_3$ の電流の向き、受ける力の向き、およびその大きさを求めよ。

**【公式正解】**：$\textcircled{5}$（下向き，右向き，F）

**【詳細推導・解答プロセス】**
1. **電流間の相互作用力**：
   間隔 $a$ の同じ向きの電流 $I$ 間に働く引力を $f_0 = \frac{\mu_0 I^2}{2\pi a}$ とする。
   $L_1$ と $L_2$ は互いに引き合うため、$L_1$ は右向きに $f_0$、$L_2$ は左向きに $f_0$ の力を受ける。

2. **$L_3$ の電流の向きと大きさの決定**：
   $L_2$ に働く合力は左向きに $2F$ である。
   $L_1$ からの引力 $f_0$（左向き）に加えて、$L_3$ からの力も左向きでなければ合力が大きくなり得ない。
   $L_2$ が $L_3$ から左向きの力を受けるということは、$L_2$ と $L_3$ の間に **斥力** が働くことを意味する。
   したがって、$L_3$ の電流は $L_2$ と逆向き、すなわち **下向き** である。

3. **連立方程式の立式**：
   $L_3$ が単位長さあたり間隔 $a$ の導線に及ぼす斥力を $f'$ とすると、$L_1$（距離 $2a$）に及ぼす斥力は $\frac{f'}{2}$（左向き）である。
   - $L_1$ に働く力（合力は右向きに $F$）：
     $$f_0 - \frac{f'}{2} = F$$
   - $L_2$ に働く力（合力は左向きに $2F$）：
     $$f_0 + f' = 2F$$
   下の式から上の式を引くと：
   $$\frac{3}{2}f' = F \implies f' = \frac{2}{3}F$$
   これより $f_0 = 2F - \frac{2}{3}F = \frac{4}{3}F$ となる。

4. **$L_3$ に働く力の計算**：
   $L_3$（下向き電流）は、上向き電流 $L_1, L_2$ の両方から斥力（右向きの力）を受ける：
   - $L_2$ からの斥力：右向きに $f' = \frac{2}{3}F$
   - $L_1$ からの斥力：右向きに $\frac{f'}{2} = \frac{1}{3}F$
   合力の大きさは：
   $$F_3 = \frac{2}{3}F + \frac{1}{3}F = F$$
   向きは **右向き** である。

以上より、電流の向き：下向き、力の向き：右向き、力の大きさ：$F$ である。
よって、正解は選択肢 $\textcircled{5}$ である。
