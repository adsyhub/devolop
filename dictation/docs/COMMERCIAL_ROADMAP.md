# 商用化路线与验收标准

## 当前判定

目前已是「可部署的单课程产品候选」，但还不能把现有 JLPT 音频包标为可销售商品。自架／一次性销售路线的自动化技术门禁已通过；人工逐句听审、内容商用权利、真实浏览器验收与旧密钥撤销仍缺外部证据。若采订阅 SaaS 模式，CMS、账号／订阅、合规文件与运营监控仍须完成。

| 领域 | 现况 | 收费前门禁 |
|---|---|---|
| ASR／内容生成 | 517 片段、431 练习题；自动质量 0 错误／0 警告 | 逐句人工听审与母语质量签字确认 |
| 安全／秘密 | 明文密钥已移除 | 旧密钥撤销；集中秘密管理；依赖与弱点扫描 |
| 学习体验 | 响应式 PWA、离线音频、稳定进度；Edge／Chrome E2E 通过 | 完成手机 Safari／Chrome、用户与无障碍验收 |
| 用户数据 | 无账号与数据库 | 认证、权限、汇出／删除、备份恢复演练 |
| 收费 | 无 | Checkout、webhook 幂等、权益同步、自助取消、退款 |
| 内容运营 | 有来源绑定修补、具名逐句审听工作台、权利台帐与内容 revision | 完成真实审听及授权证据；规模化后再导入 CMS |
| 质量工程 | 56 个自动测试；Edge／Chrome 桌面与手机 E2E；证据与候选 ZIP 均绑定当前来源 | 真实设备／Safari、性能、无障碍与发布回滚演练 |
| 可观测性 | 无 | 错误、延迟、任务失败、付款与核心漏斗告警 |

## 里程碑 1：可封闭测试的学习产品

- 已建立响应式 Web App／PWA，完成音频加载、逐句循环、键盘操作与作答差异。
- 已保存匿名本地进度；加入提示、揭晓、重试、错题列表与旧版纪录迁移。
- 用真实 iPhone、Android、Safari、Chrome、Edge 测试日语 IME 与背景音频。
- 对 20–50 名 JLPT 学习者封闭测试，验证首课完成率与 D7 回访。

完成定义：新用户无需说明可在 2 分钟内完成第一句；没有数据遗失、音频卡死或 IME 误提交的 P0 缺陷。

## 里程碑 2：可小规模收费

- 后端采 Postgres＋物件保存＋非同步工作伫列；音档使用短效签名 URL。
- 账号、跨装置进度、SRS、内容目录与管理 CMS。
- 使用 Stripe Checkout／Billing 与 Customer Portal；webhook 必须验签、可重放且幂等。
- 发布隐私政策、使用条款、退款政策、内容版权与 AI 数据流说明。
- 加入错误监控、结构化日志、健康检查、每日备份与一次恢复演练。

完成定义：沙盒与正式付款全流程验收；取消立即生效或期末生效的权益一致；客服能查询订阅但不能看用户密码或完整付款数据。

## 里程碑 3：公开商用

- WCAG 2.2 AA 人工＋自动验收；键盘、焦点、对比、字幕与触控目标达标。
- 依 OWASP ASVS 5.0 建立最低 L1 验证清单；对上传、ZIP、CMS、认证与 webhook 做威胁建模。
- APPI／目标市场法规审查；最小化搜集音档、作答与分析事件，定义保留期与删除 SLA。
- 内容授权台帐涵盖权利人、用途、地域、期限、证据与下架责任人。
- 服务 SLO：学习 API 月可用性 99.9%；P95 互动 API < 400ms；内容工作失败可重试且不重复计费。
- 灰度发布、数据库 migration 回滚、事故分级与联络流程演练。

## 本轮已完成

- 清除启动脚本中的明文 API 密钥，补 `.gitignore` 与环境变数范例。
- 修正 `--out` 数据夹处理与安全档名，使既有未使用的解析函式真正生效。
- 以音档 SHA-256＋转录参数校验续跑缓存；同大小但不同内容不再误判。
- 以来源摘要绑定每个 AI 结果，防止旧批次翻译错配。
- JSON 与 ZIP 改为原子输出；ZIP 验证 CRC、重复／危险路径、音档存在与非空。
- 加入 API timeout、参数边界、输出长度／空讲解验证与 prompt injection 防护。
- 生成可机器读取的质量报告，并提供一般／严格发布门禁。
- 依赖延迟加载，纯逻辑可在没有 CUDA／Whisper 的 CI 执行。
- 测试由 4 个增至 56 个。
- 新增响应式学习播放器：逐句循环／调速、IME 安全作答、宽松／严格评分、字符差异、三级提示、答案与解析、错题、本地进度及键盘操作。
- 新增稳定课程与句子 ID、内容 revision、题型与可练习伫列；纯标记不再污染完成率。
- 进度与错题由阵列索引迁移到句子 ID，内容修订后不会对错题。
- 将旧有中文字段统一转换为 `zh-Hans-CN`，且后续生成管线默认输出简体中文并保留转换历史。
- 新增 Service Worker，缓存应用壳、manifest 与音档，离线时支持音频 Range 请求。
- 以系统 Edge 与 Chrome 跑桌面／手机四组真浏览器核心流程，验证在线与离线音频；证据绑定 `courseId`、`contentRevision` 与全部前端文件摘要。
- 新增 localhost 人工审听工作台，要求逐句明确确认转写稿、时间、翻译与解析；禁止批次隐性核准。
- 新增来源绑定的商用权利台帐，逐项验证权利类型、地域、期限、证据档 SHA-256 与具名审批。
- 候选 ZIP 逐档比对当前 manifest、音频与前端；发布就绪报告的技术状态通过，四项外部审批维持阻挡。
- 最终抽查以 large-v3／small 独立上下文交叉转写，将 89 个 ASR 假题号重建为 28 个真实片段，并新增长串标记与「解析自承转写可疑」的质量规则。
