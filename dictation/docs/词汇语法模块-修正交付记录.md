| 在线刷新丢失草稿 | 服务端会话与客户端状态按题目/轮次合并；仅保留仍待答的草稿；同版本未读反馈恢复。浏览器覆盖输入与反馈刷新 |
| 勾选待审题仍不能组题 | 请求直接传 `includeDrafts`；题面、反馈、报告显示待审提示，离线统计排除待审题 |
| 提交成功但响应丢失 | 保留原 operationId 和待确认操作，禁止未确认时重新提交同一答案；重连以原 ID 重放，服务端只保存一次 |
| 跳过后返回作答 409 | 新增服务端 `resume-skipped`，分配未使用轮次并更新服务端队列；重复重排不追加同一待答任务；支持离线重排按顺序同步 |
| 跳过后的首次有效回答不进入 SRS | 区分“第 0 轮”和“首次实际作答”；跳过后的首次作答可以调度，后续巩固不重复推进；报告和统计保持一致 |
| 准备离线后当前题仍没有本地判题数据 | 提交时读取最新离线题包，避免使用准备之前的闭包快照 |
| 真正停服后刷新无法恢复 | Service Worker 对合成的后端不可达响应附加明确标志；前端按连接故障处理并读取已有会话缓存 |
| 草稿保存/快捷键 | 保存退出等待写入完成；保存失败显示提示；数字键选择触发草稿持久化 |
| 存储失败推进题目风险 | 浏览器注入 IndexedDB 写事务失败，确认不发送作答、不推进游标；保留原答案 |
| 全量考试接口回归失败 | 补放弃状态迁移、关闭会话拒绝再作答、恢复进度、逐题恢复及跨试卷复习汇总接口 |
| 考试页面缺失返回与恢复入口 | 增加保存返回、继续未完成作答、显式放弃；专题按完整试卷题组选择数量；普通练习整组交卷后反馈，错题复习保留逐题查看 |
| 测试受本机配置/日期影响 | 缺模型测试显式清空本机继承模型；最近 7 天测试动态生成近期时间，不依赖固定 9 月 1 日 |

## 内容范围与审校边界

词汇包现有 **325 条**，原有 300 条的 entryId / entryKey 全部保留。候选处置结果为自动唯一匹配 300、模型逐项消歧 25、未匹配/未处置 0。模型消歧不计为人工审核。

语法包保持 **191 条、48 单元**。两个包均没有缺中文释义或缺例句的条目，发布报告与内容版本一致。

**人工语言审校尚未完成，不能宣称所有题型已正式验收。** 当前 2,185 个生成模板保留待审状态（新增 25 词增加 100 个模板）；它们可通过明确的待审选项练习，但不进入正式正确率、错题统计或长期 SRS。没有把生成器检查、模型比对或结构测试伪装成人工审核。

逐条资格、待审题目身份、原因码及内容版本见 [内容资格清单](词汇语法内容资格清单.json)。可复现生成：

```bash
python scripts/lexicon_review_inventory.py
```

这份清单区分程序资格与人工语言准确性结论。原方案的“每种正式题型至少 20 道人工审核样本”仍需要实际审校人员逐条完成，代码修正不能替代这项工作。
