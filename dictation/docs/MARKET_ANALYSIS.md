# 日语听写软体市场与功能基准

数据日期：2026-08-13。价格会依地区、促销与结算周期变动，以下以各产品官方页当时显示为准。

## 市场结论

优秀的听写产品卖的不是单次辨识，而是一个完整学习闭环：`听音 → 输入 → 精准比对 → 提示／揭晓 → 解释 → 错题回流 → 间隔复习 → 进度与成就`。内容量能吸引用户，反馈质量和复习机制决定留存，账号／付款／客服／隐私与内容授权才让产品真正能收费。

本项目最有价值的差异化方向，是「面向简体中文用户的 JLPT 日语精听」：保留真实考试／自然语速音频、逐句离线练习、AI 语法与易错音解析，再以人工审核保证可付费内容质量。不要正面模仿综合型语言平台的内容广度。

## 建议的产品功能优先级

### P0：能收费前必须完成

1. 听写播放器：单句循环、前后句、A-B 区间、0.5–1.5x、倒退 2 秒、音量与全键盘操作。
2. 日语输入评分：IME 组字期间不误送出；区分汉字／假名／标点；显示字词级增删改；可设置严格或读音等价模式。
3. 教学反馈：逐级提示、揭晓答案、中文翻译、文法／词汇／连音与易错音、再次作答。
4. 错题与复习：错句自动入列，采间隔重复；跨装置同步进度、正确率、重播次数、学习时间。
5. 内容 CMS：转录、翻译、时间轴、授权数据与审核状态可编辑；未通过质量门禁不可发布。
6. 商业底座：Email／社交登入、订阅与自助取消、试用／优惠码、发票、权限、客服与退款流程。
7. 质量与信任：隐私政策、删除／汇出数据、API 密钥管理、备份恢复、错误监控、可用性监控、WCAG 2.2 AA。

### P1：验证留存后加入

- 个人化难度、每日任务、连续学习与周报。
- 点词字典、假名／音调、个人单字本、Anki 汇出。
- 跟读录音与发音反馈。
- JLPT N5–N1、题型、语速、主题与口音筛选。
- 内容推荐与「只练常错音／文法」模式。

### P2：扩张能力

- 教师班级、派课、学生报表与席次付款。
- 用户合法上传内容、非同步生成、用量配额与版权申诉。
- 原生行动 App、完整离线同步、家庭方案。

## 定价假设

市场年付折合月价约落在 US$7–20，综合型平台月付可达 US$30。因本产品初期聚焦单一语言与听写，建议先验证：

- Free：完整试用 5 课，每日有限复习，无信用卡。
- Plus：日本 ¥980/月或 ¥7,800/年；台湾 NT$199–249/月，可解锁全部课程、SRS、离线与进度同步。
- Teacher：按席次报价，包含派课与班级报表。

这是待 A/B 测试的价格假设，不是最终定价。关键指标应是启用率（首日完成 3 句）、D7／D30 留存、每周有效听写句数、错题复习完成率、试用转付费与退款率，而不只是注册数。
